## 2. 变量与常量


## 3. 基本类型

```go
// 数值
var i int        // 平台相关：32 位或 64 位
var i32 int32    // 明确 32 位
var i64 int64
var u uint64
var f float64
var c complex128

// 字符串（不可变，UTF-8 编码）
s := "你好"
r := []rune(s)   // rune = Unicode 码点
b := []byte(s)   // byte = uint8

// 布尔
flag := true

// 零值（声明未初始化时的默认值）
var n int        // 0
var t string     // ""
var p *int       // nil
var s []int      // nil
var m map[string]int  // nil
```

**关键**：Go 没有 null/undefined 概念，只有"零值"。

## 4. 控制流

```go
// if（没有括号，可以带初始化语句）
if err := doSomething(); err != nil {
    return err
}

// switch（可以没有表达式，作为 if-else if 链）
switch {
case score >= 90:
    grade = "A"
case score >= 80:
    grade = "B"
default:
    grade = "F"
}

// for（唯一的循环关键字）
for i := 0; i < 10; i++ { }

// 等价 while
for condition { }

// 无限循环
for { }

// range 遍历
for i, v := range slice { }
for k, v := range map1 { }
for i, c := range "你好" { }  // rune 遍历
```

## 5. 函数

```go
// 多返回值（Go 的标志性设计）
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// 命名返回值
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return  // 裸返回
}

// 可变参数
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

// 函数作为一等公民
type Handler func(req *Request) Response

// 闭包
func makeCounter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

// defer：函数退出时执行（LIFO）
func readFile(path string) error {
    f, err := os.Open(path)
    if err != nil {
        return err
    }
    defer f.Close()  // 无论怎么返回都会执行
    // ...
    return nil
}
```

## 6. 数组、切片、Map

```go
// 数组（长度是类型的一部分，很少直接用）
var a [5]int
a[0] = 1

// 切片（日常用的"动态数组"）
s := []int{1, 2, 3}
s = append(s, 4)
fmt.Println(len(s), cap(s))  // 长度和容量

// make 预分配（性能优化）
s := make([]int, 0, 100)  // 长度 0，容量 100

// 切片是引用类型，共享底层数组
a := []int{1, 2, 3, 4, 5}
b := a[1:3]    // [2, 3]
b[0] = 99
fmt.Println(a)  // [1, 99, 3, 4, 5]  ← a 也变了

// Map
m := map[string]int{"a": 1, "b": 2}
m["c"] = 3

v, ok := m["d"]  // ok = false，v = 0（零值）
delete(m, "a")

// Map 不是并发安全的！多协程读写要用 sync.Map 或加锁
```

## 7. 结构体与方法

```go
type User struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"`
}

// 构造函数（Go 没有 new 关键字用于结构体，惯例是 NewXxx）
func NewUser(name, email string) *User {
    return &User{Name: name, Email: email}
}

// 方法（receiver）
// 值 receiver：方法内部的修改不影响原对象
func (u User) DisplayName() string {
    return u.Name
}

// 指针 receiver：可以修改原对象
func (u *User) UpdateEmail(email string) {
    u.Email = email
}

// 使用
u := NewUser("Alice", "a@example.com")
u.UpdateEmail("alice@example.com")
```

**经验法则**：
- 小结构体（< 64 字节）可以用值 receiver
- 需要修改原对象，用指针 receiver
- 同一个类型的方法 receiver 风格要一致

## 8. 接口

Go 的接口是**结构化类型**（duck typing），只要方法签名匹配就自动实现。

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 组合
type ReadWriter interface {
    Reader
    Writer
}

// 实现：不需要显式 implements，只要有 Read 方法就自动实现 Reader
type MyFile struct{ /* ... */ }

func (f *MyFile) Read(p []byte) (n int, err error) {
    // ...
    return 0, nil
}

// 空接口 any（Go 1.18+ 的别名）
var x any = 42      // 可以赋任何值

// 类型断言
if s, ok := x.(string); ok {
    fmt.Println("string:", s)
}

// 类型 switch
switch v := x.(type) {
case int:
    fmt.Println("int:", v)
case string:
    fmt.Println("string:", v)
default:
    fmt.Println("unknown")
}
```

## 9. 错误处理

Go 的错误处理哲学：**错误是值，显式处理**。

```go
// 经典模式
result, err := doSomething()
if err != nil {
    return fmt.Errorf("doSomething failed: %w", err)  // %w 包装错误
}

// 自定义错误
type NotFoundError struct {
    Resource string
    ID       string
}

func (e *NotFoundError) Error() string {
    return fmt.Sprintf("%s with id %s not found", e.Resource, e.ID)
}

// 判断具体错误类型
var notFoundErr *NotFoundError
if errors.As(err, &notFoundErr) {
    // 处理 not found
}

// 判断哨兵错误
if errors.Is(err, sql.ErrNoRows) {
    // 处理无记录
}
```

**反模式**：
```go
// ❌ 吞掉错误
result, _ := doSomething()

// ❌ 只打印不处理
if err != nil {
    log.Println(err)
}

// ✅ 要么处理，要么往上传
if err != nil {
    return fmt.Errorf("context: %w", err)
}
```

## 10. Go 1.24 / 1.25 / 1.26 新特性

### Go 1.24（2025-02）

- **泛型类型别名**正式支持：`type MySlice[T any] = []T`
- **Swiss Tables** map 实现：内置 map 性能显著提升
- `tool` 指令：`go tool install` 统一管理开发工具
- `testing/synctest` 包：测试中模拟时间流逝

### Go 1.25（2025-08）

- `testing/synctest` 正式 Stable
- `encoding/json/v2` 实验包：性能和 API 改进
- 容器感知的 GOMAXPROCS：在 K8s 容器中自动适配 CPU 限额

### Go 1.26（2026-02）

- **泛型自引用**：泛型类型可以在自己的类型参数列表中引用自身
- `new` 函数的操作数可以是表达式：`p := new(someExpression)`
- `go fix` 命令完全重写，支持代码自动迁移
- `go tool doc` 移除，统一用 `go doc`

来源：[Go 1.26 Release Notes](https://go.dev/doc/go1.26)

## 11. 生产项目清单

```
新项目必备：
☐ go.mod 明确 Go 版本（推荐 go 1.25 或 1.26）
☐ golangci-lint 配置（staticcheck、govet、errcheck、revive）
☐ Makefile 或 Taskfile.yml 封装常用命令
☐ Dockerfile 多阶段构建（alpine 或 distroless）
☐ GitHub Actions / CI 跑 test、lint、build
☐ 使用标准库的 log/slog 结构化日志
☐ context.Context 作为首个参数传递
☐ 所有外部依赖（DB、Redis、HTTP）都有 context 超时
☐ 不要滥用 goroutine，注意泄漏
☐ 错误包装使用 %w，不是 %v 或 %s
```
