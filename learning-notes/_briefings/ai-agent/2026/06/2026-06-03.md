## 📌 头条

### Anthropic 秘密提交 IPO，估值 $965B

Anthropic 于 6 月 1 日向 SEC 提交了保密 S-1 文件，准备在今年秋天上市，估值达到 9650 亿美元，超越 OpenAI 的 8520 亿。紧随其后的是 Claude Opus 4.8 发布——agentic coding 得分从 64.3% 提升至 69.2%，fast mode 速度提高 2.5 倍、成本降低 3 倍。此外 Anthropic 宣布 6 月 15 日起 Agent SDK 使用将独立计费（$20-$200/月信用额度），不再与对话式 chat 共用额度。对开发者意味着：如果你在用 Claude Code / Agent SDK 做 long-running agent 任务，现在就该评估新计费模型对工作流的影响。

### OpenAI Codex 扩张：6 款白领插件 + 登陆 AWS Bedrock

OpenAI 在 6 月 2 日一口气发布 6 个面向白领工作的 Codex 插件——覆盖数据分析、创意生产、销售、产品设计、股权投资和投行场景，把 Codex 从纯代码工具推向通用知识工作。同日，GPT-5.5 和 Codex 正式上架 Amazon Bedrock，企业用户可以通过 AWS 统一调用。这标志着 agent 平台之争进入「渠道分销」阶段——选择哪个云就能用哪家模型。如果你在 AWS 上有工作负载，现在可以直接在 Bedrock 里试跑 Codex agent 了。

## ⚡ 快讯

- **SafeMCP**：新论文提出 MCP 环境下的主动权力调控框架——通过 environment-grounded look-ahead reasoning 限制 agent 的 power-seeking 行为，在 action space 扩张时预防灾难性错误放大 → [arXiv](https://arxiv.org/abs/2606.01991)
- **MARFT**：多智能体强化微调框架（v5 更新），首次系统性地将 RL fine-tuning 应用于 LLM-based Multi-Agent Systems，解决传统 RL 在多 agent 协作中的信用分配问题 → [arXiv](https://arxiv.org/abs/2504.16129)
- **Leyline**：为 agentic inference 设计的 KV Cache 指令系统——解决 agent 对话中 tool call 重试、轨迹修剪导致的缓存失效问题，突破传统 chatbot 式 append-only 假设 → [arXiv](https://arxiv.org/abs/2606.01065)
- **Agent OS**：论文提出将 agentic control plane 集成到操作系统内核的架构——让进程、权限、文件系统等 OS 抽象适配概率性、长时运行的 agent 实体 → [arXiv](https://arxiv.org/abs/2606.01508)
- **Google DeepMind**：CEO Demis Hassabis 在 I/O 大会表示人类站在「奇点前的山脚」，AI agent 是 AGI 的 practice run；Gemini Spark 作为通用 agent 已支持跨 app 推理与代理操作 → [Axios 报道](https://www.axios.com/2026/05/26/deepmind-ceo-demis-hassabis)
- **Xcode 26.3**：Apple Xcode 原生集成 Claude Agent SDK，开发者可在 IDE 内使用 subagent、后台任务和插件——无需离开 Xcode → [Anthropic 公告](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)
- **SkillReact**：新论文度量开放 agent 技能生态中的组合安全风险——单独安全的 skill 组合后可能产生 unsafe 行为，提出 compositional security measurement 框架 → [arXiv](https://arxiv.org/abs/2606.00448)

## 📈 趋势

- 🆕 Agent 计费独立化 — Anthropic 率先将 agent workload 从订阅中拆出单独计费，预期其他厂商跟进
- 🔺 MCP 安全研究井喷 — SafeMCP、SkillReact、tool poisoning defense 等多篇论文同期出现，MCP 攻击面已成为独立研究方向
- 🔺 Agentic inference 优化 — Leyline (KV cache)、LayerRoute (层跳过)、Hybrid Verified Decoding 三篇论文围攻 agent 推理效率
- 🆕 Agent OS 概念成型 — 从内核调度到文件系统，传统 OS 抽象正在被重新设计以适应 probabilistic、long-lived agent 实体
