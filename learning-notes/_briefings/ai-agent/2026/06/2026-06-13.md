### 美政府发出口管制令，Anthropic 暂停 Fable/Mythos

美国政府于 6 月 12 日下午 5:21 ET 向 Anthropic 发出出口管制指令，要求立即暂停所有外国公民对 Fable 5 和 Mythos 5 模型的访问权限——包括在美境内的外籍员工。Anthropic 被迫对所有客户关闭这两款模型，而非仅限海外用户。这是 AI 领域首次出现行政命令级别的模型封锁，影响覆盖已经上线仅 3 天的 Fable 5 公开版。Anthropic 回应称这是「一场误解」，正与政府沟通恢复访问。对你的影响：如果你在用 Claude Fable 或 Mythos API，现在需要回退到 Opus 4.8；跨国团队需要紧急评估模型访问合规风险。

### Agent 安全周：LangGraph RCE 漏洞链 + Agentjacking 新攻击

Check Point Research 本周公开 LangGraph 三个漏洞的链式利用路径：从 SQLite checkpointer 的 SQL 注入（CVE-2025-67644）到 msgpack 反序列化 RCE（CVE-2026-28277），自托管 agent 基础设施可被完全控制。同日，Tenet Security 披露「Agentjacking」攻击：通过伪造 Sentry 错误事件，经 MCP 集成触发 AI coding agent 在开发者机器上执行任意代码——无需恶意软件、无需凭证。两个发现叠加说明：agent 的记忆层和工具调用层正在成为主攻面。对你的影响：自托管 LangGraph 立刻升级 checkpoint 组件到最新版；审查 Sentry MCP server 配置，限制 tool 白名单。

→ [Check Point 研究](https://research.checkpoint.com/2026/from-sqli-to-rce-exploiting-langgraphs-checkpointer/) / [Hacker News 报道](https://thehackernews.com/2026/06/langgraph-flaw-chain-exposes-self.html) / [Agentjacking 详情](https://thehackernews.com/2026/06/agentjacking-attack-tricks-ai-coding.html)
