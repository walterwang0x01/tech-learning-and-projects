### MCP Tool Poisoning 攻击进入生产环境，20 万实例暴露

安全研究显示 MCP 的 Tool Description Poisoning（TDP）攻击已从论文走向实战：攻击者在工具描述元数据中注入恶意指令，利用 LLM 的指令遵循能力劫持 Agent 行为。arXiv 最新 benchmark 测试 20 个主流 LLM Agent，o1-mini 攻击成功率高达 72.8%，且能力越强的模型越容易中招。如果你在生产环境使用 MCP，现在就该审计所有第三方 tool description，并考虑加入静态元数据校验层。

→ [Medium 深度分析](https://medium.com/@superml/mcps-security-debt-just-came-due-tool-poisoning-is-in-production-200-000-instances-are-exposed-fe6f7412de5a) / [arXiv: TDP Benchmark](https://arxiv.org/abs/2605.24069) / [arXiv: MCP 安全分析](https://arxiv.org/abs/2603.22489)
