## 📌 头条

### 76 个 MCP 工具把四大模型扔进《文明 VI》

英国前首相府数据科学家 Liam Wilkinson 用一个周末，通过游戏引擎端口搭了 76 个 MCP 工具，把 Claude、GPT、Gemini 等四个顶尖模型接入《文明 VI》互相对战，打了 23 局。AI 看不到画面，整个世界只有管道符分隔的文本和六边形坐标。他的动机很实在：选择题测不出真本事——同一批模型在他做的 GovBench（3497 道英国政务题）上 GPT-5 能考 99.26 分，但治国靠的是多线程决策、资源分配、长期规划和不完整信息下的判断，这些得靠一个真正的「考场」。结果有个 AI 造核弹炸了法国，然后还是输了。对你意味着什么：这是 MCP 作为通用工具层最有说服力的演示之一——把任意带 API 的环境包成工具集，agent 就能在里面长程行动；想给自己的 agent 设计评估，与其堆 benchmark，不如做一个能逼出真实决策的沙盒。

→ [原文](https://www.ithome.com/0/969/570.htm)

### 出口管制松动：Fable 5 临近解禁，亚洲替代涌现

Anthropic 前沿模型的出口管制拉锯进入新阶段。6 月 12 日的管制令让 Anthropic 紧急关停 Mythos 5 与 Fable 5 后，周五美国政府已批准向部分本土「可信机构」开放 Mythos 5；据 Axios 消息，针对 Fable 5 的限制最快下周解除。与此同时管制的副作用开始显现——TechCrunch 报道亚洲 AI 创业公司趁禁令拖延期密集推出 Mythos-like 模型抢占空窗。Fable 5 与 Mythos 底层架构一致但定位不同，前者面向更广的应用场景。对你意味着什么：如果你的 agent 管线依赖 Anthropic 前沿模型，访问恢复有时间表但仍存变数，值得现在就把模型层抽象出来、备好可切换的开源或亚洲替代，别让单一供应商的监管节奏卡住你的发布。

→ [Mythos 开放报道](https://www.semafor.com/article/06/27/2026/us-releases-powerful-anthropic-model-mythos-to-some-us-companies) / [Fable 5 即将解禁](https://www.ithome.com/0/969/553.htm) / [亚洲替代涌现](https://techcrunch.com/2026/06/27/asian-ai-startups-launch-mythos-like-models-as-anthropics-export-ban-drags-on)
