## 📌 头条

### Anthropic 发布 Claude Tag：AI 同事正式入驻 Slack

Anthropic 推出 Claude Tag，让 Claude 以团队成员身份加入 Slack 频道——不是传统 chatbot，而是一个能理解上下文、规划任务、异步执行并主动汇报的 agent。开启 ambient 模式后，Claude 会主动追踪沉寂的 thread、标记已解决问题。Karpathy 评价这是 LLM UI/UX 的第三次重大范式迁移：从聊天窗口到 IDE 插件，再到 inline 协作。目前面向 Claude Enterprise 和 Team 用户开放 beta。

→ [官方介绍](https://www.anthropic.com/news/claude-tag) / [开源中国报道](https://www.oschina.net/news/466760)

---

### LangChain 实战：多 Agent 协作如何把调试时间砍掉 93%

LangChain 官方博客发布了一篇关于 Agentic Engineering 的深度长文，展示了基于 LangGraph 构建的多 agent 系统如何模拟真实工程团队——不只是加速写代码，而是让 agent 各司其职处理设计、实现、Code Review、测试。实测中，调试时间减少 93%，跨团队交付周期大幅压缩。这是目前最详细的 production-level multi-agent 架构公开案例之一。

→ [原文](https://www.langchain.com/blog/agentic-engineering-redefining-software-engineering)

- **OpenAI × Broadcom**：OpenAI 首颗自研推理芯片 Jalapeño 曝光，与 Broadcom 联合设计，专为 LLM 推理负载优化，早期测试每瓦性能显著优于现有方案。 → [公告](https://openai.com/index/openai-broadcom-jalapeno-inference-chip)
- **千问 Qwen-AgentWorld 开源**：阿里千问开源首个原生语言世界模型 Qwen-AgentWorld，从 CPT 阶段就内置环境建模目标，单一模型覆盖七大领域的 agent 交互环境模拟。 → [报道](https://www.oschina.net/news/466541)

- **LangChain × EU AI Act**：距离 EU AI Act 合规截止日（8 月 2 日）不到 6 周，LangChain 发布详细指南展示 LangSmith 如何帮助满足各项要求。 → [指南](https://www.langchain.com/blog/langsmith-langchain-oss-eu-ai-act)

## 📈 趋势

- 🆕 Agent 从工具变同事：Claude Tag 的 ambient 模式标志着 agent 交互从 request-response 转向 proactive collaboration，人管 agent 正在变成"管理一个高效下属"
- 🔺 Agent 安全成为独立研究方向：RIFT-Bench、Red-Teaming the Agentic Red-Team、Cryptographic Certificates 同天出现，学术界开始系统性地攻克 agent 特有攻击面
- 🆕 World Model 路线升温：Qwen-AgentWorld 将环境建模原生植入训练全流程，比 post-hoc adapter 路线更彻底——agent 不再只是调 API，而是内建世界理解
- 🔺 框架层加速整合：OpenAI 收拢 Agent Builder 到 SDK、CrewAI 引入 FlowDefinition、LangGraph 修安全漏洞——生态在从"百花齐放"走向"少数平台化"
