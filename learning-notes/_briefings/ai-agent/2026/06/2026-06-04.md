## 📌 头条

### GitHub 审计 + MCP 精简，Agent 工作流 Token 成本降 62%

GitHub 工程团队公布了一套 agent 工作流成本优化方案：通过每日审计 tool definition schema 膨胀、精简 MCP server 注册数量，将 Copilot 内部 agentic 工作流的 token 消耗最高降低 62%。背景是社区发现 GitHub MCP server 每次调用固定消耗约 42k token 的工具定义开销。对你来说，如果你在 Claude Code 或其他 coding agent 里接了多个 MCP server，现在就值得跑一轮 token 审计——关掉不用的 tool、合并冗余 schema，效果立竿见影。

→ [InfoQ 原文](https://www.infoq.cn/article/OVsDMDL84vuoXXdTDALd)

### Hugging Face 将 MCP 工具接入 Reachy Mini 机器人

Hugging Face 发布教程，展示如何为 Reachy Mini 桌面机器人接入 MCP 工具协议——模型读取 tool 描述后自主调用表情、摄像头、头部运动等能力。这是 MCP 从纯软件编排走向物理世界的标志性案例：协议的 tool name + description 范式天然适配机器人动作抽象。如果你在做 embodied agent 或 IoT 场景，可以参考这个最小化集成路径。

→ [HF Blog](https://huggingface.co/blog/adding-mcp-tools-to-reachy-mini)
