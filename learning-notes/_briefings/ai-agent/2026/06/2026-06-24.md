## 📌 头条

### Sakana AI 发布 Fugu：7B 编排模型指挥多 Agent 达到前沿水平

东京 AI 实验室 Sakana AI 于 6 月 22 日发布 Fugu 和 Fugu Ultra，一个将多模型编排封装为单一 OpenAI 兼容 API 的系统。核心是一个 7B 参数的 RL Conductor 模型，动态选择、委派和验证任务给 GPT-5、Claude 等前沿模型。Fugu Ultra 在 SWE-Bench Pro 得分 73.7、TerminalBench 82.1，声称比肩 Fable 5。这意味着不训练前沿模型也能通过编排层达到前沿性能——对受出口管制约束的团队尤其有意义。试试用它跑你的 coding benchmark，看 routing 开销是否值得。

→ [Sakana AI 官宣](https://gigazine.net/gsc_news/en/20260622-sakana-fugu-multi-agent-system-ai) / [深度分析](https://www.panewslab.com/en/articles/019eef07-5781-73cd-8d49-3f6918641f98)

### Netflix 工程师开源 Headroom：为 Agent 压缩 60-95% Token，4.4 万 Star

Netflix 高级工程师 Tejas Chopra 因一次 287 美元的 Claude 对话账单，开发了 Headroom——一个 Apache 2.0 的 context 压缩层。它作为 library、proxy 或 MCP server 部署在应用与 LLM 之间，对 tool output、日志、RAG chunk 做智能压缩，原始数据可按需还原。GitHub 已获 4.4 万 star。Context engineering 正在成为 Agent 应用的必修课，这是目前最成熟的开源方案。

→ [GitHub](https://github.com/chopratejas/headroom) / [开源中国报道](https://www.oschina.net/news/465967)
