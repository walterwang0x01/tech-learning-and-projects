### Anthropic 秘密提交 S-1，估值近万亿美元冲刺 IPO

Anthropic 于 6 月 1 日向 SEC 秘密提交 S-1 招股书草案，抢在 OpenAI 之前启动 IPO 流程。公司当前估值接近 1 万亿美元，若顺利上市将成为 AI 领域最大规模 IPO。这意味着 Claude 生态将获得更充裕的资本弹药，对依赖 Anthropic API 的开发者来说，长期服务稳定性和定价策略值得持续关注。

### Claude Code Dynamic Workflows：最多 1000 个并行子 Agent

Anthropic 发布 Claude Code 动态工作流（research preview），允许 Claude 自主编写编排脚本，在单个会话中调度数十到数百个并行子 agent 执行任务。实测案例中，一个周末完成了 Bun 从 Zig 到 Rust 的移植（约 75 万行代码）。该功能已在 CLI、Desktop、VS Code 扩展及 API/Bedrock/Vertex AI 上可用。对你来说：如果你有大型重构或跨模块迁移任务，现在可以用 claude code /workflow 试试水。

→ [官方博客](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code) / [TechCrunch](https://techcrunch.com/2026/05/28/anthropic-releases-opus-4-8-with-new-dynamic-workflow-tool/)

## ⚡ 快讯

- **MiniMax M3**：上海稀宇发布 M3 模型：首个同时具备前沿 Coding 能力、1M token 上下文和原生多模态的开源权重模型。SWE-Bench Pro 超过 GPT-5.5，采用全新 MSA（MiniMax Sparse Attention）架构。 → [官方博客](https://www.minimax.io/blog/minimax-m3)
- **OpenAI GPT-5.5 + Codex 登陆 Amazon Bedrock**：GPT-5.5、GPT-5.4 和 Codex 正式 GA 上线 Bedrock，按 token 计费与 OpenAI 一致，推理在用户选定 Region 内完成。每周超 400 万开发者使用 Codex。 → [AWS 博客](https://aws.amazon.com/blogs/aws/get-started-with-openai-gpt-5-5-gpt-5-4-models-and-codex-on-amazon-bedrock)
- **MCP 开销实测引发争议**：Quandri 工程团队实测：4 个 MCP server 的工具定义消耗约 21000 token，占 200K 上下文窗口的 10.5%。部分场景下直接用 CLI 更划算，引发社区对 MCP 协议开销的重新审视。 → [开源中国报道](https://www.oschina.net/news/450274)
- **LangChain × Rippling**：Rippling 用 LangChain Deep Agents + LangSmith 在 6 个月内将 AI 部署到 HR、IT、财务、薪资等全产品线，服务百万级用户。 → [案例详情](https://www.langchain.com/blog/how-rippling-went-ai-native-across-every-product-in-6-months-with-deep-agents-and-langsmith)
- **Agent 安全：Trojan Backdoor 攻击范式**：新论文揭示 agentic harness 的木马后门攻击：攻击者在文件/工具输出中嵌入 prompt injection，agent 读取后存储并延迟执行，单步无恶意但组合后实现持久控制。 → [arXiv](https://arxiv.org/abs/2605.31042)
- **Aaron Levie 谈企业 Agent 的 #1 问题**：Box CEO 指出企业 AI Agent 最大瓶颈是上下文获取：知识碎片化分散在不兼容的遗留系统中，访问控制进一步加剧了 context 问题。 → [原推](https://x.com/levie/status/2061247380897579500)
