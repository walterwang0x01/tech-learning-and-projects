## 📌 头条

### Sakana Fugu：一个模型指挥所有模型

东京 AI 实验室 Sakana AI 在 6 月 22 日发布了 Fugu 和 Fugu Ultra——一个多 Agent 编排系统，但交付形态是单一的 OpenAI 兼容 API。Fugu 本身是一个被训练来做模型调度的语言模型，它背后动态协调 GPT-5.5、Gemini 3.5 Flash、Claude Opus 4.8 等多个前沿模型，自动处理任务拆分、委派、验证和结果聚合。Fugu Ultra 在 SWE-Bench Pro 上跑出 73.7，TerminalBench 2.1 达到 82.1，GPQA-D 95.5，宣称比肩 Claude Fable 5 和 Mythos Preview——而这一切不需要自己训练前沿模型。

这意味着什么？如果你正在做 multi-agent 编排，Fugu 代表了一种新范式：把编排逻辑本身变成一个可训练的模型，而不是硬编码的 DAG 或 state machine。对于受出口管制无法直接使用 Fable/Mythos 的团队，这是一条可行的替代路径。

→ [Sakana 官方发布](https://sakana.ai/fugu-release/) / [The Decoder 分析](https://the-decoder.com/sakana-ais-fugu-orchestrates-multiple-llms-to-match-anthropics-fable-and-mythos-benchmarks/)

### AWS Summit NYC：Agentic AI 全栈发布 + Grok 4.3 登陆 Bedrock

AWS Summit NYC 上周开幕，VP of Agentic AI Swami Sivasubramanian 在 Keynote 上集中发布了一系列 Agent 基础设施：AgentCore Gateway 加入 Web Search 工具、Agentic Retriever 支持复杂多步检索、Amazon Quick 可直接在桌面端创建和运行 multi-step agents。同时 xAI 的 Grok 4.3 正式上线 Bedrock，这是 xAI 首次进入 AWS 生态——$1.25/$2.50 per million tokens，支持 1M token context，configurable reasoning effort（none/low/medium/high），在 Tau2 Telecom tool-calling 基准和 Omniscience 幻觉率测评中均排第一。

对开发者来说，Bedrock 上可选的 reasoning 模型越来越多元，Grok 4.3 的价格优势（比同级别便宜 2-10x）让它成为高频 Agent 调用的务实选择。

→ [AWS 官方博客](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-ny-summit-recap-local-zone-in-hanoi-grok-4-3-in-bedrock-price-reductions-and-more-june-22-2026/) / [xAI 公告](https://x.ai/news/grok-amazon-bedrock)
