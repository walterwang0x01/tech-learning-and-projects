### GPT-5.6 三连发：Sol/Terra/Luna 限量预览

OpenAI 于 6 月 26 日发布 GPT-5.6 系列三款模型：旗舰 Sol、日常工作 Terra 和轻量快速 Luna。应白宫要求，首批仅向政府审核通过的可信合作伙伴开放，计划数周内转为公开可用。Sol 在 MMLU-Pro 和 SWE-bench 上刷新纪录，Terra 定位平衡性价比，Luna 主打低延迟低成本。这是 OpenAI 首次在政府介入下分阶段发布模型，标志着前沿 AI 进入「准入审查」时代。对开发者意味着：近期可关注 API waitlist，同时评估现有 Agent 切换 Sol 的收益。

### MCP 2026 规范定稿：全面无状态化

Model Context Protocol 发布 2026-07-28 规范 Release Candidate，核心变化是协议层完全无状态——取消了初始化握手和 Session ID，协议版本与客户端信息改为附在每个请求的 _meta 字段中。这意味着 MCP server 可以水平扩展、任意路由请求，不再需要粘性会话。对现有 MCP 服务开发者来说，7 月 28 日是最终截止日，握手逻辑和 session 管理代码需要在此之前迁移。同时新增 OAuth 2.0/OIDC 原生认证和 Tasks 扩展（异步长任务）。

→ [解读](https://web-hub.aliz.ai/blog/mcp-specification-release-candidate) / [安全挑战](https://www.securityweek.com/new-enterprise-ready-mcp-specification-brings-new-security-challenges/)
