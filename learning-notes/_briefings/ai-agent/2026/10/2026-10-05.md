### 常驻 Agent 三方混战：Muse、Dots、Grok Bot

七周之内 xAI（Grok Bot，8 月）、Meta（Muse，9 月 8 日）、OpenAI（Dots，9 月 29 日 DevDay）各自推出了同一个形态的产品：关掉 App 还在后台跑的「常驻 Agent」。三家的公开说法高度一致——每个 Agent 跑在自己的云虚拟机上，保有独立的文件和记忆，按计划或事件触发任务，只在需要人做决定时才来找你。OpenAI 说 Dots 接了 4000+ 应用（Slack、Spotify 等），Meta Muse 走 WhatsApp 审批交互。对做 Agent 的人来说，这是从「一问一答的 chatbot」正式转向「带持久状态 + 人类审批关口 + 主动 check-in」的架构范式，和 LangGraph 的 checkpointer / interrupt 思路是同一条路——值得照着这个 human-in-the-loop 模式重新审视自己的 Agent 要不要加持久化和审批门。

→ [Forbes: OpenAI Dots](https://www.forbes.com/sites/the-prompt/2026/09/29/with-dots-openais-answer-to-muse-and-instinct-is-here/) / [三方对比](https://aimultiple.com/always-on-agents) / [36氪: Muse vs Dots 定位](https://www.36kr.com/newsflashes/4011299198898310)

### TypeSafe Jev：不说话、只做决定的 Agent 内核

前 OpenAI 研究员 Diogo Almeida（ChatGPT 共同发明人之一）的创业公司 TypeSafe，9 月 15 日放出了一个叫 Jev 的模型——它不生成文本，而是把输入状态归类到预设的输出集合里（是/否、一个数值评分、或从给定列表里选一个），并带可校准的置信概率。官方把训练方法称作 RLCD（面向校准决策的强化学习），对标常规的 RLHF/RLVR。据 IT之家引《华尔街日报》，上线三周日处理量已达 1 万亿 token，并已催生仿制品；此前拿到 DCVC 领投的 4000 万美元种子轮。为什么对 Agent 有意义：一个 Agent loop 里有大量「小判断」——该调哪个模型、这条命令安不安全、哪段上下文相关、任务是不是真的做完了，这些用大模型跑既慢又贵且不可复现，Jev 这类「决策专用模型」正好卡这个位。官方宣称约 0.1 秒、几分之一美分一次调用。注意融资额与跑分来自单一来源，技术边界要等更细的报告。

→ [IT之家](https://www.ithome.com/1/009/744.htm) / [20 个 Agent 用例](https://www.marktechpost.com/2026/09/27/20-agentic-use-cases-of-typesafe-ais-jev/)

## 📈 趋势

- 🆕 「常驻 Agent」成新品类：持久虚拟机 + 独立记忆 + 事件触发 + 需要决定时才找人，三家七周内齐发
- 🔺 决策专用小模型兴起：Jev 这类「不生成文本只给带概率的决定」被定位成 Agent loop 里路由/安全/相关性判断的内核
- 🔺 编码 Agent 工具链「插件化 / 可迁移」加速：DeepSeek Harness 一切皆插件 + Claude Code 兼容层，生态桥接插件涌现
- 🔻 纯 chatbot 形态退场：产品叙事从「一问一答」转向「后台持续干活 + 人类审批关口」
