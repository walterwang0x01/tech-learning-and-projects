## 📌 头条

### Proof-Carrying Messages：让 Agent 间的话可验证

A2A 和 MCP 只认证通道，不管发送方说的是不是真话，被提示注入的 Agent 可以把编造的“测试通过”“已获人工批准”一路传下去。这篇论文提出 PCM：每条声明附带来自只增不改的 Merkle 日志的证据和包含证明，由 Agent 无法控制的签名方背书，接收方离线验证，结果分 proven / unproven / failed 三态，仅凭 Agent 自述的声明永远不算 proven。权限以授权链传递，根是一次被记录的人工批准，链只能收窄。论文在 926 条真实运行消息（其中 712 条是 16 类谎言）上测试，PCM 误收 10 条，全部是过期证据（1.4%），普通 A2A 全收，验证约 1 ms。这是作者自己设计的基准，结论待独立复现。如果你在用 LangGraph 或 MCP 做多 Agent 编排，可以对照它检查“下游怎么确认上游真的跑过测试”这一环。

→ [arXiv](https://arxiv.org/abs/2610.39109)

### 编码 Agent 听谁的：仓库先例压过默认偏好

5,625 次试验、4 个编码 Agent 的对照实验显示，Agent 默认实现选择一致，但当仓库里已有先例与默认冲突时，几乎都跟随先例（359/360）。先例的影响力取决于位置：三个本地相关文件采用率 96%，兄弟资源文件只有 4%，仅改文件摆放位置就能让采用率从 0% 变到 100%。当新任务意图与旧代码冲突时，写明优先级的规则远胜只给代码示例（59/60 对 38/60）。在四个开源仓库验证中，harness 加载一条规则把联合成功率从 0/120 提到 117/120。对你的意义很直接：在 CLAUDE.md / steering 里写清“冲突时以谁为准”，比指望 Agent 看代码猜意图可靠得多。

→ [arXiv](https://arxiv.org/abs/2610.38244)

## ⚡ 快讯

- **Cursor Agent SDK**：Cursor 10 月 20 日开放了内部构建 Bugbot、Security Reviewer、Rollouts 等托管 Agent 所用的框架，让团队按自己的工作流搭 Agent，而不是二选一（用现成产品或从零写）。以上来自国内媒体转述，细节未能核对官方原文 → [开源中国](https://www.oschina.net/news/503287/cursor-agent-sdk)
- **Gemini 4 Carbon**：据报道，Google DeepMind 发布 Gemini 4 Carbon，距上一代 Argon 两周，主打网络安全与长程任务能力，Artificial Analysis Intelligence Index v5.0 得 59 分居首，安全能力先向白帽开放。数字为媒体转述，未核对官方 → [开源中国](https://www.oschina.net/news/503286/google-gemini-4-carbon)
- **Mistral Large 4**：据报道权重开源，1 万亿参数、原生多模态，称是开放权重里编码最强的；“第一”的依据是 Cognition 的私有基准 FrontierCode 2.0，属厂商侧说法，需独立评测佐证 → [开源中国](https://www.oschina.net/news/503310/mistral-large-4-oss)
- **Snyk VulnBench 2.0**：108 个可被攻击者触达的漏洞上，Snyk Code 召回 82.4%，Claude Code /security-review（Opus 5 xhigh）79.3%，两者合计覆盖 101/108。结论是静态扫描和 AI 安全 Agent 互补，且 harness 策略对漏检的影响不亚于模型。注意作者来自 Snyk，对自家产品有利益关系 → [arXiv](https://arxiv.org/abs/2610.38617)
- **Sandman（Amazon）**：Amazon 内部在共享 Kubernetes 上为 Agent 强化学习运行的沙箱服务，处理成千上万环境的突发创建，用于工具执行与评测，是自建 Agent 训练基础设施的一手参考 → [arXiv](https://arxiv.org/abs/2610.39711)
- **Agent Transfer Protocol**：针对跨组织 Agent 协作提出服务器中介的通信架构，覆盖稳定通信入口、实例离线时的消息接收和延迟读取后的来源验证，可与 A2A 方案对照阅读 → [arXiv](https://arxiv.org/abs/2610.38398)
- **PoPLi 串谋检测**：提出行为测试：共享暗号的搭档会对消息措辞敏感，局外 Agent 不会，用两者行动变化之差检测只看消息内容的监控发现不了的隐蔽串谋 → [arXiv](https://arxiv.org/abs/2610.37849)
- **Seq@K**：指出 Pass@1 / Pass@K 无法衡量模型利用反馈迭代修正的能力，提出在顺序反馈下评估语言模型的指标，贴近真实 Agent 工作流 → [arXiv](https://arxiv.org/abs/2610.37859)
