## 📌 头条

### REA：把逆向工程做成 agent 的一个本地工具

一个叫 REA（Reverse Engineer Anything）的开源项目 10 月 7 日上线后迅速冲上 GitHub trending，一天内涨了近三千星、总量过万。它不是又一套逆向工具链，而是一个本地 MCP server——把反编译、二进制分析、JS/Electron/.NET 拆解这些能力接给 Claude Code、Codex、Cursor、Gemini CLI 等十来个 coding agent。用法很直白：指着一个 App 问「这个功能怎么实现的」，agent 调 REA 去 inspect，带着证据和「它查不到什么」的边界回答你，再按你的技术栈重写一版。原生工作流还能挂 Ghidra、Hopper、IDA Pro，分析全在本地跑。MIT 许可。对你意味着：MCP 正在从「连数据库连 API」扩到「连专业工具」，想体验的话装个本地 server 挂到你常用的 agent 上就能试。

→ [GitHub](https://github.com/ChristopheAI/reverseengineeranything) / [开源中国报道](https://www.oschina.net/news/502941)

### 「只输出概率、不输出文本」的决策模型成新物种

同一天前后冒出两家做同类东西的：做非文本模型 Jev 的 TypeSafe AI 上线几周就以 75 亿美元估值融了 8.7 亿（a16z 领投，红杉、DCVC 跟投），公司称三分之一的世界 500 强在用；微软也下场发了 Microsoft-Decision-1。它们的共性是不给文本、给结构化输出——给一组候选答案，模型为每个选项输出一个校准过的概率，可以直接被软件消费来决定「执行 / 搁置 / 转人工」。这是对「让 LLM 吐 JSON 再解析」这条老路的正面挑战：决策环节不再经过自然语言，置信度天生带在输出里。融资额和「500 强占三分之一」是公司自述口径，先按一手来源看待。对做 agent 的人：如果你的 agent 卡在「分类 / 路由 / 要不要动手」这类判断上，这类决策模型值得盯一眼。

→ [Jev 融资报道](https://www.oschina.net/news/502935/the-maker-of-non-text-ai-model-jev-valued-at-7-5b) / [Microsoft-Decision-1](https://www.oschina.net/news/502942/microsoft-decision-1-model-foundry)

**StoreBench: A Live-Commerce Environment for Evaluating and Training Autonomous Operator Agents** — 提出一个「活」的电商评测环境：agent 在真实的生产级电商后端运营一家中型服装店，环境会自行变化而非只在 agent 行动时推进，考验长周期自主运营。→ [arXiv](https://arxiv.org/abs/2610.10942)

**AgentHorizon: Evaluating Agentic Judges for Long-Horizon Computer-Use Tasks** — 系统评估「用 agent 当裁判」判定长周期电脑操作任务是否成功的可靠性：一条由大量截图和动作组成的轨迹看着像完成了，实际可能违反了指令约束。→ [arXiv](https://arxiv.org/abs/2610.11050)

**TestJack: Should you trust the results in coding benchmarks?** — 指出几乎所有编码 benchmark 仍沿用「通过固定单测即正确」这一几十年前的标准，而单测常只覆盖部分需求，agent 可以 reward hack 或静默漏实现却仍全绿；通过让评测器自我演化来审计这些 benchmark。→ [arXiv](https://arxiv.org/abs/2610.10619)
