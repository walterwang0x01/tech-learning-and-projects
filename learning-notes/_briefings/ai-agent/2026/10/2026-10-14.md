## 📌 头条

### 个人 Agent 一夜混战：Meta、Google、阿里同台

一天之内三家都把牌亮了。Meta 发布 Muse Wonder 系列，官方称其在个人和专业 agent 任务上拿到 SOTA，并把它定位成通向『个人超级智能』的一步；Google DeepMind 全球上线 Gemini 4 Argon，主打 coding、企业工作流和一个冷门方向——网络安全防御，输出上限做到 100 万 tokens；阿里的个人助理「千问 Go!」开放体验申请，官方演示里它帮用户跟平台客服磨出了航班延误理赔和淘宝价保退款。三条线指向同一件事：Agent 的竞争正从『会聊天』转向『能替你把事办完』。对你来说，值得挑一个能接 MCP / 工具调用的产品亲手跑一遍真实任务（订票、退差价、查数据），感受一下它在多轮里会不会掉链子。

→ [Muse Wonder](https://www.oschina.net/news/502995/meta-ai-muse-wonder) / [Gemini 4 Argon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon) / [千问 Go!](https://www.leiphone.com/category/industrynews/GalDeSPl8orEfNoI.html)

### LangChain 开源 Open SWE，补齐内部编码 Agent 骨架

LangChain 一口气推了围绕 Deep Agents 的几件东西，最值得关注的是 Open SWE——一个基于 Deep Agents 和 LangGraph 的开源框架，官方定位是给企业做『内部编码 Agent』提供核心架构组件。配套还上线了 Deep Agents Deploy（beta），号称是把模型无关、开源的 agent harness 快速部署到生产的最快路径，摆明了对标 Claude 的托管 Agent 方案。对 LangGraph 用户来说，这意味着不用从零搭长时任务的编排骨架；官方同时放出的几篇 harness engineering、context management 文章里，有把自家编码 Agent 从 Terminal Bench 第 30 名做到前 5 的具体做法，适合照着抄作业。

→ [Open SWE](https://www.langchain.com/blog/open-swe-an-open-source-framework-for-internal-coding-agents) / [Deep Agents Deploy](https://www.langchain.com/blog/deep-agents-deploy-an-open-alternative-to-claude-managed-agents) / [harness engineering](https://www.langchain.com/blog/improving-deep-agents-with-harness-engineering)
