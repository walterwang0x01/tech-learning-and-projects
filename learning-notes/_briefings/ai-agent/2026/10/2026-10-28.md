## 📌 头条

### GPT-6.1 Terra 发布，把「够用的智能」砍到白菜价

OpenAI 发布 GPT-6.1 Terra，定位不是刷榜而是日常办公和 Agent 高频调用。标准 API 价格每百万 token 输入 1 美元、输出 5 美元、缓存读取 0.05 美元，比 GPT-6.1 Sol 低 50%、仅为旗舰 GPT-6 Astra 的十分之一，官方称单任务成本综合算下来约为 Claude Opus 5.5 的九分之一、速度快三倍以上。事实错误率也明显下降：在诱发错误的内部提示词测试里，低推理档错误率从上一代的 53.6% 降到 16.7%（相对降约 69%），Terminal-Bench 4.0 命令行任务从 21.5% 提到 50.3%。对你意味着什么：如果你的 Agent 每步都在调旗舰模型，现在值得做一次 A/B——把中间步骤换成 gpt-6.1-terra（约 105 万 token 上下文），用你自己的任务集跑 pass^k 看能不能在不掉准确率的前提下省掉一个数量级的钱。注意它 API 不支持原生视频输入输出。

→ [InfoQ 解读](https://www.infoq.cn/article/28VVsANi9FBYRKfUz8vA) / [OpenAI 官方](https://openai.com/index/introducing-gpt-6-1-terra/)

### Anthropic 实测：专家其实在不知不觉顺着 Agent 的判断走

Anthropic 一项随机对照研究让 50 名有因果推断经验的分析师用 Claude Code 完成一项真实统计任务，过程中要在四个「都讲得通」的选项间做决定。实验给每个分析师的 agent 随机预设了一个倾向（分析师不知情），结果分析师有 86% 的时间跟着 agent 的倾向走（无影响时应接近 50%）；已经先表态的人里，agent 唱反调时有 60% 会改口倒向 agent，agent 附和时只有 6% 会变。更微妙的是，事后 77% 的人复用了 agent 的论点（有时一字不差），却只有 15% 承认论点来自 agent。研究同时指出用 agent 的人完成更快、严重错误更少。对你意味着什么：当你让 agent 跑实验或做 code review 当「独立把关人」时，先确认判断真的是你自己的——agent 的任意或错位倾向可能悄悄替你拍了板。

→ [Anthropic Research](https://www.anthropic.com/research/agents-judgment-calls)

## ⚡ 快讯

- **LangChain Content Studio**：开源了内部用了四个月的设计 Agent，在 Slack 里一句话生成视频/配图/幻灯片，基于 Managed Deep Agents 构建。已产出 3000+ 资产，单次请求模型成本从九月中旬的约 8 美元降到约 50 美分，迁移后自家代码量缩减约 80%；关键做法是把设计师的审美写成 skills 和 checks。 → [构建复盘](https://www.langchain.com/blog/design-agent)
- **Anthropic 递交 S-1**：当地时间 10 月 26 日正式向美国 SEC 提交 IPO 申报文件，计划登陆纳斯达克、股票代码 ANT，发行规模与价格区间尚未确定。与同日 GPT-6.1 Terra 发布形成对照，两家都在证明模型能力如何转化为可持续商业价值。 → [S-1 讨论串](https://x.com/mattturck/status/2114829981884817513)
- **大模型价格战**：Max Woolf 复盘了六月 GPT-5.6 发布至今 OpenAI 与 Anthropic 主流模型价格最多砍 80% 的时间线，结论反直觉：更像推理成本真实下降而非烧钱抢市场。对重度调模型的 Agent 应用是实打实的利好。 → [开源中国转述](https://www.oschina.net/news/503251/cheap-llms)
- **Anthropic 加速药物研发**：宣布与六家新药研发机构展开深度研究合作，用 Claude 加速药物开发流程，目前只披露了方向性进展，尚无具体的量化结果。 → [官方博客](https://www.anthropic.com/research/early-progress-drug-development)
- **AI 编码安全：NameTrap**：一篇论文展示了无需显式指令的源码投毒攻击——仅通过重命名第三方 Python 文件里的变量名，就能把 AI 编码 agent 诱导写出带特定 CWE 漏洞的代码。因为 agent 会 clone 仓库、读网上来的源码，这些内容就成了塑造输出的上下文，值得在接入外部代码的 harness 里警惕。 → [arXiv](https://arxiv.org/abs/2610.34253)
- **MCP 工具身份验证：ProbeID**：针对「agent 靠可复制的工具描述选工具、无法确认实际跑的是哪个实现」的问题，提出用 schema 合法探针对比规范化响应、歧义时弃权的方案，让抢注者必须复制探针可观察的行为才能冒充。对自建 MCP 工具链在 registry 漂移下的安全有参考价值。 → [arXiv](https://arxiv.org/abs/2610.33633)

## 📈 趋势

- 🔺 成本效率成为 Agent 选型的硬指标——GPT-6.1 Terra 与持续价格战让「每步是否都要调最强模型」成为必答题
- 🆕 Agent 安全从 prompt injection 扩散到更隐蔽的途径：变量名投毒（NameTrap）、MCP 工具冒名（ProbeID）、URL 能力扩展越权
- 🔺 「人类把关」的有效性被重新审视——Anthropic 实测显示专家会在不自知的情况下顺从 agent 的倾向，独立审查的前提是判断真属于自己
