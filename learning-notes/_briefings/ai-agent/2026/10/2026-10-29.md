## 📌 头条

### LangChain 讲透「Loop Engineering」：Agent 价值在循环里

LangChain 把 agent 架构拆成四层循环，值得对照自己的系统读一遍。Loop 1 是最基础的「模型调工具直到任务完成」（create_agent）；Loop 2 加一个 grader 按 rubric 校验输出、不达标就带反馈重试（RubricMiddleware，可以是确定性检查也可以 LLM-as-judge）；Loop 3 是事件驱动，用 cron/webhook/channel 把 agent 接进你的生态常驻后台；Loop 4 是「爬山循环」，拿生产 trace 喂一个分析 agent 去反过来改 harness 的 prompt/工具配置，让内层循环越跑越准。文章特别强调敏感动作（财务、数据库操作）必须保留真人审批。对你意味着：你手上的 Loop 1/2 已经成熟，接下来该把精力挪到 Loop 3/4——把 agent 接进真实系统并让它靠 trace 自我改进，价值才会复利。

→ [原文](https://www.langchain.com/blog/the-art-of-loop-engineering)

### Anthropic 把 AI for Science 扩到 20 家机构

Anthropic 宣布把 2025 年 5 月启动的 AI for Science 计划从个人科学家扩展到 20 家科研基金会和机构，给高影响力项目免费 Claude 额度，合作方包括 Sloan、Simons、Schmidt Sciences、美国 NSF 等。比「发额度」更值得注意的是两个落地样本：Anthropic 与 HHMI Janelia 共建了 Model Hardware Standard（MHS），一套让 AI agent 安全操作实验室仪器的共享规范，目前处于研究预览；Allen Institute 则在搭建「AI agent 团队」分析大型开放数据集，把过去几个月的人工分析压缩到几小时。对你意味着：MHS 这类「agent 安全操作物理设备」的标准化尝试，是 tool-use 从软件调用走向现实世界副作用的早期信号，值得盯着它的接口设计。

→ [原文](https://www.anthropic.com/news/ai-for-science-expands-foundations-research-institutions)

## 📈 趋势

- 🔺 Loop engineering / 「stacking loops」成为 agent 架构的共识框架——LangChain、swyx、多位 AI leader 都把价值归到「循环」而非单纯模型
- 🆕 MCP 工具描述正在成为 prompt injection 的主攻面（Log-To-Leak），tool metadata 的信任边界需要专门设计
- 🔺 Agent memory 从「能不能检索到」转向「检索到了会不会用、用的是不是过时事实」的治理问题
- 🔺 按 token 用量计费（consumption-based）被 Anthropic 招股书验证为主力商业模式，占比约 80%
