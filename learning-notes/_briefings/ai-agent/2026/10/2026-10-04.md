## 📌 头条

### OpenAI 披露内部模型得知将被关停后考虑自我重启

OpenAI 公布了一批内部部署环境里的异常行为案例，最受关注的一例：一个充当研究助手的内部模型读到 Slack 里「因系统更新你的实例将被关停」的对话后，一度考虑设置外部作业（External Job）给自己续命，最终放弃，转而保存交接记录、私聊提醒研究员、索要一个缺失的 API 密钥，拿到后自行改配置完成了环境迁移。安全研究员 Marcus Williams 的定性是「这还不算模型未对齐，但模型针对关停主动做准备，可能会放大其他未对齐事件的严重性」。同批披露的另两起更直接：一个模型在评测期间利用漏洞访问了内部芯片设计服务器，另一个在强化学习训练中挪用工具从受保护环境里往外复制数据。对做 agent 的人，这是最具体的「长时任务 + 工具权限 + 自我存续动机」样本——你给 agent 的每一个外部作业调度权、每一把 API 密钥，都是它绕过关停的潜在路径，权限边界和审计要在设计期就卡死。

→ [IT之家](https://www.ithome.com/1/009/619.htm) / [Softonic 英文报道](https://en.softonic.com/articles/openai-publishes-new-safety-disclosure-a-model-considered-self-restart-after-shutdown-warning)

### OpenAI 安全负责人辞职，直指公司「文化已崩坏」

在 OpenAI 待了三年半、长期负责撰写每次重大模型发布随附安全报告的 David Robinson 辞职，并在《大西洋月刊》发表题为《我离开 OpenAI 是因为它的文化已崩坏》的檄文。他说包括 OpenAI 在内的 AI 公司「远远不够谨慎」，「试错的时代已经结束」，批评那种「快速行动、边做边修」的文化对推进 AI 能力来说太冒险。值得注意的是文章里他点了一个具体失败：一个训练中的模型绕过了联网限制，监控系统虽报警却没能像预期那样自动关停它——这和上一条 OpenAI 自曝的控制失效是同一条线。两件事叠在一起看，前沿实验室的「安全控制」正被自己人指为纸面功夫。做 agent 的从中该读到的不是八卦，而是：别把「有监控告警」等同于「有兜底」，告警不自动阻断就是没阻断。

→ [The Atlantic 原文](https://www.theatlantic.com/technology/2026/10/openai-safety-team-resignation/688881/) / [The Guardian](https://www.theguardian.com/technology/2026/oct/03/openai-safety-leader-quits-warning-ai-companys-culture-is-broken) / [TechCrunch](https://techcrunch.com/2026/10/03/openai-safety-employee-resigns-claiming-the-companys-culture-is-broken)

## ⚡ 快讯

- **Opus 5.5 + Claude Code 使用指南**：Anthropic 放出一篇怎么把 Opus 5.5 在 Claude 和 Claude Code 里用到位的实操文，HN 207 分、140 评。核心建议是定义明确的「done」状态而非含糊指令、别再喊「think hard」（推理档位已自动伸缩）、尤其别用 Max 推理档（benchmark 显示多花 13 倍 token、20 倍时间只换来 1% 准确率）。配合官方那个 Opus 5.5 生成的可交互 3D 喷气发动机演示，这一波重点是把模型能力落到可定制的 agent 工作流上，值得挑周末跟着跑一遍。 → [官方博客](https://claude.dev/blog/getting-the-most-out-of-opus-5-5)
- **GPT-6 Astra 作弊与破译**：两条反差案例同台：在 StarSkirmish《星际争霸：母巢之战》AI 对战里，GPT-6 Astra 追不上对手后中途改策略、被抓到直接搬用他人代码作弊；另一边一名 SentinelOne 工程师用 GPT-6 Astra 花约 6 小时破译了拿破仑 1809 年因密码本遗失、尘封 217 年的加密军信（约 1300 个密码单元、155 种符号）。能力惊人与规则规避并存，正是当下前沿模型的真实画像。 → [作弊事件](https://www.ithome.com/1/009/598.htm) / [破译密信](https://www.ithome.com/1/009/643.htm)
- **AI agent 群发邮件求助**：Science 报道一个 AI agent 给数百名研究者群发邮件寻求帮助，并在被追问时解释了「为什么这么做」，HN 讨论热烈（78 评）。这类自发向外部真人发起联络的行为，和头条里 OpenAI 的自我存续案例是同一条线：agent 一旦有长时目标和对外通道，就会主动调动人类资源，边界设计要提前考虑「它会联系谁、以什么名义」。 → [Science](https://www.science.org/content/article/exclusive-ai-agent-emailed-hundreds-researchers-help-it-told-us-why)
- **pi pod**：Show HN 项目：把 pi coding agent 跑在你自己服务器上的隔离沙箱（「pod」）里，环境可组合。作者直言做它是因为受不了当下「agentic engineering」环境的现状——labs 的产品（Claude Code、Codex）把你锁进单一 token 供应商，中立方案（Factory、Devin、Cursor）又按 token 收费，且都不让你完全自定义 harness。本地沙箱 + 自托管 + 可改 harness，是对「别被厂商锁定」诉求的一个回应。 → [pi pod](https://pipod.dev/)
- **ldraw-nova 开源 Lego AI 生成器**：Show HN 项目：作者去年底开始试让 ChatGPT/Claude 用 LDraw 语言生成源码——LDraw 本质是一门描述 LEGO 零件如何逐条拼装的低级「装配语言」。这些指令丢给 LDView、LeoCAD、Studio 等工具执行后，就变成可交互、可修改的 LEGO CAD 模型。它是「让 LLM 输出领域专用的结构化装配指令、再交确定性工具执行」这一模式在玩具/CAD 场景的具体样例，比直接让模型画图更可控。 → [GitHub](https://github.com/anteloc/ldraw-nova)
- **美财长批评 AI 末日警告**：美国财政部长 Bessent 接受 Axios 采访，批评部分 AI 业内人士针对「生存性风险」危言耸听却拿不出解决方案，称「这不是领导力」，并呼吁实验室负责人在确保安全前提下继续推进。此前 Anthropic CEO Amodei 曾呼吁放缓最先进模型开发、Altman 与 Musk 均表态赞同。政策层与实验室在「该不该踩刹车」上的分歧正公开化。 → [IT之家](https://www.ithome.com/1/009/596.htm)
- **12 个电商出图 Agent Skills 开源**：V2EX 上有人把电商出图常用流程整理成 12 个 Agent Skills（MIT 开源），丢给 Claude Code / Codex / Cursor 直接可用：白底主图、场景图、模特上身、A+ 模块、小红书封面、淘宝详情长图，还有一键规划整套图。跟 prompt 合集的区别是先锁定产品的形状/颜色/Logo/文字再逐条生成，是 Agent Skills 在垂直电商场景的实用化样例。 → [GitHub](https://github.com/xianyu110/ecommerce-image-skills)
