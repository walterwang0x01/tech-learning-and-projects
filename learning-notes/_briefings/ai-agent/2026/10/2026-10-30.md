## 📌 头条

### 托管 Deep Agents 加入浏览器与异步子代理

LangChain 发布 Managed Deep Agents v0.10，新增两项能力。一是浏览器使用：Agent 可以操作没有 API 的网站，遇到登录时把窗口交还给你自己登录。二是异步子代理，让后台任务不再阻塞主 Agent。官方说浏览器工具针对上下文占用做过调优。如果你在用 LangGraph 做长任务编排，可以对照看看“登录交接”这个设计，它比把账号密码塞给 Agent 稳妥得多。

→ [v0.10 发布](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents) / [浏览器使用详解](https://www.langchain.com/blog/browser-use-in-managed-deep-agents)

### MiniMax Code 开源 16 个日常 Agent 技能

MiniMax Code 团队把自己每天在用的工作流和 skills 开源，共 16 个。仓库开头就声明：这不是提示词合集，也不是“最佳实践”清单。内容覆盖如何让 AI 写的代码保持高标准、怎么判断任务该不该交给子 agent、长命令该等多久、长会话怎么不变迟钝等。这些是真实使用中踩出来的经验，适合拿来对照自己的 CLAUDE.md 或 skills 目录，挑几条能直接抄的。

→ [开源中国报道](https://www.oschina.net/news/503308)

## ⚡ 快讯

- **Vercel CI**：Rauch 称 Vercel CI 靠三点解决“AI 编码瓶颈”：更快更稳的基础设施、Turborepo 集成（少做重复工作）、Agentic CI。他还提到每天在全球 20 个集群上运行数百万个 microVM，这是他本人的说法 → [原帖](https://x.com/rauchg/status/2115539426684408300)
- **Vercel 模型别名**：Rauch 把模型别名比作“模型的 DNS”：别名解析到具体模型，可做流量调度，避免团队卡在旧模型版本上，也有助控成本 → [原帖](https://x.com/rauchg/status/2115573969369845855)
- **joLink**：开源工具，通过 MCP 接入现有 AI 编程助手，提供 Java 增量编译、测试、应用启动、热更新和调试，底层用 Eclipse JDT 但不需要打开 IDE。作者的目标是让 Agent 也能“改完接着跑” → [V2EX](https://www.v2ex.com/t/1253079)
- **Termexo v0.11.0**：MIT 开源的本地编程 Agent 工作台，用项目工作区组织真实终端、原生会话和任务。新版提供 Windows x64 与 macOS（Apple Silicon、Intel）安装包 → [开源中国](https://www.oschina.net/news/503267)
- **Mistral Large 4**：Hugging Face 发文欢迎 Mistral Large 4 上线（代号 Le Chonk）。页面没有给出更多细节，参数与许可证需看模型卡 → [HF 博客](https://huggingface.co/blog/mistral-large4)
