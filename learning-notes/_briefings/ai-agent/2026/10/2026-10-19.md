## 📌 头条

### 网站开始把 Agent 挡在门外，DeepSeek 顺势给检索层标价

The Verge 报道，一些此前能被 AI agent 正常访问的网站（Cars.com、Amtrak 等）现在打不开了，背后是 Cloudflare 从 2026-09-15 起对新接入域名默认拦截它归类为 Training/Agent 的爬虫（带广告的页面），只放行 Search。换句话说，你写的会自己浏览网页的 agent，默认身份正从「被容忍」变成「被拒」。几乎同一时间 DeepSeek 把自研 Search/Fetch API 开放给所有开发者，每个端点 1000 次成功请求 0.75 美元（失败、空结果、超时不计费），11 月 1 日北京时间 0 点起计费——官方和多家媒体都强调这个价远低于竞品普遍的 5 美元起。两件事放一起看是同一个信号：agent 自由抓网页的时代在收口，检索正在变成一个要付费、要守规矩的基础设施层。如果你的 agent 依赖浏览/抓取，现在就该盘一遍它走的是哪条检索通道、会不会被默认拦。

→ [The Verge](https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web) / [DeepSeek 定价](https://finance.yahoo.com/technology/ai/articles/deepseek-monetizes-agent-retrieval-layer-185236272.html) / [Cloudflare 政策](https://developers.cloudflare.com/bots/additional-configurations/block-ai-bots/)

### DeepSeek V4.1-Flash-1017 开源权重，主打低成本编码

DeepSeek 于 2026-10-17 把 V4.1-Flash-1017 以 MIT 许可传到 Hugging Face / ModelScope，API ID 为 deepseek-flash，价格不变。官方说法是一次「性能-费用的帕累托改进」：基准全面提升的同时缩短了任务耗时和输出长度，也就是跑得更快、输出更省。配套的 Search/Fetch API 见头条一。对做 agent 的人来说，它的卖点是「在为每个任务付前沿模型价之前，先拿一个便宜的编码模型试一遍」——具体是不是你场景里够用，建议直接拉下来在自己的 agent 流程里跑一遍 benchmark，官方公布的分数只是起点。

→ [官方公告](https://api-docs.deepseek.com/news/news261017) / [Hugging Face](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)

## ⚡ 快讯

- **HybridAgent 论文**：新论文提出让 agent 在「潜空间默想」和「文本输出」之间切换——内部推理走 latent 不解码成文字，只有要调工具或给最终答案时才落成文本，论文称可把推理计算成本降最多 73%（约 3.7x）。对 context 开销敏感的 agent 架构值得一看 → [arXiv](https://arxiv.org/abs/2610.18861) / [解读](https://cryptobriefing.com/hybrid-reasoning-agents-cut-compute-costs/)
- **Anthropic 开放外部审计**：2026-10-15 起让非营利机构 METR 的 6 名评估员拿到「类员工级」访问权（公司硬件、办公场地、内部系统，大致等同其自家风险评估团队），但客户数据、法律特权信息和模型架构仍不开放；另在与 Hugging Face 等洽谈。是头部实验室引入第三方审计的实质一步 → [Ars Technica](https://arstechnica.com/ai/2026/10/anthropic-gives-outside-ai-watchdog-employee-like-access/) / [CNBC](https://www.cnbc.com/2026/10/15/anthropic-metr-securebio-ai-safety-evaluators.html)
- **Anthropic 公益基金**：宣布将拿出公司 5% 的股份投入一个「公益基金」。这是其在筹备 IPO（传估值最高可达 2 万亿美元）背景下的动作，具体用途和治理细节以官方公告为准 → [官方](https://www.anthropic.com/news/public-benefit-fund) / [TechCrunch](https://techcrunch.com/2026/10/18/anthropic-says-its-committing-5-of-its-shares-to-a-public-benefit-fund)
- **Replit 换默认模型**：Replit CEO 称其 Agent 的默认模型从 Anthropic 换成 OpenAI，理由是性能、成本和合作关系；但平台仍保持模型中立，Claude 等其他模型用户照样能选。一个典型的「默认体验用一家、但保留模型选择权」的产品取舍 → [TechCrunch](https://techcrunch.com/2026/10/17/replit-is-no-longer-working-with-anthropic-ceo-says)
- **WhatsApp MCP**：Show HN 项目：一个单文件 MCP server，让 Claude 免费跑在 Cloudflare 上访问个人 WhatsApp 消息，还会连 Google 账号把联系人名字补上（否则搜索只能看到手机号）。想给自己的 agent 接即时通讯数据的可参考其实现 → [GitHub](https://github.com/finereli/whatsapp-mcp)
- **Sphinx 代码理解关卡**：开源 Show HN 工具，挂进现有编码 agent 流程：每次往生产环境推代码时弹一份问卷，考你是否真搞懂了这段 AI 写的代码。对「AI 代劳后人还得对结果负责」这个老问题是个有意思的刹车 → [项目](https://sphinx-six-theta.vercel.app/)
- **开源 agent 行为测试**：一篇博客称把 53 个开源 AI agent 跑了一遍行为测试、提了 37 个 bug（HN 热度不高，结论单一来源，当作一个测试方法的样本看）。给自己的 agent 建回归测试时可借鉴其用例思路 → [原文](https://defuzex.ai/blog/we-ran-53-open-source-ai-agents-through-behavioral-tests-and-filed-37-bugs)
