## 📌 头条

### LangChain 在 Interrupt 一口气更新全家桶

LangChain 发了 10 月 newsletter，把 Interrupt NYC 和 London 上公布的东西集中放出。最值得看的是 LangSmith Engine v2 和 Managed Deep Agents v0.9：Engine v2 新增了 agent 红队（上线前主动找问题）、更广的 issue 检测和「自动修复验证」，官方博客给的数字是内部基准上定位高影响 issue 的能力翻了一倍、在业界基准上写修复的质量提升 25%，定位是「你只负责 review 和 merge，它自己盯生产 trace、聚类失败、改 prompt 和代码」。Deep Agents v0.9 则主打跟具体运行上下文绑定的个性化 agent：能在 Slack 里响应、带 user 级 memory 和工具调用、能排任务，还自带免费 web search，而且声明支持 OpenAI/Google/Anthropic/Bedrock/Ollama 等任意模型。如果你在用 LangGraph 栈，Engine v2 的自动修复闭环值得起一个 demo 项目实测它改出来的 prompt 到底靠不靠谱——官方数字是自报的，别直接当结论。

→ [newsletter](https://www.langchain.com/blog/october-2026-langchain-newsletter) / [Engine v2 + Deep Agents 发布](https://www.langchain.com/blog/interrupt-2026-overview)

### 阶跃 Step 5 Preview 如期开权重

阶跃（StepFun）10 月 15 日按主页倒计时如期放出了 Step 5 Preview 的权重，模型和技术博客同天上线。参数口径几家来源一致：稀疏 MoE，总参数 600B、每 token 只激活 27B，支持 100 万 token 上下文，原生吃文本/图像/视频，面向的就是长程 Agent 任务——AI 编程、软件工程、长链路工具调用，官方还特别点了金融方向。要自己部署得先掂量硬件：BF16 下 600B 约需 1.2TB 显存（还没算 KV cache），基本是多卡服务器起步；想省显存可以看官方同时放出的 NVFP4 量化版。另一个信号是它的真实使用量——截至 10 月 15 日在 OpenRouter 周榜冲到第 2，近 7 天消耗约 18.8 万亿 token，API 定价 \$1 输入 / \$2.70 输出每百万 token，对想找便宜大上下文模型跑 agent 的人是个现成选项。

→ [权重 (NVFP4)](https://huggingface.co/stepfun-ai/Step-5-Preview-NVFP4) / [国内报道](https://www.oschina.net/news/503035/stepfun-ai-step-5-preview)

- **字节 Seed**：字节 Seed 把安全从「合规附庸」提成一级部门，新设「Seed Model-Alignment & Preparedness」专管大模型安全风险，并向全球招 10 位研究员；多家媒体称这是国内首家单独设安全与对齐部门的前沿实验室。 → [开源中国](https://www.oschina.net/news/503048)
- **苹果智能入华**：库克确认 Apple Intelligence 及其接入的阿里千问大模型已获批，10 月晚些时候面向中国用户发测试版，首批含实时翻译、书写工具、照片清除，Siri AI 暂不在列。 → [量子位](https://www.qbitai.com/2026/10/503640.html)

- **151 款 App 拒绝豆包代操作**：微信、淘宝、美团、DeepSeek 等 151 款应用集体拒绝豆包手机助手的 GUI 自动化代操作——GUI agent 替用户点手机 App 这条路，正撞上平台方的明确抵制，落地场景会受限。 → [雷峰网](https://www.leiphone.com/category/zaobao/VMod1gHtw3lRoiXd.html)

| 项目/论文 | 一句话 | 链接 |

| Terminal Agents Suffice for Enterprise Automation | 质疑 MCP / web agent 这类重型架构的必要性，论证很多企业自动化任务用终端 agent 就够了——给选型泼了盆冷水 | [→](https://arxiv.org/abs/2604.00073) |

**When Is Smaller Greener? Right-Sizing Language Models for Agentic AI** — 指出按「单次调用」比模型会误导 agent 选型：任务要所有步骤都成功才算成功，每步可靠性的微小差距会被长链路放大，该按「完成整个任务」的能耗/成本/时间来比。→ [arXiv](https://arxiv.org/abs/2610.19345)

**DeLoop: Repeated Actions as Self-Supervision for Long-Horizon Agents** — 发现 Qwen/Llama/Gemini 的 agent 普遍会「打转」：重复发同一个工具调用拿回完全一样的观察，而且历史被压缩进上下文窗口后更严重；用重复动作本身当自监督信号来减少这种空转。→ [arXiv](https://arxiv.org/abs/2610.19376)

**Towards Secure Agent Skills** — 系统梳理 Agent Skills（基于文件系统的技能打包标准）的安全属性与威胁分类，这个标准正被多个 agent 平台和社区市场快速采用，安全面却一直没人系统研究。→ [arXiv](https://arxiv.org/abs/2604.02837)

## 📈 趋势

- 🆕 开权重长程 Agent 模型密集落地：阶跃 Step 5 Preview（600B/1M 上下文）之外，小米也开源了空间音频理解模型，国产开源在往 agent 专用方向走
- 🔺 Agent 可靠性成研究主线：这批 arXiv 新论文集中在验证门禁、运行时监控、防打转、按任务（而非按调用）right-size 模型——都在解决「长链路里一步错污染全局」
- 🔺 Agentic web 的规则在重订：Cloudflare × OpenAI 做 AI discovery、AI Gateway 加 web search，内容抓取与分发正从「默认开放」转向「你的内容你定规则」
- 🔻 GUI 代操作遇阻：151 款头部 App 集体拒绝豆包手机助手代点，端侧 GUI agent 的现实落地空间被平台方压缩
