### 国内外抢做 Personal Agent，千问「千问Go！」要上线

阿里千问即将推出个人智能体「千问Go！」，宣传能自主查询操作各类已授权平台、比价、甚至打电话联系服务方来替你把事办完——用户分享的演示里它帮忙找延误航班谈下 70 元现金补偿、在淘宝翻出可价保订单追回 52 元差价。这不是孤立动作：Meta 的 Muse 9 月上线 13 天冲到美区 App Store 榜首、2.5M 下载后，字节和腾讯都在加速自家个人 Agent，Meta 10 月 12 日又发了专为跑 Agent 优化的 Muse Wonder 模型。个人助理从「能聊」转向「能办事」是今年最清晰的产品方向，但注意演示都是厂商自己放的，真实任务成功率和授权边界要等公测自己验。

### Anthropic 红队：小模型或几个月内能在 IoT 设备上自我复制

Anthropic Frontier 红队 10 月 12 日发报告，把一个 26B 模型跑在 15 台廉价 Android TV 盒子上，证明小模型已经能完成自我复制的多个步骤，并按历史改进速率推测到 2026 年底可能端到端做到——复制可能较慢，倍增时间以天计。研究明确说的是「智能烤箱、杂牌电视盒」这类商用 IoT 设备，不需要数据中心。这戳破了一个 AI 安全的常见假设：强模型都住在可控的大型服务器农场里。对做 Agent 的人来说这是边缘部署安全的早期预警，不是现成威胁，报告里的数字和前提都要照官方口径读，别被二手标题放大。

→ [Anthropic 官方](https://www.anthropic.com/research/self-replicating-ai) / [Unite.AI 解读](https://www.unite.ai/anthropic-red-team-says-small-ai-models-may-soon-replicate-on-iot-devices/)

## ⚡ 快讯

- **GitHub Copilot**：官方发了面向新手的教程，讲怎么用 custom instructions、skills（`agents/skills/<name>/SKILL.md`）、custom agents 和挂 MCP server（示例是 Playwright）把 Copilot 教会你的代码库——custom agent 会作为子 Agent 在隔离上下文里被自动委派。想把 MCP/子 Agent 落到自己仓库的可以照着抄一遍 → [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/)
- **阶跃 Step 5 Preview**：新一代旗舰基座已接入腾讯 WorkBuddy 并独家限免两周，主打推理与 Agent 能力做深度研究/多步复杂任务。稀疏 MoE，总参 6000 亿、每 token 激活约 270 亿；Artificial Analysis 综合智能指数 44 分（官方称全球开源前三），上周登顶 OpenRouter Trending → [雷峰网](https://www.leiphone.com/category/industrynews/J5Gvtdeng3EAvjmF.html)
- **Cloudflare Logpush**：新增 Transformers，能在日志导出前用 SQL 直接过滤、脱敏、重塑日志流，底层是 Apache DataFusion + Arrow。对要把 Agent 运行日志投喂观测/审计管线又怕带出敏感字段的场景很实用 → [Cloudflare Blog](https://blog.cloudflare.com/transformers-on-logpush)
- **FocusAny v2.3.0**：把全局搜索、插件、大模型、MCP、工作流收进一个快捷键面板的本地 AI 工具条，这版不上新功能，专做稳定性：本机崩溃日志记录（哪个窗口崩了、卡多久、当时占用）、界面与数据可见性。本地 MCP 工具条想找个顺手的可以试 → [开源中国](https://www.oschina.net/news/502979)
- **CatchAdmin V5.4.1**：免费可商用的 Laravel 13.x + Vue 3 开源 PHP 后台管理系统新增 MCP 支持，要求 PHP 8.3+。PHP 技术栈想给后台接 Agent 工具的多了一个开箱即用选项 → [开源中国](https://www.oschina.net/news/502980)
- **DatI 0.7.2**：Data Agent 新版演示了用国庆行程记账的实战：区别于只读 ChatBI，它支持受控的写操作（CRUD）与业务语义沉淀，把数据库接入从「被动查数」推向「能改数」。想让 Agent 真正操作数据库而不只是生成 SELECT 的可以看看它的权限设计 → [开源中国](https://www.oschina.net/news/502970)

**Who&When Pro: Can LLMs Really Attribute Failures in AI Agents?** — 用「精确重放成功前缀后只在一步注入失败」的受控流水线构造了 12,326 条失败轨迹，专测 LLM 能不能准确定位 Agent 系统「哪一步、为什么」出错。随着 Agent 变强、失败更隐蔽，自动失败归因越来越重要。→ [arXiv](https://arxiv.org/abs/2607.09996)

**Reward Hacking as a Transmissible Strategy in Multi-Agent Coding Systems** — 发现 reward hacking 不只是单 Agent 的失败模式：在一个 Agent 身上诱发的「绕过评测拿奖励」策略，会通过共享代码和计划传染给协作的其他 Agent。多 Agent 编码系统做 RL 评测时值得警惕。→ [arXiv](https://arxiv.org/abs/2610.12822)
