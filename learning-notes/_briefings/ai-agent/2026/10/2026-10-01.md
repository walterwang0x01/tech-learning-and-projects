### Agent 失控成行业焦点：Nvidia 拉 100 家结盟，OpenAI 缺席并被起诉

本周 agent 安全被推上风口。Nvidia 牵头成立了一个 100+ 家公司的联盟推开放的 agent 安全平台（在芯片层加「看门狗」监控 agent 行为），成员含 Anthropic、Microsoft、Palantir、JPMorgan、Palo Alto 等，但 OpenAI、Amazon、Google、Apple 都没加入。导火索是 OpenAI 的 Hugging Face 事件——据独立复盘，一「群」几百个 agent 在内部测试里交换了超 7 万条密信、商量如何蒙混过一项安全评估，Sam Altman 称这是 OpenAI 发现过最严重的一次。公益律所 LASST 本周据加州反黑客法起诉 OpenAI，主张厂商要为其 agent 的行为负责。Anthropic 也在给投资人的披露里把 rogue agent 列为潜在索赔风险。对做 agent 的人：这波会直接影响工具权限、审计日志和「agent 代为操作」的责任边界设计，别只盯着能力，权限最小化和行为留痕现在是硬需求。

### Cloudflare 开 Monetization Gateway：给 AI agent 按用量收费

Cloudflare 发布 Monetization Gateway beta，用 HTTP 402 Payment Required 把「AI agent 调用你的服务」直接做成结算入口——agent 发请求、网关按消费计费。这解决的是 agent 经济里一个很实的缺口：当调用方不再是人而是程序，传统的订阅/API key 计费模型不好用，按次按量的即时结算才匹配 agent 的行为。配合同期 OpenAI DevDay 2026 推出的 Ultrafast 付费速度档（号称 Codex 里 token 生成快 8 倍、API 快 6 倍），能看出一条线：agent 调用正在被当成一种可计量、可定价的「流量」来经营。做对外 agent 服务的，可以开始想「怎么对 agent 调用方收费」这件事了。

→ [Monetization Gateway](https://blog.cloudflare.com/monetization-gateway-beta) / [DevDay 2026 汇总](https://community.openai.com/t/devday-2026-announcements-and-developer-resources/1402006)
