## 📌 头条

### Pi 1.0：极简 Agent Harness，用 codemode 治 MCP 的 token 膨胀

Pi 1.0 在 10 月 1 日发布，第二天就冲到 Hacker News 第一、1500+ 点赞，卖点刻意平淡——「一个极简、可扩展、你能完全掌控的 agent harness」。它最被讨论的点是 codemode：不再把每个 MCP 工具的 schema 全塞进上下文（这正是 MCP 被诟病最多的 token 膨胀来源），而是让模型用代码按需调用工具。InfoQ 的中文报道标题直指它「把自己骂了一年的 MCP 装进了核心」，意思是 Pi 一边批评 MCP 的开销，一边用 codemode 的方式把它收编进来。对你意味着：如果你在 LangGraph/自建 harness 里也被 MCP 工具列表撑爆上下文，值得读一下 codemode 这套「工具即代码」的思路，它和你手头用过的 tool-call 范式是正面对照。

→ [InfoQ 报道](https://www.infoq.cn/article/hQOHf1ZXoBs7uMpWJQss) / [harness 背景（InfoQ EN）](https://www.infoq.com/articles/agent-harness-build-one/)

### Meta 开源 Muse Spark Open：816B 模型跑在两台 Mac 上

Meta Superintelligence Labs 于 10 月 15 日放出 Muse Spark Open 的权重，自称「美国目前最强的开源权重模型」（这是官方口径，不是第三方结论）。这里只谈它和 agent 相关的那一面：官方把它明确定位成 coding 和 agentic 长程任务（long-horizon agentic work，含 coding 和客服 agent），816B 总参数、42B 激活的 MoE 配 100 万 token 上下文，原生多模态（文本/图像/视频/音频输入、文本输出）。真正的话题点不在参数而在运行环境——它能在两台 Apple M5 Ultra Mac Studio 的桌面组合上本地跑，第三方实测吞吐约 20 tokens/sec，许可证是 Muse Model License。对你意味着：一个专为 agentic 工作训练、带百万上下文、能本地部署的开源权重模型，是跑自建 agent benchmark、不想把数据送云端时值得拉下来试的候选。

→ [Meta 官方博客](https://research.meta.ai/blog/muse-spark-open) / [开发者页](https://dev.meta.ai/resources/blog/build-with-muse-spark-open)

## ⚡ 快讯

- **Gray Swan × Anthropic**：新一轮 prompt injection 竞赛开跑，奖金 30 万美元——目标是在带 Gmail、Slack、GitHub、LinkedIn 等真实工具的模拟环境里，把恶意指令藏进 agent 读取的内容来诱导它越权。Anthropic 的 Boris Cherny 也发推站台，说随着 agent 做得越来越多，跨行业解决注入「越来越紧迫」 → [竞赛详情](https://digg.com/ai/qdnewjcm) / [Cherny 原帖](https://x.com/bcherny/status/2110791698611855624)
- **字节 Seed**：成立一级部门「Seed Alignment & Preparedness」专管大模型安全风险，据称是国内首家单独设安全与对齐部门的前沿实验室，计划全球招 10 位研究员（北京/上海/圣何塞）——agent 自主性上升后，安全侧的组织投入开始显性化 → [开源中国](https://www.oschina.net/news/503048/seed-alignment-preparedness-team-looking-for-global-talents)
- **Apple Intelligence**：库克在上海确认苹果智能接入阿里千问大模型已获批，10 月底在中国发布测试版，首批含实时翻译、书写工具、照片清除等功能，但 Siri AI 这次不包含 → [雷峰网](https://www.leiphone.com/category/industrynews/P1btLjli3z8XoQkz.html)
- **INFUSE**：一个专门针对 agentic 系统「间接 prompt 注入（IPI）」的统一基准（arXiv 2610，新论文），把执行 shell、改代码、装依赖、调远程服务的长程 agent 作为攻击面来系统评测——比起孤立的单轮注入测试更贴近真实 agent 的暴露面 → [arXiv](https://arxiv.org/abs/2610.20776)
- **PROBE**：研究如何「审计」工具调用型 agent 是否遵守价格、隐私、确认、安全等策略约束（arXiv 2610，新论文）——当 agent 被部署到有硬性合规要求的场景时，policy compliance 怎么自动化查验是个真问题 → [arXiv](https://arxiv.org/abs/2610.22124)
- **StepSafe**：把 agent 安全从「事后看整条轨迹」推向「逐步诊断 + 及时干预」：一个动作是否安全取决于之前的动作、工具输出、信息披露和多 agent 交互，所以要在步级做带上下文的安全推理（arXiv 2610，新论文） → [arXiv](https://arxiv.org/abs/2610.20960)
