## 📌 头条

### GPT-6.1 Terra 把重心压到 Computer Use，API 还降价 50%

OpenAI 在 10 月 26 日发布 GPT-6.1 Terra，定位是介于贵的 Sol/Astra 和便宜的 Luna 之间的中端模型，主打视觉推理和 Computer Use——看着屏幕认按钮、输入框、表格，拿到权限后自己点鼠标、打字、跨应用录数据。和以往侧重聊天写作、复杂推理的升级不同，这次明确瞄准「把活干完」的高频办公场景。最有信息量的是价格:官方称 API 价格较上一代下调约 50%(具体每百万 token 单价以官方页为准)。对你意味着:如果你在做 GUI agent 或 RPA 类自动化,这是一个值得立刻跑 benchmark 对比的候选——先拿自己真实的跨应用录单流程测一轮成功率和单价,再决定要不要换底座。

→ [开源中国报道](https://www.oschina.net/news/503232/openai-gpt-6-1-terra) / [另一篇](https://www.oschina.net/news/503228)

### Anthropic 向 SEC 递交 S-1,准备 IPO

Anthropic 10 月 26 日正式向美国 SEC 递交 S-1 招股书,为拟议中的首次公开募股做准备。官方公告本身只确认了递交这一事实,没有给出发行规模、估值区间或时间表(这些要等后续招股书细节披露)。对你意味着:Claude 和 Claude Code 是不少人日常 agent 工作流的底座,母公司走向上市意味着财务和产品路线会更受公开市场约束——短期产品不会变,但值得关注招股书里披露的收入结构和研发投入,那是判断 Claude 系列后续定价与稳定性的一手信号。

| 项目/论文 | 一句话描述 | 链接 |

| MCP-Injector | 协议感知的故障注入中间件,测 agent 对真实 MCP 工具故障的韧性:规模并不自动买来容错 | [→](https://arxiv.org/abs/2610.32555) |

**本周 MCP 安全密集出论文**——除上表的 MCPHunt、MCP-Injector 外,还有一篇 *Agentic AI Defense: Decode-Time Provenance Binding for MCP* 演示了「跨模态信任洗白」:把指令用 LSB/DCT/隐写藏进邮件签名图片,绕过文本扫描器混进多模态 agent,并提出解码时的来源绑定防御。如果你的 agent 接入了任何处理图片的 MCP 工具,这是个值得警惕的注入面。→ [arXiv](https://arxiv.org/abs/2610.31974)

**Agent harness 的可靠性正被单独拆出来评测**——*When Agents Fail: Model or Harness--Who's to Blame?* 用 Valid Completion Rate 等五个维度把失败归因到模型还是 harness;*Async-RBench* 专门测异步场景:主 agent 继续干活、子 agent 还在跑、任务状态已变,主 agent 怎么决定更新/保留/重查而不违规——这正是做 subagent 编排时最容易踩的坑。→ [When Agents Fail](https://arxiv.org/abs/2610.32483) / [Async-RBench](https://arxiv.org/abs/2610.32429)

**长程任务的 context compaction 与 skill 生命周期**——*Benchmarks Are Surprisingly Compaction-Friendly* 指出压缩默认是有损的,agent 会悄悄丢掉约束和早期决策的理由;*Beyond Gain: Measuring Skill Internalization* 则研究 skill hub(规模可达 10 万条)如何判断某个模型已「内化」某技能从而为它退役该技能。对用 LangGraph 做长 horizon、带 memory/skill 的 agent 直接相关。→ [Compaction](https://arxiv.org/abs/2610.31778) / [Skill Retirement](https://arxiv.org/abs/2610.32322)

## 📈 趋势

- 🔺 Computer Use 成为模型发布主战场:GPT-6.1 Terra 把看屏幕、点鼠标、跨应用操作作为核心卖点,还靠降价拉使用量

- 🔺 agent harness 可靠性被当成独立评测对象:失败归因、异步状态管理、compaction 丢信息都在被基准化
- 🆕 AI 自写底层算子逼近甚至刷新人类手调极限(ForgeKernel 登顶双榜),算力层的竞争开始卷到算子
