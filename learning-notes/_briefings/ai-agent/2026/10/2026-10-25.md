## 📌 头条

### Kimi K3.1 Pro 发布，开放权重逼到前沿 3 分以内

月之暗面 10 月 23 日发布 Kimi K3.1 Pro，独立评测机构 Artificial Analysis 给它的 Intelligence Index 综合分是 55，在其追踪的全部模型里排第 4，只落后 Claude Opus 5.5(58)、Sonnet 5.5 和 Muse Wonder Full，比上一代 K3 的 44 分跳了 11 分。对 Agent 场景更关键的是 agentic 指标：Terminal-Bench 4.0 从 K3 的 13% 冲到 67%、超过 Claude Sonnet 5.5(64%)，AutomationBench-AA 从 58% 升到 73%。官方口径是「3T 级最强开放权重模型」，但要注意权重 11 月 4 日才放出、现在还下不到，API 价格降到每百万 token 输入 2 美元/输出 10 美元(上一代是 3/15)。如果你在做 agent 编排，等 11 月 4 日权重落地后值得拿 Terminal-Bench 这类工具调用场景实测一轮，看能不能替掉部分闭源调用。

→ [AA 发布分析](https://artificialanalysis.ai/articles/kimi-k3-1-pro-launch-benchmarks) / [官方博客](https://www.kimi.ai/blog/kimi-k3-1-pro)

### Anthropic 平台团队：代码「全部」交给 Claude 写

Anthropic 平台工程负责人 Katelyn Lesse 在 Grafana 的 ObservabilityCON 上说，她管的约 200 人团队(负责核心服务、开发者工具和基础设施)的代码「literally all」都是 Claude 写的，工程师的活已经变成系统设计和验证，连一次 Python 到 Rust 的迁移也是交给 Claude Code 做的。这是模型厂商第一方团队把 agentic coding 推到极致的样本，但要冷静看：说这话的人本身卖 Claude Code，是自述而非第三方核验。真正可借鉴的是职责转移的方向——人把精力压到「定义要什么 + 验证做对没」，实现下放给 agent。你可以拿自己手上一个边界清晰的模块试一次，看验证环节能不能跟上 agent 的产出速度。

→ [Business Insider](https://www.businessinsider.com/anthropic-katelyn-lesse-team-shifted-to-ai-coding-entirely-2026-10) / [开源中国转述](https://www.oschina.net/news/503177)

## ⚡ 快讯

- **LangChain Deep Agents**：新博客把「context engineering」拆到检索层：内置文件系统工具先搜后读(glob 配文件名、grep 配行、read_file 一次一页)，超大工具结果直接落盘、只把路径和预览喂给 agent——和你平时用的 glob/grep 省 context 思路一致，是 LangGraph 栈上现成可抄的做法 → [原文](https://www.langchain.com/blog/context-engineering-starts-with-retrieval)
- **qKnow v3.1.5**：工作流编排能力扩容，支持统一编排 MCP、Skills 和各类工具并调用已有 Agent/工作流，同时上线 Text2SQL 插件(覆盖 SQL 生成/改写/纠错/优化)、增强 MCP 元数据查询——又一个把 MCP 当工具总线的国产平台 → [原文](https://www.oschina.net/news/503174)
- **Claude Opus 5.5 逆向能力**：多名用户在 Reddit r/Claude 反馈 10 月 21 日一波更新后，Opus 5.5 对受 IP 保护内容的逆向工程被安全护栏中途拦截；Anthropic 没官宣改动，也有用户认为逆向本就结果不稳、是分类器敏感——属单一社区来源的现象，别当成官方定论 → [IT之家](https://www.ithome.com/1/017/554.htm)
- **Claude Code 隐私争议**：有开发者在 X 上发帖称 Claude Code 在出站 HTTP 请求里悄悄带上了用户邮箱(HN 讨论)——目前只是单条爆料、尚无官方回应，但对把 agent 接进内网的人是个提醒：出站流量该抓包核一遍 → [HN 讨论](https://news.ycombinator.com/item?id=50219875)
- **千问 Personal Agent**：阿里千问 AI 算法负责人蒋冠军在 2026 中国计算机大会提出 Personal Agent 三要素——模型、记忆、生态协同，强调从被动应答转向带增量价值的主动服务；是方向性观点，没放具体架构细节 → [雷峰网](https://www.leiphone.com/category/industrynews/DHR4Qc9YwHX7lin8.html)
- **AI 编码放大老漏洞**：安全研究者用 AI 工具翻出 PHP 里埋了多年的高危漏洞，随后 AI 辅助的攻击也跟着来了；PHP 基金会只有 1 名全职员工，靠和 OpenAI、Wiz 等合作发补丁，Cloudflare 称已监测到数百万次攻击尝试——AI 把「挖洞」和「打洞」同时加速了 → [Wired](https://www.wired.com/story/kernel-panic-the-php-meltdown-shows-how-ai-makes-bugs-more-exploitable)
