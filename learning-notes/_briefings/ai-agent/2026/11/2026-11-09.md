## 📌 头条

### 高盛收回交易员和投行人员的 Claude Code

据彭博社报道（经 State of AI 转述），高盛 10 月更新内部指引，把 Claude Code 和 GitHub 的编码工具限定给工程师使用，交易员和投行人员不能再用；Strats 岗位仍保留权限。高盛的出发点是风险与生产力复盘：编码 Agent 能自己读文件、写代码、执行，权限和使用者一样大，而交易员写的监控脚本很容易绕过评审、测试和上线流程，还可能碰到信息隔离墙。这条报道的来源是单一媒体转述，高盛官方只说按场景提供 AI 工具。对你的实际意义：如果团队里有非工程师在用 Agent 写脚本，先定好谁对 Agent 写出的代码负责，再放权限；高盛的做法是反面教材，一刀切之前没有替代方案。

→ [State of AI 报道](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers)

### 苹果加速 Siri 走向 Agent

彭博社的 Mark Gurman 称，苹果 CEO John Ternus 在催 Federighi 加快 Siri 路线图。预计 iOS 27.3 先让 Siri 精细操控苹果自家 App（比如在照片里旋转裁剪、整理 Safari 标签页），接入第三方 App（点 Grubhub、订 OpenTable）更晚，大概在明年春天。更大的目标是让 Siri 能记住目标、持续执行任务，而不是每一步都等用户发起。以上都是 Gurman 的爆料，苹果没有官方确认。对做 Agent 的人来说，值得留意的是第三方 App 调用的接入方式，它会决定移动端 Agent 的工具协议走向。

→ [The Verge](https://www.theverge.com/ai-artificial-intelligence/1029552/apple-siri-ai-agentic)

## ⚡ 快讯

- **Pi 对 Claude Code**：一位长期用户写了篇退出 Claude Code、改用开源 Agent 框架 Pi 的文章（博文日期 9 月 21 日，今天在 HN 重新冲上热门）。理由：今年 244 次发版中超过四分之三改动了系统提示或工具描述，影响自己的配置；默认 Bash 工具描述就近 3000 token；VS Code 里同一时间只有一个会话能接收选区。 → [原文](https://caleb.software/posts/claude-to-pi.html)
- **Agent 记忆格式**：LoreKit 博客呼吁给 Agent 记忆定一个统一格式，类比 2019 年合并成 OpenTelemetry 的可观测性行业。文章盘点了 AGENTS.md、Anthropic 记忆工具、Copilot Memory、LangGraph BaseStore、Mem0、Graphiti 等不同形态，作者自己做 LoreKit，所以立场并不中立。 → [原文](https://www.lorekit.io/blog/open-agent-memory-format)
- **llama-modchip**：开源项目称能在 64GB 内存、纯 CPU 上跑 284B 参数的 DeepSeek-V4-Flash（1.71 bpw 量化，56.56 GiB），预填充 44.4 tok/s，生成 9.1 到 14.7 tok/s，并支持 Claude Code 提示的 KV 快速恢复。数字来自项目自述，未经第三方复现。 → [GitHub](https://github.com/synchopate/llama-modchip)
- **腾讯 WorkBuddy**：WorkBuddy 就 DeepSeek-V4.1 Flash 折扣活动致歉：原定 9 月 24 日结束的 5 折积分活动调整后没有及时公告，将按 5 折结算并返还积分。 → [IT之家](https://www.ithome.com/1/024/025.htm)
- **苹果 HomeView**：iOS 27.3 测试版代码里出现「Conversational Apps」分类标记，暗示苹果智能家居中枢可能支持聊天机器人，属于代码线索，尚无官方说法。 → [The Verge](https://www.theverge.com/tech/1029526/chatbots-might-be-coming-to-apples-homeview)
