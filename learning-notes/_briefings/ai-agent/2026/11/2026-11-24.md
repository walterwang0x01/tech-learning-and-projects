### 智谱 GLM-5.4：让 28 层循环两轮的 Loop Transformer

智谱发布 GLM-5.4 技术公告，在 750B 基座上对其中 28 层做两轮循环，靠权重共享换参数效率。官方称智能水平达到 2-3T 级模型，这是官方口径，尚无第三方复现。公告同时把架构、数据、能力提升和限制都摆了出来，并把能力定位成“泛 Coding”。如果你的 Agent 底座在选国产模型，这次值得先读公告里的限制部分，再决定是否跑自己的 benchmark。

### CLAUDE.md 为什么越写越长

一篇 arXiv 论文把 CLAUDE.md 这类 Agent 提示文件无限膨胀归因于“不完整回忆”：追加一条指令很便宜，但指令背后的推理一旦丢失，要安全删除就得付出随提示长度指数增长的代价（论文给出 O(2^|D|)）。连续编辑会不断抹掉这些隐含推理，新增总是快过删除。注意这是 v2 修订版，论文 ID 为 2608，并非本周新作。如果你维护着很长的 CLAUDE.md，别急着整体重写，先给每条指令补上“为什么”。

→ [arXiv](https://arxiv.org/abs/2608.11095)

## ⚡ 快讯

- **localcode**：一条命令在 Mac 上跑本地模型的编程 Agent：uv pip install localcode 后在项目目录运行即可，能读改文件、跑测试，模型全在本地 → [详情](https://www.oschina.net/news/503746)
- **Replit Desktop**：Amjad Masad 称与 Windows 团队合作为 Replit Desktop 做了安全模型，并说佳士得选用它做安全的 Agent 工作；属单方表述，细节未披露 → [X](https://x.com/amasad/status/2124604574606795002)
- **Hugging Face**：发布《如何构建并维护 Agentic 评测》，讲评测集如何随 Agent 迭代保持有效 → [博客](https://huggingface.co/blog/agentic-evals)
- **Epistemic Guard**：针对 MCP 工具 Agent 的三个运行时验证缺口（动作捏造、来源混淆、镜像页面伪造多源佐证），提出进程外 MCP 回执代理等方案 → [arXiv](https://arxiv.org/abs/2611.27095)
- **端侧 Agent 安全**：研究发现端侧小模型在会话内先正确放行一个已解禁条目后，更容易放行下一个仍受限条目，即被自己的正确决策带偏 → [arXiv](https://arxiv.org/abs/2611.27216)
- **Advisor-Aware 后训练**：研究如何训练小模型 Agent 向强模型求助并自己执行建议；摘要称直接把小模型接到顾问上在多个模型族都失效 → [arXiv](https://arxiv.org/abs/2611.27443)
