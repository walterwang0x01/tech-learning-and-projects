## 📌 头条

### 哈佛论文：AI 编程 Agent 的瓶颈在 Code Review

两位哈佛博士候选人的工作论文覆盖 718 家公司、725938 名员工。用上编程 Agent 后，人均每月新增代码行数从 5017 涨到 6511，约多 30%；提交数涨 20%，Pull Request 涨 23%。产出变多了，但据报道论文认为真正的卡点转到了审查环节。这是单一来源的二手转述，具体结论以论文原文为准。如果你的团队在推 Agent 写代码，先看审查队列有没有堆积，再谈提速。

→ [报道](https://www.oschina.net/news/503706/harvard-researchers-find-ai-coding-agents-shifted)

### Anthropic 完成 IPO，每股 83 美元

Anthropic 官方公告称已完成首次公开募股，共 1,127,000,000 股 A 类普通股，发行价 83.00 美元，承销商选择权已全额行使。TechCrunch 报道七位创始人套现近 20 亿美元；Guardian 称 Nasdaq 同日抹去全年涨幅，市场对 AI 板块在回调。对做 Agent 的人来说，主要是模型供应商的资金与定价预期会变，值得留意 API 价格与合同条款。
