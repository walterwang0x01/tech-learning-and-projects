## 📌 头条

### LangChain 融资 3 亿美元，估值 30 亿

LangChain 官方宣布 C 轮融资 3 亿美元，估值 30 亿美元，由既有投资方 CapitalG 领投，GIC 和 DFJ Growth 新进。公司称 LangSmith 已有 7000 多家组织在用，并把产品拆成运行时、改进、治理三层：Agent Runtime 对应 Deep Agents、LangGraph 和 Agent Server，Agent Improvement 对应观测、评测和 LangSmith Engine，Agent Governance 对应 LLM 与工具网关。对 LangGraph 用户来说，值得留意的是它被明确放进“框架无关平台”的运行时这一层；官方预告 11 月 20 日发布新的 LangSmith 能力，可以到时对照看。融资额与客户数均为公司自述。

→ [官方公告](https://www.langchain.com/blog/series-c) / [LangSmith 重构为以 agent 为中心](https://www.langchain.com/blog/we-rebuilt-langsmith-around-the-agent)

### Windows 11 在记录你用过哪些 AI 编程助手

有开发者在 Windows 11 的 MissionControlAggregator.dll 里发现一份进程名单，包含 codex.exe、claude.exe、copilot.exe、cursor 等编程助手。这是社区逆向发现，微软尚未在我们看到的材料里给出官方说明，所以它具体记录什么、是否上传，目前只能等进一步验证。如果你在 Windows 上跑 agent，先看自己机器的遥测设置，别把它当成已证实的结论。

→ [开源中国](https://www.oschina.net/news/503608/windows-coding-agent-telemetry) / [原帖](https://xusheng.dev/posts/windows-coding-agent-telemetry)
