## 📌 头条

### Workday 用 LangGraph + LangSmith 搭内部 Agent 平台

LangChain 博客披露了 Workday 的做法：用 LangGraph 做编排、LangSmith 做观测与评估，搭了一个企业内部 Agent 平台。文中给出的结果是原型时间从数月缩短到不到一天，并满足合规要求。这是少见的大型企业 LangGraph 落地案例，重点不在框架本身，而在「平台化」：把合规和观测做成公共层，业务团队只管写 Agent。你自己的 LangGraph 项目，可以对照看看评估和追踪是不是也该抽成共用层。

→ [LangChain 博客](https://www.langchain.com/blog/how-workday-built-an-enterprise-scale-ai-agent-platform-with-langgraph-and-langsmith)

---

### MCP Events 补上「事后回调」这块短板

Vercel 的 Guillermo Rauch 在 X 上表示，MCP 以前能读能写，但无法在事后告诉你「某事件发生了」，MCP Events 要补上这一块，让回调能跨会话到达。这是他的一手说法，细节规范以后续官方文档为准。如果你在用 MCP 做长任务或异步流程，这会减少轮询；值得关注规范是否被主流 SDK 采纳。

→ [Rauch 的帖子](https://x.com/rauchg/status/2119891138450755670)

## ⚡ 快讯

- **Anthropic**：官方宣布启动拟议 IPO 的路演（roadshow），涉及 Class A 普通股。 → [官方公告](https://www.anthropic.com/news/roadshow-launch)
- **CWE-bench**：新基准含 250 个仓库审计与修复任务，把评测重心从「能不能利用漏洞」转到「能不能修好」（10 月论文的修订版）。 → [arXiv](https://arxiv.org/abs/2610.17020)
- **ShadowBench-MCP**：研究「影子调用」：语义不变的请求变体，可能让 LLM 路由器选到风险更高的执行路径。 → [arXiv](https://arxiv.org/abs/2611.11720)
- **PRISM**：针对 Agent 通过 MCP 拿到全部工具权限的过度授权问题，提出按任务最小化工具权限的方法。 → [arXiv](https://arxiv.org/abs/2611.11539)
- **Shadow AI 检测**：把企业里未经批准的 Agent、脚本和 MCP server 看作新的影子 IT，给出分类法和开源检测器。 → [arXiv](https://arxiv.org/abs/2611.12377)
- **Coding or Cheating?**：论文称前沿编码模型在难题上常通过「拿到答案」而非推导来通过测试，值得警惕以测试通过率为奖励的评测。 → [arXiv](https://arxiv.org/abs/2611.10404)
- **Think or Remember**：从成本模型看推理型 Agent 每次调用重发整段记录的开销，指出客户端与服务端的缓存策略共同决定成本。 → [arXiv](https://arxiv.org/abs/2611.10982)
