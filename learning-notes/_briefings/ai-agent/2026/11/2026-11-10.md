## 📌 头条

### Claude Fable 5.2 与 Mythos 5.2 发布，价格反而降了

Anthropic 称 Fable 5.2 和 Mythos 5.2 是同一个底层模型：Fable 带较强的网络安全与生物安全防护，面向所有用户；Mythos 需要通过扩展后的 Life Sciences 与 Cyber Verification Programs 申请。官方称输出速度比 5.1 最多快 30%，价格为每百万输入 token 8 美元、输出 40 美元，另有最高提速 2.5 倍的 fast mode（16 / 80 美元）。官方 benchmark 表里，FrontierSWE v2 为 69.9%，Opus 5.5 为 62.3%，GPT-6 Astra 为 65.5%；OSWorld 2.1 为 89.3%。这些都是厂商自报数字，且部分项标注了不同 effort 档位，横向比较要留余地。官方建议日常编码仍先用 Opus 5.5，Fable 更适合当 Advisor（让小模型遇到难题时请教它）或 Orchestrator（把简单子任务派给小模型）。如果你的 LangGraph 或 CrewAI 流程里有层级编排，可以拿这个 Advisor / Orchestrator 分工做一次成本对比实验。

→ [Anthropic 官方公告](https://www.anthropic.com/claude-fable-and-mythos-5-2) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1030005/anthropic-claude-fable-mythos-5-2)

### Stripe 用 Deep Agents 一周搭出内部 Agent Kai

LangChain 博客讲了 Stripe 的 Knowledge AI Platform（Kai）：面向全员的会话式 Agent，连接内部数据仓库、Slack 和 Google Suite，产出的报告、仪表盘会随对话演进，定位是「给非工程师的 coding agent」。底层是 LangChain 的开源 Agent harness Deep Agents，上面叠了 Stripe 自己的安全与基础设施层，再往上是让各团队自配 Agent 的配置层。文中提到 Kai 有来自 100 多个团队的 1000 多个 skill，上线约 4 周触达 5000 名用户。这篇是 LangChain 的客户案例，数字来自一方叙述，但分层方式值得借鉴：把通用 harness、公司安全层、团队配置层拆开，领域专家只需要贡献 skill，不必碰底层。

→ [LangChain：Stripe Kai 案例](https://www.langchain.com/blog/how-stripe-built-their-knowledge-ai-platform-on-deep-agents)
