## 📌 头条

### LangSmith BYOC 扩到三云：AWS 转正，Azure/GCP 进 Beta

LangChain 把 LangSmith 的「自带云」(Bring Your Own Cloud) 从 AWS 单一平台扩到了三大云：AWS 上正式 GA，Azure 和 Google Cloud 进入 Beta。BYOC 的卖点是 trace、eval、数据集、prompt 和 agent 部署全部留在你自己的云账户里，LangChain 只负责管理数据平面（编排、扩缩容、平台升级）。对数据主权有硬要求、又不想自己运维基础设施的团队，这是把 agent 可观测性落到合规边界内的直接路径。如果你在 Azure 或 GCP 上跑 LangGraph，现在可以申请 Beta 把 LangSmith 搬进自己的 VPC。

→ [原文](https://www.langchain.com/blog/langsmith-byoc-aws-gc-azure) / [Unite.AI 报道](https://www.unite.ai/langchain-brings-langsmith-byoc-beta-to-azure-and-google-cloud/)

### LangChain 复盘 Deep Agents 的浏览器选型：七套工具里挑了 Stagehand

LangChain 发文复盘了为 Deep Agents 做浏览器自动化选型的过程：横评了七套浏览器工具集，最后选了 Browserbase 的 Stagehand，再用 LangSmith 的 trace 和 eval 做了调优。文章给出的经验是浏览器工具的差异在 agent 实际跑长任务时才暴露出来，光看接口看不出来。做浏览器 agent 的可以拿这篇当选型参照，别自己从零趟一遍七套工具的坑。

→ [原文](https://www.langchain.com/blog/how-we-optimized-browser-use-for-deep-agents)
