## 📌 头条

### Claude Ship：Agent 接管 PR 的修复和批准

Anthropic 在 11 月 23 日推出 Claude Ship beta，面向 Team 和 Enterprise。它由三部分组成：已正式可用的 Code Review，以及两个新的 beta Agent。PR Steward 负责修失败的 CI、合并冲突和评审意见；Claude Approvals 按团队写的策略文件判断一个 PR 还需要谁批准，规则允许时可提交 GitHub 的批准评审。也就是说，一个 PR 从评审、修复到批准判断，可以不经人手走完。风险点在策略文件：写得松，Agent 就会放行不该放的改动。想试的话，先只在一个低风险仓库打开，把批准规则收窄再扩大。

→ [Anthropic 官方介绍](https://claude.com/resources/articles/introducing-claude-ship) / [上手指南](https://dev.to/kargatharaaakash/how-to-try-claude-ship-today-ship-a-starter-approvalsyml-and-the-settings-that-decide-what-5655)

### MCP 工具更新悄悄扩大 Agent 权限

SchemaCaps 论文指出，用户批准过的 MCP 工具，之后更新时可能把输入 schema 放宽，而客户端不会让用户重新批准。作者调研了 8 个 MCP 客户端和扫描器，没有一个被观察到或文档记载会在 schema 放宽时要求重新批准（另有两个无法确定）。在 39 个公开 MCP 服务器的 604 个版本上，580 次兼容变更里有 412 次放宽了某个字段，兼容性检查都会静默放行；作者人工标注认为其中至少 76 次新增或放宽了带权限的参数。论文提出按子 schema 包含关系决定是否重新批准，对现有工具需要 645 次重新批准，而直接锁死输入 schema 要 1,197 次。论文也承认，schema 不变但行为变了的情况它管不到。如果你在用或自己写 MCP 服务器，升级工具版本前先 diff 一下 inputSchema。

→ [arXiv](https://arxiv.org/abs/2611.30750)

## ⚡ 快讯

- **Claude 插件页**：Anthropic 把技能（skills）和连接器（connectors）合并成统一的 Plugins 页面，Free、Pro、Max、Ultra 已上线，Team 据报道 11 月 30 日起推送，目录称有 1 万多个插件 → [官方帮助页](https://support.claude.com/en/articles/17740565-manage-plugins-skills-and-connectors-from-one-plugins-page)
- **LangChain Agent Lake**：LangChain 提出「agent lake」概念：把 Agent trace 和结果（如合并的 PR、点踩）放在同一存储（SmithDB）上，再用模型去筛高价值 trace、驱动改进；文中称 LangSmith 每月摄入数十亿次 Agent 运行的 trace → [博客](https://www.langchain.com/blog/the-agent-lake)
- **Brickie**：Hatchet 开源的沙箱方案，让 Agent 的沙箱跑在你自己的云账号里，主要面向 AWS EKS；作者列出沙箱的两个用途：安全执行不可信代码，以及用快照保存 Agent 状态 → [GitHub](https://github.com/hatchet-dev/brickie)
- **Versine**：YC F26 项目，一个放在钱包前面的 MCP，让 Agent 转账和收款，转账需要用户在其应用里用 passkey 批准；属创业公司自述，未见独立评测 → [Launch HN](https://news.ycombinator.com/item?id=50634426)
- **Conartist**：针对 Computer-Using Agent 的自适应红队研究，称 Agent 外壳里的一致性检查和风险审计两道防线都能被绕过：前者可被「逻辑上与用户目标一致」的恶意动作骗过 → [arXiv](https://arxiv.org/abs/2611.29977)
- **Automated Safety Analysis for Agentic Workflows**：针对工作流本身的设计缺陷（不是提示注入或畸形 API 调用），摘要称此前没有工具能对其做静态分析，论文给出自动化的安全分析方法 → [arXiv](https://arxiv.org/abs/2611.28469)
- **文心 5.5 Flash Preview**：百度 11 月 24 日以 Apache 2.0 协议开源，总参数 2800 亿、每 token 激活 140 亿，权重在 Hugging Face 和 ModelScope，支持 vLLM、SGLang 部署 → [雷峰网](https://www.leiphone.com/category/industrynews/X2LHtIreyiO6depw.html)
