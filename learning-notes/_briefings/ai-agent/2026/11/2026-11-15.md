### Cloudflare 开源 Kitesurf：给 Agent 用的轻量浏览器

Cloudflare 把实验性的 Kitesurf 以 Apache 2.0 开源。它完全跑在 Workers 上，不用浏览器容器，能解析 HTML、套 CSS、执行页面 JavaScript、渲染截图，并支持 CDP，所以 Puppeteer 这类客户端可以直接连。官方的目标是比完整 Chromium 更省 CPU 和内存，并随 Workers 按需扩展。做浏览器类 MCP 或 Agent 自动化的人，可以拿它和现有的 Chromium 方案对比成本，再决定要不要自托管。

→ [Cloudflare 博客](https://blog.cloudflare.com/kitesurf-open-source) / [GitHub](https://github.com/cloudflare/kitesurf)
