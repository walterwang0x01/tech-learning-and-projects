## 📌 头条

### OpenCode Browse：让 Agent 直接用你已登录的浏览器

OpenCode 发布了 Browse，形态是一个 Chromium 扩展加一个 MCP server。Agent 会在后台开标签页并收进折叠的标签组，能读页面、点击、输入、截图、录制标签页。遇到登录、2FA、付款这类环节，它会把标签页交还给你。这条路线让 Agent 复用你现成的登录态，不必另配凭据，也意味着权限边界要自己把好。如果你在用 MCP 接浏览器能力，可以对照现有方案试一下它的交还机制。

→ [原文（开源中国）](https://www.oschina.net/news/503625/opencode-browse)

### K2-Horizon：从 0.9B 到 375B-A23B 的全开源模型族

arXiv 论文 K2-Horizon 发布了一组六个完全开源的语言模型，规模从 0.9B 稠密模型到 375B-A23B 的 MoE，面向通用推理与 Agent 工作，覆盖数学科学、软件工程、深度研究、办公自动化等。摘要称它们在同尺寸开源模型的 Agent 与编码基准上领先或有竞争力，这是作者自述，需等独立复现。想选开源底座做 Agent 的人可以关注其小尺寸型号。

→ [arXiv](https://arxiv.org/abs/2611.21003)
