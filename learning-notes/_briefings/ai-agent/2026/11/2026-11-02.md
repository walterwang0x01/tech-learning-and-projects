### DeepSeek 开源 dsh-superagent：把 Agent 当「操作系统」

DeepSeek Harness 团队 10 月 31 日发了篇架构长文，并在 GitHub 开源了研究原型 dsh-superagent（MIT 许可）。核心观点一句话：单任务的上限取决于模型能力，多任务的上限取决于人的注意力——一个人通常只能同时跟进 3 到 5 个活跃 Session。它的设计是「一个常驻 router + 多个 worker session」：绑定单个仓库，监听 chat 和 GitHub 事件，被授权的人（或预设规则）触发后在独立 worker 里干活、开 PR，只在需要人决策时才出声。官方给的内部实例数据是：一半任务 12.4 分钟内完成、95% 在 15.7 分钟内，并已接入自家 R&D 日常。注意这是 research prototype 不是产品，想抄架构的可以直接读代码——这套「router/worker + 跨中断续作」的模式和 LangGraph 多 agent 编排思路高度同频。

→ [开源中国解读](https://www.oschina.net/news/503338/deepseek-harness-super-agent) / [GitHub 原型](https://github.com/deepseek-ai/dsh-superagent-prototype)

### Anthropic 给 Claude 加了「禁止复刻游戏」规则，误伤正当逆向

大约 10 月 27 日起，有开发者发现 Claude Code（配 Opus 5.5）开始拒绝复刻已有游戏的请求，即便改名或声称原创也拦。Anthropic 已确认这是服务端下发的 prompt 指令（走远程配置，本地客户端不变也会被拦），依据是其既有的 IP 使用政策，背景是前阵子 Steam 被 AI 生成的游戏「仿品」刷屏。问题在于误伤：多名开发者反映正当的逆向工程任务（含用 Reverse Engineer Anything 工具）也被挡。对靠 Claude Code 做逆向或改游戏的人，这意味着同一条 prompt 可能今天能跑明天不能——服务端规则不写进你的代码，排查时先怀疑是不是被远程策略拦了。

→ [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropics-ai-model-is-now-blocking-attempts-at-video-game-recreation-and-cloning-users-also-claim-non-malicious-generic-reverse-engineering-tasks-are-blocked) / [PC Gamer](https://www.pcgamer.com/gaming-industry/anthropic-updates-claude-to-steer-it-away-from-letting-users-clone-games-following-weeks-of-steam-being-inundated-with-ai-slop/)

## 📈 趋势

- 🆕 常驻式 / 事件驱动 agent 成形：从「一次问一次答」转向「绑仓库、监听事件、并行多 session、只在需要决策时找人」（DeepSeek Super-agent 是代表）
- 🔺 厂商开始用服务端策略给 coding agent 划红线（Anthropic 禁复刻游戏），远程配置带来排查新难点与误伤风险
- 🔺 AI 进攻侧升温：自动人肉的信息窃取软件、针对 AI 公司的快速入侵，agent 安全从「prompt injection」扩到完整攻击链
