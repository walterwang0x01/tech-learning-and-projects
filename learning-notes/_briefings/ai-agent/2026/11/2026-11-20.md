## 📌 头条

### 苹果招人自研通用 AI Agent

彭博社 Mark Gurman 报道，苹果官网挂出「主动式智能体 AI」（Agentic AI - Proactive）高级工程经理岗位，要做能操控设备、浏览网页、写代码、调用服务的智能体。招聘描述里提到它要在浏览器、文档、终端、代码编辑器之间切换，规划跨应用的多步任务，还要协调多个分工的子智能体。苹果同时强调，这类会运行代码、使用用户凭据的 Agent 需要严格的权限管控。目前只是招聘信息，产品形态和时间表都没有公布。对做 Agent 的人来说，值得留意的是它把权限与隐私放在了岗位描述的显眼位置。

→ [The Verge](https://www.theverge.com/tech/1038227/apple-ai-agent-engineer-job-listing) / [IT之家](https://www.ithome.com/1/029/750.htm)

### LangSmith Tool Gateway 公测：工具调用的统一权限层

LangChain 宣布 LangSmith Tool Gateway 进入 Public Beta，把 Agent 每次工具调用涉及的凭据、身份和访问控制收在一处，并附带策略、审批和 trace。同一天它还发文谈「治理从可观测性开始」，另一篇讲如何在 Claude Code、Cursor、Copilot 等之间追踪并管控编码 Agent 的开销。三篇放在一起，方向很清楚：Agent 从能跑转向可管、可审计。如果你的 LangGraph 项目里工具密钥是散落在各处的环境变量，可以先看看这套网关的接入方式。

→ [Tool Gateway](https://www.langchain.com/blog/langsmith-tool-gateway) / [治理与可观测性](https://www.langchain.com/blog/agent-governance-observability) / [编码 Agent 账单](https://www.langchain.com/blog/fix-your-coding-agent-bill)
