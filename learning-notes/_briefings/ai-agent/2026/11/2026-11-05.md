## 📌 头条

### Kimi K3.1 Pro 开放权重，登顶 Agent Arena 开源榜

月之暗面今天在 Hugging Face 放出了 Kimi K3.1 Pro 的完整权重。这是一个 2.8 万亿总参数、每 token 激活约 1040 亿的混合专家模型，原生支持视觉，上下文窗口到 100 万 token。在 Arena 运营的 Agent Arena 智能体排行榜上，它位列开放权重模型第一、全部参评模型第 13，工作/编程/聊天三项都居开源首位，模型卡自称 Terminal-Bench 4.0 得 65.7、BrowseComp 得 92.1。昇腾和 AMD 都做到了发布首日（0-day）推理适配。对你意味着什么：这是目前能自己下载部署的最强 Agent 底座之一，但代价不小——权重约 1.56TB，自托管大约需要 8 张顶级 GPU，年营收超 2000 万美元的托管方还得单独跟月之暗面签协议。想试水先用云端 API，不急着本地拉权重。

→ [IT之家](https://www.ithome.com/1/022/490.htm) / [Hugging Face 模型卡](https://daily.dev/posts/kimi-k3-1-pro-model-weights-are-out-fbrf3kpbp) / [昇腾 0-day 适配](https://www.ithome.com/1/022/502.htm)

### Claude 企业版让插件自动连接

Anthropic 的 Boris Cherny 宣布 Claude 现在能自动连上公司配置好的插件（plugins）。以前每个插件都要单独登录一次很烦，现在 Team 和 Enterprise 的管理员一次配好，团队成员第一次用到某个插件时就被自动接上。这背后其实是 MCP 工具授权体验的持续打磨——把登录这道摩擦从每人每插件降到管理员配一次。对你意味着什么：如果你在团队里推 Claude Code 接内部工具，这省掉了大量重复授权；但自动连接也意味着权限边界要在管理员侧想清楚，别让 Agent 默认拿到比需要更多的工具。

→ [Boris Cherny (@bcherny)](https://x.com/bcherny/status/2117693181651542387)

## ⚡ 快讯

- **Ripple-65B Preview**：Ricursive Intelligence 放出首个模型，65B 稠密、12T tokens 从零训练、Apache-2.0 许可，在 TerminalBench 2.1 拿到 80.52，官方称超过数个参数大得多的美国开源模型（如 Reflection Beam 501B 的 80.1）；据报训练成本约 3200 万美元。HN 上 233 赞热度很高。 → [Hugging Face](https://huggingface.co/ricursiveAI/Ripple-65B-Preview) / [VentureBeat](https://venturebeat.com/technology/ex-googlers-new-apache-2-0-model-ripple-65b-preview-claims-the-u-s-open-coding-lead-on-two-major-benchmarks)
- **Gartner / The Register**：一篇被 HN 热议的报道援引 Gartner 观点：开源模型能以约二十分之一的成本完成九成的 agentic 工作，提醒大家别默认什么都上前沿闭源大模型。 → [The Register](https://www.theregister.com/ai-and-ml/2026/11/03/open-models-can-do-90-percent-of-agentic-work-at-a-twentieth-of-the-cost-of-a-frontier-llm-gartner/5307132)
- **Cloudflare**：推出面向「个人 AI Agent」的可见性与管控能力，让站点主能区分自动化流量与真人流量、并对个人 Agent 的访问设定条件。随着浏览型 Agent 普及，网站侧的准入控制正成为新战场。 → [Cloudflare Blog](https://blog.cloudflare.com/personal-agents-visibility-control)
- **MCP 授权安全**：一篇技术文讨论如何让用户信任自己的 MCP 客户端、同时不打开钓鱼漏洞（trusted redirect URIs 的做法），对正在接 MCP 的人是实打实的安全参考。 → [streamvessel.com](https://streamvessel.com/blog/mcp-trusted-redirect-uris)
- **Anthropic**：为重要开源项目新增可选的安全扫描服务，把 Claude 的代码审查能力对接到开源供应链安全场景。 → [InfoQ](https://www.infoq.cn/article/hdmi6FdjpYSEvuMhPOAa)
- **智能体自律公约**：在乌镇世界互联网大会上，中国信通院、360、华为等共同发布《智能体发展自律公约》，八条措施聚焦跨平台交互时的权限越界、数据泄露、行为失控等问题——多 Agent 协同的治理开始有行业规约。 → [雷峰网](https://www.leiphone.com/category/industrynews/UB25ocDFu1ntNMtz.html)
- **人才流动**：前 Claude Code 产品负责人 Cat Wu 宣布加入 OpenAI 任核心产品管理负责人；她在 Anthropic 两年，见证了 Claude Code 从内部工具长成主力产品。Agent 产品的人才正在头部公司间高频流动。 → [36氪](https://www.36kr.com/newsflashes/4056253270791048)
