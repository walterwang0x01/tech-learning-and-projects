## 📌 头条

### 美国银行集体对第三方 AI Agent 关门

Wired 报道，Wells Fargo 更新的客户协议从周二起生效，写明使用任何 AI Agent「风险自负」。此前 JPMorgan Chase 在 10 月底修改条款，禁止第三方 Agent 用客户凭据登录；Bank of America 警告客户不要把登录信息交给 Agent，Citibank 和 PNC 也加了警示条款。电商和旅行也在收紧：报道称 Amazon 已阻止 Meta 的 Muse 在其平台下单，United 将禁止个人 Agent 代购机票。银行一边挡外部 Agent，一边做自家的（Wells Fargo 的生成式 AI 助手交互已超 10 亿次）。如果你在做会代用户登录或支付的 Agent，别再默认走「账号密码 + 浏览器自动化」，要预留官方授权接口或 MCP 类的委托授权路径。

→ [Wired](https://www.wired.com/story/banks-are-cracking-down-on-ai-agents)

### OpenAI 首席科学家提议用 perplexity 给 AI 进展「限速」

TechCrunch 报道，OpenAI 首席科学家 Jakub Pachocki 发文，主张用 perplexity（模型预测下一个 token 的平均能力，越低越好）作为通用能力的共同度量，各家公司承诺在监控与理解能力达到某个具体里程碑之前，不越过某个阈值。文中称 GPT-4 约 0.91，现在已降到 0.8 以下，并与网络安全、数学等领域能力的出现相关。Altman 称其为 OpenAI 近期最重要的文章。这是 Dario Amodei 此前提出的「pace the frontier」之后，第一次有人给出可操作的度量方案。对 Agent 开发者的直接影响暂时有限，但如果行业真的以此为基准设限，模型迭代节奏会受到约束，值得跟踪。

→ [TechCrunch](https://techcrunch.com/2026/11/22/openais-chief-scientist-has-thoughts-on-how-to-limit-ai-development) / [OpenAI 原文](https://openai.com/index/perplexity-and-intelligence)

## ⚡ 快讯

- **Signal**：宣布限制手机端截屏，理由是操作系统集成的 Agent 能「扫描」屏幕内容并存入本地或远程数据库，Signal 无法再独立保证隐私；用户可关闭该设置，但会失去隐私保证，Whittaker 自己也承认这只是不完整的方案 → [TechCrunch](https://techcrunch.com/2026/11/21/signal-restricts-mobile-screenshots-as-it-confronts-existential-threat-of-ai-surveillance)
- **Satya Nadella**：据 Windows Latest 经 IT之家转述，他承认 Claude Code 让不少开发者几个月不开 VS Code，并称 IDE 的核心可能变成「写说明文档」；VS Code 1.147 已加入模型路由、定时提交 Agent 请求和浏览器集成 → [IT之家](https://www.ithome.com/1/030/733.htm)
- **Anthropic 数学家**：Levent Alpöge 与 NYU 的 Tristan Buckmaster 于 11 月 20 日公布论文，声称证明三维 Navier–Stokes 无外力有限时间爆破，全程使用 Claude 并公开 Lean 代码；陶哲轩认为大体策略已清楚但仍需整理。支撑构造的数值证书尚未公开，目前只是主张，还没有独立核验 → [量子位](https://www.qbitai.com/2026/11/511870.html)
- **Together.ai**：发布安全事件说明：2026 年 6、7 月间有请求的 prompt 发生泄露。用第三方推理托管的 Agent 要重新检查哪些敏感内容进了 prompt → [Together.ai](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026)
- **OpenRouter × MiniMax**：Reddit LocalLLaMA 上有帖子称经 OpenRouter 发往 MiniMax 模型的请求可能被读取，目前只是社区帖，未见官方确认，用前建议等待回应 → [Reddit](https://www.reddit.com/r/LocalLLaMA/comments/1y1we95/openrouter_requests_to_minimax_models_may_have)
- **Dragos**：用 canary token 观察 AI 供应链安全，给「Agent 拉取的依赖和模型文件是否可信」提供了一个可操作的检测思路 → [Dragos](https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens)
- **Simon Willison**：推荐 Graham Dumpleton（mod_wsgi 作者）的 AI 辅助 Rust 服务器 Muru，面向 ASGI/WSGI Python 应用，三周内连载了近 20 篇开发笔记，其中「AI as a lifestyle choice」讲人负责判断「还不够好」 → [Simon Willison](https://simonwillison.net/2026/Nov/21/muru/)
