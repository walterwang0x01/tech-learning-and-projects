### Claude Code 授权文件泄露 2539 个凭据

Apiiro 扫描公开 GitHub 后称，在 104185 份 `.claude/settings.local.json` 中，有 1122 份至少含一个密钥或密码；把 Git 历史、共享设置和 agent 聊天日志也算上后，共发现 2539 个凭据，分布在 1994 个仓库。机制是用户选择 “Yes, and don't ask again” 时，Claude Code 可能把完整命令逐字保存为权限规则，命令里的凭据也会落进明文文件。研究方没有验证所有凭据是否仍然有效，因此这些数字代表暴露记录，不等于每个都可被利用。处置顺序应是先轮换凭据，再清理 Git 历史，并把 `.claude/settings.local.json` 加进项目自己的 `.gitignore`；只删当前文件不够。

→ [Apiiro 报告](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again) / [The Hacker News 核查](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html)

### 生成式 UI 进入 Slack 与 Teams

Vercel 11 月 6 日发布 Chat SDK 与 `json-render` 的新集成：agent 输出受类型约束的 JSON spec，适配器再把它转换成 Slack Block Kit 或 Teams Adaptive Cards。`streamCard` 在根元素就绪后立即发卡片，默认最多每 500 毫秒更新一次，流结束时再校验最终结果；属性不合法会抛出 `CardSpecError`。这种做法比让模型直接生成任意 HTML 更可控，因为组件和动作必须先进入开发者定义的目录，但平台自身的表格、图表数量限制仍需显式处理。可以直接用官方示例做一张“表格 + 按钮”卡，再故意传一个非法属性，验证纠错路径是否真的工作。

→ [Vercel 更新](https://vercel.com/changelog/json-render-and-chat-sdk-agents) / [API 文档](https://json-render.dev/docs/api/chat)

## ⚡ 快讯

- **663 条 HN 评论里的 coding agent 用法**：一份人工统计从 530 名发言者中找到 424 名明确说了所用工具：180 人用 Claude Code、103 人用 Codex，156 人同时用两种以上 coding agent；这是 Ask HN 自报样本，不应当作全行业份额，但“多模型 + 独立 worktree + 第二个 reviewer”已经是高频组合 → [统计与方法](https://theainewsreport.com/2026-11-06-hn-agentic-setups-counted.html)
- **Cordonix 0.4.1**：这款用 C11 编写、面向 coding agent 的本地执行与文件工作区工具加入每日后台更新检查，补全全部 MCP 工具参数说明，并让文件创建失败提示更准确；相较本周早些时候的 0.0.5，这是明确的新版本进展 → [发布说明](https://www.oschina.net/news/503467)
- **OpenAI 出站 SIP 通话**：官方 Telephony and SIP 文档已覆盖 agent 主动拨号：SIP 信令走 TLS，GPT-Live 音频要求 SRTP，而呼叫授权、会话配置和业务逻辑仍由你的后端负责；这让语音 agent 能直接接电话系统，但没有把风控责任交给模型 → [官方文档](https://developers.openai.com/api/docs/guides/voice-sip)
- **Agent Builder 进入迁移倒计时**：OpenAI 文档写明 Agent Builder 将在 11 月 30 日关闭，ChatKit 保留；仍把生产流程绑在 workflow ID 上的团队应尽快盘点，并按场景迁到 Agents SDK 或 Workspace Agents → [官方迁移说明](https://developers.openai.com/api/docs/guides/agent-builder)
- **IBM CUGA 的同模型对照**：IBM Research 在 Hugging Face 的文章称，同一个开放权重模型跑 90 个 AppWorld 任务时，仅更换 agent harness 就让完成率从 30% 变到 81%；这是厂商自己的实验，但足以提醒评测时必须固定模型再比较 harness → [实验说明](https://huggingface.co/blog/ibm-research/cuga-harness)
- **从已验证轨迹自动编译 Skills**：Zep Agent Skills 只把验证过的执行轨迹编译成带版本的程序性记忆；论文报告，教师模型轨迹生成的 Skills 让三个较弱执行模型在多项任务上的通过率提高 4.5 至 18.8 个百分点，说明“可复用做法”可以独立于模型训练传播 → [arXiv](https://arxiv.org/abs/2611.01386)
