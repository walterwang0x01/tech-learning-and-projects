## 📌 头条

### Gemini 4 Hydrogen 发布，直接顶替 3.8 Flash

Google 昨天发布 Gemini 4 Hydrogen，同步进入 Search、Gemini app 等入口。The Verge 转述官方说法：它擅长拆解多部分问题、容忍错别字、处理很具体的请求。Ars Technica 点出两个细节：它是 3.8 Flash 的替代者，而且不像前两个型号 Carbon 和 Argon 那样走“慢速、重安全”的分批放量路线。Google 的 Antigravity 同步写了 Hydrogen 与 Orchestrator 的接入文章，HN 上这两条首发帖分别有 473 和 321 个赞，说明开发者关注的是它能不能放进 agent 工作流。官方页面没给出完整基准数字，选型前先在自己的任务集上跑一遍。

→ [官方发布](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen) / [Antigravity 接入](https://antigravity.google/blog/gemini-4-hydrogen-in-google-antigravity) / [Ars Technica](https://arstechnica.com/google/2026/11/google-rolls-out-gemini-4-hydrogen-finally-replacing-3-8-flash) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1032505/google-search-ai-mode-gemini-4-hydrogen)

### 联合航空：不许 AI agent 代客订机票

联合航空表示不再允许客户用 AI agent 预订机票和管理订单，理由是网络安全风险。TechCrunch 和 CBS 都报道了这件事，CBS 那条在 HN 上拿到 661 个赞，是今天讨论最热的 agent 话题。对做“代用户操作”类 agent 的人，这是第一个来自大型消费服务商的明确封堵。公开报道只给了“安全风险”这一个理由，没有说明具体技术手段。如果你的 agent 依赖网页自动化去订票或改签，需要预案：官方 API、用户本人确认步骤，或者换场景。

→ [TechCrunch](https://techcrunch.com/2026/11/12/united-airlines-blocks-ai-agents-from-booking-flights-citing-cybersecurity-risks) / [CBS](https://www.cbsnews.com/news/united-airlines-bans-ai-agents-booking-flights)
