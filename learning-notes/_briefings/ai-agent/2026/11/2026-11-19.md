## 📌 头条

### OpenAI 发布 GPT-6.2 Astra 与 Sol，每任务成本大降

OpenAI 上线 GPT-6.2 的两个型号：Astra 是旗舰，定位面向最难的专业与科研任务，官方称其每任务成本不到 GPT-6 Astra 的三分之一；Sol 是另一档型号，具体定位以官方说明为准。Agent 的账单是按任务累计的，单任务成本砍到三分之一以下，意味着长链路、多轮工具调用的 Agent 流程更容易跑得起。该成本数字来自官方对外说法的转述，尚无独立复现，选型前建议用自己的任务集跑一遍对比。

→ [开源中国报道](https://www.oschina.net/news/503626/openai-gpt-6-2-astra-sol)

---

### 腾讯开源 Hy4 flash：220B 总参数，每 token 激活 12B

腾讯混元开源 Hy4 flash，总参数 220B，每个 token 只激活 12B。模型卡称单任务平均成本为 Hy4 的 1/20、DeepSeek-V4.1-Flash-1017 的 1/8，这些是厂商自报数字。InfoQ 称其上线首日登顶 OpenRouter，同样是单一来源转述。对本地或自托管 Agent 来说，稀疏激活比例是真正的看点：值得拿一个现有的工具调用评测去试跑，看成本和成功率的实际曲线。

→ [开源中国](https://www.oschina.net/news/503636) / [InfoQ](https://www.infoq.cn/article/o4edzZ1lM7CUQgcupk8H)
