## 📌 头条

### A2UI 1.0 发布：Agent 直接回 UI，不只回文字

谷歌今天把 2025 年底公布的生成式 UI 协议 A2UI 推到 1.0，这是首个稳定版。思路是 Agent 只描述「要显示什么」，由各个应用用自己的原生组件去画，所以同一个回答在 Web、Android、iOS 上都是原生观感。1.0 新增了双向函数调用，加了无障碍和额外元数据的扩展支持，配套有 React、Angular、Lit 的 Web 渲染器，以及 Python、TypeScript、Dart 的 Agent SDK。据报道 Atlassian、彭博社、字节跳动等已在用。对做 MCP / LangGraph 的人来说，这是 Agent 输出层终于有了一个稳定协议可以对接，值得拉下 Python 或 TypeScript SDK 跑一个最小 demo，看它和现有工具调用链怎么拼。

→ [IT之家报道](https://www.ithome.com/1/025/862.htm)

### Anthropic 发 Fable 5.2 与 Mythos 5.2

据开源中国编译的报道，Anthropic 11 月 9 日发布 Claude Fable 5.2 和 Mythos 5.2，两者是同一个底层模型：Fable 带完整的网络安全与生物学防护，面向所有用户；Mythos 去掉部分限制，只通过验证计划提供给做防御性安全或生物医学研究的机构。标题里「8 天写出一个能开机的操作系统」是 Anthropic 自己的说法，目前只看到单一来源转述，别当成已被独立验证的结论。同日 Claude 还把 Dashboards 改名 Claude Data 并在付费计划正式可用，另有「交互式连接器」，可以在 Claude 里直接打开 Adobe、Atlassian、Box 的完整界面。如果你的 Agent 依赖某个 Claude 工具集成，可以留意连接器形态是否影响你现在的 MCP 接法。

→ [开源中国](https://www.oschina.net/news/503499/claude-fable-and-mythos-5-2) / [Claude Data 公告](https://x.com/claudeai/status/2120206372478566799) / [交互式连接器](https://x.com/claudeai/status/2120206375137484875)

**From Attack Surface to Defense Architecture** — 指出编程 Harness 会把 bash、curl、find 等双用途程序变成注入后的攻击载荷，主张安全是认知架构与权限组合的结构性属性。→ [arXiv](https://arxiv.org/abs/2611.13960)
