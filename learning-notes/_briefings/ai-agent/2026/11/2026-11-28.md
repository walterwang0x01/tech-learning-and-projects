## 📌 头条

### SkillsBench 被审计：skill 的提升可能没那么稳

SkillsBench 此前报告称，人工编写的 agent skill 平均能把通过率提高约 16.6 个百分点，但对部分任务反而拉低了结果，后续研究开始按单任务增益来筛选或剔除 skill。这篇新论文对该基准做了源码级审计，并用考虑噪声的方法重新分析，质疑「单任务 skill lift」到底测到了什么。摘要里没有给出重新分析后的具体数字，结论幅度要读全文才能确认。如果你在用 skills 目录给 coding agent 加指令，别只凭一次评测的单任务增减决定留不留，同一任务多跑几次再比较。

→ [arXiv](https://arxiv.org/abs/2611.33943)

### 护栏拒绝信息会泄露给攻击者：FORK 研究安全披露

当 guardrail 拒绝 agent 的某个动作时，拒绝信息会被观察轨迹的攻击者看到：固定的拒绝语让正常用户无法恢复任务，详细解释又会告诉攻击者下一步该试什么。FORK 把这个问题定义为「安全披露」，目标是让被授权的任务能恢复，同时不提高自适应攻击的成功率，并让拦截决策和披露话术共同演化。摘要只说明了问题设定和方法方向，攻击成功率等数字未在摘要中给出。做 MCP 工具权限或审批层的人可以回头检查：拒绝消息里有没有暴露规则细节。

→ [arXiv](https://arxiv.org/abs/2611.33879)
