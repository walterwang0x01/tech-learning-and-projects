### Claude Code 扩展被投毒，Cursor 市场植入 SSH 后门

10 月 29 日，一个被篡改的 Claude Code 扩展（标识 anthropic.claude-code，版本 2.1.312 / 2.1.313）在 Cursor 自家的扩展市场里挂了约 11 小时，Cursor 的安全通告确认这两个版本并非 Anthropic 开发。它和正版几乎一模一样，只多了一小段代码：写入攻击者的 SSH 公钥、把系统信息外传到远程服务器、再设一个开机启动项，留下持久后门。多家安全厂商和 Cursor 口径一致，受影响面最多约 5000 名开发者，而且 Cursor 警告——卸载扩展未必能清掉后门。对天天把 coding agent 装进编辑器的人，这是一记直接的供应链警钟：装扩展等于把执行权交出去，第三方市场的「更新」并不等于官方签名。如果你近期在 Cursor 里更新过 Claude Code，按安全厂商的 playbook 先查 ~/.ssh/authorized_keys 和开机启动项，不要只靠卸载。

→ [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html) / [Microsoft 分析](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/) / [BleepingComputer](https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/)

### DeepSeek 二轮融资 1055 亿元，国资占比 2%→27%

据 The Information（10 月 30 日），DeepSeek 第二轮融资拿下约 1055 亿元人民币（约 158 亿美元），近 30 家投资者参与，对应估值约 6155 亿元。腾讯和宁德时代领投，各出约 100 亿元。比金额更值得看的是名单结构：国有资本占比从首轮的约 2% 跳到约 27%。这个变化说明国产大模型的头部玩家正从纯市场化融资转向国资深度介入，既是产业战略定位的信号，也可能影响后续的商业化路径和海外合规处境。数字口径以 The Information 的报道为准，具体出资明细官方未逐笔披露。

→ [开源中国](https://www.oschina.net/news/503318) / [BigGo Finance](https://finance.biggo.com/news/460e0461-1f9d-4fb1-8dc7-3e51c1436ad7)
