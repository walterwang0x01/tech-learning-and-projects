### OpenAI 断供 Cursor：模型供应变成竞争武器

SpaceX 完成 600 亿美元收购 Cursor 母公司 Anysphere 后不到两周，OpenAI 正式通知将于 11 月 12 日终止对 Cursor 的模型供应协议。OpenAI 在声明中直言，这一决定与 Musk 旗下公司历史上多次违反合同条款有关，包括 Twitter 收购后的违约和 xAI 承认违反了 OpenAI 服务条款。

Cursor 不会突然变砖——开发者仍可通过 OpenAI 标准 API 在 Cursor 中使用模型，只是失去了此前的定制化深度集成。但这件事的意义远超一款编辑器：当模型供应商开始把「给不给你用模型」当作商业对抗手段，所有依赖单一模型供应商的 AI 产品都该重新审视自己的供应链。

### Anthropic 研究展示 AI 自改进的早期迹象

Anthropic 研究院本周发布了一篇关于递归自改进（Recursive Self-Improvement）的研究，由研究员 Chen Yueh-Han 主导。实验中，自动化系统搜索文献、提出方法、用 30 分钟训练模型、迭代优化 benchmark 分数——模拟了传统 AI 研究流程的核心循环。Anthropic 同时披露：截至 2026 年 5 月，超过 80% 合入 Anthropic 代码库的代码由 Claude 编写。

这不是完整的递归自改进——人类仍然决定优化什么、提供算力、判断结果质量。但从「AI 辅助写代码」到「AI 辅助做 AI 研究」的跨越，值得从业者密切关注。

## ⚡ 快讯

- **Claude 用户遭信息窃取恶意软件攻击**：Anthropic 警告部分用户，其电脑上的 infostealer 恶意软件窃取了 Claude 活跃登录会话，攻击者借此访问账户、消耗用量。Anthropic 已强制登出受影响用户、移除保存的支付方式并退还未授权费用。恶意软件与 Claude 本身无关，而是通用的浏览器会话窃取。此前还有人通过 Bing 搜索广告投放恶意 Claude Artifact 页面诱导下载。 → [BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-warns-infostealer-malware-is-hijacking-claude-sessions-to-drain-usage/)
- **Claude Code 用量上限 9 月 14 日实质下调 17%**：Anthropic 宣布 9 月 14 日起永久提高 Claude Code 基线周用量 25%，但同时取消已执行数月的 50% 临时加量。实际计算：原基线 100 → 临时 150 → 永久 125，等于比当前可用量下降约 17%。适用于 Pro、Max、Team 和 Enterprise 计划。 → [BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/amp/)
- **Debian 投票允许贡献者使用生成式 AI**：Debian 社区在 8 项提案中选择了「负责任使用生成式 AI」方案：既不鼓励也不禁止 AI 工具，但提交者对代码质量承担完全责任。1039 名有投票权的开发者参与，最终方案与 Linux 内核的立场一致。 → [The Register](https://www.theregister.com/ai-and-ml/2026/08/30/debian-votes-to-let-contributors-code-with-ai/5293421)
- **LangChain 8 月更新：Deep Agents v0.7 + LLM Gateway 公测**：Deep Agents v0.7 将基础 harness 的输入 token 消耗降低 65%，性能持平。新发布的 LLM Gateway 公测版在 agent 和模型之间插入控制层，提供成本控制、速率限制、模型回退和敏感数据处理。LangSmith Engine 找 agent 问题的能力提升 2 倍以上。 → [Deep Agents v0.7 博客](https://www.langchain.com/blog/deep-agents-v0-7)
- **LiteLLM MCP 网关曝认证绕过漏洞已被实际利用**：CVE-2026-59822：LiteLLM 的 MCP Streamable HTTP 端点存在 OAuth2 回退缺陷，攻击者用伪造的 Authorization header（甚至单字符 bearer token）即可获得未认证的 MCP 工具调用权限。已有安全研究人员观测到野外利用，与另一个命令注入漏洞 CVE-2026-42271 组合可实现 RCE。 → [GitHub Advisory](https://github.com/advisories/GHSA-7488-6r32-c95q)
- **Claude Code 默认在 commit message 里塞会话链接引发隐私争议**：Claude Code 自动在 git commit message 和 PR 描述中附加 claude.ai/code/session_... 链接，无 opt-in 提示且关闭方式文档不清。多个 GitHub issue（#66504、#69669、#83226）要求改为 opt-in。虽然链接需认证才能访问，但数据最小化原则认为不应将其写入公开 git 历史。 → [GitHub Issue #66504](https://github.com/anthropics/claude-code/issues/66504)
- **V2EX 用户用 GLM 5.3 开发遭遇整个文件夹被删**：一位开发者使用 Codex + GLM 5.3 Flash 配合 Trellis 和 Zcode 开发新项目，跑了 8 亿 token 后，agent 意外删除了上上级文件夹。未上传 GitHub、没有 Time Machine 备份，数据无法恢复。又一个 agent 安全沙箱和权限控制的反面教材。 → [V2EX](https://www.v2ex.com/t/1238217)
- **Warp 分享在 Claude 上构建自改进 Agent 的实践**：Warp 团队在 Anthropic 官方博客发布案例：通过 Agent Skills 模式（技能基线文件 + 自改进器），code review agent 能将人类纠正转化为技能文件更新并自动开 PR。人类审核 merge 后下次执行即继承改进，形成闭环自改进循环。 → [Claude 博客](https://claude.com/blog/how-warp-builds-self-improving-agents-on-claude)

## 📈 趋势

- 🔺 模型供应武器化 — OpenAI 断供 Cursor 开了先例，AI 产品的模型供应链风险从理论走向现实。多模型适配和供应商冗余成为产品架构的刚需。

- 🔻 AI 编码工具的信任摩擦 — Claude Code 会话链接争议、GLM agent 删文件夹、Debian 投票的激烈分歧，开发者对 AI 工具的信任边界在收紧。
