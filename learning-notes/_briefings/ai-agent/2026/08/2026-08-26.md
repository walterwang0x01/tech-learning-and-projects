## 📌 头条

### MCP 无状态化重构全面落地，企业级扩展就绪

Model Context Protocol 最大一次规格修订已全面被采纳：移除传输层会话管理和 Mcp-Session-Id header，改为纯 request/response 无状态协议。Google 主导的 Transports Working Group 驱动了这次变革，使 MCP server 可部署在任意 HTTP 负载均衡基础设施上。Cloudflare 已发布配套 SDK 更新（TypeScript/Python/Go/C#），Anthropic、Microsoft、Okta 联合推进统一授权扩展。这意味着 agent 工具集成从 stdio 本地单连接真正迈入企业级水平伸缩。

→ [CData 企业解读](https://www.cdata.com/blog/mcp-2026-07-28-release) / [Ars Technica 报道](https://arstechnica.com/ai/2026/07/with-a-stateless-makeover-new-mcp-spec-targets-enterprise-scale/) / [Google Blog](https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/)

### OpenAI 暂停训练强化安全，GPT-5.6 降价 20%

OpenAI 因 Hugging Face 安全事件暂停部分前沿模型训练两周并实施新安全控制，调查成本估计 400-1500 万美元。同期宣布 GPT-5.6 Sol API 定价下调超 20%（为期 3 个月），并发布 ChatGPT Agent——支持自主浏览网站、执行代码、生成可编辑幻灯片和表格。OpenAI 同期完成 1220 亿美元融资（估值 8520 亿），资金将用于加速下一阶段 AI 发展。对开发者：Sol 降价使高频 agent 调用成本显著降低，值得重新评估推理预算。

→ [GPT-5.6 (8/21降价更新)](https://openai.com/index/gpt-5-6/) / [OpenAI 1220亿融资](https://openai.com/index/accelerating-the-next-phase-ai/) / [安全暂停报道](https://fortune.com/2026/08/18/openai-says-it-paused-ai-training-for-two-weeks-and-announces-new-security-protocols-following-hugging-face-hack/)

## 📈 趋势

- 🆕 MCP 无状态化是本月最大基础设施事件——agent 工具调用从「本地 stdio 单连接」正式进入「云原生水平伸缩」时代，Google/Cloudflare/Anthropic/Microsoft 联合推进。
- 🔺 Agent 安全成为独立研究方向：间接提示注入检测（hidden states 编码）、工具调用后 unlearning 失效、Agentic 渗透测试失败模式——三篇论文同日上线。
- 🆕 「Workflow first, Agent last」模式持续收敛：STAGE、LangChain Loop Engineering、covonaut DAG/Pregel 双模——行业共识是把 LLM 判断限定在最小必要范围内。
- 🔻 前沿模型价格战加速：GPT-5.6 Sol 降价 20%，Gemini 3.7 Flash 主打性价比，开源 Qwen 被路透社/Airbnb/Pinterest 采用——agent 推理成本正在快速下探。
