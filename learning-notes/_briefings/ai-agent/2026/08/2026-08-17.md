## 📌 头条

### Stripe 70 亿美元买下 OpenRouter

据 Bloomberg 报道，Stripe 已敲定以超过 70 亿美元收购 AI 模型网关 OpenRouter——这家公司做的事很朴素：给开发者一个统一入口，背后接了 400 多个模型。多家媒体提到这个价格相当于它三个月前 Series B 估值（约 13 亿美元）的五倍多，Stripe 官方仍是「不对传言和猜测置评」。值得琢磨的是买家身份：一家支付公司把模型路由层收进去了。Agent 的两个脏活——「这次调用该走哪个模型」和「这次调用该记谁的账」——本来分属两个系统，现在有人打算合在一根管子里做。如果你的 agent 现在通过 OpenRouter 出流量，短期不用动，但值得开始把 provider 抽象层留出口子，别把 base_url 硬编码进业务逻辑。

### dsh 发布三天，第三方生态先跑起来了

DeepSeek Harness（dsh）本身几天前就进了 developer preview，今天值得说的不是它——官方那页架构说明没变——而是围着它长出来的东西。插件市场、桌面壳（含系统通知插件）、Awesome 列表在同一周内冒出来；有人补上了官方缺的那一环，开源了插件 DAG 编排扩展，把「手写 YAML 把 skill、工具、事件钩子组装成 agent」变成画布拖拽连线；还有人把 Web GUI 反代到服务器做手机端远程开发，并踩明白了它默认只监听 127.0.0.1:3080 且刻意禁止直接放开监听地址这一层设计。V2EX 上已经有「用 Pi 的要不要转 dsh」的迁移讨论。这个速度能起来，跟它的架构直接相关：运行时只管生命周期、插件解析和上下文传递，模型、工具、skills、session、sandbox、存储、循环、调度乃至 UI 全是插件，靠底层 Cordis 的服务与事件机制协作。如果你在 LangGraph 上做编排，值得花半小时读它的插件契约——「一切皆插件」和「图是一等公民」是两种不同的扩展哲学，等生态锁定后再迁移成本会高得多。

→ [The New Stack](https://thenewstack.io/deepseek-harness-open-source-plugins/) / [插件 DAG 编排扩展](https://www.v2ex.com/t/1234808) / [服务器部署实践](https://www.v2ex.com/t/1234815) / [量子位](https://www.qbitai.com/2026/08/473597.html)

## 📈 趋势

- 🆕 harness 层成了新战场 — 插件化 agent runtime（dsh / Cordis）开始跟图式编排（LangGraph）抢同一批开发者
- 🔺 模型路由与支付结算合流 — Stripe 买 OpenRouter，把「走哪个模型」和「记谁的账」放进同一层
- 🔺 MCP 安全从单个 CVE 升级成结构性问题 — OX Security 今年 4 月披露的 STDIO 设计缺陷牵连 1.5 亿次下载、约 20 万脆弱实例，核心结论是 localhost 不再是信任边界；近期 Cloudflare 等厂商开始在网络层做检测
- 🔻 前沿实验室的专职安全编制在收缩 — OpenAI 解散 preparedness 团队后改为按领域拆入业务线
