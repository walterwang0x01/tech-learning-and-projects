## 📌 头条

### Cloudflare Wallets：Agent 终于能自己花钱了

Cloudflare 8 月 4 日发布 Cloudflare Wallets，让部署在其平台上的 AI Agent 拥有稳定身份和自主支付能力。核心机制基于 x402 协议——将支付指令嵌入 HTTP 402 响应，Agent 签名稳定币完成付款后即可获取数据或 API 调用结果，全程无需 API key 或人工介入。安全层面，消费上限在钱包 API 层强制执行而非依赖 system prompt，从架构上堵住了 prompt injection 导致超支的口子。这意味着 agent-to-agent 的 API 经济有了原生结算层，值得关注 x402 Foundation 后续生态进展。

→ [官方博客](https://blog.cloudflare.com/wallets) / [新闻稿](https://www.cloudflare.com/press/press-releases/2026/cloudflare-gives-ai-agents-an-identity-and-a-wallet/)

### GitHub Copilot 首份生产级 Agent 负载画像出炉

微软研究院发布首个生产规模的 agentic coding 工作负载分析，基于 2026 年 6 月 GitHub Copilot 的采样 trace：3.2M 用户、13M 会话、761M 次 LLM 调用、95T tokens。论文揭示 agent 编码负载与聊天机器人截然不同——多步推理与工具执行交织产生高度不规则的调度模式，对推理基础设施的弹性调度、KV 缓存管理和尾延迟优化提出新要求。如果你在做 LLM serving 或 AgentOps，这份数据值得细读。

→ [arXiv](https://arxiv.org/abs/2608.00101) / [微软研究页](https://www.microsoft.com/en-us/research/publication/agentic-coding-in-the-wild-characterizing-github-copilot-at-production-scale/)

## ⚡ 快讯

- **MateClaw 2.0**：从单 Agent 任务执行升级到多 Agent 围绕共享任务板协作，支持 MCP/ACP 工具接入、工作流触发器与多渠道接入。Spring Boot 生态的 AI Agent 平台又进了一步。 → [发布公告](https://www.oschina.net/news/487697)
- **Cloudflare Codex**：Cloudflare 公开自家用 AI Agent 执行工程标准的实践：将 RFC 结构化为可机读规范（"Codex"），由 agentic review 在代码、spec 和事故报告中自动检测不一致。从内部治理到外部最佳实践的转化。 → [博客](https://blog.cloudflare.com/engineering-standards-enforcement)
- **MCP 服务器首次大规模动态安全评估**：arXiv 新论文扫描公网 21000+ MCP 实例，结合 11 个数据源发现与主动动态测试工具 Corvus。这是首份对 MCP 服务器进行行为级（而非静态扫描）安全评估的研究，量化了暴露面与实际可利用程度。 → [arXiv](https://arxiv.org/abs/2608.00150)
- **智谱 GLM-5.3 提前曝光**：智谱下一代模型尚未正式发布，但 AI 编程工具 ZCode 官网已上线 "ZCode for GLM-5.3" 页面，SDK 仓库也出现对应提交。细节待官方确认。 → [报道](https://www.oschina.net/news/487000)
- **Google/Kaggle AI Agents Intensive 结课**：6 月 15-19 日举办的免费 5 天 AI Agent 课程吸引了 35.3 万注册学员，课程涵盖 agent 架构、工具调用、记忆与评估，从原型到生产。Google 官方总结已发布。 → [回顾](https://blog.google/innovation-and-ai/technology/developers-tools/ai-agents-intensive-recap-2026)
- **论文：Agentic AI 评测可靠性危机**：《Measurement Without Validity》指出 agent 评测的复合可靠性问题：benchmark 由 LLM 生成、评分器与被测系统共享偏差、分数膨胀掩盖真实能力。提出三层累积误差模型。对依赖评测做部署决策的团队是警示。 → [arXiv](https://arxiv.org/abs/2608.00794)
