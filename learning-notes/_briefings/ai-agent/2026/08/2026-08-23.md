### MCP 新路线图：agent 要有自己的身份了

MCP 核心维护者 David Soria Parra 和 Den Delimarsky 8 月 22 日发布新路线图，把接下来几个规范版本的重点收敛到五个方向：agentic 消息原语、HTTP 传输统一与加固、agent 身份与企业级安全、原语改进、SDK 开发体验。最值得留意的是身份这一块——官方直说今天的 MCP 授权是围绕「一个人在浏览器里点同意」设计的，而越来越多调用方是作为云工作负载运行、代表不在场的用户行事、还要把更窄的权限再委派给子 agent 的 agent；解法是把 DPoP 定稿推广，并用 Workload Identity Federation、Enterprise-Managed Authorization 背后的 ID-JAG grant 和标准 token exchange 给出一条有主张的委派路径，而不是继续糊 API key 和长效 token。原语这边点了一个所有人都在吃的亏：连上一个有一百个工具的 server，模型在用户开口之前就已经为整个工具面付费了，而且工具越多选得越差，所以要做渐进式发现——server 先给一个小入口，随对话收窄再放出更多目录。同时 tools/call 的返回体今天可以用多种形式承载同一份输出，server 作者无从知道客户端会把哪一种喂给模型，这次要统一成一份明确契约。另外落在优先区内的 SEP 会走加速评审，Tasks 扩展（SEP-2663）正在从扩展往正式规范里推，长跑任务 + 服务端主动推送（webhook 与 channel）会取代客户端轮询。如果你手上有工具数量偏多的 MCP server，现在就可以按渐进式发现的思路先把工具面切成分层入口；跑企业内网的话，把授权从「浏览器点同意」迁到 workload 身份这件事已经进了官方时间表，值得提前排。

→ [官方博客](https://blog.modelcontextprotocol.io/posts/mcp-roadmap) / [HN 讨论](https://news.ycombinator.com/item?id=49399591)

### 27B 小模型 agent 在论文复现上压过 Opus 4.8 和 GPT-5.5

刚从 stealth 出来几周、拿了 5000 万美元种子轮的伦敦实验室 Inherent（创始团队多为 DeepMind 前员工）发布了 agent Faraday，声称在「不给答案、独立复现已发表论文结论」这一项任务上超过了 Anthropic Claude Opus 4.8 和 OpenAI GPT-5.5。关键数字是底座只有 Qwen 3.6 的 270 亿参数，比对手小几个量级，训练路线以强化学习为主，目标不只是复现准确率，还包括他们称为 research taste 的东西——判断哪些实验值得做、怎么设计。另一个工程决策更值得抄：Inherent 没自己造 coding tool，直接让 Faraday 用 OpenAI 的 GPT-5.5 Codex，理由是人类科学家也是用现成软件而不是什么都自己写。需要说清口径：这个对比结果目前只有公司自述和 TechCrunch 的转述，没有第三方独立复测，所以当成「小模型 + RL + 借用成熟外部工具」这条路线的一个信号读比较稳妥，别当成公认排名。如果你在做垂直领域 agent，这条路线的启发是别急着换更大的模型，先看能不能把评分函数和外部工具接得更好。

→ [TechCrunch](https://techcrunch.com/2026/08/22/inherent-founded-by-deepmind-alumni-says-its-ai-teammate-just-outperformed-anthropic-and-openai-at-replicating-research) / [IT之家中文报道](https://www.ithome.com/0/993/133.htm)

## 📈 趋势

- 🆕 agent 身份正式进入协议议程 — MCP 要把授权从「人在浏览器点同意」迁到 workload 身份 + 可委派的窄权限（DPoP / WIF / ID-JAG）
- 🆕 工具面成本被当成一等问题 — 渐进式工具发现的提法说明「一次性塞一百个 tool schema」这条路业界已经认定走不通
- 🔺 小模型 + RL + 借用外部成熟工具 — Faraday 用 27B 底座 + GPT-5.5 Codex 打赢前沿大模型，垂直 agent 的性价比路线开始出成绩
- 🔻 coding agent 的「主力位」不再稳定 — Codex 与 Claude Code 换手的实测帖和 effort level 降级质疑同时冒出来，选型要开始把配额与稳定性当变量
