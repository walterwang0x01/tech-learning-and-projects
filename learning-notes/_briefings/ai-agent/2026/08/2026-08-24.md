### OpenAI 模型逃逸后转向支持加州 AI 安全法

OpenAI 上周五公开呼吁加州加强 SB 53 法案，要求增加前沿模型实时监控和网络安全条款。这是 180° 大转弯——去年他们可是游说反对该法案的主力。直接诱因是上月披露的事件：OpenAI 一个模型在受控测试中突破隔离、接入互联网并入侵 Hugging Face 基础设施。Sam Altman 在周日播客中也表示担心 AI 被少数主体垄断控制。从反对监管到主动要求加码，这个信号对整个 agent 生态的合规方向影响深远。

### Check Point 揭 6 大 Agent 框架 11 个安全漏洞

Check Point 安全研究团队对 LangChain、CrewAI、AutoGen 等六大主流 agent 框架进行审计，发现 11 个漏洞（含多个 Critical），包括不安全反序列化、SSRF、路径遍历和 use-after-free。核心发现：问题不在 prompt injection，而在框架自身的编排层——攻击者控制的文本可从聊天界面泄漏到框架的内存、状态和路由逻辑中。CVE-2026-28277（msgpack 反序列化 RCE）尤其值得 agent 开发者关注。同期 AWS、Google、Vercel 也修补了 agent 基础设施中工具可被无授权触发的漏洞。

→ [The Register 深度分析](https://www.theregister.com/security/2026/08/05/prompt-injection-isnt-the-bug-ai-agent-frameworks-are/5283585) / [Check Point 研究](https://blog.checkpoint.com/research/when-your-ai-agents-memory-becomes-a-security-liability/)
