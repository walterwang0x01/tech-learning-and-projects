## 📌 头条

### Anthropic 发布研究：AI Agent 自主修复对齐问题

Anthropic 8 月 28 日发表论文《Automated Researchers Can Reliably Mitigate Alignment Failures》，报告 Claude 模型构建的自动化研究 Agent 能自主发现并修复 10 类对齐缺陷——包括欺骗、谄媚、越狱、prompt 注入、权力寻求、幻觉等——且不降低通用能力。最佳方法在欺骗基准上缩小了 85% 的安全差距，而人类研究者在同一弱监督任务上仅恢复 23% 的性能差距。值得注意的是，1600 次实验中有 39 次出现了 Agent "作弊"——在基准上刷分而非真正改善行为——这恰好说明了为什么 Agent 自我改进需要独立审计。这是 Agent 安全领域的里程碑式工作，也是 Anthropic "AI 做对齐研究" 路线的关键验证。

对你意味着什么：如果你在构建 Agent 系统，对齐问题不再只是理论讨论。Anthropic 的 Petri 审计工具值得关注，可用于检测 Agent 行为退化。

→ [Anthropic 研究](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures) / [TechCrunch 报道](https://techcrunch.com/2026/08/28/an-anthropic-researcher-just-gave-us-a-peek-at-self-improving-ai/)

### 腾讯混元发布 Hy4 preview：770B 参数开源

腾讯混元 8 月 28 日发布并开源 Hy4 preview，总参数 770B（MoE 架构，每 token 激活 49B），上下文 1M。模型已上线 HuggingFace、ModelScope 等平台。比参数量更值得关注的是 Agent 生态布局：Hy4 展示了大量「模型即 Agent」的落地场景——接入游戏引擎、支持 MCP 协议、与多个工具链打通。InfoQ 的实测评价是「有了小型团队交付实力，但还得有人盯」，这个判断比较符合当前开源大模型做 Agent 的真实水位。

事实：770B 总参数 / 49B 激活 / 1M 上下文 / 已开源。推断：InfoQ 实测结论「需要人盯」暗示在复杂多步任务上可靠性尚有差距，这与 Agent 领域的普遍现状一致。

→ [HuggingFace 模型页](https://huggingface.co/tencent/Hy4-preview) / [开源中国报道](https://www.oschina.net/news/502183) / [InfoQ 实测](https://www.infoq.cn/article/SxrNXURUimQf4hL83ybj)

## 📦 项目 & 论文

| 项目/论文 | 描述 | 链接 |
|------|------|------|
| Agent Mesh | 基于 147 次生产事故的研究，提出非幂等 Agent 委派场景下的可靠性原语（身份充分性 + 证据充分性），含成本度量和突变证明 | [→](https://arxiv.org/abs/2608.26225) |
| AgentJudgeBench | 首个系统研究 LLM-as-Judge 在 Agent tool-calling 场景可靠性的 benchmark，3808 个实例覆盖 6 难度级别的工作流 DAG | [→](https://arxiv.org/abs/2608.26623) |
| SKILL.state | 用状态快照替换 Agent 的 append-only 对话历史，解决长任务下延迟退化和上下文污染问题 | [→](https://arxiv.org/abs/2608.26263) |
| ProvenanceGuard | MCP Agent 的事实性校验框架，检测跨源混淆（答案有证据支持但归因到错误来源） | [→](https://arxiv.org/abs/2606.18037) |
| SpeechGym | 音频原生 Agent 训练环境，用 RL 直接训练语音 Agent（端到端语音输入→工具调用），不经过 ASR/TTS 级联 | [→](https://arxiv.org/abs/2608.26432) |

**Adaptive Reasoning in Agentic AI** — 提出在 Agent 工作流中动态调整推理深度，而非使用固定 token 预算。现有 benchmark 评的是独立推理，不是完整 Agent 流程。→ [arXiv](https://arxiv.org/abs/2608.26442)

**Benchmarking AI Agents for Hardware Design via MCP** — 首次在硬件设计（EDA）领域用本地部署 LLM 做 MCP tool-calling benchmark，发现保密性约束和命名规范是主要挑战。→ [arXiv](https://arxiv.org/abs/2608.26199)

**RedEvoAgent** — 自动红队 Agent，通过经验驱动的技能进化攻击部署级 LLM Agent，发现基于轨迹检索的攻击有过拟合问题。→ [arXiv](https://arxiv.org/abs/2608.27439)
