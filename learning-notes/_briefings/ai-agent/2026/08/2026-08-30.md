## 📌 头条

### OpenAI 断供 Cursor：模型成为竞争武器

OpenAI 于 8 月 28 日正式通知 SpaceX，将在 11 月 12 日终止向 Cursor 提供 GPT 模型。原因很直白——信任。SpaceX 今年 6 月以 600 亿美元收购 Cursor 母公司 Anysphere 后，OpenAI 援引合同中的「控制权变更」条款触发终止权。Cursor 用户仍可通过个人 API key 或 OpenAI IDE 插件继续使用 GPT 模型，但内置的模型直供管道将彻底关闭。Replit CEO Amjad Masad 随即表态：Replit 可免费提供 OpenAI 模型，并愿意资助企业从 Cursor 迁移。Anthropic CEO Thariq 也发推表示将继续与 Cursor 合作。模型供应正在从技术决策变成商业博弈筹码。

→ [OpenAI 官方声明](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/) / [CNBC 报道](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)

### Anthropic 发布 MHS：AI Agent 接管实验室硬件

8 月 27 日 Anthropic 发布 Model Hardware Standard（MHS），这是继 MCP 之后第二个试图定义行业标准的协议。MHS 让 AI agent 能发现、监控和操作可编程物理设备——显微镜、液体处理器、机械臂。Anthropic 的类比是「USB-C for AI-to-hardware」：一个统一接口层取代针对每台设备的定制集成，号称把设备接入时间从数月压缩到小时级。MHS 与模型无关，任何 agent 可通过 MCP 接入。研究预览阶段已在 HHMI Janelia 研究中心的神经科学实验中完成实测，用于药物发现实验和量子计算机激光校准。Anthropic 计划在安全评估后开源 MHS。这实质上是 agent 从数字世界向物理世界扩展的第一个正式接口标准。

→ [Anthropic 官方公告](https://www.digitaltrends.com/computing/anthropic-previews-new-standard-to-streamline-ai-to-machine-connections/) / [Ars Technica 深度](https://arstechnica.com/ai/2026/08/anthropics-new-hardware-standard-lets-ai-agents-control-the-physical-world/)
