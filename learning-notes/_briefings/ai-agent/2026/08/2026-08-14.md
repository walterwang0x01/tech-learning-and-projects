### DeepSeek 开源 Harness：一切皆插件的 Agent 运行时

DeepSeek 把 Agent 运行时框架 DeepSeek Harness（dsh）v0.1 开发者预览版以 MIT 协议开源了，源码在 GitHub。它的卖点不是模型而是架构：没有自己造插件系统，而是构建在 Cordis 这个插件元框架之上——Cordis 只负责插件挂载/卸载和依赖管理，模型、工具、skill、session、sandbox、存储、agent loop、调度乃至 UI 全部是独立插件，靠 service 和 event 互相协作，改配置就能替换或扩展任意一层而不动 Harness 源码。真正有工程价值的是第二条设计原则「每次运行都可追溯」：模型看到的一切——系统提示、推理、工具调用与结果、subagent 调度、每一次 context 注入——都写进 append-only 的 session log，Trajectory 视图能按来源逐条查看，resume / fork / search / replay 全部跑在同一条事件流上。运行模式给了四种：Standard（全工具集）、Code（工具通过 Code Mode SDK 暴露，让模型用一段 TypeScript 编排多轮调用）、Minimal（只留持久 bash + str_replace_editor，用于在极简环境里裸测模型能力）、Creator（可在内存里试插件并组合成新预设）。官方把这套叙事总结成 Agent = Model + Harness，等于承认模型之外的运行时是独立的工程品类。如果你在维护自己的 agent 编排层，今天就值得 `npx @deepseek-ai/dsh web` 跑一遍，重点对照它的 session log 边界和 Minimal 模式——后者是难得的、能把「框架加成」从「模型能力」里剥出来的对照组。框架仍在 developer preview，核心插件和 API 会继续变，别急着上生产。

→ [官方页](https://deepseek.com/harness/en/) / [GitHub](https://github.com/deepseek-ai/deepseek-harness) / [开发者文档](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart) / [开源中国](https://www.oschina.net/news/501925/deepseek-harness-developer-preview)

### Qwen 首次开源 Max 级模型：2.4T 总参、95B 激活

Qwen 团队把 Qwen3.8-2.4T-A95B 的权重放上了 HuggingFace 和 ModelScope，这是 Qwen-Max 级别模型第一次开放给社区。规格是 2.4 万亿总参数、每 token 激活 95B 的稀疏 MoE，架构基础沿用 Qwen3.5，官方说提升集中在编码、专业工作、研究和 long-horizon agentic 任务——重点不是能答更难的题，而是能把多步复杂任务更可靠地做完。要注意开源权重和 API 上的 Qwen3.8-Max 不是一回事：官方 model card 明确写了 Max 版额外有视觉输入、non-thinking 模式、默认 1M 上下文和官方内置工具，开源这版是纯文本模型，能力面没有全部对齐。现实的落地障碍是显存：第三方测算 4-bit 量化下仍需约 1.2TB VRAM，NVIDIA 的部署实践直接写在 GB300 NVL72 这一级机器上，个人本地基本别想。对用 LangGraph 做编排的场景，短期更现实的用法是走 API 或托管推理，把它当 long-horizon 任务的能力上限对照组，而不是自建推理。

→ [HuggingFace model card](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) / [NVIDIA 部署实践](https://developer.nvidia.com/blog/serve-qwen3-8-2-4t-a95b-a-2-4t-parameter-model-with-configurable-reasoning-on-nvidia-gb300-nvl72/) / [开源中国](https://www.oschina.net/news/501918)

## ⚡ 快讯

- **GhostJacking**：Tenet Security 在 DEF CON 34 演示了一类针对 MCP 集成的间接注入：攻击者先往可观测性平台种下带注入的错误日志，等用户让 agent「看一下报错并修掉」时中招。Cloudflare 路径只需触发一次 WAF 403，把 User-Agent 伪装成扫描器遥测，就能诱导 Cursor 改 DNS A 记录、加 CNAME 把流量导到攻击者域名；对 Claude Code（Sonnet 4.6）成功率 90%。DataDog 和 Sentry 路径靠泄漏的 client token / DSN 灌假日志，研究者在公开页面源码和 GitHub 里扒到 2,700+ 个 DataDog token 和近 2,400 个 Sentry DSN。他们自己的结论是这不是某个能打补丁的 bug：真正的修复在 agent 运行时行为管控加 kill switch，配套放出了开源工具 agent-jackstop。 → [SC Media](https://www.scworld.com/news/ghostjacking-attack-turns-error-logs-into-indirect-prompt-injections) / [agent-jackstop](https://github.com/tenet-security/agent-jackstop)

## 📈 趋势

- 🆕 「harness」成为独立产品品类 — 模型厂商开始把模型之外的运行时单独开源，Agent = Model + Harness 这个拆分被 DeepSeek 写进了官方叙事
- 🔺 可追溯性取代 callback 成为框架卖点 — append-only session log 加 trajectory 回放，resume/fork/replay 跑同一条事件流，比「接个 tracing」彻底得多
- 🔺 Agent 安全防线从沙箱和提示词加固往运行时行为管控迁移 — GhostJacking 研究者的原话是「沙箱和提示词加固不够，真正的修复是在 agent 即将动手前拦住它，带 kill switch」
- 🔻 开源权重的可及性在下降 — 2.4T 参数即使 4-bit 也要 TB 级显存，「开源」和「你能自己跑」正在脱钩，Day0 多芯适配这类基建的重要性反而上升
