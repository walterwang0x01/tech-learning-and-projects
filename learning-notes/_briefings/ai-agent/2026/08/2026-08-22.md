## 📌 头条

### Nvidia 实测：决定 Agent 上限的是 harness，不是模型

Nvidia 周五放出的研究里，同一个 Claude Opus 5 换个 harness，ARC-AGI-3 成绩从 30% 直接拉到 100%。ARC-AGI-3 是一组没有说明书的 2D 游戏，模型得自己摸索规则再赢，30% 已经是所有被测模型里的最好成绩。他们自己写的 harness 叫 Agentic Variation Operators（AVO），关键改动有两处：把 memory 管好，以及在主 agent 之外加一个 supervisor——Nvidia 产品副总裁 Adel El Hallak 的说法是它「像个 CEO」，agent 跑偏、钻进死胡同或者重走老路时把它拽回来。这条结论有旁证：OpenAI 上个月只调了 harness 的两个设置，自家模型 ARC-AGI-3 分数就翻了三倍（但仍远不到 100%）；Databricks 七月的研究则说同一个模型换错 harness 成本能差一倍。今天大多数人的 agent 只有单层 harness——Claude Code、Codex、Hermes 就是全部。如果你在做长程任务，值得先别急着换模型，把 supervisor 层和 memory 策略补上再测一遍。AVO 不是 Nvidia 的新产品，相关组件散在 Nemo 品牌下，部分开源。

→ [TechCrunch](https://techcrunch.com/2026/08/21/nvidia-just-showed-that-the-harness-not-the-ai-model-is-now-the-real-hero)

### Claude Security 开放代码库扫描，patch 直接落到 Claude Code

Anthropic 把 Mythos 5 的安全能力开放给更多防守方：把 Claude Security 指向一个 GitHub 仓库，它会跨文件追踪数据流、推理组件之间怎么交互，然后逐条给出漏洞——每条带 CWE 分类、置信度和严重性评级，以及一个建议修复。建议的 patch 直接在网页版 Claude Code 里打开，用你团队本来在用的模型。官方特意说明了这套的权限边界：模型跑在扫描背后，只返回结论，防守方拿到结果不需要直接接触模型；计费按现有套餐的标准 token 用量走，没有额外定价。这基本是「agent 做静态分析」这条路线的第一个大厂正式产品化形态，值得拿自己的仓库跑一遍对比一下现有 SAST 的误报率。

→ [官方公告](https://x.com/claudeai/status/2090852316328902930) / [Anthropic 博客](https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders) / [HN 讨论](https://news.ycombinator.com/item?id=49392331)

## 📈 趋势

- 🔺 harness 工程正在盖过模型选择 — Nvidia（30%→100%）、OpenAI（分数翻三倍）、Databricks（成本差一倍）三家的结论指向同一件事：supervisor 层和 memory 策略的收益，比换模型大
- 🆕 agent 安全从注入攻击走向「加密混淆注入」 — Grok 的 Cryptographic Context Injection 说明明文关键词过滤这条防线已经不够用；同一周 Anthropic 反向把 agent 做成扫漏洞的防守工具，攻防两头同时提速
- 🔺 推理成本继续跳水 — OpenAI 主力模型三个月内降 20%+，国内云厂商为冲量把第三方模型打到 3 折击穿成本线；对 agent 来说，多轮长程调用的经济性门槛在快速下移
- 🔻 「全员铺 agent」式投放降温 — 美团 8 万人、日耗千万算力换不来生产力提升的复盘，把叙事从「规模换认知」拉回到单场景 ROI 验证
