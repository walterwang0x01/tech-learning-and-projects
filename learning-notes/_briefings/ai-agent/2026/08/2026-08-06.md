## 📌 头条

### Cloudflare OS 开源：企业级 Agent 工作平台

8 月 5 日 Cloudflare 将内部使用数月的 AI 工作平台 Cloudflare OS v2 完整开源。它基于 Workers + Durable Objects 构建，为每个员工提供浏览器内的 Agent 工作空间，可连接内部系统、生成文档/幻灯片、创建按需运行的 micro-app，并通过名为 Gatekeepers 的能力型访问控制层管理数据权限。Cloudflare 称该平台已在内部覆盖工程、销售、IT 等所有职能。对企业来说，这提供了一条不依赖第三方 SaaS 的 Agent 部署路径——fork 后接入自己的身份认证和内部 API 即可落地。

→ [官方博客](https://blog.cloudflare.com/cloudflare-os/) / [内部使用实践](https://blog.cloudflare.com/how-we-use-ai-with-cloudflare-os/)

---

### WriteGuard 私测：MCP 写操作终于有了细粒度管控

同日 Cloudflare 宣布 WriteGuard 进入私测，这是针对 MCP Server Portal 的写操作审计与管控层。WriteGuard 以 deny-by-default 策略为每个 Agent 的写工具调用设置 allow-list，记录调用方身份、MCP 客户端、会话信息，并在目标应用内标注写操作来源。核心动机是 Cloudflare 在内部扩展 MCP 写权限时发现「不能依赖每个员工正确配置每个 Agent」。对于正在部署 MCP 的团队，这标志着 MCP 生态正式进入「治理层」建设阶段。

→ [博客原文](https://blog.cloudflare.com/mcp-portal-writeguard-private-beta) / [私测申请](https://www.cloudflare.com/resource/writeguard-beta-landing-page)

## ⚡ 快讯

- **Cloudflare Computer**：开源 @cloudflare/computer npm 包，提出 isolate-first 的 Agent 运行时——Agent 日常工作跑在轻量 Isolate 里，仅不到 10% 需要完整容器。挑战了「每个 Agent 一个容器」的行业默认假设。 → [→](https://www.oschina.net/news/487766/cloudflare-computer)
- **微软 ETW MCP**：微软发布 ETW MCP Server 早期预览，让 GitHub Copilot 等 MCP 客户端用自然语言查询 Windows 事件追踪数据，配合此前的 WPA MCP 构成完整的 AI 性能诊断方案。 → [→](https://devblogs.microsoft.com/performance-diagnostics/etw-mcp-intro/)
- **LangChain**：公开自主 SRE Agent 构建实践：基于 Deep Agents 运行时，对 Kubernetes 集群进行健康分诊与修复提案，变更操作需人工审批，配合 LangSmith 追踪和 eval 保障可靠性。 → [→](https://www.langchain.com/blog/how-we-build-an-autonomous-sre-agent-for-kubernetes-deployments)
- **CX Agent 生产经验**：LangChain 联合 Lyft、Vodafone、LATAM Airlines 分享客服场景 Agent 落地经验。这是 Agent 在非开发者场景规模化部署的行业信号。 → [→](https://www.langchain.com/blog/customer-experience-cx-agents-in-production-lessons-from-lyft-vodafone-and-latam-airlines)
- **Cloudflare CI Workflows**：Cloudflare 推出原生 CI/CD 能力，用 TypeScript workflow steps 替代 YAML 配置，内置自愈 AI Agent 处理构建失败。直接与 GitHub 竞争 CI 市场。 → [→](https://blog.cloudflare.com/ci-workflows)
- **Gitee AI 队友**：Gitee 正式上线 AI 队友功能——提 Issue 后 AI 自动理解需求、编码并提交 PR；跟踪项目进度识别延期风险；自动代码审查与安全扫描。新用户赠 500 Credits。 → [→](https://www.oschina.net/news/486884)
