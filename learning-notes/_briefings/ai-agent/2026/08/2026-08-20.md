## 📌 头条

### Stripe 收购 OpenRouter，路由层比模型公司还贵

Stripe 昨天正式宣布同意收购 OpenRouter，官方新闻稿只说这是「AI 模型网关与路由平台」，帮企业在 80 多家供应商的 400 多个模型之间路由和优化 token 用量，交易金额没有披露。价格靠媒体口径拼：NYT 消息源给 75 亿美元，Axios/Forbes 说超过 80 亿——不管取哪个数，一个夹在应用和模型之间的路由层，估值已经压过了绝大多数单个模型公司。对做 agent 的人来说这件事的信号比金额本身重要：多模型路由已经被认定是一个独立的、值得付钱的基础设施位置，而买家是支付公司而不是云厂商，说明按 token 计费/结算这条链路才是它真正看上的东西。如果你的 agent 现在直接打某一家的 API，可以顺手评估一下把模型调用抽一层出来的成本，Stripe 进场之后这个位置的商业化只会更快。

→ [Stripe 官方新闻稿](https://stripe.com/newsroom/news/stripe-agrees-to-acquire-openrouter) / [TechCrunch 解读](https://techcrunch.com/2026/08/19/stripe-didnt-really-buy-openrouter-because-of-the-singularity/) / [开源中国](https://www.oschina.net/news/502014/openrouter-is-joining-stripe)

### GLM-5.3 上线 API，AA 拿 60 分并列开源第一

智谱昨天凌晨上线 GLM-5.3 API，在 Artificial Analysis 综合智能指数上拿到 60 分，与 Kimi K3 并列开源模型第一，落后 GPT-5.6 Sol 一分。最值得看的不是总分而是 agent 维度：GDPval-AA v2 的 Elo 从 GLM-5.2 的 1524 跳到 1770，涨了 246 分，仅次于 Claude Opus 5 的 1855。定价维持 100 万输入 token 1.40 美元 / 输出 4.40 美元 / 缓存输入 0.26 美元，单任务成本 0.68 美元，比上一代 0.44 涨了 55%，但仍比 Kimi K3 的 0.84 便宜约 19%。官方口径称这一版和 GLM-5.2 共享同一个 base model，提升全部来自 post-training 规模化——这个说法目前只有官方博客一个来源，权重据称本周内开放，等权重出来才能验。国家超算互联网也已经上线免部署的 GLM-5.3 API 调用。如果你在跑长程 agent 任务的选型，这一版值得进你的对比池。

→ [开源中国](https://www.oschina.net/news/502007) / [The Decoder 评测拆解](https://the-decoder.com/glm-5-3-tops-the-open-model-rankings-and-undercuts-rivals-on-price-but-its-release-is-delayed/) / [超算互联网上线](https://www.36kr.com/newsflashes/3947244309085573)
