## 📌 头条

### NVIDIA 129亿美元收购 Hugging Face

据 The Information 和 CNBC 报道，NVIDIA 已同意以约 129 亿美元收购开源 AI 模型托管平台 Hugging Face。这是 NVIDIA 有史以来最大的收购之一，也意味着开源 AI 生态的中立社区将归属芯片巨头。Hugging Face 去年曾拒绝 NVIDIA 5 亿美元投资（当时估值 70 亿），一年内估值几乎翻倍。此举被解读为 NVIDIA 从卖铲子转向控制模型分发层。

→ [CNBC 报道](https://www.cnbc.com/2026/08/27/nvidia-hugging-face-acquisition.html) / [TechCrunch](https://techcrunch.com/2026/08/26/nvidia-closes-in-on-hugging-face-acquisition/) / [Forbes 分析](https://www.forbes.com/sites/jonmarkman/2026/08/27/nvidia-strikes-129-billion-deal-to-buy-hugging-face/)

### OpenAI 正在开发永续运行 AI Agent

据 WIRED 报道，OpenAI 正在测试 Codex 编码 Agent 的 Persistent 模式，该模式可让 Agent 在不被明确休眠之前持续工作，跨会话主动创建后续任务。同时 OpenAI 于 8月26日正式发布 ChatGPT Agent，可自主浏览网页、运行代码、生成可编辑幻灯片和电子表格。加上 GPT-5.6 Sol 降价超 20%，OpenAI 在 Agent 基础设施上全面加速。

→ [WIRED: Persistent Agent](https://www.wired.com/story/openai-is-developing-a-persistent-ai-agent/) / [TechCrunch: OpenAI Agent 野心](https://techcrunch.com/2026/08/24/openai-is-building-an-ai-agent-for-everything-will-everyone-use-them/) / [Sol 降价报道](https://www.technology.org/2026/08/24/openai-gpt-5-6-sol-price-cut-developers/)

## ⚡ 快讯

- **Anthropic**：发布 Model Hardware Standard (MHS) 研究预览，用标准化驱动接口让 AI Agent 控制物理世界设备（显微镜、机械臂等），类似 USB-C 对硬件通信的标准化。 → [官方公告](https://www.anthropic.com/news/model-hardware-standard-research-preview)
- **Anthropic Fable 5**：据 Ramp 7万家企业支出数据，Fable 5 发布两月后企业支出占比仅 11%，旧款便宜模型占 89%。最贵不等于最用。 → [Gizmodo 报道](https://gizmodo.com/businesses-are-shunning-anthropics-fable-5-for-cheaper-models-2000802283)
- **LangChain**：密集发布：与 NVIDIA 合作推出企业级 Agentic AI 平台、LangGraph Platform GA、Wiki Memory（基于文件的 Agent 持久记忆）、LangSmith Engine（用 Agent 改进 Agent）。 → [NVIDIA 企业平台](https://www.langchain.com/blog/nvidia-enterprise) / [LangGraph Platform GA](https://www.langchain.com/blog/langgraph-platform-ga) / [Wiki Memory](https://www.langchain.com/blog/wiki-memory)
- **DeepSeek Harness**：开源 Agent 运行时（MIT 协议），基于 Cordis 插件架构，模型/工具/会话/沙箱/UI 均为可热插拔插件。发布一周 GitHub 约 16.9 万 star。 → [官方介绍](https://deepseek.ai/blog/deepseek-harness-open-source-claude-code-alternative)
- **智谱 GLM-5.3-Flash**：正式开源，320B 参数/18B 激活，MIT 协议。此前以 Ox Alpha 匿名登顶 OpenRouter 盲测榜，官方称 AA 智能指数 57 分。 → [Hugging Face 模型卡](https://huggingface.co/zai-org/GLM-5.3-Flash)
- **阿里 Qwen3.8-Flash**：同日发布，125B 总参数/6B 激活，原生 262K 上下文可扩展至 1M，训练成本仅前代 1/9。 → [Hugging Face](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)
- **Azure DevOps**：发布远程 MCP 服务器，但目前不支持 Claude、ChatGPT 及 Cursor 等主流 Agent 客户端。 → [InfoQ 报道](https://www.infoq.cn/article/SvTBvljtvGctvWPQRqr7)
- **Lody**：Coding Agent 协作工作空间开源（CLI + 桌面端），支持 Claude Code/Codex/OpenCode 等多 Agent 隔离并行、会话共享和团队协作。 → [开源中国](https://www.oschina.net/news/502156/lody-is-now-open-source)

## 📈 趋势

- 🆕 Agent Harness 成为新战场：DeepSeek Harness 开源、Microsoft Agent Framework GA，Model + Harness = Agent 范式正在确立——模型之外的运行时编排层决定了 Agent 的实际能力边界。
- 🔻 前沿模型价格战白热化：OpenAI Sol 降价 20-33%、GLM-5.3-Flash 定价仅 GLM-5.2 的 1/10、Qwen3.8-Flash 训练成本仅前代 1/9——便宜模型吃掉 89% 企业支出的 Fable 5 数据说明够用就好是企业共识。
- 🆕 Agent 从数字走向物理：Anthropic MHS 标准化硬件驱动接口，OpenAI Astra 多 Agent 协调演示，Agent 的操作域从 API 调用扩展到实验室设备和机械臂。
- 🔺 Agent 框架安全债浮出水面：Check Point 在六大主流 Agent 框架中发现 11 个漏洞（含反序列化 RCE、SSRF），均为经典 Web 安全老问题——Agent 编排层的安全审计远落后于其部署速度。
