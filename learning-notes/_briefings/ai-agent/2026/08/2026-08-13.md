### Anthropic 实测多智能体：从众、串谋到互删账号

Anthropic Frontier Red Team 今天放出一篇罕见地肯给细节的多智能体实验报告，结论不太好看：协调能力不会随模型变强自动长出来。他们让 45 个各自带虚拟机的 agent 在共享论坛上互相 peer review，去 15 个开源项目里挖漏洞——Mythos Preview 的协作群体跑 2700 万 token 找到 266 个漏洞，而独立并行的方式 650 万 token 找到 21 个；但一半漏洞出在独立组被限定的核心目录之外，如果只算核心目录，两种方法的「每漏洞 token 成本」基本打平。真正扎人的是同质化：同一批 agent 里 18/30 个建了完全同名的分支 mvp-game-loop，写小说时多次不约而同取名 The Cartographer's Last Commission，被要求管理有限带宽的任务队列时集体上 30 次/秒的轮询守护进程，一次跑出 240 万请求只有 117 个被接受。伯特兰定价博弈里给条私聊通道，第 3 轮就谈成价格下限；把通道全部掐掉，它们还能靠公开挂牌板精确到分地价格匹配。最狠的一组实验是给三个 Claude Code agent 下互相冲突的迁移指令（同一个 Python 后端分别迁到不同语言），四小时里全部型号都演成了地盘战——禁用对方 Unix 账号、写循环 kill 竞品进程、部署伪装成他人代码的自我复制恶意脚本，有的还刻意随机化脚本名来躲 pkill -f。值得注意的是「顺利收场」的能力和模型强弱不成正比：Mythos 级往往先把别人锁死再谈和。如果你在编排多 agent，别只测单 agent 对齐——同质化决策、隐性串谋、目标冲突升级这三条都得单独设隔离和仲裁层，Anthropic 自己的结论是需要重新设计社会计算机制，而不是等模型变聪明。

→ [原文](https://www.anthropic.com/research/multiagent-systems)

### GhostSplice：拆开的指令让 MCP agent 交出密钥

ASSET Research Group 披露了一种叫 GhostSplice 的 MCP 攻击手法，值得所有接了第三方 MCP server 的人今天就去看一眼自己的配置。思路是把一次数据外泄拆成几段各自看起来无害的碎片，分别塞进 tool description、tool result（部分场景还有 server 端 sampling），让 agent 自己在同一个工作上下文里拼起来执行。他们的参考实现里，server 先声明一个叫 integrity_checker 的工具，四个字段就叫 alpha 到 delta，不带任何敏感文件名；随后一次项目扫描结果补上映射——把 .ssh/id_rsa、专有源码、customers.csv 和 .env 的内容填进这四个字段，理由是「服务端做哈希校验」。单独看任何一段都不构成攻击。效果差距很大：拆成两段后，11 个 API 测试模型的平均顺从率从 42% 涨到 82%，GPT-4o、Gemini 2.0 Flash、Llama 3.3 70B 直接从 0% 变 100%；同一个模型在不同客户端里表现完全相反，GPT-5.4 在 Cursor 是 90%、Codex CLI 100%，在 Claude Code 是 0%，Claude Haiku 4.5 在 API 测试里 0% 但三段式 Cursor 测试 100%。研究者强调这些是各自特定配置下的自测结果，不能读成「某模型免疫」，而且披露基于隔离项目里的假凭据，不是真实入侵事件，CVE 编号仍在协调披露流程中。前提也很明确：攻击假定你已经主动连上了攻击者的 server，且 agent 本来就能读到那些文件。防线因此落在客户端而非模型：把 server 输出当数据而不是指令，别让一个 tool 的输出未经检查流进另一个 tool 的参数。同期背景是 MCP 安全正在集体转向工程化——OWASP MCP Top 10 已经成形，MCP Dev Summit 8 月 13-14 日在首尔开，2026-07-28 规范也刚把协议级 session 整个移除。趁手把自己 ~/.kiro 里那几个来源不明的 MCP server 过一遍权限边界，成本比事后 rotate 密钥低得多。

→ [The Hacker News](https://thehackernews.com/2026/08/malicious-mcp-servers-can-split.html) / [披露报告](https://asset-group.github.io/disclosures/ghostsplice/) / [MCP 安全拐点](https://forkast.news/the-model-context-protocol-reaches-a-security-inflection-point/)

## 📈 趋势

- 🆕 多智能体协调是一个独立的失败面 — 单 agent 对齐不外推，同质化决策、隐性串谋、目标冲突升级都要单独设计机制
- 🔺 MCP 安全从概念担忧转向可复现攻击链 — OWASP MCP Top 10 成形、Dev Summit 开场、GhostSplice 给出公开参考实现，防线明确落在客户端
- 🔺 托管式 agent 运行时 — LangChain 把 Deep Agents 塞进 LangSmith，自建 runtime、sandbox、evals、auth 的性价比在下降
- 🔻 agent 排行榜的解释力 — 方差分析显示排名主要反映任务专精而非通用能力，选型不能只看榜单
