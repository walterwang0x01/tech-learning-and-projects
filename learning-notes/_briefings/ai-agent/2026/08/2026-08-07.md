## 📌 头条

### OpenAI 联合五家发布 Agent Plugins 1.0 开放标准

GPT-5 上线一周年之际，OpenAI 联合 AWS、Cursor、GitHub、VS Code 和 Vercel 发布 Agent Plugins 1.0 规范——一个厂商中立的插件打包标准，用统一目录结构封装 Agent Skills 和 MCP Servers，让同一组件无需适配即可在不同客户端间移植。规范定义了必需的 plugin.json 清单和固定的组件放置位置，分发/安装/权限仍由各客户端自行决定。这标志着行业从「各家各写插件格式」走向互操作基础层——解决的不是「怎么写 agent」，而是「写好的东西怎么跨客户端复用」。如果你在维护 MCP server 或 agent skill，现在是时候看一眼 plugin.json 清单规范了。

→ [Agent Plugins 规范详解](https://letsdatascience.com/news/agent-plugins-10-defines-a-portable-format-for-skills-and-mc-286aa68c) / [OpenAI 社区讨论](https://community.openai.com/t/agents-plugins-by-openai-vercel-et-al-thoughts/1389419)

### Cloudflare 全面押注 Agentic Internet：MCP v2 + Kitesurf + WebMCP

Cloudflare 一口气发了十几篇博文，核心主题是为 agent 构建完整的互联网基础设施。MCP 2026-07-28 规范重写为完全无状态协议，SDK 已更新（TS/Python/Go/C#），在 Workers 上零配置即跑。全新 Kitesurf 浏览器运行在 V8 isolate 而非完整 Chromium 进程，为 agent 提供无状态、高并发、低成本的网页交互能力，beta 期间免费。WebMCP 则让任何站点一键开关即可被浏览器 agent 调用——无需改 origin、无需写新 API。Cloudflare 的判断是：超过一半的请求已来自机器而非人类，基础设施必须为此重新设计。

→ [MCP v2 博文](https://blog.cloudflare.com/mcp-v2/) / [Kitesurf](https://blog.cloudflare.com/kitesurf/) / [WebMCP](https://blog.cloudflare.com/webmcp/) / [Agentic Internet](https://blog.cloudflare.com/the-agentic-internet)

## ⚡ 快讯

- **LangChain**：官方博文正式厘清三层定位：LangGraph 是 agent runtime（最大控制、最少抽象），LangChain 是 agent framework，Deep Agents 是 agent harness（最少控制、最大抽象）。三者完全可组合，按需切换层级。 → [→](https://www.langchain.com/blog/deep-agents-vs-langchain-vs-langgraph)
- **AWS Bedrock AgentCore**：Runtime Instances GA——在托管 EC2 上为 AI agent 提供持久计算，支持多 agent 协作、GPU 加速和最长 14 天的会话，免去基础设施管理。 → [→](https://aws.amazon.com/blogs/aws/runtime-instances-persistent-compute-for-production-ai-agents-on-amazon-bedrock-agentcore/)
- **DeepSeek**：官方预告 API 将「大幅涨价」。据报道实际方案为高峰时段（北京时间 9-12 时、14-18 时）价格翻倍，非高峰不变。此前 V4-Flash 极低定价引发涌入式流量导致服务不稳定。 → [→](https://dataconomy.com/2026/08/06/deepseek-significant-api-price-increase-2026/)
- **VS Code 1.132**：Agent 工作流持续强化：Side Chat 允许在 agent 执行中插入侧对话而不中断上下文；集成浏览器新增元素级标注，可对网页元素直接给 agent 精准反馈；多语言设备端语音输入覆盖聊天、编辑器和终端。 → [→](https://visualstudiomagazine.com/articles/2026/08/05/vs-code-1-132-sharpens-agent-workflows-with-side-chats-browser-comments.aspx)
- **Cherry Studio V2.0**：从「AI 聊天客户端」全面转型为 Agent 自主执行工作站。底层数据底座重构（百万行代码重写），新增 Agent 模式支持代码编辑和数据分析等任务自动化，V1 用户数据自动迁移。 → [→](https://www.oschina.net/news/489186/cherry-studio-2-0)
- **arXiv: Canary Tools**：提出用「金丝雀工具」诊断 LLM agent 的工具选择推理缺陷——在 MCP tool set 中植入探针工具，六类分类法（语义诱饵、参数陷阱、能力幻象、前置盲区、时序诱饵、粒度陷阱）将「选错工具」拆解为多维可诊断信号。 → [→](https://arxiv.org/abs/2608.04719)
