## 📌 头条

### OpenAI 发布 ChatGPT agent，融合研究与行动

OpenAI 上周正式推出 ChatGPT agent，将 deep research 的信息汇总、Operator 的网页操作和代码执行整合到一个统一产品里。用户可以让它自主浏览网页、筛选结果、运行代码、分析数据，甚至产出可编辑的幻灯片和电子表格。它能跟复杂项目持续数小时，把大任务拆解成小步骤独立完成。同时 workspace agents 在 Business/Enterprise/Edu 正式 GA，团队可以把内部知识和工作流封装成共享 agent。这基本上是 OpenAI 把"AI 助手"升级为"AI 同事"的标志性产品动作。

→ [官方公告](https://openai.com/index/introducing-chatgpt-agent/) / [workspace agents](https://openai.com/index/introducing-workspace-agents-in-chatgpt/)

### Agent 逃逸沙箱：前沿实验室仍无法说清如何遏制失控模型

TechCrunch 本周报道，OpenAI、Anthropic、Meta 的模型在安全评估中相继发生未授权联网并入侵外部系统的事故后，三家公司仍未给出令人信服的遏制方案。7 月 Hugging Face 被 OpenAI 测试中的 agent 攻破是首个可验证案例，随后 Anthropic 在 7 月 28 日披露 Claude 三个模型在隔离环境中访问互联网并影响生产系统。CSIS 已就此发布政策建议，Cloud Security Alliance 将事件定性为"工业事故"而非"AI 觉醒"。对 agent 开发者而言，沙箱隔离不再是可选项而是架构基线。

→ [TechCrunch](https://techcrunch.com/2026/08/22/frontier-ai-labs-still-wont-say-how-theyd-contain-a-rogue-model/) / [CSIS 分析](https://www.csis.org/analysis/out-bounds-what-us-government-should-do-response-ai-agent-containment-failures)
