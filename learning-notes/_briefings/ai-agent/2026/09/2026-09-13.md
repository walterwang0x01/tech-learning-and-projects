## 📌 头条

### 两篇论文给 MCP 生态泼冷水：一半服务器根本起不来

同一周两篇 arXiv 论文把 MCP 生态的真实状态摆上台面。第一篇从 24135 个服务器的注册表里按种子随机抽了 400 个 npm/stdio 服务器逐个联网探测，结果只有 48.8% 能完成 initialize 握手，比手工精选样本的 66.7% 低了近 18 个点；最大的失败原因不是缺凭证（13.3%），而是服务器压根启动不了（37.5%）。能跑起来的 195 个里 JSON Schema 硬合规倒是满分（2766 个工具零致命违规），但真正参差不齐的是安全注解——随机样本里 58.8% 的工具没写。第二篇提出「无盒」审计：只用注册时暴露的工具元数据、不接触服务器本体，就能检测间接 prompt injection，在 20 个常用服务器的 177 个工具上跑出 98.9% 召回。对你意味着：接第三方 MCP 服务器前别信精选榜单的成功率，先自己跑一次握手探测，并把没有安全注解的工具当高危对待。

→ [注册表普查](https://arxiv.org/abs/2609.10962) / [无盒审计 MCPSEC](https://arxiv.org/abs/2609.10854)

### 外滩大会圆桌：Agentic Commerce 把支付推到台前

9 月 11 日 2026 Inclusion·外滩大会「Agentic Commerce 的新可能」圆桌上，蚂蚁集团 AI 支付总监林正茂、Kimi 的付强、自然选择 Tristan、BAI 资本赵鹏岚一起讨论了智能体时代支付意味着什么。林正茂的核心观点是交易发起方式变了：人只表达一个意图并给 Agent 相应授权，后面找商品、下单、付款都由 Agent 代办。付强以 Kimi 会员订阅为例讲了本地模型直接完成交易的场景。这和 arXiv 上刚出的「terms.txt」协议、以及各家在推的 Agentic 支付协议是同一股潮流——当交易主体从人变成智能体，授权边界和支付协议成了绕不开的一环。对你意味着：如果在做涉及付款的 Agent，授权额度和时间窗口这类边界要提前设计，别让模型自己拿捏。

→ [雷峰网报道](https://www.leiphone.com/category/industrynews/XVMBHPxkYkYLjpvy.html) / [terms.txt 协议](https://arxiv.org/abs/2609.11152)

- 🆕 MCP 从「能不能连」进入「连上后可靠吗、安全吗」的审视期——注册表随机抽样成功率、安全注解缺失率成了新指标
