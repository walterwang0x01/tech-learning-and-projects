## 📌 头条

### Claude Fable 5.1 发布，agent 长任务成本大幅下降

Anthropic 发布 Fable 5.1 和 Mythos 5.1，主打的是价格而不是跑分。据 The Verge，Fable 5.1 性能强于上一代 Fable 5，但典型场景便宜约 25%、复杂 agentic 任务最多便宜 45%。开源中国点出了这背后最实在的一个数字：每百万 token 的缓存读取价格从 1 美元砍到 0.25 美元，降幅 75%——标准输入/输出价（每百万 10 美元和 50 美元）没动，Anthropic 只动了缓存读取这一项。对 agent 开发者的意义很直接：跑长任务时反复读取的上下文缓存正是成本大头，这一刀砍在了刀刃上。官方称这一版还回应了客户对价格、数据保留和过度安全拦截的抱怨。如果你在用 Claude 跑多轮 agent，值得重新算一遍长上下文的账单。

→ [The Verge](https://www.theverge.com/ai-artificial-intelligence/987830/anthropic-claude-fable-mythos-5-1) / [开源中国：缓存读取价砍 75%](https://www.oschina.net/news/502267/claude-fable-and-mythos-5-1)

### Manus 宣布恢复独立运营

9 月 1 日，Manus 官方在 X 宣布「恢复独立运营」，配文称进入「由同样创新精神驱动的新篇章」。官方措辞克制，创始团队 @Red_Xiao_、@hidecloud、@peakji 将继续领导公司。这条推文十小时浏览量 42.8 万，评论区一条高赞写道「最好的篇章由创始人书写，而不是收购方」——外界普遍把这理解为 Manus 从此前的被收购关系中回归自主，但官方公告本身并未展开细节，具体的股权与业务安排还需等后续披露。作为去年最受关注的通用 agent 产品之一，Manus 的走向对整个 agent 应用赛道有风向意义。

→ [开源中国](https://www.oschina.net/news/502250/manus-resumes-independent-operations)

## ⚡ 快讯

- **DeepSeek 多模态**：DeepSeek 在 Hugging Face 上线 V4-Flash-Vision-Exp（MIT License），V4 家族首款实验性多模态模型，305B 参数，基于 V4-Flash-0731 底座接入视觉编码器和 Aligner。官方强调它重新定义了「多模态」的用法（并非传统的看图说话），具体边界要读技术细节。 → [开源中国](https://www.oschina.net/news/502240/deepseek-v4-flash-vision-exp)
- **Qwen3.8-27B**：阿里 Qwen3.8-27B 登上 Hugging Face 热门榜第一，开始与顶级闭源模型正面较量。雷峰网本地实测指出性能很强，但「过度思考」和 Agent 场景适配仍是短板——想拿它做 agent 的可先看实测再决定。 → [雷峰网评测](https://www.leiphone.com/category/yanxishe/LyUNV8iNxl2VuE3X.html)
- **OpenClaw 2.0**：OpenClaw 发布 2.0，发布博客标题就叫《OpenClaw 2.0, Accidentally》——原计划只做「简化安装 + 浏览器端重建」，清理工作一路蔓延到配得上一个大版本号。累计 933 个贡献者、16,000+ PR。 → [开源中国](https://www.oschina.net/news/502255/openclaw-2-accidentally)
- **Hugging Face kernels**：Hugging Face 推出 @huggingface/kernels，提供 200+ 个 WebGPU kernel，面向浏览器/本地端的 AI 推理——本地跑模型的工具链又厚了一层。 → [HF Blog](https://huggingface.co/blog/webgpu-kernels)
- **Anthropic 企业安全**：Anthropic 宣布与企业客户共同开发「Enterprise Frontier Safeguards」，面向前沿模型的企业级安全防护——做 agent 安全/合规的团队可关注其框架方向（官方公告细节有限）。 → [Anthropic News](https://www.anthropic.com/news/enterprise-frontier-safeguards)
- **Microduck 开源机器人**：Hugging Face 与 Pollen Robotics 发布 Microduck：25cm、不到 800g 的鸭子机器人，15 个舵机 + 50Hz 控制循环驱动神经网络策略，能走能蹲、摔倒自己爬起，售价 399 美元，已在北美/欧洲/英国开放预订。 → [开源中国](https://www.oschina.net/news/502235/hugging-face-pollen-robotics-microduck)
- **ZSvirt 命题**：上海开源大赛公布 ZSvirt 命题：面向「智算云」环境下 AI 应用/Agent 的跨层故障诊断，覆盖主机、虚拟机、网络、存储、GPU/vGPU、告警等基础设施视角——对做 AIOps/可观测的开发者是个练手场景。 → [开源中国](https://www.oschina.net/news/502247)

## 📦 项目 & 论文

| 项目 | 描述 | 链接 |

| DynamicMCPBench | 面向 live MCP server 的 agent 评测框架，不是固定数据集——可在自己的 MCP server 上按自己的任务跑，用「trace + effect 打分」替代脆弱的最终答案/固定工具列表比对（对做 MCP 的人很实用） | [→](https://arxiv.org/abs/2607.20531) |

| ShardMemo | agentic 记忆检索的「先定范围再路由」：把访问权限（哪些记忆可被读）与相关性检索分开处理，避免在检索后才过滤而浪费探测预算 | [→](https://arxiv.org/abs/2601.21545) |

## 📈 趋势

- 🔺 agent 成本战打到缓存层——Fable 5.1 只砍缓存读取价（75%）不动标准价，说明厂商已经意识到长任务反复读上下文才是 agent 真正的成本大头
- 🆕 MCP 评测与 agent 失败诊断成研究热点——DynamicMCPBench、AgentRx 等把关注点从「答对没有」转向「过程可观测、失败可定位」
- 🔺 开源多模态密集发布——DeepSeek V4-Flash-Vision、Qwen3.8-27B 接连上线，国产开源模型持续冲榜，但 Agent 场景适配仍被点名待补
