### Cloudflare：自动化流量已在 5 月超过真人

Cloudflare 在成立 16 周年的年度创始人信里给了一组硬数字：原本预测自动化流量要到 2027 下半年才会超过真人访问，结果被 AI agent 和爬虫提前拉到了 2026 年 5 月，官方口径是自动化请求约占六成。信里进一步推演，照当前趋势五年内自动化流量可能达到真人的 1000 倍。对做 agent 的人这意味着两件事：你的服务此后面对的调用方越来越多是别的 agent 而非浏览器，鉴权、限流、机器人识别的默认假设要跟着改；Cloudflare 同时在推按爬取付费的机制，如果你的 agent 要抓别人内容，规则正在收紧。

→ [创始人信](https://blog.cloudflare.com/cloudflares-2026-annual-founders-letter) / [Fortune 报道](https://fortune.com/2026/09/18/cloudflare-ceo-matthew-prince-ai-bots-human-web-traffic-pay/)

### Vercel CEO 把浏览器里的 agent 走 ACP+MCP 接出去

Guillermo Rauch 把他的极简浏览器 Mini 从 Electron+Bun 重写成 Rust+Swift，用 cef crate 内嵌最新 Chromium。真正值得留意的是架构：浏览器里的 agent 不塞进 app，而是通过 ACP（Agent Client Protocol）跟本地 fx CLI 通信，fx 再经一个 MCP server 反过来操控浏览器。这是一个把 agent 运行时和宿主应用解耦的具体样例——agent 逻辑留在独立 CLI 进程里，宿主只暴露一个 MCP 工具面，靠协议边界隔离，而不是把模型调用和业务代码焊在一起。如果你在做 LangGraph/MCP 方向的集成，这个 ACP↔CLI↔MCP 的三段式接法值得抄一下思路。

→ [Rauch 原推](https://x.com/rauchg/status/2104428800134013205) / [PiunikaWeb 解读](https://piunikaweb.com/2026/09/28/vercel-ceo-rebuilds-his-minimalist-browser-with-rust-swift-and-cef/)

## ⚡ 快讯

- **MCP 工具发现**：Cartograph 提出联邦式 MCP 代理，把 agent 可见的工具发现从 O(n) 遍历整个 catalog 降到 O(k) 渐进披露，还给能力卡加了运营方签名的 Ed25519 背书——目录一大就爆 context 的老问题有了工程解法 → [arXiv](https://arxiv.org/abs/2609.30293)
- **MCP × 数据空间**：另一篇用 MCP 做「概率性语言模型」和「策略驱动数据基础设施」之间的架构中介层，落成一个叫 Eunomia Agent 的实现，思路是让治理策略成为 agent 调工具时的准入约束 → [arXiv](https://arxiv.org/abs/2609.30341)
- **Skill 供应链安全**：「Skill Cascading Attacks」把矛头对准 skill 生态：单个 skill 看着无害，多个组合起来却能级联造成危害——正好击中当前 agent 到处 load 第三方 skill/插件 的开放攻击面，值得给自己的 skill 加载路径过一遍 → [arXiv](https://arxiv.org/abs/2609.30383)
- **Coding agent 成本**：一篇分析 Claude Code 和 Mini-SWE-Agent 在 SWE-bench Verified 上 1200 条轨迹，归纳出三类烧钱行为：重复检索、生成相似脚本、反复重跑测试——如果你在为 coding agent 付 token 账单，这三条是可量化的优化点 → [arXiv](https://arxiv.org/abs/2609.30725)
- **Agent 执行控制**：「LLM Parkinsonism」给了个非临床比喻描述一种常见毛病：agent 在原目标已满足后还继续动作，产出低价值的反复精修和自造复杂度的修补，作者提出一个带不确定性感知的全局执行控制架构来刹车 → [arXiv](https://arxiv.org/abs/2609.30662)
- **Harness 多目标优化**：MoMHa 把「模型外面那层 Python harness（拼 prompt、路由调用、解析输出）」当成一等设计对象，在准确率、安全、token 三个目标间做多目标优化——提醒一句：一个不拒绝不安全请求、或多烧一个数量级 token 的 harness 不算好 harness → [arXiv](https://arxiv.org/abs/2609.30967)

## 📈 趋势

- 🔺 MCP 从「能连工具」转向「连太多工具怎么办」——工具发现的可扩展性和签名背书成新焦点（Cartograph / Eunomia）
- 🆕 Skill/插件生态的供应链安全首次被系统性攻击面对待，单点无害、组合有害的级联风险浮出水面
- 🔺 Agent 的「省钱」和「知道何时停」成显学：从 coding agent 成本剖析到执行控制架构，都在治「干得多不等于干得好」
