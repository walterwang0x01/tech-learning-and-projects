## 📌 头条

### Anthropic 发 Fable 5.1：缓存读价砍 75%，长跑 Agent 直接省钱

9 月 1 日 Anthropic 发布 Claude Fable 5.1 和 Mythos 5.1（同一底模、不同安全策略，Mythos 仅面向可信访问计划）。真正的重点不是分数，而是账单：base 输入/输出仍是 $10 / $50 每百万 token 不变，唯独把缓存读价从 $1 砍到 $0.25（降 75%）。官方口径是典型负载省约 25%、重度 agentic（缓存命中多）最多省约 45%——第三方实测有分歧，Cognition 测到 54%、Artificial Analysis 在 max effort 下反而算出单任务更贵。对你意味着：如果你在跑 LangGraph/Claude Code 这类长会话、多轮工具调用的 agent，切 5.1 基本无脑省钱；另外切换 reasoning effort 不再打断 prompt cache，低 effort 跑简单任务更划算。

→ [官方公告](https://www.anthropic.com/claude-fable-and-mythos-5-1) / [InfoQ 解读](https://www.infoq.cn/article/K8OwgoWM1gHNi2i4yLkU)

### OpenAI Astra 越过「Critical」网络安全线，引发安全担忧

OpenAI 披露即将发布的 Astra 是首个跨过其 Preparedness Framework 最高级「Critical」网络能力门槛的模型：内部测试中它能自主发现未知漏洞并写出 exploit，无需人类一步步引导。OpenAI 称会限制其最强网络工具的访问、只给可信伙伴早期权限，并强调 Astra 拒绝 91.5% 的网络类越狱尝试（前代 GPT-5.6 Sol 仅 59%）。但研究者对 The Verge 警告这「可能是迄今 AI 安全领域最糟的进展」。对你意味着：一个能独立找 0day 的模型上线在即，如果你的系统给 agent 开了写权限或对外网络访问，现在正是收紧授权边界、加执行审计的时候。

→ [OpenAI 官方](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/) / [Wired](https://www.wired.com/story/openai-astra-first-ai-model-with-critical-cyber-abilities) / [The Verge（安全担忧）](https://www.theverge.com/ai-artificial-intelligence/988334/openai-astra-ai-monitoring-safety)
