## 📌 头条

### AWS 上线 CloudWatch Omni：跨框架的 Agent 可观测性

AWS 昨天正式 GA 了 CloudWatch Omni，专门给 Agent 工作负载做 trace、评测和实验。它不绑自家框架——官方明确列出支持 LangChain、LangGraph、CrewAI、OpenAI SDK、Strands、Vercel AI SDK，Python 和 TypeScript 都行，埋点走 OpenInference 和 ADOT 开放标准，Agent 跑在 Lambda / ECS / EKS 甚至别家云上都能接。它把每一步 trace（LLM 调用、工具调用、推理步骤）铺成一条分层时间线，内置 17 个评测器（连贯性、忠实度、路由正确性等），还能把两条 trace 并排 diff 来定位「改了个 prompt 就变差、但监控指标一切正常」这种没错误码的回归。落地面有两个：VS Code 和 Kiro 的 IDE 插件（免费，本地即可用，不必连 AWS），以及一个脱离控制台的独立 Web 端给运维看全局。如果你在用 LangGraph 或 CrewAI 又苦于 Agent 行为不可观测，这是个可以直接装插件试的现成方案。

→ [原文](https://aws.amazon.com/blogs/aws/introducing-amazon-cloudwatch-omni-ai-powered-observability-for-generative-ai-and-agentic-workloads) / [VS Code 插件](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.amazon-cloudwatch-omni)

### GitHub 用 Copilot 把自己的运行时重写成 Rust

GitHub 披露：支撑 Copilot CLI / App / SDK / VS Code / Code Review 的公共 Agent 运行时，已从 TypeScript（Node.js + V8）整体迁到 80 万行以上的生产级 Rust，绝大部分代码由 AI agent 写成，跨 128 个合入 main 的 PR 增量上线，而不是最后一次性切换。成本约 12 万美元 token 费 + 一名工程师三周。性能提升有具体数字：某个特定 workload 从每秒 7.55 个生命周期提到 120 个（15.9 倍），内存从 1383MB 降到 126MB——注意这是单一 benchmark 口径，不是全局倍率。最值得记的是官方给的诚实结论（Stephen Toub）：AI 写 Rust「能编译不等于正确」，迁移中冒出几十个回归，需求校验和质量把关仍是人不能让渡的责任。想复用这套「让 agent 迭代式改代码」的路子，得先备好回归测试兜底。

→ [The Register（含性能数字）](https://www.theregister.com/devops/2026/09/19/microsoft-agentically-ports-copilot-runtime-to-rust-for-120k/) / [The New Stack（对比 Anthropic）](https://thenewstack.io/github-copilot-anthropic-rust-migration/)

## ⚡ 快讯

- **OpenAI GPT-6 Sol / Luna**：OpenAI 推出 GPT-6 家族的两个廉价版，训练方法对齐旗舰 Astra，但能力刻意钉在 Astra 之下、价格腰斩（Sol 输入 $4 降到 $2），主打专业工作、事实性、编程和 computer use 的降本落地。 → [报道](https://www.oschina.net/news/502683/openai-gpt-6-sol-and-luna)
- **Anthropic Claude Opus 5.5**：5.5 家族首发，多数任务持平 Fable 5.1 但运营成本比 Opus 5 低约 40%，编程尤强；发布前走完了 METR 等外部评测加内部自动化行为审计。融资/跑分类数字以官方口径为准。 → [报道](https://www.oschina.net/news/502685/anthropic-claude-opus-5-5)
- **Rabbit OS3**：Rabbit 推出不依赖 R1 硬件的独立 Agent：号称云端运行、本地跨 Windows/Mac/Linux 操作的「agentic operating system」，把此前捆死在设备上的能力解耦成纯软件。 → [The Verge](https://www.theverge.com/ai-artificial-intelligence/999094/rabbit-ai-agent-os3)
- **Vercel Jev（System One Model）**：TypeSafe 开源的 Jev 放弃字符串生成，直接输出类型安全的概率化决策，专治软件里的分类/路由/打分；Guillermo Rauch 宣布现可通过 AI Gateway 走 HTTP 调用。适合替代「让 LLM 生成 JSON 再解析」的脆弱路由层。 → [介绍](https://www.oschina.net/news/502660) / [Rauch](https://x.com/rauchg/status/2102205684544852121)
- **给 Agent 接数据库**：开源中国一篇实操：直连或裸暴露数据库 MCP 的 demo 好跑，进生产就炸——模型看不懂缩写枚举、多表联查写错、生产账密暴露客户端、一条无 WHERE 的 SQL 就越权。要点是把凭据和权限收在服务端，别让模型直接握写权。 → [原文](https://www.oschina.net/news/502677)
- **用 Agent 迭代把 Rust 越改越快**：minimaxir 实测：不手写优化，而是反复让 agent「把这段代码改得更快」，靠 benchmark 反馈驱动迭代逼出高性能 Rust，HN 96 分讨论。是上面 GitHub 案例的个人版方法论佐证。 → [文章](https://minimaxir.com/2026/09/agentic-iteration)

## 📈 趋势

- 🆕 Agent 可观测性走向产品化——AWS CloudWatch Omni 把 trace + 评测 + 实验做成跨框架标配，不再是自己糊 OpenTelemetry。
- 🔺 「让 agent 迭代式改代码」从 demo 走进生产——GitHub 80 万行 Rust 迁移和 minimaxir 的 Rust 提速都印证这条路，但都强调回归测试兜底、编译通过≠正确。
- 🔺 模型降价 + 能力分层成主线——GPT-6 Sol/Luna 与 Claude Opus 5.5 都在「持平上代能力、成本砍三到四成」上做文章。
- 🆕 企业级 MCP 安全成研究热点——零信任授权、跨组织信任外部性、工具接口粒度基准同日多篇上 arXiv。
