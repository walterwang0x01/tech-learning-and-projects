## 📌 头条

### NVIDIA 拟 129 亿美元收购 Hugging Face，开源生态震动

8 月 28 日传出英伟达拟以 129 亿美元收购 Hugging Face 的消息（数字来自开源中国转述，官方尚未见正式确认，以下按传闻处理）。开源圈两天内持续发酵：天际资本创始人张倩与开源中国 CEO 徐勇做了约两小时直播对谈，把焦点放在「被收购是不是开源公司的宿命」这个母题上。对做 agent 的人来说，Hugging Face 是模型托管、Transformers 库和 Inference 端点的事实标准入口，一旦归入英伟达，模型分发与硬件栈的绑定关系会更紧——值得留意后续对开源许可与免费额度的影响。连带一提，Hugging Face 早先收购的法国 Pollen Robotics 也随之进入英伟达版图。

→ [开源中国对谈复盘](https://www.oschina.net/news/502227) / [Pollen 开源机器人](https://www.oschina.net/news/502221/pollen-robotics-microduck)

### OpenAI 曝「GPT-6」灰测 demo，且 ChatGPT 突破 2500 万活跃

量子位报道 GPT-6 的灰度测试 demo 在社交平台刷屏，传本周四发布（发布时间来自媒体转述，未见官方公告，谨慎对待）。同一时间 OpenAI 的 Thibault Sottiaux 在 X 上确认 ChatGPT 达到 2500 万活跃用户，并宣布为所有 ChatGPT Work 和 Codex 付费订阅重置用量额度；他补充 Codex 的「20X」指的是每周用量上限、Pro 计划不再有 5 小时限制。对重度用 Codex 写代码的人这是实打实的额度松绑，可以趁窗口把积压的大改跑一批。

→ [量子位报道](https://www.qbitai.com/2026/08/481893.html) / [Sottiaux 原推](https://x.com/thsottiaux/status/2094252447271366730)
