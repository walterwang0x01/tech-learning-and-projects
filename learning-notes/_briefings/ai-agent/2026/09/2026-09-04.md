## 📌 头条

### OpenAI 发布 GPT-6 Astra，主打「电脑操作」能力

OpenAI 于 9 月 3 日正式发布 GPT-6 Astra，定位为其最强模型，重点押注 computer use——像人一样操作电脑：填表格、跑表格软件、跨网页导航。官方给出的 benchmark 里，Astra 在 ARC-AGI-3 拿到 98.6%（上一代 GPT-5.6 Sol 仅 7.8%、Anthropic Claude Opus 5 为 30%），ExploitBench 拿到 100%。这些分数全部来自 OpenAI 自己发布的评测，尚无第三方独立复现，先当方向性信号看。因为触发了内部安全阈值，Astra 先通过一个名为 Daybreak 的门控计划向网络安全防御者和企业账号灰度，普通消费者账号「未来几天」开放。对做 agent 的人来说，值得关注的是它把「电脑操作」从演示阶段推向可用阶段——等 API 开放后可以拿自己的 computer-use 任务跑个对照，看是否真比现有 Claude computer use 强。

→ [Fortune](https://fortune.com/2026/09/03/openai-debuts-gpt-6-astra-computer-use-greg-brockman-says-start-of-agi/) / [Wired](https://www.wired.com/story/openai-says-gpt-6-can-use-a-computer-better-than-a-human/) / [量子位](https://www.qbitai.com/2026/09/483898.html)

### LangChain 把 MCP 收进核心，支持 elicitation 与无状态协议

LangChain 更新了 MCP 集成，跟进了 2026-07-28 的 MCP 无状态协议规范。两个对 agent 开发直接有用的变化：一是 elicitation（服务端调用中途要用户补充输入）现在被映射成 LangGraph 的 interrupt()，人回答后 run 从断点续跑；二是工具列表可缓存，不必每次运行都重新拉取整个工具目录。同时 MultiServerMCPClient 默认变成无状态——每次工具调用新建一个 ClientSession、执行完就清理。MCP 支持现在直接进了 langchain.mcp 命名空间，取代独立的 langchain-mcp-adapters 包。如果你在用 LangGraph + MCP，值得升级后把人机交互环节改走 interrupt() 而不是自己造轮子。

→ [LangChain 博客](https://www.langchain.com/blog/mcp-in-langchain-stateless-protocol-elicitation-and-more) / [LangChain changelog](https://docs.langchain.com/oss/python/releases/changelog)
