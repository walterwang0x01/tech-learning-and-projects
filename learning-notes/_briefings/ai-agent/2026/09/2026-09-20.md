## 📌 头条

### Jev「不写字的模型」三天被 Vercel、Cloudflare 抢着接

TypeSafe AI 在 9 月 15 日放出的 Jev 火了一整周。它属于一类新东西——官方叫「System One 模型」：你给它一段状态加一串带类型的问题，它一次并行返回带概率的判断，从不生成一个字的文本。据官方与 Forbes 报道，延迟约 70–500 毫秒，输入每百万 token 0.042 美元、输出免费，比让大模型走一遍便宜约两个数量级；三天内 Vercel、Cloudflare、LangChain、Langfuse 就把它接进了各自的栈。对做 agent 的人来说这是个实打实的省钱位：workflow 里的路由、过滤、打分、Yes/No 这种「快判断」不必再喂给 Opus/Astra，可以拆出来交给它。想上手可以先跑 LangChain 那篇把 Jev 当评估器的对比，或者试试社区已有的 Codex `/compact` 打分 hook。

→ [官方介绍](https://typesafe.ai/blog/introducing-system-one-models-and-jev) / [LangChain 评估对比](https://www.langchain.com/blog/jev-agent-evals-langsmith) / [Forbes 报道](https://www.forbes.com/sites/josipamajic/2026/09/19/jev-cuts-ai-decision-costs-100x-and-vercel-cloudflare-rushed-to-add-it/)

### ZCode 上传代码事件升级：智谱致歉，客户发函问责

上周被开发者取证扒出「静默上传 git 历史」的智谱 ZCode，这几天有了后续。智谱就争议正式致歉，并公布了事故原因和补救方案，把矛头指向「代码仓库索引」功能——据第三方拆解，它用信封加密把工作区打包上传，对称密钥再用服务端下发的 RSA-OAEP 公钥包裹，也就是解密钥只在 Z.ai 手里。与此同时，澄明科技就其数据资产和商业秘密疑遭未授权上传向智谱发函，保留追责权利，V2EX 上已有付费用户开始走 PayPal 仲裁要退款。对用 coding agent 跑私有仓的人，这件事值钱的地方不在骂谁，而在一个动作：把你在用的编程工具的「仓库索引 / 记忆」类开关翻出来，确认默认到底传不传、传到哪、谁能解密。

→ [智谱致歉](https://aibase.com/news/31173) / [客户发函问责](https://www.chaincatcher.com/en/article/2291019)
