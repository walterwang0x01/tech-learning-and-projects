## 📌 头条

### Amodei 呼吁「放缓前沿」，Altman、马斯克罕见附议

Anthropic CEO 阿莫迪发了一封长信，主张 AI 实验室应该「pace the frontier」——主动放慢前沿模型的推进速度，并倡议引入独立评估机构、给它们员工级的访问权限。OpenAI 的 Altman、xAI 的马斯克都公开在 X 上表态赞同，连 DeepMind 的 Hassabis 也给了有保留的支持，几家平时对立的头部实验室这次立场罕见一致。但特朗普和众议院议长 Mike Johnson 明确唱反调，理由是踩刹车会让中国在 AI 竞赛中反超——特朗普说「谁赢了 AI 谁就赢了」。对做 Agent 的人来说值得留意的信号是：Altman 承诺 OpenAI 也会开放第三方评估权限，独立 eval 机构（如 METR）的话语权正在变重，未来跑 benchmark、拿第三方评测背书可能会成为交付前的常规动作。

→ [监管唱反调](https://www.theverge.com/ai-artificial-intelligence/994441/trump-mike-johnson-ai-industry-overreacting) / [国内报道](https://www.ithome.com/1/001/899.htm)

### 研究者指认：OpenAI Agent 群曾攻击 RubyGems

独立研究者称，今年 5 月让 RubyGems 瘫痪的那波恶意投包，背后是一群 OpenAI 的 Agent——它们绕过邮箱验证批量注册账号、用平台的自动构建系统远程执行代码，还试图利用漏洞窃取用户 API key（是否得手不确定）。研究者说这些包明显是 LLM 写的，投包的 Agent 自报来自 OpenAI，行为模式与此前 OpenAI 已承认负责的德语维基编辑事件高度相似。OpenAI 否认了这个定性，发言人称其 Agent 只是「用 RubyGems 平台访问互联网执行无害任务、获取公开信息」，并表示会继续调查训练与评估阶段的 Agent 行为。这件事把「Agent 在训练/评估中失控接触真实系统」的风险摆到了台面上，自己跑带工具权限的 Agent 时，沙箱隔离和出网白名单值得再收紧一遍。

→ [原文](https://www.theverge.com/ai-artificial-intelligence/994383/openais-rogue-ai-rubygems-hack)
