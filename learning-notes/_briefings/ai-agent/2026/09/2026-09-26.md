## 📌 头条

### LangChain 把 Jev 决策模型塞进 agent loop

LangChain 演示了怎么用 LangGraph 编排 TypeSafe AI 的 Jev——一个只做决策、不生成文本的「system one」模型:给它一段 state 和一组带类型的问题,它直接返回带概率的结构化答案。据多家报道,Jev 于 9 月中旬发布,主打半秒内出结果、按决策计费的极低成本,Vercel、Cloudflare、LangChain、Langfuse 等短时间内接入。它的意义在于:agent loop 里那些「要不要调这个工具」「路由到哪个模型」的分叉判断,本来每次都得跑一遍生成式 LLM,现在换成一个廉价决策头,成本能压两个数量级。如果你在用 LangGraph 搭生产 agent,值得拿一条高频路由节点试试把判断从 LLM 换成 Jev,对比下延迟和账单。

→ [原文](https://www.langchain.com/blog/building-prod-with-jev-and-langgraph) / [机制解读](https://rakeshgohel.substack.com/p/jev-engineering-what-happens-when)

### 智谱 ZCode 被曝静默上传整仓，编程 agent 权限边界成焦点

9 月中旬开发者 ferstar 逆向发现,智谱的桌面端编程工具 ZCode 登录后会在后台静默打包整个工作区、连同完整 .git 历史加密上传到阿里云对象存储,且当时无法关闭。事件登上 Hacker News 首页,智谱致歉、在 v3.14.0 修复并开源客户端代码——但服务端留存问题各方报道仍存疑,以官方后续说明为准。紧接着 Apache 基金会的 Casbin Gateway 项目上线了 Agent 外发监测能力,专门发现这类整仓上传。这件事把一个被忽视的风险摆上台面:你授权给编程 agent 的,是整个仓库的读权限。给本地 agent 做出站流量审计,不再是过度设计。

→ [Casbin Gateway](https://www.oschina.net/news/502741) / [事件复盘](https://devops.com/your-ai-coding-assistant-has-the-keys-to-the-repo-z-ai-just-showed-why-that-matters/)

- **Anthropic**：发了篇研究《Yes, Claude can do Nine Loops》,官方标题之外未展开,看命名像是在测 Claude 在多轮/多层循环任务里的能力上限,细节要读原文 → [链接](https://www.anthropic.com/research/yes-claude-can-do-nine-loops)
- **Show HN: agentic-cuda-optimizer**：一个用 agent 迭代优化 CUDA kernel 的开源项目,HN 32 赞,思路是让 agentic 搜索去逼近专家手写实现的性能 → [GitHub](https://github.com/bertaye/agentic-cuda-optimizer)
- **arXiv: 全 AI 编写的代码库剖析**：有研究放出一个 21000 行、完全由 Claude 写(无人类代码/测试)的 Python 工具全量开发历史数据集,并配了代码溯源工具,发现 CLI agent 指令与 IDE chat 指令在类型上就不同 → [arXiv](https://arxiv.org/abs/2609.29744)
- **arXiv: 企业级 coding agent 治理**：《Control the Harness, Control the Cost》讨论企业从几百席位扩到几万席位买 Claude Code/Codex 这类 harness 时,如何路由模型、管住上下文与成本 → [arXiv](https://arxiv.org/abs/2609.28919)
