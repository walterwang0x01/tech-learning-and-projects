## 📌 头条

### GPT-6 Astra 发布：主打自主操作电脑

OpenAI 9 月 3 日发布 GPT-6 Astra，官方定位是长周期、多步骤的 agentic 工作。模型页给的硬指标：上下文窗口约 105 万 token（1,050,000）、最大输出 128K、只吃文本和图片、支持 low 到 max 五档推理强度，API 名 gpt-6-astra，定价 $10/百万输入 + $50/百万输出。多家报道称它在「能不能真的操作一台电脑」这类 computer-use 基准上首次越过人类基线，ARC-AGI-3 报了 99.9。值得留一个心眼：OpenAI 同时给它标了 Critical 级网络安全风险并上了额外管控，这类满分附近的跑分是官方自报口径，真实落地能力要自己跑 benchmark 验。对你意味着：如果你在做需要长链路工具调用的 agent，这是继 Claude Opus 之后又一个可拿来压测的候选，先用你自己的任务集跑一轮再决定换不换。

→ [OpenAI 官方(Sam Altman)](https://x.com/sama/status/2095973658867171733) / [InfoQ 报道](https://www.infoq.cn/article/mKGb7ZiPRlAiFDZCWK0v) / [MarkTechPost](https://www.marktechpost.com/2026/09/03/openai-releases-gpt-6-astra-a-1-05m-context-computer-use-model-gated-behind-a-critical-cyber-threshold/)

### NVIDIA 129 亿美元收购 Hugging Face

NVIDIA 确认以约 129.3 亿美元收购 Hugging Face，黄仁勋亲自在官方博客宣布，并承诺平台保持开放、用 HF 不强制用 NVIDIA 算力。收购看中的不是营收（有报道称年化约 1.5 亿美元、溢价约 86 倍），而是它托管的三百万个模型和上千万开发者社区。对做 agent 的人来说，模型分发、数据集、推理托管这条链路的中枢换了东家，值得关注后续在私有部署授权和推理定价上会不会有变化——短期没影响，但这是你依赖的开源基础设施，盯着点。

→ [NVIDIA 官方博客](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/) / [开源中国报道](https://www.oschina.net/news/502310/nvidia-to-acquire-hugging-face)

## ⚡ 快讯

- **WebMCP**：Vercel CEO Guillermo Rauch 力挺 WebMCP——让网页直接把自己的 agent 工具暴露给 agent，不用再单独找和配一个 MCP server，比如 Next.js 调试页能把调试工具直接给到正在测试的那个 tab。这是把 MCP 从「独立服务端」往「页面自带能力」推的方向，值得关注它会不会成标准。 → [Rauch 原帖](https://x.com/rauchg/status/2096065378598441431)
- **阿里千问办公**：阿里企业级通用 Agent 产品千问办公上线满一个月用户数破 3000 万、企业用户占比过半，一个月迭代 120 个版本。此前它开源了上下文基础设施 MyContext（把异构工作数据转成 agent 可调用的上下文），开源数周 GitHub 超 3000 star。 → [量子位](https://www.qbitai.com/2026/09/484155.html)
- **Meta Muse Spark 1.3**：Meta 新模型把上下文拉到 100 万 token，明确定位长周期多步骤 agentic workflow，多模态感知+工具调用一阶成功率比前代高。定价分两档、差价超 10 倍（有报道称达 21 倍），核心卖点是用数据换折扣。 → [开源中国](https://www.oschina.net/news/502295/meta-ai-muse-spark-1-3)
- **三大 AI 服务同时宕机**：9 月 3 日 ChatGPT、Claude、Grok 在几乎重叠的时间窗集体故障，Claude 部分中断持续约 3 小时 6 分。三家官方口径不一（OpenAI 称路由错误），未有统一解释。对重度依赖单一 API 的 agent 是一次提醒：加降级和多供应商兜底。 → [开源中国](https://www.oschina.net/news/502312/chatgpt-grok-claude-outage-down)
- **Anthropic 形式化费马大定理**：Anthropic 研究团队公布用 AI 辅助形式化费马大定理的工作，属于把 agent 推向严谨数学证明这类高确定性任务的探索方向。 → [Anthropic Research](https://www.anthropic.com/research/formalizing-fermats-last-theorem)
- **Open Flow 开源**：OOMOL Lab 开源 Open Flow，一个面向 AI Agent 的工作流自动化平台，带可视化 Workbench、命令行和自托管运行时，可配合 Claude Code、Codex 等智能体直接创建节点、编排并运行。 → [开源中国](https://www.oschina.net/news/502325)

**Interface-Induced Trajectory Censoring** — agent 评测报的 tool-call 成功率可能被 serving 层「审查」：同一模型只换 serving adapter，同一批用例分数能从 0.00 跳到 0.96，说明 benchmark 数字对推理框架适配层极其敏感，别只看分数。→ [arXiv](https://arxiv.org/abs/2609.03966)

**Fresh Memory, Stale Plans (PlanFence)** — 分布式多 agent 团队会「读到最新事实却按旧计划行动」：规划者依据 r3 出的动作，另一 agent 已提交 r4，执行者拿到 r4 却没替换计划。论文提出依赖域校验来拦这类陈旧计划执行，对做多 agent 编排的直接相关。→ [arXiv](https://arxiv.org/abs/2609.03340)

**CASCADE** — 对 MCP 系统分层本地防御做组件消融和语料审计，指出各家 prompt injection 防御的报告数字口径不一、不可比，是 MCP 安全选型时的清醒剂。→ [arXiv](https://arxiv.org/abs/2604.17125)

## 📈 趋势

- 🆕 computer-use 成为旗舰模型的核心卖点——GPT-6 Astra、Meta Muse Spark 都把「自主操作电脑/长周期 agentic workflow」写进定位。
- 🔺 百万级上下文成新基线：Astra 1.05M、Muse Spark 1M，长链路 agent 的上下文瓶颈在被硬件+定价策略往后推。
- 🔺 MCP 生态两条线并进——WebMCP 把工具能力下沉到网页本身，安全侧(CASCADE)开始质疑各家防御口径的可比性。
- 🆕 多 agent 编排的真问题从『能不能协作』转向『陈旧计划/评测口径』这类可靠性细节(PlanFence、Trajectory Censoring)。
