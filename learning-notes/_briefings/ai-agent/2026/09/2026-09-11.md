## 📌 头条

### Cognition 发布 SWE-2 编码 Agent，价格砍到零头

Cognition 昨天发布了 SWE-2，一个从 Kimi K3（2.8T 参数）经 RL 后训练而来的编码 Agent 模型。它在 FrontierCode 1.1 Main 上拿到 50.0%，距 Fable 5.1 的 50.9% 不到一个百分点，比 GPT-5.6 Sol（47.5%）高 2.5 分。真正的看点是价格——据称比 Fable 5.1 便宜一大截（原文提到约便宜 64%，具体折扣以官方口径为准）。对天天用编码 Agent 的人来说，这意味着接近第一梯队的能力可以用明显更低的单价跑，值得抓个真实仓库对着 Fable 跑一轮对比再决定切不切。

→ [原文](https://www.oschina.net/news/502413/cognition-swe-2)

### Meta 发布个人 Agent「Muse」，关掉 App 还替你干活

Meta 把 Muse 明确定位成 agent 而非聊天机器人或助手：核心规矩是「关掉 App 它还在跑」——你让它盯天气、下雨提醒，它会在你退出应用后继续执行。产品已上 App Store 和 Google Play，也能直接在 WhatsApp 里使唤。「退出后仍在后台替你完成长任务」是它区别于普通助手的地方，也是当前个人 agent 最难做稳的一环；具体的任务持久化机制和权限边界，官方公告没有展开，得看后续文档。想体验的话现在就能装来试它的定时/触发类任务。

→ [原文](https://www.oschina.net/news/502392/meta-ai-muse)
