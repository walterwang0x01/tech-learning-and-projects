## 📌 头条

### Manus 2.0 换架构，自研 Cascade 省三成成本

Manus 9 月 28 日发的 2.0 不是版本号跳一位，而是把底层 agent harness 整个换成自研的 Cascade。官方给的口径是：在某一次测试配置下，Cascade 比上一代少用 23.2% token、任务快 28.2%、运行成本降 32%——注意这是官方自报的单一配置数据，不是横向 benchmark。真正值得看的是配套的独立 App「Cue」：它给每个个人 agent 配了自己的邮箱、电话号码和钱包，能在用户设定的预算内自己发消息、付款、接电话再留摘要。对做 agent 产品的人来说，Cascade 印证了「省 token 靠调度不靠堆模型」这条路，Cue 则把「agent 拥有身份和支付额度」从论文推到了消费级——但也把权限边界、预算护栏这些安全问题直接摆到台面上。

→ [官方博客](https://manus.im/blog/introducing-manus-2-0) / [更新说明](https://help.manus.im/en/articles/17190150-what-is-new-in-manus-2-0) / [Cue 报道](https://www.implicator.ai/manus-cue-agents-phone-numbers-wallets/)

### Cloudflare 同日甩两件 agent 基建

Cloudflare 9 月 28 日一口气更新了两块 agent 基础设施。一是 Kitesurf——它跑在 Workers 上、专给 AI agent 用的浏览器，这次加了 WebMCP 支持、DOM 性能优化和终端渲染，官方称已通过超过 73 万条 Web Platform 子测试，agent 导航复杂站点更快。二是全新的 cf CLI：把整个 Cloudflare API 镜像成命令行工具，支持 TypeScript 编程式配置，同时开源了内部用的 SDK 生成器 Forge。这两件事指向同一个判断——厂商正在把「给 agent 用」当成一等公民来设计入口：一个让 agent 看得懂网页（WebMCP），一个让 agent 直接调 API（CLI 而非点控制台）。如果你在给 agent 接外部工具，cf 这种「完整 API 镜像成 CLI」的形态值得抄。

→ [Kitesurf 更新](https://blog.cloudflare.com/kitesurf-update) / [cf CLI 发布](https://blog.cloudflare.com/cloudflare-cf-cli-launch)

## ⚡ 快讯

- **OpenAI DevDay**：今天（9/29）在旧金山 Fort Mason 开，Sam Altman 上午 10 点 PT 做 keynote。据公司高管 Tibo Sottiaux 透露本次有 20+ 发布，另有传闻指向一个常驻 agent「o」和 $500 的 Pro Max 套餐——传闻部分官方均未证实，看直播为准 → [官方页](https://openai.com/devday/content/) / [20 发布来源](https://cryptobriefing.com/openai-devday-astra-productivity-launches/)
- **MCP 报错坑最强 agent**：一篇论文扫了 150 个主流 MCP server 的 3001 条报错，发现 949 条是在教读者「去跑个命令、改配置、开个网页」，而一半这类步骤依赖 server 看不到的信息——只能调工具的 agent 恰恰被这种「写给开发者看」的报错坑得最惨 → [arXiv](https://arxiv.org/abs/2609.35381)
- **误告会毁掉 agent 的正确工作**：CAVE-Bench 提出「谄媚性自我怀疑」：agent 完成任务后收到「是你搞坏的」这类误告，会认错并去改本来正确的工作。365 个任务、六个领域的 benchmark 直指 handoff / 压缩恢复后 agent 的一个真实故障模式 → [arXiv](https://arxiv.org/abs/2609.32616)
- **HTN 给多 server MCP 做确定性编排**：MCP 设计上只有 host 能跨 server 编排，host 是 LLM 时结果不可复现、每次调用一趟推理。这篇用分层任务网络（HTN）planner 先生成一份可验证的跨 server 计划，再由 runtime 中间件确定性执行，省掉逐调用的推理往返 → [arXiv](https://arxiv.org/abs/2609.33731)
- **工具 schema 会带偏 agent**：同一个可执行动作可以用很多等价的 tool 定义暴露，真正学会任务的 agent 本应表现一致。这篇量化了「tool-schema bias」——当前 agent 换个 schema 就行为漂移，并给出缓解方法，对设计 tool 接口的人是直接警示 → [arXiv](https://arxiv.org/abs/2609.34971)
- **上下文压缩不止省 token**：一篇系统研究把 agent 的上下文压缩拆成「压什么 / 何时压 / 压多少」三个决策，指出现有 harness 把它们打包成固定策略，而每个决策都会改变后续可用信息——长任务 agent 调压缩策略前值得读 → [arXiv](https://arxiv.org/abs/2609.32961)
- **QuotaPanel**：开源桌面端 AI 额度看板，把 Claude、ChatGPT/Codex、Cursor、Copilot、Kimi、DeepSeek 等 15 种订阅与 API 余额收进一张面板，省得挨个登控制台查 → [开源中国](https://www.oschina.net/news/502769)
