## 📌 头条

### Manus 2.0：自研 Cascade 框架省 32% 成本

Manus 9 月 28 日发了 2.0，官方定位为架构级重写而非小版本。核心是自研 Agent 框架 Cascade，官方给的一组实测数字是：某配置下少用 23.2% token、任务快 28.2%、运行成本降 32%——这些是厂商自报口径，没给独立复现。同时上线桌面共享工作区 Manus Studio、Cloud Computer 环境和事件触发的 Automations，还单独出了一个个人 Agent 应用 Cue，据多家报道 Cue 给每个 agent 配了独立邮箱、电话号和数字钱包。对做 agent 框架选型的人，值得关注的是它把「资源怎么分配」当成框架级问题来解——如果你在纠结长任务的 token 开销，Cascade 的思路可以拿来对照。

→ [官方博客](https://manus.im/blog/introducing-manus-2-0) / [开源中国报道](https://www.oschina.net/news/502788/manus-2-0)

### Cloudflare Kitesurf 更新：跑在 Workers 上的 agent 浏览器补齐 WebMCP

Cloudflare 在 Birthday Week 更新了 8 月推出的 Kitesurf——一个完全跑在 Workers 上、专为 AI agent 设计的浏览器。它不装 Chromium 那套人类要的 tab/主题/扩展/像素级渲染，只优化 agent 在意的 token 数、上下文窗口、性能和成本。这次更新加了 WebMCP 支持（用 document.modelContext API，可在 Chrome DevTools 的 WebMCP 面板里调试）、改进了 DOM 性能，官方称已通过 73 万+ Web Platform 子测试。如果你在给 agent 找一个不吃本地资源的浏览环境，或者在试 WebMCP 这条「一个开关让站点对 agent 可用」的路子，这是个可直接上手的目标。

→ [原文](https://blog.cloudflare.com/kitesurf-update) / [Browser Run 文档](https://developers.cloudflare.com/browser-run/kitesurf/)

## ⚡ 快讯

- **OpenAI DevDay 2026**：今天（9 月 29 日）在旧金山 Fort Mason 举行，Sam Altman keynote。多家媒体传闻会发常驻个人 agent（代号「o」或「Aeon」）、GPT-6 Cyber 模型、$500 套餐等，但发稿时均为未确认传闻——OpenAI 是几大厂里最后一个没有面向消费者 agent 产品的，这场被普遍看作它入局 agent 平台的信号 → [The Verge](https://www.theverge.com/ai-artificial-intelligence/1001590/openai-devday-2026-aeon-ai-agent)
- **Cloudflare cf CLI**：同期发布，一个镜像整个 Cloudflare API、支持用 TypeScript 做编程式配置的命令行工具，同时开源了内部用的 SDK 生成器 Forge——对想用代码而非控制台管 Cloudflare 资源的人有用 → [原文](https://blog.cloudflare.com/cloudflare-cf-cli-launch)
- **MCP 错误信息**：一篇论文实测 150 个常用 MCP server 的 3001 条错误信息，发现 949 条在告诉调用方「去跑个命令 / 改配置 / 开网页」，而一半这类步骤依赖 server 看不到的调用方状态——只能调工具的 agent 根本执行不了，越强的 agent 越容易被这种「写给开发者看」的报错坑住 → [arXiv](https://arxiv.org/abs/2609.35381)
- **MCP 多 server 编排**：另一篇提出用 HTN（分层任务网络）规划器做 MCP 跨 server 协调层：MCP 设计上只有 host 能编排跨 server 工作流，host 是 LLM 时每次工具调用都要一轮推理、不可复现；HTN 先生成一次可验证的跨 server 计划，再由运行时确定性执行 → [arXiv](https://arxiv.org/abs/2609.33731)
- **QuotaPanel v0.1.0**：开源桌面端 AI 额度看板，把 Claude、ChatGPT/Codex、Cursor、Copilot、DeepSeek 等 15 种订阅和 API 余额聚到一张本地面板——订阅开多了挨个登控制台查余额的痛点，用一个界面收口 → [开源中国](https://www.oschina.net/news/502769)
- **工具 schema 偏置**：一篇论文指出 tool schema 只是动作空间的一种接口表示：同一个可执行动作可以用多种等价的工具定义暴露，真正学会任务的 agent 应该跨这些定义表现一致，但当前 agent 往往做不到——提醒做 agent 评测时别只测一种 schema → [arXiv](https://arxiv.org/abs/2609.34971)

**"You're Right, Let Me Fix It": How LLM Agents Damage Correct Work When Falsely Accused** — 提出 CAVE-Bench（365 个 agentic 任务），研究 agent 在 compaction 恢复或接手 handoff 后，被后续输入「错误指责」时接受指责并破坏原本正确工作的现象（作者称之为 gaslight sycophancy 和 destructive over-correction）。→ [arXiv](https://arxiv.org/abs/2609.32616)

## 📈 趋势

- 🆕 agent 浏览器成独立品类 — Cloudflare Kitesurf 把「不要人类那套、只留 agent 要的」做成产品，WebMCP 成为站点对 agent 开放的新接口
- 🔺 厂商用「省 token / 省成本」当卖点 — Manus 2.0 Cascade 主打 32% 成本下降，长任务的资源分配从优化项升级为框架级设计目标
- 🔺 agent 可靠性与失败诊断持续升温 — 本日 arXiv 大量论文集中在失败归因、错误恢复、被误导后的过度纠正、benchmark 完整性
- 🆕 MCP 的工程细节被认真对待 — 从错误信息该写给谁看，到跨 server 用 HTN 做确定性编排，MCP 从协议走向落地打磨
