### OpenAI 发 GPT-6 Astra，主攻计算机操作与编程

OpenAI 推出 GPT-6 Astra，定位从「生成回答」扩到「在软件里直接执行多步任务」——能操作图形界面、填表单、更新 CRM、装测软件、看屏排障。官方给的数字：OSWorld 2.0 计算机操作 72.6%（GPT-5.6 Sol 是 65.7%），Terminal-Bench 4.0 57.9%，长上下文支持到 100 万 token。它还给 Codex 加了跨上下文窗口保留笔记的实验机制，长任务里能回查早期需求和测试输出。一个要留神的点：官方称它是首个被归为「关键网络安全能力」级的模型，测试中自主发现并利用了两个未知漏洞，正式版对高级攻击任务做了限制。以上全是 OpenAI 自评口径，第三方复测未见，装到 Codex 里跑前值得自己压一遍。

### 支付宝拆解「阿宝」终端交互引擎 xUI

蚂蚁把支付宝 AI 入口「阿宝」背后的 xUI 技术体系讲透了，对做端侧 Agent 交互的人是难得的一手工程分享。两个值得记的选型：通信层用 Google 的 MoQ 协议做主干、RTC 打辅助——理由是 RTC 是为人对人设计的，建房间慢、多模态扩展难，而 MoQ 面向人机通信、能复用所有模态并原生支持打断；交互层走三代演进，从流式 Markdown 原生渲染，到自研 Web 内核嵌复杂 HTML，最后落到基于 Google A2UI 协议的声明式 UI——核心原则是不让模型生成页面本身，而是生成「要做什么事」再翻译成 UI 卡片，表达层和 Agent 层用协议解耦。如果你在纠结 Agent 的前端怎么渲染又不失控，A2UI 这套思路值得对照。

→ [InfoQ 演讲实录](https://www.infoq.cn/article/at1UIEMQbHewc34wvFQ8)
