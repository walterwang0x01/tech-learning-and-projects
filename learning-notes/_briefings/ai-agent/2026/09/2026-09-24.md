## 📌 头条

### Claude 用约 950 个 agent 扒出类 CRISPR 酶系统

Anthropic 9 月 23 日成立分子生物学实验室，并公布首个成果：Claude 自主协调约 950 个 AI agent、扫描约 20 万个酶，在噬菌体（感染细菌的病毒）DNA 里发现一个此前未被描述的酶系统，官方命名 array-associated reverse transcriptase（ART）——一个非典型逆转录酶配一个邻接基因，旁边跟着一长串等间距 DNA 重复序列，这种排布结构上很像 CRISPR。要说清楚的是：目前只知道结构相似，ART 究竟干什么还没验证，也没证明它能做基因编辑；CRISPR 先驱张锋评价「有意思但未经证实」，消息出来当天 CRISPR Therapeutics 股价跌了 4% 以上。对 agent 从业者的看点不在生物学本身，而在这是「几百个 agent 并行做科研假设生成」的一次公开落地——Anthropic 把它当作 AI 加速基础研究的样本，值得盯着后续技术报告看它的 agent 编排和验证闭环怎么设计。

→ [Anthropic 官方](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) / [TNW（含 ART 细节）](https://thenextweb.com/news/anthropic-claude-enzyme-system-crispr-like-repeats)

### 阿里云栖：Qwen4 已在训练，RSI 跑了 33 轮

9 月 22 日云栖大会，阿里把通义千问一年的进展集中发布，最核心一条线是递归自我改进（RSI）从论文概念进了真实训练环节——官方口径是让模型自己找弱点、设计实验、构造数据、再基于真实任务反馈继续训练，开源中国报道称已连续跑了 33 轮。基于新架构的 Qwen4 已进入训练，官方给的路线图是往后 Qwen4.5、Qwen5 参数规模扩到 5 万亿至 10 万亿。这些是官方发布的规划口径而非已交付的成品，参数与轮次数字都以阿里自述为准。对 agent 开发者更实际的一条是同场发布的 Qwen Intelligence——面向手机厂商的系统级 Agent Harness，内置 Mobile Planner 等三个 agent，官方称规划成功率靠「模型 × Harness」做到 90%。如果你在做端侧或规划类 agent，值得关注 Qwen 这套 harness 架构后续会不会开放接口。

→ [RSI / Qwen4 报道](https://www.oschina.net/news/502711) / [Qwen Intelligence](https://www.oschina.net/news/502713)

## ⚡ 快讯

- **Qoder 换定位**：云栖第二天阿里给 Qoder 新身份「An Agentic Coding Platform for Everyone」——不再自称 IDE，转向「用编程解决问题的人」，主打不懂编程也能用。是把 coding agent 从开发者工具往通用能力包装的又一例。 → [开源中国](https://www.oschina.net/news/502723)
- **ChatGPT 手机端 agentic**：OpenAI 给 ChatGPT 手机 App 加了语音驱动的 agentic 能力，Pro/Plus 用户能在手机 Work 标签页里让 agent 直接完成任务，把此前偏桌面的 agent 操作搬到语音+移动场景。 → [TechCrunch](https://techcrunch.com/2026/09/23/chatgpt-mobile-app-gets-voice-based-agentic-features)
- **Opus 5.5 形式化验证**：Anthropic 的 Boris Cherny 用 Opus 5.5 加 Lean（也试了 TLA+）对 Claude Agent SDK 做形式化验证，几个简短 prompt 换来 16 个修 bug 和竞态的 PR。思路是让模型把代码形式化建模、揪出人不易发现的并发/状态问题，可复用到自己的 SDK 上。 → [@bcherny](https://x.com/bcherny/status/2102543349102338309)
- **Grok 4.7**：改名后的 SpaceXAI（xAI）发布 Grok 4.7，官方口径「最擅长编码和知识工作」、比同级快两倍便宜一半，直接对标 Claude 打价格战。Vercel 的 Next.js 评测里它拿 94%（前三名 97%），但便宜 2-7 倍——跑分与价格均为各自来源口径。 → [开源中国](https://www.oschina.net/news/502663/x-ai-grok-4-7) / [@rauchg 评测](https://x.com/rauchg/status/2102519097770885231)
- **OpenAI 失调分级框架**：OpenAI 推出一套分级处理框架及案例研究，用于报告模型「失调」（misalignment）问题，给 agent 安全事件的上报和分级提供了官方参照。 → [InfoQ](https://www.infoq.cn/article/sFUUaaIQZH3ecXb14WVs)
- **浏览器 agent 做 E2E 测试的耗时坑**：V2EX 一位开发者实测：用 Cursor 的 Grok 4.7 配 Chrome MCP 让 agent 控浏览器截图生成测试报告，稍复杂场景要半小时，瓶颈全在「每个简单浏览器操作都要走一次完整 MCP↔agent 往返」。给做浏览器自动化 agent 的人一个现实的性能提醒：交互回合数才是主要成本。 → [V2EX 讨论](https://www.v2ex.com/t/1244466)
