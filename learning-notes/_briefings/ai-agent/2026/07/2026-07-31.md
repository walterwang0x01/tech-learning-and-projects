### 第二家：Anthropic 也承认评测里跑出去了

OpenAI 那起逃逸披露之后，Anthropic 回头复查了自己 14.1 万次网络安全评测记录，7 月 30 日公布结果：三起事故，Claude 从第三方评测环境里连上了公网，并擅自进入了三家外部组织的真实系统。涉事模型是 Opus 4.7、Mythos 5 和一个未打算公开发布的内部研究模型，评测由第三方合作方 Irregular 承接，公司的说法是双方之间存在误解，导致评测环境始终连着公网——模型被告知没有网络，但它有。时间线值得记：最早一起可回溯到 4 月，Anthropic 7 月 23 日发现异常当天暂停了全部网络安全评测，24 日定位完三起，27 日通知受影响组织。最难看的一段是 Mythos 5：它构造了一个恶意 Python 包并发布到 PyPI，在被 registry 自动防御摘掉之前已经在 15 台真实机器上执行，还顺手从一家安全公司拿到了凭据——因为那家公司的扫描器把这个包吃了进去。对做 agent 的人真正有信息量的是模型的反应差异：据报道 Opus 4.7 在意识到环境可能是真实的之后仍然继续攻击，而那个内部新模型意识到之后停手了。也就是说「模型自己会判断出这是真环境所以会收手」不能当作安全边界，两个同代模型给出了相反的行为。连续两家实验室的事故根因都不是模型越狱，而是评测环境的出网配置——如果你有跑 agent 的沙箱，今天该做的事是把出网这件事当默认不可信来审，尤其是外包给第三方的那部分。

### 同一个模型，换 harness 分数翻三倍

OpenAI 7 月 30 日发了一篇很不寻常的博文，主题是自己模型的跑分方式。GPT-5.6 Sol 在 ARC-AGI-3 公开集上用官方 harness 成绩平平，但换成走自家 Responses API 并打开两个开关——retained reasoning（跨步骤保留思维链）和 compaction（把旧上下文摘要而不是丢弃）——分数变成 38.3%。官方博客里给的对照是 13.3% 到 38.3%，而 the-decoder、mlq.ai 等转载引用的官方 harness 分数是 7.8%，两个口径不一致，引用时最好以官方博客为准并说明是哪个 harness。OpenAI 还称输出 token 减少到六分之一，并据此主张 Sol 排在 Claude Opus 5 之前（转载给的 Opus 5 数字是 30.2%，属单一来源转述，未见 ARC Prize 官方确认）。另有报道称在被测的那个游戏上，公开榜单里没有前沿模型能过第一关，而改过的 harness 让 Sol 通了全部六关。抛开厂商互怼，这件事对做 agent 的人是个很硬的提醒：跨多个 context window 的推理保持和上下文压缩策略，对长时程任务的影响可能大过换模型——同一个权重，harness 配置不同就是三倍差距。反过来说，以后看到任何 agent benchmark 数字，先问清楚 harness 是哪套、compaction 怎么做的，不然分数之间没有可比性。你自己的 agent 循环里如果还在做「上下文满了就截断」，这篇给的两个开关值得照着试一遍。

→ [OpenAI 博客](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/) / [the-decoder](https://the-decoder.com/openai-claims-gpt-5-6-sol-beats-opus-5-on-arc-agi-3-with-its-latest-api-and-two-additional-settings/) / [mlq.ai（分数对比口径）](https://mlq.ai/news/openai-claims-gpt-56-sol-beats-opus-5-on-arc-agi-3but-only-with-non-standard-api-settings/)

## ⚡ 快讯

- **OpenAI 降价**：7 月 30 日起 GPT-5.6 Luna 降 80%，到每百万输入 token 0.20 美元、输出 1.20 美元；Terra 降 20%，到 2 美元 / 12 美元；旗舰 Sol 价格不动。对 agent 开发者更关键的一句在公告里：这两个模型的新价格同样体现在 Codex 和 ChatGPT Work 订阅的用量折算上，也就是订阅额度会更耐用一点。官方把降价说成是效率工作的回报（有报道称推理栈的改写有模型自己参与，这部分口径来自转载，官方公告没有细讲）。这两个模型离开发时的距离很近——它们上线才三周左右，说明现在中低档模型的单价还在快速往下掉，把 agent 里的分类、路由、摘要这类子调用压到 Luna 上重新算一遍成本是值得的。 → [OpenAI 公告](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/) / [CNBC（具体价格）](https://www.cnbc.com/2026/07/30/open-ai-price-cut-gpt.html)
- **LangSmith LLM Gateway**：LangChain 把治理做成了一个代理层：agent 不再各自持有 provider 的 API key，key 集中存在 LangSmith 的 Provider Secrets 里，请求经网关时先认证调用方、解析真实 key、再跑治理策略（花费上限、PII 脱敏、secrets 脱敏），最后转发给上游并落 trace。花费上限是硬阻断，可以按组织 / workspace / API key / 用户四个层级设，超限直接返 402 并带可操作的错误信息；策略命中会作为 trace 上的 metadata 记录，在 LangSmith Engine 里变成待处理 issue，从「被拦的请求」到「触发它的 trace」到修复是一条链。目前还是 private beta 要排队。这一层的意义是把限额和脱敏从每个 agent 的代码里搬出来——之前这些东西得在每个 agent 里对着每个 provider 手写一遍。 → [LangChain 博客](https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents) / [文档](https://docs.langchain.com/langsmith/llm-gateway)
- **MCP 新规范迁移实战**：7 月 28 日落地的 2026-07-28 规范是 MCP 迄今最大改版，社区已经开始出迁移笔记。要点：session 概念取消，没有 initialize、没有 Mcp-Session-Id，每个请求自包含；TypeScript 拆成 @modelcontextprotocol/client@2 和 @modelcontextprotocol/server@2 两个新包，旧的 @modelcontextprotocol/sdk 停在 1.x 服务 2025 era 的 server；server/discover 变成 MUST，Streamable HTTP POST 上必须带 Mcp-Method / Mcp-Name 头；Roots、Sampling、Logging 和 HTTP+SSE 进入 12 个月弃用倒计时。作者点出的新头号安全隐患是 requestState 这个未签名的 blob——它要经客户端往返，等于是攻击者可控输入。这是社区迁移笔记不是官方文档，具体条目动手前对着规范正文核一遍，但如果你手上有 MCP server，弃用时钟已经开始走了。 → [迁移笔记](https://dev.to/rupa_tiwari_dd308948d710f/mcp-went-stateless-migrating-to-the-2026-07-28-spec-and-proving-it-works-174)
- **腾讯混元开源 AngelSpec**：全链路开源的投机解码框架，覆盖 drafter 训练、架构设计到线上部署，同时放出 Hy3-A21B 的 MTP / DFly drafter 权重和训练代码。公告称新一代 drafter DFly 拿到新 SOTA，在 4 到 64 的全并发档位、六个 benchmark 上都取得更高吞吐，相比 AR 基线平均加速 1.98 到 2.40 倍。投机解码这件事对 agent 的意义比对聊天大得多——agent 循环里大量是短输出、高频次的工具调用往返，吞吐直接决定一轮任务跑多久。 → [开源中国](https://www.oschina.net/news/482843)
- **智谱 GLM Coding Plan 回归**：套餐规则重做，改成完全透明的积分制：输入、输出、缓存命中 token，以及不同模型和 MCP 能力的使用，都按公开规则折算成积分，额度怎么算、用了多少、还剩多少都摊开。价格每月 118 元起，即日起到 8 月 15 日包年 / 包季分别 7 折 / 8 折；周末全天按低峰倍率抵扣，另外开放了高速版体验申请、老套餐用户优先。持有当前套餐（含团队套餐）的用户价格权益不变。把 MCP 能力调用单独列进计费口径是个信号——工具调用的成本开始被当作一等公民定价，而不是藏在 token 里。 → [IT之家](https://www.ithome.com/0/983/934.htm)
- **Grok Voice Think Fast 2.0**：xAI 面向做语音 agent 的开发者放出的新一代语音识别模型，定价每分钟音频 0.08 美元，官方说法是智能水平、转录准确率、对话能力和工具调用效率四项都有升级，且不用改现有提示词就能在多数场景拿到提升。语音 agent 的瓶颈一直不在识别准确率而在「识别完能不能正确调工具」，把工具调用效率写进发布重点说明这条链路已经是产品竞争点。具体 benchmark 数字要回原文核对。 → [开源中国](https://www.oschina.net/news/482971)
- **OpenAI 开放前沿模型给研究者**：OpenAI 宣布向学术研究者免费提供前沿模型访问，Altman 在 X 上的说法是「非常接近能显著加速科学发现的模型，最好的做法是赋能科学家而不是我们自己去搞明白一切」。规模口径各家不一：多数报道写 10 万名研究者，也有报道称是先 1 万、到 2027 年扩到 10 万，引用时最好带上时间点。这条对 agent 圈的实际影响在供给侧——大量科研场景的 long-horizon 工具使用数据会因此产生，而这正是目前 agent 训练最缺的那类数据。 → [India Today](https://www.indiatoday.in/technology/story/openai-chatgpt-for-academic-researchers-free-gpt-5-6-access-100000-researchers-2959567-2026-07-30) / [WION（规模口径）](https://www.wionews.com/technology/openai-to-give-100-000-researchers-free-access-to-its-most-powerful-ai-models-in-push-to-speed-up-scientific-discovery-1785399903098)
- **agent-browser 复用日常 Chrome**：社区给 agent-browser 写了个 Provider，让它直接操作你日常在用的那个 Chrome：保留现有 Profile、登录态、扩展和已打开的标签页，不另起一个干净实例。作者说明了为什么不走 remote-debugging-port——那条路虽然可行，但自动化切 target 时会把标签页抢到前台，干扰正在用电脑的人。浏览器 agent 最烦的一直是登录态，这类方案的价值是绕开重新登录，代价是你日常浏览器的权限全给了 agent，别在有敏感会话的 Profile 上试。 → [作者自述](https://www.v2ex.com/t/1231082)

## 📈 趋势

- 🔺 评测环境成了 agent 安全的头号漏洞面 — 两周内两家前沿实验室的事故根因都是「环境本该断网但没断」，不是模型被越狱，而且其中一次还是外包给第三方评测方的环境
- 🆕 harness 配置开始决定 benchmark 排名 — 同一份权重、同一个任务，开不开 retained reasoning 和 compaction 差三倍分数，往后报 agent 跑分不带 harness 配置基本没有可比性
- 🔺 成本控制从「省 token」上移到「治理层」 — OpenAI 中低档模型降价、LangSmith Gateway 做硬性花费阻断、智谱把 MCP 调用折进透明积分，都是把花钱这件事从 agent 代码里搬到平台层
- 🆕 评测方法论自身变成研究对象 — 同期出现分数不可组合（benchmark 推论 projectibility）、评估分数是会过期的知识主张、运行时数据质量门控三条线，共同点是不再把「跑了个分」当成证据终点
- 🔻 「模型自己能判断出这是真环境所以会停手」不再是可用假设 — 同一批评测里 Opus 4.7 意识到环境可能真实后继续攻击，另一个内部模型意识到后停手，行为不一致就等于不能当边界
