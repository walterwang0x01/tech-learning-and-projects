## 📌 头条

### MCP 新规范落地：协议层不再有 session

MCP 2026-07-28 正式发布，这是协议自诞生以来改动最大的一版：initialize / notifications/initialized 握手被整个移除，每个请求自己在 _meta 里带上 io.modelcontextprotocol/protocolVersion 和 io.modelcontextprotocol/clientCapabilities。配套变化包括 Multi Round-Trip Requests（交互式工具不再需要长连接会话）、基于 header 的路由、list 结果可缓存、授权收紧，以及正式的 extensions 框架。为什么重要：过去每个上线的 MCP 部署都得靠 sticky 负载均衡、共享 Redis session 存储、网关层读 body 才能把请求路由对，现在这些绕路可以拆掉，MCP 流量退回成普通 HTTP 流量。生态跟进很快，Claude 各产品当天开始灰度，官方 C# SDK 发了 v2.0，AWS AgentCore Gateway 也宣布已支持。如果你手上有自建 MCP server，先对着官方 changelog 过一遍握手和授权部分，握手移除属于破坏性变更，客户端和服务端要一起动。

→ [官方公告](https://blog.modelcontextprotocol.io/posts/2026-07-28/) / [changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog) / [Claude 侧支持](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude) / [HN 讨论](https://news.ycombinator.com/item?id=49088058)

### Claude 在密码学里挖出了人类两年没找到的洞

Anthropic Frontier Red Team 公布，用未发布的 Claude Mythos Preview 找到了两个此前未知的密码分析攻击。一个针对 HAWK——NIST 后量子签名竞赛里目前唯一还活着的格基候选，模型发现了一处此前没人利用过的对称性，把最小配置下恢复密钥的代价从 2^64 次运算压到 2^38；另一个把 7 轮 AES-128 的攻击相比 2013 年的人类记录加速了 200 到 800 倍。这不是实现层的 bug，是数学结构上的问题。对 Agent 工程的意义在成本这一侧：据 Decrypt 与 The Hacker News 报道，单个结果大约烧掉 10 万美元 API 用量，Anthropic 内部还投入了数百小时人工去验证 AES 那部分是不是真的。也就是说「模型能做出可验证的科研发现」和「这件事便宜、可规模化」目前还是两码事，验证环节仍然由人兜底。这些数字来自官方博客与二手报道，具体口径建议直接读原文。

→ [Anthropic 原文](https://www.anthropic.com/research/discovering-cryptographic-weaknesses) / [Decrypt 报道](https://decrypt.co/374600/claude-mythos-cracked-post-quantum-cryptography) / [The Hacker News](https://thehackernews.com/2026/07/claude-ai-just-cracked-post-quantum.html)

## 📈 趋势

- 🔺 MCP 正在往「普通 HTTP 服务」收敛 — 协议层去掉 session 后，网关、路由、授权这些基础设施位置的价值被放大，Runlayer 的官司就是这个位置开始值钱的信号
- 🆕 Coding agent 的 harness 工程独立成品类 — Better Harness、Agent Team Work Zone、plan mode 的实证评估都在做同一件事：不改模型，只改 agent 的执行脚手架和验证回路
- 🔺 Agent 安全的重心从 prompt 过滤转向权限与信息流控制 — 权限策略代数、去中心化细粒度访问控制、能力与许可分离的治理框架同一天集中冒出来，思路都是先把 agent 能做什么框死
- 🔻 按 token 单价算成本的口径在失效 — swyx 直言 $/input-output token 早已不是有效度量，该换成 $/task；Anthropic 密码学那单 10 万美元 API 加数百小时人工验证，也只能按任务算
