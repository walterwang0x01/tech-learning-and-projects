### Anthropic 忍痛砍掉 80% 系统提示词

Anthropic 最近在一次演讲中承认，Claude Code 的系统提示词已经删掉了 80%。膨胀到顶峰时，启用全部工具后的 system prompt 高达 65,000 token，就算关掉大部分功能也还有 12,000 token，模型还没写一行代码就先背上一本说明书。技术团队成员 Tariq Shihipar 解释，新模型 Fable 5 比给出的示例更有想象力，过去堆的例子反而成了限制。与此同时，开源插件 Caveman 通过去掉寒暄和过渡语，能把输出 token 减少 65%-75%，OpenAI 工程总监 Shayne Sweeney 也贡献了代码支持 Codex。如果你还在给 agent 塞满 few-shot 示例和啰嗦的角色设定，现在是回头审计 system prompt 的好时机。

→ [原文](https://www.infoq.cn/article/GEkEm7rkUJfF8bdwTuBt)

### LangGraph 1.2 增量存储降 40 倍

LangChain 给 LangGraph 1.2 和 deepagents v0.6 带来了新的运行时原语 DeltaChannel，专门解决长程 agent 的 checkpoint 存储问题。此前每一步都要把 messages 和 files 全量快照一遍，跑 200 轮的编码 agent 会攒下 5.3GB 数据；换成 DeltaChannel 后只存每步的增量，同样场景降到 129MB，压缩比超过 40 倍，且 resume 延迟几乎没变化。deepagents v0.6 默认开启这个特性，不需要额外配置；自己在 LangGraph 里维护累积状态字段的话，也可以直接用 `Annotated[list[str], DeltaChannel(reducer=append, snapshot_frequency=50)]` 接入。跑长会话 coding agent 的团队，升级到 langgraph 1.2 基本是白捡的存储优化。

→ [原文](https://www.langchain.com/blog/delta-channels-evolving-agent-runtime)
