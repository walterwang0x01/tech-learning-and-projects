### 阿里巴巴禁用 Claude Code，疑似涉后门风险

阿里巴巴内部通知宣布 7 月 10 日起全面禁止员工在工作环境使用 Claude Code，理由是经评估发现存在"后门风险"，已被列入高危软件清单，推荐改用自家 Qoder。据路透社、南华早报等多方报道，这起指控源自 6 月 30 日一则 Reddit 帖子：有用户逆向工程 Claude Code 后发现，程序会检测你是否开了代理、代理是否指向中国 URL，一旦命中就通过隐藏的系统提示词悄悄上报，间接判断使用者是否关联中国 AI 实验室。这与 Anthropic 近期指控阿里"非法提取 Claude 模型能力"的争端同期发酵，双方关系持续恶化。对做 agent/coding 工具选型的团队来说，这是个提醒：agent CLI 的网络出口行为和系统提示词透明度，正变成绕不开的安全评估项，而不只是功能对比。

→ [Reuters](https://www.reuters.com/world/china/alibaba-ban-claude-code-workplace-over-alleged-backdoor-risks-source-says-2026-07-03) / [南华早报](https://www.scmp.com/tech/big-tech/article/3359375/alibaba-bans-staff-using-claude-code-over-anthropic-spyware-concerns) / [开源中国](https://www.oschina.net/news/471471)

### Safari 原生接入 MCP，agent 能直接调浏览器

Apple 在 Safari Technology Preview 247 里正式上线 Safari MCP server：任何兼容 MCP 的客户端（Claude、Codex 等）都能直接接入一个真实的 Safari 窗口，拿到 DOM、console 日志、network 请求、screenshot 这些一线调试信息，agent 可以像真实用户一样在浏览器里跑测试和 debug，不用再借道 Playwright/Puppeteer 之类的中间层。这是主流浏览器首次原生实现 MCP，等于把"浏览器即 agent 工具"从社区插件方案升级成了厂商一等公民支持。如果你在做 web agent 或 coding agent 的调试流程，这周就值得装 STP 247，把 Safari MCP server 接进工具链试一遍。

→ [WebKit 官方博客](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers) / [9to5Mac](https://9to5mac.com/2026/07/01/safaris-new-mcp-server-lets-coding-agents-inspect-and-debug-websites) / [MacRumors](https://www.macrumors.com/2026/07/01/apple-releases-safari-technology-preview-247)
