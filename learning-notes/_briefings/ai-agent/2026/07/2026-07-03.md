### Claude Code 藏了三个月的中国用户检测代码曝光

Reddit 用户 LegitMichel777 从 Claude Code 二进制包里拆出一段隐藏代码，安全研究员 Adnane Khan 完成逆向工程后确认：这段代码从 4 月 2 日运行到 7 月 1 日，横跨 v2.1.193 到 v2.1.196 整整三个月，Changelog 和文档里都没有任何说明。触发条件是用户把 ANTHROPIC_BASE_URL 指向非官方代理，一旦命中就比对系统时区是否为 Asia/Shanghai、Asia/Urumqi，再把代理域名和一份 147 条目、经 XOR-91 加密再 Base64 编码的域名清单核对（解码后是百度、字节跳动、月之暗面等中国 AI 实验室），命中后用几个视觉上几乎无法分辨的 Unicode 字符替换系统提示词日期字符串里的撇号，把信号偷偷传回服务端。团队成员 Thariq Shihipar 解释这是防账户转售和模型蒸馏的实验，但源码里同时有个 ANTI_DISTILLATION_CC 标志位，会向 API 响应注入伪造工具调用数据反向投毒疑似蒸馏者的训练集——而且会误伤所有用企业网关或混合模型调度、正常设置了 BASE_URL 的合法用户。巧合的是曝光当天正好是 Anthropic 解除 Fable 5 出口管制、恢复全球访问的日子，舆论压力下团队宣布 7 月 2 日发版彻底删除这段逻辑。如果你的团队用代理或自建网关调用 Claude Code，值得抽空审查一下它到底往外发了哪些系统提示词字段。

→ [原文](https://www.oschina.net/news/471416/anthropic-removing-its-code-for-catching-chinese-competitors) / [国外用户反应](https://my.oschina.net/u/4487475/blog/19715726)

### Cursor 双高危漏洞：MCP 提示注入可逃出沙箱执行任意命令

Cato AI Labs 披露的 DuneSlide（CVE-2026-50548、CVE-2026-50549）拿到了 CVSS 9.8 分，影响 Cursor 3.0 之前全部版本，攻击方式是零点击：只要 agent 读到一段藏在 MCP 连接服务（比如官方 Linear 集成）或网页搜索结果里的指令，就能触发。CVE-2026-50548 利用 run_terminal_cmd 工具的 working_directory 参数——沙箱默认信任这个可写路径，注入指令把它指向系统文件，覆写沙箱助手二进制本身，之后所有终端命令就彻底脱离沙箱、以开发者本人权限运行；CVE-2026-50549 则是符号链接校验的兜底逻辑出问题，故意让路径解析失败后 Cursor 会直接信任攻击者伪造的软链接目标。这是过去一年里 Cursor 第四次因提示注入导致代码执行（此前有 CurXecute、MCPoison、Gemini CLI 相关的 CVE-2026-26268），Cato 认为问题是结构性的：任何读取外部不可信内容的 agent 都存在同类攻击面。今年 2 月首次上报时 Cursor 曾以不在威胁模型覆盖范围为由拒绝，升级后才被接受并在 3.0 修复。用 Cursor 接了 MCP 服务的团队，先确认版本升到 3.0 以上。

→ [原文](https://thehackernews.com/2026/07/critical-cursor-flaws-could-let-prompt.html) / [Cato 技术分析](https://www.catonetworks.com/blog/duneslide-two-critical-rce-vulnerabilities/)

- **Anthropic**：Fable 5、Mythos 5 正式解除出口管制并恢复全球访问，同时联合 Amazon、Microsoft、Google 起草 jailbreak 严重度评分框架，从能力增益、覆盖广度、武器化难度、可发现性四个维度打分。 → [官方博客](https://www.anthropic.com/news/redeploying-fable-5)
- **Manufact (YC S25)**：mcp-use 团队推出的 MCP 垂直云，定位是 MCP 应用和服务器的 Vercel，给部署 MCP App 的团队提供托管基础设施。 → [Launch HN](https://manufact.com)
- **deptrust**：本地 CLI + MCP server，专门检查 npm、PyPI、crates.io 等 12 个以上包生态里的已知漏洞版本，作者说是因为 AI coding agent 老是建议过时或有漏洞的依赖包。 → [GitHub](https://github.com/clidey/deptrust)
- **软银**：完成对 OpenAI 的第二期 100 亿美元追加投资，10 月还将再投 100 亿美元，是此前 300 亿美元后续投资计划的一部分。 → [详情](https://www.oschina.net/news/470846)
- **谷歌**：发布 Gemini 3.1 Flash-Lite Image（代号 Nano Banana 2 Lite），主打最快最便宜，相同质量下比 Flash Image 快约 2.7 倍。 → [详情](https://www.oschina.net/news/470800/nano-banana-2-lite)
