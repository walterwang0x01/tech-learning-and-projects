### Anthropic 3 亿美元收购 Stainless，把 OpenAI 和 Google 的 SDK 管线收编

Anthropic 周一官宣收购 Stainless，多家媒体确认成交价 3 亿美元以上。Stainless 干的是一件被低估的「脏活」：从一份 OpenAPI spec 自动生成各家厂商的官方 SDK、CLI 工具和 MCP server，OpenAI、Google Gemini、Meta Llama、Cloudflare 的官方 SDK 都跑在它的编译器上。Anthropic 在公告里把话挑明：前沿 AI 正从「答问题的模型」转向「干活的 agent」，而 agent 的能力天花板取决于它能触达多少系统——掌控 SDK 与 MCP 工具链的生成管线，等于卡住了整个生态接入「最后一公里」的咽喉。对 Walter 这种押注 LangGraph + MCP 的开发者，短期影响是 Anthropic 主导的 MCP server 生成质量会变得更稳，中期要警惕的是竞争对手未来不再容易拿到一致的 SDK 体验，多模型路由策略要把「SDK 是不是 Stainless 出的」当成新维度。

### LangChain 把流式 API 升级到 Agent Streams：从 token 流到带类型的事件投影

LangChain 同步发布博客和 Deep Agents v0.6，核心是用 `stream_events(..., version="v3")` 替代过去那套 token 级流式接口。新模型把流抽象成「带类型 + 按 agent 树位置打 tag」的事件，应用层订阅自己关心的投影：messages、tool_calls、values、subagents 各自一个独立迭代器，subagent 的 task 是 lazy 发现的，调到才打开内部流。配套是同一套 schema 从 Python runtime 一路打通到 React / Vue / Svelte / Angular SDK，远程 thread 和本地运行行为一致。对做 agent 前端的人来说这是真有用的工程升级：以前要在 stream_mode chunk 上手写分支判断 subagent 进度，现在可以直接 `stream.subagents` 拿独立 handle，配合 typed events 做精细 UI——值得这周抽 30 分钟把现有 agent UI 跑通新接口。

→ [LangChain 官方博客](https://www.langchain.com/blog/token-streams-to-agent-streams) / [Deep Agents v0.6 发布说明](https://www.langchain.com/blog/deep-agents-0-6) / [Python streaming 文档](https://docs.langchain.com/oss/python/langchain/streaming) / [JS Deep Agents streaming](https://docs.langchain.com/oss/javascript/deepagents/event-streaming)
