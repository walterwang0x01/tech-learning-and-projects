## 📌 头条

### LangChain Interrupt 大会密集发布：LangSmith 全面升级为 Agent 生产平台

LangChain 在旧金山 Interrupt 2026 大会（5/13-14）上一口气发布了 7 项重磅更新：Deep Agents v0.6 带来 code interpreter、streaming v3 和 delta channels（checkpoint 存储降低 100x）；LangSmith Engine 自动聚类生产故障并提出修复建议；SmithDB 作为专用分布式数据库将 agent 可观测性查询提速 12x；Context Hub 提供 agent 行为文件的版本化协作空间；LLM Gateway 内置 PII 脱敏和花费限额的运行时治理；Sandboxes GA 提供内核隔离 microVM；Managed Deep Agents 进入 private beta，开发者无需自建运行时即可部署长时 agent。这标志着 LangChain 从"框架"正式转型为端到端 agent 基础设施平台。

→ [Deep Agents v0.6](https://www.langchain.com/blog/deep-agents-0-6) / [Interrupt 大会](https://interrupt.langchain.com/)

### MCPShield：首个针对 MCP 工具调用流量的攻击检测框架

随着 MCP 成为 AI Agent 连接外部工具的事实标准，安全问题日益突出——OX Security 4 月披露的"设计缺陷"影响超 20 万服务器和 1.5 亿次下载。MCPShield 论文提出将每个 agent session 编码为图结构（tool call 为节点，顺序和数据流为边），结合 sentence-embedding 特征进行攻击检测。这是学术界首次系统性地为 MCP 流量建立监控框架，对正在部署 MCP 的团队有直接参考价值。

→ [论文](https://arxiv.org/abs/2605.11053) / [MCP 安全漏洞报道](https://www.techrepublic.com/article/news-mcp-ai-security-vulnerability-data-layer-governance/)
