### Google I/O 2026 把整条产品线压到 agent 上

Sundar Pichai 周二开场就把 Gemini 重新定位成「agentic Gemini era」。模型侧端出 Gemini 3.5 Flash，Google 自称是迄今编码与 agent 任务最强的版本，比对手前沿模型快 4 倍、调优后可达 12 倍，API 价 $1.50/M 输入 + $9/M 输出，明显低于 Pro 档；Google 同时甩出一组数字，最重度用 token 的客户从 Pro 切到 Flash 一年能省十亿美元级别。应用侧上线 Gemini Spark，24/7 运行的个人 agent，跑在 Gemini 基模 + Antigravity harness 之上，能写邮件、跨 Gmail/日历联动、监控信用卡账单的隐藏订阅扣费。开发者侧 Antigravity 升到 2.0（新桌面应用 + CLI + 自定义 workflow SDK），同步发布兼容 Claude Code 与 Codex 的 Android CLI，让 agent 直接命令行造 Android 应用。Gemini app 月活已破 9 亿。这周可以试试把日常 Pro 用量切一份到 3.5 Flash 跑同一组 agent，对账成本和质量。

### KPMG 把 Claude 装进 27.6 万员工的全部业务

Anthropic 周二宣布与 KPMG 缔结全球战略联盟，规模上是迄今最大的企业 agent 部署之一：覆盖 KPMG 在 138 个国家和地区的全部 276,000 名员工，把 Claude Cowork 与 Claude Managed Agents 直接嵌进 KPMG 内部 Digital Gateway 平台（Microsoft Azure 上）。第一批落地在税务和法务客户工作流，KPMG Tax 副主席给出的对比是：以前搭一个跟踪税法变化的 agent 要几周、要在多个工具与对话窗口之间反复切换，现在在 Digital Gateway 里几分钟搞定。同时 KPMG 被 Anthropic 指定为 PE（私募股权）领域的优先合作伙伴，将通过 KPMG Blaze（嵌入 Claude Code）帮投资组合公司做 IT 现代化。这是继上周 PwC 全球部署 Claude Code/Cowork 之后的第二个十万人量级落地，企业 agent 的「头部咨询所打头阵」格局基本成形——如果你做 to-B 的 agent 产品，下个季度的客户参考案例池被这两家先填满了。

→ [Anthropic 公告](https://www.anthropic.com/news/anthropic-kpmg) / [PwC 同期对比](https://www.anthropic.com/news/pwc-expanded-partnership)

## 📈 趋势

- 🔺 Agent 优化的轻量模型成主战场：Gemini 3.5 Flash 自称比前沿模型快 4-12 倍、价格只有 Pro 一半，叠加 Anthropic 的 Haiku、OpenAI 的 mini 系列，「跑得起」开始压过「跑得最强」
- 🔺 企业 agent 落地由头部咨询所打头阵：KPMG 27.6 万 + PwC 数十万 + Hershey $2B 营销决策，连续两周都是十万人量级的真实部署而不是 demo
- 🆕 Agent 执行层正在被托管化：Cloudflare Claude Managed Agents、AWS Claude Platform、Vercel Sandbox 都在替企业接管「沙箱 + MCP 工具 + 私网通道」，builder 不再需要自己运维代码执行环境
- 🔺 评估体系的危机被摆上台面：DeepMind 离职工程师质疑跨能力阶段的 benchmark 系统失效；同时 IBM/HF Open Agent Leaderboard 把成本维度纳入评估，行业开始反思「分数 ≠ 可用」
