## 📌 头条

### LangChain Labs 成立：把 agent 自我改进做成持续工程问题

Interrupt 大会次日，LangChain 抛出 LangChain Labs 这条独立研究线，主攻 continual learning for agents——让 agent 从自身产生的 trace、用户反馈、eval 结果和生产行为里持续吸取经验，而不是每次 prompt 都从零开始。同日发的《The Anatomy of an Agent Harness》把 agent harness 拆成 filesystem、sandbox、memory 三大组件，配合 SmithDB / LangSmith Engine / Sandboxes 把"自动聚类故障 → 提出修复 → 上线 eval 守门"这套循环跑通。如果你在用 LangGraph/Deep Agents 写 agent，现在该把生产 trace 存好，下一步官方平台会直接喂回去做自适应。

→ [LangChain Labs](https://www.langchain.com/blog/introducing-langchain-labs) / [Agent Harness 拆解](https://www.langchain.com/blog/the-anatomy-of-an-agent-harness)

---

### OpenAI Codex 进 ChatGPT 移动端，coding agent 全面异步化

OpenAI 把 Codex 集成进 iOS/Android 上的 ChatGPT App：手机里能查看正在远端跑的编码任务、审批命令、切模型、打开新 thread——但本机不写代码，手机只是 Codex 在 Mac mini / devbox / 云端实例上长跑时的遥控器。同期还放出 Codex on Windows Sandbox（基于 Windows Sandbox 内核隔离）。配上前几天的 GPT-5.5 长任务能力，方向已经很明确：coding agent 的形态从"开 IDE 配合 AI"变成"派 agent 出去做几小时活，手机来回 review"。Walter 这种 Mac + 远程 devbox 工作流可以直接把日常 review 链路搬到手机。

→ [Codex from anywhere](https://openai.com/index/work-with-codex-from-anywhere) / [Codex Windows Sandbox](https://openai.com/index/building-codex-windows-sandbox)
