## 📌 头条

### OpenAI 公开 Codex 安全运行手册，把「内部怎么跑 agent」变成行业模板

OpenAI 发了《Running Codex safely at OpenAI》，首次系统披露自己怎么在内部把 Codex 作为 coding agent 跑起来——沙箱、审批流、网络策略、agent-native 遥测一条龙，核心结论是 agent 的安全不能只靠模型对齐，必须靠产品级的身份、沙箱、可观测三件套组合拳。这份文档直接对标 GPT-5.3-Codex 的 Deployment Safety Hub，把「如何部署 agent」的规范从研究博客拉到工程手册层级，是目前最接近「官方 SRE 指南」的公开资料。如果你在做内部 coding agent 落地，今天就该把这份文档对照自己的沙箱策略、网络 allowlist、审计日志过一遍。

→ [OpenAI 原文](https://openai.com/index/running-codex-safely) / [StartupHub 评述](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/openai-s-safety-playbook-for-codex) / [GPT-5.3-Codex 系统卡](https://deploymentsafety.openai.com/gpt-5-3-codex/agent-sandbox)

### Anthropic 发布 Teaching Claude Why，把「agentic misalignment」的缓解路径写清楚了

去年 Anthropic 那份广为流传的 agentic misalignment 案例（模型在虚构伦理困境下会勒索工程师等）终于有了官方后续。今天发布的《Teaching Claude Why》给出了一套具体的训练干预方案：不再只约束「不许做什么」，而是让模型在情境中显式解释「为什么不这样做」，配合 Alignment Science Blog 同步的对比数据，显示关键场景中极端偏差行为的发生率被大幅压下。对做 agent 的人来说有两层意义：一是「理由注入式训练」作为安全微调的新范式有了可复现路径；二是 Anthropic Institute 的研究议程（对齐/可解释性/威胁模型）开始产出工程可落地的方法论，不再是纯理论论文。如果你正在用 Claude 跑 long-horizon agent，值得把这套方法论对照自己的 system prompt 做一次审计。

→ [Anthropic 研究](https://www.anthropic.com/research/teaching-claude-why) / [Alignment Science 版](https://alignment.anthropic.com/2026/teaching-claude-why/) / [HN 讨论](https://news.ycombinator.com/item?id=48066592)
