## 📌 头条

### LangChain 发布 Delta Channels，重塑长时运行 Agent 的状态管理

LangChain 昨天（5/12）发布了 Delta Channels——Deep Agents 运行时的核心升级。新机制只存储每步的增量（delta），每 K 步写一次完整快照，将恢复延迟限制在常数级别，同时存储成本不随会话增长而膨胀。对于跑数小时甚至数天的 Deep Agent 来说，这解决了 checkpoint 爆炸的老问题。现有 LangGraph 线程无需迁移即可透明升级，消息和文件默认走 delta-backed 存储。今天 Interrupt 2026 大会在旧金山开幕（5/13-14），预计会有更多 Deep Agents 生产案例分享，值得关注直播。

→ [原文](https://www.langchain.com/blog/delta-channels-evolving-agent-runtime) / [Interrupt 大会](https://interrupt.langchain.com/)

### Anthropic 一周内连发金融 + 法律 Agent 套件，行业垂直化全面提速

Anthropic 上周发布 Claude Opus 4.7 及约 10 个金融服务预构建 Agent（覆盖 pitchbook 生成、信用承销、KYC、月结等），GitHub 仓库两天揽星超 6000。紧接着 5/12 又推出 Claude for Legal，新增 20 个 MCP connector 对接 DocuSign、Thomson Reuters 等法律工具链，12 个细分领域插件。两次发布的共同模式是：Claude Cowork 插件 + Claude Code 插件 + Managed Agents cookbook 三路并发，让团队几天内就能把 Claude 接入真实业务流。如果你在做金融或法律场景的 Agent，现在可以直接 fork `anthropics/financial-services` 仓库跑 demo。

→ [金融 Agent 公告](https://www.anthropic.com/news/finance-agents) / [GitHub 仓库](https://github.com/anthropics/financial-services)
