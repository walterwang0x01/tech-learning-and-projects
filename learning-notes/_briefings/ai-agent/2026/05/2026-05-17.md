## 📌 头条

### Anthropic 6 月 15 日把 Agent SDK 拆出独立计费池：所有第三方 agent 用户都得重新算账

Anthropic 官方确认从 6 月 15 日起对订阅模式动刀：Agent SDK、`claude -p` 命令、Claude Code GitHub Actions，以及 OpenClaw、Conductor、Zed、Jean 这些第三方 agent 应用，全部从现有的 Claude 订阅 usage pool 中剥离，迁到一个独立计费的 "Agent SDK Credit pool"，起步价 $100/月。官方说法是结束 "compute arbitrage"——那种用 $200 Pro 订阅跑出每月几千美元等价用量的玩法。对每天靠 Claude Code 跑 agent 的开发者，这一刀直接落到日常工作流：要么把 Claude Code 切到 API key + per-token 计费、要么换 OpenAI Codex 或本地模型当主力、要么在网关层做 cost cap 防爆。Walter 这边今晚就该评估：把现在 Claude Code 上的多 agent 任务过一遍 token 估算，看 6 月 15 日切到 Agent SDK Credit 池后单月预期落在哪个区间，再决定是续费还是换 LangSmith LLM Gateway 做 spend limit。

→ [Anthropic Agent SDK 分池详解](https://help.apiyi.com/en/anthropic-claude-subscription-agent-sdk-billing-split-june-2026-en.html) / [行业解读](https://techstrong.ai/articles/anthropic-reverses-third-party-agent-ban-introduces-agent-sdk-credit-tier/) / [实操 mitigation](https://astgl.com/p/anthropic-agent-sdk-billing-playbook)

### 3 人小队 + 100 个 AI agent = 一个月烧掉 130 万美元，OpenAI 全单买

Peter Steinberger（OpenClaw 之父）在 X 上甩出一张 30 天账单截图：$1,305,088.81，6030 亿 token，760 万次 API 请求，3 个人指挥 100 个 agent 跑。结论是 OpenAI 替他全报销，关掉 fast mode 之后他自己估算成本"低于一个工程师"。这是 agentic CLI 经济学的第一份公开账单：把单次请求成本压低、把并发拉到 100，单月 token 消耗会跳到 6 × 10^11 的量级。这对"AI 流水线" 是个标定值——任何想做 multi-agent 自动化的团队，可以拿这个数字反推自己的并发上限和 LLM 预算合理区间。Walter 如果计划在 LangGraph 里跑 50+ 并发 agent 节点，今晚把这条数据点钉到设计文档里，做容量规划时直接引用。
