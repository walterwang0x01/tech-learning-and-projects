## 📌 头条

### Anthropic 把 Stainless 买下来，agent 时代的 SDK 层归一家

Anthropic 周一宣布完成对 Stainless 的收购，外界报道交易额约 3 亿美元。Stainless 是 Stripe 前工程师 Alex Rattray 创立的开发者工具公司，几乎所有 Anthropic 官方 SDK 都靠它生成，同时也在给 OpenAI、Google、Cloudflare 等家的 SDK 和 MCP server 提供同一套自动生成基础设施。这笔 deal 看起来不大（相对于 Anthropic 同期传出的 300 亿美元融资、9000 亿估值），但实质是把 agent 调用 API 时最关键的「客户端代码 + MCP 连接器」生成层锁进自家。对 builder 来说，短期不会立刻断供，但 SDK 升级节奏和 MCP 兼容性后面大概率会优先服务 Claude；如果你的 agent 重度依赖第三方 API 通过 MCP 调用，趁这周扫一遍现有 MCP server 的来源（哪些是 Stainless 生成的），心里有数。

→ [原文](https://www.anthropic.com/news/anthropic-acquires-stainless) / [TechCrunch 报道](https://techcrunch.com/2026/05/18/anthropic-has-acquired-the-dev-tools-startup-used-by-openai-google-and-cloudflare/)

### OpenAI 和 Dell 联手，把 Codex 直接送进企业机房

OpenAI 同一天宣布与 Dell 合作，把 Codex 部署到 hybrid 和本地环境。配套是 Dell Technologies World 上一起亮相的 Dell AI Data Platform、与 NVIDIA 共建的 NemoClaw 参考栈、OpenShell 运行时——意思是数据不用出企业网络，agent 也能跑。这是 Codex 路线里关键的一步：上周刚说全球开发者数从 4 月的 300 万跳到 4 月底的 400 万周活，又上线了 Codex Labs 帮企业做落地工作坊；这周直接和 Dell 把硬件方案打包。再叠加 OpenAI 三月吃掉 Astral（uv / Ruff / ty 进 Codex 团队），Codex 现在不只是 IDE 插件，正在成为「能编、能跑工具、能链路集成本地数据」的完整企业 agent 栈。如果你在企业环境里推 agent，本周可以重新评估「云 API + on-prem 数据」是否还是默认架构。

→ [原文](https://openai.com/index/dell-codex-enterprise-partnership) / [Codex Labs 背景](https://openai.com/index/scaling-codex-to-enterprises-worldwide/) / [Astral 收购](https://openai.com/index/openai-to-acquire-astral/)

**SDOF: Taming the Alignment Tax in Multi-Agent Orchestration** — 把 LangChain / LangGraph / CrewAI 的图式编排显式建模成「受约束状态机」，靠双层防御（Online-RLHF Specialized Intent Router + 状态约束分发）解决多 agent 流水线绕过业务流程的问题，对 LangGraph 用户值得一读。→ [arXiv](https://arxiv.org/abs/2605.15204)

**Verifiable Agentic Infrastructure: Proof-Derived Authorization** — 提出基于证明的授权模型替代「拿到合法 credential 就能执行」的传统假设，专门针对 agent 会生成语义上不安全但语法合法操作的风险，sovereign AI 系统的安全基线提案。→ [arXiv](https://arxiv.org/abs/2605.15228)

**Hidden in Memory: Sleeper Memory Poisoning in LLM Agents** — 在 agent 的长程记忆里埋潜伏指令，平时正常、特定触发条件下激活；现实威胁度相当高，建议 RAG / agent memory 设计时把「写入路径」也当不可信输入对待。→ [arXiv](https://arxiv.org/abs/2605.15338)

**SaaS-Bench: Can Computer-Use Agents Leverage Real-World SaaS** — 把 computer-use agent 放进真实 SaaS 工作流（不再只是 web/GUI 浏览 benchmark），暴露了「跨工具状态保持」是当前最大短板。→ [arXiv](https://arxiv.org/abs/2605.15777)

## 📈 趋势

- 🔺 **Agent 工具链垂直整合加速**：Anthropic 拿下 SDK + MCP 生成层（Stainless），OpenAI 三月吃掉 Python 工具链（Astral / uv / Ruff），AWS 把 Claude Platform 和 Transform agents 直接装进自家 marketplace——上下游开始在同一家手里收口。

- 🆕 **MCP 在传统企业语言生态扩张**：Quarkus Agent MCP 上线、Spring AI 持续迭代、JobRunr ClawRunr 内置 MCP，Java 阵营第一次出现完整的「agent + 本地任务调度 + MCP 工具」组合。
- 🔺 **Agent 评估转向系统级 + 成本维度**：Open Agent Leaderboard 第一次把质量和单轮运行成本同时报出来，行业开始承认「跑得动 ≠ 跑得起」。
