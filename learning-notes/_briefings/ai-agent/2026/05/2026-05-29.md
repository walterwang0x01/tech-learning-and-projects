### AWS 把 OpenSearch Serverless 推倒重做：NextGen 是从零为 agent 重建的搜索/向量库

同样 5/28 落地：AWS 把 OpenSearch Serverless 整个架构换掉，新生代叫 **NextGen**，旧的存量集合自动改名 Classic，从今天起在 Console 里新建 collection 默认走 NextGen。这次的关键不是性能数字，而是设计目标的彻底转向——AWS 直接把这次重构定性为「为 agentic workload 而建」：instant autoscaling，从 0 弹到每秒数千请求、idle 时缩回 0，跟旧版按 peak 预留的最高 60% 成本差；agent 触发任务时 sub-second 起服，不用再撑住一台常开 OCU。配合同期 OpenSearch 推出的 Agent Skills（封装好搜索 + 向量 + 观测的 agent 调用模式），整套是要把 RAG / 工具调用的底层从「数据库 + 应用层 agent」改成「专门给 agent 用的 retrieval runtime」。如果你现在的 RAG 基础设施还在用 Pinecone / Weaviate / 自托管 pgvector，本周值得测一下 NextGen 的成本曲线，特别是 burst 模式（多 agent 并发查询）下能不能省一截。

→ [AWS NextGen 发布](https://aws.amazon.com/blogs/aws/introducing-the-next-generation-of-amazon-opensearch-serverless-for-building-your-agentic-ai-applications/) / [The New Stack 架构拆解](https://thenewstack.io/aws-opensearch-serverless-agentic-rebuild/) / [TechCrunch：互联网正在为机器重建](https://techcrunch.com/2026/05/28/the-internet-is-being-rebuilt-for-machines/)
