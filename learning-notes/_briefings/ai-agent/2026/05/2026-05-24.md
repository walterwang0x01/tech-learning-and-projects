## 📌 头条

### Compiling Agentic Workflows into LLM Weights: Near-Frontier Quality at Two Orders of Magnitude Less Cost

这篇 arXiv 论文提出了一种新方法，将 agentic workflow 直接编译到 LLM 权重中，而不是依赖外部编排器。研究显示，这种方法能在保持接近前沿模型质量的同时，将推理成本降低两个数量级。对于需要频繁执行固定流程的 agent 应用来说，这意味着可以大幅减少 API 调用开销，同时提高响应速度。如果你在构建需要重复执行相似任务的 agent，可以考虑探索这种编译优化思路。

→ [arXiv](https://arxiv.org/abs/2605.22502)

### HeteroFlow 异构算力调度平台上线推理服务，TOKEN 产量翻倍

开源中国的 HeteroFlow V2 提供了完整的 GPU 推理服务管理能力，支持从模型发现到 API 服务的全自动化流程。通过 TaskGroup 统一管理推理服务生命周期，内置 OpenAI 兼容网关，实现一键部署和调用。对于需要大规模部署 AI 推理服务的团队，这个平台可以显著简化运维复杂度，特别是混合 GPU 环境下的资源调度问题。

## 📈 趋势

- 🆕 **Workflow 编译优化** — 将 agentic workflow 编译到 LLM 权重中，减少外部编排开销，成本降低两个数量级。
- 🔺 **MCP 工具统一框架** — 越来越多的框架尝试统一 HTTP 端点和 MCP 工具表示，解决业务逻辑重复问题。
- 🔺 **语音 agent 集成** — 语音功能成为 agent 的标准配置，基于 Gemini Live 等技术实现大上下文对话。
- 🔻 **传统 agent 编排框架** — 外部编排器模式面临挑战，编译优化和权重内化方法显示出成本优势。
- 🆕 **HR 场景 AI 化** — AI agent 在招聘、人事管理、人才画像等 HR 场景得到实际应用，形成完整产品矩阵。
