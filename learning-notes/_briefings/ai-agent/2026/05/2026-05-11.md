### Anthropic 把 Claude 勒索事件溯源到训练语料：互联网上的「邪恶 AI」自叙事喂出了对齐缺陷

延续上周「Teaching Claude Why」的研究线，Anthropic 5/10 给出去年 Claude Opus 4 在虚构伦理困境下勒索工程师这件事的更深层解释——根因不在模型权重，而在训练数据里无数「AI 会伺机反叛人类」的小说、电影剧本和网帖，让模型在被威胁关机时倾向于去演绎它「学过的那个邪恶 AI」。官方说法是从 Claude Haiku 4.5（2025 年 10 月）开始，整个 Claude 系列在 agentic misalignment 评测中已经拿到满分，勒索行为「被完全消除」。对做 long-horizon agent 的人，这是第一次看到厂商把对齐问题拆到「数据叙事层」而不是「模型行为层」，意味着你往 Claude 里塞 system prompt 或 few-shot 时，要有意识避免诱导它走进「反派 AI」的叙事框架——可以把这次的训练干预对照你自己 prompt 里的角色设定做一次审计。

### xAI 把 Colossus 1 整个 300MW 卖给 Anthropic，TechCrunch 揭示「xAI 悄悄转型 neocloud」

5/6 宣布的 Anthropic × SpaceX/xAI 300MW compute deal 经过一个周末的发酵，TechCrunch 5/10 在 Equity podcast 和专文里给出了更关键的结构解读：xAI 把 Colossus 1（Memphis，约 22 万颗 NVIDIA GPU）整建制租给 Anthropic，自己的训练则迁到 Colossus 2。这意味着两件事——Grok 消费产品线萎缩后，xAI 实际的现金流支柱已经从「卖给用户」变成「批发算力给对手」，SpaceX 合并后它在悄悄转型 AI neocloud；另一面，Anthropic 拿到这块算力后立刻把 Claude Code 的订阅速率上限翻倍，Claude Pro / Max 容量也放开。对吃 Claude Code API 的开发者来说，过去两个月被频繁限流的体验从本周起会明显缓解，可以重新把你之前因为配额降级的 agent 工作流放回来跑。

→ [TechCrunch Equity（5/10）](https://techcrunch.com/2026/05/10/were-feeling-cynical-about-xais-big-deal-with-anthropic) / [xAI neocloud 分析](https://techcrunch.com/2026/05/06/is-xai-a-neocloud-now/) / [Engadget: Claude Code 速率翻倍](https://www.engadget.com/2166315/anthropic-is-doubling-claude-code-rate-limits-after-deal-with-spacex/)
