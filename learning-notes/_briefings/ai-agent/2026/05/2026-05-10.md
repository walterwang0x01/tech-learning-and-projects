## 📌 头条

### OpenAI 把 Codex 搬进 Chrome：coding agent 正式跨过浏览器这堵墙

OpenAI 5/7 上线的 Codex for Chrome 扩展在周末持续发酵。它把 Codex 从 CLI / IDE 直接推进到浏览器上下文：跨多个 tab 采集上下文、调用 Chrome DevTools、在真实前端页面上跑测试和调试，全部在用户正常浏览的同时后台执行，而不是接管浏览器。这解决了 coding agent 一直没吃到的一块——前端开发的闭环（改代码 → 看渲染 → 读 console → 再改）。对标 Claude for Chrome 当初还停在 preview 研究预览，OpenAI 这一步把「浏览器里的 agent」从概念拉到可装插件试一下的阶段。如果你主做 Web 前端或全栈，今天就值得把 Chrome extension 装上跑一个真实 bug 调试，看它读 DevTools 和 Network 面板的能力是否能省掉你来回切窗口的成本。

→ [OpenAI 公告](https://openai.com/index/unlocking-the-codex-harness/) / [MacRumors 评述](https://www.macrumors.com/2026/05/07/openai-codex-chrome-extension/) / [The New Stack](https://thenewstack.io/openai-codex-chrome-extension/)

### Meta「Hatch」+ Google「Remy」同周曝光：个人 AI agent 消费级战场正式开局

CNBC 5/8 把最近一周的「agentic wars」做了一次汇总：Meta 正在训练内部代号 **Hatch** 的 agent（基于 Muse Spark，面向 30 亿月活用户，Instagram 购物 agent 赶在 Q4 前上线，整体内测 6 月底完成），Google 则在测试代号 **Remy** 的「24/7 个人 agent」贯穿工作/学习/日常。同时 Google 已经在 5/4 关掉了老项目 Project Mariner，把人员转移到 Remy。过去一年「企业级 agent」被 Anthropic/OpenAI 基本瓜分，现在 Meta 和 Google 绕开企业侧，直接从消费流量入口（IG/FB/WhatsApp vs Android/Chrome/Gemini app）开第二战场。对开发者的直接影响是：2026 下半年个人场景的 agent SDK / 插件生态大概率会跟着被两家强推，MCP / A2A 之外要提前想好「给消费级 agent 做工具」的接入路径。现在值得做的是关注 Meta AI SDK 和 Gemini Agent 的 developer preview。

→ [CNBC 综述](https://www.cnbc.com/2026/05/08/ai-agent-meta-google-agentic-wars-tech-download.html) / [Business Insider: Remy](https://www.businessinsider.com/google-ai-agent-openclaw-remy-gemini-assistant-2026-5) / [The Decoder 背景](https://the-decoder.com/google-and-meta-race-to-build-personal-ai-agents-as-anthropic-and-openai-pull-further-ahead/)
