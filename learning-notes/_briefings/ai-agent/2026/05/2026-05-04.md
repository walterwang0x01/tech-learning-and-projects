### 1. DeepClaude：用 DeepSeek V4 Pro 替换 Claude Code 后端，成本降低 17 倍

- **来源**：[DeepClaude – Claude Code agent loop with DeepSeek V4 Pro, 17x cheaper](https://github.com/aattaran/deepclaude)
- **标签**：`Claude Code` `DeepSeek V4` `成本优化` `开源`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 5 = 总分 20
- **摘要**：DeepClaude 通过设置环境变量将 Claude Code 的 API 调用重定向到 DeepSeek V4 Pro（$0.87/M output vs Anthropic $15/M），保留完整的 Claude Code 工具循环（文件编辑、bash 执行、子 Agent 生成、Git 操作）。支持 DeepSeek、OpenRouter、Fireworks AI 多后端切换，DeepSeek 的自动上下文缓存让 Agent 循环成本极低（缓存后 $0.004/M）。HN 获得 192 分 / 95 条评论。
- **影响**：继 Uber 四个月烧完全年 AI 预算后，Claude Code 成本问题持续发酵。DeepClaude 提供了一个实用的降本方案——保留 Claude Code 的工具链体验，用更便宜的模型做推理。这是 AI 编码工具"换脑不换壳"趋势的典型代表。
- **行动建议**：如果 Claude Code 成本是痛点，可以试用 DeepClaude；注意 DeepSeek 在复杂推理任务上可能不如 Opus，建议用 `--backend anthropic` 回退处理难题

### 2. Specsmaxxing：克服 AI 编码焦虑，用 YAML 写规格说明

- **来源**：[Specsmaxxing – On overcoming AI psychosis, and why I write specs in YAML](https://acai.sh/blog/specsmaxxing)
- **标签**：`Spec 驱动开发` `AI 编码` `工程实践` `ACAI`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 5 = 总分 20
- **摘要**：作者分享了从"AI 编码焦虑"到 Spec 驱动开发的心路历程。核心观点：我们正在进入"后 Slop 时代"，上下文窗口是真正的瓶颈。文章提出 ACAI（Acceptance Criteria for AI）方法论——用结构化 YAML 编写验收标准，让 Agent 在代码中直接引用需求编号（如 `// AUTH-1`），实现需求到代码的可追溯性。HN 获得 262 分 / 275 条评论，引发大量关于 Spec 驱动开发的讨论。
- **影响**：这篇文章触及了 AI 编码的核心痛点——如何让 Agent 持续产出高质量代码而非"看起来能用的 slop"。ACAI 方法论与 Kiro 的 Spec 驱动开发理念高度一致。
- **行动建议**：阅读原文了解 ACAI 方法论；考虑在项目中引入结构化验收标准来约束 Agent 行为

### 3. LangChain Deep Agents 发布模型专属 Harness Profile，性能提升 10-20 分

- **来源**：[Tuning Deep Agents to Work Well with Different Models](https://www.langchain.com/blog/tuning-deep-agents-different-models)
- **标签**：`LangChain` `Deep Agents` `Harness` `模型优化`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 4 = 总分 19
- **摘要**：LangChain 为 Deep Agents 引入 Harness Profile 机制，允许按模型定制提示词、工具和中间件。内置 OpenAI、Anthropic、Google 三家模型的默认 Profile。在 tau2-bench 子集上，GPT 5.3 Codex 从 33% 提升到 53%，Claude Opus 4.7 从 43% 提升到 53%。核心发现：同一模型在不同 Harness 中表现差异巨大，Claude Code Harness 在 Terminal-Bench 2.0 上排名垫底。
- **影响**：证明了 Harness 工程（提示词、工具配置、中间件）对 Agent 性能的影响可能比模型选择更大。这对所有构建 Agent 系统的开发者都是重要启示。
- **行动建议**：如果使用 Deep Agents，升级到最新版本自动获得 Profile 支持；关注 Harness 工程作为 Agent 性能优化的新维度
