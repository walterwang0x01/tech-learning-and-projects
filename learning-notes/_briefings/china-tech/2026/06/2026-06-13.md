## 📌 头条

### 华为 HDC 2026 发布鸿蒙 HarmonyOS 7

余承东在华为开发者大会上正式推出 HarmonyOS 7，宣布鸿蒙已成为中国第二大智能手机操作系统。搭载 HarmonyOS 6 的终端设备突破 6600 万台，注册开发者超 1100 万。新系统重点升级五大维度：互联、智能、安全、流畅、空间感，引入 2000+ AI Agent 能力，正式从「万物互联」迈向「智能体时代」。Mate 90 系列今秋首发搭载。对于开发者来说，版本号格式改为语义化版本（SemVer），统一了 HarmonyOS 与 OpenHarmony 版本体系。

→ [原文](https://www.ithome.com/0/963/721.htm)

### 月之暗面开源 Kimi K2.7 Code 编程模型

月之暗面发布并开源 Kimi K2.7 Code，基于 MoE 架构（1T 总参数 / 32B 激活），显著提升长上下文编程场景表现。相比 K2.6，Kimi Code Bench v2 提升 21.8%，Program Bench 提升 11.0%，推理 token 减少约 30%。模型权重已上线 Hugging Face（Modified MIT 协议），同时上架 Cloudflare Workers AI。API 定价与 K2.6 一致，6 倍速高速版下周一上线。对 Walter 来说，这意味着国产编程模型又有一个可直接替代 Claude Code 的选项。

→ [原文](https://www.oschina.net/news/457565) / [Hugging Face](https://huggingface.co/moonshotai/Kimi-K2.7-Code)
