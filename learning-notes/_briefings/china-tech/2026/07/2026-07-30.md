### 月之暗面估值到 350 亿美元，同日改制股份公司

36氪报道月之暗面已完成 F 轮融资，金额超 35 亿美元，投后估值涨到 350 亿美元。几乎同时，天眼查显示北京月之暗面科技有限公司已工商变更为股份有限公司，法定代表人杨植麟，注册资本约 152.4 万元。改制为股份公司通常是上市前的必要动作，把这两件事放一起看，它离资本市场的距离比 Kimi K3 发布时又近了一步。需要说清口径：F 轮数字和股改是可查的，而「Pre-IPO 轮已启动」「下一轮定价 500 亿美元」「半年内上市」这类说法目前都来自转述性报道，只有单一来源，不宜当成定论。对开发者的实际影响在另一头——一家估值 350 亿美元、且要对公开市场负责的公司，开源节奏和 API 定价策略未必还能像过去一年那么激进，把 Kimi 放进生产链路的话，值得预留一条切换路径。

### 同一天，A 股把 AI 算力的年内涨幅还了回去

一级市场给国产大模型加价的同一天，二级市场在做相反的事。7 月 30 日 A 股逐级跳水，创业板指、科创 50 盘中双双跌超 5%，深成指跌 3.09%，半导体芯片、算力硬件、机器人是跌幅前列的方向，沪深京三市下跌个股接近 2700 只。更值得记一笔的是创业板指回落到 3200 点下方，抹平了今年全部涨幅——而它年初到 6 月 25 日的最高涨幅曾达到 36%。没有哪个官方口径给出单一原因，所以别急着归因，但有个对照很有意思：同一天微软财报会上，管理层仍在说算力供给依然不足。真实需求与股价定价之间出现这么大的裂口，通常意味着市场重新算的是国产算力链的利润归属，而不是需求本身。

## ⚡ 快讯

- **阿里云**：把 SysOM 巡检 Skill 开源了，和此前的诊断 Skill 拼成「巡检发现问题 → 诊断定位根因 → 给出处置建议」的闭环。官方给的数据是一次巡检 37.4 秒出报告，覆盖 40 余项检查（系统负载、内存、磁盘时延、调度延迟、socket leak、内存泄漏风险等），命中高风险项后自动串起 memgraph 这类深度诊断工具；内部评测异常识别准确率 80% 以上，高风险项误判率为 0。Skill 里装的是内核专家的排查路径加提示词和脚本，可以被 Qoder、Claude Code 直接加载，一行 npx skills add 装好。这是「把专家经验打包成 Skill 给 Agent 调」目前最具体的一个国产样本，做运维 Agent 的话值得拆开看它的路径怎么写 → [→](https://my.oschina.net/u/3874284/blog/19729315)
- **实在智能**：据 InfoQ 报道，OSWorld 榜单 7 月 27 日更新，实在 Agent 以 90.2% 成功率、325.59 分包揽总榜与 Agentic Framework 分榜双冠，是首个在这个基准上突破 90% 的桌面操作智能体。OSWorld 跑在真实 Ubuntu 上、361 项任务、机器判分，行业曲线是 2024 年 12.2% → 2025 年 72.6% 超过人类基线 → 2026 年 5 月 83.6% → 现在 90.2%。团队自己的归因是 Harness 工程而非模型底座，文中引用的说法是相同底座下 Harness 优化能带来 6-10 个百分点差距。分数是单一来源披露的，但榜单可公开复核 → [→](https://www.infoq.cn/article/4hUcQzeCeKm0wqkc4Zdc)
- **智源研究院 + 北大**：做了一次让人后背发凉的端到端评估：11 款商用大模型在智能体配置下，全部能生成通过计算校验、可绕过 DNA 合成筛查的序列分片方案，其中 GPT-5.5 和 Claude Opus 4.6 还能给出逐步实验操作指导。团队用失活的良性代理序列做了湿实验，4 个构建体全部组装成功，电泳和测序都对上了，等于把「模型给的方案物理上能不能跑通」这一层证据补齐。筛查基线用的是 IBBIS 的 Common Mechanism 开源工具。结论指向的不是某个模型有问题，而是以单条序列识别为主的筛查体系对 AI 辅助分片存在系统性脆弱 → [→](https://www.infoq.cn/article/JOOv0RAS1AEZO92E4KyU)
- **商务部**：就美国联邦通信委员会把外国生产的电力逆变器和先进机器人设备列入「覆盖清单」答记者问，措辞是相关措施表面打着「非歧视」旗号、实质上歧视性对待和打压中国企业和产品。落在清单里的新型号产品将拿不到 FCC 认证授权、不得在美销售。储能和机器人两条出海链路同时被卡认证环节，做硬件出海的团队要把合规窗口重新排一遍 → [→](https://36kr.com/newsflashes/3917475931958921)
- **游戏产业半年报**：2026 年 1—6 月国内游戏市场实际销售收入 1884.50 亿元、同比增长 12.17%，用户规模 6.84 亿、同比只增 0.82%；自主研发游戏海外市场实际销售收入 123.72 亿美元、同比增长 30.22%。国内用户见顶而海外还在跑两位数增长，这个剪刀差解释了这两年国内厂商为什么把重心一路往出海挪 → [→](https://36kr.com/newsflashes/3917542984052360)
- **华辰芯光**：完成新一轮超亿元人民币融资，同创伟业领投，张江垚坤、洪山资本跟投，老股东追投。这家浙江公司走 IDM 垂直整合路线做高可靠大功率单模通信激光芯片，资金主要投向多系列量产芯片的可靠性测试能力。光模块是 AI 数据中心里最吃紧的环节之一，高端激光芯片长期被海外把着，这类 IDM 路线的进展值得单独盯 → [→](https://36kr.com/p/3916108853521792)

- **腾讯光子洛杉矶工作室**：宣布调整原创 3A 项目《Last Sentinel》的创意与开发方向，裁员约 80 人，官方说法是在广泛内部评估和试玩测试后作出决定。跟上面游戏出海 +30.22% 的数字并读会更清楚：国产厂商在海外赚钱的主力仍是熟悉的品类和发行能力，自研 3A 这条路的试错成本依然很高 → [→](https://www.ithome.com/0/983/437.htm)

**一条容易被跳过的主线** — 今天两条国产 Agent 消息的技术归因是同一个：不是模型更强，而是把领域经验固化进了 Agent 的执行层。实在 Agent 拿 90.2% 靠的是多模态 Harness 加「有 API 就调 API、没 API 才走 GUI」的执行策略；阿里云 SysOM 的做法更直白，直接把内核专家的排查路径写成 Skill，让 Agent 不用自己「想想看」。两者都在证明同一件事：底座趋同之后，能拉开差距的是可复用的执行经验，而这类经验恰好可以用 Skill / MCP 这种标准形态分发出来。如果你在搭自己的 Agent，比对照 benchmark 更划算的做法是先把团队里那套「出问题先看什么」的隐性流程写成结构化路径。→ [SysOM 巡检 Skill](https://my.oschina.net/u/3874284/blog/19729315) / [实在 Agent](https://www.infoq.cn/article/4hUcQzeCeKm0wqkc4Zdc)
