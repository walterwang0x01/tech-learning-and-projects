## 📌 头条

### 3T 模型落到国产卡：摩尔线程 Day-0 跑通 Kimi K3

Kimi K3 权重放出的同一天，摩尔线程宣布基于 MTT S5000 训推一体卡和 MUSA 软件栈完成 Day-0 支持，把 2.8 万亿参数的模型跑起来了。这件事的难点不在参数量，而在架构：K3 的主干是 69 层 KDA 混合线性注意力加 24 层 Gated MLA，Stable Latent MoE 用 896 个专家、每 token 激活 16 个，等于给所有非英伟达软件栈重新出了一套算子和缓存管理的题目，摩尔线程说自己是在开源后第一时间做完了结构解析、权重加载、核心算子到分布式推理这一整条链。九章云极当天也宣称 Alaya Token 完成了 K3 适配，据量子位报道是首个把 3T 级开源模型接进 Token 工厂的平台。部署成本仍然是个没统一口径的问题：官方推荐 64 卡以上的超节点配置，而 vLLM 给的最省路径是 8 张 B300 或 8 张 MI355X，量化方案不同差出好几倍。想自己托管的话先照着 vLLM 的部署说明估一遍卡数，别只看参数表。

→ [摩尔线程适配](https://www.ithome.com/0/982/959.htm) / [九章云极](https://www.qbitai.com/2026/07/462058.html) / [vLLM 部署](https://vllm.ai/blog/2026-07-27-k3)

### 美团 CatPaw 与 360 纳米Work 同期开闸

两家风格完全不同的公司在同一周把企业级 Agent 平台推向外部。美团 CatPaw 走的是内部先跑透再对外：官方数据是覆盖 9 万员工、搭出 3 万个 Agent，产品形态是开箱即用的 AI 工作台加企业级 Agent 开发托管，本地生活商家是第一批目标客户。周鸿祎发布的纳米Work 则把话说得更直白，主打「老板要先用」，先帮 1000 家小企业落地。两者放一起看，国内企业 Agent 的竞争点已经不是模型能力，而是谁能把「一句话到可交付结果」这条链路在真实组织里跑顺，以及谁手上有存量商家和企业客户可以直接灌进去。如果你在为公司选 Agent 平台，值得关注的是托管形态和权限模型，而不是发布会上的 demo。

→ [美团 CatPaw](https://my.oschina.net/meituantech/blog/19728543) / [纳米Work](https://www.qbitai.com/2026/07/462062.html) / [InfoQ 报道](https://www.infoq.cn/article/Ey2MtxSL1FaYWesfqLGE)

## ⚡ 快讯

- **Qoder Voice**：同一个团队还上线了实时语音智能体，由全双工语音模型 Qwen-Audio-3.0-Realtime 驱动，在 Quest 模式里用悬浮窗随时唤起，靠说话完成任务创建、方案讨论和代码执行。编程助手从「打字对话」挪到「边说边改」，交互形态的变化比模型指标更值得留意 → [→](https://www.oschina.net/news/481439)
- **火山引擎**：开源了 Agent 驱动的搜索自迭代技术。思路是让 Agent 不止会调搜索，还能在结果不好时自己找改进方向，通过一轮轮实验把搜索质量提上去。这类「自己评估自己再改」的闭环，正好是 RAG 系统里最难自动化的一段 → [→](https://my.oschina.net/u/6210722/blog/19728179)
- **中央网信办**：联合北京、上海、浙江、深圳四地网信办，会同 5 家头部大模型企业在雄安启动「人工智能大模型 IPv6 能力提升专项行动」，要求生成式大模型应用全面支持 IPv6。官方给的理由是大模型应用带来的 Token 流量爆发式增长对网络承载提出新要求。做面向国内的模型服务，网络栈合规这一项要提前排进上线清单 → [→](https://www.oschina.net/news/481266)
- **寒武纪**：发布 2026 年限制性股票激励计划草案，拟授予 500 万股、占总股本 0.80%，授予价 750 元/股；首次授予 400 万股涉及 945 人，占员工总数 85.37%，粗算总价值 37.5 亿元、人均约 396.8 万元。国产 AI 芯片公司开始用这种量级留人，是这一轮算力景气度最直接的读数 → [→](https://www.ithome.com/0/982/897.htm)
- **腾讯 APIJSON 生态**：开源 A2API，一套 Agent-to-API 协议、引擎与 Demo，思路是让大模型只生成一次任务 UI，之后改筛选、排序、分页都直接调 HTTP API 不再回到模型。对成本敏感的数据类 Agent 来说，这种「一次生成、多次复用」的结构值得对着自己的实现比一比 → [→](https://www.oschina.net/news/481862)
- **国家知识产权局**：截至 6 月底，人工智能、互联网、云计算、大数据等新一代信息技术领域有效发明专利占总量 16.5%，全国高价值发明专利拥有量达 236 万件，每万人口 16.8 件；今年前 5 个月知识产权使用费出口额 455 亿元、同比增长 64.9%。技术出口这条曲线比专利数量本身更能说明问题 → [→](https://www.ithome.com/0/982/913.htm)
- **得物**：分享了推荐系统自动化评测平台的做法：把新颖性、相关性这些长期靠人工主观打分的维度交给大模型评测，反馈周期从周级压到小时级，单周支撑百万级审计量。推荐和搜索团队里「指标之外说不清好坏」的老问题，现在有了一条可落地的量化路径 → [→](https://my.oschina.net/u/5783135/blog/19728170)

## 📈 趋势

- 🔺 国产算力接模型的时间差压到 0 — 摩尔线程、九章云极在 K3 开源当天完成适配，Day-0 支持从宣传语变成基本要求

- 🆕 3T 级模型的真实门槛是部署不是训练 — 显存需求从数百 GB 到 1.5TB 取决于量化方案，超节点和国产卡的适配能力成了模型能不能用起来的分水岭
