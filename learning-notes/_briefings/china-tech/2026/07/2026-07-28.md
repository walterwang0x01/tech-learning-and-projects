## 📌 头条

### Kimi K3 开权重：全球第一个 3 万亿级开源模型

月之暗面昨晚在 Kimi K3 开放日把权重和技术报告一起放了出来：2.8 万亿总参数、1040 亿激活的 MoE，原生视觉理解，100 万 token 上下文，架构上换成了自研的 Kimi Delta Attention 加 Attention Residuals。真正值得注意的不是参数表，而是它同时开源了三件支撑训练的 Infra：MoonEP、FlashKDA 和 AgentEnv。官方公告只给了名称没有展开，从命名推测分别对应专家并行、KDA 算子实现和 Agent 训练环境，具体边界要等技术报告细读。7 月 16 日 K3 先以托管 API 形式亮相，11 天后权重落地，这种「先验证再开放」的节奏和 DeepSeek 当年不太一样，更像是在拿商业化收入养开源。对做 Agent 的人来说，三件里最值得先翻的是 AgentEnv——如果它确实是 Agent 训练环境，那这是国内团队第一次把这层能力开源出来。想跑起来先看清成本，2.8T 权重本地部署门槛不低，阿里云百炼和千问平台的 API 是更现实的入口。

### OpenRouter 7 月调用量前五，全是中国模型

小米 MiMo-V2.5 拿下 OpenRouter 全球大模型调用量周榜和月榜双第一，7 月 20 至 26 日单周 10.46T token，环比涨 12%，是当周全球唯一破 10T 的模型；从 5 月的 1.46T 算起，两个月增长约 616%。更值得琢磨的是榜单结构：7 月调用量前五名依次是小米 MiMo-V2.5、DeepSeek V4 Flash、腾讯 HY3、智谱 GLM-5.2、DeepSeek V4 Pro——全部来自中国厂商。这个位置不是靠榜单刷出来的，OpenRouter 统计的是真金白银的 token 消耗，说明海外开发者在「够用 + 便宜」这个象限上已经默认选国产模型。上周美国 25 家科技公司联名信里那句「限制开源会把用户推向中国 AI 系统」，在这张表上已经是既成事实。如果你在做多模型路由，现在值得把国产开放权重模型排到默认档而不是备选档。
