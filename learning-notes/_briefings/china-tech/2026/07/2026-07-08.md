## 📌 头条

### GB/Z 185 国标落地，智能体有了「普通话」

7 月 3 日，我国正式发布《人工智能 智能体互联》系列 7 项国家标准（GB/Z 185.1—185.7），由中国电子技术标准化研究院牵头，华为、阿里云、中国移动等 70 余家单位共同研制。标准从身份码、能力描述、发现匹配到交互协作、工具调用，搭起智能体全生命周期的互联框架——相当于给各家 Agent 定了统一的「数字身份证」和对话规则。国际上 MCP、A2A 各说各话，国内这次走的是产业协同路线。对做 LangGraph、CrewAI 或多 Agent 编排的开发者，接下来要关注各家产品如何对齐这套规范，以及它与 MCP 生态是互补还是竞合。

→ [开源中国解读](https://www.oschina.net/news/471543)

### 腾讯混元 Hy3 正式开源

继 4 月底 Preview 之后，腾讯混元 Hy3 于 7 月 6 日正式开源，采用 Apache 2.0 协议，权重已上线 Hugging Face、ModelScope 等平台。模型为 295B MoE、激活 21B，支持 256K 上下文，主打推理与 Agent 任务——内部测评显示 WorkBuddy 场景任务解决率从 72% 跃升至 90%。腾讯称 Hy3 在参数仅为旗舰模型 1/2～1/5 的情况下，效果可与之比肩，且已接入元宝、CodeBuddy 等近 50 个业务。国产大模型竞争焦点正从榜单分数滑向「谁能低成本跑通 90% 的 Agent 活儿」。

→ [开源中国](https://www.oschina.net/news/471516) / [GitHub](https://github.com/Tencent-Hunyuan/Hy3)
