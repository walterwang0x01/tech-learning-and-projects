## 📌 头条

### 荣耀 Robot Phone：把机械云台装进手机

荣耀本周正式发布 Robot Phone，9999 元起，官方称其为全球首款「机器人手机」——机身里嵌了一条可伸出的机械臂云台，用物理移动传感器来稳定画面，而不是靠软件后期补救。Wired 的现场报道提到，市面上的现成云台电机都太大，荣耀自研了微型电机把体积压缩约 65%，钛合金云台电机重 2.6 克，塞进 9.59mm 厚的 6.3 英寸机身；多家海外媒体还提到内置了 ARRI 色彩科学管线，目前只在中国市场发售。这个价位已经超过国产旗舰的常规区间，本质上是把「手机 + DJI Osmo Pocket」打包卖给内容创作者。值得注意的不是这台机器本身，而是信号：在影像和 SoC 都卷不出差异的当下，手机厂商开始往「机械结构 + AI」这个方向找增量，小米同日发的澎湃 OS 4 走的是软件侧同一逻辑。各家发布口径对首销日期说法不一（有报道称 8 月 18 日，也有称已开售），要买的话按官方渠道为准。

### 面壁启动 IPO 辅导，具身智能同期上市热

中国证监会 IPO 辅导公示显示，北京面壁智能已向北京证监局提交上市辅导备案，中信证券担任辅导机构——注意这只是辅导备案，不等于已递交上市申请，板块、募资规模和时间表都还没披露。面壁是国内最早把端侧模型当核心战略的创业公司，MiniCPM 系列累计下载超 3800 万次，已上三星旗舰机型和长安马自达 EZ-60、吉利银河 M9 等量产车；据媒体报道其 2026 上半年累计融资超 50 亿元、估值突破 200 亿元（单一口径，未经官方确认）。同一周，宇树科技在上海挂牌，发行价 150.8 元/股，散户申购被外媒描述为约 8000 倍超额认购。两件事拼起来看，是国内一级市场对「模型 + 硬件落地」的估值逻辑正在被公开市场检验：面壁接下来要回答的不再是开源下载量，而是 3800 万次下载能换来多少可复制的收入。

→ [InfoQ](https://www.infoq.cn/article/hMG80lZUX1kaJWpr58g1) / [宇树 IPO 报道](https://beincrypto.com/unitree-ipo-embodied-ai-china-robots/)

## ⚡ 快讯

- **腾讯云 Cube Sandbox**：InfoQ 专访腾讯云 IaaS 前沿技术团队，讲清了这套 Agent 沙箱的来路：底层是 2023 年起为 Serverless 做的 RustVMM + Cloud Hypervisor 轻量虚机，冷启动不到 60ms，靠快照启动 + 写时复制做到单机上千实例。v0.3.0 加了快照/克隆/回滚，v0.4.0 补出站治理和凭证托管，v0.6.0 支持 Helm 部署到 TKE/k3s 并引入兼容 E2B 标准的 Volume 抽象。跑 Agent 又不想把 OpenClaw 那类工具直接放进生产环境的，这是目前国内最成熟的一条自建路线 → [访谈](https://www.infoq.cn/article/KwZX2bLcaHRjuLG95vHI) / [GitHub](https://github.com/tencentcloud/CubeSandbox)
