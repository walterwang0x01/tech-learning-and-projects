## 📌 头条

### DeepSeek 开源 Harness，同时把 API 价格调上去

8 月 13 日晚，DeepSeek 放出第一个 Agent 产品 DeepSeek Harness v0.1 开发者预览版，代码以 MIT 许可开源。它不是又一个模型发布，而是模型外面那一层执行壳：读工作区、调工具、把一次 run 撑到结束。架构上建在 Cordis 插件系统上，官方页面写得很直白——模型、工具、skill、会话、沙箱、存储、循环、调度、UI 全是插件，插件之间靠 Cordis 的 service 和 event 打通。同一时间 DeepSeek 更新了 V4-Pro 并上调 API 定价，据 the-decoder 报道 8 月 16 日起 V4-Pro 每百万输出 token 峰时价来到 $3.96，此前是 $0.87。两件事放一起看信号很清楚：靠低价 API 换量的阶段结束了，接下来卷的是 agent 执行层的生态位。如果你在用 LangGraph 或自己那套 harness，值得花半天读一下它的插件边界怎么切的——这是国内第一份把 agent runtime 完整摊开的开源实现。

→ [官方预览页](https://www.deepseek.com/harness/en/) / [量子位实测](https://www.qbitai.com/2026/08/472208.html) / [涨价与 V4-Pro 更新](https://the-decoder.com/deepseek-launches-an-improved-v4-pro-model-raises-api-prices-and-makes-its-agent-software-open-source/)
