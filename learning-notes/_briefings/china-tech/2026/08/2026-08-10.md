### 宇树今日申购，人形机器人有了每天报价的标的

宇树科技今日在科创板启动网上申购，发行价 150.8 元/股，发行约 4044.64 万股占发行后总股本 10%，对应上市市值约 610 亿元；IT之家给出的口径是对应 2025 财年发行后市盈率 219 倍。真正让这件事有嚼头的是配套的两条旧账：证券时报报道大疆 2018 年曾以 1012.86 万元拿下宇树约 17% 股份、一度是最大外部股东，2019 年减资退出，今天「大疆错失宇树」冲上微博热搜；同一天量子位那篇灵巧手行业稿说全球灵巧手企业约一半在中国、半年涌进约 200 亿热钱、单只手贵到几十万。上市之前这个赛道只有故事和估值，之后它每天都有一个公开价格，二级市场的定价会往下传导到一级的融资节奏和供应链报价。对你的实际影响不在打新——中签率据电商报测算只有 0.02%~0.05%，而在于具身智能这条线接下来会有强制披露的财报数据可读，比看融资新闻靠谱得多。

### 千问开放平台上线，Agent 接入走的是「入驻」模式

阿里今天上线千问开放平台，向生态伙伴开放手机、PC 和 AI 眼镜三类终端的服务接入，第三方可以创建智能体、以独立对话空间的形态在千问 App 上跑完从咨询、推荐到履约的链路。首批伙伴覆盖物流、房产、本地生活、理财、汽车等十多个领域，点名的有顺丰速运、自如租房、哈啰租车、闪送、快递100、飞常准、美的美居、彩云天气、盈米且慢，菜鸟和夸克系产品也同步接入。值得注意的时间点是一个月前：千问在 7 月 15 日刚下线了用户自建智能体功能，同一天《人工智能拟人化互动服务管理暂行办法》施行——两件事形态完全不同（个人自建 vs 持牌企业入驻），官方也没说有关联，但从「谁能建 Agent」的口子来看方向是收窄到机构。对做 Agent 的人来说，这跟 MCP 那套「谁都能起一个 server 挂上去」的开放路线是两种截然不同的接入范式，国内落地时值得对照着看：能力边界由平台定义，履约责任跟着入驻资质走。

→ [千问开放平台（IT之家）](https://www.ithome.com/0/987/720.htm) / [7 月智能体下线背景](https://m.ebrun.com/685743.html)

## 🛠 工程与开源

**AICon 深圳两场 Agent 工程实践** — 一场讲智能互动 Agent 在快手商业场景的落地，一场讲基于系统控制论做 Agent 安全防御体系。国内大厂把 Agent 从 demo 推到线上流量之后，暴露的问题基本都在「怎么让它别乱来」这一层，跟 LangGraph 里那套显式状态机与中断点是同一个问题的两种答法。→ [快手实践](https://www.infoq.cn/article/KCw3ZLsEJcNYFegzd7dx) / [安全防御](https://www.infoq.cn/article/MMh1pkuNSPDlUAtuRelk)

**数据层 RSI** — 量子位报道国内一支团队跑通了「AI 给自己出题」的数据层递归自我改进，思路是题库跟不上模型能力时让模型参与生成下一代训练数据。文章没给可复现的评测细节，当作方向读。→ [量子位](https://www.qbitai.com/2026/08/468782.html)

**JimuChatBI v1.0.0** — 开源对话式 Chat2BI，一句话生成报表和数据大屏，打包成独立 Spring Boot starter 可嵌入，兼容国产信创数据源，定位是帆软那类商业 BI 的开源替代。Java 栈要塞个自然语言查询进现有系统的话，这个集成方式比自己拼 LLM + SQL 省事。→ [开源中国](https://www.oschina.net/news/491587)

**阿里百炼个人版 token plan 踩坑记** — V2EX 一位用户吐槽 139 元周限 10000 credit 的套餐：预览版 qwen3.8max 被静默切成正式版调用后，同一个功能一下吃掉周额度 50% 以上，结果还做错了。单一用户体验不代表普遍情况，但「模型版本在你不知道的情况下被替换、计费口径跟着变」这个坑值得记一下。→ [V2EX](https://www.v2ex.com/t/1233208)
