## 📌 头条

### 张一鸣三次否决蒸馏，字节同步讨论 5 万亿参数模型

据 The Information 报道，张一鸣 7 月在 Seed 团队全员会上做出明确指令：禁止蒸馏任何外部模型，无论闭源还是开放权重。据知情人士透露，动机并非 TikTok 政治风险（该权重"几乎为零"），而是长远自主能力建设。与此同时，多家媒体报道字节正在讨论训练一个参数规模超 5 万亿的模型，超过阿里 Qwen3.8-Max 的 2.4 万亿和月之暗面 K3 的 2.8 万亿。两件事合在一起看，字节的策略很清晰：不走捷径，直接堆资源。

→ [开源中国报道](https://www.oschina.net/news/489199/bytedances-founder-rules-distillation-ai-models) / [Odaily 5万亿参数](https://www.odaily.news/en/newsflash/507328)

### 小米正式开源具身基座模型 Xiaomi-Robotics-1

8 月 5 日小米正式开源自研具身基座模型 Xiaomi-Robotics-1，基于超 10 万小时真实机器人操作轨迹预训练。在 RoboCasa365 上达到 57.6% 成功率（前 SOTA 46.6%），RoboDojo 得分 20.07（前 SOTA 13.07）。完整训练流程、部署工具和评测代码均已在 GitHub 公开。这是国内具身智能领域迄今最大规模的开源模型之一，小米在机器人赛道的投入正在兑现为可验证的技术成果。

→ [GitHub](https://github.com/XiaomiRobotics/Xiaomi-Robotics-1) / [arXiv 论文](https://arxiv.org/abs/2607.15330) / [开源中国](https://www.oschina.net/news/488953/xiaomi-robotics-1)

## ⚡ 快讯

- **DeepSeek**：以 150.8 元/股的价格认购宇树科技科创板 IPO 93.3 万股，投入约 1.41 亿元，锁定期 36 个月，双方将联合开发人形机器人 AI 模型。杭州双子星正式战略合体。 → [Reuters via Yahoo](https://finance.yahoo.com/technology/ai/articles/deepseek-invests-20-8-million-134424894.html)
- **蚂蚁集团**：正式开源多智能体协作基础设施 Avernet，首版聚焦 Agent 发现、共识、跨团队协作与治理能力，支持不同团队的 Agent 像组织一样协同工作。 → [量子位](https://www.qbitai.com/2026/08/467871.html)
- **PPIO**：发布 Fusion 融合模型，号称用十分之一价格超越顶级模型智商。路线和 OpenRouter Fusion 类似，通过多模型并行推理 + Judge 融合输出最佳答案。 → [量子位](https://www.qbitai.com/2026/08/467834.html)
- **腾讯**：开源 UCL-MPComm 通信库，针对 AI Memory 池化场景深度优化，将接入 Mooncake TENT，零拷贝传输性能提升 30%。 → [开源中国](https://www.oschina.net/news/488652)
- **千问 App**：推出定时任务、办公助理、语音通话等功能，同时上线最新旗舰模型 Qwen3.8-MAX。定时任务支持每天自动搜索行业新闻并生成趋势小结。 → [IT之家](https://www.ithome.com/0/986/849.htm)
- **光伏硅料**：八大多晶硅企业（合占国内有效产能超 90%）在上海签署反内卷倡议书，承诺产品售价不得低于团体标准核算成本，违者须立即纠正。 → [IT之家](https://www.ithome.com/0/986/836.htm)
- **全球半导体**：SIA 数据显示 2026 Q2 全球半导体销售额达 4033 亿美元，环比增 35.1%；6 月单月 1344.5 亿美元同比增 123.6%。SIA 预计 2026 全年将超 1.5 万亿美元。 → [SIA 官方](https://www.semiconductors.org/global-semiconductor-sales-increase-35-1-from-q1-2026-to-q2-2026/)
