## 📌 头条

### 阿里 Qwen3.8-27B 开源：一张消费级卡跑 Agent

8 月 14 日阿里 Qwen 团队放出 Qwen3.8-27B，27B dense、带原生视觉编码器、Apache-2.0，定位就是「一张卡装得下」的本地多模态模型。官方模型卡强调的是 agent execution——自主规划和处理环境反馈的端到端任务完成率，而不是单点跑分；量子位和多家海外评测把它跟 Claude Opus 级模型放在一起比，称其在 computer-use 类榜单上反超，这些对比属于第三方口径，官方公告没有背书。架构上第三方拆包称它用 Gated DeltaNet 线性注意力换掉了大部分注意力层，并把 attention output gate 融进 q_proj，这也解释了为什么社区反馈它对低比特量化比同尺寸模型更敏感（乘性门上的量化误差比加性投影更难忍）——想上 4bit 的话先在自己任务上验一遍。中国产业视角上，这是阿里继续用「开源密度」而不是「参数规模」抢开发者的一步：27B 这个档位正好卡在个人开发者和中小团队的自有硬件预算上。

→ [量子位](https://www.qbitai.com/2026/08/473669.html) / [模型卡](https://huggingface.co/Qwen/Qwen3.8-27B/blob/main/README.md) / [Ollama](https://ollama.com/library/qwen3.8:27b-q8_0)

### 智谱 GLM-5.3：不换底座，但权重被安全审查压住

同一天（8 月 14 日）智谱 Z.ai 发布 GLM-5.3，最反常的一点是它没有重新预训练——官方说法是沿用 GLM-5.2 的 MoE 底座（第三方报道给的参数量在 743B~744B 之间，口径略有差异），全部提升来自延长后训练：更多可执行环境、更长时程任务、更多 RL 算力。最抢眼的分数是网络安全基准 CyberGym 的 84.5%，多家外媒称其超过了 Anthropic 受限版模型。也正因为这个分数，权重发布被推迟做安全审查——各家报道口径不一致，有的写「open-weights 已发布」，有的写「weights staged / 延后两周」，官方公告并未明确日期，要下载的话别按已放出来规划。这件事的信号量大于跑分本身：国产开源模型第一次因为「攻击性能力太强」而主动踩自己的发布刹车，之前这类顾虑主要出现在美国实验室的叙事里。

→ [SiliconANGLE](https://siliconangle.com/2026/08/14/z-ai-debuts-glm-5-3-long-horizon-coding-cybersecurity-upgrades/) / [权重延后报道](https://www.implicator.ai/z-ai-delays-glm-5-3-weights-two-weeks-after-cyber-score-beats-mythos-5/)
