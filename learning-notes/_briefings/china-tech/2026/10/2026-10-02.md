## 📌 头条

### Manus 2.0 发布：给每个 Agent 配邮箱、手机号和钱包

中国出身、现落脚新加坡的 Manus（Butterfly Effect）9 月 28 日发布 Manus 2.0，换上名为 Cascade 的新架构，同时推出独立 App「Cue」——每个个人 Agent 拥有自己的邮箱、手机号、数字钱包和云电脑，能在用户设定的预算内自己发消息、付款、接电话并留下摘要。多家外媒报道其估值目标约 40 亿美元，官方微信也称正在组建团队做中国市场版本。给 Agent 配独立身份与支付能力，正是「让 LLM 不再只是聊天、而能代办真实事务」这条路的激进一步；对做 agent 编排的人，Cue 这种「每个 Agent 一套身份+钱包+预算约束」的产品形态值得拆开看它怎么处理授权和额度边界。

→ [TheNextWeb](https://thenextweb.com/news/manus-2-0-cue-ai-agents-email-phone-wallet) / [量子位报道](https://www.qbitai.com/2026/09/499592.html)

### 华为发布首个量产 NPO 光引擎 Hi-ONE，押注昇腾超节点

华为全联接大会公布自研光引擎 Hi-ONE，单颗带宽 7.2T，以 NPO（近封装光学）形态进入下一代昇腾 960 超节点。按官方口径，5500 颗 Hi-ONE 可替代约 4.8 万颗 800G 可插拔光模块，整体省电 550kW 以上。当英伟达、博通、台积电押注 CPO（共封装）时，华为选了把高速电连接压到约 5 厘米的 NPO 路线，试图在带宽、时延和可维护性之间找平衡。这是算力规模撞上互联瓶颈后的典型取舍——光互联正从可插拔模块向芯片侧迁移，阿里、腾讯据报道也在推 NPO，这条路线之争接下来会直接影响国产万卡集群的成本和能耗。

→ [雷峰网](https://www.leiphone.com/category/chips/kgknicdWxIIoulL9.html) / [华为官方](https://finance.yahoo.com/technology/ai/articles/huawei-unveils-industrys-first-npo-152800916.html)
