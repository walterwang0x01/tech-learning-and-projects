## 📌 头条

### 亚马逊云科技开源智能体「决策器」和「安全箱」

AWS 开源了两个面向 Agent 的组件：一个负责决策路由、一个做执行沙箱（隔离 Agent 的工具调用）。思路跟国内一众「把 Agent 装进企业」的产品撞线，但 InfoQ 这篇点出了还没解决的硬骨头——高并发下的调度和冷启动延迟。对国内做 Agent 平台的团队是个参照系：决策器 + 安全箱这套拆法已经是行业共识，真正的工程壁垒在并发和冷启动上，而不是又造一个框架。

→ [InfoQ](https://www.infoq.cn/article/YmgmEh686wTClmj3PY8o)

### 百度开源「文心 Unlimited OCR 2」，宣称任意页数文档解析

百度开源了文心 Unlimited OCR 2，卖点是号称全球首次做到不限页数的文档解析。配合量子位那条报道，这波国产 OCR 的竞争焦点已经从「识别准不准」转到「长文档怎么扛」——有报道提到 KV Cache 被压成常数、缓存砍掉约 96%，页数没上限。具体压缩口径和实测对比要以官方技术说明为准，但方向很清楚：OCR 开始按 Agent 处理长上下文的方式来做工程。

→ [开源中国](https://www.oschina.net/news/503269) / [量子位（KV Cache 相关）](https://www.qbitai.com/2026/10/505773.html)
