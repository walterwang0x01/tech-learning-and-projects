### 腾讯 WorkBuddy 全面开放架构，支持企业自建 Agent 网络

腾讯全球数字生态大会上，汤道生宣布以 WorkBuddy 为工作台的一体化套件 Buddy One 正式发布，腾讯云 Agent Runtime 和安全能力全面升级。更关键的是 WorkBuddy 将全面开放产品架构，既支持企业自研 Agent，也接入生态第三方 Agent，甚至第三方 IM 系统。官方口径是自今年 3 月上线以来已落地 50 多个行业、覆盖中国企业 500 强的 50%，开放平台伙伴和开发者超 5 万家、上架 Skills 超 20 万。对做 Agent 平台的团队来说，大厂开始把「企业自建 Agent 网络」当卖点，意味着竞争从单个 Agent 转向了编排和生态接入的能力。

### 国产 OCR 开源新王：KV Cache 压成常数，页数没上限

量子位报道一个新开源 OCR 模型，卖点是文档解析不限页数——把 KV Cache 压成常数、缓存砍掉约 96%，号称进入「OCR 3.0 时代」。这波国产 OCR 的竞争焦点已经从「识别准不准」转到「长文档怎么扛」，工程思路明显借鉴了 Agent 处理长上下文的缓存优化。具体压缩口径和实测对比以原报道和官方技术说明为准，但方向很清楚：长文档处理正在成为 OCR 的新战场。

→ [量子位](https://www.qbitai.com/2026/10/505773.html)
