## 📌 头条

### DeepSeek 又崩了，这次全额退了一周 API 钱

10 月 15 日 DeepSeek 的网页版和 API 从北京时间 8:11 一路挂到 13:04，这是三天内的第二次大规模故障。据雷峰网援引的统计，这已是它年内至少第 18 次大规模异常。真正少见的是善后姿态：官方把 10 月 8 日到 14 日这一整周的 API 消费按代金券全额返还，用量大的用户据报道最高拿到 3000 元。国内互联网服务主动退款到这个程度不多见。对你的意义很直接——如果线上业务只挂在单一国产模型 API 上，稳定性仍是真实风险，多供应商兜底（或本地部署小模型做降级）该提上日程了。

→ [雷峰早报](https://www.leiphone.com/category/zaobao/EReMkZNn9w5H85Tf.html) / [SCMP 报道](https://www.scmp.com/tech/big-tech/article/3371047/deepseek-offers-user-refunds-after-suffering-another-major-outage)

### 蚂蚁百灵开源新 Flash 模型（注意型号别搞混）

蚂蚁百灵（InclusionAI）本周继续放出 Ling 系列的 Flash 开源模型。这里有个事实要掰清楚：InfoQ 标题里的「560B」其实对应的是更新的 Ling-3.1-flash（560B 总参数、25B 激活、支持 100 万上下文），而官方 HuggingFace 卡片明确写的 Ling-3.0-flash 是 124B 总参数、5.1B 激活的混合推理 MoE——两个型号别当成一个。卖点都是「小激活、低成本跑复杂工作流」，InfoQ 给出的单任务成本说法是 0.19 美元。对做 Agent 的人来说，这类「总参大、激活小」的 MoE 正是国产开源想抢的推理性价比生态位，值得拉下来跑一轮自己的 benchmark 再下结论。

→ [InfoQ 报道](https://www.infoq.cn/article/SxQO3Aw6JCTgNMTGPPE8) / [官方模型卡 (3.0-flash)](https://huggingface.co/inclusionAI/Ling-3.0-flash) / [官方模型卡 (3.1-flash)](https://huggingface.co/inclusionAI/Ling-3.1-flash)
