### 谷歌开源 Harness²：让 agent 自己改自己的脚手架

谷歌 Cloud AI Research 开源了 Harness²，一个在 harness（agent 脚手架）层做递归自我改进（RSI）的框架，Apache 2.0 许可，明确支持 OpenCode 和 Codex。它的思路是：模型权重冻结不动，运行时让 agent 自动改写自己的系统提示词、记忆、技能库、工具规则和脚本插件——每遇到新任务就提出候选改动、跑一遍用执行结果打分、保留真正带来行为差异的那些。官方论文里给的数据是在一个法律 agent benchmark 上最高提升 11.8 分，有意思的是它用来当「编辑器」的模型是 Anthropic 的 Claude Opus 4.8。对你这种天天在 harness/MCP/技能库上折腾的人来说，这正好是「不换模型也能把 agent 调好」这条路线的一个公开参照；国内开发者接 Jev 实测反馈也说「真行」。量子位那篇还点了这个团队华人浓度很高。要落地先读 arXiv 预印本和仓库里那套「提议改动→测候选→合并」的回路设计。

→ [量子位报道](https://www.qbitai.com/2026/10/504184.html) / [InfoQ 国内实测](https://www.infoq.cn/article/AD1M3mJ2SH1dJrTA1r5q) / [arXiv 预印本](https://arxiv.org/html/2609.00006)

### 玄铁发布 E908A：首个同过 ASIL-B/D 的 RISC-V 车规 CPU IP

第六届 RISC-V 中国峰会 10 月 18-20 日在深圳开，阿里达摩院玄铁在会上首发车规产品路线图，核心是 E908A 处理器。据达摩院说法，这是首个同时满足 ASIL-B 和 ASIL-D 两档车规功能安全标准的 RISC-V CPU IP，单点安全指标 SPFM 超过 90%。放在中国产业语境里看，这是 RISC-V 从「IoT/嵌入式凑数量」往「车规、服务器这些高价值、高门槛场景」真正往上爬的一个信号——过去 T-Head 常被引用的「累计 25 亿颗」里绝大部分是嵌入式，服务器和车规才是硬骨头。峰会上 RISC-V 加速进入 AI 与高性能计算、国产服务器芯片 IP 也集中亮相。想追这条线的话，盯玄铁后续车规产品的量产客户落地比盯发布会 PPT 更有信息量。

→ [量子位报道](https://www.qbitai.com/2026/10/504238.html) / [InfoQ：RISC-V 加速进 AI/HPC](https://www.infoq.cn/article/J1Z3RYgH3Vyd9LFEfmlF)
