## 📌 头条

### 阶跃星辰开放 Step 5 Preview 权重，长程 Agent 卷到开源

阶跃星辰把 9 月 20 日上线 API 的旗舰 Step 5 Preview 权重开源了。这是个稀疏 MoE，总参约 600B、每 token 只激活约 27B，原生支持 100 万 token 上下文，在第三方 Artificial Analysis 智能指数上拿到 44 分——按 StepFun 自己的说法进了全球开源权重前三，仅次于闭源旗舰。它主打的不是聊天跑分而是「长时间自主干活」：官方放出的例子是让它不间断跑 24 小时、迭代 180 多轮去优化一个未调优的 Triton GPU kernel。对你做 LangGraph / 多步 Agent 的意义在于，一个能本地部署、单 token 成本极低的长上下文底座，正把「长程任务」的门槛往下压。注意权重走 FP8 checkpoint、显示约 650GB,本地部署前先按精度变体核清显存。

→ [InfoQ 报道](https://www.infoq.cn/article/EwqsJX6f03ODRac6Kk4c) / [HuggingFace](https://huggingface.co/stepfun-ai/Step-5-Preview-BF16)

### 蚂蚁百灵开源 Ling-3.1-flash，560B 跑进 1M 上下文

蚂蚁百灵（inclusionAI）开源了 Ling-3.1-flash，总参约 560B、每 token 激活约 25B，最高支持 100 万 token 上下文，是 Ling-3.0-flash 的升级版。Artificial Analysis 智能指数 41、输出速度约每秒 210 token。它特别做了本地部署的量化方案：routed experts 用 MXFP4、dense 层保持 block-FP8，权重占用从约 534GB 压到 292GB，对应 Hopper GPU 部署从 8 卡降到 4 卡——这是国产大模型把「能跑」的硬件账算到实处的一步。工具调用也强化了对 JSON Schema 的支持，接现有业务接口更顺。它和同期阶跃 Step 5 的开源一起，说明国内头部这一周集体在「长上下文 + Agent + 可本地部署」这条线上加码。

→ [IT之家](https://www.ithome.com/1/013/700.htm) / [HuggingFace](https://huggingface.co/inclusionAI/Ling-3.1-flash)
