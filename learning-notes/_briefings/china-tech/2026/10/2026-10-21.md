## 📌 头条

### DeepSeek 开源生产级推理框架 DeepInfer

DeepSeek 10 月 20 日在 X 上宣布开源 DeepInfer——它自称是「支撑 DeepSeek 大规模生产服务的高性能推理框架」，以 Apache 2.0 协议放上 GitHub，同时放出把 API 请求在 token 之间来回转换的 deepseek-recipe 组件。按官方口径，这套框架正是线上服务 DeepSeek V4.1-Flash 的那一套。国内媒体转述的「单集群日吞吐 155 万亿 Token、KVCache 可保存 7 天」属于性能宣称，官方公告没给复现条件，具体要等自己压测才算数。对你而言，这是继 DeepEP、FlashMLA 之后 DeepSeek 又一次把自家生产栈直接开源——如果你在本地或私有云跑大模型推理，这是比论文更实在的一手参考，值得 clone 下来看它的调度与 KV 管理实现。

→ [原文（InfoQ）](https://www.infoq.cn/article/NBXP966Bz3eqr6Qidvaf) / [SiliconAngle](https://siliconangle.com/2026/10/20/deepseek-open-sources-deepinfer-the-inference-framework-behind-its-production-services/)

### 小米 MiMo V2.5 今日下线，全量切 V2.6

小米 MiMo 文档宣布，mimo-v2.5-pro 与 mimo-v2.5 已于 10 月 21 日上午 10 点正式下线，此后请求自动路由到 mimo-v2.6-pro / mimo-v2.6-flash。换代后最大的变化是从纯文本输入升级为多模态理解：MiMo V2.6-Pro 是 1.02 万亿参数、42B 激活的稀疏 MoE，原生支持文本 / 图像 / 视频 / 音频，100 万 token 上下文，MIT 协议开源（9 月 22 日发布）。如果你的代码里还硬编码了 mimo-v2.5-pro 的调用，今天起会被静默改道——官方说 API 参数完全适配，但思考模式下的默认参数值有变动，接了 MiMo 的应用值得今天回归一遍。

→ [原文（IT之家）](https://www.ithome.com/1/015/709.htm) / [MiMo V2.6 模型页](https://mimo.mi.com/models/en-US/mimo-v2.6-pro)
