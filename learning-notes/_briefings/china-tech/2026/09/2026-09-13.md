## 📌 头条

### Kimi 突发 K2.8 Preview：百万上下文全员开放

9 月 11 日月之暗面在 Kimi Code / Kimi Work 全量上线 K2.8 Preview，官方称综合性能接近旗舰 K3，Coding 和 Agent 能力进一步提升，并支持 low/high/max 三档 reasoning effort、图片和视频输入。最实质的变化是权限：所有会员档位（含免费档）都能用上 1M 上下文，而 K3 的百万上下文此前需 199 元以上会员。这被外界看成月之暗面商业化的一步棋——据彭博社，其 ARR 8 月已破 10 亿美元、目标年底冲 20 亿，仅靠贵而重的 K3 难以撑起规模，需要一个单位成本更低、能大规模铺开的主力模型接力。注意官方本次没有公布任何 benchmark，「接近 K3」的具体程度未知；对你而言，若在 Agent 框架里用 Kimi，K2.8 无思考版会接管关闭 thinking 的 K3 请求，Model ID 保持不变，可无感切换试用。

→ [量子位报道](https://www.qbitai.com/2026/09/487688.html) / [Kimi Code 更新日志](https://www.kimi.com/code/docs/kimi-code/whats-new.html)

### 蚂蚁发布 APASS：给 Agent 建一套身份与信任基础设施

9 月 11 日外滩大会 AI 支付论坛上，蚂蚁集团发布面向智能体商业活动的信任基础设施 APASS，基于 KYA（Know Your Agent）理念，围绕「Agent 是谁、代表谁、被允许做什么、行为是否可信」提供身份注册、持续核验、意图安全和可信存证。它用静态身份 / 运行时身份 / 责任主体身份三层模型加六维持续核验，把传统的一次性「验 ID」延伸为贯穿交易前中后的持续信任。现场披露已接入超 100 万个 Agent、激活 11 万个，覆盖 442 家服务供给方；阿里、理想、联想、OPPO、小米、智谱、阶跃等 50 余家机构加入 IIFAA 智能体可信生态共建。对做 Agent 支付的人这条最值得盯：APASS 已在跟 Visa 智能体可信协议、Mastercard 可验证意图、Alipay+ AMP 对接搭 KYA 互联互通框架——这正是 Agent 代付需要的「授权 + 时间窗 + 可追溯」那层。

→ [雷峰网报道](https://www.leiphone.com/category/industrynews/gVe8AKc2ibKGewUO.html)
