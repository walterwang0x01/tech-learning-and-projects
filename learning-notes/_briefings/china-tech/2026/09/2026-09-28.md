## 📌 头条

### 七部门定调新型电池「十五五」：全固态 2030 规模化

工信部、发改委、交通运输部等七部门联合印发《新型电池产业发展「十五五」规划》，目标到 2030 年全固态电池初步实现规模化应用，长寿命锂电池循环寿命达到 15000 次，头部企业产品缺陷率进入 PPB（十亿分率）级别。规划明确以锂电池为主、钠电池和液流电池协同的产品体系，并把柔性/异形电池推向可穿戴、移动医疗，把电动化拓展到重卡、航空、内河船舶。对做电池材料、储能和新能源车供应链的团队来说，这份文件圈定了未来五年国家层面的资源投向和技术攻关方向，值得逐条对照自己所在环节。

### MiniMax M3.1-Flash-Preview 开公测，主打编码闭环

MiniMax 上线文本模型 M3.1-Flash-Preview 并开启公测。官方称它支持原生多模态和百万上下文窗口，能承接 Bug 修复、完整功能开发到回归测试的开发闭环，也可参与问题定位、代码实现和测试验证。需要注意的是，这一版本目前只在 MiniMax Code 内提供访问，官方没有放出 model card、benchmark 报告或独立定价，「快、可靠」都还是官方口径而非第三方实测。想验证它对 LangGraph/MCP 这类工作流的实际帮助，得自己在 MiniMax Code 里跑一遍再下结论。
