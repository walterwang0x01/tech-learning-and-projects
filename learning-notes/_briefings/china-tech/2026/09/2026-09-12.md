## 📌 头条

### 外滩大会：蚂蚁把 Agent 商业化押注在「信任」上

今年 2026 Inclusion·外滩大会主论坛，蚂蚁 CEO 韩歆毅抛出「智能体商业爆发前夜」的判断，配套动作一整套砸下来：面向 Agent 商业活动的信任基础设施 APASS（基于 Know Your Agent 理念，围绕「Agent 是谁、代表谁、被允许做什么、行为是否可信」提供身份注册与可信存证）、支付宝「一句话就能下单」的对话式商业入口、以及「碰一下」面向品牌商的经营智能体「图图」。这一串动作指向同一个赌注：当 Agent 从工具变成替人下单、付款的行动者，谁来验证它的身份和授权边界，就成了新的基础设施位。对做 Agent 的人来说，值得关注的是 APASS 想解决的正是支付/订单这类高风险写操作的授权链——身份与行为两条信任链的设计思路，和海外 AP2、ACP 那批 Agent 支付协议是同一战场。官方目前只给了框架，具体的授权令牌机制和 KYA 核验细节要等技术文档。

→ [APASS 发布](https://www.leiphone.com/category/industrynews/wH6gNreENqAYh0EW.html) / [韩歆毅谈商业入口](https://www.infoq.cn/article/EKC1INXeMjIo00JWMQdV) / [碰一下·图图](https://www.leiphone.com/category/industrynews/5OJHmXu4zqpsYkk3.html)

### 物理 AI 的中国路径：先跑出商业收入，再讲战略

同一周有两条无人配送车的消息值得连起来看。九识召开战略发布会，宣布重心转向「物理 AI 赋能城市治理」——按官方口径，其无人车规模已超 3 万辆、覆盖 300 余座城市、累计运营里程 2.5 亿公里，走的是「先让机器跑出商业收入、再宣布战略升级」的顺序。同期新石器在东京流通中心启动日本首个 L4 级封闭场地测试，首批车队 8 月底抵日、计划扩到 10 台，主打无需预建高精地图、号称建图部署成本最高降 90%。跟很多还停在 PPT 里讲「物理 AI」故事的公司相比，这两家的共同点是把落地跑量和数据飞轮放在叙事前面。里程和车队规模都来自公司自述，尚无第三方核验。

→ [九识战略发布](https://www.leiphone.com/category/transportation/JXhS5Joxp68qFEmE.html) / [新石器日本首测](https://www.leiphone.com/category/industrynews/iYgTdJzoP107I4qa.html)

## ⚡ 快讯

- **金融领域首个智能体安全标准**：北京金融科技产业联盟发布《智能体技术金融应用安全要求》团体标准，明确「双重授权」——第三方智能体操作金融 App 须同时获得用户与机构授权，未经授权不得自动化读取/操作金融应用 GUI。工行、银联、华为、蚂蚁、火山引擎、腾讯云等共同参与，背景是去年底某 AI 手机助手引发多家银行 App 登录/支付异常。 → [详情](https://www.leiphone.com/category/industrynews/tyenZtjsxcp3OzDb.html)
- **阿里云 Token Plan**：个人版升级，加量不加价，Standard/Pro 套餐新增 12 类 Agent Harness 工具（联网搜索、网页解析、代码解释器、语音、图像生成等），全部走 MCP 标准协议开放，可直接接入自有 Agent 应用无需逐项单独购买。对个人开发者是现成的 MCP 工具箱。 → [详情](https://www.leiphone.com/category/industrynews/IbRxUXgE35rsi98b.html)
- **支付宝「阿宝」生态**：携程、同程、锦江、大麦等酒旅出游头部商家集体接入支付宝对话式智能体「阿宝」，覆盖出行/住宿/周边游/演出四大场景；黄山、万岁山等景区也接入。支付宝同步推出智能体激励政策连接开发者与商家供给。 → [详情](https://www.leiphone.com/category/industrynews/DQPAnyOUCjOHfOfb.html)
- **微信 zero-click 蠕虫演示**：安全团队 Calif 公布名为 WeWorm 的演示蠕虫，声称是首个跨 iOS/Android、通过微信通话传播的 zero-click 蠕虫：拨一通电话即可接管账号并逐级扩散，用三部真机做了演示。目前仅为研究演示，尚未见野外利用，但攻击面值得关注。 → [详情](https://www.oschina.net/news/502420/wechat-worm-ai-calif-tencent-zero-click)
- **百度秒哒**：百度低代码/自然语言造应用平台「秒哒」再升级，把开发、交付和接单打通，主打「让最懂业务的人亲手造自己的系统」。是国产 vibe-coding / 无代码 Agent 方向的又一动作。 → [详情](https://www.qbitai.com/2026/09/487415.html)
- **证监会《期货公司监督管理办法》**：证监会发布修订后的《期货公司监督管理办法》，将业务分为基础类（经纪、交易咨询）与交易类（做市、资管、衍生品），完善设立变更与业务准入规范，并同步出台《实施公告》安排过渡。金融科技/量化相关业务需留意合规口径变化。 → [详情](https://www.36kr.com/newsflashes/3978961814977280)
- **摩尔线程解禁跌停**：国产 GPU 摩尔线程限售股解禁当日即跌停，钛媒体称是一场国产 GPU 的「反厄尔尼诺」现象。国产算力芯片的资本市场情绪与商业化兑现之间的落差再次显性化。 → [详情](https://www.tmtpost.com/8135737.html)
