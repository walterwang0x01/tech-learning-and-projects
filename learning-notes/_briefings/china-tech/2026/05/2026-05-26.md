## 📌 头条

### 华为发布「韬（τ）定律」，把摩尔从面积竞赛拉到时间维度

在 2026 国际电路与系统研讨会上，华为半导体业务部总裁何庭波正式提出「韬（τ）定律」，把半导体性能提升的逻辑从经典的「几何缩微」（每代制程把晶体管做得更小）转向「时间缩微」——靠网络、存储、封装、算力调度等环节协同压缩时延来兑现性能。这是中国厂商第一次在全球半导体领域抛出指导性原则，也是华为对「拿不到 EUV 仍要继续追算力」这条路给出的解释。配套消息是过去六年华为已用这条路径设计并量产 381 款芯片，今年秋季还将推出新一代麒麟手机芯片，外媒援引信源称单代性能提升约 30%。对国产产业链而言，韬定律真正的信号在于把价值重心明确推给互联、HBM 类存储、Chiplet 封装、CXL/光互联，以及面向推理的算力调度软件栈，国内做这些方向的公司今年的产业能见度会被明显抬高。

### DeepSeek V4-Pro 75% 折扣永久化，国产推理 API 进入「白菜价」常态

DeepSeek 官方账号 5 月 23 日宣布，V4-Pro 限时 25% 折扣到 5 月 31 日 UTC 15:59 后转为永久价，相当于 API 长期按原价四分之一收费。换算下来 V4-Pro 的 token 单价区间落到约 0.025~6 元/百万 tokens（约 $0.0035~$0.83），最低档比 GPT-4 类闭源 API 低一个数量级。DeepSeek 同期还在推进 70 亿元规模的新一轮融资。社区也在配合放大优势——量子位报道一款新缓存工具能把 V4-Pro 的命中率推到 99.82%，原本 4 亿+ tokens、61 美元的实际账单可以压到 12 美元。组合起来等于把「便宜的开源权重 + 便宜的官方 API + 极致缓存」打成一个全栈成本面，国内做 agent / RAG / coding 工具的团队，定价模型基本都得按 DeepSeek 这条线重算一遍——不是省一点钱，是有些原本必须在端上跑的功能现在能直接走云端 API。
