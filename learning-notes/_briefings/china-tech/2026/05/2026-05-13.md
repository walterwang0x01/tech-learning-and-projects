## 📌 头条

### 百度 Create2026：李彦宏提出 DAA 指标，DuMate 正式亮相

今天的 Create2026 百度 AI 开发者大会上，李彦宏抛出了一个新概念——DAA（Daily Active Agents，日活跃智能体数）。他认为 AI 时代的核心度量不再是 DAU，而是有多少智能体在替人干活。同时发布的 DuMate 是百度的 Agent 产品，集成了 AI 搜索、秒哒、伐谋等能力，定位"随身搭子"。这个信号很明确：百度把 Agent 当成下一个流量入口来做，而不只是一个功能模块。对做 Agent 开发的同学来说，百度的 Agent 生态（包括千帆平台）值得持续跟踪。

### 快手可灵 AI 拟分拆，估值 200 亿美元

据 The Information 报道，快手正计划将可灵（Kling）AI 视频业务独立分拆，目标 2027 Q1 启动 IPO，当前估值 200 亿美元。有意思的是，快手整体市值不到 300 亿美元——也就是说，市场认为一个单季收入 7500 万美元、尚未盈利的 AI 视频业务，价值是快手 7.4 亿月活短视频主业的两倍。这种估值"倒挂"折射出资本对 AI 生成式视频赛道的疯狂预期。对开发者而言，可灵的 API 和开放能力可能会随着独立融资加速开放。
