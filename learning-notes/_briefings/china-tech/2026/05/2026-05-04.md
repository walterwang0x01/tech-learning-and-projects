### 3. Cloudflare 推出 Code Mode MCP 服务器，优化 AI Agent 的 Token 使用

- **来源**：[Cloudflare推出Code Mode MCP服务器以优化AI智能体的Token使用](https://www.infoq.cn/article/KSmLVsumhdf7OiLXYaj3)
- **标签**：`Cloudflare` `MCP` `Token 优化` `AI Agent`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 5 = 总分 20
- **摘要**：Cloudflare 发布 Code Mode MCP 服务器，核心思路是让模型生成代码而非逐个调用工具——将多个操作压缩为一段代码，在 Dynamic Worker Loader 中安全执行。这种方式大幅减少上下文窗口占用和 token 消耗，是 Agent 成本优化的基础设施级方案。
- **影响**：与 DeepClaude 的"换模型降本"不同，Code Mode 从协议层面优化 token 使用，是更根本的解决方案。对构建 Agent 平台的团队有直接参考价值。
- **行动建议**：如果在 Cloudflare 上构建 Agent 应用，评估 Code Mode MCP 的集成方案；关注"代码即工具调用"的设计模式
