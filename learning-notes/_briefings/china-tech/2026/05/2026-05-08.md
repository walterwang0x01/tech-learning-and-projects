## 📌 头条

### Moonshot AI 20 亿融资落袋，估值 200 亿美元，开源权重赛道被重新定价

Kimi 背后的月之暗面刚完成约 20 亿美元融资，估值 200 亿，消息由参投的华峰资本确认。全球市场对开源权重模型的需求在过去两个月显著走高，Kimi 系列是中国厂商里吃到这波红利最直接的一个。与此同时，DeepSeek V4 系列（V4-Pro 1.6T/49B 活跃 + V4-Flash 284B/13B 活跃，均支持 1M token 上下文）已经在 HuggingFace 放出预览权重，用的是 Compressed Sparse Attention + Heavily Compressed Attention 混合方案，1M 上下文下推理 FLOPs 只要 V3.2 的 27%、KV Cache 只要 10%。开源中文权重这边，国产栈的长上下文能力正式脱离「能跑就行」阶段。如果你在选型自部署基线，V4-Flash 和 Kimi 新系列都该重新测一遍。

→ [Moonshot 融资](https://techcrunch.com/2026/05/07/chinas-moonshot-ai-raises-2b-at-20b-valuation-as-demand-for-open-source-ai-skyrockets/) / [DeepSeek V4](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash)

### 无问芯穹再融超 7 亿，清华系 AI Infra 再获数亿，Token 经济的基础设施层被反复砸钱

48 小时内国内 AI Infra 至少两笔大单落地：无问芯穹宣布完成新一轮超 7 亿元融资，CEO 夏立雪把打法总结成「以中国方案回答全球 Token 经济的核心命题」；清华系的一家 AI Infra 厂商也拿下数亿元融资，走「以 GPU 为核心重构计算机系统架构」的路线。这两笔都发生在黄仁勋强调「下一代 AI 基础设施需要大量光学连接，铜线已无法满足」的同一周。看懂信号的话，国内 Infra 层的核心卡位是「如何把 Token 单位成本打下来」，这是未来所有国产大模型 API 降价的前置条件。

→ [无问芯穹](https://www.infoq.cn/article/K1aiYMtOPSTswV999WZR) / [清华系 AI Infra](https://36kr.com/p/3799984046333186)
