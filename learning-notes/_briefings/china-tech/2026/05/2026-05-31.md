## 📌 头条

### 小米 MiMo API 永久降价最高 99%

继 DeepSeek 之后，小米成为又一家宣布 API「永久降价」的国产大模型厂商。MiMo-V2.5 系列从 5 月 27 日起全面下调价格，最高降幅达 99%，同时取消了按上下文长度区分定价的老做法，同样付费金额下可用 Token 量提到原来的 5~8 倍。这次小米还罕见地在技术博客里完整公开了降价背后的工程路径——KVCache 双池 + SWA-aware 前缀树、GCache 分布式缓存、KVCache 亲和调度、Decode 阶段 MTP 加速、多模态推理优化五大突破，靠 Hybrid SWA 架构把 KVCache 压到 Full Attention 的约 1/7，号称降价后仍能维持收支平衡。对开发者来说，这意味着国产长上下文推理的单价被又一次系统性打下来，跑多轮 Agent 工具调用的成本门槛进一步降低；但与此同时智谱却反向操作，Q1 累计涨价 83% 仍直言「供不应求、调用量涨了 400%」，国产模型的定价策略正在明显分化。

### MiniMax 启动 A 股 IPO，冲 A+H 双重上市

AI 独角兽 MiniMax 已与中信证券签署辅导协议，正式启动 A 股 IPO 进程。距它 1 月在港交所上市、首日大涨超 100% 才过去几个月，如今又转身冲刺 A 股，意在拿下 A+H 双重上市的资本结构。据公开信息，公司 ARR 已突破 3 亿美元。把这件事放进国内大模型的资本竞赛里看更有意思：智谱、MiniMax 接连完成港股上市，DeepSeek 拿下国家大基金领投的首轮融资，「AI 六小龙」正从拼模型能力转向拼资本耐力——谁能在持续烧钱的训练和算力投入里活得更久。对关注国产模型走向的人来说，MiniMax 选择回 A 股，也透露出这批公司越来越倾向于把融资和叙事锚定在境内资本市场。
