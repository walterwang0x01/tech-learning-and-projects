## 📌 头条

### 美团发 LongCat-2.5：1.6 万亿参数，押注长程 agent

11 月 2 日美团 LongCat 团队发布 LongCat-2.5，一款面向长程智能体任务的原生多模态 MoE 模型：总参数 1.6 万亿，每 token 约激活 480 亿，在 LongCat-2.0 基础上强化了原生视觉理解和 agent 编程能力。一家外卖公司拿出世界级规模的模型本身就够反常；雷峰网报道称它全程在国产算力上训练、是目前国产算力上完成的最大训练任务——这条产业信号比参数量更值得盯，但训练细节仍以官方后续技术披露为准。

→ [雷峰网报道](https://www.leiphone.com/category/industrynews/mUPVr3RF0MHNmn3t.html) / [模型概览(第三方)](https://www.unite.ai/longcat-2-5-debuts-with-1-6t-parameters-and-native-visual-tokens/)

### 小米 150 元开源 AI 小玩意火到配件涨价

量子位报道小米开源了一款 150 元的 AI 硬件，既能指挥 agent 干活、又能控制智能家居，热度高到配件都跟着涨价。低价+开源+能联动本地 agent 和智能家居，是国内把 agent 能力塞进消费级硬件的一个样本。具体型号与开源协议、能接哪些 agent 框架，建议看原文细读再判断能不能折腾。
