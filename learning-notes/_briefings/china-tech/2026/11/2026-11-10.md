## 📌 头条

### 蚂蚁灵波开源触觉基础模型 LingBot-Touch

据 IT之家，蚂蚁灵波科技今天开源触觉基础模型 LingBot-Touch，用近 5000 小时真实触觉数据预训练，目标是给机器人大脑补上「手感」这块感知短板。InfoQ 同日的标题把它描述为通用触觉模型，称其把触觉也做成了 Token，不过正文需点开原文，这里只能确认到标题层面。放在具身智能的脉络里看，视觉和语言已经有成熟的基础模型，触觉一直缺公开的预训练底座，开源之后做灵巧手和抓取的团队可以直接拿来微调，而不必从零采集触觉数据。具体的模型规模、接口和评测结果官方介绍里有更细信息，值得做具身方向的同学去仓库核对再决定是否接入。

→ [IT之家](https://www.ithome.com/1/024/701.htm) / [InfoQ](https://www.infoq.cn/article/W7VPoeNBPX4y2u72WAGM)

### 联想万全混合词元工厂落地张家口

联想今天在张家口发布万全混合词元工厂品牌，宣布国内首个「万全混合词元母本工厂」落地当地，并计划 2027 年建成 15000P 的异构算力集群，以张家口为起点布局全国的词元经济网络。「词元」就是 token，联想想把算力、模型和服务打包成按 token 计量的供给，这和云厂商卖推理 API 是同一条路，只是主打自建异构算力加线下落地。目前公开信息只有发布会层面的目标，集群规模是计划值而非已交付，定价与客户暂未披露，后续要看首批落地客户和实际 token 单价。

→ [IT之家](https://www.ithome.com/1/024/640.htm)
