## 📌 头条

### 腾讯开源云端自进化研发平台 LoopForge

开源中国报道，腾讯开源了 LoopForge，瞄准的是单机 Coding Agent 进团队后的问题：合盖断流、多人上下文割裂、Vibe Coding 质量失控、盯单耗时、同类坑反复踩。思路是把 agent 搬到云端，由平台承载团队协作与经验沉淀。原文我这边打不开，仅据站内摘要，具体架构和许可证待核。做团队级 agent 工作流的人值得看看它的仓库。

→ [开源中国](https://www.oschina.net/news/503437)

### 千问办公走进李佳琦直播间，半小时卖出 10 万份月卡

雷峰网称，11 月 2 日晚千问办公在李佳琦直播间上架 Token 算力，半小时售出 10 万份个人会员月卡，累计约 2 万亿 Token。同期千问办公与申通快递签约，用 Agent 能力支撑全国网点。Token 被当成“流量包”卖给个人，说明国内大模型已在抢消费端。数字来自单一媒体报道，口径以官方为准。
