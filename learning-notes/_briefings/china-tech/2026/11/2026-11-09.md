## 📌 头条

### 腾讯元器今日停服，智能体平台走向收口

据 IT之家，腾讯元器今天正式停止服务：应用访问、数据读写、API 调用和控制台都不再对公众开放，经元器发到公众号、微信客服等渠道的智能体也不再响应对话。10 月 29 日起平台已停止新建智能体和分发 API Key，数据导出申请只受理到 2027 年 1 月 9 日，之后除法规要求留存的日志外，用户数据将被删除。官方给出的替代是腾讯云智能体开发平台 ADP 和公众号智能回复。元器 2024 年 5 月发布时主打低门槛创建加全域分发，如今被收进云侧企业产品线，和雷峰网同日提到的腾讯 Agent 打法（WorkBuddy、Buddy One、ADP、ClawPro 面向企业）相互印证：通用智能体商店这条路在收缩，资源转向能接业务系统和数据的企业 Agent。如果你有挂在元器上的智能体，现在就该导出数据，并确认迁移到 ADP 的接口差异。

→ [IT之家](https://www.ithome.com/1/024/022.htm) / [雷峰网：腾讯的 Agent 布局](https://www.leiphone.com/category/industrynews/oxR5pn9S7tI1IfF5.html)

### 蚂蚁灵光 2.0 一周：用户破 2000 万

蚂蚁集团称，灵光 2.0 自 10 月 27 日上线一周，帮用户管理超 116 万项事务、执行超 360 万次任务，用户总数突破 2000 万。2.0 的变化是 AI 把介入点前移：用户授权后，它会结合已接入的信息与服务主动发现需求、发起监测和跟进，而不是等指令。官方同时提到接入蚂蚁 APASS，把身份认证、意图安全放进 Agent 执行流程，授权密钥与 Agent 分离托管，用户可随时撤销授权。这些数字都是蚂蚁自己披露的，没有第三方验证，且用户数与活跃度是两回事。值得看的是授权密钥与 Agent 分离这个设计，做自家 Agent 的权限模型时可以参考。

→ [IT之家](https://www.ithome.com/1/024/010.htm)
