## 📌 头条

### 美团龙猫发布 LongCat-2.5：1.6T 参数，专攻长程智能体

美团龙猫 11 月 2 日发布面向长程智能体任务的原生多模态模型 LongCat-2.5，总参数 1.6 万亿、每 token 激活约 480 亿（MoE）。相比 2.0 版，它强化了原生视觉理解和智能体编程能力：在长序列训练里加了更多长程轨迹数据、跑大规模长程强化学习，还把真实 Agent 的失败轨迹转化成训练信号，目标是能端到端扛住复杂代码库开发、完整项目构建这类活。据第三方资料，预览版支持 1M token 上下文、128K 输出，面向浏览器/终端/桌面的长程 agent 任务。对关注国产 coding agent 底座的人，这是继 DeepSeek Harness 之后又一个把「长程、多模态、agentic」写进训练目标的国产大模型。

→ [IT之家](https://www.ithome.com/1/020/873.htm)

### 英伟达 10 亿美元入股 Naver，跃居第三大股东

据韩国经济日报报道，韩国搜索门户 Naver 创始人李海珍以 10 亿美元交易引入英伟达并稀释自身持股，英伟达认购后将持有约 4.54% 股权，超越创始人升至第三大股东（前两席为机构投资者，第一为韩国国民年金公团）。这是英伟达加速全球 AI 布局的又一落子——把算力供应商的身份延伸成战略股东，绑定区域头部互联网公司。放在东亚科技竞争的盘面上看，韩国正同步加码自研大模型（李在明政府单列 4.6 万亿韩元押注自主顶尖模型），而英伟达则在上游用股权卡位。数字以原报道为准。
