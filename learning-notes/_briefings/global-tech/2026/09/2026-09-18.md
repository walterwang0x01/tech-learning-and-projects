### 英伟达正式押注 Rust 写 GPU 内核

英伟达把 Rust 抬进了 CUDA 的一等公民行列。它在 9 月 8 日以 NVlabs 名义开源了两个项目——cuda-oxide 走 SIMT 模型（自定义 rustc 后端，把 Rust 编到 GPU 汇编 PTX，目前仅支持 Linux），cutile-rs 走较新的 Tile 模型（可在稳定版 Rust 上用）。两者都直接编译到 PTX，底层不再套一层 C++。官方博客明确说不是二选一试水，而是要把 CUDA Rust 长期养到 2027 年及以后，和现有的 CUDA C++、CUDA Python 并列。对做推理引擎、驱动、Agent 运行时这类系统层的人，这意味着以后写 GPU 内核能直接吃到 Rust 的所有权和内存安全，不用再退回 C++。两个项目仍是早期研究软件，想上手可以先读官方的 cuda-oxide book。

→ [中文报道](https://www.oschina.net/news/502539/nvidia-cuda-rust-two-tracks-for-writing-gpu-kernels) / [cuda-oxide](https://github.com/NVlabs/cuda-oxide) / [cutile-rs](https://github.com/NVlabs/cutile-rs)

### ESLint 的护城河被 Rust 和 Go 合围

前端 lint 长期是 ESLint 一家独大，靠的是庞大的插件生态这道护城河。InfoQ 这篇分析指出，新一代用 Rust（如 Oxc、Biome）和 Go 写的工具正从性能一侧突破——同样一份代码，编译型语言的 linter 快出一个数量级。文章的判断是护城河正在被攻破，而不是已经攻破，插件兼容性仍是拦路的关键。对 TypeScript 项目来说，值得关注的是这些工具能否把 ESLint 插件生态迁过来，否则速度优势换不来实际采用。

→ [InfoQ 分析](https://www.infoq.cn/article/ymjJ9iJxHIU8iYpkPglp)
