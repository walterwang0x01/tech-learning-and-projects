### AMD 82 亿美元收购李飞飞的 World Labs

AMD 官方宣布以约 82 亿美元全股票收购李飞飞 2023 年联合创立的 World Labs，交易预计今年年底前完成（待监管审批）。这是 AMD 史上第二大收购，押注的是「物理 AI / 世界模型」——让 AI 理解真实三维世界，用于机器人、自动驾驶等具身场景。交易完成后李飞飞将出任 AMD 执行副总裁兼首席科学家，直接向 Lisa Su 汇报。对你意味着：GPU 大厂开始为「世界模型」这条新赛道抢技术和人，Nvidia 之外多了一个明确对手，物理 AI 的算力需求会成为下一轮竞争焦点。

→ [AMD 官方公告](https://newsroom.amd.com/news/amd-acquire-world-labs/) / [World Labs](https://www.worldlabs.ai/blog/amd-announcement) / [TechCrunch](https://techcrunch.com/2026/09/28/amd-will-acquire-fei-fei-lis-world-labs-for-8-2-billion/)

### Cloudflare 一周连发一整套「给 Agent 用」的开发栈

Cloudflare 在一周内密集开源了一批工具：Forge（在 CI 里从 API 定义生成 SDK/CLI/文档的流水线）、Vinext 1.0（把 Next.js 跑在 Vite 上，可部署到 Workers 免费版、Netlify、AWS Lambda，官方称构建快约 4 倍、客户端包小约 57%）、EmDash 1.0（面向 Astro 的开源 CMS，内置 MCP server）、以及公开的 BEACON 真实用户性能数据集。核心动机是官方给出的一个数据：今年 3 月 Agent 已占 Wrangler 用量的四分之一，上周达到 48%——所以它们推出了新 CLI `cf`，专为 Agent 设计（内建命令搜索、JSON 默认输出、TypeScript 配置）。InfoQ 把这套东西称作「智能体开发栈生命周期，取代传统 SDLC」。对你意味着：如果你在用 LangGraph/MCP 搭 Agent，Cloudflare 正在把整条工具链往「Agent 是一等公民」的方向重写，值得盯。

→ [Vinext 1.0](https://blog.cloudflare.com/vinext-nextjs-on-vite/) / [Forge](https://blog.cloudflare.com/forge-open-source-generation-pipeline/) / [EmDash 1.0](https://blog.cloudflare.com/emdash-cms-plugin-registry/) / [InfoQ 解读](https://www.infoq.cn/article/OooAe7xY816xAdLrkv8V)
