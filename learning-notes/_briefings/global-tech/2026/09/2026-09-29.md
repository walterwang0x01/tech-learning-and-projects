## 📌 头条

### AMD 82 亿美元收购李飞飞 World Labs，押注「物理 AI」

AMD 宣布以约 82 亿美元全股票收购李飞飞（Fei-Fei Li）2024 年创立的 World Labs，交易预计年底前完成、待监管审批。这是 AMD 史上第二大收购，官方定位在「物理世界 AI / 世界模型」这条线上——用于理解和模拟真实世界，指向机器人、自动驾驶等具身智能场景，而非纯语言模型。李飞飞将以执行副总裁兼首席科学家身份加入 AMD。对做 Agent 的人来说值得留意的信号是：算力厂商开始直接买下世界模型团队，把「感知-推理-行动」的物理侧能力收进自己的栈里，未来 Agent 的可用底座可能不再只有云上大模型。

→ [AMD 官方公告](https://newsroom.amd.com/news/amd-acquire-world-labs/) / [TechCrunch](https://techcrunch.com/2026/09/28/amd-will-acquire-fei-fei-lis-world-labs-for-8-2-billion) / [World Labs 声明](https://www.worldlabs.ai/blog/amd-announcement)

### Meta 推企业 AI 平台，挖走 MongoDB CEO 掌舵

Meta 正式成立面向企业客户的新业务单元 Meta Enterprise Platform，并挖来 MongoDB 现任 CEO Chirantan「CJ」Desai 出任负责人（chief enterprise platform officer）。注意主角是 CJ Desai，不是老 CEO——Desai 2025 年 11 月才从执掌 11 年的 Dev Ittycheria 手里接棒，如今出走，MongoDB 董事会临时把 Ittycheria 请回来代理 CEO。消息一出 MongoDB 股价当日大跌约 18%。Meta 说会把 Muse、Meta Business Agent、Muse API、Muse Code 等整套技术栈推给企业和开发者。对开发者的意味是：大厂 To B 的 AI 平台之争又多一家重量级玩家，接入方选型时可以观望 Muse API 的定价与开放度。

→ [TechCrunch](https://techcrunch.com/2026/09/28/meta-launches-enterprise-ai-platform-hires-mongodb-ceo-to-lead-new-initiative) / [CNBC](https://www.cnbc.com/2026/09/28/mongodb-meta-cj-desai.html)
