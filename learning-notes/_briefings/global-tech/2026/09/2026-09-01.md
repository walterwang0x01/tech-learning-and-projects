## 📌 头条

### Cloudflare 推 Adaptive Intelligence，直接打击爬虫的经济账

Cloudflare 发布 Adaptive Intelligence，思路是从「静态确定性规则」转向动态自适应检测，专门瓦解 bot 运营方的经济优势——过去它们靠廉价代理和不断改造工具绕过固定规则，成本低到划算。新做法要把「绕过检测」的成本抬到不划算。对做爬虫防护或反过来做数据采集的人，这意味着以前那套「换 IP + 改 UA」的低成本套路会明显失效，得重新评估自动化访问策略。

→ [Cloudflare Blog](https://blog.cloudflare.com/introducing-adaptive-intelligence)

---

### Kubernetes v1.37 发布：存储版本迁移默认开启并 GA

Kubernetes v1.37 里 Storage Version Migration（SVM）毕业到 GA 并默认启用。SVM 解决的是一个长期痛点：当 API 对象的存储版本变更时，过去需要手动重写 etcd 里的既有对象，否则会残留旧版本编码。现在这套迁移能力默认托管，集群升级时的存储一致性负担明显减轻。运维 K8s 的人升级前值得读一遍 release note，确认默认开启不会与你的自定义存储策略冲突。

→ [Kubernetes Blog](https://kubernetes.io/blog/2026/08/31/kubernetes-v1-37-storage-version-migration-ga)
