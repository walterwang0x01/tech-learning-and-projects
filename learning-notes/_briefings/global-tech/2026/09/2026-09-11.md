## 📌 头条

### Rust 在微软升为 Tier-1 语言

Rust Foundation 刊发了一篇来自微软 DevDiv 的客座博文：Rust 已在微软内部拿到 Tier-1 级别的工程支持，与 C++、C#、TypeScript 同列。按博文的说法，这意味着 Rust 有了从本地开发到生产部署的完整「铺平路径」——安全的工具链构建、配套开发者工具、质量工作流、深度平台集成，以及符合 SDL 安全开发生命周期的要求。对写 Python/TypeScript 为主的你，信号在于：Rust 不再只是尝鲜选择，一线大厂已把它当作可长期投入的主力语言来供养，性能敏感或安全敏感的模块选型时值得认真列进候选。

→ [Rust Foundation 原文](https://rustfoundation.org/media/guest-post-rust-is-tier-1-language-at-microsoft) / [中文报道](https://www.oschina.net/news/502414/rust-is-tier-1-language-at-microsoft)

### Shopify 从 React Native 退回原生开发

Shopify 宣布把旗下所有移动应用从 React Native 迁回原生：iOS 用 Swift、Android 用 Kotlin。首款应用 Shop 已在 AI 辅助下用 12 周从概念验证走到发布，旗舰的 Shopify 应用（300+ 屏、桌面/锁屏小组件、Apple Watch、Siri 捷径）正在重写，计划年内发布。这是 2020 年那次「全面押注 RN」决策的公开反转，官方给的理由是原生体验与平台能力的深度整合，值得注意的还有那句「12 周重写」——他们把 AI 辅助重写当成了这次迁移可行的前提。如果你也在跨平台 vs 原生之间犹豫，这是一个来自重度 RN 用户的第一手复盘。

→ [中文报道](https://www.oschina.net/news/502416/shopify-engineering-back-to-native) / [HN 讨论](https://news.ycombinator.com/item?id=49643546)
