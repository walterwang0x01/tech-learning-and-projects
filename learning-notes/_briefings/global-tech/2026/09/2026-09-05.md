## 📌 头条

### Chrome 又一个在野利用的 V8 零日

谷歌紧急修复 CVE-2026-85046，一个 V8 引擎里的类型混淆漏洞，CVSS 8.8，已经在野被利用。攻击者只要让你打开一个精心构造的网页，JS 就能在 Chrome 沙箱渲染进程里读写内存乃至执行代码。这是 2026 年第六个被在野利用的 Chrome 零日，CISA 已把它加进「已知被利用漏洞」清单。凡是基于 Chromium 的东西（Edge、各类 Electron 应用）都在波及范围。修复版本是 Chrome 152.0.7977.82/.83，赶紧把浏览器更到最新。

→ [CISA KEV](https://nvd.nist.gov/vuln/detail/cve-2026-85046) / [The Hacker News](https://thehackernews.com/2026/09/google-releases-chrome-update-to-patch.html)

### React Compiler 的 Rust 原生版进了 Vite

前端工具链彻底 Rust 化的又一步：React Compiler 被移植成 Rust 实现，现在能在 Vite 的 plugin-react 里用 compiler: true 直接开启，不再需要走 Babel。配合 Vite 8 的 Rolldown/OXC 工具链，构建和 lint 环节都能明显提速（oxlint 侧报告 lint 快 3 倍以上）。不过官方口径需要注意：React 团队说 Compiler 核心仍会以 JavaScript 为主，Rust 目前是原生封装/加速层，不是把整套编译器改写成 Rust。用 TypeScript/React 的话可以关注这条演进线，实测收益再决定切换。

→ [原文](https://blog.master.dev/react-now-rusted-all-the-way-out)
