## 📌 头条

### GitHub 用三年把官网从 CSS-in-JS 迁到 CSS Modules

GitHub 在工程博客复盘了一场持续三年的迁移：把 github.com 整套 UI 从 CSS-in-JS（styled-components、styled-system、sx props）全面搬到 CSS Modules，到 2026 年 6 月网站已 100% 跑在 CSS Modules 上。起因是 Primer 设计系统在组件数量爆炸后，运行时 CSS-in-JS 带来的性能开销拖慢了页面，静态 CSS 能把样式在构建期算好、去掉运行时代价。对做前端架构的人，这是一份少见的大规模、真实业务下的技术债偿还案例：值得读它怎么分阶段推进、怎么在不停机的前提下删掉旧方案，而不是只记住「CSS-in-JS 慢」这个结论。

→ [开源中国](https://www.oschina.net/news/502761/github-improving-site-performance-by-shipping-more-css)
