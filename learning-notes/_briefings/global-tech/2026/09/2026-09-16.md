## 📌 头条

### CPython 官方支持 RISC-V，纳入 Tier 3 平台

Python 核心团队宣布 RISC-V 正式进入 CPython 支持文档 PEP 11，作为 Tier 3 平台。贡献者在真实物理硬件上跑了几个月测试、修架构特有缺陷、加固构建基础设施才达成。Tier 3 意味着平台仍可能偶尔出故障、不会因此卡住核心版本发布，但拿到上游官方支持，等于扫掉了长期以来把 RISC-V 接进 CI/CD 流水线的一大障碍。团队下一步想推到 Tier 2，并研究利用向量扩展、位操作等特性优化解释器性能。如果你手上有兼容开发板，官方明确在征集反馈。

→ [InfoQ 中文](https://www.infoq.cn/article/ipaJ5VXPgUiMFmaAgAEG) / [原文](https://www.infoq.com/news/2026/09/riscv-cpython/)

### K8s v1.37：Pod 级资源管理器进入 Beta

Kubernetes v1.37 把 Pod-Level Resource Managers 升到 Beta（默认关闭，需用 PodLevelResourceManagers feature gate 手动开启）。它让 Kubelet 的 Topology / CPU / Memory Manager 直接读 Pod 级的 .spec.resources 做硬件放置决策。以前给延迟敏感应用要独占 NUMA 对齐的核，只能给 Pod 里每个容器都设整数 request，日志/telemetry 这类轻量 sidecar 白占物理核。现在可以混合分配：主容器拿独占 NUMA 核，sidecar 丢进 Pod 隔离的共享池。v1 PodResources gRPC 也新增了顶层 cpu_ids 和 memory 字段，监控工具能直接查 Pod 级独占分配、不再重复计数。

→ [K8s 官方博客](https://kubernetes.io/blog/2026/09/15/kubernetes-v1-37-pod-level-resource-managers-beta)
