## 📌 头条

### GitHub 用 Copilot 把 Copilot 运行时重写成 80 万行 Rust

GitHub 工程团队发文，讲了他们如何把 Copilot 的 agent 运行时迁移到 80 万行生产级 Rust 代码。原文最直白的一句是「这种规模的重写在 agent 出现之前根本负担不起」——真正的新意不在于选了 Rust，而在于把大规模改写这件事本身交给了编码 agent 来做，人只负责把关。对你意味着：这是一次大厂用自家 AI 编码工具啃下超大迁移的一手案例，Walter 关注的 Rust + agent 工具链正好在这条线上，值得读它对哪些环节人还必须接管、哪些环节交给了模型。

→ [原文](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot)

### 伊朗袭击致亚马逊中东数据中心永久丢失客户数据

据《华尔街日报》与 Ars Technica 报道，伊朗对亚马逊中东设施的军事打击造成部分客户数据永久无法恢复，AWS 官方承认这类物理损毁超出了其服务设计的承受范围。这不是一次常规宕机——它把「多可用区就够了吗」这个问题推到了台面：当整栋设施被摧毁，没有跨区域冗余的数据就真的没了。对你意味着：如果关键数据只落在单一区域，这就是最直接的反例，跨区域备份和灾备策略该重新过一遍了。（多源报道，具体丢失范围以 AWS 口径为准）

→ [WSJ (HN)](https://news.ycombinator.com/item?id=49719249) / [Ars Technica](https://arstechnica.com/gadgets/2026/09/iran-strikes-on-amazon-data-centers-caused-permanent-loss-of-customer-data)
