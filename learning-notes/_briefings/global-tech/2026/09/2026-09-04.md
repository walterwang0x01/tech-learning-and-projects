## 📌 头条

### Kubernetes 1.37 发布，DRA 动态资源分配正式转 GA

Kubernetes 1.37（代号 Garhwal）在 8 月底发布，动态资源分配（DRA）里的 Extended Resource 支持连续打磨三个版本后终于转为 GA，另有多项特性升到 Beta/GA。DRA 的核心价值是让调度器按需把 GPU、专用硬件这类异构资源精确分配给 Pod，正好对上现在越来越多的 AI / 机器学习跨节点大负载。如果你在用 K8s 跑训练或推理，这一版是值得排期升级的节点——GA 意味着 API 稳定、可以进生产。

→ [DRA 更新官方详解](https://kubernetes.io/blog/2026/09/03/kubernetes-v1-37-dra-updates) / [CloudNativeNow 解读](https://cloudnativenow.com/features/kubernetes-v1-37-enhances-dynamic-resource-allocation/)

### Audacity 4.0 发布，两年重写界面迁到 Qt

老牌开源音频编辑器 Audacity 花了两年多把整个界面从 wxWidgets 迁到 Qt6，4.0.0 正式版发布，HN 上冲到 1000+ 分。这不只是换皮：带来了原生高 DPI 渲染、浅色/深色/高对比度主题、可保存的 Workspace 布局，以及重做的 clip 编辑模型（clip 可重叠、可分组移动、非破坏性裁剪能恢复）。代价是砍掉了 Sync-Lock、旧绘制模式等老功能，MIDI 轨道也被移除，重度用户升级前要留意工作流变化。

→ [GitHub Release](https://github.com/audacity/audacity/releases/tag/Audacity-4.0.0) / [The Register 报道](https://www.theregister.com/personal-tech/2026/09/03/audacity-audio-editing-app-no-longer-looks-like-its-from-the-early-2000s/5294270)
