### Git 2.55-rc0 发布，Rust 默认启用

Git 2.55 候选版最大变化：Rust 支持从 opt-in 变为默认启用。此前开发者需通过 Meson 或 Makefile 的 WITH_RUST 标志手动开启，现在开箱即用。这是 Git 项目引入 Rust 以来的里程碑——从实验走向生产默认。用户仍可按需禁用。同时 Git 3.0（带 SHA-256）预计年底发布，两个大版本叠加将重塑 Git 内部架构。

→ [Phoronix](https://www.phoronix.com/news/Git-2.55-rc0-Released) / [开源中国](https://www.oschina.net/news/457283/git-2-55-rc0)
