## 📌 头条

### Miasma 蠕虫入侵 73 个微软 GitHub 仓库

6月5日，自复制蠕虫 Miasma 在 105 秒内感染了微软 Azure、Azure-Samples、Microsoft、MicrosoftDocs 四个 GitHub 组织下的 73 个仓库，向 AI 编程工具注入凭证窃取恶意软件。GitHub 紧急下线受影响仓库，微软已恢复部分项目但仍在调查中。这是近年最严重的开源供应链攻击之一——如果你用到 Azure Functions 相关包，务必检查依赖完整性。

→ [The Hacker News](https://thehackernews.com/2026/06/miasma-worm-hits-73-microsoft-github.html) / [TechCrunch](https://techcrunch.com/2026/06/08/microsofts-open-source-tools-were-hacked-to-steal-passwords-of-ai-developers)

---

### Let's Encrypt 禁止在美国制裁地区使用证书

Let's Encrypt 更新用户协议 v1.7，明确禁止在任何美国制裁地区使用其签发的证书。HN 上引发 275+ 评论热议，核心争议在于免费 CA 将合规义务转嫁给终端用户是否合理，以及这是否会推动制裁地区转向自签或其他 CA。对运营跨境服务的开发者来说值得留意。

→ [协议变更 PDF](https://letsencrypt.org/documents/LE-SA-v1.7-June-04-2026-diff.pdf)

- **Gooey**：用纯 Zig 编写的 GPU 加速跨平台 UI 框架亮相，支持 macOS Metal、Linux Vulkan/Wayland 和 WebAssembly/WebGPU，填补 Zig 社区 GUI 空白。 → [GitHub](https://github.com/duanebester/gooey)
- **Meta**：从 Meta AI 智能眼镜 app 中移除人脸识别代码（此前被 WIRED 曝光），同时缩减追踪员工键鼠行为训练 AI 的内部计划。 → [WIRED](https://www.wired.com/story/meta-removes-face-recognition-code-meta-ai-app-smart-glasses)
