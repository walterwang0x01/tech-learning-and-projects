### Valve Steam Machine 正式发售，$1,049 起步

Valve 的 Steam Machine 今天正式发布，512GB 版本 $1,049，2TB 版本 $1,349。这是 Valve 继 Steam Deck 后推出的客厅游戏主机，性能接近 PS5，采用 SteamOS 3.8，支持用户自行组装。Valve 没有补贴硬件，坦言 2026 全球 RAM 短缺让元件谈判异常艰难。HN 讨论量超过 1200 条。同时 Valve 宣布 SteamOS 3.8 开放桌面安装，任何人都能用自己的 PC 零件搭建 Steam Machine。

→ [Steam 官方页面](https://store.steampowered.com/news/group/45479024/view/685257114654870245) / [The Verge 详细评测](https://www.theverge.com/games/953411/valve-steamos-desktop-nvidia)

### AWS Lambda 推出 MicroVMs：VM 级隔离的新 Serverless 原语

AWS 发布了全新的计算原语 Lambda MicroVMs——每个沙箱拥有独立内核，无共享资源，毫秒级启动，支持状态保持长达 8 小时，完全无需管理基础设施。这是 Serverless 从"函数即服务"向"安全沙箱即服务"演进的重要一步，对需要长时运行、强隔离的工作负载（如 AI Agent 运行时）意义重大。

→ [AWS 官方博客](https://aws.amazon.com/blogs/aws/run-isolated-sandboxes-with-full-lifecycle-control-aws-lambda-introduces-microvms)
