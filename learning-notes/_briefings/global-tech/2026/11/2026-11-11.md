## 📌 头条

### AWS 推出 Nitro Sandboxes，覆盖 EKS、ECS、EC2

AWS 在 What's New 中宣布 Nitro Sandboxes 可用于 EKS、ECS 和 EC2。官方页面的细节有限，具体隔离模型与定价请以文档为准。同日 Vercel 的 Rauch 称新一代模型能承担大规模并行工作，需要云沙箱才能发挥，二者放在一起看，是 Agent 时代沙箱基础设施在升温。

→ [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/nitro-sandboxes-eks-ecs-ec2) / [Rauch 的帖子](https://x.com/rauchg/status/2119878364794372162)

### DeepMind 用 AI 工具形式化验证 Signal 协议

据 Wired 报道，DeepMind 研究人员借助新的 AI 工具，形式化验证了 Signal 协议按预期工作，并把「验证全世界软件」当作远期目标。目标是否可达还不好说，但把形式化验证交给 AI，对安全关键代码是个值得跟踪的方向。HN 上同日 AlphaProof Code 热度很高（约 584 分）。

→ [Wired](https://www.wired.com/story/a-new-ai-tool-from-google-deepmind-formally-verified-the-signal-protocol) / [AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code)
