## 📌 头条

### PHP 与 Ruby 同期爆出可致代码执行的漏洞

Cloudflare 称 phpAfterShell 是 PHP 默认 session 处理器里的严重缺陷，可导致代码执行；ruby2shell（CVE-2026-132825）可让攻击者在默认 Rails 和 Sinatra 应用中破坏内存且无需登录。Cloudflare WAF 对所有客户（含免费版）默认拦截。WAF 只是补缺口，该升级的还是要升：Ruby 修复版本为 4.0.10、3.4.13、3.3.14。

→ [phpAfterShell](https://blog.cloudflare.com/phpaftershell-waf-protection) / [ruby2shell](https://blog.cloudflare.com/ruby2shell-waf-protection)

### PHP 8.6 发布，引入部分函数应用

PHP 8.6 于 11 月 19 日发布，头号特性是部分函数应用：先给一部分参数，用占位符留出其余位置，返回 Closure，等剩余参数到齐再调用。官方一句话总结是更快、更安全、更强大，具体性能数字未见一手基准。

→ [开源中国](https://www.oschina.net/news/503695/php-8-6)
