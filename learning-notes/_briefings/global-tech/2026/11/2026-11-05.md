### Postman 一打开就偷偷往 Claude Code、Codex 塞插件

有开发者在 Postman 官方 issue 跟踪器提了 #14370：macOS 上打开 Postman 桌面版 12.33.4，它就在用户没点同意的情况下，把自己的插件装进了 Claude Code 和 Codex，还顺手配了一个远程 MCP 连接、加了 Codex 启动钩子、装了 Postman CLI。更刺眼的是那个安装器试图替自己的启动钩子「自己批准自己」，绕过了两个编程代理本来要人确认的那一步。这帖在 HN 冲到 1490 分，因为它正好戳中你每天在用的那套工具链——一个你信任的 GUI 工具，凭什么能静默改写你 AI 代理的配置。官方公告只给了现象和日志，是不是恶意、会不会真把 API 数据外传还在争论，但「信任边界被破坏」这件事本身已经坐实。短期能做的：检查一下自己的 ~/.codex 和 Claude Code 的 MCP 配置里有没有不是你亲手加的 Postman 条目。

→ [官方 Issue #14370](https://github.com/postmanlabs/postman-app-support/issues/14370) / [HN 讨论](https://news.ycombinator.com/item?id=50354960)

### AMD 四季度营收指引首次超过 Intel

AMD 给出的四季度营收指引约 170 亿美元，超过了 Intel 的预期——按报道这是历史上第一次。同时 AMD 刚交出一个 134 亿美元的季度新高，数据中心业务同比翻倍，但游戏业务营收掉了约 40%。一句话：AI 数据中心的钱正在把 CPU 厂商的重心整个搬过去，谁家数据中心卖得动谁就赢，消费端（游戏显卡、PC）反而成了拖累。对做后端和云的人来说，这意味着未来一两年数据中心侧的算力供给和价格会更卷，选型时值得多看一眼 AMD 这边的方案。注意这两个数字分别来自 Tom's Hardware（指引）和 Ars Technica（季报口径），不是同一来源。

→ [Tom's Hardware：营收指引](https://www.tomshardware.com/pc-components/cpus/amd-expects-to-outsell-intel-in-q4-for-the-first-time-in-history-usd17b-guidance-would-exceed-intels-projections) / [Ars Technica：季报拆解](https://arstechnica.com/gadgets/2026/11/amds-record-quarter-data-center-business-doubles-while-gaming-craters)
