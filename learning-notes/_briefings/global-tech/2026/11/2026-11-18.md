## 📌 头条

### GitHub 与微软：开源维护者要的是修复，不是更多 AI 报告

GitHub 在 Codename MDASH 试点中，把数千条原始 AI 发现整理成 99 份经过核验的私密报告并附修复建议，覆盖六个被广泛使用的开源项目，维护者已修复超过一半。这是 GitHub 官方博客的说法。思路是先核验再附修复，减轻维护者被低质量 AI 报告淹没的负担。

→ [GitHub Blog](https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes)

### 英伟达财报会：董事会不打算让黄仁勋复任

英伟达在 Q3 财报会上，新任董事长 Harvey Jones 表示董事会一致接受了黄仁勋的辞呈，不打算让他复任 CEO，并称不会就辞职情形回答提问。临时 CEO 为 Colette Kress，财报本身开场未提此事。
