### AWS 开源 Rust 写的本地模拟器 AWS Emulator

AWS 发布免费开源的本地模拟器 AWS Emulator，用 Rust 实现，官方称可以在本地对近乎所有 AWS 服务测试应用。AWS CTO 同日发文《AWS Emulator and the engineer's job when agents write the code》，把它放在「Agent 写代码」的背景下讨论，言下之意是让 Agent 有一个便宜、可重复的沙箱去试错。对写 Lambda、S3、DynamoDB 应用的人，值得拉下来跑一遍现有集成测试，看覆盖度和 LocalStack 之类方案比起来如何；「几乎所有服务」是官方说法，具体差距要自己验证。

→ [AWS 博客](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator) / [GitHub](https://github.com/aws/aws-emulator) / [Werner Vogels 文章](https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html)
