## 📌 头条

### Cloudflare 发布 AI 写的 TypeScript 编译器 tsrs

Cloudflare 与 VoidZero 推出 tsrs，TypeScript 编译器的 Rust 移植版，Apache-2.0 开源。作者 Max Schwenk 说自己没写代码，而是指挥以 Claude Opus 5.5 为核心的 agent，用 TypeScript 的 15197 个一致性测试当规格。官方称类型检查最快提速 8 倍、内存降约 70%。但有人拿 TypeScript 7.1 beta 对比，提速缩到 2.7 倍；另有开发者发现错误退出码是 2 而 tsc 是 1，可能悄悄弄坏 CI。项目仍属实验阶段，没有 watch 模式和语言服务器。想试的话 npx tsrs -p . --noEmit，先别换进 CI。

→ [InfoQ 报道](https://www.infoq.cn/article/lGoA1ZSw6ojeh68GVlBl)

### OpenSSH “sshole”：超长密码可绕过登录

开源中国报道，musl libc 里一个潜伏十四年的漏洞，让输入超过 256 个字符的任意密码就能登上本不该登录的账号，包括 root。发现者是 Özgün Kültekin。我只读到站内摘要，影响条件（昨天的简报称需 musl 加 PAM 关闭）以 Alpine 公告为准。用 Alpine 或 musl 系镜像的，先查 sshd 版本。

→ [开源中国](https://www.oschina.net/news/503439/openssh-sshhole)
