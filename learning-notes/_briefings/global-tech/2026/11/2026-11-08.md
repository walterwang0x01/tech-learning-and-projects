## 📌 头条

### Cloudflare 探索后量子匿名凭证

Cloudflare 指出，Privacy Pass 仍依赖 RSA 和椭圆曲线密码；未来足够强的量子计算机可能伪造令牌并绕过限流，但令牌签发与使用之间的不可关联性不会因此消失。团队正在研究把 VOLE-in-the-Head 与 UOV 等多变量密码方案组合成盲签名，供下一代 MOLE 匿名凭证使用。其当前估算里，PoMFRIT 的 UOV 版本展示约 4.3KB，候选 MOLE 方案的使用证明约 6.5KB 至 12KB，不过 46.6KB 公钥和仍在变化的安全参数说明它离生产部署还有距离。值得注意的不是某个算法名字，而是后量子迁移已经从 TLS 扩展到匿名令牌，协议和系统都要为更大的密钥、签名与证明重新设计。

→ [Cloudflare 原文](https://blog.cloudflare.com/vole-mole/) / [PoMFRIT 论文](https://eprint.iacr.org/2026/109)

### Asahi Linux 7.3：M3 支持转正

Asahi Linux 的 Linux 7.3 进展报告宣布，M3 系列支持已移除 EXPERT 标记，DCP 支持还带来了睡眠能力和刘海区域可用性。M4 Pro、M4 Max 与 M5 有了可启动到 TTY 的初始设备树，Thunderbolt 也开始向用户提供，但目前只支持 USB3、XDomain 和 Thunderbolt Networking，常见扩展坞所需的 PCIe 与 DisplayPort 隧道仍未完成。团队还用 Android 的 P3S 思路让部分 x86 Windows 游戏脱离虚拟机运行，不过因为实现写死页大小且上游方向未定，明确表示暂不下发。项目同时宣布开始把仓库迁往 GPLv2 或更高版本；这是一份把硬件逆向、主线合入、兼容性边界和开源许可变化都说清楚的进展报告。

→ [Asahi Linux 原文](https://asahilinux.org/2026/11/progress-report-7-3/)

## ⚡ 快讯

- **Parcel 3 alpha**：打包器核心被重写成不依赖 Node.js 的单个 Rust 二进制；官方在 React Spectrum 三类冷构建中测得 29 至 108 倍提速、内存降至原来的约 1/2.5 至 1/6.6，但 `.d.ts` 生成和编程式 JavaScript API 等仍未完成，适合并行试用而不是直接替换生产链路 → [官方发布](https://v3.parceljs.org/blog/v3-alpha)
- **GitHub PR Overview**：新的 opt-in 公开预览把合并状态、检查、审批和下一步动作放到页面顶部，还能只看未解决对话或按最新评论排序；长 PR 不必再滚到底部才知道卡在哪里 → [GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/)
- **GoLand 2026.3**：除新的 Agent 工作区外，这版能把本地运行配置复制到 Git worktree，直接连接远程项目，并在 Kubernetes Pod 中浏览、创建和编辑文件；做并行分支与远程开发的人会更直接受益 → [JetBrains 发布说明](https://blog.jetbrains.com/go/2026/11/05/goland-2026-3-is-now-available/)
- **Underground 2 Revived**：开发者把《Need for Speed: Underground 2》的 PC 版代码重新编译到 Chrome 与 Firefox，网页支持宽屏、在线比赛和多类控制器，并称最高可到 120 fps；这是老游戏移植到现代浏览器的一次有趣工程展示 → [在线项目](https://nfsu2.xyz/)
- **Discord 原生客户端**：Discord 正在内测以 Rust 和 GPUI 重做的桌面客户端；CTO 演示中的早期版本同时登录两个账户时占用约 290MB，并比 Electron 版更快冷启动，但尚无同机同负载的正式基准，也没有公开发布日期 → [演示与采访整理](https://www.windowslatest.com/2026/11/06/every-windows-11-app-should-kill-electron-and-discord-just-showed-why-no-starting-screen-and-70-less-ram-even-with-two-accounts-signed-in/)
- **Microsoft 与 Oracle 云容量合作**：Reuters 转述 Bloomberg 称，Microsoft 没有续签 Oracle 的 AI 算力租用合同，并在逐步停用相关容量；这是匿名消息源报道，双方尚未用正式公告确认，但它显示超大规模客户开始重新审视外部云容量组合 → [Reuters](https://www.reuters.com/business/microsoft-is-winding-down-oracle-deal-rent-ai-cloud-capacity-bloomberg-news-2026-11-06/)
- **Fox 完成收购 Roku**：Fox 完成价值 220 亿美元的 Roku 收购，获得覆盖超过 1 亿家庭的流媒体入口；“美国第三大电视业务”是 Fox 对合并后收视规模的表述，后续更值得观察 Roku 的开放平台和广告业务会怎样变化 → [Fox 公告](https://www.foxcorporation.com/news/corp-press-releases/2026/fox-corporation-completes-acquisition-of-roku/) / [TechCrunch](https://techcrunch.com/2026/11/06/fox-completes-its-22b-acquisition-of-roku/)

## 🔒 安全动态

- **ARTEX 控制台暴露**：Censys 在 11 月 4 日观测到 1465 台公开 ARTEX 主机；剔除两批高度同构的托管节点后约有 815 个不同部署，且 32 个开放目录暴露后渗透工具。并非每个实例都用于恶意活动，但这类控制台没有公网开放的必要。→ [Censys 研究](https://censys.com/blog/artex-agentic-asbestos/)
- **Node.js 11 月安全更新预告**：Node.js 项目将在 11 月 11 日为 22.x、24.x、26.x 发布最高等级为 HIGH 的修复，并提醒 EOL 版本在安全发布时默认视为受影响；使用这些分支的团队可先留出升级窗口。→ [官方预告](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)
