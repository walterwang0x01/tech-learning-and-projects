## 📌 头条

### Java4Shell：OpenJDK Base64 解码器内存损坏漏洞

Calif 安全团队披露 OpenJDK Base64 解码器中的内存损坏漏洞，编号 CVE-2026-114938，代号 Java4Shell，Cloudflare 称其可导致远程代码执行。Java 的卖点之一是内存安全，但运行时自身有大量 C/C++ 与汇编实现，问题就出在这一层。Cloudflare 已为付费计划上线六条 WAF 托管规则，默认只记录匹配请求不拦截，并建议立即升级 Java 运行时。动作很具体：盘一遍线上 JDK 版本，等补丁就位尽快升级，WAF 规则只能当临时缓冲。

→ [Cloudflare](https://blog.cloudflare.com/java4shell-waf-protection) / [开源中国](https://www.oschina.net/news/503646/java4shell-write-once-rce-everywhere)

### Nginx HTTP/2 存在未认证远程代码执行漏洞

Wiz 披露 Nginx 的 HTTP/2 相关漏洞，涉及 CVE-2026-123633 和 CVE-2026-123007，标题称可未认证远程代码执行。该帖在 Hacker News 上拿到 1284 分，热度很高。具体受影响版本和修复版本要以 Wiz 与 Nginx 官方公告为准，这里只有标题级信息。如果你的入口层开着 HTTP/2，先查版本、关注官方补丁。

→ [Wiz](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)
