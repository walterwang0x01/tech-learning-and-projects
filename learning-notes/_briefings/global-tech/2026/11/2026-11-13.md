## 📌 头条

### .NET 11 发布，C# 15 随行

.NET 11 在 11 月 10 日正式发布。它是 STS（标准支持）版本，支持期两年，不是 LTS，要长期支持仍然选 .NET 10。开源中国的解读文章认为值得看的是 C# 15 的几处实打实变化，标题称它补上了缺了二十年的东西，具体语言特性请看原文。升级建议：生产环境留在 .NET 10，个人项目和库作者可以先在 CI 里加一个 .NET 11 矩阵，提前发现不兼容。

→ [开源中国](https://www.oschina.net/news/503542/microsoft-announcing-dotnet-11)

### Agent 正在重塑 Pull Request？

InfoQ 中文站转述了一个讨论：当 agent 产出的代码越来越多，传统的 Pull Request 流程是否还合适，连 GitHub 自己也在重新审视。摘要没有展开方案。GitHub 官方博客同日给了一个可操作的方向：把可重复的工程工作写成团队可评审、可复用的 agent skills 文件，一次编写，在不同 agent 上运行。想试的话，先把团队里最常重复的评审清单写成一个 skill。

→ [InfoQ](https://www.infoq.cn/article/x0B056QFxzYEewT1Et34) / [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills)
