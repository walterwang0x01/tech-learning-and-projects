### GitHub 在微软治下打的是「保命战」：故障 / 被黑 / 人才流失三杀

The Verge 周日发了一篇近半年最尖锐的 GitHub 检视，把 5 月的内部仓库被盗（3800+ repos / TeamPCP）、Notepad 都集成 Copilot 这种产品方向漂移、前 CEO Thomas Dohmke 离任后的领导真空、外加 Cursor / Claude Code 抢走默认开发者心智，串成一条「被微软买下八年后正在被掏空」的因果链。少数派同步报道补刀：内部技术债和工程师持续外流，让 Azure 化迁移（GitHub 被要求 7 月前把 50% 流量迁到 Azure）撞上熟练运维的真空期，故障可能还会继续。CNBC 的解读最毒——微软原本是 enterprise AI coding 默认赢家，结果被自己的可用性问题拖到反向送客。

对工程组织里的我们三点直接影响：第一，把关键 CI / 自动化对 GitHub Actions 的硬依赖列入风险清单，准备好 GitLab CI / Forgejo Actions 之类后备路径，最起码把 self-hosted runner 起一个；第二，PAT 全部转 fine-grained 短租期 token，配 1Password / Bitwarden CLI 自动轮换，别让长期 token 在 TeamPCP 后续行动里被打开第二轮；第三，重新评估 Copilot 续约——Anthropic Claude Code、Cursor、Codeium 这一两个月都在抢企业单，价格谈判窗口正在最大处。

### SpaceX 招股书曝 Musk 能源矛盾：xAI 加 28 亿气电、SpaceX 押注太空太阳能

SpaceX S-1 里出现了一段会让 Tesla 投资人皱眉的披露：xAI 计划再花 28 亿美元采购天然气涡轮机为 AI 数据中心供电，Southaven 现场已经在跑 27 台无空气许可证的涡轮，Earthjustice 已经起诉。同一份文件里 SpaceX 又花重笔描绘「太空太阳能」远景——轨道阵列收到的能量是地面的五倍。这把 Musk 自己 2006 年第一版 Tesla Master Plan 的「solar electric economy」打成了过去时：地面光伏给 Tesla 卖、地面 AI 训练用化石燃料、太空才搞光伏。TechCrunch 的 take 很直白——这是 Musk 在「先把 AI 算力建出来」和「能源转型叙事」之间彻底选了前者。

短期对你的判断有用的是：AI 数据中心的电力瓶颈到了「燃机比电网快」的临界点。OpenAI / Anthropic / xAI 都在抢气电机组和燃机产能，2026 下半年北美 GE / Siemens 燃机交付排产已经溢出到 2028。如果你在做相关基础设施 / 能源 SaaS / 排放数据产品的方向，今年的窗口期就是燃机过量部署带来的环境合规反扑。
