## 📌 头条

### AWS MCP 服务器 GA：把 IAM 权限模型搬进了 Agent 工具调用

AWS 把 MCP（Model Context Protocol）服务器从预览推到了正式可用，全面适配现有 AWS API，并把 IAM 权限控制叠进了协议层——也就是说 Agent 现在调一个 AWS 工具，鉴权走的还是熟悉那套 IAM 策略和角色，而不是再造一套权限。对所有用 LangGraph、CrewAI 或自研编排器接 AWS 的人来说，这是把 MCP 从「玩具协议」变成「企业级集成」的关键一步。再叠加同一周 arXiv 上多篇讨论 MCP 信任与污染攻击的论文，方向已经很明确：协议层会越来越像传统 RPC，鉴权、审计、配额一个都跑不掉。

→ [InfoQ 中文](https://www.infoq.cn/article/4gwXqyRPs4RTUIMpRte7) / [MCP 安全研究](https://arxiv.org/abs/2605.24248)

### Starlette 高危漏洞 BadHost：3.25 亿次周下载的 Python 底座炸了

Ars Technica 报道，Starlette 被发现一枚被命名为 BadHost 的高危漏洞，影响数百万部署在生产里的 AI Agent。Starlette 周下载量 3.25 亿，是 FastAPI 的底层依赖，绝大多数 Python 写的 Agent 服务都跑在它上面。这意味着：如果你用 FastAPI + LangGraph / FastAPI + 自研 Agent，今天就该去 pip 锁版本、查 CVE、走灰度。这一波也把「AI Agent 供应链」这个新攻击面正式摆到了台前——比起模型本身，吃掉你的更可能是依赖图里某个被忽视的中间件。

→ [Ars Technica](https://arstechnica.com/information-technology/2026/05/millions-of-ai-agents-imperiled-by-critical-vulnerability-in-open-source-package)
