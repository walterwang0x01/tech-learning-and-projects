## 📌 头条

### NGINX Rift：18 年老漏洞被 AI 一脚踢出，CVSS 9.2

NGINX 1.30.1 紧急发布，修复 `ngx_http_rewrite_module` 中潜伏 18 年的堆缓冲区溢出（CVE-2026-42945，CVSS 4.0 评分 9.2）。漏洞由安全初创 DepthFirst 用 LLM 驱动的代码扫描平台发现，6 小时扫描捕到 5 个安全问题，未认证攻击者通过构造 HTTP 请求即可触发 DoS 甚至 RCE。受影响版本横跨 0.6.27 到 1.30.0，几乎是全球部署最广的 Web 服务器全员中招。配合 `rewrite + set` 指令的 API 网关配置最危险，PoC 已公开。这件事的另一层信号是：AI agent 第一次在大型成熟开源项目里挖出了高价值的内存安全漏洞，过去靠人工审计和模糊测试 18 年没碰到的角落，被 LLM 用几小时跑了出来。把生产环境的 nginx 升级到 1.30.1 不要拖。

→ [The Hacker News](https://thehackernews.com/2026/05/18-year-old-nginx-rewrite-module-flaw.html) / [DepthFirst 研究报告](https://depthfirst.com/research/nginx-rift-achieving-nginx-rce-via-an-18-year-old-vulnerability) / [开源中国](https://www.oschina.net/news/440530/nginx-1-30-1-released)

### Bun 全量 Rust 重写已合并主线，96 万行代码 6 天搞定

Bun 创始人 Jarred Sumner 把 PR #30412 合并进了主分支，将 Bun 从 Zig 完整移植到 Rust——大约 96 万行代码，由 Claude Code 在 6 天内生成。重写通过了 Bun 现有全部测试（99.8% pass rate），修复了若干内存泄漏与 flaky test，二进制体积缩小 3–8 MB，基准测试持平到略快。HN 上 479 分、577 条讨论吵成一团，焦点是这种规模的 AI 辅助语言迁移到底是工程奇迹还是技术债埋雷。从已合并的事实看，这是迄今为止最大规模的 AI 主导生产级语言移植案例，给 Rust 重写浪潮（之前 TypeScript 移植到 Go、Cursor 重写编辑器内核）又加了一注。如果你在用 Bun，关注 v1.4 版本动向，下个版本就会基于 Rust 实现发布。

→ [PR #30412](https://github.com/oven-sh/bun/pull/30412) / [The Register](https://www.theregister.com/devops/2026/05/14/anthropics-bun-rust-rewrite-merged-at-speed-of-ai/5240381) / [HN 讨论](https://news.ycombinator.com/item?id=48132488)
