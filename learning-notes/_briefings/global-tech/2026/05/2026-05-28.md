### Cognition 拿 10 亿美元，估值九个月翻 2.5 倍至 260 亿

做出 Devin 的 Cognition 又融了一轮：Lux Capital、General Catalyst、8VC 联合领投，总额超过 10 亿美元，pre-money 估值 250 亿、post-money 260 亿，比去年九月那轮 102 亿翻了一倍多。更关键的是收入数字——12 个月里 ARR 从 3700 万冲到 4.92 亿，自家代码 90% 由 Devin 自己写，客户名单上有 Goldman Sachs、Mercedes-Benz 和美国政府。这一笔意味着 AI 编码 Agent 已经从「实验项目」进入「企业 IT 预算项」的新阶段，对在做 LangGraph / 自研编码 Agent 的团队来说，估值天花板和差异化路径都得重画。

### CrowdStrike 联手 Google 端掉 GlassWorm：一次开发者供应链反击

5 月 26 日 14:00 UTC，CrowdStrike、Google 和 Shadowserver 同时切断 GlassWorm 僵尸网络的全部四条 C2 通道，正式宣告这一长达半年、专门吃开发者的蠕虫被打掉。GlassWorm 干的事情是把恶意代码塞进 npm / VS Code 扩展 / GitHub 仓库，再从开发者机器顺藤摸出 GitHub Token、云密钥和源码，把上游污染层层下推。它和上周的 Starlette BadHost 形成同一条主线：攻击者已经放弃打产品，转而打写产品的人。如果你在维护开源包或跑构建管道，今天就得复盘一遍 token 权限、CI runner 隔离和 IDE 扩展白名单。

→ [CrowdStrike 博客](https://www.crowdstrike.com/en-us/blog/inside-crowdstrike-takedown-of-a-developer-targeting-botnet/) / [TechCrunch](https://techcrunch.com/2026/05/27/crowdstrike-and-google-take-down-botnet-used-by-hackers-to-target-software-developers-in-supply-chain-attacks/) / [The Register](https://www.theregister.com/cyber-crime/2026/05/27/crowdstrike-google-shatter-glassworm-botnet/5247337)
