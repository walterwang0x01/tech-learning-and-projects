### AV2 开放视频标准定稿，五年磨一剑要给 AV1 接班

经过五年、两千七百多次提交的打磨，开放媒体联盟（AOMedia）正式放出 AV2 的最终 v1.0 规范，参考编码器 AVM 也同步打到 1.0.0。这是继 AV1 之后的下一代免专利费视频编码标准，官方与早期评测口径都指向「同画质下相比 AV1 最多省约 40% 带宽」。免授权这一点才是真正的杀伤力——它直面的是 H.266/VVC 那套层层叠叠的专利池，Netflix、YouTube、各家流媒体一旦能省下编码授权费，AV2 的落地动力就远比技术参数更硬。规范定稿只是起跑线，接下来要盯的是硬件解码（GPU、手机 SoC）什么时候跟上，软件编码器的速度能不能从「能用」做到「好用」。

→ [AV2 规范官网](https://av2.aomedia.org) / [HN 讨论](https://news.ycombinator.com/item?id=48340910) / [VideoCardz：AVM 1.0.0](https://videocardz.com/newz/aomedias-av2-encoder-gets-first-1-0-0-release)

### GitHub Copilot 6/1 改按 token 计费，开发者成本一夜暴涨

从 6 月 1 日起，GitHub Copilot 把沿用已久的固定订阅制换成按 token 用量计费的「AI Credits」模式，开发者社区直接炸锅。Reddit 和 X 上吐槽不断：有人原本月付约 29 美元，新规下预估飙到近 750 美元；更夸张的截图显示从 50 美元涨到 3000 美元。这不是孤例——同期有报道称微软内部用 Claude Code、Uber 等公司都在四个月内烧穿了全年 AI 预算，整个行业正从「包月随便用」滑向「每行生成都计费」。对个人开发者和小团队来说，这意味着要么精打细算控制上下文，要么回头比较 Cursor、Cline 这类自带模型选择、计费更透明的方案。本周可以趁机算一笔账：你现在的日均 token 消耗，换算到新价上到底是涨还是降。
