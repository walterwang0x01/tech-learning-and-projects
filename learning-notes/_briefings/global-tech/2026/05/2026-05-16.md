### Apple 五年百亿美元砌的 M5 内核护城河，被 Anthropic Mythos 五天打穿

越南安全团队 Calif 公开了 macOS 26.4.1（M5 裸机）上的首个 kernel 内存破坏漏洞利用链——从普通用户起步，靠正常系统调用拿 root shell，一路绕过 Apple 五年磨一剑、宣称耗资约 50 亿美元打造的 Memory Integrity Enforcement（MIE）硬件防护。两个 bug 串联加几个数据流污染技巧，整套 PoC 五天写完。研究团队反复强调一句：所有重活都是 Anthropic 在四月小范围放出的 Mythos Preview 干的——一个还没正式发布、被 Anthropic 形容为「surfacing unknown vulns / building working exploits」的模型变体。Apple 五年防御 vs AI 五天进攻，这是一次对称破裂。同一周 Google Project Zero 也公布了 Pixel 10 的零点击根权限链（Dolby 解码 → kernel），AI 攻防的杠杆开始压向进攻方。开发同侧的人能做的具体动作：把内核级别威胁建模重新审一遍，假设漏洞从发现到 PoC 的窗口只剩几天。

### 微软撤掉 Claude Code 许可：太好用反成生态威胁

The Verge 的 Tom Warren 爆料，微软正在大规模收回内部 Claude Code 许可，要求数千名 Experiences + Devices 部门工程师在 6 月 30 日（财年结束）前切换到 GitHub Copilot CLI。微软内部最初让产品经理、设计师、工程师试用 Claude Code 是为了让"非工程岗也能写点东西"，结果它在过去半年里太受欢迎——Windows、Microsoft 365、Outlook、Teams、Surface 团队都在用。讽刺的是这次撤许可不是因为 Claude Code 不好用，而是因为它太好用——既贵（按 token 烧 Anthropic 的钱）又战略别扭（用着竞争对手的产品对外推 Copilot 不好讲）。这件事的真正信号在于：大厂自家 AI 工具的"内部接受度"正成为产品力指标，Copilot 卖给客户之前先要赢回自家工程师。如果你在评估编码 agent 选型，这是一份很难得的内部用户票决。

→ [The Verge 原报道](https://www.theverge.com/tech/930447/microsoft-claude-code-discontinued-notepad) / [开源中国](https://my.oschina.net/u/4487475/blog/19669675) / [TechRadar 跟进](https://www.techradar.com/pro/microsoft-may-discontinue-claude-code-internally-as-it-looks-to-push-users-towards-github-copilot)
