### 微软封禁安全研究员、扬言刑事追责，0-day 披露之争白热化

一位化名 Nightmare-Eclipse（又称 Chaotic Eclipse）的研究员连续披露了六个未修复的 Windows 漏洞并附上可用的 PoC 利用代码，微软随即封禁了其 GitHub 账号（GitHub 归微软所有）、删除了它用于报告漏洞的 Microsoft 账户，逼得对方转到 GitLab，新账号又被封。事情迅速升级：微软公开谴责这种「未协调」的披露，并威胁要走法律程序甚至报警，而 CISA 与微软都确认其中三个漏洞（BlueHammer、RedSun、UnDefend）在 PoC 公开后已被攻击者在野利用。整个安全社区为此炸锅——一边是「厂商不修就只能公开施压」的老问题，一边是「把利用代码塞进坏人手里永远不可接受」的反驳，负责任披露这套机制再一次被推到台前拷问。对任何维护 Windows 侧软件供应链的团队来说，这周需要盯紧这几个漏洞的补丁节奏。

### SpaceX 上市前夕：政府合同狂揽，投资者却开始用脚投票

距离 IPO 推介只剩一周多，SpaceX 一边在政府订单上高歌猛进——本周拿下 64.5 亿美元 Space Force 发射合同（其 2025 年约五分之一营收来自政府），外加 41.6 亿美元为特朗普「Golden Dome」防御系统造导弹预警卫星——一边却在资本市场遭遇逆风：丹麦一家养老基金以「公司治理与估值」为由把 SpaceX 从投资组合中剔除，HN 上这条讨论冲到 300 多分。The Verge 更直接把这份 S-1 招股书类比当年的 WeWork，警告散户可能成为接盘方。一个公司同时是国防基建的事实垄断者、又被机构投资者公开质疑治理，这种张力在 IPO 前夕尤其值得关注——它定价的不只是火箭，更是「太空 + AI」叙事还能撑多高。
