### AWS MCP Server GA 上线，云厂商开始争夺 "AI Agent 的默认入口"

AWS 今天正式 GA 了 **AWS MCP Server**——一个托管的远程 Model Context Protocol 服务器，让 Claude Code、Cursor、Codex 之类的 coding agent 通过统一鉴权直达全线 AWS 服务（S3、EC2、Lambda、RDS 等）。官方把它定位为 Agent Toolkit for AWS 的核心，同时配套推出 Skills 和插件库。这是继 OpenAI、Anthropic、Google 之后，**第一家大云厂商把 MCP 升级到 GA**——意味着 MCP 从"Anthropic 牵头的开放协议"变成了云生态的事实标配。叠加 Google Cloud 刚发布的 reCAPTCHA 下一代 Fraud Defense（HN 211 分）和 Cloudflare 的 .de TLD 应急响应，云厂商在 Agent 基础设施层的争夺已经正面开打。如果你在构建和 AWS 交互的 Agent，今天就该把自建的 AWS SDK wrapper 替换成官方 MCP Server，节省长期维护成本。

→ [AWS 公告](https://aws.amazon.com/blogs/aws/the-aws-mcp-server-is-now-generally-available/) / [Google Cloud Fraud Defense](https://cloud.google.com/blog/products/identity-security/introducing-google-cloud-fraud-defense-the-next-evolution-of-recaptcha/) / [Cloudflare .de 应急](https://blog.cloudflare.com/de-tld-outage-dnssec/)
