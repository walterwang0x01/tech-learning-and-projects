### TeamPCP 攻破 GitHub 内部，3800 个仓库被盗、CVSS 9.4

GitHub 周二（5/19）确认其内部代码库遭入侵，攻击者 TeamPCP 通过一个被植入恶意代码的 VS Code 扩展（Nx Console 仿冒版）拿下了某员工开发机，进而横向移动到内部 GitLab/构建系统，最终拿走 3800+ 个内部仓库——TeamPCP 自己说接近 4000，且已经在地下论坛挂牌出售，起价 5 万美元。CVE 编号 CVE-2026-33634，CVSS 9.4。GitHub 已轮换关键 secret，但安全研究员 ramimac 整理的时间线显示，这是 TeamPCP 数周来跨 npm、PyPI、Docker Hub、GitHub Actions、OpenVSX、Jenkins 的一波连锁攻击的最新一站，已知受害者还包括 Trivy、Checkmarx KICS、LiteLLM、Bitwarden、TanStack、Mistral AI 等。

这件事的杀伤力在于「攻击面已经从源代码包扩到了开发者的本地编辑器」。VS Code/OpenVSX 的扩展安装量级和审核机制远不如 npm/PyPI，但拿到的权限是开发机本机——一旦中招，员工的 GitHub token、AWS profile、SSH key、kubeconfig 全部暴露。GitHub 自己被打穿，等于给所有仍在「我装一个流行的 AI 扩展、没事吧」的工程师上了一节最硬的课。今晚就该做的两件事：在企业层用 OpenVSX-Allowlist 或 Code Server policy 锁住能装的 VS Code 扩展白名单，在个人机用 1Password CLI / GitHub fine-grained token + 短期租约把长 token 全替换掉。GitHub 的 secret 轮换里就漂着不少长期 PAT，TeamPCP 的下一步十有八九是拿这些去打它的客户。

### SpaceX Starship V3 首飞：上面级达成大部分目标，Booster 在墨西哥湾 RUD

5/22 晚 Starbase，SpaceX 在前一晚地面塔架问题中止后第二次尝试，成功把史上最高、推力最强的火箭 Starship V3 第 12 次试飞送上天。Ship 39 上面级在丢失 6 台主发动机中的 1 台后仍以 5 台推进器到达预定亚轨道速度并按计划在印度洋溅落，Block 3 隔热瓦、抓回 Sphere 的箭体硬点、星链分发模拟门都过了。Super Heavy 一级则没那么走运：33 台 Raptor 中的 1 台在升空时关停，分离后 Boost-Back 点火序列异常，箭体后段被破坏，最后未受控坠入墨西哥湾——本来就不打算回收，但 Boost-Back 失败意味着 V3 的「快速复用」剧本距离稳态还有一段路。

把这次和前一周交付的 SpaceX S-1 招股书放一起看才能体会这次发射的重量：S-1 里 36 页的风险因素、$28 万亿 TAM、CEO 薪酬绑火星殖民——整个估值故事的现金流锚点就是「Starship V3 试飞节奏 + 星链 V3 卫星部署速度」。今天的结果是「上面级基本可以工作、一级仍需迭代」，这正好对应 SpaceX 招股书里提的「2026 年内做到回收一级」的 milestone：拿到了大部分资本市场要的进度，但还没到能让一级股东把 Mars 那一栏当现金流计的状态。下一次窗口预计 4-6 周，节奏会被市场和监管同时盯到锱铢必较。如果你在做空间数据 / 星链 backbone 相关的产品规划，把「2026Q4 商业 Starship 入轨」继续当作风险事件来排，不要当默认条件。

## 📈 趋势

- 🆕 **开源供应链战进入「攻击编辑器」阶段**：TeamPCP 用恶意 VS Code 扩展打穿 GitHub 自身，把过去针对 npm/PyPI 包的逻辑迁到 IDE 扩展层。Cursor / Windsurf / VS Code 全生态接下来都要做扩展白名单和 sandbox
- 🔺 **Rust 吃掉 JS 工具链已成定局**：Vite 8 用 Rolldown 替掉 esbuild+Rollup，叠加 Biome / Oxc / Rspack / Turbopack，2026 的前端 build 工具基本都是 Rust binary 在跑——但 Bun 这次的 13365 个 unsafe block 提醒：「用 Rust 重写」不等于「内存安全」
- 🔺 **Durable Execution 转向「per-agent / per-tenant」运行时**：Cloudflare Dynamic Workflows、Inngest agent kit、Temporal Replay 都在重做控制面，目标都是让一个 agent 长跑数小时甚至数天的 step 不丢状态。LangGraph / CrewAI 这层之下的基础设施战开始白热化
- 🆕 **「mega IPO 窗口」打开**：SpaceX 和 OpenAI 同周交 S-1，加上 Oura 也在排队，2026 年下半年美股 tech 一级市场的钱会被前三家拿走大半，中尾部 startup 的二级估值要重新定价
