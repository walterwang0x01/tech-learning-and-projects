### Windows IKE 高危漏洞确认在野利用

微软 Windows Internet Key Exchange 服务扩展的一个 double free 漏洞（CVE-2026-33824，CVSS 9.8）被确认已遭实际攻击利用。攻击者不需要任何认证，向开启 IKEv2 的机器的 UDP 500 / 4500 端口发特制报文就能远程执行代码，影响范围覆盖所有在支持周期内的 Windows 10、Windows 11 和 Windows Server。值得注意的是这个补丁四月就发了，CISA 是在 8 月 18 日才把它加进 KEV 目录并要求联邦机构 8 月 21 日前修完——也就是说风险窗口是补丁发布到实际打上之间的四个月。如果你手上有对外暴露 IPsec/VPN 端点的 Windows 机器，先确认四月累积更新是否真的落地，比读任何威胁情报都实在；短期缓解手段是在边界上限制 UDP 500/4500 的来源。

→ [MSRC 公告](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-33824) / [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-critical-windows-ike-extension-flaw-now-exploited-in-attacks/) / [IT之家](https://www.ithome.com/0/993/113.htm)

### 内存涨价传到货架：Amazon 硬件最高涨 60%

Amazon 一夜之间上调了 Echo、Kindle、Fire TV 和 eero 全线第一方硬件价格，最大涨幅接近 60%：Echo Dot 从 49.99 涨到 79.99 美元，Fire TV Stick 4K Max 从 59.99 涨到 84.99，16GB Kindle 从 109.99 涨到 149.99。官方给 Fortune 的口径是「内存与存储元件成本显著上涨」，而非关税——也就是说这是 AI 需求推高的 DRAM/NAND 行情第一次以这种规模落到消费终端的标价上。低价机型涨得最狠，说明成本里元件占比越高的产品越没有缓冲空间。如果你的项目要采购边缘设备、自建小型集群或今年要换开发机，内存和 SSD 的报价可以按继续上行来做预算，别拿半年前的价格表估。

→ [The Verge](https://www.theverge.com/tech/983598/amazon-price-increase-echo-kindle-fire-tv) / [Engadget](https://www.engadget.com/2242185/amazon-devices-kindle-echo-eero-price-hikes/)
