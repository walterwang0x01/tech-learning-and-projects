## 📌 头条

### Tesla/SpaceX 联合投资 168 亿美元在德州建芯片厂 Terafab

Tesla 与 SpaceX 正式宣布将在德州 Grimes County 建造名为「Terafab」的先进半导体工厂，首期投资 168 亿美元，计划建设超过 1 亿平方英尺的垂直整合设施，覆盖制造、封装和测试全链条，预计创造至少 3000 个就业岗位。这是 Musk 系企业首次自建芯片产能，目标是为 AI 和航天提供规模化自主芯片供应，也是美国半导体回流的标志性项目之一。

→ [TechCrunch](https://techcrunch.com/2026/08/06/tesla-and-spacex-will-invest-16-8b-to-start-building-terafab-chip-factory-in-texas)

### Meta 被判赔偿 9.42 亿美元：未保护未成年人

新墨西哥州法院判决 Meta 需支付总计 9.42 亿美元（第二阶段新增 5.67 亿），以弥补其平台对未成年人造成的伤害。这是迄今为止社交媒体领域针对儿童安全的最大金额裁决。法院认定 Meta 违反了州消费者保护法，未能对平台对青少年心理健康的风险给予充分警示。该判决可能为其他州的类似诉讼树立先例。

→ [The Guardian](https://www.theguardian.com/technology/2026/aug/06/new-mexico-court-meta) / [WSJ via HN](https://www.wsj.com/tech/meta-ordered-to-pay-942-million-to-address-harm-to-kids-from-social-media-8ba5aab7)

## ⚡ 快讯

- **AMD 收购 Taalas**：AMD 宣布收购 AI 推理芯片初创公司 Taalas。Taalas 的技术路线是将 AI 模型权重直接烧进硅片（ASIC），牺牲通用性换取推理速度提升数千倍、成本大幅降低。该公司成立以来已累计融资 2.19 亿美元，收购金额未披露。 → [AMD 官方](https://newsroom.amd.com/news/amd-acquires-taalas-ai-inference/)
- **GitHub Actions/Pages 大规模宕机**：GitHub Actions 和 Pages 周四经历数小时严重故障，工作流无法启动或中途失败，REST API 返回错误，HN 获 349 分热议。这是 GitHub Actions 历史上第二长的重大事故。 → [GitHub Status](https://www.githubstatus.com/incidents/qcvjkzcs7j74)
- **Snowflake 黑客认罪**：26 岁加拿大人 Connor Moucka 在西雅图联邦法院认罪，承认入侵 165 家 Snowflake 客户、窃取数十亿条记录并勒索约 250 万美元，面临最高 32 年刑期。 → [DOJ 公告](https://www.justice.gov/opa/pr/canadian-man-pleads-guilty-hacking-us-cloud-storage-provider-and-extorting-its-customers)
- **Apple 紧急修复 macOS 屏幕共享认证漏洞**：macOS Tahoe 26.6.1 修复 CVE-2026-65400：同一网络的攻击者可在无有效凭据情况下认证到屏幕共享。罕见的单一漏洞更新，建议所有 Mac 用户尽快升级。 → [Apple 安全公告](https://support.apple.com/en-us/148170)
- **Nvidia 考虑降低 Rubin Ultra 内存规格**：据 The Information 报道，Nvidia 因 HBM 供应短缺，正在评估至少 3 种低配版 Rubin Ultra GPU 方案（从 12-Hi HBM4E 降至 8-Hi 或 HBM4），最终规格尚未确定。 → [TrendForce 分析](https://www.trendforce.com/presscenter/news/20260804-13166.html)
- **Hadrian 融资 13.7 亿美元**：国防科技制造商 Hadrian 完成 Series D 融资 13.7 亿美元，估值 78.7 亿，将用于扩建 AI 驱动的自动化工厂，为美国国防和航空航天提供关键零部件。 → [TechCrunch](https://techcrunch.com/2026/08/06/defense-tech-hadrian-raises-1-37b-at-8b-valuation)
- **Python 3.14.7 发布**：Python 3.14 第七个维护版本发布，包含约 499 项错误修复和文档改进；同步发布 3.13.15。 → [Python 下载](https://www.oschina.net/news/489060/python-3147-31315)
