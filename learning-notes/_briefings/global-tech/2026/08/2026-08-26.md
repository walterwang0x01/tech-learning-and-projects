## 📌 头条

### X 向 Nitter 发出停止函，开源隐私代理下线

X Corp. 向开源项目 Nitter 发出 cease-and-desist，指控其非法抓取 API 数据和绕过会话 token。nitter.net 已在 8 月 25 日下午 5 点 EST 截止日前主动下线，依赖 Nitter 的第三方服务 XCancel 同步收到警告。Nitter 曾让用户无需账号即可阅读 X 帖文，是开源社区对抗平台封闭化的标志性项目。这是 X 继限流 API、收费化之后对第三方生态最直接的一次法律打击。

→ [TechCrunch](https://techcrunch.com/2026/08/25/x-sends-cease-and-desist-to-open-source-project-nitter-over-alleged-scraping/) / [NotebookCheck](https://www.notebookcheck.net/XCancel-gets-taken-down-as-X-Corp-sends-cease-and-desist-letter-to-Nitter.1378427.0.html)

### GitHub Stacked PRs 进入公开预览

GitHub 于 7 月 30 日上线 Stacked Pull Requests 公开预览。开发者可以将大 PR 拆分为有序链式小 PR，每个独立审查和 CI 验证，最后一键合并。此前这个工作流需要 Graphite、ghstack 等第三方工具，现在原生支持。对 AI 生成代码尤为重要——Copilot/Codex 产出的大 diff 可自动拆分为可审查的堆栈，GitHub 官方博客已给出配合教程。

→ [GitHub 公告](https://github.com/orgs/community/discussions/201439) / [DevOps.com 分析](https://devops.com/github-brings-stacked-pull-requests-out-of-the-shadows/)
