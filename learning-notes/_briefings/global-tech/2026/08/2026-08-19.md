### GitHub 宕机近 8 小时，Cursor 同天上线 Origin

GitHub 8 月 17 日的事故按官方 incident 记录从 13:40 UTC 持续到 21:15 UTC 标记解决，约 7 小时 36 分钟，Actions、Pull Requests、Issues、API、Webhooks、SAML/OIDC 和 Copilot 逐个进入 major outage，网页与 API 错误率约 20%，archive 下载和 raw 仓库内容失败率约 50%，根因至今未公开（各家媒体给的时长从「3 小时 19 分」到「近 8 小时」不等，差别在于算峰值中断还是算整个 incident 窗口）。就在同一天，Cursor 上线了 Origin——一个内建在编辑器里的代码托管平台，早期 beta 覆盖所有付费方案（Pro / Teams / Enterprise），目前只有仓库、PR、代码浏览、搜索和与 GitHub 同步这几样基础能力，官方把 GitHub 仍然定位成 source of truth，有报道称它对付费账号默认开启、需要管理员主动 opt out。HN 上 Origin 拿了 488 分 379 条评论，同期 Ask HN「GitHub employees what's going on?」也冲到 231 分，社区讨论的重心其实不是 Cursor 好不好，而是「除了自托管 GitLab 还能去哪」，而多位评论者都指出自托管的真实成本是运维负担。对你的实际意义：Origin 现在只是 GitHub 之上的一层壳，把它当主仓不现实；但如果 CI 完全押在 GitHub Actions 上，值得趁这次事故把关键流水线改造成能在本地或第二个 runner 上跑通的形式。

### 内存 12 个月涨 500%，128GB DDR5 报价 3399 美元

Tom's Hardware 拿 PCPartPicker 的历史均价库把 DDR5 过去 12 个月的涨幅统计了一遍：2×16GB 4800 MT/s 涨 372%，2×32GB 5600 MT/s 涨 485%，128GB DDR5-6400 套装现在报 3399 美元，是有记录最低价 329 美元的十倍；去年 222 美元的 64GB 6000 MT/s 套装现在要 1272 美元。原因指向 AI：三星和美光都提到 AI 服务器需求加洁净室产能有限让 DRAM 供给持续紧张，TrendForce 的说法是供应商正把产能往 HBM 和服务器内存挪，另有报道指出不少客户签了 3-5 年长期供货协议（LTA），把现货市场进一步抽干。数字口径本身是打架的：ComputerBase 追踪的 Kingston Fury Beast 32GB 从 2025 年 9 月 114 欧涨到 2026 年 8 月 523 欧、约 360%，和 PCPartPicker 的 485% 差了一截，看的是不同型号与不同区域市场，引用时最好带上口径。对你意味着：「本地跑模型先加内存」这条最省钱的经验暂时失效了，一台 128GB 的开发机现在光内存就顶一台整机，短期内把重活 offload 到云端 GPU 反而可能更划算。

→ [Tom's Hardware](https://www.tomshardware.com/pc-components/ram/memory-prices-climb-500-percent-in-12-months-up-to-10x-the-lowest-ever-tracked-prices-128gb-of-ddr5-now-usd3-399) / [TechPowerUp 分档数据](https://www.techpowerup.com/351689/memory-prices-break-a-record-with-nearly-500-surge-in-the-last-12-months) / [HN 讨论](https://news.ycombinator.com/item?id=49334960)
