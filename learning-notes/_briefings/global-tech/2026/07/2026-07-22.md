## 📌 头条

### 微软7月补丁修复622个CVE，含3个零日漏洞

微软发布了史上最大规模的 Patch Tuesday 更新，一次性修复 622 个安全漏洞，其中 59 个为严重级别，3 个零日漏洞中有 2 个已在野外被积极利用——Active Directory 联合服务提权（CVE-2026-56155）和 SharePoint Server 提权（CVE-2026-56164）。CISA 已发布紧急加固指南要求联邦机构优先修补 SharePoint 漏洞。如果你还在跑 Windows Server 或 SharePoint，本周必须安排紧急补丁窗口。

→ [Malwarebytes 分析](https://www.malwarebytes.com/blog/bugs/2026/07/july-2026-patch-tuesday-fixes-622-microsoft-cves-including-three-zero-days) / [CISA 紧急通告](https://www.cisa.gov/news-events/alerts/2026/07/14/cisa-urges-sharepoint-hardening-after-new-exploitations)

### Poolside 发布 Laguna S 2.1 开源编码模型

旧金山初创公司 Poolside 发布了 Laguna S 2.1，一个 118B 参数的 MoE 开源编码模型（每 token 激活 8B 参数），支持 100 万 token 上下文窗口。Poolside 称它是「西方最强开源权重模型」，在 SWE-bench 等 agentic coding 基准上匹敌甚至超越数倍体积的闭源模型，可在单台桌面机上运行。HN 热度 255 分。对于不想依赖 API 的团队来说，这是目前最值得尝试的本地部署编码模型之一。

→ [官方博客](https://poolside.ai/blog/introducing-laguna-s-2-1) / [Hugging Face](https://huggingface.co/poolside/Laguna-M.1)
