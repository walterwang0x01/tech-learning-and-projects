## 📌 头条

### TypeScript 7.0 正式版发布

微软 7 月 8 日正式发布 TypeScript 7.0——自 2012 年诞生以来最大的一次底层变革：编译器完整迁移到 Go，借助原生代码与共享内存并行，全量编译和类型检查速度相比 6.0 平均提升约 10 倍，大型代码库上可达 8–12 倍。移植过程逐行翻译现有逻辑而非重写，语义与 6.0 严格一致，并通过十年积累的测试套件验证。7.0 暂不含稳定版 programmatic API（预计 7.1 补齐），依赖编译器内部 API 的工具可继续并行使用 6.0。HN 讨论帖 476 赞、186 条评论，社区普遍认可「编辑器终于不卡了」的体验跃升。

→ [官方公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) / [HN 讨论](https://news.ycombinator.com/item?id=48833715)

### Bun 核心代码 Zig 全面转 Rust

Bun 团队 7 月 8 日宣布：历时 11 天，全部 1448 个 Zig 源文件已机械转换为 Rust，测试套件 100% 通过，v1.4.0 已通过 canary 渠道发布。团队称此举并非简单换语言，而是为长期稳定性与可维护性押注 Rust 生态——二进制体积减少 3.8–6.8 MB，服务端吞吐量与编译速度提升 2%–5%。V2EX 社区热议迁移过程大量借助 AI 辅助（API 开销 reportedly 超 16 万美元），但结论清晰：JavaScript 全栈运行时赛道正在经历「性能语言打底」的第二轮洗牌，继 TypeScript 编译器 Go 化之后，Bun 选择了另一条 Rust 路线。

→ [官方博客](https://bun.com/blog/bun-in-rust) / [开源中国](https://www.oschina.net/news/471581)
