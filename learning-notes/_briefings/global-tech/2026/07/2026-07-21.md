## 📌 头条

### Airbus 弃 AWS 转向法国主权云

空中巨头 Airbus 宣布将约 900 个应用系统迁出 AWS，首批 70 个涉及 ERP、CRM、制造系统等关键业务，交由法国云服务商 Scaleway 承接，合同为期十年、金额超 5000 万欧元。这是欧洲「数字主权」运动中规模最大的一次云迁移，核心动机是让敏感数据彻底脱离美国司法管辖的潜在触及范围。The Register 评论直言：留在美国云平台上，数据主权就永远是别人说了算。对于跟欧洲企业或政府客户打交道的团队，「能否证明数据不受外国法律管辖」正在变成实打实的商业竞争力。

→ [The Register 评论](https://www.theregister.com/columnists/2026/07/20/airbus-takes-flight-from-aws-what-happens-next-is-critical/5274109) / [迁移细节](https://theregister.co.uk/paas-and-iaas/2026/07/16/airbus-migrating-70-critical-apps-from-aws-to-frances-scaleway-amid-digital-sovereignty-push/5272373)

### TypeScript 7.0 正式发布，编译提速 8-12 倍

微软正式发布 TypeScript 7.0，这是编译器和语言服务从「自举 JS 代码库」完整移植到 Go 之后的第一个稳定版本。得益于原生代码执行速度和共享内存多线程，全量构建速度提升 8 到 12 倍，编辑器的自动补全、跳转定义等响应也明显变快。团队没有选渐进式优化 JS 版编译器的路线，而是彻底重写——继 Anthropic 用 Claude 把 Bun 从 Zig 迁到 Rust 之后，主流工具链「脱 JS/脱慢语言」重写正在成为常态。日常写 TypeScript 的话，升级后大型项目的 CI 耗时和 IDE 卡顿会有直观改善。

→ [Microsoft DevBlogs 公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)
