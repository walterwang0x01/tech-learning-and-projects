## 📌 头条

### AWS 推出 Lambda MicroVMs

AWS 发布基于 Firecracker 的 Lambda MicroVMs：把「VM 级隔离 + 近乎瞬时启动 + 可保留状态」直接做成无服务器原语。你用 Dockerfile 定义环境、一次打成 MicroVM Image，之后按需拉起独立沙箱、走 HTTPS 交互、用完即毁——适合跑用户/模型即时生成的代码、分析作业或安全扫描，而不用自己搭虚拟化层。对做 AI 沙箱、多租户执行环境或 IDE-as-a-Service 的团队，这是 serverless 从「一次调用」走向「可驻留环境」的明确信号。

→ [原文](https://aws.amazon.com/blogs/compute/announcing-lambda-microvms-serverless-compute-environments-with-vm-level-isolation-and-near-instant-startup/)

### TypeScript 7.0 正式 GA

微软在 7 月 8 日宣布 TypeScript 7.0 正式可用：编译器与语言服务整体用 Go 重写，官方称全量构建通常可提速约 8–12 倍（例：VS Code 代码库类型检查从约 126 秒降到约 11 秒）。npm 装 `typescript` 即可；因 7.0 暂无稳定可编程 API，依赖编译器内部 API 的工具可并行装 `@typescript/typescript6`（`tsc6`）过渡，等 7.1。Walter 侧若 monorepo / 类型检查是 CI 瓶颈，这是本周最值得先试的一刀。

→ [官方公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) / [InfoWorld](https://www.infoworld.com/article/4196378/go-based-typescript-7-0-arrives.html)
