## 📌 头条

### Deno 团队整体并入 Cloudflare，runtime 一年后停更

Node.js 之父 Ryan Dahl 带着整个 Deno 团队加入了 Cloudflare——不是收购，是全员并入。官方公告写得很直接：Deno runtime 还会维护一年（只发 bug 修复和安全更新），之后停止官方开发；Deno Deploy 六个月后关停，付费用户迁去 Cloudflare Workers；JSR 包仓库继续运营，转到 Cloudflare 基础设施上。2022 年 Dahl 还点名 Workers 是 Deno Deploy 最直接的竞争对手，如今是直接加入对手，把资源押到 Workers 编程模型上。对还在用 Deno 的人这是明确的迁移信号：生产项目该开始评估 Workers/Durable Objects 的等价能力，别等到六个月倒计时结束。

→ [Deno 官方](https://deno.com/blog/cloudflare) / [Cloudflare 博客](https://blog.cloudflare.com/deno-joins-cloudflare)

### Chrome 155 用 Rust 解码器复活 JPEG XL

Google 在 Chrome 155 里默认支持解码 JPEG XL（image/jxl），这是对 2022 年砍掉该格式的政策反转。关键不在格式本身，而在解码器：这回是用 Rust 重写的 jxl-rs，是 Chrome 第一个用内存安全语言写的完整图片解码器——此前 C++ 解码器的越界读、use-after-free 漏洞是老大难。JPEG XL 比 JPEG 压缩率高 30%-50%，支持无损、原生 HDR、以及把已有 JPEG 可逆转码。同一版本还修了 247 个安全漏洞（4 个 Critical、53 个 High），其中 12 个由 Claude 协助报告、2 个来自 OpenAI Codex Security，并给 WebCrypto 加了抗量子加密。该升早升。

→ [247 漏洞修复](https://www.esecurityplanet.com/news/news-google-chrome-155-247-security-flaws/) / [JPEG XL 技术说明](https://developer.chrome.com/blog/jpeg-xl-in-chrome)

## ⚡ 快讯

- **Oxide Computer**：拿下 Eclipse 领投的 4.45 亿美元 D 轮，估值 60 亿美元，AMD Ventures 和 Atreides 新进。这家卖「企业自有的整机架云」的公司今年春天开始交所得税——靠正常卖机器盈利，不是一次性事件；过去 12 个月产能翻了 20 倍仍供不应求 → [官方](https://oxide.computer/blog/our-445m-series-d)
- **Prime Intellect**：把 Prime Agent 用 Rust 重写（HN 25 分）。又一个把 Agent 运行时从动态语言迁到 Rust 的案例，图的是启动速度、内存可控和部署成单文件——跟 Chrome 换 Rust 解码器是同一股劲 → [官方博客](https://www.primeintellect.ai/blog/prime-agent-rust)
- **Bevy 0.20**：Rust 游戏引擎憋了十个多月的大版本，核心词是「场景编辑器」，几乎所有新特性都在为它铺路。着色器语言换 WESL、实时路径追踪渲染器 Solari 转正（但默认关掉了 ReSTIR，吃性能换不来明显画质） → [开源中国](https://www.oschina.net/news/502913/bevy-engine-0-20)
- **Let's Encrypt**：官宣时间表：2027 年 2 月 10 日起默认签发 64 天有效期证书（也可自选 45 天或 6 天），10 月 14 日 staging 环境先切。短周期证书逼着大家把续签自动化，手动续签的站点要提前改造 → [开源中国](https://www.oschina.net/news/502931/letsencrypt-64-day-certs)
- **Cloudflare Workers**：上线按需 CPU/内存 profiling，能直接在生产环境生成交互式火焰图定位内存泄漏和性能瓶颈——不用预埋探针，排查线上问题的门槛降了一截 → [Cloudflare 博客](https://blog.cloudflare.com/workers-on-demand-profiling)
- **Margaret Hamilton**：「软件工程」这个术语的创造者、阿波罗制导系统的掌舵人于 9 月 30 日去世，享年 90 岁。那张她站在齐腰高的代码打印纸旁的照片，是一代人对「写代码也是工程」的最初认知 → [开源中国](https://www.oschina.net/news/502922/margaret-hamilton-computing-pioneer-dies)
- **开源可持续性**：一份调查称 23 个核心开源项目里有 11 个只靠 1-2 个人维护（HN 70 分）。供应链安全讨论喊了这么多年，底层维护者稀缺这件事依然没解 → [原文](https://linuxstans.com/11-of-23-core-open-source-projects-run-on-1-or-2-people)

## 📈 趋势

- 🔺 内存安全语言攻入系统底层——Chrome 用 Rust 写图片解码器、Quake 移植到安全 Rust、Eurydice 把 Rust 编回 C，Rust 正从「应用层新宠」渗透到最吃安全的解码/移植场景
- 🔺 JS/TS 运行时与托管在收缩合并——Deno 并入 Cloudflare、Deno Deploy 关停，edge 平台在往 Workers 这类少数编程模型收口
- 🆕 「自有基础设施」重新被买单——Oxide 4.45 亿 D 轮、估值 60 亿且已盈利，企业把云从「租」转向「在自家机房拥有」的需求被资本确认
- 🔺 证书有效期继续压缩——Let's Encrypt 2027 年默认 64 天，续签自动化从「最佳实践」变成「不做就断」
