## 📌 头条

### GitHub Octoverse 2026：40% 的 PR 由 Agent 发起

GitHub 年度 Octoverse 报告给了一组硬数字：过去 12 个月推送代码 179 亿次，比 2024 和 2025 加起来还多；提交数涨到 343 亿，是两年前的三倍多。最值得盯的是工作方式的变化——截至 9 月，超过 40% 的 pull request 由 Agent 发起，而今年 3 月这个数字还只有 17%。带 agent 配置文件的新仓库，平均提交量是没有的八倍。开发者选模型也更杂，9 月 61% 的 Copilot 用户用了不止一个模型。一句话：先指挥 Agent、再 review 结果，正在变成默认动作。

→ [Octoverse 2026](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/) / [GitHub Universe 2026](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)

### Apple 发触屏 MacBook Pro，顶配要价 $14,549

Apple 这次动了十几年没碰的地方——给 MacBook Pro 上了触摸屏，还换成 OLED 显示屏。多家媒体同步报道，产品本身没悬念，悬念在价格：满配版本标到 $14,549。对开发者的实际意义有限（触屏在 macOS 上的生产力增益一直存疑），更值得看的是它释放的信号——Apple 终于松口触屏方向，后续会不会下放到更便宜的机型。想入手高配的先看清这个数字再决定。

→ [Ars Technica](https://arstechnica.com/apple/2026/10/apple-announces-touchscreen-macbook-pro-with-oled-display) / [顶配定价（The Verge）](https://www.theverge.com/tech/1021308/apple-touchscreen-macbook-pro-proled-xdr-fully-specced)
