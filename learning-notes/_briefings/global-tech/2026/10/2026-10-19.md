### OpenCode Console 被攻破，1.4% 用户的第三方 API key 可能泄露

构建 OpenCode 的 Anomaly Innovations（原 SST）在 10 月 17 日披露，其云端管理服务 OpenCode Console 发生安全事件，约 1.4% 的 Console 用户受影响——都是把外部模型商（OpenAI / Anthropic / Google）API key 存进 Console 的那部分人，存在里面的 key 可能已被窃取。官方把这次事件描述为「大规模蒸馏攻击」，已逐一邮件通知受影响用户，没收到邮件的即未受影响，并称正与三家模型商联合处置。如果你用 Console 托管过模型商密钥，别等邮件，直接去各家后台吊销并重新签发——这类「替你保管凭证」的平台正成为攻击目标，密钥一旦落库就等于把账单和额度交了出去。

→ [官方公告](https://twitter.com/opencode/status/2111519637049319818) / [HN 讨论](https://news.ycombinator.com/item?id=50139083)

### 3blue1brown：现在是投身数学最好的时代

数学科普频道 3blue1brown 作者 Grant Sanderson 的新视频在 HN 冲到 199 分、194 条评论。他的核心论点是：AI 能自动化的恰恰是「执行已知算法」那部分，而提出问题、建立抽象、判断什么值得算，这些数学素养反而更稀缺、更值钱——所以现在反而是学数学最好的时机，而不是最坏。对天天跟 LLM 协作写代码的人尤其有共鸣：当生成代码变得廉价，能看懂一个方案对不对、边界在哪，才是你真正的护城河。评论区关于「数学 vs 具体技术栈」的争论也值得一读。

→ [视频](https://www.youtube.com/watch?v=LKrwhjOI8Nc) / [HN 讨论](https://news.ycombinator.com/item?id=50136150)
