## 📌 头条

### 英伟达把 Vera Rubin 机架设计开源给 OCP

在 10 月 12 日的 OCP 全球峰会上，英伟达通过 MGX 架构把下一代旗舰平台 Vera Rubin 的机架与计算托架设计贡献给了开放计算项目（OCP）。更新后的 MGX 1.2 规范支持单机架最高 250kW 部署，加入了机架级盲插式液冷、可互操作机架互连和液冷 5000A 母线。这意味着系统厂商可以照着一套公开蓝图去造 AI 工厂基础设施，而不必各做各的。Meta 已承诺采用英伟达 Spectrum-6 以太网交换机搭建超过 10 万 GPU 的 Vera Rubin 工厂，Google 也接入了相关开放网络栈——两家一线超大规模厂商同时站台，是这套开放规范最有分量的背书。对做基础设施的人来说，液冷和高压直流供电正在从各家私有方案变成行业默认选项。

→ [英伟达官方博客](https://blogs.nvidia.com/blog/ocp-global-summit-vera-rubin-scale-ai-factories/) / [IT之家](https://www.ithome.com/1/012/120.htm)

### 黑客远程把法国超市冷柜加热到 50℃

周一，法国多家大型连锁超市称遭遇一次「前所未有」的网络攻击：黑客远程触发了冷藏系统的强制除霜功能——这个本来每天只跑约两小时的功能被改成持续运行，温度被拉到 50℃。结果是数百家门店生鲜冷冻货品报废、多家门店起火，损失据报道达数百万欧元。多家媒体（CBS、路透、独立报）口径是法国境内 150 家以上门店受影响，HN 上原标题写的是「欧洲」，实际集中在法国。这不是偷数据那种攻击，而是直接让 IoT/楼宇控制系统造成物理破坏，给所有把制冷、楼控接上网的行业提了个醒：OT 侧的默认口令和开放接口才是真正的软肋。

→ [Reuters/Yahoo](https://www.yahoo.com/news/world/articles/french-supermarkets-hit-fires-food-135801100.html) / [Tom's Hardware](https://www.tomshardware.com/tech-industry/cyber-security/unprecedented-cyberattack-cripples-supermarket-fridges-across-europe-as-hackers-activate-automatic-defrosting-delivery-and-store-prices-also-impacted-by-incident)

## ⚡ 快讯

- **AWS Lambda Web Functions**：AWS 发布新的无服务器计算原语 Lambda Web Functions，让你的代码直接处理 HTTP 请求、原生跑 HTTP 框架，官方主打多并发执行和自动全球分发带来的快速一致响应。对习惯了 API Gateway + Lambda 两件套的人，这是把 Web 应用直接搬进 Lambda 的新路子。 → [AWS Blog](https://aws.amazon.com/blogs/aws/announcing-aws-lambda-web-functions-for-fast-consistent-web-app-performance-anywhere)
- **SvelteKit 3**：SvelteKit 3 进入 RC：svelte.config.js 配置文件被取消，$lib 别名也要退休。属于框架级的破坏性变更，升级前先看迁移指南，别直接把生产项目往上怼。 → [InfoQ](https://www.infoq.cn/article/Hs5X7EdO6PNHk367zZv3)
- **Postgres 不慢，是存储慢**：POSETTE 2026 上 ClickHouse 的 Sai Srirampur 跑了组对比：同一份 PostgreSQL 负载，本地 NVMe 拿到 16,030 TPS，EBS 只有 1,734 TPS，差 9.24 倍。观点很直接——很多人骂 Postgres 慢，其实瓶颈在云盘的 IOPS 和延迟上。单一来源的 benchmark，数字当参考。 → [oschina 译介](https://www.oschina.net/news/502975/postgres-isn-t-slow-your-storage-is)
- **Meta ZGateway**：Meta 分享了内部网关 ZGateway 的实践：在每秒处理超过 10 亿次操作的同时，把到 ZippyDB 的连接数减少了 19 倍。典型的「连接收敛」思路，对做高并发数据库中间层的有参考价值。 → [InfoQ](https://www.infoq.cn/article/d5x9BkQ9AoIZq5mf6LN0)
- **Uber Kubernetes**：Uber 介绍了他们在 Kubernetes 平台上把「扩容意图」与「执行操作」解耦的做法——先声明想要什么容量，再由独立组件负责怎么扩。这种控制面/数据面分离的模式，是大规模集群治理里越来越常见的套路。 → [InfoQ](https://www.infoq.cn/article/2SNgaiHoK808v22dl5SJ)
- **Google DevSite RCE**：安全研究员 Simon Köck 披露了一个 Google DevSite 上的远程代码执行漏洞，拿到约 9 万美元赏金。根因是 Flask session 用 pickle 反序列化——又一个「不要用 pickle 处理不可信输入」的真实案例，写 Python Web 的都该看一眼。 → [writeup](https://simonkoeck.com/writeups/google-devsite-flask-session-pickle-rce)
- **苹果推 Switch to Safari**：苹果美国官网上线「切换到 Safari」宣传页，对比 Chrome 主打三点：Mac 上视频流媒体续航最多多 5 小时、常用网站加载最高快 35%、默认拦更多第三方跟踪器。都是苹果自家口径的营销数据，当成一次浏览器战争的信号看。 → [IT之家](https://www.ithome.com/1/012/133.htm)
