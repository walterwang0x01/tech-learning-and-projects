### Mistral Large 4「Le Chonk」公开预览

法国 Mistral 放出 1T 总参、49B 激活的原生多模态 MoE 模型 ML4，昵称 Le Chonk，官方称是其迄今最强模型，想以此证明在前沿竞赛里「还没掉队」。但要注意：现在只开放了 API 预览（通过 Mistral Studio 的 guardrail endpoint），权重要等 10/27 安全测试完成才公开——所以此刻它还不算 open-weight 模型，Wired 标题里「中国以外最强开源」的说法要打个折扣。它号称上下文 100 万 token、带 16 亿参数视觉编码器,HN 讨论热度极高(1600+ 分)。等 27 号权重放出,才是真正能自部署评测的节点。

→ [Mistral 官方](https://mistral.ai/news/mistral-large-4/) / [TechCrunch](https://techcrunch.com/2026/10/06/mistrals-new-1t-model-aims-to-leapfrog-closed-and-open-rivals/) / [Wired](https://www.wired.com/story/mistral-new-model-le-chonk-open-source-china-us-frontier)

### 黑客劫持三国域名注册局，伪造 Google TLS 证书

Google 周二披露：攻击者没有攻破 Google 服务器，而是劫持了 .gh / .sl / .as 三个国家级顶级域（ccTLD）的注册局，篡改权威 DNS 记录通过了域名验证，从证书颁发机构手里拿到了覆盖 Google 及其他大型机构域名的「真实可信」HTTPS 证书。这是对 Web 信任链的釜底抽薪——域名验证本身被绕过。Google 已在 Chrome 通过 CRLSets 封锁这些证书并协调 CA 吊销。对做 Web 服务的人:这类事件说明单靠 DV 证书验证不够,值得关注 CT 日志监控和证书透明度告警。

→ [Google 官方](https://blog.google/security/chromes-response-to-recent-cctld-registry-hijacks/) / [Ars Technica](https://arstechnica.com/security/2026/10/hackers-obtain-counterfeit-tls-certificates-for-google-and-other-large-services)
