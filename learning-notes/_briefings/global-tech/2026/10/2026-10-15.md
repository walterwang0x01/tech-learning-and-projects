### Python Workers GA 之后：冷启动和维护成焦点

Cloudflare 的 Python Workers 已经在上个月转正式可用（Python 和 JS/TS 平级坐在 Developer Platform 上，可绑定 Workers AI、R2、D1、Hyperdrive、Durable Objects、Queues、Workflows，支持 FastAPI、Django、Flask）。InfoQ 本周的这篇跟进没有停在发布本身，而是把两个落地前的硬问题摆上台面：冷启动表现到底如何，以及这套 Python 运行时的上游依赖由谁长期维护。对准备把 FastAPI 应用丢到边缘的人，这篇比发布公告更值得读——先拿自己的依赖集压一遍冷启动再决定。

→ [InfoQ 跟进](https://www.infoq.cn/article/fycaxN0NvWHBq6B7d3zY) / [GA 公告（背景）](https://blog.cloudflare.com/python-workers-ga/)

### Microsoft Defender 登陆 Linux

微软以公共预览版把 Defender 搬上 Linux，不只是杀毒，还带上了端点检测与响应（EDR）、威胁搜寻、漏洞管理、设备隔离这一整套企业级能力，覆盖 RHEL、CentOS、Ubuntu、Debian、SLES、Fedora、Oracle Linux。门槛是需要 Defender for Endpoint P2 或 Microsoft 365 E5 订阅。如果你的团队本来就在微软安全体系里，这让 Linux 服务器终于能和 Windows 端点进同一块运维面板，不用再单独拼开源 EDR。

→ [IT之家报道](https://www.ithome.com/1/013/188.htm)
