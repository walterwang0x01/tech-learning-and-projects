## 📌 头条

### 亚马逊开源 TorchNeuron，PyTorch 代码改一行就能跑 Trainium

亚马逊宣布开源 TorchNeuron，让现有 PyTorch 代码只改一个配置项、不用重写就能原生跑在自研 Trainium 芯片上，10 月 20 日在圣何塞的北美 PyTorch 大会以 Apache 2.0 许可发布公测，可用 pip install torch-neuronx 装，目前支持 Trainium2 和 Trainium3。这是直接冲着英伟达十多年攒下的 CUDA 软件壁垒去的——亚马逊的说法是给行业一个「真正可行的换芯片选择权」。对你意味着:如果你在 AWS 上跑 PyTorch 训练/推理，以后换到 Trainium 的迁移成本理论上降到改一行配置,但官方也承认部分 PyTorch 特性暂不支持,别指望首发就无缝。Google 也在做对标的 TorchTPU，这条「绕开 CUDA」的赛道开始热了。

→ [亚马逊官方](https://www.aboutamazon.com/news/innovation-at-amazon/torchneuron-pytorch-aws-trainium-chips-ai) / [TechCrunch](https://techcrunch.com/2026/10/19/amazon-is-taking-its-biggest-shot-at-nvidia-yet-with-new-torchneuron-dev-tool) / [HF Blog](https://huggingface.co/blog/hf-torchneuron)

### Cloudflare 推 agent-first CLI「cf」，逐步替代 Wrangler

Cloudflare 发布全新命令行工具 cf，定位是「给整个 Cloudflare API 用的 agent 化 CLI」。理由很直白:老的 Wrangler 只覆盖约 280 个操作，而 Cloudflare 有上千个 API，而且官方数据说如今将近一半的 Wrangler 调用来自 agent（3 月还只有四分之一）。cf 默认输出 JSON、带 search 子命令让模型自己找命令、配置改成 TypeScript 文件方便编辑器和 agent 做类型检查——处处是为「调用方是 AI」设计。迁移节奏:cf 目前是公测，等正式 GA 后才开始废弃 Wrangler，并给 18 个月迁移窗口，现有项目不会立刻崩。对你意味着:如果在用 Workers，可以先让 cf 和现有 Wrangler 项目并存试跑，不急着整仓迁移。

→ [Cloudflare 官方博客](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) / [InfoQ 中文](https://www.infoq.cn/article/Ddda0DF68laqfoqa4Lju)
