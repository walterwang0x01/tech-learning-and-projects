## 📌 头条

### Cloudflare 生日周集中放大招：数据平台 Basin GA + 后量子加密

10 月 1 日 Cloudflare 的 Birthday Week 2026 一口气放出一串产品。最硬的是 Cloudflare Basin 正式 GA——建立在 Apache Iceberg + R2 对象存储之上的无服务器数据/分析平台，官方卖点是「无数据 egress 费用」地摄取和查询大规模数据集。同天 Workers KV Instant 上线，官方实测读延迟 p99 低于 2ms、比经典模式快百倍以上，仍沿用熟悉的 Workers KV API；Workers 还新增了对后量子算法 ML-KEM / ML-DSA 的 opt-in 支持。对边缘计算栈的人，Basin 补上了此前缺的「自带数据建分析应用」一环，KV Instant 则直接去掉了冷读惩罚。

→ [Basin](https://blog.cloudflare.com/cloudflare-basin) / [KV Instant](https://blog.cloudflare.com/workers-kv-instant) / [后量子加密](https://blog.cloudflare.com/workers-ml-kem-ml-dsa-support)

### Earendil 发布 Pi 1.0，掉头加上 MCP 支持

由 Armin Ronacher 等人组建、今年 4 月收购 Pi 的 Earendil，发布了编码 agent Pi 的首个稳定版 1.0——官方自称「硬化、极简、可自定义的 agent harness」，类比成 Python Web 框架的话是 Flask 而不是 Django，已有数十万人每周在用。此前 Pi 对 MCP 态度保留，这次 1.0 直接加入了 MCP 支持，并带上 harness 侧的工具调用沙箱、deferred tool loading、会话中途系统消息等。同时还发布了实验性的 Pi Durable 包，面向可在任意 JS 运行时跑的长时/持久 agent（持久化会话与操作状态，中断后不重复已完成的副作用），但它不替代 Pi 编码 agent。MCP 又添一个重量级宿主，关注 MCP 生态的可以读下它的 harness 规范。

→ [Pi 1.0](https://earendil.com/posts/pi-1-0) / [Pi Durable](https://earendil.com/posts/pi-durable) / [The Register 报道](https://www.theregister.com/ai-and-ml/2026/10/02/pi-coding-agent-pulls-a-180-and-adds-mcp-support/)
