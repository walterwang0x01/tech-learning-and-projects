  - **建议动作**：1) 给 SceneRouter 工具调用加白名单——只允许调用 `app/scenes/*/tools` 目录里登记过的工具，第三方 MCP server 必须显式登记；2) 把所有外部 MCP server 包到 Docker 沙箱里（cap-drop=ALL 起步），网络限制到目标域名 allowlist；3) 工具参数从 LLM 输出之前必须经过 schema 校验（Pydantic），任何 shell 调用走 `subprocess.run([...], shell=False)`；4) 把 `app/services/agent_executor.py` 的工具调用日志接到独立审计表，便于事后追溯
