> 特征工程是机器学习成功的关键步骤

## 1. 特征工程概述

特征工程包括：
- 特征选择
- 特征变换
- 特征创建
- 特征编码

## 2. 特征选择

### 2.1 相关性分析

```python
import pandas as pd
import numpy as np

# 计算相关性
correlation = df.corr()
print(correlation)

# 选择高相关性特征
high_corr_features = correlation[correlation > 0.8].stack().reset_index()
high_corr_features = high_corr_features[high_corr_features[0] != 1.0]
```

### 2.2 特征重要性

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import SelectFromModel

# 训练模型获取特征重要性
model = RandomForestClassifier()
model.fit(X, y)

# 选择重要特征
selector = SelectFromModel(model, threshold='median')
X_selected = selector.fit_transform(X, y)
```

### 2.3 方差过滤

```python
from sklearn.feature_selection import VarianceThreshold

# 移除低方差特征
selector = VarianceThreshold(threshold=0.01)
X_selected = selector.fit_transform(X)
```

## 3. 特征变换

### 3.1 对数变换

```python
# 处理偏态分布
df['log_feature'] = np.log1p(df['feature'])
```

### 3.2 标准化和归一化

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 归一化
min_max_scaler = MinMaxScaler()
X_normalized = min_max_scaler.fit_transform(X)
```

### 3.3 分箱

```python
# 等宽分箱
df['age_bin'] = pd.cut(df['age'], bins=5, labels=['低', '中低', '中', '中高', '高'])

# 等频分箱
df['age_bin'] = pd.qcut(df['age'], q=5, labels=['低', '中低', '中', '中高', '高'])
```

## 4. 特征创建

### 4.1 组合特征

```python
# 数值特征组合
df['total'] = df['feature1'] + df['feature2']
df['product'] = df['feature1'] * df['feature2']
df['ratio'] = df['feature1'] / df['feature2']

# 类别特征组合
df['category_combo'] = df['cat1'] + '_' + df['cat2']
```

### 4.2 时间特征

```python
df['year'] = df['date'].dt.year
df['month'] = df['date'].dt.month
df['day_of_week'] = df['date'].dt.dayofweek
df['is_weekend'] = df['date'].dt.dayofweek >= 5
```

### 4.3 文本特征

```python
# 文本长度
df['text_length'] = df['text'].str.len()

# 词数
df['word_count'] = df['text'].str.split().str.len()

# 特殊字符数
df['special_chars'] = df['text'].str.count(r'[!@#$%^&*()]')
```

## 5. 特征编码

### 5.1 One-Hot编码

```python
df_encoded = pd.get_dummies(df, columns=['category'], prefix='cat')
```

### 5.2 Label编码

```python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
df['category_encoded'] = le.fit_transform(df['category'])
```

### 5.3 Target编码

```python
# 基于目标变量的编码
target_mean = df.groupby('category')['target'].mean()
df['category_target_encoded'] = df['category'].map(target_mean)
```

## 6. 总结

特征工程要点：
- **特征选择**：相关性、重要性、方差
- **特征变换**：对数、标准化、分箱
- **特征创建**：组合、时间、文本特征
- **特征编码**：One-Hot、Label、Target编码

良好的特征工程可以显著提升模型性能。

> 🔄 更新于 2026-07-08

<!-- version-check: scikit-learn 1.9.0, narwhals, checked 2026-07-08 -->

scikit-learn 1.9.0 于 2026-06-02 发布，对特征工程流水线有三项直接影响：**实验性 Callback API**、**narwhals DataFrame 互操作**、以及 **Pandas 3 `StringDtype` 兼容性修复**。

### 7.1 Callback API：特征工程进度可视化

1.9 引入实验性回调机制，可在 `fit` 过程中插入进度条和评分监控。与特征工程直接相关的支持对象：

- `StandardScaler`（标准化步骤）
- `Pipeline`（多步特征变换组合）
- `GridSearchCV` / `RandomizedSearchCV` / `HalvingGridSearchCV`（超参搜索中的特征管线调优）
- `LogisticRegression(solver="lbfgs")`（Target 编码后的验证模型）

```python
from sklearn.callback import ProgressBar, ScoringMonitor
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.linear_model import LogisticRegression

pipe = Pipeline([
    ("scale", StandardScaler()),
    ("select", SelectKBest(f_classif, k=10)),
    ("clf", LogisticRegression(solver="lbfgs", max_iter=200)),
])

# 嵌套进度条：Pipeline 各步骤 + 内部 estimator 均可见
monitor = ScoringMonitor(scoring="accuracy")
pipe.set_callbacks(monitor, ProgressBar())
pipe.fit(X_train, y_train)

# 查看每步评分日志
logs = monitor.get_logs().data_as_pandas
print(logs[["task_name", "task_id", "accuracy"]])
```

> Callback API 目前为实验性，可能在不走常规 deprecation 周期的情况下变更。GPU Array API 模式下暂不支持 callbacks。

来源：[Callbacks 用户指南](https://scikit-learn.org/stable/callbacks.html)、[1.9 Release Highlights](https://scikit-learn.org/stable/auto_examples/release_highlights/plot_release_highlights_1_9_0.html)

### 7.2 narwhals：Pandas 3 / Polars 统一输入

scikit-learn 1.9 新增 [narwhals](https://narwhals-dev.github.io/narwhals/) 依赖，替代已被 Polars 弃用的 DataFrame Interchange Protocol（`__dataframe__`），让 `set_output(transform="pandas")` 和 estimator 输入同时支持 Pandas 与 Polars：

```python
import polars as pl
from sklearn.preprocessing import StandardScaler

# Polars DataFrame 直接作为输入（1.9+）
pldf = pl.DataFrame({"age": [25, 30, 35], "income": [50000, 60000, 70000]})
scaler = StandardScaler()
scaler.set_output(transform="pandas")  # 输出仍为 pandas（或 polars，视配置）

X_scaled = scaler.fit_transform(pldf)
```

特征工程典型工作流：Polars 做大规模 ETL → 直接喂给 sklearn Pipeline，无需 `to_pandas()` 中转。

### 7.3 Pandas 3 兼容性修复

Pandas 3 默认 `StringDtype` 替代 `object` 存储字符串列。1.9 修复了 `check_array(dtype="numeric")` 对 `StringDtype` 的静默放行问题——现在会正确抛出 `ValueError`，避免字符串列误入数值特征管线：

```python
import pandas as pd
from sklearn.utils.validation import check_array

df = pd.DataFrame({"name": ["alice", "bob"], "age": [25, 30]})
# Pandas 3: name 列 dtype 为 StringDtype

# 1.9 修复前：静默接受字符串列
# 1.9 修复后：正确拒绝
try:
    check_array(df[["name"]], dtype="numeric")
except ValueError as e:
    print(f"预期错误: {e}")
```

同时 `PowerTransformer(method="yeo-johnson")` 改用 `scipy.stats.yeojohnson`，数值稳定性更好，偏态特征变换结果更可靠。

### 7.4 GPU 加速特征相关 estimator（预览）

1.9 在 Array API 兼容路径上扩展了 GPU 支持，与特征工程相关的包括：

| Estimator / 函数 | GPU 支持（lbfgs / Array API） |
| ---------------- | --------------------------- |
| `LogisticRegression` | ✅ `solver="lbfgs"` |
| `PoissonRegression` | ✅ `solver="lbfgs"` |
| `average_precision_score` 等指标 | ✅ |
| `Nystroem` 核近似 | ✅ |

```python
# 需要安装支持 Array API 的后端（如 cupy）
# sklearn.config_context(array_api_dispatch=True) 下自动调度 GPU
from sklearn.linear_model import LogisticRegression

clf = LogisticRegression(solver="lbfgs")
# 当 X 为 cupy/cupy.array 且 array_api_dispatch=True 时走 GPU
```

> GPU 路径的用户体验尚不如 NumPy 默认后端，适合已有 GPU 基础设施的团队试点。
