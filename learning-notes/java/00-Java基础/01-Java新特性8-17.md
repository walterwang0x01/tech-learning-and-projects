## Java 8 新特性

### 1. Lambda表达式

Lambda表达式是Java 8最重要的特性之一，它允许我们将函数作为方法的参数，或者将代码本身当作数据处理。

**语法格式：**
```java
(parameters) -> expression
或
(parameters) -> { statements; }
```

**示例：**
```java
// 旧写法
Collections.sort(list, new Comparator<String>() {
    @Override
    public int compare(String s1, String s2) {
        return s1.compareTo(s2);
    }
});

// Lambda表达式写法
Collections.sort(list, (s1, s2) -> s1.compareTo(s2));
```

### 2. 函数式接口

函数式接口是只包含一个抽象方法的接口。Java 8提供了`@FunctionalInterface`注解来标识函数式接口。

**常用的函数式接口：**
- `Function<T, R>`: 接受一个参数，返回一个结果
- `Consumer<T>`: 接受一个参数，无返回值
- `Supplier<T>`: 无参数，返回一个结果
- `Predicate<T>`: 接受一个参数，返回boolean值

**示例：**
```java
@FunctionalInterface
public interface MyFunction {
    int apply(int x, int y);
}

MyFunction add = (x, y) -> x + y;
MyFunction multiply = (x, y) -> x * y;
```

### 3. Stream API

Stream API是Java 8中处理集合的关键抽象概念，它可以让你以一种声明的方式处理数据集合。

**Stream的特点：**
- 不是数据结构，不会存储数据
- 不会改变源数据，会返回一个新的Stream
- 延迟执行，只有在终端操作时才会执行
- 可以并行处理

**常用操作：**
```java
List<String> list = Arrays.asList("a", "b", "c", "d");

// 过滤
list.stream().filter(s -> s.startsWith("a")).forEach(System.out::println);

// 映射
list.stream().map(String::toUpperCase).forEach(System.out::println);

// 排序
list.stream().sorted().forEach(System.out::println);

// 收集
List<String> result = list.stream()
    .filter(s -> s.length() > 1)
    .collect(Collectors.toList());
```

### 4. 接口默认方法和静态方法

Java 8允许在接口中定义默认方法和静态方法。

**默认方法：**
```java
public interface MyInterface {
    default void defaultMethod() {
        System.out.println("Default method");
    }
}
```

**静态方法：**
```java
public interface MyInterface {
    static void staticMethod() {
        System.out.println("Static method");
    }
}
```

### 5. 新的日期和时间API

Java 8引入了新的日期和时间API（java.time包），解决了旧API的线程安全问题。

**主要类：**
- `LocalDate`: 日期（年月日）
- `LocalTime`: 时间（时分秒）
- `LocalDateTime`: 日期时间
- `ZonedDateTime`: 带时区的日期时间
- `Duration`: 时间间隔
- `Period`: 日期间隔

**示例：**
```java
// 获取当前日期
LocalDate today = LocalDate.now();

// 创建指定日期
LocalDate date = LocalDate.of(2024, 1, 1);

// 日期格式化
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
String formatted = date.format(formatter);

// 日期解析
LocalDate parsed = LocalDate.parse("2024-01-01", formatter);
```

### 6. Optional类

Optional类是一个容器类，可以保存类型T的值，或者仅仅保存null。Optional提供很多有用的方法，这样我们就不用显式进行空值检测。

**示例：**
```java
Optional<String> optional = Optional.of("value");
optional.ifPresent(System.out::println);
String value = optional.orElse("default");
```

### 7. 方法引用

方法引用是Lambda表达式的简化写法。

**四种方法引用类型：**
1. 静态方法引用：`ClassName::staticMethod`
2. 实例方法引用：`instance::instanceMethod`
3. 类的实例方法引用：`ClassName::instanceMethod`
4. 构造器引用：`ClassName::new`

**示例：**
```java
List<String> list = Arrays.asList("a", "b", "c");
list.forEach(System.out::println); // 方法引用
list.forEach(s -> System.out.println(s)); // Lambda表达式
```

### 8. 并发增强

Java 8在并发方面做了很多改进：
- `CompletableFuture`: 异步编程
- `StampedLock`: 新的锁机制
- `LongAdder`: 高并发计数器

> Java 21 于 2023 年 9 月发布，是继 Java 17 之后的下一个长期支持版本，也是目前企业级开发的推荐版本。

### 1. Virtual Threads（虚拟线程，正式）

虚拟线程是 Java 21 最重要的特性，由 Project Loom 引入。虚拟线程是轻量级线程，由 JVM 调度而非操作系统，可以轻松创建数百万个并发线程。

**核心优势：**
- 轻量级：每个虚拟线程仅占用几 KB 内存（平台线程约 1MB）
- 高并发：可创建数百万个虚拟线程
- 编程模型简单：使用同步代码风格实现异步性能

```java
// 创建虚拟线程
Thread.startVirtualThread(() -> {
    System.out.println("运行在虚拟线程中: " + Thread.currentThread());
});

// 使用 ExecutorService
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    // 轻松提交百万级任务
    IntStream.range(0, 1_000_000).forEach(i -> {
        executor.submit(() -> {
            Thread.sleep(Duration.ofSeconds(1));
            return i;
        });
    });
}

// Spring Boot 3.2+ 启用虚拟线程
// application.yml:
// spring.threads.virtual.enabled: true
```

### 2. Record Patterns（记录模式，正式）

允许对 Record 类型进行解构，与 `instanceof` 和 `switch` 配合使用。

```java
record Point(int x, int y) {}

// 解构 Record
if (obj instanceof Point(int x, int y)) {
    System.out.println("坐标: " + x + ", " + y);
}

// 嵌套解构
record Line(Point start, Point end) {}

if (obj instanceof Line(Point(int x1, int y1), Point(int x2, int y2))) {
    System.out.println("线段: (" + x1 + "," + y1 + ") -> (" + x2 + "," + y2 + ")");
}
```

### 3. Pattern Matching for switch（正式）

switch 表达式的模式匹配正式发布，支持类型模式、守卫条件和 null 处理。

```java
// 类型模式 + 守卫条件
String describe(Object obj) {
    return switch (obj) {
        case Integer i when i > 0 -> "正整数: " + i;
        case Integer i            -> "非正整数: " + i;
        case String s when s.isEmpty() -> "空字符串";
        case String s             -> "字符串: " + s;
        case null                 -> "null 值";
        default                   -> "其他类型";
    };
}
```

### 4. Sequenced Collections（有序集合）

新增三个接口：`SequencedCollection`、`SequencedSet`、`SequencedMap`，统一了有序集合的访问方式。

```java
// 统一的首尾元素访问
SequencedCollection<String> list = new ArrayList<>(List.of("a", "b", "c"));
list.getFirst();    // "a"
list.getLast();     // "c"
list.addFirst("z"); // 在头部添加
list.reversed();    // 反转视图

SequencedMap<String, Integer> map = new LinkedHashMap<>();

map.put("b", 2);

map.pollLastEntry(); // 移除并返回最后一个

### 1. Stream Gatherers（正式，JEP 485）

    .gather(Gatherers.windowFixed(3))
    .toList();
// 结果: [[1, 2, 3], [4, 5, 6]]

// 内置 Gatherer：滑动窗口
List<List<Integer>> sliding = Stream.of(1, 2, 3, 4, 5)
    .gather(Gatherers.windowSliding(3))
    .toList();
// 结果: [[1, 2, 3], [2, 3, 4], [3, 4, 5]]

// 自定义 Gatherer：去重（按属性）
Gatherer<String, ?, String> distinctByLength = Gatherer.ofSequential(
    HashSet::new,
    (state, element, downstream) -> {
        if (state.add(element.length())) {
            downstream.push(element);
        }
        return true;
    }
);
```

### 1. Compact Object Headers（正式，JEP 519）

对象头从 12 字节压缩到 8 字节，在 Java 25 中**默认启用**。对于小对象密集的应用（如 ORM、微服务、集合操作），堆内存节省约 10-20%，CPU 消耗可降低约 30%。

```java
// 验证 Compact Object Headers 是否开启
// 默认已开启（Java 25）
// 检查 JVM 参数：-XX:+UseCompactObjectHeaders

public class ObjectHeaderDemo {
    public static void main(String[] args) {
        long before = getHeapUsed();
        Object[] arr = new Object[1_000_000];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = new Object();
        }
        long after = getHeapUsed();
        // Java 25 默认：每对象 8 字节头（Java 24 仍需 -XX:+UseCompactObjectHeaders）
        System.out.printf("百万对象占用：%d MB%n", (after - before) / 1024 / 1024);
    }

    static long getHeapUsed() {
        Runtime rt = Runtime.getRuntime();
        return rt.totalMemory() - rt.freeMemory();
    }
}
```

来源：[OpenJDK JEP 8361187: Compact Object Headers by Default](https://openjdk.org/jeps/8361187)

### 2. Ahead-of-Time Method Profiling（正式，JEP 515）

运行时收集方法调用画像，在 AOT 缓存中持久化，下次启动时直接用画像来做内联、去虚拟化等优化。典型的 Spring Boot 应用**启动时间降低 30%** 以上。

```bash
# 第 1 步：记录训练运行画像
java -XX:AOTMode=record -XX:AOTConfiguration=app.aotconf \
     -jar app.jar

# 第 2 步：根据画像生成 AOT 缓存
java -XX:AOTMode=create -XX:AOTConfiguration=app.aotconf \
     -XX:AOTCache=app.aot -jar app.jar

# 第 3 步：生产运行时加载 AOT 缓存
java -XX:AOTCache=app.aot -jar app.jar
# 启动时间显著缩短，JIT 峰值性能更快达到
```

### 3. Scoped Values（正式，JEP 506）

正式取代大部分 `ThreadLocal` 使用场景，尤其适合虚拟线程。Scoped Values 是**不可变的线程局部数据**，性能和内存都优于 ThreadLocal。

```java
// 声明 Scoped Value
public class RequestContext {
    public static final ScopedValue<String> USER_ID = ScopedValue.newInstance();
    public static final ScopedValue<String> TRACE_ID = ScopedValue.newInstance();
}

// 绑定作用域，只在 where() 内的代码可见
public class Server {
    void handleRequest(HttpRequest req) {
        ScopedValue.where(RequestContext.USER_ID, req.userId())
                   .where(RequestContext.TRACE_ID, req.traceId())
                   .run(() -> {
                       // 在此作用域内，任何被调用的方法都能读取这些值
                       processBusinessLogic();
                   });
    }

    void processBusinessLogic() {
        // 读取 scoped value
        String userId = RequestContext.USER_ID.get();
        String traceId = RequestContext.TRACE_ID.get();
        // ... 业务逻辑
    }
}
```

### 4. Structured Concurrency（第五次预览，JEP 505）

仍在预览阶段，但 API 已基本稳定，是 Virtual Threads 的配套能力，用于管理一组需要协同完成的并发任务。

```java
import java.util.concurrent.StructuredTaskScope;

record Order(String user, List<Item> items, Payment payment) {}

Order fetchOrder(String orderId) throws Exception {
    try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
        // 并发发起三个请求
        var userTask = scope.fork(() -> userService.getUser(orderId));
        var itemsTask = scope.fork(() -> itemService.getItems(orderId));
        var paymentTask = scope.fork(() -> paymentService.getPayment(orderId));

        scope.join();          // 等待所有任务完成
        scope.throwIfFailed(); // 任一失败则抛出

        return new Order(userTask.get(), itemsTask.get(), paymentTask.get());
    }
}
// 优势：结构化的 try-with-resources，自动取消未完成任务，清晰的错误传播
```

### 5. JFR CPU-Time Profiling（实验性，JEP 509）

Linux 上的 Java Flight Recorder 新增基于 CPU 时间的采样，而非墙钟时间。这样**阻塞 I/O 的线程不会污染性能画像**，CPU 热点更准确。

```bash
# 开启 CPU-Time 采样
java -XX:StartFlightRecording=filename=app.jfr,settings=profile \
     -XX:FlightRecorderOptions=experimental=true \
     -jar app.jar

# 分析 JFR 文件
jfr print --events jdk.CPUTimeSample app.jfr
```

### 6. Generational Shenandoah（正式）

Shenandoah GC 正式支持分代模式，与分代 ZGC 一起提供了现代低延迟 GC 的两条路线。

```bash
# 启用分代 Shenandoah
java -XX:+UseShenandoahGC -XX:ShenandoahGCMode=generational -jar app.jar

# 对比：分代 ZGC（Java 24+ 默认）
java -XX:+UseZGC -jar app.jar
```

## 总结

Java 8-24 的演进主要围绕以下几个方面：
1. **函数式编程**：Lambda 表达式、Stream API、函数式接口、Stream Gatherers
2. **类型推断与模式匹配**：var 关键字、instanceof 模式匹配、switch 模式匹配、Record Patterns
3. **模块化**：模块系统、Module Import Declarations
4. **语法简化**：记录类、文本块、switch 表达式、Simple Source Files
5. **并发革命**：Virtual Threads、Structured Concurrency、Scoped Values
6. **性能优化**：ZGC 分代模式、Compact Object Headers、AOT 类加载
7. **API 增强**：日期时间 API、HTTP Client、Sequenced Collections、Foreign Function & Memory API
8. **安全增强**：后量子密码学（ML-KEM、ML-DSA）

Java 21 是当前企业级开发的最佳选择，Virtual Threads 彻底改变了 Java 并发编程模型。
