## 1. 前向加噪：一条马尔可夫链

扩散模型（diffusion model）的核心想法很朴素：**先定义一个把图像逐步破坏成纯噪声的过程（前向过程），再训练一个网络学会这个过程的逆过程（反向过程）**。生成图像就是从纯噪声出发，一步步执行反向过程。

前向过程被定义成一条马尔可夫链（Markov chain）：每一步只在上一步基础上加入少量高斯噪声，共执行 `T` 步（通常几百到上千）。

```
x0 --(加噪)--> x1 --(加噪)--> x2 --...--> x_{T-1} --(加噪)--> xT
x0：原始图像          xT：几乎纯高斯噪声（信号完全被破坏）
```

单步加噪的定义（`beta_t` 是第 `t` 步的噪声强度，噪声调度，通常随 `t` 增大而增大）：

```
q(x_t | x_{t-1}) = N( x_t ; sqrt(1-beta_t) * x_{t-1} ,  beta_t * I )
```

用重参数化技巧（reparameterization trick）把这个高斯分布写成可采样、可求导的形式：

```
x_t = sqrt(1 - beta_t) * x_{t-1} + sqrt(beta_t) * eps_t,   eps_t ~ N(0, I)
```

这一步是马尔可夫性质的直接体现——`x_t` 只依赖 `x_{t-1}` 和一个新采样的噪声，不需要知道更早的历史。

## 2. 任意时刻重参数化：跳过中间步骤

如果训练时每次都要从 `x0` 递归执行 `t` 次加噪才能拿到 `x_t`，训练效率会很差。扩散模型一个关键推导是：**任意时刻的 `x_t` 可以由 `x0` 和一个单一的噪声采样直接算出**，不需要逐步递推。

推导思路：令 `alpha_t = 1 - beta_t`，反复代入递推式展开两步，两个独立高斯噪声的线性组合仍是高斯（方差直接相加），不断展开到 `x0`，定义 `alpha_bar_t = alpha_1 * alpha_2 * ... * alpha_t`（所有 `alpha` 的累乘），最终得到闭式解：

```
x_t = sqrt(alpha_bar_t) * x0 + sqrt(1 - alpha_bar_t) * eps,   eps ~ N(0, I)
```

意义：**给定原始图像 `x0`，想要哪个时刻 `t` 的加噪结果，只需采样一个标准高斯噪声，按 `alpha_bar_t` 决定的比例混合信号和噪声即可一步得到**，不需要逐步递推。`alpha_bar_t` 随 `t` 增大单调递减，`t` 足够大时趋近 0，`x_t` 趋近纯噪声，与马尔可夫链定义的直觉一致。这个重参数化技巧是扩散模型训练效率的基础——训练时对任意 `t` 都能直接采样。

## 3. 反向去噪：为什么预测噪声而不是预测图像

反向过程要学习 `q(x_{t-1} | x_t)`——给定当前噪声更重的 `x_t`，恢复噪声更轻的 `x_{t-1}`。这个分布数学上无法直接求解（需要知道 `x0`，而生成时 `x0` 正是要求的答案），所以用神经网络 `p_theta(x_{t-1} | x_t)` 近似它。

网络输出目标可以是**直接预测 `x0`**，也可以是**预测混入的噪声 `eps`**。DDPM 选择后者：预测 `x0` 时任务难度随 `t` 剧烈变化（`t` 小时简单，`t` 大时几乎"无中生有"），而预测 `eps` 无论 `t` 大小任务性质都一致，训练信号更稳定；且已知 `x_t = sqrt(alpha_bar_t)*x0 + sqrt(1-alpha_bar_t)*eps`，预测出 `eps` 即可反解 `x0` 估计，二者数学等价，但 `eps` 数值尺度更稳定（始终标准正态，不随内容和 `t` 变化）。

网络实际输入是 `(x_t, t)`，输出 `eps_theta(x_t, t)`——`t` 必须编码成时间嵌入（类似 Transformer 位置编码）作为条件输入，因为同一个 `x_t` 在不同 `t` 下对应的噪声强度完全不同。

## 4. 训练损失的简化形式

完整训练目标来自变分下界（variational lower bound），推导涉及逐步 KL 散度求和，形式复杂。DDPM 的重要发现是：**化简后等价于一个极简的均方误差损失**：

```
L_simple = E_{t, x0, eps} [ || eps - eps_theta(x_t, t) ||^2 ]
其中 x_t = sqrt(alpha_bar_t) * x0 + sqrt(1-alpha_bar_t) * eps
```

训练一步：①采样真实图像 `x0`；②随机采样 `t ~ Uniform(1,T)`；③采样噪声 `eps ~ N(0,I)`；④用闭式解算出 `x_t`；⑤网络前向 `eps_hat = eps_theta(x_t, t)`；⑥损失 `= || eps - eps_hat ||^2`，反向传播。这个形式简单到几乎是"给图像加已知噪声，训练网络猜出噪声"，但背后是变分下界严格推导后各项系数恰好化简掉的结果——工程实现极简，理论保证不打折扣。

## 5. DDPM 与 DDIM 采样：为何 DDIM 能减步

**DDPM 采样**严格按照训练时定义的马尔可夫链反向执行，从 `xT` 走到 `x0` 需要 `T` 步，每一步都要调用一次网络，`T` 通常几百到上千，采样速度慢是 DDPM 最大的实用问题。

**DDIM**（Denoising Diffusion Implicit Models）的关键洞察是：**训练目标（简化后的 MSE 损失）只依赖前向过程的边缘分布 `q(x_t|x0)`（第2节的闭式解），并不依赖马尔可夫链每一步具体怎么转移**。只要训练好的网络 `eps_theta` 不变，可以设计一条**非马尔可夫、跳步的确定性路径**，只要在边缘分布上与原链条一致，就能复用同一网络采样。

```
DDPM: x_T -> x_{T-1} -> x_{T-2} -> ... -> x_1 -> x_0   （必须走完全部T步）
DDIM: x_T -> x_{T-k} -> x_{T-2k} -> ... -> x_0          （可以跳步，k可调）
```

DDIM 采样公式基于闭式解反解出 `x0` 的估计，再按目标时刻 `alpha_bar` 重新混合：

```
x0_hat = (x_t - sqrt(1-alpha_bar_t) * eps_theta(x_t, t)) / sqrt(alpha_bar_t)
x_{t-1} = sqrt(alpha_bar_{t-1}) * x0_hat + sqrt(1-alpha_bar_{t-1}) * eps_theta(x_t, t)
```

这个更新式子没有额外随机噪声项（可设为完全确定性），且能直接跳到任意目标时刻。代价是：**跳步越大，对 `x0` 的估计误差越大**——网络是在训练时看到的中间步长度分布上学到去噪能力，步子跳得远超训练分布，估计会更不准，步数极少时图像质量会下降。DDIM 本质是在采样速度和保真度之间做权衡，通常十几到几十步就能接近 DDPM 几百步的效果。

## 6. Latent Diffusion：把计算搬到隐空间

DDPM 直接在像素空间（pixel space）对图像加噪去噪，一张高分辨率图像本身维度很大，每一步都要在完整像素网格上跑一次 U-Net，计算量随分辨率平方级增长，是早期扩散模型生成成本高、速度慢的主要原因。

**Latent Diffusion 先用自编码器（VAE）把图像压缩到远小得多的隐空间（latent space），扩散过程完全在这个低维隐空间进行**：图像先经 Encoder 得到隐向量（如 512x512x3 压缩到 64x64x4），扩散的前向加噪、U-Net 去噪都作用在隐向量 `z_t` 上，最后用 Decoder 把生成的 `z0` 还原成图像。

成本下降的关键点：隐空间尺寸通常远小于原始图像（如每边缩小8倍，总像素数缩小64倍），U-Net 每一步处理的张量体积大幅缩小，而扩散迭代次数不受影响——**节省的是每一步的计算量，不是步数**。代价是重建质量上限被自编码器压缩能力限制，精细高频细节可能在编码-解码中损失。

## 7. U-Net 骨干与 cross-attention 条件注入

扩散模型里预测噪声的网络 `eps_theta` 几乎总是 U-Net 结构：编码器逐步下采样提取多尺度特征，解码器逐步上采样恢复分辨率，编码器解码器对应层之间有跳跃连接（skip connection），保留细节不被下采样丢失。输入是 `x_t` 与时间步 embedding，经下采样编码器到 bottleneck，再经上采样解码器（融合 skip 连接特征）输出预测噪声 `eps_hat`。

要做**文本到图像**这类条件生成，需要把条件信息注入 U-Net。主流做法是在每个分辨率层插入 **cross-attention** 子层：U-Net 当前特征图展平后作为 Query，文本编码器输出的 token 序列作为 Key/Value，每个空间位置根据自身内容"查询"文本描述里相关的词，而非把文本信息笼统加到全局。这与 Transformer 里 cross-attention 机制一致（参考 [../01-Transformer原理/01-注意力机制推导.md](../01-Transformer原理/01-注意力机制推导.md)），只是 Query 来自图像特征、Key/Value 来自文本特征。

## 8. Classifier-Free Guidance：不用分类器也能引导生成

早期条件扩散模型用额外训练的分类器梯度引导生成方向（classifier guidance），需要单独训练分类器，成本高且易引入偏差。**Classifier-Free Guidance（CFG）不需要额外分类器**：训练阶段以一定概率把条件 `c` 替换成空条件 `null`，同一网络 `eps_theta(x_t,t,c)` 既学会有条件去噪也学会无条件去噪；采样时组合两者：

```
eps_final = eps_theta(x_t,t,null) + w * ( eps_theta(x_t,t,c) - eps_theta(x_t,t,null) )
```

`w` 是 guidance scale，`(有条件预测-无条件预测)` 可理解为"条件c拉动去噪结果的方向"，`w>1` 放大这个拉力：`w` 越大与文本一致性越强但多样性下降、可能过饱和；`w` 越小结果更自然但可能不够"听话"。guidance scale 是采样时超参数，无需重新训练，是保真度/一致性与多样性/自然度之间的权衡，是实际使用扩散模型时最常调的参数。

## 9. Flow Matching：另一条建模路线

扩散模型把生成建模成"去噪"，而 **flow matching** 把生成建模成学习一个**从噪声分布到数据分布的连续变换路径（概率流）**，训练目标是直接预测路径每个时刻的速度场（velocity field），而非预测噪声。常取线性插值路径 `x_t=(1-t)*x0+t*x1`，学习速度 `dx_t/dt`。两者数学上紧密相关——扩散模型的反向 SDE/ODE 本身也定义了一条概率流，flow matching 可看作对这条路径做了更直接灵活的参数化，训练目标更简洁，天然支持确定性 ODE 采样，采样步数往往更少。这是当前生成模型研究的活跃方向，与扩散模型并非互斥。

## 10. 代码：验证前向加噪的任意时刻重参数化

用 numpy 验证第2节推导的闭式解——从 `x0` 逐步加噪 `t` 步得到的 `x_t`，和直接用闭式公式一步跳到 `x_t`，二者在统计分布（均值、方差）上应当一致。

```python
import numpy as np

rng = np.random.default_rng(0)


def make_beta_schedule(T, beta_start=1e-4, beta_end=0.02):
    """线性 beta 调度，T 个时间步"""
    return np.linspace(beta_start, beta_end, T)


def forward_diffusion_stepwise(x0, betas):
    """逐步加噪：按马尔可夫链一步步执行 x_t = sqrt(1-beta_t)*x_{t-1} + sqrt(beta_t)*eps_t"""
    T = len(betas)
    x = x0.copy()
    xs = [x0.copy()]
    for t in range(T):
        eps = rng.normal(0, 1, size=x.shape)
        x = np.sqrt(1 - betas[t]) * x + np.sqrt(betas[t]) * eps
        xs.append(x.copy())
    return xs


def forward_diffusion_closed_form(x0, betas, eps_total, t):
    """任意时刻重参数化：x_t = sqrt(alpha_bar_t)*x0 + sqrt(1-alpha_bar_t)*eps
    一步跳到第 t 步，不需要逐步递推"""
    alphas = 1 - betas
    alpha_bar_t = np.prod(alphas[: t + 1])
    return np.sqrt(alpha_bar_t) * x0 + np.sqrt(1 - alpha_bar_t) * eps_total, alpha_bar_t


T = 50
betas = make_beta_schedule(T)
x0 = rng.normal(0, 1, size=(5000,))  # 模拟一批像素/特征值

t_check = 30
xs = forward_diffusion_stepwise(x0, betas)
x_t_stepwise = xs[t_check + 1]

eps_direct = rng.normal(0, 1, size=x0.shape)
x_t_closed, alpha_bar_t = forward_diffusion_closed_form(x0, betas, eps_direct, t_check)

print(f"T={T}, 检查时刻 t={t_check}")
print(f"alpha_bar_t = {alpha_bar_t:.6f}")
print("逐步加噪 x_t：均值={:.6f} 方差={:.6f}".format(x_t_stepwise.mean(), x_t_stepwise.var()))
print("闭式重参数化 x_t：均值={:.6f} 方差={:.6f}".format(x_t_closed.mean(), x_t_closed.var()))

# 重复实验验证分布层面的一致性，而非单次巧合
n_trials = 200
stepwise_vars = [forward_diffusion_stepwise(x0, betas)[t_check + 1].var() for _ in range(n_trials)]
closed_vars = [forward_diffusion_closed_form(x0, betas, rng.normal(0, 1, size=x0.shape), t_check)[0].var()
               for _ in range(n_trials)]

print(f"\n重复{n_trials}次：逐步方差均值={np.mean(stepwise_vars):.6f}  闭式方差均值={np.mean(closed_vars):.6f}")

print("\n不同时刻 t 的 alpha_bar_t（信号保留比例）：")
alphas = 1 - betas
for t in [0, 10, 20, 30, 40, 49]:
    ab = np.prod(alphas[: t + 1])
    print(f"  t={t:<3} alpha_bar_t={ab:.6f}  信号系数={np.sqrt(ab):.4f}  噪声系数={np.sqrt(1-ab):.4f}")
```

实测输出（numpy 2.4.4）：

```
T=50, 检查时刻 t=30
alpha_bar_t = 0.824688
逐步加噪 x_t：均值=-0.005012 方差=0.988432
闭式重参数化 x_t：均值=-0.007693 方差=0.984036

重复200次：逐步方差均值=0.991460  闭式方差均值=0.990741

不同时刻 t 的 alpha_bar_t（信号保留比例）：
  t=0   alpha_bar_t=0.999900  信号系数=0.9999  噪声系数=0.0100
  t=10  alpha_bar_t=0.976802  信号系数=0.9883  噪声系数=0.1523
  t=20  alpha_bar_t=0.916098  信号系数=0.9571  噪声系数=0.2897
  t=30  alpha_bar_t=0.824688  信号系数=0.9081  噪声系数=0.4187
  t=40  alpha_bar_t=0.712486  信号系数=0.8441  噪声系数=0.5362
  t=49  alpha_bar_t=0.602952  信号系数=0.7765  噪声系数=0.6301
```

两种方式算出的方差高度接近（单次 0.988 vs 0.984，200 次重复后均值 0.991 vs 0.991），验证闭式解与逐步链条在统计意义上等价。`alpha_bar_t` 随 `t` 单调下降，信号系数从接近1衰减到0.78，噪声系数从接近0增长到0.63，展示了信息随扩散步数被逐渐淹没的过程。

## 11. 小结

| 主题 | 核心结论 |
| --- | --- |
| 前向过程 | 马尔可夫链逐步加噪，`alpha_bar_t` 累乘决定信号/噪声混合比例 |
| 重参数化 | 任意时刻 `x_t` 可由 `x0` 和单一噪声一步算出，训练时无需递推 |
| 预测目标 | 预测噪声而非图像，任务难度更均匀、数值尺度更稳定 |
| 训练损失 | 变分下界化简为简单 MSE：`|| eps - eps_theta(x_t,t) ||^2` |
| DDPM vs DDIM | DDIM 复用边缘分布、走非马尔可夫确定性路径，可跳步但精度打折 |
| Latent Diffusion | 用 VAE 把扩散计算搬到低维隐空间，省的是每步计算量而非步数 |
| U-Net + cross-attn | 多尺度骨干处理空间信息，cross-attention 让条件按内容注入 |
| CFG | 训练时学会有/无条件两种预测，采样时外推组合控制一致性强度 |
| Flow matching | 直接学习噪声到数据的速度场，路径参数化更灵活，常配 ODE 采样 |
