## 1. 量化为什么有效：权重分布特性

量化（quantization）是把模型权重、激活值从高精度浮点数（如 FP32/FP16）映射到低精度表示（如 INT8/INT4）的过程。它能生效的前提，来自神经网络权重的两个统计特性：

- **权重分布集中且大致对称**：训练收敛后的权重矩阵，绝大多数元素取值集中在 0 附近的较窄区间，呈近似钟形分布。用较少离散取值点（如 INT8 的 256 个整数）就能覆盖绝大多数权重值，不会有大量数值被挤到区间边界导致精度损失。- **网络对权重的微小扰动有一定容忍度**：训练过程依赖大量随机性（初始化、dropout、batch 采样噪声），网络学到的是能容忍一定噪声的解。量化引入的误差在很多任务上可以被鲁棒性"吸收"，不会显著改变输出。

合起来说明：**用更少比特表示权重，映射方式合理时精度损失可控**，同时换来显著的显存节省和推理加速（在支持低精度计算的硬件上）。

## 2. 对称量化与非对称量化

量化本质是把浮点数 `x` 映射到整数 `q`，再乘回缩放系数 `scale` 近似还原：

```
量化：q = round(x / scale) + zero_point
反量化：x_approx = (q - zero_point) × scale
```

### 对称量化（symmetric quantization）

假设数值分布以 0 为中心对称，`zero_point=0`，只需一个 `scale`：

```
scale = max(|x|) / (2^(b-1) - 1)      # b 是量化比特数
q = round(x / scale)                  # q 落在 [-(2^(b-1)-1), 2^(b-1)-1]
```

优点是计算简单（反量化不需额外加减法），缺点是若原始分布本身不对称（比如激活值经 ReLU 后全是非负数），对称量化会浪费一半表示范围。

### 非对称量化（asymmetric quantization）

引入非零 `zero_point`，让量化范围对齐实际数据的最小最大值：

```
scale = (max(x) - min(x)) / (2^b - 1)
zero_point = round(-min(x) / scale)
q = round(x / scale) + zero_point     # q 落在 [0, 2^b - 1]
```

**零点解决的问题**：原始数据分布不以 0 为中心（比如 ReLU 后激活值全部 ≥ 0，或某层权重整体偏正）时，`zero_point` 把整数表示范围"挪动"到跟实际数据对齐的位置，避免表示范围浪费。代价是反量化多一次减法，且 `zero_point` 需额外存储（每个量化组通常只需一个标量，开销很小）。

**如何选择**：权重通常接近对称分布，用对称量化即可；激活值（尤其经过非线性激活后）常呈非对称分布，非对称量化更合适。

## 3. 量化粒度：逐张量、逐通道、逐组量化时 `scale`（和 `zero_point`）的计算范围决定"粒度"，粒度越细精度越高，但存储和计算开销也越高：

| 粒度 | 做法 | 权衡 |
| --- | --- | --- |
| 逐张量（per-tensor） | 整个权重矩阵共享一组 `scale`/`zero_point` | 存储开销最小，但矩阵内数值范围差异大时被最大值主导 |
| 逐通道（per-channel） | 每个输出通道独立一组 `scale` | 精度明显提升，各通道独立缩放更贴合分布 |
| 逐组（per-group） | 每行/每通道内再切成固定大小小组，组内共享 `scale` | 接近逐元素效果，但存储开销随组数上升 |

```
逐张量：[整个矩阵]              → 1 组 scale
逐通道：[行1] [行2] [行3] ...    → 每行 1 组 scale
逐组：  [行1: 组a|组b|组c] ...   → 每行内每组 1 个 scale
```
LLM 权重量化实践中，**逐通道或逐组**是主流选择，逐张量的精度损失在大模型上往往不可接受，叠加离群值问题更明显。

## 4. PTQ 与 QAT

- **PTQ（Post-Training Quantization）**：模型已用浮点数训练完成，量化是训练后的独立步骤，通常只需一小批校准数据估计激活值分布范围，不需重新训练。成本低、速度快，是 LLM 量化的主流方式。
- **QAT（Quantization-Aware Training）**：训练过程中模拟量化的舍入误差（用"伪量化"节点，前向按量化误差计算，反向仍用浮点梯度直通），让模型训练时适应量化噪声。精度通常优于 PTQ，但需完整训练/微调流程，成本高。

LLM 受限于训练成本几乎都用 PTQ，GPTQ、AWQ 等改进方法都是在"不重新训练"约束下让 PTQ 更精确。

## 5. GPTQ：逐层重构误差最小化

GPTQ 是一种 PTQ 方法，核心思路是**逐层、逐权重量化，同时利用未量化权重补偿已量化权重的误差**，而非简单独立舍入每个权重。

数学上，对某层权重矩阵 `W`，量化目标是找到 `Ŵ`，使该层在校准数据上输出误差最小：

```
minimize  || W·X - Ŵ·X ||²
```

`X` 是该层输入激活。直接联合优化所有权重是复杂的组合优化问题，GPTQ 借鉴最优脑外科手术（OBS）思路：**逐列量化，每次量化一列后用剩余未量化列补偿误差**：

```
for 每一列 w_i（按某种顺序遍历）:
    量化 w_i → ŵ_i（舍入到最近的量化格点）
    误差 e = w_i - ŵ_i
    用 e 和 Hessian 矩阵信息，调整剩余未量化的列，抵消误差传播
```

Hessian（对应 `X·Xᵀ`）指导"如何调整剩余权重以最大程度抵消当前量化误差"。相比逐元素独立舍入，这种补偿机制显著降低量化对模型输出的影响，是 GPTQ 能在 INT4 甚至更低比特下仍保持较好精度的关键。

## 6. AWQ：激活感知的量化思路

AWQ（Activation-aware Weight Quantization）核心观察：**并非所有权重同等重要，与"较大激活值"对应的权重通道对量化误差更敏感**。

直觉上，若某输入通道激活值普遍很大，该通道权重即使量化误差微小，乘以大激活值后误差也会被放大；反之小激活值通道即使误差稍大，影响也有限。

AWQ 的做法：**量化前对重要通道（激活值较大）的权重先做缩放放大，量化后在激活值上做反向缩放，让重要通道权重量化前获得更大数值范围，量化后保留更高相对精度**：

```
对通道 j：
  若激活值幅度较大 → 认为该通道重要
  权重缩放：W[:, j] ← W[:, j] × s_j        (s_j > 1)
  激活反向缩放：X[:, j] ← X[:, j] / s_j    (保证 W·X 乘积不变)
  量化 W（缩放后分布更适合量化）
```

不需要像 GPTQ 那样做复杂逐层重构优化，只需按通道缩放，计算成本更低、工程实现更简单，经验上精度保留效果也不错。

## 7. 离群值：LLM 量化的核心难点

**为什么离群值（outlier）在 LLM 量化里格外突出**：与 CNN 等视觉模型不同，Transformer 激活值中会出现少数数值远超其余部分的通道，这些离群通道即便数量很少，也会主导量化时的 `scale` 估计：

```
假设某激活张量：绝大多数值落在 [-2, 2]，少数通道达到 [-50, 50]

逐张量量化，scale 由最大值决定：
  scale = 50 / 127 ≈ 0.39   (INT8)
  绝大多数落在 [-2,2] 的值，量化后只能用约 ±5 个整数格点表示
  → 相对误差非常大，大量信息被压缩到极少的量化格点里
```

离群值的破坏性在于：**数值占比很小，但由于量化范围要覆盖它们，会挤压其余"正常"数值的有效表示精度**。逐通道/逐组量化能部分缓解，但若离群值出现在同一通道不同位置，细粒度分组仍有限。

思路：AWQ 的激活感知缩放（给可能有离群值的重要通道更大数值空间）、**混合精度**（少数离群值单独用更高精度存储，其余正常量化）。

## 8. INT8/INT4/FP8/NF4 对比

| 格式 | 位数 | 特点 |
| --- | --- | --- |
| INT8 | 8 bit | 整数均匀量化，硬件支持成熟，精度损失通常较小，最保守稳妥 |
| INT4 | 4 bit | 显存节省更明显，但均匀格点在权重分布"尾部"表示效率低，通常需配合 GPTQ/AWQ |
| FP8 | 8 bit 浮点 | 保留指数位，动态范围更大，处理数值范围差异大的场景更友好，需硬件原生支持 |
| NF4 | 4 bit | 为**正态分布**权重设计的非均匀量化格点，间距按标准正态分布分位数设置，数值集中区域密度更高，比均匀 INT4 更贴合分布 |

**核心权衡**：均匀量化实现简单、硬件支持广泛；非均匀量化更贴合分布但需专门查表；浮点格式动态范围有优势但需硬件支持。

## 9. KV Cache 量化

KV Cache 本身也可量化——把缓存的 Key/Value 从 FP16 压缩到 INT8 甚至更低比特，进一步降低显存占用（公式见 [01-KV-Cache与显存分析.md](01-KV-Cache与显存分析.md)）。

特殊之处：**它是动态生成的，不能像权重那样离线校准优化**，量化必须在推理过程中实时完成，通常用更简单的逐 token/逐通道对称或非对称量化，而非 GPTQ 迭代优化方案。Key/Value 分布特性可能不同，实践中常分别设置量化参数，比特数越低显存节省越大，但精度损失会直接影响注意力权重准确性。

## 10. 代码：INT8 对称/非对称量化误差与离群值影响

用 numpy 实现 INT8 对称和非对称量化，测量量化误差，并模拟离群值对量化精度的破坏性影响。

```python
import numpy as np

rng = np.random.default_rng(0)

def symmetric_quantize(x, bits=8):
    """对称量化：zero_point=0，范围由 max(|x|) 决定"""
    qmax = 2 ** (bits - 1) - 1  # INT8 -> 127
    scale = np.max(np.abs(x)) / qmax
    q = np.clip(np.round(x / scale), -qmax - 1, qmax)
    return q * scale, scale

def asymmetric_quantize(x, bits=8):
    """非对称量化：零点对齐实际数据的 min/max"""
    qmax = 2 ** bits - 1  # INT8 -> 255
    x_min, x_max = np.min(x), np.max(x)
    scale = (x_max - x_min) / qmax
    zero_point = np.round(-x_min / scale)
    q = np.clip(np.round(x / scale) + zero_point, 0, qmax)
    return (q - zero_point) * scale, scale, zero_point

def quant_error(x, x_dequant):
    """量化误差：均方根误差（RMSE）"""
    return np.sqrt(np.mean((x - x_dequant) ** 2))

# 场景 1：正常近似对称分布的权重
weights_normal = rng.normal(0, 1.0, 10000)
sym_dequant, _ = symmetric_quantize(weights_normal)
asym_dequant, _, _ = asymmetric_quantize(weights_normal)

print("场景 1：近似对称分布的权重（正态分布，均值 0）")
print(f"  对称量化 RMSE:   {quant_error(weights_normal, sym_dequant):.6f}")
print(f"  非对称量化 RMSE: {quant_error(weights_normal, asym_dequant):.6f}")

# 场景 2：非对称分布（模拟 ReLU 后的激活值，全部非负）
activations_relu = np.abs(rng.normal(0, 1.0, 10000))
sym_dequant2, _ = symmetric_quantize(activations_relu)
asym_dequant2, _, _ = asymmetric_quantize(activations_relu)

print("\n场景 2：非对称分布的激活值（ReLU 后，全部非负）")
print(f"  对称量化 RMSE:   {quant_error(activations_relu, sym_dequant2):.6f}  (浪费了一半表示范围)")
print(f"  非对称量化 RMSE: {quant_error(activations_relu, asym_dequant2):.6f}  (范围对齐实际数据)")

# 场景 3：离群值的破坏性影响
# 99.5% 数值集中在 [-2,2]，0.5% 是离群值，幅度达到 ±50
n = 10000
normal_part = rng.normal(0, 1.0, int(n * 0.995))
outlier_part = rng.choice([-50.0, 50.0], size=n - len(normal_part))
data_with_outliers = np.concatenate([normal_part, outlier_part])

_, scale_with = symmetric_quantize(data_with_outliers)
_, scale_without = symmetric_quantize(normal_part)

# 只看"正常范围"数值的量化误差，对比离群值存在与否的影响
dequant_with_outlier_scale = np.round(normal_part / scale_with) * scale_with
dequant_without_outlier_scale = np.round(normal_part / scale_without) * scale_without

print("\n场景 3：离群值对正常数值量化精度的破坏")
print(f"  不含离群值时的 scale: {scale_without:.6f}")
print(f"  含离群值时的 scale:   {scale_with:.6f}  (被拉大了 {scale_with / scale_without:.1f} 倍)")
print(f"  正常数值 RMSE（无离群值 scale）: {quant_error(normal_part, dequant_without_outlier_scale):.6f}")
print(f"  正常数值 RMSE（有离群值 scale）: {quant_error(normal_part, dequant_with_outlier_scale):.6f}  (明显更差)")
```

实测输出（numpy 2.4.4）：

```
场景 1：近似对称分布的权重（正态分布，均值 0）
  对称量化 RMSE:   0.008899
  非对称量化 RMSE: 0.008319

场景 2：非对称分布的激活值（ReLU 后，全部非负）
  对称量化 RMSE:   0.009209  (浪费了一半表示范围)
  非对称量化 RMSE: 0.004568  (范围对齐实际数据)

场景 3：离群值对正常数值量化精度的破坏
  不含离群值时的 scale: 0.035387
  含离群值时的 scale:   0.393701  (被拉大了 11.1 倍)
  正常数值 RMSE（无离群值 scale）: 0.010260
  正常数值 RMSE（有离群值 scale）: 0.113920  (明显更差)
```

三场景验证了机制分析：场景 1 对称分布下两种量化误差接近；场景 2 非对称分布下对称量化误差明显更大（浪费表示范围）；场景 3 展示离群值把 `scale` 拉大十倍以上，导致正常数值量化误差被放大超过 10 倍——这正是逐通道/逐组量化与 AWQ 要解决的核心问题。

## 11. 小结

| 主题 | 核心结论 |
| --- | --- |
| 量化有效前提 | 权重分布集中近似对称，网络对权重扰动有一定容忍度 |
| 对称 vs 非对称 | 对称简单但浪费非对称分布的表示范围；非对称用零点对齐实际数据范围 |
| 量化粒度 | 逐张量最省但精度低，逐通道/逐组更贴合分布，是 LLM 量化主流 |
| PTQ vs QAT | PTQ 不需重训，是 LLM 主流；QAT 精度更好但训练成本高 |
| GPTQ | 逐列量化 + Hessian 信息补偿误差 |
| AWQ | 识别激活值大的重要通道，量化前放大其权重、量化后反向缩放激活 |
| 离群值问题 | 少数极端值主导 scale 估计，挤压其余数值有效精度 |
| 格式选择 | INT8 稳妥，INT4 需误差补偿，FP8 动态范围大，NF4 贴合正态分布权重 |
| KV Cache 量化 | 动态生成、无法离线校准，通常用更简单的逐 token/逐通道量化 |
