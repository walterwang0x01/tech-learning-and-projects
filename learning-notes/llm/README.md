# 大模型原理与工程

> Author: Walter Wang

本目录讲**大模型内部怎么运作**，与 `../ai-agent/00-基础概念/02-大语言模型基础.md` 的分工是：

| 位置 | 视角 | 典型问题 |
| --- | --- | --- |
| `../ai-agent/00-基础概念/02-大语言模型基础.md` | **使用视角** | 上下文窗口多大、怎么调 API、Prompt Caching 怎么省钱、模型怎么选 |
| `llm/`（本目录） | **原理视角** | 注意力为什么要除 sqrt(d_k)、RoPE 凭什么能外推、DPO 怎么从 RLHF 推导出来、KV Cache 占多少显存 |

两者互补，不重复。遇到「这个模型为什么会这样输出」「微调为什么没效果」「推理成本为什么下不来」这类问题时看本目录。

每篇约定：开头列「读完你能回答的 3 个问题」，正文含**可运行的 numpy 实现**（不依赖 torch/transformers），结尾有小结表格。
