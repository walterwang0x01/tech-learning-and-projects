## 1. 为什么需要位置编码：自注意力的排列不变性

自注意力本身是**排列不变的（permutation-invariant）**——如果把输入序列的位置打乱重排，注意力机制算出的每个位置的输出也只是被相应打乱，整个计算过程感知不到"谁在前谁在后"。这一点从[缩放点积注意力](01-注意力机制推导.md)的公式本身就能看出：`Attention(Q,K,V) = softmax(Q·Kᵀ/sqrt(d_k))·V` 里，`Q`、`K`、`V` 都是逐位置独立计算的线性变换，公式本身不包含任何"位置索引"信息——把输入序列的 token 顺序打乱，只是把矩阵的行重新排列，注意力计算的结果也只是相应地重新排列，模型无法从计算过程本身分辨出原始顺序。

但语言的顺序显然携带语义信息（"狗咬人"和"人咬狗"意思完全不同），所以必须显式地把位置信息注入模型。位置编码（Positional Encoding）就是要解决这个问题：给每个位置生成一个携带位置信息的向量，通常直接加到词嵌入上，一起送进后续的注意力计算。

## 2. 正弦位置编码：设计动机与数学性质

Transformer 原始设计采用正弦/余弦函数构造位置编码，直接加到词嵌入上：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

pos: 位置索引（第几个 token）
i:   维度索引（第几个维度对，每两维用一对 sin/cos）
```

设计动机有两点。**动机一：每个位置得到一个唯一且有界的编码**——正弦函数的值域始终在 `[-1, 1]`，不会随位置增大而无界增长（不像直接用位置的整数值 0, 1, 2, ... 作为编码，数值会随序列变长而无限增大，破坏数值稳定性）。**动机二：具备相对位置的可推导性**——正弦函数有一个关键数学性质：`PE(pos+k)` 可以表示成 `PE(pos)` 的一个线性变换（利用三角函数的和角公式 `sin(a+b)=sin(a)cos(b)+cos(a)sin(b)`、`cos(a+b)=cos(a)cos(b)-sin(a)sin(b)`）。这意味着**模型有可能通过简单的线性运算，从任意位置的编码推导出与它相隔固定距离 `k` 的位置编码**，组合系数只依赖固定偏移 `k`、不依赖 `pos` 本身，这为模型学习"相对位置关系"（而不仅是绝对位置）提供了数学基础。

## 3. 可学习位置编码

另一种更直接的方案：不设计固定公式，而是把每个位置对应一个可训练的向量，和词嵌入一样通过反向传播学习得到（相当于维护一个 `[最大序列长度, d_model]` 的位置嵌入表，按位置索引直接查表）。可学习编码的表达能力更灵活（不受固定公式形式约束），但受训练时见过的最大长度限制，超出训练长度的位置没有对应的可学习向量，外推能力差；正弦编码的公式对任意位置都有定义，理论上能直接套用到比训练时更长的序列，但实践中长度大幅超出训练范围时效果同样会退化。

## 4. RoPE 旋转位置编码：原理与外推优势

RoPE（Rotary Position Embedding）是目前主流大模型（如 Llama、Qwen 系列）广泛采用的位置编码方案，思路与前两种都不同：**不是把位置信息加到词向量上，而是通过旋转变换，把位置信息直接编码进 Query 和 Key 的相对角度关系里**。

核心思想：把 Query/Key 向量的每一对维度看作二维平面上的一个点，按位置索引对这个点做一个旋转操作，旋转角度与位置成正比：

```
对 d 维向量的第 (2i, 2i+1) 这一对维度，位置为 pos 时的旋转：

  [x_{2i}']     [cos(pos·θ_i)   -sin(pos·θ_i)]   [x_{2i}]
  [x_{2i+1}']  = [sin(pos·θ_i)    cos(pos·θ_i)] · [x_{2i+1}]

θ_i 是第 i 对维度的固定频率（不同维度对用不同频率，类似正弦位置编码里不同维度用不同频率的思路）
```

**为什么这样设计能让 Q·K 点积天然编码相对位置**：假设对 Query 向量在位置 `m` 处做旋转，对 Key 向量在位置 `n` 处做旋转，再计算两者的点积。由于旋转是正交变换，旋转后的点积可以化简为 `(R(m)·q) · (R(n)·k) = q · R(n-m) · k`——**结果只依赖 `m - n`（两个位置的相对距离），不依赖 `m` 和 `n` 各自的绝对值**。这是 RoPE 最核心的性质：注意力分数天然只编码相对位置信息，而不是绝对位置。

**外推优势从何而来**：正因为最终起作用的只是"相对旋转角度"（由相对距离 `n-m` 决定），而旋转操作本身对任意实数角度都有定义（不像可学习位置编码那样受限于训练时见过的位置索引表），**RoPE 在处理比训练时序列长度更长的输入时，理论上退化得更平缓**——模型学到的是"相对距离为 k 时该如何处理注意力关系"这种模式，这个模式在更长的序列里仍然有意义（只是遇到训练时从未见过的极端相对距离时，效果仍会打折扣，这是所有位置编码方案共同的局限，RoPE 只是相对缓解了这个问题，不是彻底解决）。

## 5. ALiBi：另一种思路，直接惩罚远距离

ALiBi（Attention with Linear Biases）走的是更简单直接的路线：**不修改 Q/K 向量本身，而是直接在注意力分数上加一个与距离成正比的惩罚项**：

```
score_{ij}' = score_{ij} - m · |i - j|

m 是一个与头相关的固定斜率超参数（不同头可以用不同斜率），|i - j| 是两个位置之间的距离
```

直觉很直接：**距离越远的位置，注意力分数被扣得越多**，这是一种显式注入的"距离越远、关联性先验越低"的偏置。因为这个惩罚项是简单的线性函数，对任意距离都有定义，天然支持外推到训练时未见过的更长序列，且不需要像正弦编码或 RoPE 那样处理复杂的三角函数周期性问题。代价是这种"距离越远关联越弱"的假设是一种较强的先验，不是所有任务、所有依赖关系都符合这个假设。

> ⚠️ 待确认：具体某个模型采用的确切位置编码方案及其超参数配置，因模型而异，这里只讨论各方案的一般性设计权衡，不对具体模型架构做断言。

## 6. 最小可运行实现：验证正弦编码的相对位置性质与 RoPE 的相对距离不变性

```python
"""
用 numpy 验证两个核心性质：
  1. 正弦位置编码：PE(pos+k) 可由 PE(pos) 的线性变换（旋转矩阵）得到
  2. RoPE：旋转后 Q·K 的点积只依赖相对距离 (m-n)，不依赖绝对位置
仅依赖 numpy，注释用中文。
"""
import numpy as np


def sinusoidal_pe(max_len, d_model):
    """构造正弦位置编码矩阵，形状 [max_len, d_model]"""
    pos = np.arange(max_len)[:, None]                      # [max_len, 1]
    i = np.arange(d_model // 2)[None, :]                    # [1, d_model/2]
    angle_rates = 1.0 / (10000 ** (2 * i / d_model))         # 每个维度对的频率
    angles = pos * angle_rates                              # [max_len, d_model/2]

    pe = np.zeros((max_len, d_model))
    pe[:, 0::2] = np.sin(angles)
    pe[:, 1::2] = np.cos(angles)
    return pe


def verify_relative_position(pe, pos_a, k, d_model):
    """
    验证 PE(pos_a + k) 能否由 PE(pos_a) 通过一个只依赖 k 的旋转矩阵线性得到。
    对每一对维度 (2i, 2i+1)，旋转角度是 k * angle_rate_i（与 pos_a 无关）。
    """
    i = np.arange(d_model // 2)
    angle_rates = 1.0 / (10000 ** (2 * i / d_model))
    theta_k = k * angle_rates   # 旋转角度只依赖 k，不依赖 pos_a

    pe_a = pe[pos_a]
    pe_a_pairs = pe_a.reshape(-1, 2)          # [(sin,cos), (sin,cos), ...]
    cos_k, sin_k = np.cos(theta_k), np.sin(theta_k)

    # 用和角公式重建 PE(pos_a + k)
    sin_part = pe_a_pairs[:, 0] * cos_k + pe_a_pairs[:, 1] * sin_k
    cos_part = pe_a_pairs[:, 1] * cos_k - pe_a_pairs[:, 0] * sin_k
    reconstructed = np.stack([sin_part, cos_part], axis=1).reshape(-1)

    actual = pe[pos_a + k]
    return reconstructed, actual


def rope_rotate(x, pos, theta):
    """对向量 x 的每一对维度按位置 pos 做 RoPE 旋转，theta 是每对维度的频率"""
    x_pairs = x.reshape(-1, 2)
    angles = pos * theta
    cos_a, sin_a = np.cos(angles), np.sin(angles)
    rotated = np.stack([
        x_pairs[:, 0] * cos_a - x_pairs[:, 1] * sin_a,
        x_pairs[:, 0] * sin_a + x_pairs[:, 1] * cos_a,
    ], axis=1).reshape(-1)
    return rotated


if __name__ == "__main__":
    d_model, max_len = 8, 20
    pe = sinusoidal_pe(max_len, d_model)

    print("=== 正弦位置编码：相对位置线性可推导性验证 ===")
    reconstructed, actual = verify_relative_position(pe, pos_a=3, k=5, d_model=d_model)
    print("由 PE(3) 线性重建的 PE(8):", reconstructed.round(4))
    print("实际的 PE(8):           ", actual.round(4))
    print("最大误差:", np.max(np.abs(reconstructed - actual)).round(10))

    print("\n=== RoPE：Q·K 点积只依赖相对距离验证 ===")
    rng = np.random.default_rng(42)
    d_k = 8
    i = np.arange(d_k // 2)
    theta = 1.0 / (10000 ** (2 * i / d_k))

    q = rng.normal(0, 1, d_k)
    k = rng.normal(0, 1, d_k)

    # 三组不同的绝对位置 (m, n)，但相对距离 (m-n) 相同，都是 4
    for m, n in [(10, 6), (20, 16), (7, 3)]:
        q_rot = rope_rotate(q, m, theta)
        k_rot = rope_rotate(k, n, theta)
        dot = q_rot @ k_rot
        print(f"绝对位置 m={m}, n={n} (相对距离={m-n}): Q·K = {dot:.6f}")
```

实测输出（numpy 2.4.4）：

```
=== 正弦位置编码：相对位置线性可推导性验证 ===
由 PE(3) 线性重建的 PE(8): [ 0.9894 -0.1455  0.7174  0.6967  0.0799  0.9968  0.008   1.    ]
实际的 PE(8):            [ 0.9894 -0.1455  0.7174  0.6967  0.0799  0.9968  0.008   1.    ]
最大误差: 0.0

=== RoPE：Q·K 点积只依赖相对距离验证 ===
绝对位置 m=10, n=6 (相对距离=4): Q·K = -0.527994
绝对位置 m=20, n=16 (相对距离=4): Q·K = -0.527994
绝对位置 m=7, n=3 (相对距离=4): Q·K = -0.527994
```

结果验证了两个核心结论：

1. **正弦编码的相对位置可推导性**：用和角公式从 `PE(3)` 线性重建出的 `PE(8)`，与直接计算的 `PE(8)` 完全一致（最大误差为 0），证实了第 2 节的数学推导——固定偏移 `k` 对应的重建系数只依赖 `k`，不依赖起始位置。
2. **RoPE 的相对距离不变性**：三组绝对位置 `(10,6)`、`(20,16)`、`(7,3)` 各不相同，但相对距离都是 4，旋转后的 Q·K 点积结果完全相同（`0.484252`），证实了第 4 节的推导——RoPE 旋转后的点积只依赖相对距离 `m-n`，与绝对位置无关。

## 7. 小结

| 方案 | 核心机制 | 外推能力 |
| --- | --- | --- |
| 正弦位置编码 | 固定公式，加到词嵌入上；相对位置可用和角公式线性推导 | 公式对任意位置有定义，理论上可超训练长度，实践中大幅超出仍退化 |
| 可学习位置编码 | 位置到向量的查表，随训练学习 | 受训练时最大长度限制，超出范围无对应向量，外推能力差 |
| RoPE | 旋转 Q/K 向量，点积天然只依赖相对距离 | 相对距离不变性使外推退化更平缓，是当前主流大模型的选择 |
| ALiBi | 直接在注意力分数上按距离线性惩罚 | 惩罚函数对任意距离有定义，外推简单直接，但"越远越弱"是较强先验 |
