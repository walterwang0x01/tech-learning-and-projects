## 1. 深度学习时代，特征工程为什么还重要

图像、文本、语音领域，深度学习基本淘汰了"手工特征"——CNN 自己学边缘纹理，Transformer 自己学词法语法。但**表格数据（tabular data）是例外**。

原因在数据结构：图像/文本有**空间/序列局部相关性**，卷积核、attention 能利用这种先验；表格数据的列之间**没有固定的几何或序列关系**——"年龄"和"收入"该放进哪个卷积核感受野？这个问题没有意义。树模型（GBDT/XGBoost/LightGBM）和线性模型至今在表格数据上仍是强基线甚至最优解，而它们**不会自动做特征交叉、不会自动处理类别语义、不会自动做非线性变换**——都要靠特征工程喂进去。

> ⚠️ 待确认：近年也有专门针对表格数据设计的深度网络架构，但具体基准和结论时效性不确定，这里不展开对比。

实践经验（不涉及具体榜单数字）：**特征工程的天花板往往比模型选择的天花板更高**。同一个 GBDT，加一个强特征带来的提升，常超过换更复杂的模型架构，这是风控、推荐排序场景的共识性经验。

## 2. 缺失值处理：策略与偏差

缺失值处理不存在"正确答案"，只有"引入什么偏差，是否可接受"。

| 策略 | 做法 | 引入的偏差 |
| --- | --- | --- |
| 删除样本 | 丢弃含缺失值的行 | 缺失非随机时会系统性丢失某类样本，导致分布偏移 |
| 删除特征 | 丢弃缺失率过高的列 | 可能丢掉"是否缺失"本身携带的信号 |
| 统计量填充 | 用均值/中位数/众数填补 | 人为压低方差，形成不自然的"尖峰" |
| 分组统计量填充 | 按类别分组填充组内统计量 | 比全局填充更准，但组内样本太少时统计量不稳定 |
| 模型预测填充 | 用其他特征训练模型预测缺失值 | 预测模型有偏时缺失值被系统性填偏；必须只在训练集内拟合 |
| 显式缺失标记 | 填充固定值 + 增加一列 `is_missing` | 偏差成本最低，"是否缺失"信息被保留 |

**缺失是否随机**（MCAR/MAR/MNAR）决定策略选择：

```
MCAR：缺失与任何变量都无关 → 均值填充影响较小
MAR ：缺失依赖于其他已观测变量 → 分组/模型填充更合理
MNAR：缺失依赖于变量本身的值（如高收入者不愿填收入）→ 任何填充都有偏，
      显式缺失标记 + 让模型自己学更稳妥
```

工业场景中"缺失"本身往往是强特征，**优先加 `is_missing` 标记列**，而不是简单填充后忽略这个信号。

## 3. 类别特征编码

### one-hot 编码

把类别拆成多个 0/1 列。优点是无泄露风险、语义清晰；缺点是类别数（cardinality）一高就维度爆炸，且完全没有利用类别与标签的关系。

### target encoding（目标编码）

用该类别在训练集里对应标签的统计量（通常是均值）替代类别值：

```
TE(category c) = mean(y | x = c)
```

问题：**如果直接在全量训练集上算这个均值，再编码同一批训练样本，就是标签泄露**——本质是用样本自己的标签（间接通过所在类别的其他样本）预测自己的标签，模型会严重高估该特征重要性，线下分数虚高、线上崩。

修正手段是**交叉拟合（cross-fitting，即 out-of-fold encoding）**：

```
把训练集分成 K 折
for 每一折 i:
    用其余 K-1 折的数据算 target encoding 统计量
    把这个统计量应用到第 i 折上
```

这样每个样本的编码值永远来自"不包含它自己"的数据，杜绝直接泄露。常配合**平滑（smoothing）**：

```
TE_smooth(c) = (n_c · mean_c + m · global_mean) / (n_c + m)
```

`n_c` 是该类别样本数，`m` 是平滑强度超参数。类别样本数越少，编码值越向全局均值收缩——避免小样本类别的统计量不稳定。

### 频数编码（frequency encoding）

用类别出现的频次/频率替代类别值。没有标签泄露风险（只用 `x` 的信息，不涉及 `y`），常作为 target encoding 的补充特征，或高基数类别的低成本替代。

### 编码方式选择

| 场景 | 推荐 |
| --- | --- |
| 类别数少 | one-hot |
| 类别数多、与标签强相关 | target encoding（必须交叉拟合）|
| 类别数多、只关心热度 | 频数编码 |
| 树模型 | 也可直接用整数编码（label encoding），树能处理非单调关系 |
| 线性模型 | 避免裸的 label encoding，会引入不存在的序关系 |

## 4. 数值特征变换

- **标准化**：`(x - mean) / std`。对基于距离/梯度的模型（线性回归、神经网络、KNN、SVM）几乎必需，量纲不同的特征会让梯度下降在不同方向步长失衡。
- **归一化**：`(x - min) / (max - min)`，压缩到 `[0,1]`。对异常值敏感，标准化对异常值相对更稳健。
- **分箱**：把连续值切成离散区间。等宽分箱简单但对非均匀分布不友好；等频分箱按分位数切；也可用决策树分裂点做**监督分箱**。代价是丢失箱内精细差异，换来对异常值、非线性关系更鲁棒。
- **对数变换**：`log(1+x)`，用于右偏长尾分布（收入、点击量、价格），压缩大值尺度；树模型收益较小（只关心分裂点相对顺序，单调变换不改变分裂结果）。

## 5. 特征交叉

单个特征往往不足以刻画非线性关系，需显式构造交叉特征：

```
数值 × 数值：x1 * x2，或 x1 / x2（比率特征，如"负债/收入"）
类别 × 类别：拼接后当新类别处理，如 "城市_职业" 组合
数值 × 类别：分组统计量，如"该用户所在城市的平均消费"
```

线性模型和低阶树模型学不到"两个特征乘积"这种关系，必须靠特征工程显式构造；深度模型（FM、DeepFM 系列）会自动学交叉项，但本质是把交叉先验做进模型结构。

## 6. 时间特征与窗口统计的泄露陷阱

时间序列/事件类数据做特征工程，最容易出的错是**用了未来信息**：

- **窗口统计用错时间边界**：算"过去 7 天平均下单量"时，若窗口右边界包含预测那一刻本身（甚至之后），就是用未来预测过去。窗口必须严格是 `[t - 7d, t)`，不含 `t` 时刻。
- **全局统计量代替时点统计量**：比如"该商品历史平均评分"，若直接用整个数据集（含未来评分）算平均值，同样泄露。必须按时间切片，只用截止到预测时刻的历史数据。
- **train/test 划分与时间穿越**：随机 K 折用在时间序列上会导致训练集混入测试样本的"未来"数据。应用**时序切分**：训练集时间早于验证集，验证集时间早于测试集，不能随机打乱。
- **群体聚合特征的时间泄露**：比如"当天下单总次数"用于预测"第 3 次下单是否退货"——如果统计是当天结束后算的，就包含了第 3 次之后的信息，同样泄露。

排查泄露的通用方法：**观察可疑特征的重要性，若异常高（远超其他合理特征），要重点怀疑是否泄露**。模型如果能"看到答案"，会毫不犹豫地把权重压在那个特征上。

## 7. 特征选择方法

| 类型 | 思路 | 代表方法 | 优缺点 |
| --- | --- | --- | --- |
| 过滤法（Filter） | 独立于模型，用统计量打分后筛选 | 方差阈值、相关系数、卡方检验、互信息 | 快，但忽略特征间组合效应 |
| 包裹法（Wrapper） | 用目标模型实际效果指导子集搜索 | 递归特征消除（RFE）、前向/后向选择 | 效果贴合具体模型，但每个子集都要重新训练，成本高 |
| 嵌入法（Embedded） | 特征选择嵌入训练过程 | L1 正则化（Lasso）产生稀疏解、树模型特征重要性/增益 | 一次训练同时拿到模型和特征重要性，性价比最高 |

实践中常见组合：先用过滤法快速砍掉明显无关或高度冗余的特征，再用嵌入法（如树模型特征重要性）做精细筛选；包裹法成本高，一般只在特征数已经较小、需要抠最后一点效果时才用。

## 8. 特征漂移监控

模型上线后，特征分布可能随时间偏离训练时分布（**feature drift**），这是线上效果衰减的常见原因，独立于"标签漂移"（label drift，即 `P(y|x)` 本身发生变化）。

监控手段：

- **单特征分布对比**：定期对比线上特征分布与训练时分布，常用 **PSI（Population Stability Index）** 或 KL 散度量化漂移程度。
- **统计量监控**：跟踪均值、方差、缺失率、类别频次随时间的变化曲线，设置告警阈值。
- **模型输入-输出一致性检查**：若某特征漂移导致模型输出分布明显变化，说明该特征影响较大，需优先排查。

发现漂移后应定位来源（上游数据管道变更？真实业务分布变化？），再评估是否需要重新训练或调整特征处理逻辑。

## 9. 代码：target encoding 泄露与交叉拟合修正

用 numpy 构造类别特征，对比"直接在全量数据上做 target encoding"与"交叉拟合"两种方式，观察前者在训练集上的虚假分数提升。

```python
import numpy as np

rng = np.random.default_rng(42)

# 类别特征：20 个类别，每个类别有一个真实"类别效应"
n_categories = 20
n_samples = 4000
true_category_effect = rng.normal(0, 1.0, n_categories)

categories = rng.integers(0, n_categories, n_samples)
noise = rng.normal(0, 1.0, n_samples)  # 与类别无关的噪声
y = true_category_effect[categories] + noise


def naive_target_encoding(cats, labels):
    """朴素做法：直接用全量数据算类别标签均值，编码同一批数据（有泄露）"""
    encoded = np.zeros_like(labels, dtype=float)
    for c in np.unique(cats):
        mask = cats == c
        encoded[mask] = labels[mask].mean()  # 用了样本自己的标签
    return encoded


def cross_fit_target_encoding(cats, labels, n_folds=5, smoothing=10.0, seed=0):
    """交叉拟合：K 折内用其余 K-1 折数据算统计量，编码当前折"""
    rng_local = np.random.default_rng(seed)
    n = len(labels)
    fold_id = rng_local.integers(0, n_folds, n)
    encoded = np.zeros(n, dtype=float)
    global_mean = labels.mean()

    for fold in range(n_folds):
        train_mask = fold_id != fold
        val_mask = fold_id == fold
        cats_train, labels_train = cats[train_mask], labels[train_mask]

        for c in np.unique(cats):
            c_mask_train = cats_train == c
            n_c = c_mask_train.sum()
            mean_c = labels_train[c_mask_train].mean() if n_c > 0 else global_mean
            smooth_mean = (n_c * mean_c + smoothing * global_mean) / (n_c + smoothing)
            c_mask_val = (cats == c) & val_mask
            encoded[c_mask_val] = smooth_mean

    return encoded


def correlation(a, b):
    """皮尔逊相关系数"""
    a_c, b_c = a - a.mean(), b - b.mean()
    return np.sum(a_c * b_c) / (np.sqrt(np.sum(a_c ** 2)) * np.sqrt(np.sum(b_c ** 2)))


naive_encoded = naive_target_encoding(categories, y)
crossfit_encoded = cross_fit_target_encoding(categories, y)
corr_naive = correlation(naive_encoded, y)
corr_crossfit = correlation(crossfit_encoded, y)

print(f"朴素 target encoding 与标签的相关系数: {corr_naive:.4f}  (虚高，因为用了自身标签)")
print(f"交叉拟合 target encoding 与标签的相关系数: {corr_crossfit:.4f}  (更接近真实可用信息量)")

# 用全新同分布数据模拟线上真实效果
new_categories = rng.integers(0, n_categories, n_samples)
new_noise = rng.normal(0, 1.0, n_samples)
new_y = true_category_effect[new_categories] + new_noise

category_means = {c: y[categories == c].mean() for c in np.unique(categories)}
new_encoded = np.array([category_means[c] for c in new_categories])
corr_on_new_data = correlation(new_encoded, new_y)

print(f"用训练集统计量编码全新数据的相关系数: {corr_on_new_data:.4f}  (线上真实表现的近似)")
print("结论：朴素编码在训练集上的相关系数明显偏高于新数据上的真实表现，")
print("      而交叉拟合的相关系数更接近新数据上的真实表现，说明它更少泄露。")
```

实测输出（numpy 2.4.4）：

```
朴素 target encoding 与标签的相关系数: 0.6463  (虚高，因为用了自身标签)
交叉拟合 target encoding 与标签的相关系数: 0.6408  (更接近真实可用信息量)
用训练集统计量编码全新数据的相关系数: 0.6422  (线上真实表现的近似)

结论：朴素编码在训练集上的相关系数明显偏高于新数据上的真实表现，
      而交叉拟合的相关系数更接近新数据上的真实表现，说明它更少泄露。
```

这组数据下，朴素编码与交叉拟合的差距不算大（每个类别样本量足够大、类别效应本身较强）；但**泄露方向始终成立**：朴素编码的相关系数一定 ≥ 交叉拟合编码，且类别数越多、单类别样本量越少，差距会明显拉大——这正是高基数类别做 target encoding 时泄露风险更高的原因。

## 10. 小结

| 主题 | 核心结论 |
| --- | --- |
| 深度学习时代的地位 | 表格数据没有稳定的空间/序列先验，特征工程仍决定树模型/线性模型效果上限 |
| 缺失值 | 优先显式标记 `is_missing`，避免盲目均值填充抹掉信息 |
| 类别编码 | one-hot 无泄露但维度高；target encoding 效果好但必须交叉拟合；频数编码零风险 |
| 数值变换 | 标准化服务于基于距离/梯度的模型；对数变换处理长尾；分箱换鲁棒性、丢精细信息 |
| 特征交叉 | 线性/低阶树学不到乘积关系，需显式构造；深度模型自动交叉是把先验做进结构 |
| 时间特征 | 窗口边界不能含未来，统计量按时间切片，验证集按时间而非随机划分 |
| 特征选择 | 过滤法快但忽略组合效应，嵌入法性价比最高，包裹法成本高但最贴合模型 |
| 特征漂移 | 用 PSI/KL 散度监控线上分布偏移，是模型效果衰减的常见诱因 |
