# 类别与高基数特征

> Author: Walter Wang

> **读完你能回答的 3 个问题**

> 1. 类别基数（cardinality）从"低"变"高"后，one-hot 和标签编码分别会遇到什么具体问题？
> 2. target encoding 交叉拟合+平滑+噪声三件套，分别对抗哪种泄露/不稳定风险？
> 3. 哈希技巧和嵌入编码分别适合什么场景，各自牺牲了什么？

## 1. 低基数 vs 高基数：处理方式的分水岭

类别特征的处理策略几乎完全由**基数（cardinality，即不同取值数量）**决定，这不是精确数字界限，而是连续权衡曲线：

```
低基数 (几到几十)                                    高基数 (几千到千万)
  |------------------------------------------------------|
  one-hot 安全区                中间地带              one-hot 灾难区
```

低基数场景（"性别""省份""会员等级"）下 one-hot 几乎总是安全选择：新增列对模型无压力，且不引入虚假序关系。高基数场景（"商品ID""用户ID""URL域名"，取值几万到几千万）下，one-hot 会带来维度爆炸和稀疏两个复合问题。

## 2. one-hot 在高基数下的问题

一个取值数为 `V` 的类别做 one-hot 会新增 `V` 列，多个高基数特征叠加后特征矩阵列数很容易膨胀到 `n_features >> n_samples`，推高存储计算成本，也让线性模型在样本不足时过拟合每一列。

one-hot 矩阵每行只有一个 1，稠密度是 `1/V`，`V` 越大稀疏性越严重——不只是工程成本问题，更是统计意义上的**有效样本不足**：某一列只有 3 个非零样本，无论用什么模型都学不出可靠权重。

## 3. 标签编码：为什么线性模型受伤更重

标签编码（label encoding）把类别按任意顺序映射成整数：`{"北京":0, "上海":1, "广州":2}`。映射本身任意，但整数一旦生成就携带了**大小和距离关系**：`2-0=2` 暗示"广州离北京的距离是上海的两倍"——大多数场景下是编造的关系。

线性模型对特征值做线性加权 `w·x`，会被迫学出**单一斜率**拟合这个人为排序趋势，等价于假设类别间存在线性递增效应，通常是错的。树模型学的是"是否小于某阈值"的规则，即使整数顺序任意，也能通过**多次不同阈值的切分**把无序类别重新组合成任意子集。标签编码对树模型是"次优但可用"，对线性模型是"直接引入错误先验"。

## 4. 频数编码与计数编码

频数编码（frequency encoding）用类别出现频率替代类别值：`FreqEnc(c)=count(x=c)/n_samples`；计数编码不做归一化，直接用次数，二者本质相同。

关键特性：**只利用 `x` 的分布信息，不涉及标签 `y`**，天然没有标签泄露风险。常见用途：高基数类别的低成本替代特征；配合 target encoding 让模型同时看到"类别效应"和"类别置信度"；罕见类别自然获得很小的频数值，隐式做了粗粒度分组。

## 5. target encoding 完整防泄露方案

target encoding 用类别对应标签的统计量替代类别值，是高基数类别最常用、效果通常也最好的编码方式，但泄露风险和修正手段需要展开讲清楚。

**泄露的本质**：朴素做法在全量训练集上直接算 `mean(y|x=c)` 再编码同一批样本——本质是让每个样本特征里包含了它自己的标签信息（经由同类别其他样本间接汇总）。极端情况下（类别只有 1 个样本）等价于把标签直接当特征喂给模型。

**修正手段一：交叉拟合（cross-fitting）**。把训练集切成 K 折（通常 K=5），每折用其余 K-1 折数据算类别统计量再应用到本折；测试集用全部训练数据的统计量。核心不变量：**任何样本的编码值都不能用到它自己的标签**。这解决同源泄露，但没解决小样本不稳定问题。

**修正手段二：平滑（smoothing）**。某类别在某折训练部分可能只剩 2-3 个样本，均值方差极大，是小样本估计噪声。贝叶斯收缩：

```
TE_smooth(c) = (n_c · mean_c + m · global_mean) / (n_c + m)
```

`n_c`: 该类别样本数, `mean_c`: 原始目标均值, `global_mean`: 全局均值, `m`: 平滑强度

`m` 的直觉是"虚拟样本数"：`n_c` 越小虚拟样本权重占比越大，编码值越向全局均值收缩；`n_c` 越大越接近类别真实均值。`m` 靠验证集调参，无普适固定值。

**修正手段三：噪声注入**。加高斯噪声 `TE_final(c)=TE_smooth(c)+ε, ε~N(0,σ²)`，进一步压低平滑仍残留的系统性偏高相关性，代价是新增 `σ` 超参数，过大会淹没真实信号，本质是**方差换偏差**的权衡。三件套不是互相替代：交叉拟合是必须项，平滑和噪声注入是在此基础上的稳健性增强。

## 6. 哈希技巧与嵌入编码

**哈希技巧**把类别通过哈希函数映射到固定大小 `d` 个桶：`bucket(c)=hash(c) mod d`，`d` 与原始类别数 `V` 无关。优点：内存固定、天然支持未见新类别、无需维护类别字典，适合类别集合持续增长的在线场景。代价是**哈希冲突**——不同类别落入同一桶，模型无法区分；`d` 越小冲突越多，是明确的内存/精度权衡，适合基数开放且未知上界的场景（URL、自由文本 token）。

**嵌入编码**把每个类别映射成低维稠密向量，通过模型训练学出来。值得用的条件：每类别有足够样本支撑学习、下游是能整体优化嵌入层的神经网络、类别间存在语义相似结构。不值得用：样本量小、下游是树模型或线性模型（不参与嵌入梯度更新）、基数本身不大（target encoding 或 one-hot 已够用）。

> ⚠️ 待确认：嵌入维度与类别基数的通用经验公式，不同资料给出的法则差异较大，这里不给具体数字。

## 7. 罕见类别与未见类别

**罕见类别**：出现次数很少的类别，可归并为统一 `"__rare__"` 类别（用频次阈值判定），或依赖 target encoding 平滑机制让编码值趋近全局均值，或用频数编码隐式处理。

**未见类别（unseen/OOV）**：推理时出现训练阶段没见过的取值，必须提前设计兜底：

```
one-hot/label encoding: 需要显式 "unknown" 槽位或默认索引
target encoding: 直接返回 global_mean
频数编码: 返回 0 或训练集最小频次
哈希技巧: 天然支持，任何字符串都能算出桶
```

target encoding 的平滑公式在 `n_c=0` 时自动退化为 `global_mean`——未见类别和小样本类别用同一套逻辑，无需额外分支。

## 8. 类别特征的交叉组合策略

单个类别信息量有限，交叉组合能捕捉更细粒度模式：类别×类别拼接成新类别（"城市_职业"）；类别×数值分箱交叉（"年龄段_会员等级"）；groupby 统计（"该用户所在城市的平均客单价"）。

代价是**基数乘积增长**——基数 100 和 50 交叉理论上限 5000 组合，实际出现的远小于此，但仍推高有效基数和稀疏度，交叉特征几乎总要配合 target encoding、频数编码或哈希技巧，而非直接 one-hot。交叉顺序上优先选有明确业务交互假设的特征对，而非暴力枚举——组合空间大了噪声特征和过拟合风险会显著上升。

## 9. 代码：交叉拟合 + 平滑对高基数类别泄露的抑制效果

构造 200 个类别、Zipf 长尾分布（部分类别样本极少）的高基数场景，对比朴素编码、无平滑交叉拟合、加平滑交叉拟合、加噪声四种方案。

```python
"""验证target encoding的交叉拟合+平滑+噪声注入对泄露的抑制效果。
200个类别，Zipf分布制造长尾：少数类别占大量样本，多数类别样本很少。"""
import numpy as np

rng = np.random.default_rng(7)
n_cat, n = 200, 6000
true_effect = rng.normal(0, 1.0, n_cat)  # 真实类别效应，仅用于生成数据
w = 1.0 / np.arange(1, n_cat + 1); w /= w.sum()
cats = rng.choice(n_cat, size=n, p=w)
y = true_effect[cats] + rng.normal(0, 1.0, n)


def naive_te(c, lab):
    """朴素做法：全量数据算均值编码同一批数据（有泄露）"""
    enc = np.zeros_like(lab, dtype=float)
    for v in np.unique(c):
        enc[c == v] = lab[c == v].mean()
    return enc


def cross_fit_te(c, lab, k=5, m=10.0, noise_std=0.0, seed=0):
    """K 折交叉拟合 + 贝叶斯平滑(强度 m) + 可选噪声注入"""
    r = np.random.default_rng(seed)
    fold = r.integers(0, k, len(lab))
    enc = np.zeros(len(lab)); gm = lab.mean()
    for f in range(k):
        tr, va = fold != f, fold == f
        c_tr, y_tr = c[tr], lab[tr]
        for v in np.unique(c):
            mask_tr = c_tr == v
            n_v = mask_tr.sum()
            mean_v = y_tr[mask_tr].mean() if n_v > 0 else gm
            enc[(c == v) & va] = (n_v * mean_v + m * gm) / (n_v + m)
    if noise_std > 0:
        enc = enc + r.normal(0, noise_std, len(lab))
    return enc


def corr(a, b):
    a, b = a - a.mean(), b - b.mean()
    return np.sum(a * b) / (np.sqrt(np.sum(a ** 2)) * np.sqrt(np.sum(b ** 2)))


naive = naive_te(cats, y)
cf0 = cross_fit_te(cats, y, m=0.0)
cf20 = cross_fit_te(cats, y, m=20.0)
cf20n = cross_fit_te(cats, y, m=20.0, noise_std=0.05)

_, counts = np.unique(cats, return_counts=True)
print(f"类别数:{n_cat} 样本数:{n} 最大类别样本数:{counts.max()} 最小:{counts.min()} "
      f"样本数<5的类别占比:{np.mean(counts < 5):.2%}")
print("训练集上编码值与标签的相关系数（越接近新数据表现越好，不是越高越好）:")
print(f"  朴素TE(无交叉拟合)={corr(naive, y):.4f}  交叉拟合无平滑(m=0)={corr(cf0, y):.4f}")
print(f"  交叉拟合+平滑(m=20)={corr(cf20, y):.4f}  +噪声注入={corr(cf20n, y):.4f}")

# 模拟线上全新数据：用训练集统计量编码全新样本
new_cats = rng.choice(n_cat, size=n, p=w)
new_y = true_effect[new_cats] + rng.normal(0, 1.0, n)
gm = y.mean()
stats = {v: (np.sum(cats == v) * y[cats == v].mean() + 20.0 * gm) / (np.sum(cats == v) + 20.0)
         for v in np.unique(cats)}
new_enc = np.array([stats[v] for v in new_cats])
print(f"用训练集统计量编码全新数据的相关系数(近似线上真实表现)={corr(new_enc, new_y):.4f}")

rare = [v for v in np.unique(cats) if np.sum(cats == v) <= 3][0]
n_v = np.sum(cats == rare)
raw_mean = y[cats == rare].mean()
smoothed = (n_v * raw_mean + 20.0 * gm) / (n_v + 20.0)
print(f"小样本演示: 类别{rare}仅{n_v}个样本, 原始均值={raw_mean:.4f}, "
      f"平滑后={smoothed:.4f}(全局均值={gm:.4f}, 向全局收缩)")
```

实测输出（numpy 2.4.4）：

```
类别数:200 样本数:6000 最大类别样本数:1016 最小:2 样本数<5的类别占比:11.00%
训练集上编码值与标签的相关系数（越接近新数据表现越好，不是越高越好）:
  朴素TE(无交叉拟合)=0.6012  交叉拟合无平滑(m=0)=0.5611
  交叉拟合+平滑(m=20)=0.5289  +噪声注入=0.5268
用训练集统计量编码全新数据的相关系数(近似线上真实表现)=0.5234
小样本演示: 类别118仅3个样本, 原始均值=0.9602, 平滑后=-0.0443(全局均值=-0.1950, 向全局收缩)
```

结果呈现单调下降梯度：朴素编码相关系数最高（0.6012）但完全来自泄露；仅交叉拟合去掉直接同源泄露后降到 0.5611；叠加平滑后降到 0.5289，接近"编码全新数据"的 0.5234，说明平滑后训练集表现不再虚高；噪声注入只带来很小的进一步下降（0.5268），本规模下边际收益有限，长尾更极端时会更明显。小样本演示验证了平滑公式的直觉：仅 3 个样本、原始均值 0.96 的类别被平滑拉到 -0.04，回归到全局均值 -0.195 附近。

## 10. 小结

| 主题 | 核心结论 |
| --- | --- |
| 低基数 vs 高基数 | 基数越高 one-hot 维度爆炸和稀疏问题越严重，是连续权衡而非固定界限 |
| 标签编码 | 强加不存在的序关系，线性模型被误导；树模型可通过多次分裂规避 |
| 频数/计数编码 | 只用 `x` 信息，零泄露风险，可单独用也可配合 target encoding |
| target encoding | 效果通常最好，但必须交叉拟合 + 平滑 + （可选）噪声注入三件套防泄露 |
| 哈希技巧 | 内存固定、天然支持未见类别，代价是哈希冲突带来的精度损失 |
| 嵌入编码 | 只在样本量充足、下游是神经网络、类别有语义结构时值得用 |
| 罕见/未见类别 | target encoding 平滑公式统一处理两者，退化为全局均值 |
| 交叉组合 | 基数乘积增长，优先交叉有业务假设支撑的特征对，避免暴力枚举 |
