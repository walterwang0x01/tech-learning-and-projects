## 1. 线性回归：最小二乘法的推导

线性回归假设目标变量 `y` 是特征 `x` 的线性组合加噪声：`y = w^T x + b + ε`。给定训练集 `{(x_i, y_i)}`，目标是找到 `w, b` 使预测值 `ŷ_i = w^T x_i + b` 尽量接近真实值 `y_i`。

### 最小二乘目标函数

用平方误差衡量偏差，对所有样本求和（`N` 为样本数）：

```
J(w, b) = (1/N) · Σ_{i=1}^{N} (y_i - w^T x_i - b)²
```

为什么用平方而不是绝对值？平方误差处处可导（绝对值在 0 点不可导），且对大误差的惩罚呈平方增长，让优化器优先修正明显偏离的点；代价是对异常值（outlier）更敏感。

### 闭式解推导（正规方程）

把偏置 `b` 吸收进 `w`（给每个样本的特征向量拼接一个恒为 1 的维度），写成矩阵形式：`J(w) = (1/N)‖y - Xw‖²`，`X` 形状 `[N, d+1]`。对 `w` 求导并令导数为零：

```
∂J/∂w = -(2/N) · X^T(y - Xw) = 0
⟹ X^T X w = X^T y
⟹ w* = (X^T X)^{-1} X^T y     （正规方程）
```

这是一个**闭式解**——之所以能直接解出来，是因为 `J(w)` 是 `w` 的二次函数，其梯度是 `w` 的线性函数，令梯度为零就是解一个线性方程组。前提是 `X^T X` 可逆（特征间不存在完全线性相关，且样本数不少于特征数）。

## 2. 逻辑回归：为什么没有闭式解

逻辑回归处理二分类问题，把线性组合 `z = w^T x + b` 通过 **sigmoid 函数** 压缩到 `(0,1)` 区间，解释为"属于正类的概率"：

```
p = σ(z) = 1 / (1 + e^{-z})
```

### 损失函数：从最大似然推导

假设标签 `y ∈ {0,1}`，模型给出的 `p = P(y=1|x)`。单个样本的似然可以统一写成 `p^y · (1-p)^{1-y}`（`y=1` 时取 `p`，`y=0` 时取 `1-p`）。对整个数据集取对数似然并加负号（转成最小化问题），得到**交叉熵损失**：

```
L(w,b) = -(1/N) · Σ_{i=1}^{N} [ y_i·log(p_i) + (1-y_i)·log(1-p_i) ]
```

### 为什么没有闭式解

对 `L` 关于 `w` 求导（利用 `σ'(z) = σ(z)(1-σ(z))` 这一性质，链式法则化简后有一个优雅的结果）：

```
∂L/∂w = (1/N) · Σ_{i=1}^{N} (p_i - y_i) · x_i
```

这个梯度里 `p_i = σ(w^T x_i + b)` 本身是 `w` 的非线性函数（sigmoid 是非线性变换），令梯度等于零得到的是一个**非线性方程组**，没有代数上的闭式解，必须用梯度下降等迭代方法数值求解。这是线性回归和逻辑回归的本质区别：线性回归的梯度是参数的线性函数，逻辑回归的梯度因为 sigmoid 的存在变成了非线性函数。

### 两者梯度形式的共同结构

对比线性回归梯度 `∂J/∂w = (2/N)·Σ(ŷ_i - y_i)·x_i` 和逻辑回归梯度 `∂L/∂w = (1/N)·Σ(p_i - y_i)·x_i`，两者形式几乎一致：**梯度 = (预测值 - 真实值) 加权的特征向量之和**。这不是巧合——两者都属于广义线性模型（GLM），线性回归的"链接函数"是恒等函数，逻辑回归的链接函数是 sigmoid（对应 Bernoulli 分布的自然参数化），当损失函数选为对应分布的负对数似然时，梯度总会化简成这个"残差加权特征"的统一形式。

## 3. 决策边界与概率解释

逻辑回归的决策边界是 `p=0.5` 对应的位置，即 `z=0`，也就是 `w^T x + b = 0`——这是一个**线性**决策边界（在特征空间中是一个超平面）。这也是"逻辑回归"容易被误解的地方：尽管名字里带"回归"，且使用了非线性的 sigmoid，但它本质上是一个**线性分类器**，非线性只体现在把线性得分转换成概率的那一步，分类边界本身仍是线性的。

概率解释的价值：逻辑回归不仅给出类别，还给出一个可信度分数（概率），这在很多需要"置信度"的下游场景（如风控、排序）中比单纯的类别标签更有用。

## 4. 最小可运行实现：梯度下降拟合两种回归

```python
"""
用 numpy 实现线性回归（验证闭式解与梯度下降的一致性）和逻辑回归（梯度下降）。
"""
import numpy as np


def linear_regression_closed_form(X, y):
    """正规方程闭式解：w = (X^T X)^{-1} X^T y，X 已包含常数列"""
    return np.linalg.inv(X.T @ X) @ X.T @ y


def linear_regression_gd(X, y, lr=0.1, epochs=500):
    """梯度下降求解线性回归，用于验证是否收敛到闭式解"""
    w = np.zeros(X.shape[1])
    n = X.shape[0]
    for _ in range(epochs):
        pred = X @ w
        grad = (2 / n) * X.T @ (pred - y)
        w -= lr * grad
    return w


def sigmoid(z):
    return 1 / (1 + np.exp(-z))


def logistic_regression_gd(X, y, lr=0.5, epochs=1000):
    """梯度下降求解逻辑回归"""
    w = np.zeros(X.shape[1])
    n = X.shape[0]
    losses = []
    for _ in range(epochs):
        p = sigmoid(X @ w)
        grad = (1 / n) * X.T @ (p - y)
        w -= lr * grad
        eps = 1e-9
        loss = -np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps))
        losses.append(loss)
    return w, losses


if __name__ == "__main__":
    rng = np.random.default_rng(42)

    print("=== 线性回归：闭式解 vs 梯度下降 ===")
    n_samples = 100
    X_raw = rng.normal(0, 1, (n_samples, 2))
    true_w = np.array([2.0, -1.5, 0.5])  # 最后一项是偏置
    X = np.hstack([X_raw, np.ones((n_samples, 1))])
    y = X @ true_w + rng.normal(0, 0.1, n_samples)

    w_closed = linear_regression_closed_form(X, y)
    w_gd = linear_regression_gd(X, y, lr=0.1, epochs=500)
    print("真实参数:      ", true_w.round(4))
    print("闭式解:        ", w_closed.round(4))
    print("梯度下降解:     ", w_gd.round(4))
    print("闭式解与梯度下降解的最大差异:", np.max(np.abs(w_closed - w_gd)).round(6))

    print("\n=== 逻辑回归：梯度下降拟合线性可分数据 ===")
    n2 = 200
    X2_raw = rng.normal(0, 1, (n2, 2))
    true_w2 = np.array([3.0, -2.0, 0.0])
    z = np.hstack([X2_raw, np.ones((n2, 1))]) @ true_w2
    p_true = sigmoid(z)
    y2 = (rng.uniform(0, 1, n2) < p_true).astype(float)
    X2 = np.hstack([X2_raw, np.ones((n2, 1))])

    w2, losses = logistic_regression_gd(X2, y2, lr=0.5, epochs=1000)
    print("真实参数:  ", true_w2.round(4))
    print("学到的参数:", w2.round(4))
    print("初始损失:", round(losses[0], 4), " 最终损失:", round(losses[-1], 4))

    pred_labels = (sigmoid(X2 @ w2) > 0.5).astype(float)
    accuracy = np.mean(pred_labels == y2)
    print("训练集准确率:", round(accuracy, 4))
```

实测输出（numpy 2.4.4）：

```
=== 线性回归：闭式解 vs 梯度下降 ===
真实参数:       [ 2.  -1.5  0.5]
闭式解:         [ 1.9857 -1.4985  0.4936]
梯度下降解:      [ 1.9857 -1.4985  0.4936]
闭式解与梯度下降解的最大差异: 0.0

=== 逻辑回归：梯度下降拟合线性可分数据 ===
真实参数:   [ 3. -2.  0.]
学到的参数: [ 2.499  -1.652   0.2212]
初始损失: 0.6931  最终损失: 0.3583
训练集准确率: 0.84
```

结果验证了两个核心结论：**线性回归的梯度下降解与闭式解完全一致**（最大差异为 0），印证了第 1 节"两者本质上求解的是同一个二次优化问题"；**逻辑回归的梯度下降从初始损失 0.6931（恰好是 `-log(0.5)`，对应参数全为 0 时输出概率恒为 0.5 的损失）逐步下降到 0.3583**，训练集准确率达到 84%，说明梯度下降确实在数值上逼近了非线性方程组的解，印证了第 2 节"逻辑回归没有闭式解，必须迭代求解"的结论。

## 5. 小结

| 方法 | 决策形式 | 损失函数 | 求解方式 |
| --- | --- | --- | --- |
| 线性回归 | 连续值预测 | 平方误差 | 闭式解（正规方程）或梯度下降 |
| 逻辑回归 | 二分类（线性决策边界） | 交叉熵（最大似然导出） | 仅梯度下降等迭代方法 |

两者共享"残差加权特征"的梯度结构，都属于广义线性模型；线性回归的闭式解得益于损失函数是参数的二次函数，逻辑回归因 sigmoid 引入非线性而失去这一性质。
