## 1. 贝叶斯定理与生成式建模

朴素贝叶斯（Naive Bayes）是一个**生成式模型（generative model）**：它不直接建模决策边界，而是先建模"每个类别会生成什么样的数据"，再用贝叶斯定理反推"给定这个数据，最可能是哪个类别"。

贝叶斯定理：

```
P(y|x) = P(x|y) · P(y) / P(x)
```

分类时要在所有类别里选后验概率 `P(y|x)` 最大的那个，而 `P(x)` 对所有类别都是同一个常数（不影响谁最大），所以可以简化为：

```
ŷ = argmax_y  P(x|y) · P(y)
```

- `P(y)`：**先验概率（prior）**，类别本身的出现频率，直接用训练集中各类别的占比估计。
- `P(x|y)`：**类条件概率（likelihood）**，"这个类别会生成这个样本"的概率，这是建模的核心难点——`x` 通常是多维特征 `(x_1, ..., x_d)`，直接建模 `P(x_1,...,x_d|y)` 需要估计特征间所有可能的联合分布，样本量稍大就估计不动了。

## 2. 条件独立假设：很强但很好用

朴素贝叶斯给出的解决方案是**朴素（naive）的条件独立假设**：假设在给定类别 `y` 的条件下，各个特征相互独立：

```
P(x_1, ..., x_d | y) = Π_{j=1}^{d} P(x_j | y)
```

这把一个高维联合分布的估计问题，拆成了 `d` 个一维分布的估计问题——每个 `P(x_j|y)` 只需要统计"类别 `y` 下特征 `j` 的分布"，需要的样本量和参数量都大幅下降。

这个假设在现实中几乎总是不严格成立的（比如垃圾邮件分类里，"免费"和"中奖"两个词的出现显然不独立），但朴素贝叶斯依然在很多任务上表现不错，原因是：**分类只需要"正确类别的后验概率最大"，不需要"每个类别的后验概率被精确估计"**。即使条件独立假设让每个 `P(x|y)` 的绝对值估计得不准，只要这个不准确在各个类别之间是"同方向"的系统性偏差，最终argmax 选出的类别排序仍然可能是对的。换句话说，朴素贝叶斯要解决的是一个比"精确密度估计"更容易的问题。

## 3. 三种朴素贝叶斯变体：按特征类型选择

`P(x_j|y)` 具体用什么分布建模，取决于特征 `x_j` 的类型：

- **高斯朴素贝叶斯（Gaussian NB）**：特征是连续值（比如身高、温度），假设每个类别下特征服从高斯分布，用训练集里该类别样本的均值和方差估计参数。适合特征是连续数值型的场景。
- **多项式朴素贝叶斯（Multinomial NB）**：特征是离散计数（比如文档里每个词出现的次数），假设特征服从多项分布。最经典的应用是文本分类的词频特征（bag-of-words）。
- **伯努利朴素贝叶斯（Bernoulli NB）**：特征是二值（比如"某个词是否出现"，不关心出现几次），假设每个特征服从伯努利分布。适合"有没有"比"有多少"更重要的场景（比如短文本，词频信息不明显）。

三者的区别本质是对 `P(x_j|y)` 用了不同的分布假设，选择哪种取决于特征本身的性质，不是效果好坏之分。

## 4. 拉普拉斯平滑：解决零概率问题

以多项式朴素贝叶斯为例，`P(x_j|y)` 的最大似然估计是"词 `j` 在类别 `y` 的所有文档中出现的次数占比"：

```
P(x_j|y) = count(x_j, y) / Σ_k count(x_k, y)
```

问题：如果某个词在训练集里从未在类别 `y` 的文档中出现过，`count(x_j,y) = 0`，估计出 `P(x_j|y) = 0`。而朴素贝叶斯预测时是把各特征的概率**相乘**，只要有一个特征概率为 0，无论其他特征多支持这个类别，整个乘积都会被拉成 0——一个从未见过的词，直接否决了整个类别，这显然不合理（训练集没见过，不代表真实世界不会出现）。

**拉普拉斯平滑（Laplace smoothing / additive smoothing）** 给每个计数加一个小的常数 `α`（通常取 1）：

```
P(x_j|y) = (count(x_j, y) + α) / (Σ_k count(x_k, y) + α·d)

d: 特征总数（分母同步加 α·d 保证所有概率仍然和为1）
```

这样任何未出现过的特征也能拿到一个很小但非零的概率，避免了"一个未见特征否决整个类别"的问题。`α` 越大平滑越强（概率分布越接近均匀），`α→0` 时退化为无平滑的最大似然估计。

## 5. 数值下溢与对数域计算

朴素贝叶斯的预测公式是多个概率相乘：

```
P(y) · Π_{j=1}^{d} P(x_j|y)
```

当特征数 `d` 较大时（文本分类里词表可能有几千上万个词），几十个小于 1 的数连续相乘，乘积会以指数速度趋近于 0，很快超出浮点数能表示的最小正数范围，直接下溢为 0——一旦所有类别的乘积都变成 0，argmax 就失去了区分度。

解决方法是把乘积转换成对数域的加和，因为 `log` 是单调函数，不改变 argmax 的结果：

```
argmax_y [ log P(y) + Σ_j log P(x_j|y) ]
```

对数值不会指数级趋近于 0（只会趋近于负无穷，但在浮点数表示范围内始终能保留大小关系），求和运算本身也不会有乘法那样的误差累积问题。**这是朴素贝叶斯（以及几乎所有涉及概率乘积的模型）实践中必须使用对数域计算的原因**，不是优化技巧，而是数值正确性的必要条件。

## 6. 生成式模型 vs 判别式模型

朴素贝叶斯是生成式模型的代表，与逻辑回归、SVM 等判别式模型形成直接对比：

- **生成式模型（generative）**：建模 `P(x|y)` 和 `P(y)`，本质是在学习"数据是怎么被生成出来的"，分类只是其中一个副产品（可以反过来用学到的 `P(x|y)` 生成新样本）。优点是需要的训练数据可以更少（假设简单，参数少），能处理缺失特征（对缺失维度直接不计入乘积），天然支持无监督/半监督扩展。
- **判别式模型（discriminative）**：直接建模决策边界或 `P(y|x)`，不关心数据本身是怎么生成的。通常在有充足训练数据时准确率更高（不需要对数据分布做强假设），因为它把全部建模能力都投入在"分类"这一件事上，而不是先建模一个更难的联合分布问题再退回到分类。

选择哪一类，取决于数据量、是否需要处理缺失值、是否需要生成能力等具体场景，不存在绝对优劣。

## 7. 最小可运行实现：高斯 NB 分类 + 拉普拉斯平滑对比 + 数值下溢演示

```python
"""
三个实验：
  1. 高斯朴素贝叶斯在连续特征数据上的分类效果
  2. 拉普拉斯平滑前后，对"训练集未出现过的词"的对数概率估计对比
  3. 对数域求和 vs 直接概率乘积的数值稳定性对比（真实触发下溢）
"""
import numpy as np

rng = np.random.default_rng(0)


class GaussianNB:
    def fit(self, X, y):
        self.classes = np.unique(y)
        self.priors, self.means, self.vars = {}, {}, {}
        for c in self.classes:
            Xc = X[y == c]
            self.priors[c] = len(Xc) / len(X)
            self.means[c] = Xc.mean(axis=0)
            self.vars[c] = Xc.var(axis=0) + 1e-9  # 防止方差为0导致除零

    def _log_likelihood(self, X, c):
        mean, var = self.means[c], self.vars[c]
        return -0.5 * np.sum(np.log(2 * np.pi * var)) - 0.5 * np.sum(
            (X - mean) ** 2 / var, axis=1
        )

    def predict(self, X):
        log_probs = np.stack(
            [np.log(self.priors[c]) + self._log_likelihood(X, c) for c in self.classes],
            axis=1,
        )
        return self.classes[np.argmax(log_probs, axis=1)]


class MultinomialNB:
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes = np.unique(y)
        self.priors, self.log_feat_prob = {}, {}
        n_features = X.shape[1]
        for c in self.classes:
            Xc = X[y == c]
            self.priors[c] = len(Xc) / len(X)
            feat_counts = Xc.sum(axis=0)
            total = feat_counts.sum()
            # 拉普拉斯平滑：分子+alpha，分母+alpha*特征数
            self.log_feat_prob[c] = np.log(
                (feat_counts + self.alpha) / (total + self.alpha * n_features)
            )


if __name__ == "__main__":
    # ---- 实验 1：高斯 NB 分类 ----
    n_per_class = 50
    X0 = rng.normal([0, 0], 1.0, (n_per_class, 2))
    X1 = rng.normal([3, 3], 1.0, (n_per_class, 2))
    X = np.vstack([X0, X1])
    y = np.array([0] * n_per_class + [1] * n_per_class)

    gnb = GaussianNB()
    gnb.fit(X, y)
    print("=== 高斯朴素贝叶斯 ===")
    print(f"训练集准确率: {np.mean(gnb.predict(X) == y):.4f}")

    # ---- 实验 2：拉普拉斯平滑对"未见过的词"的影响 ----
    # 6篇文档，5个词；词4只在类别1中出现过，类别0从未见过词4
    X_text = np.array([
        [3, 1, 0, 0, 0], [2, 2, 1, 0, 0], [4, 0, 0, 0, 0],
        [0, 1, 2, 3, 1], [0, 0, 1, 4, 2], [1, 0, 0, 2, 3],
    ])
    y_text = np.array([0, 0, 0, 1, 1, 1])

    mnb_smooth = MultinomialNB(alpha=1.0)
    mnb_smooth.fit(X_text, y_text)
    mnb_nosmooth = MultinomialNB(alpha=1e-10)
    mnb_nosmooth.fit(X_text, y_text)

    print("\n=== 拉普拉斯平滑对比（词4在类别0中的对数概率）===")
    print(f"平滑 (alpha=1.0):      log P = {mnb_smooth.log_feat_prob[0][3]:.4f}")
    print(f"几乎不平滑 (alpha=1e-10): log P = {mnb_nosmooth.log_feat_prob[0][3]:.4f}")

    # ---- 实验 3：数值下溢，对数域 vs 直接乘积 ----
    print("\n=== 数值下溢演示 ===")
    small_probs = np.full(400, 0.01)  # 400个特征，每个条件概率都是0.01
    direct_product = np.prod(small_probs)
    log_sum = np.sum(np.log(small_probs))
    print(f"直接乘积（400个0.01相乘）: {direct_product}")
    print(f"对数域求和后取exp: {np.exp(log_sum)}")
    print(f"对数域求和（比较大小时实际使用的值）: {log_sum:.4f}")
```

实测输出（numpy 2.4.4）：

```
=== 高斯朴素贝叶斯 ===
训练集准确率: 0.9600

=== 拉普拉斯平滑对比（词4在类别0中的对数概率）===
平滑 (alpha=1.0):      log P = -2.8904
几乎不平滑 (alpha=1e-10): log P = -25.5908

=== 数值下溢演示 ===
直接乘积（400个0.01相乘）: 0.0
对数域求和后取exp: 0.0
对数域求和（比较大小时实际使用的值）: -1842.0681
```

高斯 NB 在两个高斯簇的数据上达到 96% 训练准确率，验证了条件独立假设下的分类效果。第二组实验印证了第 4 节：不加平滑时词 4 在类别 0 中的对数概率被压到 -25.59（对应概率 `exp(-25.59)≈7.6e-12`，接近但不是硬性的 0，因为 `alpha=1e-10` 仍是极小的正数）；加了拉普拉斯平滑后这个概率是 -2.89（对应约 0.055），保留了合理的不确定性而不是直接否决。第三组实验直接触发了下溢：400 个 0.01 连续相乘，直接乘积精确下溢为 `0.0`（超出 float64 能表示的最小正数），此时对该乘积取 `exp(log_sum)` 也已经无法恢复出非零值；但 `log_sum=-1842.07` 这个对数域的值本身没有损失任何信息，仍然可以正确地和其他类别的对数域得分比较大小——这正是第 5 节强调的"对数域计算是数值正确性的必要条件"。

## 8. 小结

| 概念 | 核心含义 |
| --- | --- |
| 生成式建模 | 建模 `P(x\|y)·P(y)`，用贝叶斯定理反推分类 |
| 条件独立假设 | 拆解高维联合分布为多个一维分布，假设强但降低了估计难度 |
| 高斯/多项式/伯努利 NB | 按特征类型（连续/计数/二值）选择对应分布假设 |
| 拉普拉斯平滑 | 给计数加常数，避免未见特征导致零概率否决整个类别 |
| 对数域计算 | 避免多个小概率连乘导致的数值下溢 |
| 生成式 vs 判别式 | 生成式建模数据分布本身，判别式直接建模决策边界 |
