## 1. 维度灾难：高维空间的反直觉现象

**维度灾难（curse of dimensionality）** 指很多在低维空间里符合直觉的性质，在高维空间会失效：

- **数据变得稀疏**：要在 `d` 维空间保持固定的采样密度，需要的样本数随 `d` 指数增长。样本数固定时，维度越高数据点就越稀疏，"局部"方法（KNN、核密度估计）会因附近几乎没有点而失效。
- **距离失去区分度**：高维空间中随机采样点两两之间的距离会趋于集中（最近点和最远点的距离比趋近于 1），依赖距离的算法（KNN、K-Means）效果会退化。
- **模型更容易过拟合**：特征数越多，模型自由度越高，样本数不变时越容易学到噪声而非规律（呼应[学习范式与泛化](../01-机器学习基础/01-学习范式与泛化.md)里"结构风险最小化"要解决的问题）。

降维的核心目标是把数据从高维空间映射到更低维的子空间，同时尽量保留原始数据中"有用"的结构信息，从而缓解上述问题。

## 2. PCA 视角一：方差最大化

**主成分分析（Principal Component Analysis, PCA）** 的第一个视角是：找一个方向，使数据投影到这个方向后**方差最大**——方差大意味着这个方向上数据的差异性/信息量最大，是最能区分不同样本的方向。

设数据已中心化（均值为 0），要找单位向量 `w`（`||w||=1`），使投影 `Xw` 的方差最大：

```
Var(Xw) = (1/n) Σ_i (x_i · w)^2 = w^T Σ w

Σ = (1/n) X^T X : 数据的协方差矩阵
```

这是一个带约束的优化问题（`max w^T Σ w`，约束 `||w||=1`），用拉格朗日乘子法求解：

```
L(w, λ) = w^T Σ w - λ(w^T w - 1)
∂L/∂w = 2Σw - 2λw = 0  =>  Σw = λw
```

这正是**特征值方程**——最优的 `w` 是协方差矩阵 `Σ` 的特征向量，对应的方差就是特征值 `λ`。**要让方差最大，就选最大特征值对应的特征向量作为第一主成分**；第二主成分是与第一主成分正交、且方差次大的方向，对应第二大特征值的特征向量；以此类推。

## 3. PCA 视角二：重构误差最小化

第二个视角从相反的方向出发：如果只能保留 `k` 维（`k < d`）来近似原始数据，**怎么选这 `k` 维，才能让降维后再"还原"回原始维度的重构误差最小**？

设用一组正交基 `W`（`d×k` 矩阵，列正交）把数据投影到 `k` 维再重构回来，重构误差是：

```
min_W  Σ_i ||x_i - W W^T x_i||^2   s.t. W^T W = I
```

这个问题的最优解同样是协方差矩阵前 `k` 个最大特征值对应的特征向量。直觉上并不意外：**方差最大的方向是数据"延展"得最开的方向，把数据压缩到这些方向上损失的信息（重构误差）自然最小；反过来，方差很小的方向上数据几乎不变化，压缩掉这些方向几乎不损失信息**。两个视角（最大化保留的信息 vs 最小化丢弃的信息）在数学上是同一个优化问题的两种等价表述，都收敛到"协方差矩阵的主特征向量"这个解。

## 4. 特征值分解与 SVD 的关系

实践中很少直接对协方差矩阵做特征值分解，而是对中心化后的数据矩阵 `X`（`n×d`）直接做**奇异值分解（SVD）**：

```
X = U S V^T

U: n×d，列正交（左奇异向量）
S: 对角矩阵，对角元素是奇异值 σ_1 ≥ σ_2 ≥ ... ≥ 0
V: d×d，列正交（右奇异向量）
```

`V` 的列恰好就是协方差矩阵 `Σ = X^T X / (n-1)` 的特征向量，且特征值 `λ_i = σ_i^2 / (n-1)`——**SVD 直接给出 PCA 需要的主成分方向和方差，不需要先显式构造协方差矩阵再分解**。这在工程上有实际好处：特征数 `d` 很大时，`d×d` 协方差矩阵的计算和分解开销很大，直接对 `n×d` 原始数据做 SVD 通常更稳定、更省内存（尤其 `n < d` 时）。

## 5. 为什么必须中心化

PCA 的目标是找"数据本身内部差异最大"的方向，这个"差异"应该是相对于数据中心（均值）衡量的方差，而不是相对于坐标原点的绝对位置。如果不先减去均值，协方差矩阵 `X^T X` 实际计算的是**未中心化的二阶矩**，其中会混入均值本身的贡献——如果数据整体离原点很远（均值很大），"第一主成分"很可能会被拉向"从原点指向数据均值"的方向，而不是数据内部真正方差最大的方向，导致主成分完全偏离预期。这不是数值稳定性问题，是优化目标本身被错误定义的问题，因此中心化是 PCA 的**必要前置步骤**，不是可选的工程技巧。

## 6. 如何选择主成分个数

- **累积方差贡献率（cumulative explained variance ratio）**：每个主成分的方差贡献率是它的特征值占所有特征值总和的比例，累加前 `k` 个的贡献率，选能覆盖足够高比例（如 90%、95%，具体阈值取决于任务对信息损失的容忍度）的最小 `k`。
- **肘部法则**：类似聚类里选 `K` 的思路，画出特征值（或累积贡献率）随主成分个数的变化曲线，找下降速度明显变缓的拐点。
- **按下游任务效果调**：如果降维是为了给下游模型用，也可以把 `k` 当作超参数，用交叉验证直接看下游任务效果来选。

> ⚠️ 待确认：不同领域对"足够高比例"阈值的选择没有统一标准，本文不给出通用数值建议。

## 7. t-SNE 与 UMAP：非线性降维，用于可视化

PCA 是线性降维——只能捕捉能用直线/平面近似的结构，如果高维数据的内在结构是非线性的（比如两个卷曲缠绕的流形），线性投影会把原本分开的结构压缩到一起。**t-SNE（t-distributed Stochastic Neighbor Embedding）** 和 **UMAP（Uniform Manifold Approximation and Projection）** 是两种流行的非线性降维方法，核心思路是：在高维空间衡量点与点的"邻近关系"，再在低维空间找一个映射，尽量保持这种邻近关系（近的点在低维空间也近，远的点不强求保持精确距离）。

它们最主要的应用场景是**高维数据可视化**（把上百维特征压缩到 2D/3D 画图，直观观察数据是否存在聚类结构）。

**常见误用陷阱：把 t-SNE/UMAP 的输出直接当作下游模型的输入特征。** 原因是：

- 它们优化的目标是"局部邻近关系在可视化意义下看起来合理"，**不保证全局距离、方向、尺度有实际意义**——图上分得很开的两个簇，原始空间的距离未必真的悬殊；图上离得近的点，原始特征也未必真的相似。
- 通常是非参数化或依赖随机初始化的（换个随机种子结果可能明显不同），缺乏可重复性，也不像 PCA 那样能用同一组主成分方向一致地变换新样本。
- 目标函数是"让可视化图符合高维邻近关系"，不是"最大程度保留下游任务需要的信息"，用作特征会引入与下游任务目标无关的失真。

**正确用法**：t-SNE/UMAP 用于探索性数据分析、直观检查数据是否有可分性/聚类结构；下游模型需要降维时应该用 PCA 等保留了可解释、可复现映射关系的方法。

## 8. 最小可运行实现：PCA 两种视角验证 + 中心化必要性 + 重构误差

```python
"""
四个实验：
  1. 中心化的必要性：对比中心化前后PCA得到的"第一主成分"方向
  2. 特征值分解 vs SVD：验证两种方法给出的主成分方向和方差一致
  3. 累积方差贡献率：观察前几个主成分能覆盖多少方差
  4. 重构误差：保留的主成分越多，重构误差应单调下降
"""
import numpy as np

rng = np.random.default_rng(0)


def pca_eig(X_centered, n_components):
    """视角1：方差最大化，对协方差矩阵做特征值分解"""
    cov = (X_centered.T @ X_centered) / (len(X_centered) - 1)
    eigvals, eigvecs = np.linalg.eigh(cov)  # 对称矩阵，返回升序特征值
    order = np.argsort(eigvals)[::-1]
    eigvals, eigvecs = eigvals[order], eigvecs[:, order]
    components = eigvecs[:, :n_components]
    explained_var_ratio = eigvals[:n_components] / eigvals.sum()
    return components, explained_var_ratio, eigvals


def pca_svd(X_centered, n_components):
    """视角2：直接对数据矩阵做SVD，V的列即协方差矩阵的特征向量"""
    U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)
    components = Vt[:n_components].T
    eigvals_from_svd = (S ** 2) / (len(X_centered) - 1)
    ratio = eigvals_from_svd[:n_components] / eigvals_from_svd.sum()
    return components, ratio, eigvals_from_svd


if __name__ == "__main__":
    # 构造数据：沿[1,1,0]方向方差大，正交方向方差小，且整体偏离原点（验证中心化必要性）
    n = 200
    t = rng.normal(0, 3, n)
    noise = rng.normal(0, 0.3, (n, 3))
    direction = np.array([1, 1, 0]) / np.sqrt(2)
    X_raw = np.outer(t, direction) + noise
    X_raw += np.array([10, 5, -3])  # 非零均值

    mean = X_raw.mean(axis=0)
    X_centered = X_raw - mean

    comp_nocenter, _, _ = pca_eig(X_raw, 1)       # 错误做法：不中心化
    comp_center, var_ratio, eigvals = pca_eig(X_centered, 1)

    print("=== 中心化的必要性 ===")
    print(f"真实主方向: {direction}")
    print(f"不中心化得到的第一主成分: {comp_nocenter[:, 0]}")
    print(f"中心化后得到的第一主成分: {comp_center[:, 0]}")

    comp_eig, var_ratio_eig, eigvals_eig = pca_eig(X_centered, 3)
    comp_svd, _, eigvals_svd = pca_svd(X_centered, 3)

    print("\n=== 特征值分解 vs SVD ===")
    print(f"特征值分解得到的特征值: {np.round(eigvals_eig, 4)}")
    print(f"SVD 还原出的特征值:     {np.round(eigvals_svd, 4)}")
    same_dir = np.allclose(np.abs(comp_eig[:, 0]), np.abs(comp_svd[:, 0]), atol=1e-6)
    print(f"两种方法第一主成分方向是否一致（绝对值意义下）: {same_dir}")

    print("\n=== 累积方差贡献率 ===")
    cumulative = np.cumsum(var_ratio_eig)
    for i, (ratio, cum) in enumerate(zip(var_ratio_eig, cumulative)):
        print(f"  第{i+1}个主成分: 贡献率={ratio:.4f}, 累积={cum:.4f}")

    print("\n=== 降维后重构误差 ===")
    for k in [1, 2, 3]:
        comp_k, _, _ = pca_eig(X_centered, k)
        projected = X_centered @ comp_k
        reconstructed = projected @ comp_k.T
        recon_error = np.mean(np.sum((X_centered - reconstructed) ** 2, axis=1))
        print(f"  保留{k}个主成分: 平均重构误差(MSE)={recon_error:.4f}")
```

实测输出（numpy 2.4.4）：

```
=== 中心化的必要性 ===
真实主方向: [0.70710678 0.70710678 0.        ]
不中心化得到的第一主成分: [-0.8594071  -0.4491401   0.24432072]
中心化后得到的第一主成分: [-0.69808909 -0.71581895 -0.01657903]

=== 特征值分解 vs SVD ===
特征值分解得到的特征值: [8.5299 0.1018 0.0916]
SVD 还原出的特征值:     [8.5299 0.1018 0.0916]
两种方法第一主成分方向是否一致（绝对值意义下）: True

=== 累积方差贡献率 ===
  第1个主成分: 贡献率=0.9778, 累积=0.9778
  第2个主成分: 贡献率=0.0117, 累积=0.9895
  第3个主成分: 贡献率=0.0105, 累积=1.0000

=== 降维后重构误差 ===
  保留1个主成分: 平均重构误差(MSE)=0.1924
  保留2个主成分: 平均重构误差(MSE)=0.0911
  保留3个主成分: 平均重构误差(MSE)=0.0000
```

结果验证了第 5 节的论断：真实主方向是 `[0.707, 0.707, 0]`，中心化后算出的第一主成分 `[-0.698, -0.716, -0.017]`（符号相反但方向一致，PCA 方向本就有正负号自由度）与真实方向高度吻合；不中心化直接算出的"第一主成分" `[-0.859, -0.449, 0.244]` 明显偏离——第三维原本几乎是纯噪声（方向分量应接近 0），却因均值偏移（`-3`）被错误赋予了 0.244 的权重，印证了不中心化会让均值污染主成分方向。特征值分解和 SVD 给出的特征值完全一致（`[8.5299, 0.1018, 0.0916]`），验证了第 4 节的等价关系。累积方差贡献率显示第一主成分就覆盖了 97.78% 的方差，与"信号集中在一个方向、其余是小噪声"的数据构造设定相符。重构误差随保留主成分数单调下降，保留全部 3 个主成分时重构误差为 0，符合预期。

## 9. 小结

| 概念 | 核心含义 |
| --- | --- |
| 维度灾难 | 高维下数据稀疏、距离失去区分度、更易过拟合 |
| PCA（方差最大化） | 找方差最大的正交方向作为主成分 |
| PCA（重构误差最小化） | 找使重构误差最小的低维子空间，与方差最大化等价 |
| 特征值分解 vs SVD | SVD 可直接给出主成分方向和方差，无需显式构造协方差矩阵 |
| 中心化 | PCA 的必要前置步骤，否则均值会污染主成分方向 |
| 选主成分个数 | 累积方差贡献率、肘部法则，或按下游任务效果调 |
| t-SNE/UMAP | 非线性降维，适合可视化，不适合作为下游特征 |
