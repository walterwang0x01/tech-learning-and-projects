## 1. 决策树的核心问题：怎么选分裂特征

决策树通过递归地把数据集按某个特征的取值切分成子集，构造出一棵树形结构，每个叶子节点对应一个预测结果。核心问题是：**在每一步，应该选哪个特征、按什么阈值切分，才能让切分后的子集尽可能"纯"（同类样本尽量聚在一起）**。三种主流算法在这个"纯度"指标上给出了不同答案。

## 2. ID3：信息增益

### 信息熵：衡量不纯度的起点

信息熵（entropy）衡量一个集合里类别分布的混乱程度：

```
Entropy(S) = -Σ_{k=1}^{K} p_k · log2(p_k)

S: 当前数据集，K: 类别数，p_k: 类别 k 在 S 中的占比
```

熵为 0 表示集合里只有一个类别（完全纯），熵越大表示类别分布越均匀混乱（`K=2` 且各占 50% 时熵取最大值 1）。

### 信息增益：切分前后熵的下降量

对特征 `A`，按它的取值把 `S` 切分成若干子集 `{S_1, ..., S_v}`，信息增益衡量这次切分带来的"纯度提升"：

```
Gain(S, A) = Entropy(S) - Σ_{i=1}^{v} (|S_i|/|S|) · Entropy(S_i)
```

第二项是切分后各子集熵的加权平均（按子集大小加权）。**ID3 在每一步选信息增益最大的特征进行切分**——直觉是：切分后子集越纯，说明这个特征越能有效区分类别。

### ID3 的固有偏向问题

信息增益有一个系统性偏向：**倾向于选择取值数目多的特征**。极端例子——如果某个特征是"样本编号"（每个样本取值都不同），按它切分后每个子集只有一个样本，熵为 0，信息增益达到最大，但这个特征对预测新样本毫无意义（过拟合到训练集的编号，没有泛化能力）。这是 ID3 的核心缺陷，直接推动了 C4.5 的改进。

## 3. C4.5：信息增益率

C4.5 引入**分裂信息（split information）** 来惩罚取值数目多的特征：

```
SplitInfo(S, A) = -Σ_{i=1}^{v} (|S_i|/|S|) · log2(|S_i|/|S|)

GainRatio(S, A) = Gain(S, A) / SplitInfo(S, A)
```

`SplitInfo` 本身衡量的是特征 `A` 把数据切成多少份、切得多均匀——切分数越多、越均匀，`SplitInfo` 越大。把信息增益除以 `SplitInfo`，相当于对"切分成很多份"这件事本身收取一个惩罚，抵消了 ID3 偏向多值特征的问题（前面"样本编号"的例子：切分成 N 份且每份 1 个样本时 `SplitInfo` 会很大，导致 `GainRatio` 反而不高）。

C4.5 还支持连续特征——把连续值排序后，尝试每两个相邻取值的中点作为切分阈值，逐一计算信息增益率，选最优阈值。

## 4. CART：基尼系数，支持回归

CART（Classification and Regression Tree）用**基尼系数（Gini impurity）** 替代熵作为不纯度指标：

```
Gini(S) = 1 - Σ_{k=1}^{K} p_k²
```

基尼系数和熵的形状类似（都在完全纯时取 0，均匀混合时取最大值），但基尼系数不需要计算对数，计算更快，是 sklearn 等库的默认选择。CART 每一步选**基尼系数下降最多**的切分（逻辑与信息增益一致，只是把 `Entropy` 换成 `Gini`）。

CART 与 ID3/C4.5 的另一个关键区别：**CART 只做二叉切分**（每次把节点分成左右两个子节点），即使是取值多于 2 个的分类特征，也会枚举所有可能的二分组合选最优的一种；对连续特征，同样是排序后取相邻中点做二分。CART 还天然支持**回归树**——把不纯度指标换成子集内部的均方误差（切分后让每个子集内部的目标值尽量集中），叶子节点的预测值是该叶子内训练样本目标值的均值。

## 5. 过拟合与剪枝：预剪枝 vs 后剪枝

决策树的表达能力很强——如果不加约束，理论上可以一直分裂到每个叶子只有一个样本（训练误差为 0），但这样的树高度过拟合训练数据中的噪声，泛化能力差。

**预剪枝（pre-pruning）**：在树生长过程中提前停止分裂。常见停止条件：达到最大深度、节点样本数少于阈值、切分后纯度提升小于阈值。优点是计算成本低（不需要生长出完整树再裁剪）；缺点是"贪心地提前停止"可能错过某个当前看起来收益不大、但后续分裂会带来大收益的切分（视野局限于当前一步）。

**后剪枝（post-pruning）**：先让树完整生长（往往会过拟合），再自底向上地评估每个子树，如果把某个子树替换成叶子节点（即剪掉它）不会显著增加验证集误差，就执行剪枝。CART 常用的**代价复杂度剪枝（cost-complexity pruning）** 引入一个惩罚项 `α`，用 `叶子节点误差总和 + α × 叶子节点数量` 衡量树的整体代价，在多个不同复杂度的子树中选一个在验证集上表现最好的。后剪枝通常比预剪枝效果更好（因为基于完整信息做决策），代价是需要先生长完整树，计算成本更高。

## 6. 最小可运行实现：手写 CART 分类树（基尼系数）

```python
"""
手写一个简化版 CART 分类树：
  1. 用基尼系数选择最优切分特征和阈值（仅支持连续特征，二叉切分）
  2. 递归构建树，支持最大深度和最小样本数两种预剪枝条件
  3. 在一个简单的二维数据集上验证分类效果
"""
import numpy as np


def gini(y):
    """基尼系数：1 - Σp_k^2"""
    if len(y) == 0:
        return 0.0
    _, counts = np.unique(y, return_counts=True)
    p = counts / len(y)
    return 1 - np.sum(p ** 2)


def best_split(X, y):
    """枚举所有特征的所有候选阈值，返回基尼系数下降最多的 (特征索引, 阈值)"""
    n_samples, n_features = X.shape
    best_gain, best_feat, best_thresh = -1, None, None
    parent_gini = gini(y)

    for feat in range(n_features):
        thresholds = np.unique(X[:, feat])
        for thresh in thresholds:
            left_mask = X[:, feat] <= thresh
            right_mask = ~left_mask
            if left_mask.sum() == 0 or right_mask.sum() == 0:
                continue
            left_gini = gini(y[left_mask])
            right_gini = gini(y[right_mask])
            weighted_gini = (left_mask.sum() * left_gini + right_mask.sum() * right_gini) / n_samples
            gain = parent_gini - weighted_gini
            if gain > best_gain:
                best_gain, best_feat, best_thresh = gain, feat, thresh

    return best_feat, best_thresh, best_gain


class Node:
    """树节点：内部节点存切分信息，叶子节点存预测类别"""
    def __init__(self, feature=None, threshold=None, left=None, right=None, value=None):
        self.feature = feature
        self.threshold = threshold
        self.left = left
        self.right = right
        self.value = value  # 仅叶子节点使用


def build_tree(X, y, depth=0, max_depth=3, min_samples=2):
    """递归构建 CART 树；预剪枝条件：达到最大深度 或 样本数不足 或 已经纯"""
    if depth >= max_depth or len(y) < min_samples or gini(y) == 0:
        values, counts = np.unique(y, return_counts=True)
        return Node(value=values[np.argmax(counts)])

    feat, thresh, gain = best_split(X, y)
    if feat is None or gain <= 0:
        values, counts = np.unique(y, return_counts=True)
        return Node(value=values[np.argmax(counts)])

    left_mask = X[:, feat] <= thresh
    left = build_tree(X[left_mask], y[left_mask], depth + 1, max_depth, min_samples)
    right = build_tree(X[~left_mask], y[~left_mask], depth + 1, max_depth, min_samples)
    return Node(feature=feat, threshold=thresh, left=left, right=right)


def predict_one(node, x):
    if node.value is not None:
        return node.value
    if x[node.feature] <= node.threshold:
        return predict_one(node.left, x)
    return predict_one(node.right, x)


def predict(tree, X):
    return np.array([predict_one(tree, x) for x in X])


if __name__ == "__main__":
    rng = np.random.default_rng(0)

    # 构造一个简单的二维、二分类数据集：两个高斯簇
    n_per_class = 50
    X0 = rng.normal([0, 0], 1.0, (n_per_class, 2))
    X1 = rng.normal([4, 4], 1.0, (n_per_class, 2))
    X = np.vstack([X0, X1])
    y = np.array([0] * n_per_class + [1] * n_per_class)

    print("=== 根节点基尼系数与最优切分 ===")
    root_gini = gini(y)
    feat, thresh, gain = best_split(X, y)
    print(f"根节点基尼系数: {root_gini:.4f}")
    print(f"最优切分特征: x{feat}, 阈值: {thresh:.4f}, 基尼下降量: {gain:.4f}")

    print("\n=== 构建树并验证不同最大深度下的训练准确率 ===")
    for max_depth in [1, 2, 3]:
        tree = build_tree(X, y, max_depth=max_depth, min_samples=2)
        pred = predict(tree, X)
        acc = np.mean(pred == y)
        print(f"  max_depth={max_depth}: 训练集准确率={acc:.4f}")
```

实测输出（numpy 2.4.4）：

```
=== 根节点基尼系数与最优切分 ===
根节点基尼系数: 0.5000
最优切分特征: x1, 阈值: 2.0024, 基尼下降量: 0.4804

=== 构建树并验证不同最大深度下的训练准确率 ===
  max_depth=1: 训练集准确率=0.9900
  max_depth=2: 训练集准确率=1.0000
  max_depth=3: 训练集准确率=1.0000
```

结果符合预期：根节点基尼系数为 0.5（两类各占一半时的最大不纯度，与第 4 节公式 `1-0.5²-0.5²=0.5` 吻合）；最优切分选在 `x1≈2.00`附近（恰好在两个高斯簇中心 0 和 4 之间），基尼下降量高达 0.4804，说明这一次切分几乎把两类完全分开——仅用深度为 1 的树（一次切分）就达到了 99% 的训练集准确率，这是因为构造的数据本身线性可分度很高；深度增加到 2 时准确率达到 100%，体现了树通过多次切分逐步修正边界附近误分类样本的能力。

## 7. 小结

| 算法 | 不纯度指标 | 切分方式 | 特点 |
| --- | --- | --- | --- |
| ID3 | 信息增益 | 多叉，仅支持分类特征 | 偏向取值多的特征，无剪枝机制 |
| C4.5 | 信息增益率 | 多叉，支持连续特征 | 用分裂信息惩罚多值偏向 |
| CART | 基尼系数（或 MSE） | 二叉，支持分类/连续/回归 | 计算快，支持后剪枝，sklearn 默认 |

剪枝是控制决策树过拟合的核心手段：预剪枝在生长阶段限制复杂度（计算快但可能欠拟合），后剪枝先长满再裁剪（效果通常更好但计算成本更高）。
