## 1. K-Means：目标函数与 EM 视角

K-Means 的目标是把 `n` 个样本划分成 `K` 个簇，使**簇内平方和（within-cluster sum of squares, WCSS，也叫 inertia）** 最小：

```
min_{C_1,...,C_K, μ_1,...,μ_K}  Σ_{k=1}^{K} Σ_{x∈C_k} ||x - μ_k||^2

C_k: 第k个簇的样本集合，μ_k: 第k个簇的中心（均值）
```

这是一个组合优化问题（同时优化"怎么分组"和"每组中心在哪"），精确求解是 NP-hard 的，K-Means 用**交替优化（迭代）** 求一个局部最优解，这个过程恰好对应 EM 算法（Expectation-Maximization）的结构：

- **E 步（分配，等价于 K-Means 的"分配"步）**：固定当前的簇中心，把每个样本分配给离它最近的中心——这是在"期望"每个样本最可能属于哪个簇。
- **M 步（更新，等价于 K-Means 的"更新"步）**：固定当前的分配结果，把每个簇的中心更新为该簇内所有样本的均值——这是在给定分配后，找能让簇内平方和最小的中心（对 `μ_k` 求导即可得到均值是最优解）。

交替执行这两步，目标函数值单调不增，最终收敛到一个局部最优（不保证全局最优，这也是为什么初始化方式很重要）。**K-Means 可以看作高斯混合模型（GMM）在"每个簇的协方差是单位矩阵、且做硬分配（hard assignment）"这个特殊假设下的极限情况**——GMM 的 E 步给出每个样本属于每个簇的概率（软分配），M 步更新每个簇的均值和协方差；当协方差被强制设为球形且相等时，软分配会退化为"离哪个中心最近就完全属于哪个簇"的硬分配，这正是 K-Means。

## 2. K-Means++：更聪明的初始化

标准 K-Means 随机选 `K` 个初始中心，如果运气不好（比如两个初始中心离得很近），容易收敛到较差的局部最优。**K-Means++** 的初始化策略是：

1. 随机选第一个中心。
2. 对剩下每个待选中心，按"离已有中心的距离平方"作为采样权重——**离现有中心越远的点，越容易被选中**。
3. 重复直到选出 `K` 个初始中心。

这个策略的动机很直接：既然目标函数是最小化"点到最近中心的距离平方和"，那么初始化时就主动让候选中心互相离得远一些，减少"多个中心挤在同一个真实簇里"的概率，从而更快收敛到更好的局部最优。K-Means++ 只改变初始化方式，不改变后续迭代逻辑。

## 3. 如何选择 K

K-Means 需要提前指定簇数 `K`，两种常见的选择方法：

- **肘部法则（elbow method）**：画出不同 `K` 下的簇内平方和（inertia），`K` 增大，inertia 必然单调递减（簇越多，每个簇内部越紧凑），但递减速度会在某个 `K` 之后明显变慢，形成一个"肘部"拐点——这个拐点通常被认为是较合理的 `K`。缺点是拐点有时不明显，判断依赖主观观察。
- **轮廓系数（silhouette coefficient）**：对每个样本 `i`，计算它与同簇内其他点的平均距离 `a(i)`（簇内紧密度），以及它与最近的其他簇内所有点的平均距离 `b(i)`（簇间分离度），轮廓系数为 `(b(i)-a(i)) / max(a(i),b(i))`，取值范围 `[-1,1]`，越接近 1 说明该点被分得越好。对所有样本取平均得到整体轮廓系数，选让平均轮廓系数最大的 `K`。相比肘部法则，轮廓系数给出的是一个可直接比较大小的量化指标，不需要主观找拐点。

## 4. K-Means 的局限：球形簇与均匀密度假设

K-Means 的目标函数（欧氏距离平方和）隐含了两个强假设：

- **簇是球形（更准确地说是凸的、各方向方差相近）**：因为 K-Means 用欧氏距离到中心点衡量归属，如果真实的簇是狭长的、环形的、或者非凸形状，用一个中心点+欧氏距离根本无法正确描述这种形状，会把一个真实簇错误地切成几块，或者把不同簇的边界样本分错。
- **各簇密度、大小相近**：K-Means 的分配规则对每个簇给予同等的"势力范围"，如果某个簇样本稀疏、分布范围很大，另一个簇样本密集、范围很小，K-Means 容易把大簇的边缘样本错误地划给附近的小簇。

这两个假设失效时（比如环形、月牙形、密度差异大的簇），K-Means 的效果会明显变差，需要考虑密度聚类等不依赖球形假设的方法。

## 5. DBSCAN：密度可达与噪声识别

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）不假设簇的形状，而是用"密度连通性"定义簇。核心概念：

- **`eps`**：邻域半径，两个点距离小于 `eps` 才算"邻居"。
- **`min_pts`**：一个点如果邻域内（半径 `eps` 内）的点数（包括自己）达到 `min_pts`，称为**核心点（core point）**。
- **密度可达（density-reachable）**：如果点 `q` 在核心点 `p` 的 `eps` 邻域内，则 `q` 从 `p` 密度可达。
- 一个簇由若干**相互密度可达的核心点及其邻域内的点**构成——从任意一个核心点出发，不断把它 `eps` 邻域内的点纳入同一簇，如果新纳入的点也是核心点，就继续从它出发扩展，直到没有新点可加入。
- 既不是核心点、也不在任何核心点的 `eps` 邻域内的点，标记为**噪声点（noise）**，不属于任何簇。

DBSCAN 不需要提前指定簇数，能自动识别任意形状的簇，还能天然剔除噪声/离群点——这些都是 K-Means 做不到的。代价是需要调 `eps` 和 `min_pts` 两个超参数，且对密度差异很大的数据（不同簇密度悬殊）效果也会打折扣（一套 `eps` 无法同时适配疏密不同的区域）。

## 6. 层次聚类与 linkage 选择

层次聚类（hierarchical clustering）不需要提前指定 `K`，而是构建一个完整的合并/分裂树（dendrogram），之后再根据需要在某个高度"切一刀"决定最终簇数。最常用的是**自底向上凝聚式（agglomerative）**：一开始每个样本自成一簇，每一步合并"距离最近"的两个簇，直到只剩目标簇数（或剩 1 个簇）。

"两个簇之间的距离"有多种定义方式（**linkage**），直接决定聚类的行为倾向：

- **single linkage**：两簇间最近的一对点的距离。倾向于产生"链状"的细长簇，对噪声敏感（一条噪声链可能把两个原本该分开的簇连起来）。
- **complete linkage**：两簇间最远的一对点的距离。倾向于产生紧凑、大小相近的簇，对噪声更鲁棒。
- **average linkage**：两簇间所有点对距离的平均值，介于前两者之间的折中。
- **ward linkage**：合并后簇内平方和增量最小的两簇优先合并，目标与 K-Means 的思路一致，倾向于产生球形、大小均衡的簇。

选择哪种 linkage 取决于对簇形状的假设：怀疑数据里有链状结构用 single linkage，希望簇紧凑均衡用 complete 或 ward linkage。

## 7. GMM 简介

高斯混合模型（Gaussian Mixture Model, GMM）假设数据由 `K` 个高斯分布混合生成，每个样本以一定概率属于每个高斯成分（软分配，而非 K-Means 的硬分配）。用 EM 算法求解：E 步计算每个样本属于每个高斯成分的后验概率（responsibility），M 步用这些概率作为权重重新估计每个高斯成分的均值、协方差和混合系数。相比 K-Means，GMM 能表达椭圆形（而非仅球形）的簇，且给出的是概率归属而不是硬性归类，但参数更多（每个簇的协方差矩阵），计算和收敛也更复杂。

## 8. 最小可运行实现：K-Means（含K-Means++）与 DBSCAN 对比

```python
"""
两个实验：
  1. K-Means + K-Means++ 初始化，用肘部法则观察inertia随K的变化趋势
  2. 在环形+球形混合数据上对比 K-Means 与 DBSCAN，验证球形假设失效时的表现差异
"""
import numpy as np

rng = np.random.default_rng(0)


def kmeans_pp_init(X, k):
    """K-Means++：按距已有中心的距离平方加权采样，让初始中心互相分散"""
    centers = [X[rng.integers(len(X))]]
    for _ in range(1, k):
        dist_sq = np.min([np.sum((X - c) ** 2, axis=1) for c in centers], axis=0)
        probs = dist_sq / dist_sq.sum()
        centers.append(X[rng.choice(len(X), p=probs)])
    return np.array(centers)


def kmeans(X, k, n_iter=100):
    """E步：分配最近中心；M步：更新中心为簇内均值"""
    centers = kmeans_pp_init(X, k)
    for _ in range(n_iter):
        dists = np.stack([np.sum((X - c) ** 2, axis=1) for c in centers], axis=1)
        labels = np.argmin(dists, axis=1)
        new_centers = np.array([
            X[labels == j].mean(axis=0) if (labels == j).any() else centers[j]
            for j in range(k)
        ])
        if np.allclose(new_centers, centers):
            break
        centers = new_centers
    inertia = np.sum((X - centers[labels]) ** 2)
    return labels, centers, inertia


def dbscan(X, eps, min_pts):
    """基于密度可达性聚类，-1表示噪声点"""
    n = len(X)
    labels = np.full(n, -2)  # -2:未访问 -1:噪声 >=0:簇编号
    dist_matrix = np.sqrt(((X[:, None, :] - X[None, :, :]) ** 2).sum(axis=2))

    def neighbors(i):
        return np.where(dist_matrix[i] <= eps)[0]

    cluster_id = 0
    for i in range(n):
        if labels[i] != -2:
            continue
        idx = neighbors(i)
        if len(idx) < min_pts:
            labels[i] = -1
            continue
        labels[i] = cluster_id
        seeds = list(idx)
        while seeds:
            j = seeds.pop()
            if labels[j] in (-1, -2):
                labels[j] = cluster_id
                j_neighbors = neighbors(j)
                if len(j_neighbors) >= min_pts:
                    seeds.extend(j_neighbors.tolist())
        cluster_id += 1
    return labels


if __name__ == "__main__":
    # ---- 实验1：肘部法则 ----
    centers_true = [[0, 0], [5, 5], [0, 5]]
    X = np.vstack([rng.normal(c, 0.5, (30, 2)) for c in centers_true])

    print("=== 肘部法则：不同K的inertia ===")
    for k in range(1, 6):
        _, _, inertia = kmeans(X, k)
        print(f"  k={k}: inertia={inertia:.2f}")

    # ---- 实验2：环形+球形混合数据，K-Means vs DBSCAN ----
    theta = np.linspace(0, 2 * np.pi, 40, endpoint=False)
    ring = np.stack([4 * np.cos(theta), 4 * np.sin(theta)], axis=1) + rng.normal(0, 0.15, (40, 2))
    blob = rng.normal([0, 0], 0.4, (20, 2))
    noise = rng.uniform(-6, 6, (5, 2))
    X2 = np.vstack([ring, blob, noise])

    km_labels, km_centers, km_inertia = kmeans(X2, 2)
    db_labels = dbscan(X2, eps=1.5, min_pts=4)

    print("\n=== K-Means vs DBSCAN（环形+球形混合数据）===")
    print(f"K-Means (k=2) inertia: {km_inertia:.2f}（球形假设失效，环形簇被强行切开）")
    print(f"DBSCAN 找到的簇数（不含噪声）: {len(set(db_labels[db_labels >= 0]))}")
    print(f"DBSCAN 识别的噪声点数: {np.sum(db_labels == -1)}（构造时真实噪声点数为5）")
```

实测输出（numpy 2.4.4）：

```
=== 肘部法则：不同K的inertia ===
  k=1: inertia=1040.80
  k=2: inertia=395.63
  k=3: inertia=41.17
  k=4: inertia=33.87
  k=5: inertia=28.12

=== K-Means vs DBSCAN（环形+球形混合数据）===
K-Means (k=2) inertia: 488.40（球形假设失效，环形簇被强行切开）
DBSCAN 找到的簇数（不含噪声）: 2
DBSCAN 识别的噪声点数: 1（构造时真实噪声点数为5）
```

肘部法则的结果符合预期：inertia 从 `k=1` 到 `k=3` 大幅下降（1040.80 → 395.63 → 41.17），在真实簇数 `K=3` 之后下降速度明显放缓（`k=3→4` 仅降了 7.3，`k=4→5` 仅降了 5.75），肘部拐点清晰地出现在 `K=3`，与构造数据的 3 个高斯簇一致。第二个实验体现了 K-Means 与 DBSCAN 的本质差异：环形簇非凸，K-Means 无法用单个中心点正确描述它（环上的点到任何中心的距离本质相同，只能把环强行切给不同簇，inertia 高达 488.40）；DBSCAN 不依赖形状假设，仅凭密度可达性正确识别出 2 个簇（环形簇和中心球形簇），并把 1 个明显离群的点判定为噪声（5 个随机噪声点里有 4 个恰好落在环或球附近被吸收为边界点，这是密度聚类在噪声点邻近真实簇时的正常现象）。

## 9. 小结

| 算法 | 核心思路 | 需要预设 | 局限 |
| --- | --- | --- | --- |
| K-Means | 最小化簇内平方和，EM式硬分配 | 簇数K | 假设球形、密度均匀 |
| K-Means++ | 更聪明的初始中心选择 | 簇数K | 只优化初始化，不改假设 |
| DBSCAN | 密度可达性，自动识别噪声 | eps, min_pts | 密度差异大的数据效果打折扣 |
| 层次聚类 | 自底向上合并，linkage决定形状偏好 | 目标簇数（切树高度） | 计算复杂度随样本数增长快 |
| GMM | 高斯混合，软分配 | 簇数K | 参数多，可表达椭圆簇 |
