# 集成学习：Bagging、Boosting 与随机森林

> Author: Walter Wang

> **读完你能回答的 3 个问题**
>
> 1. Bagging 和 Boosting 分别通过什么机制降低误差，它们分别更擅长降低方差还是偏差？
> 2. 随机森林在 Bagging 之上多做了什么，这个改动解决了什么问题？
> 3. AdaBoost 每一轮是怎么调整样本权重和弱分类器权重的？

## 1. 为什么要集成：偏差-方差视角

单个模型的预测误差可以分解成偏差（bias，模型本身的系统性偏差）、方差（variance，对训练数据扰动的敏感度）、和不可约噪声三部分（详见偏差-方差分解的完整推导）。集成学习的核心思路是：**组合多个"弱"模型，让它们的误差相互抵消，得到比任何单个模型都更好的整体表现**。两条主流路径——Bagging 主要降方差，Boosting 主要降偏差，是解决问题的两种不同哲学。

## 2. Bagging：并行训练，投票/平均降方差

Bagging（Bootstrap Aggregating）的做法：从训练集里做 `B` 次**有放回抽样（bootstrap sampling）**，每次抽出一个和原数据集大小相同的子集，在每个子集上独立训练一个模型，最终预测时把 `B` 个模型的结果做投票（分类）或平均（回归）。

### 为什么能降方差

关键在于"独立训练+平均"这个统计学操作。假设 `B` 个模型的预测是独立同分布的随机变量，每个方差为 `σ²`，它们平均值的方差是 `σ²/B`（方差随集成数量增大而下降）。现实中 `B` 个模型不是完全独立的（因为都来自同一份原始数据、用同一种算法训练），所以方差下降没有理论值那么理想，但方向是一致的——**只要各个模型的误差不完全相关，平均之后的整体方差就会比单个模型小**。

Bagging 对高方差、低偏差的模型（如未剪枝的深决策树）特别有效，因为这类模型本身"不稳定"（训练数据稍微变化，树的结构可能剧烈变化），恰好是 bootstrap 抽样带来的多样性能发挥作用的场景；对本身方差就很低的模型（如线性回归），Bagging 收益有限。

## 3. 随机森林：Bagging + 特征随机子采样

随机森林（Random Forest）在 Bagging 的基础上多做了一件事：**每棵树在每个节点做分裂时，不是考察全部特征，而是从全部特征中随机抽取一个子集（通常是 `sqrt(d)` 个，`d` 为总特征数），只在这个子集里选最优切分**。

### 为什么要多这一步

如果只做 Bagging（不做特征子采样），当数据中存在一个特别强的特征时，几乎每棵树都会在根节点选择这个特征切分，导致所有树的结构高度相似——这些树的预测误差之间的相关性会很高，而第 2 节的方差下降公式告诉我们，**相关性越高，平均之后方差下降的幅度越小**。随机森林通过强制每棵树只能看到随机的一部分特征，人为地打散了树与树之间的相关性，让集成的方差下降效果更接近理论上界。

## 4. Boosting：串行训练，加权修正降偏差

Boosting 走的是完全不同的路径：**串行地训练一系列弱模型，每一个新模型都重点关注前面模型预测错的样本**，最终把所有弱模型加权组合。这个过程逐步降低整体偏差——每一轮都在修正当前集成还没学到的模式。

### AdaBoost：样本权重与分类器权重的迭代更新

AdaBoost（Adaptive Boosting）是最早的 Boosting 算法之一，核心机制：

```
初始化：每个样本权重 w_i = 1/N（均匀）

对第 t 轮 (t = 1, ..., T)：
  1. 用当前样本权重 {w_i} 训练一个弱分类器 h_t（如决策树桩）
  2. 计算 h_t 在加权样本上的错误率 ε_t
  3. 计算这个弱分类器的权重（错误率越低，权重越大）：
       α_t = (1/2) · log( (1-ε_t) / ε_t )
  4. 更新每个样本的权重：分类错误的样本权重增大，分类正确的样本权重减小
       w_i ← w_i · exp( -α_t · y_i · h_t(x_i) )
     （y_i, h_t(x_i) ∈ {-1,+1}；预测正确时 y_i·h_t(x_i)=1，权重乘 exp(-α_t) 变小；
      预测错误时 y_i·h_t(x_i)=-1，权重乘 exp(α_t) 变大）
  5. 归一化权重使其总和为 1

最终预测：H(x) = sign( Σ_{t=1}^{T} α_t · h_t(x) )
```

直觉：**每一轮训练结束后，被当前模型分错的样本会被"放大"，逼着下一轮的弱分类器把更多注意力放在这些难样本上**；同时表现好的弱分类器（错误率低）在最终投票里获得更大的话语权（`α_t` 更大）。这种"重点关注错误样本"的机制，是 Boosting 相比 Bagging 更擅长降低偏差的直接原因——它在主动纠正模型的系统性欠拟合，而不是像 Bagging 那样被动地平均掉随机噪声。

### 现代梯度提升：残差拟合的视角

现代梯度提升方法（GBDT、XGBoost、LightGBM）用另一个等价视角理解 Boosting：**每一轮新模型不是重新加权样本，而是直接拟合当前集成预测的残差（或更一般地，损失函数的负梯度）**。第一棵树拟合原始目标，第二棵树拟合第一棵树预测的残差，第三棵树拟合前两棵树累加预测后的残差，如此迭代，每一轮都在用一个新模型去逼近"还没被解释掉的那部分信号"。这个视角把 Boosting 和梯度下降联系起来——可以把"在函数空间里做梯度下降"理解为梯度提升的本质，每一轮加入的弱模型近似于负梯度方向。

> ⚠️ 待确认：XGBoost、LightGBM 在梯度提升基础上的具体工程优化（如二阶导数信息、直方图近似分裂、按叶子生长策略等）属于更细分的实现话题，这里只给出梯度提升的通用框架，不展开具体系统的实现细节。

## 5. Bagging vs Boosting 对比

| 维度 | Bagging | Boosting |
| --- | --- | --- |
| 训练方式 | 并行，模型间互相独立 | 串行，每个模型依赖前一个的结果 |
| 主要降低 | 方差 | 偏差 |
| 基模型要求 | 高方差、低偏差（如深树） | 弱模型即可（如浅树、树桩） |
| 过拟合风险 | 较低（平均操作天然抗过拟合） | 较高（持续拟合残差可能过拟合噪声） |
| 典型代表 | 随机森林 | AdaBoost、GBDT、XGBoost、LightGBM |

## 6. 最小可运行实现：AdaBoost 与决策树桩

```python
"""
用 numpy 实现简化版 AdaBoost：
  1. 决策树桩（单层决策树）作为弱分类器
  2. AdaBoost 主循环：样本加权、弱分类器权重、样本权重更新
  3. 在一个简单二分类数据集上验证：随轮数增加，集成的训练误差下降
"""
import numpy as np


def train_stump(X, y, sample_weight):
    """
    训练一个决策树桩：枚举所有特征的所有候选阈值和方向，
    选加权错误率最小的 (特征, 阈值, 方向)。
    方向: 1 表示 "x <= thresh 预测为 +1"，-1 表示反过来。
    """
    n_samples, n_features = X.shape
    best_err, best_feat, best_thresh, best_direction = np.inf, None, None, None

    for feat in range(n_features):
        thresholds = np.unique(X[:, feat])
        for thresh in thresholds:
            for direction in [1, -1]:
                pred = np.where(X[:, feat] <= thresh, direction, -direction)
                err = np.sum(sample_weight[pred != y])
                if err < best_err:
                    best_err, best_feat = err, feat
                    best_thresh, best_direction = thresh, direction

    return best_feat, best_thresh, best_direction, best_err


def stump_predict(X, feat, thresh, direction):
    return np.where(X[:, feat] <= thresh, direction, -direction)


def adaboost_train(X, y, n_rounds=10):
    """AdaBoost 主循环，返回每一轮的 (弱分类器参数, alpha)"""
    n_samples = X.shape[0]
    sample_weight = np.ones(n_samples) / n_samples
    stumps = []

    for t in range(n_rounds):
        feat, thresh, direction, err = train_stump(X, y, sample_weight)
        err = np.clip(err, 1e-10, 1 - 1e-10)  # 避免 log(0) 或除零
        alpha = 0.5 * np.log((1 - err) / err)

        pred = stump_predict(X, feat, thresh, direction)
        sample_weight *= np.exp(-alpha * y * pred)
        sample_weight /= np.sum(sample_weight)  # 归一化

        stumps.append((feat, thresh, direction, alpha))

    return stumps


def adaboost_predict(X, stumps):
    """加权组合所有弱分类器的预测"""
    total = np.zeros(X.shape[0])
    for feat, thresh, direction, alpha in stumps:
        total += alpha * stump_predict(X, feat, thresh, direction)
    return np.sign(total)


if __name__ == "__main__":
    rng = np.random.default_rng(0)

    # 构造一个稍有重叠、非线性可分的二分类数据集（用于体现多轮弱分类器组合的价值）
    n = 100
    X0 = rng.normal([0, 0], 1.2, (n, 2))
    X1 = rng.normal([2.5, 2.5], 1.2, (n, 2))
    X = np.vstack([X0, X1])
    y = np.array([-1] * n + [1] * n)  # AdaBoost 约定标签为 {-1, +1}

    print("=== AdaBoost 训练：观察训练误差随轮数下降 ===")
    for n_rounds in [1, 3, 5, 10, 20]:
        stumps = adaboost_train(X, y, n_rounds=n_rounds)
        pred = adaboost_predict(X, stumps)
        err_rate = np.mean(pred != y)
        print(f"  轮数={n_rounds:2d}: 训练误差率={err_rate:.4f}")

    print("\n=== 查看前 3 轮学到的弱分类器 ===")
    stumps = adaboost_train(X, y, n_rounds=3)
    for i, (feat, thresh, direction, alpha) in enumerate(stumps):
        print(f"  轮{i+1}: 特征=x{feat}, 阈值={thresh:.4f}, 方向={direction:+d}, alpha={alpha:.4f}")
```

实测输出（numpy 2.4.4）：

```
=== AdaBoost 训练：观察训练误差随轮数下降 ===
  轮数= 1: 训练误差率=0.1250
  轮数= 3: 训练误差率=0.1050
  轮数= 5: 训练误差率=0.1000
  轮数=10: 训练误差率=0.0550
  轮数=20: 训练误差率=0.0450

=== 查看前 3 轮学到的弱分类器 ===
  轮1: 特征=x0, 阈值=0.9451, 方向=-1, alpha=0.9730
  轮2: 特征=x1, 阈值=1.6668, 方向=-1, alpha=0.8398
  轮3: 特征=x1, 阈值=0.6490, 方向=-1, alpha=0.4908
```

结果验证了 Boosting 逐步降低偏差的核心机制：仅用 1 轮（单个决策树桩）训练误差率是 12.5%，随着轮数增加到 20 轮，训练误差率持续下降到 4.5%——每一轮新增的弱分类器都在修正前面轮次残留的错误。第一轮选中的弱分类器权重 `alpha=0.9730` 略高于后续轮次，符合直觉：第一轮面对均匀权重的原始数据，通常能找到区分度较强的切分（错误率较低），后续轮次要处理的是被前面轮次反复加权、更难区分的样本，弱分类器的表现和权重相应下降。

## 7. 小结

| 方法 | 训练方式 | 核心机制 | 主要作用 |
| --- | --- | --- | --- |
| Bagging | 并行，bootstrap 抽样 | 独立训练+平均/投票 | 降低方差 |
| 随机森林 | 并行，样本+特征双重随机 | Bagging + 特征子采样打散树间相关性 | 降低方差，效果优于纯 Bagging |
| AdaBoost | 串行，样本重加权 | 错分样本权重增大，逼下一轮弱分类器修正 | 降低偏差 |
| 梯度提升（GBDT等） | 串行，拟合残差/负梯度 | 每轮模型拟合当前集成的欠拟合部分 | 降低偏差 |
