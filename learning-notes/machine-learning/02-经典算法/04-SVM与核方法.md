## 1. 最大间隔：SVM 的核心目标

给定线性可分的二分类数据 `{(x_i, y_i)}`，`y_i ∈ {-1, +1}`，能把两类完全分开的超平面 `w·x + b = 0` 往往不止一个。SVM 的核心思想是：**在所有能正确分类的超平面里，选一个离两类样本都最远的**，直觉是这样的边界对噪声扰动最鲁棒，泛化能力最好。

一个样本到超平面的距离是 `|w·x+b| / ||w||`。对正确分类的样本，`y_i(w·x_i+b) > 0`。定义**几何间隔（geometric margin）** 为所有样本里离超平面最近的那个距离：

```
margin = min_i  y_i(w·x_i + b) / ||w||
```

可以按比例缩放 `(w, b)` 让最近点的函数间隔 `y_i(w·x_i+b) = 1`（这不改变超平面本身，只是固定了缩放自由度），此时几何间隔就是 `1/||w||`。最大化 `1/||w||` 等价于最小化 `||w||`，等价于最小化 `(1/2)||w||^2`（平方是为了求导方便）。于是硬间隔 SVM 的原始问题是：

```
min_{w,b}  (1/2)||w||^2
s.t.  y_i(w·x_i + b) ≥ 1,  i = 1, ..., n
```

这是一个带线性约束的凸二次规划问题。

## 2. 软间隔与松弛变量：容忍少量违反约束

硬间隔假设数据严格线性可分，现实数据几乎不满足——可能有噪声点、离群点导致完全线性可分的边界不存在，或者存在但对离群点过于敏感。**软间隔（soft margin）** 引入松弛变量 `ξ_i ≥ 0`，允许部分样本违反间隔约束：

```
min_{w,b,ξ}  (1/2)||w||^2 + C · Σ_{i=1}^{n} ξ_i
s.t.  y_i(w·x_i + b) ≥ 1 - ξ_i,   ξ_i ≥ 0
```

`ξ_i` 衡量样本 `i` 违反间隔约束的程度：`ξ_i = 0` 表示样本满足原始的硬间隔约束；`0 < ξ_i < 1` 表示样本在间隔内但仍分类正确；`ξ_i > 1` 表示样本被误分类。**超参数 `C`** 控制"最大化间隔"和"容忍误分类"之间的权衡：`C` 越大，对误分类的惩罚越重，边界越贴近训练数据（可能过拟合）；`C` 越小，边界越宽松，容忍更多违反约束的点（可能欠拟合）。`C → ∞` 时软间隔退化为硬间隔。

## 3. 拉格朗日对偶与 KKT 条件

直接求解带约束的原始问题不方便，SVM 通常转化为**拉格朗日对偶问题**求解。引入拉格朗日乘子 `α_i ≥ 0`（对应每个约束），拉格朗日函数是：

```
L(w,b,α) = (1/2)||w||^2 - Σ_i α_i [y_i(w·x_i+b) - 1]
```

对 `w, b` 求偏导并令其为 0，代回原式消去 `w, b`，得到只含 `α` 的对偶问题：

```
max_α  Σ_i α_i - (1/2) Σ_i Σ_j α_i α_j y_i y_j (x_i·x_j)
s.t.  α_i ≥ 0,   Σ_i α_i y_i = 0
```

这是对偶问题的关键价值所在：**目标函数只依赖样本间的内积 `x_i·x_j`，不显式依赖 `w`**，这正是核技巧能够生效的前提（第 5 节展开）。

求解出 `α` 后，原问题的最优解满足**KKT 条件**，其中最重要的一条是**互补松弛条件（complementary slackness）**：

```
α_i · [y_i(w·x_i+b) - 1] = 0
```

这意味着对每个样本 `i`，只有两种可能：
- `α_i = 0`：此时约束 `y_i(w·x_i+b) ≥ 1` 可以严格大于 1（点在间隔边界外），这个点对最终边界**没有贡献**。
- `α_i > 0`：此时必须有 `y_i(w·x_i+b) = 1`（软间隔下是 `≤1`），点恰好落在间隔边界上（或边界内/误分类），这个点才是**支持向量（support vector）**。

## 4. 为什么只有少数支持向量起作用

由 KKT 互补松弛条件可知，最终的权重 `w = Σ_i α_i y_i x_i` 这个求和只在 `α_i > 0` 的项上非零——而 `α_i > 0` 只发生在离超平面很近（间隔边界上或违反间隔约束）的少数点上。**绝大多数"看起来很安全、离边界很远"的点，其对偶变量 `α_i` 恰好被优化到 0**，对最终边界的位置和方向完全没有贡献。

这个性质带来两个实际好处：一是模型的存储和预测只需要保留支持向量（通常远少于全部训练样本）；二是决策边界对"远处的点"天然鲁棒——新增或删除一个远离边界、分类正确的样本，不会改变已训练好的边界。

## 5. 核技巧：不显式计算高维映射

如果数据在原始空间线性不可分，一个常见思路是把数据映射到更高维空间 `φ(x)`，使其在高维空间线性可分。直接计算 `φ(x)` 往往代价很高（维度可能是无穷维）。但注意到第 3 节的对偶问题**只需要样本对的内积** `x_i · x_j`，如果能找到一个函数 `K(x_i, x_j) = φ(x_i) · φ(x_j)`，就可以**完全不计算 `φ(x)` 本身，只计算 `K(x_i,x_j)` 这个标量**，直接代入对偶问题求解——这就是核技巧（kernel trick）。

一个函数能作为核函数的充要条件（Mercer 定理）是它对应的核矩阵（Gram matrix）必须是**对称半正定**的。满足这个条件就保证存在某个（可能是无穷维的）映射 `φ`，使 `K(x_i,x_j)` 恰好是该映射下的内积——即使这个 `φ` 从未被显式构造出来。

## 6. 常用核函数对比

```
线性核:       K(x, z) = x · z
多项式核:     K(x, z) = (x · z + c)^d
RBF/高斯核:   K(x, z) = exp(-γ ||x - z||^2)
Sigmoid 核:   K(x, z) = tanh(a · x·z + c)
```

- **线性核**：等价于不做任何映射，适合特征已经足够丰富、样本数远小于特征数的场景（如文本 TF-IDF 特征）。
- **多项式核**：隐式映射到包含所有阶数 ≤ `d` 的特征交叉项的空间，`d` 越大表达能力越强，也越容易过拟合。
- **RBF 核**：隐式映射到无穷维空间，是最常用的非线性核，`γ` 控制"影响范围"——`γ` 越大，单个样本的影响范围越窄，决策边界越复杂（容易过拟合）。
- **Sigmoid 核**：形式上类似两层神经网络的激活函数，实践中较少使用，且并非在所有参数下都满足半正定条件。

选择核函数本质上是在选择"你认为数据在什么样的映射下会变得线性可分"这个归纳偏置，没有先验知识时 RBF 核是较稳健的默认选择。

## 7. Hinge Loss 视角：SVM 也是一种正则化的经验风险最小化

把软间隔 SVM 的约束优化问题消去 `ξ_i`（用 `ξ_i = max(0, 1-y_i(w·x_i+b))` 代入），可以还原成一个无约束的正则化经验风险最小化问题：

```
min_{w,b}  Σ_i max(0, 1 - y_i(w·x_i+b)) + λ ||w||^2

其中 max(0, 1 - y·f(x)) 就是 Hinge Loss
```

Hinge Loss 的形状是：当样本被正确分类且函数间隔 `y·f(x) ≥ 1` 时损失为 0（不再有任何惩罚，这正是"支持向量之外的点不起作用"的另一个视角）；当函数间隔小于 1 时损失线性增长。这个视角把 SVM 直接纳入了[学习范式与泛化](../01-机器学习基础/01-学习范式与泛化.md)里结构风险最小化的框架——`||w||^2` 就是复杂度惩罚项。

## 8. 与逻辑回归的关系

逻辑回归优化的是**对数损失（log loss）**：`log(1 + exp(-y·f(x)))`，SVM 优化的是 Hinge Loss，两者形状相似（都是 `y·f(x)` 的单调递减凸函数，且在 `y·f(x)=1` 附近的走势接近），这也是为什么两者在很多任务上表现相近。关键区别：

- **损失为 0 的区域**：Hinge Loss 在 `y·f(x)≥1` 时损失严格为 0，对数损失永远大于 0（只是趋近于 0）——这导致 SVM 的解只依赖支持向量，逻辑回归的解依赖全部样本。
- **输出形式**：逻辑回归直接输出校准过的概率 `P(y=1|x)`；SVM 原始输出只是一个到超平面的距离，没有概率意义（需要额外的校准方法才能转成概率）。
- **对核方法的支持**：SVM 通过对偶问题天然支持核技巧；逻辑回归也可以核化，但更常见的做法是直接在原始特征空间使用（配合显式的非线性特征或神经网络）。

## 9. 最小可运行实现：手写软间隔线性 SVM 并识别支持向量

```python
"""
手写一个简化版软间隔线性 SVM：
  1. 用（次）梯度下降直接优化 Hinge Loss + L2 正则的原始目标，
     不显式求解对偶 QP（对偶 QP 求解器超出 numpy-only 的合理范围）。
  2. 在线性可分数据上验证：找到最大间隔边界，并识别出支持向量
     （函数间隔恰好等于 1 附近的点，对应 KKT 条件里 alpha_i > 0 的点）。
"""
import numpy as np

rng = np.random.default_rng(0)


def train_linear_svm(X, y, C=1.0, lr=0.01, epochs=3000):
    """原始目标：min_w,b (1/2)||w||^2 + C * Σ max(0, 1 - y_i(w·x_i+b))"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0

    for _ in range(epochs):
        margins = y * (X @ w + b)
        mask = margins < 1  # 只有违反间隔约束的点才贡献 hinge loss 的梯度
        grad_w = w - C * (y[mask] @ X[mask]) if mask.any() else w.copy()
        grad_b = -C * y[mask].sum() if mask.any() else 0.0
        w -= lr * grad_w
        b -= lr * grad_b

    return w, b


def decision_function(X, w, b):
    return X @ w + b


if __name__ == "__main__":
    n_per_class = 30
    X0 = rng.normal([-2, -2], 0.6, (n_per_class, 2))
    X1 = rng.normal([2, 2], 0.6, (n_per_class, 2))
    X = np.vstack([X0, X1])
    y = np.array([-1] * n_per_class + [1] * n_per_class)

    w, b = train_linear_svm(X, y, C=1.0, lr=0.01, epochs=3000)
    margins = y * decision_function(X, w, b)

    print("=== 训练结果 ===")
    print(f"权重向量 w = [{w[0]:.4f}, {w[1]:.4f}], 偏置 b = {b:.4f}")
    print(f"||w|| = {np.linalg.norm(w):.4f}, 几何间隔 2/||w|| = {2 / np.linalg.norm(w):.4f}")

    acc = np.mean(np.sign(decision_function(X, w, b)) == y)
    print(f"训练集准确率: {acc:.4f}")

    sv_mask = margins <= 1.05  # 函数间隔接近 1 的点视为支持向量
    print(f"支持向量数量: {sv_mask.sum()} / {len(y)}")
    print(f"支持向量的函数间隔: {np.sort(margins[sv_mask])}")
    print(f"非支持向量的最小函数间隔: {margins[~sv_mask].min():.4f}")
```

实测输出（numpy 2.4.4）：

```
=== 训练结果 ===
权重向量 w = [0.5002, 0.4287], 偏置 b = -0.0800
||w|| = 0.6588, 几何间隔 2/||w|| = 3.0359
训练集准确率: 1.0000
支持向量数量: 2 / 60
支持向量的函数间隔: [0.99601605 1.01479183]
非支持向量的最小函数间隔: 1.0588
```

结果印证了第 4 节的结论：60 个训练样本里，只有 2 个点的函数间隔落在 1 附近（0.996 和 1.015），是真正意义上的支持向量；剩下的 58 个点函数间隔都大于 1.05（最小也有 1.0588），这些点即使被删除也不会改变已经学出的边界——决策边界完全由这 2 个支持向量决定，与第 4 节"绝大多数点的 `α_i` 被优化到 0"的理论预期一致。

## 10. 小结

| 概念 | 核心含义 |
| --- | --- |
| 硬间隔 | 假设完全线性可分，最大化 `1/‖w‖` |
| 软间隔 + 松弛变量 | 允许部分违反约束，`C` 权衡间隔宽度与误分类容忍度 |
| 拉格朗日对偶 | 目标只依赖样本内积，为核技巧铺路 |
| KKT 互补松弛 | 只有间隔边界上的点 `α_i>0`，即支持向量 |
| 核技巧 | 用 `K(x,z)=φ(x)·φ(z)` 避开显式高维映射 |
| Hinge Loss | SVM 的无约束等价形式，属于结构风险最小化 |
