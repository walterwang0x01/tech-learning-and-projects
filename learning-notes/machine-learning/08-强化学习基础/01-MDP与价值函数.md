## 1. MDP 五元组与马尔可夫性假设

**马尔可夫决策过程（Markov Decision Process, MDP）** 是强化学习问题的标准数学描述，由五元组定义：

```
MDP = (S, A, P, R, γ)

S: 状态空间（所有可能的状态）
A: 动作空间（所有可能的动作）
P(s'|s,a): 状态转移概率，在状态 s 执行动作 a 后转移到 s' 的概率
R(s,a): 奖励函数，在状态 s 执行动作 a 获得的即时奖励
γ: 折扣因子，γ∈[0,1]
```

**马尔可夫性（Markov property）** 假设下一状态只依赖当前状态和当前动作，与更早的历史无关：

```
P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ..., s_0, a_0) = P(s_{t+1} | s_t, a_t)
```

这个假设的意义是：**当前状态 `s_t` 已经包含了做决策所需的全部信息**，不需要记住完整历史。如果一个真实问题的状态定义不满足这个性质（比如只用当前位置无法预测下一步，还需要知道之前走过的路径），通常可以通过扩充状态定义（把必要的历史信息也编码进状态）让问题重新满足马尔可夫性。

## 2. 回报与折扣因子

智能体的目标不是最大化单步奖励，而是最大化长期累积的**回报（return）**：

```
G_t = R_t + γ·R_{t+1} + γ²·R_{t+2} + ... = Σ_{k=0}^{∞} γ^k · R_{t+k}
```

折扣因子 `γ` 的作用有两个：一是数学上保证无限长序列的回报是有限值（`γ<1` 时几何级数收敛，即使每步奖励有界，累加和也不会发散）；二是体现"即时奖励比未来奖励更有价值"的偏好——`γ` 越接近 0，智能体越短视（只看重眼前奖励）；`γ` 越接近 1，越有远见（愿意为长期收益忍受短期损失）。

## 3. 状态价值函数与动作价值函数

**状态价值函数 `V^π(s)`**：在策略 `π` 下，从状态 `s` 出发能获得的期望回报：

```
V^π(s) = E_π[G_t | S_t = s]
```

**动作价值函数 `Q^π(s,a)`**：在策略 `π` 下，从状态 `s` 执行动作 `a` 后能获得的期望回报：

```
Q^π(s,a) = E_π[G_t | S_t = s, A_t = a]
```

两者的关系：`V^π(s)` 是对 `Q^π(s,a)` 按策略 `π` 选动作的概率加权求和；反过来 `Q^π(s,a)` 也可以写成即时奖励加上下一状态的价值。这两个函数是策略梯度篇 Actor-Critic 结构里 Critic 部分要估计的核心对象。

## 4. 贝尔曼方程与贝尔曼最优方程

**贝尔曼方程（评估某个给定策略 `π`）** 把价值函数写成递归形式：

```
V^π(s) = Σ_a π(a|s) · [ R(s,a) + γ · Σ_{s'} P(s'|s,a) · V^π(s') ]
```

直觉：当前状态的价值 = 即时奖励的期望 + 折扣后下一状态价值的期望。这是一个关于 `V^π` 的线性方程组，理论上可以直接求解，但状态数一多，直接求解代价很高。

**贝尔曼最优方程**描述的是**最优价值函数** `V*(s) = max_π V^π(s)`——不再对动作做期望（按策略的概率分布加权），而是直接取让价值最大的那个动作：

```
V*(s) = max_a [ R(s,a) + γ · Σ_{s'} P(s'|s,a) · V*(s') ]
```

这个方程不再是线性的（因为有 `max` 操作），但它的解是唯一的——这是价值迭代算法能收敛到唯一最优解的理论基础。

## 5. 策略评估与策略提升

**策略评估（policy evaluation）**：给定一个固定策略 `π`，反复应用第 4 节的贝尔曼方程（评估版本）更新 `V(s)`，直到收敛，得到该策略下的真实价值函数 `V^π`。

**策略提升（policy improvement）**：有了 `V^π` 之后，对每个状态贪心地选择让 `Q^π(s,a)` 最大的动作，构造一个新策略 `π'`：

```
π'(s) = argmax_a [ R(s,a) + γ · Σ_{s'} P(s'|s,a) · V^π(s') ]
```

可以证明 `π'` 不会比 `π` 差（策略提升定理）。交替执行"策略评估→策略提升→策略评估→..."，策略会单调改善，最终收敛到最优策略——这就是**策略迭代（policy iteration）** 算法。

## 6. 价值迭代与策略迭代

**价值迭代（value iteration）** 不显式维护策略，而是直接对贝尔曼最优方程做不动点迭代：

```
V_{k+1}(s) = max_a [ R(s,a) + γ · Σ_{s'} P(s'|s,a) · V_k(s') ]
```

反复迭代直到 `V` 收敛，再从收敛后的 `V*` 中提取一次贪心策略即为最优策略。

策略迭代和价值迭代的本质区别：**策略迭代每次策略提升前都要把当前策略的价值函数评估到（近似）收敛**（内层循环跑很多步），而价值迭代把"评估"和"提升"合并成一步——每次只做一次贝尔曼最优更新（相当于把策略评估只跑一步就直接提升）。策略迭代通常每轮迭代的计算量更大，但迭代轮数（外层策略更新的次数）更少；价值迭代每轮计算量小，但需要更多轮才能收敛。两者最终都收敛到同一个最优价值函数和最优策略。

## 7. 探索与利用的权衡

价值迭代、策略迭代依赖**已知的** `P` 和 `R`（这类问题称为已知模型的**规划**问题）。但强化学习真正要解决的通常是模型未知的场景——智能体需要通过与环境交互来估计价值函数，这就带来了**探索与利用（exploration vs exploitation）** 的权衡：**利用**指按当前已知的最优估计选动作（保证短期收益不差），**探索**指尝试当前看起来不是最优、但还没被充分尝试过的动作（可能发现更好的策略，但短期可能损失收益）。纯粹利用容易困在局部最优（因为估计不准的动作永远没机会被重新评估），纯粹探索又浪费了已经学到的知识——这个权衡贯穿几乎所有基于交互采样的强化学习算法，策略梯度篇的方法本质上也要处理这个问题（通过策略的随机性天然引入探索）。

## 8. 最小可运行实现：价值迭代求解网格世界

```python
"""
用价值迭代（value iteration）求解一个 4x4 网格世界的最优价值函数和策略。
网格世界：(0,0) 起点区域，(3,3) 是终点（奖励+1），(1,1) 是陷阱（奖励-1），
其余格子每走一步奖励-0.02（鼓励尽快到达终点），撞墙则停在原地不动。
验证贝尔曼最优方程的不动点性质：多次迭代后价值函数收敛。
"""
import numpy as np

GRID_SIZE = 4
GOAL = (3, 3)
TRAP = (1, 1)
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上下左右
ACTION_NAMES = ["上", "下", "左", "右"]
GAMMA = 0.9  # 折扣因子
STEP_REWARD = -0.02


def is_terminal(state):
    return state == GOAL or state == TRAP


def step(state, action):
    """执行动作，返回 (下一状态, 奖励)；撞墙则停在原地"""
    if is_terminal(state):
        return state, 0.0
    r, c = state
    dr, dc = action
    nr, nc = r + dr, c + dc
    if nr < 0 or nr >= GRID_SIZE or nc < 0 or nc >= GRID_SIZE:
        nr, nc = r, c  # 撞墙，停在原地
    next_state = (nr, nc)
    if next_state == GOAL:
        return next_state, 1.0
    if next_state == TRAP:
        return next_state, -1.0
    return next_state, STEP_REWARD


def value_iteration(theta=1e-6, max_iter=1000):
    """价值迭代：V(s) <- max_a [ R(s,a) + gamma * V(s') ]，直接迭代贝尔曼最优方程"""
    V = np.zeros((GRID_SIZE, GRID_SIZE))
    history = []
    for it in range(max_iter):
        V_new = np.copy(V)
        delta = 0.0
        for r in range(GRID_SIZE):
            for c in range(GRID_SIZE):
                state = (r, c)
                if is_terminal(state):
                    continue
                action_values = []
                for action in ACTIONS:
                    next_state, reward = step(state, action)
                    action_values.append(reward + GAMMA * V[next_state])
                V_new[r, c] = max(action_values)
                delta = max(delta, abs(V_new[r, c] - V[r, c]))
        V = V_new
        history.append(delta)
        if delta < theta:
            break
    return V, it + 1, history


def extract_policy(V):
    """基于收敛后的 V，做一次策略提升，得到贪心最优策略"""
    policy = {}
    for r in range(GRID_SIZE):
        for c in range(GRID_SIZE):
            state = (r, c)
            if is_terminal(state):
                policy[state] = "终"
                continue
            action_values = []
            for action in ACTIONS:
                next_state, reward = step(state, action)
                action_values.append(reward + GAMMA * V[next_state])
            best_action = np.argmax(action_values)
            policy[state] = ACTION_NAMES[best_action]
    return policy


if __name__ == "__main__":
    V, n_iters, history = value_iteration()

    print(f"价值迭代收敛所需轮数: {n_iters}")
    print(f"每轮 delta（价值函数最大变化量）: {[f'{d:.4f}' for d in history]}")

    print("\n=== 收敛后的最优价值函数 V*(s) ===")
    for r in range(GRID_SIZE):
        row_str = "  ".join(f"{V[r, c]:6.3f}" for c in range(GRID_SIZE))
        print(f"  {row_str}")

    policy = extract_policy(V)
    print("\n=== 基于 V* 提取的贪心最优策略 ===")
    for r in range(GRID_SIZE):
        row_str = "  ".join(f"{policy[(r, c)]:^4}" for c in range(GRID_SIZE))
        print(f"  {row_str}")

    print(f"\n终点 {GOAL} 的价值: {V[GOAL]:.4f}（终止状态无未来奖励，恒为0）")
    print(f"陷阱 {TRAP} 的价值: {V[TRAP]:.4f}（终止状态无未来奖励，恒为0）")
    print(f"起点 (0,0) 的价值: {V[(0, 0)]:.4f}（越接近终点、越远离陷阱，价值越高）")
```

实测输出（numpy 2.4.4）：

```
价值迭代收敛所需轮数: 7
每轮 delta（价值函数最大变化量）: ['1.0000', '0.9000', '0.8100', '0.7290', '0.6561', '0.5905', '0.0000']

=== 收敛后的最优价值函数 V*(s) ===
   0.509   0.587   0.675   0.772
   0.587   0.000   0.772   0.880
   0.675   0.772   0.880   1.000
   0.772   0.880   1.000   0.000

=== 基于 V* 提取的贪心最优策略 ===
   下     右     下     下  
   下     终     下     下  
   下     下     下     下  
   右     右     右     终  

终点 (3, 3) 的价值: 0.0000（终止状态无未来奖励，恒为0）
陷阱 (1, 1) 的价值: 0.0000（终止状态无未来奖励，恒为0）
起点 (0,0) 的价值: 0.5086（越接近终点、越远离陷阱，价值越高）
```

价值迭代 7 轮收敛，delta 序列呈现精确的几何衰减（每轮约乘以 `γ=0.9`：`1.0→0.9→0.81→0.729...`），最后一轮 delta 精确为 0——说明这个确定性小规模 MDP 的价值函数已经完全稳定到不动点，这正是第 4 节"贝尔曼最优方程的解唯一"的直接体现。收敛后的价值函数呈现出符合直觉的空间分布：越靠近终点 `(3,3)` 价值越高（如 `(2,3)=0.880`、`(3,2)=1.000`，注意 `(3,2)` 走一步右就到终点，价值几乎等于奖励本身），越靠近陷阱 `(1,1)` 价值越低（如 `(0,1)=0.587` 明显低于同等距离终点的格子）。提取出的贪心策略也验证了这一点：几乎所有格子的最优动作都是"绕开陷阱、朝终点方向走"，例如 `(0,1)` 选择向右而非向下（向下会更靠近陷阱）。

## 9. 小结

| 概念 | 一句话总结 |
| --- | --- |
| MDP 五元组 | (S,A,P,R,γ)，马尔可夫性假设下一状态只依赖当前状态和动作 |
| 回报 G_t | 折扣累积奖励，γ 控制远视/短视程度 |
| V^π(s) / Q^π(s,a) | 状态价值 / 动作价值，两者可相互表示 |
| 贝尔曼方程 | 价值函数的递归定义，评估版本按策略期望，最优版本取 max |
| 策略评估/提升 | 交替评估当前策略、贪心提升策略，单调改善直到最优 |
| 价值迭代 | 直接迭代贝尔曼最优方程，评估与提升合并成一步 |
| 策略迭代 | 每轮把策略评估跑到收敛再提升，轮数少但每轮更贵 |
| 探索与利用 | 模型未知时的核心权衡，贯穿所有交互式强化学习算法 |
