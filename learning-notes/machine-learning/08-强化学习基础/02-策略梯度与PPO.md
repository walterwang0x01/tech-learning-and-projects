## 1. 为何需要策略梯度

上一篇的价值迭代、策略迭代都依赖对每个状态枚举所有动作、取 `argmax` 决策。这在两类场景下行不通：**连续动作空间**（如机器人关节角度是连续实数，无法枚举）；以及**需要随机策略**的场景（有些任务的最优策略本身该是随机的，比如石头剪刀布，确定性策略会被对手针对）。

**策略梯度（policy gradient）** 方法不再间接通过价值函数推导动作，而是直接对策略参数化 `π_θ(a|s)`（`θ` 是可学习参数），通过梯度上升直接优化策略参数，让期望回报最大化。这样动作空间是否连续、策略是否随机都不再是障碍——只要 `π_θ` 能定义出一个可采样、可求导的动作分布即可。

## 2. 策略梯度定理推导

目标是最大化策略的期望回报 `J(θ) = E_{τ~π_θ}[G(τ)]`（`τ` 表示一条完整的轨迹）。策略梯度定理给出了 `J(θ)` 关于 `θ` 的梯度的一个可采样估计形式：

```
∇_θ J(θ) = E_{τ~π_θ} [ Σ_t ∇_θ log π_θ(a_t|s_t) · G_t ]
```

推导核心是利用 `∇_θ π_θ = π_θ · ∇_θ log π_θ`（对数导数技巧），把"对轨迹概率求梯度"转化成"对轨迹概率加权求期望"——这样梯度可以用采样轨迹的均值近似估计，不需要知道环境的转移概率 `P(s'|s,a)`（这正是策略梯度相比价值迭代的关键优势：**不需要已知模型**）。直觉上，这个梯度会增大"导致高回报 `G_t`"的动作被选中的概率对数，减小"导致低回报"的动作被选中的概率。

## 3. REINFORCE 与方差问题

**REINFORCE** 是策略梯度定理最直接的实现：采样若干条完整轨迹，用每条轨迹实际获得的回报 `G_t` 直接代入上面的公式做梯度上升。

问题在于 `G_t` 是对未来所有奖励的累加，采样出来的方差非常大——同一个状态动作对，不同轨迹后续的随机性可能导致 `G_t` 波动剧烈，梯度估计噪声很大，训练不稳定、收敛慢。

## 4. 基线与优势函数

缓解方差的核心手段是引入**基线（baseline）** `b(s)`，把梯度公式改成：

```
∇_θ J(θ) = E [ Σ_t ∇_θ log π_θ(a_t|s_t) · (G_t - b(s_t)) ]
```

只要 `b(s)` 不依赖动作 `a_t`（只依赖状态），这个替换在数学上不改变梯度的期望值（减去一个只与状态相关的量，期望不变），但可以显著降低方差——直觉是：与其看动作带来的绝对回报，更该看它比"这个状态下平均水平"好多少。

最常用的基线选择是状态价值函数 `V(s_t)`，这样 `G_t - V(s_t)` 就是**优势函数（advantage function）** `A(s_t, a_t)` 的一种估计——衡量"在状态 `s_t` 选动作 `a_t` 比该状态下的平均水平好多少"。

## 5. Actor-Critic 结构

如果优势函数里的 `V(s)` 不是直接用采样回报估计，而是**用一个独立的神经网络单独学习**（通过上一篇的贝尔曼方程做自举更新），就得到了 **Actor-Critic** 结构：

- **Actor**：策略网络 `π_θ(a|s)`，负责根据 Critic 提供的优势信号更新动作概率。
- **Critic**：价值网络 `V_φ(s)`，负责估计状态价值，为 Actor 提供比原始回报方差更小的优势信号。

两个网络协同训练：Critic 让优势估计更稳定（用价值函数自举，不需要等一条轨迹完全结束才能计算），Actor 用这个更稳定的信号做策略更新——这是目前主流策略梯度算法（包括 PPO）的通用框架。

## 6. TRPO 的信任域思想

策略梯度直接用梯度上升更新 `θ`，但一个隐患是：**如果单步更新步长太大，可能让新策略比旧策略明显变差，而这种变差在高维参数空间里很难通过学习率简单控制**（参数空间的微小变化，可能导致策略分布产生剧烈变化）。

**TRPO（Trust Region Policy Optimization）** 的想法是限制每次更新前后新旧策略之间的**KL 散度**（衡量两个概率分布差异的指标）不超过一个阈值，把这个约束显式写进优化问题：

```
maximize E[ π_θ(a|s)/π_θ_old(a|s) · A(s,a) ]
subject to  KL(π_θ_old || π_θ) ≤ δ
```

这样即使某一步的优势估计信号很强、梯度很大，策略也被约束在旧策略附近的一个"信任域"内更新，避免单步更新过猛导致性能崩溃。代价是这个带约束的优化问题求解复杂（需要用共轭梯度法近似求解二阶信息），工程实现开销较大。

## 7. PPO 的剪切目标为何有效

**PPO（Proximal Policy Optimization）** 想要达到 TRPO 类似的效果（限制单步更新幅度），但用一个更简单、无需二阶优化的方式实现。核心是对重要性采样比值 `r_t = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)` 做**剪切（clip）**：

```
L^CLIP(θ) = E[ min( r_t · A_t,  clip(r_t, 1-ε, 1+ε) · A_t ) ]
```

拆开看两种情况（`ε` 是一个小的超参数，如 0.2）：

- **优势 `A_t > 0`（这个动作比平均更好，该被鼓励）**：如果 `r_t` 已经超过 `1+ε`（新策略已经比旧策略更倾向于选这个动作，且倾向程度超出阈值），`min` 会选中被剪切后的常数项 `(1+ε)·A_t`，这一项对 `r_t` 的梯度是 0——**相当于告诉优化器"已经提升得足够多了，不要再继续提升这个动作的概率"**，阻止了过度自信的更新。
- **优势 `A_t < 0`（这个动作比平均更差，该被抑制）**：如果 `r_t` 已经低于 `1-ε`（新策略已经比旧策略明显减少了选这个动作的概率），同理梯度归零，阻止过度压低。

**关键洞察**：剪切只在"更新方向本来就正确、但幅度已经超出安全范围"时才生效，把梯度直接置零；如果 `r_t` 还在 `[1-ε, 1+ε]` 范围内，或者更新方向本身是"往错误方向走"（比如 `A_t>0` 但 `r_t<1`，说明新策略反而降低了好动作的概率），梯度依然正常传递，会继续朝着提升目标的方向更新。这种"只限制过度更新、不限制正常更新"的不对称设计，用一个简单的 `min-clip` 运算就近似达到了 TRPO 信任域约束的效果，且不需要计算二阶导数或求解带约束优化问题——这是 PPO 相比 TRPO 工程上大幅简化、成为后续包括 RLHF 在内的强化学习微调标准选择的核心原因（[RLHF全链路](../../llm/04-微调与对齐/03-RLHF全链路.md)中的策略更新正是基于 PPO 的剪切目标）。

## 8. GAE 优势估计

优势函数的估计存在偏差-方差的权衡：只用单步 TD 误差 `r_t + γV(s_{t+1}) - V(s_t)` 方差小但有偏差（依赖 `V` 估计的准确性）；用完整轨迹回报 `G_t - V(s_t)` 无偏但方差大（继承了 REINFORCE 的问题）。**GAE（Generalized Advantage Estimation）** 用一个参数 `λ` 在两者之间插值，把不同步数的 TD 误差按指数衰减权重加权平均：

```
A^GAE_t = Σ_{k=0}^{∞} (γλ)^k · δ_{t+k}，其中 δ_t = r_t + γV(s_{t+1}) - V(s_t)
```

`λ=0` 时退化为单步 TD（低方差高偏差），`λ=1` 时退化为完整轨迹估计（高方差低偏差），中间值提供了一个可调节的折中——这也是 PPO 实践中通常搭配使用的优势估计方式。

## 9. 最小可运行实现：PPO 剪切目标的梯度行为

```python
"""
实现 PPO 的剪切目标(clipped surrogate objective)，展示不同"新旧策略概率比" r
和不同优势值 A 下，剪切前后目标函数值与梯度(对 r 的导数)的行为差异。
核心验证：当优势为正且 r 超过 1+epsilon，或优势为负且 r 低于 1-epsilon 时，
剪切让目标函数变成常数，对 r 的梯度归零——这正是 PPO 限制单步更新幅度的机制。
"""
import numpy as np


def surrogate_unclipped(r, A):
    """未剪切的重要性采样目标：r * A"""
    return r * A


def surrogate_clipped(r, A, epsilon=0.2):
    """PPO 剪切目标：min(r*A, clip(r, 1-eps, 1+eps)*A)"""
    r_clipped = np.clip(r, 1 - epsilon, 1 + epsilon)
    return np.minimum(r * A, r_clipped * A)


def grad_clipped_wrt_r(r, A, epsilon=0.2):
    """对剪切目标关于 r 求导（数值近似），观察梯度何时被置零"""
    h = 1e-6
    f_plus = surrogate_clipped(r + h, A, epsilon)
    f_minus = surrogate_clipped(r - h, A, epsilon)
    return (f_plus - f_minus) / (2 * h)


if __name__ == "__main__":
    epsilon = 0.2
    r_values = np.array([0.5, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.5])

    print(f"剪切范围 epsilon={epsilon} -> r 被限制在 [{1-epsilon:.1f}, {1+epsilon:.1f}]")

    print("\n=== 优势 A > 0（动作比平均更好，应该被鼓励）时的目标值与梯度 ===")
    A_pos = 1.0
    print(f"{'r':>6} | {'未剪切 r*A':>12} | {'剪切目标':>10} | {'对r的梯度':>10}")
    for r in r_values:
        unclipped = surrogate_unclipped(r, A_pos)
        clipped = surrogate_clipped(r, A_pos, epsilon)
        grad = grad_clipped_wrt_r(r, A_pos, epsilon)
        print(f"{r:>6.2f} | {unclipped:>12.4f} | {clipped:>10.4f} | {grad:>10.4f}")

    print("\n=== 优势 A < 0（动作比平均更差，应该被抑制）时的目标值与梯度 ===")
    A_neg = -1.0
    print(f"{'r':>6} | {'未剪切 r*A':>12} | {'剪切目标':>10} | {'对r的梯度':>10}")
    for r in r_values:
        unclipped = surrogate_unclipped(r, A_neg)
        clipped = surrogate_clipped(r, A_neg, epsilon)
        grad = grad_clipped_wrt_r(r, A_neg, epsilon)
        print(f"{r:>6.2f} | {unclipped:>12.4f} | {clipped:>10.4f} | {grad:>10.4f}")

    print("\n=== 关键观察 ===")
    print(f"A>0 时，r=1.30（超过1+eps={1+epsilon:.1f}）梯度={grad_clipped_wrt_r(1.30, A_pos, epsilon):.4f}（应为0，阻止过度增大该动作概率）")
    print(f"A<0 时，r=0.70（低于1-eps={1-epsilon:.1f}）梯度={grad_clipped_wrt_r(0.70, A_neg, epsilon):.4f}（应为0，阻止过度减小该动作概率）")
    print(f"A>0 时，r=0.90（未超出范围）梯度={grad_clipped_wrt_r(0.90, A_pos, epsilon):.4f}（应等于A={A_pos}，正常更新）")
```

实测输出（numpy 2.4.4）：

## 10. 小结

| 概念 | 一句话总结 |
| --- | --- |
| 策略梯度 | 直接优化策略参数，适配连续动作/随机策略，不需要已知模型 |
| REINFORCE | 用采样回报直接做梯度上升，方差大 |
| 基线/优势函数 | 减去状态相关基线降方差，优势函数衡量"比平均好多少" |
| Actor-Critic | Actor 学策略，Critic 学价值函数辅助估计优势，稳定训练 |
| TRPO | 用 KL 散度约束限制更新幅度，效果好但求解复杂 |
| PPO 剪切目标 | 用 `min-clip` 近似信任域约束，超出安全范围时梯度归零 |
| GAE | 用 λ 在单步 TD 和完整轨迹回报间插值，权衡偏差与方差 |
