# 过拟合与偏差方差

> Author: Walter Wang

> **读完你能回答的 3 个问题**
>
> 1. 只看训练损失能不能判断模型有没有过拟合？训练-验证曲线的哪种形态分别对应欠拟合、过拟合、正常？
> 2. 偏差-方差分解里，"偏差"和"方差"分别对应模型的什么行为？为什么二者通常不能同时降低？
> 3. 双下降现象为什么会推翻"模型越复杂过拟合越严重"这个直觉？它在测试误差曲线上长什么样？

## 1. 问题：模型学得好不好，看什么

训练一个模型后，第一件事是判断它处于什么状态：

- **欠拟合（underfitting）**：模型太简单，连训练数据都拟合不好
- **过拟合（overfitting）**：模型把训练数据的噪声也记住了，训练表现很好但泛化差
- **拟合良好**：训练误差和验证误差都低，且差距不大

判断的核心工具是**训练-验证曲线（learning curve）**：随着训练轮数（或训练样本量）增加，同时画出训练集损失和验证集损失。

```
损失
 │
 │╲                                    ┌─ 验证损失（欠拟合）
 │ ╲___________________________________┘   两条线都停在高位、贴在一起
 │  ╲__________________________________    → 欠拟合：模型容量不够，加数据没用
 │
 │╲
 │ ╲___________________________________    训练损失持续下降
 │        ___________________________     验证损失先降后升，两线裂开
 │       ╱
 │      ╱   ← 验证损失回升点，此后就是过拟合
 │_____╱____________________________________________ 训练轮数
      训练损失（一直下降）
```

三种形态对应关系：

| 训练损失 | 验证损失 | 两者差距 | 诊断 |
| --- | --- | --- | --- |
| 高 | 高 | 小 | 欠拟合：模型容量不足或训练不充分 |
| 低 | 高 | 大且持续拉大 | 过拟合：模型记住了训练集的噪声 |
| 低 | 低 | 小 | 拟合良好 |

**实操判据**：验证损失出现"先降后升"的拐点，那个拐点之后的训练就是在过拟合。这也是早停（early stopping）的判据来源（见 [正则化技术](02-正则化技术.md)）。

单独看训练损失是不够的——训练损失几乎总是单调下降（只要模型没坏、学习率没炸），它反映的是模型的拟合能力而非泛化能力。**过拟合是训练损失和验证损失之间的关系，不是任何一条曲线单独的形态。**

## 2. 偏差-方差分解

### 2.1 直觉

设真实数据生成过程是 `y = f(x) + ε`，其中 `ε` 是均值为 0、方差为 `σ²` 的噪声。我们用训练集拟合出一个模型 `f̂(x)`。

因为训练集是随机抽样的，**换一批训练集，`f̂` 也会变**。所以 `f̂(x)` 本身是一个随机变量（随训练集的随机性而变化）。这个视角是理解偏差-方差分解的关键。

- **偏差（bias）**：`f̂` 的平均预测，离真实 `f(x)` 有多远——衡量模型本身的表达能力是否足够
- **方差（variance）**：`f̂` 在不同训练集下的预测，波动有多大——衡量模型对训练集随机性的敏感程度

直觉上：

- 模型太简单（比如用直线拟合曲线）→ 无论换哪批数据，`f̂` 都拟合不好同一个地方 → **高偏差、低方差**
- 模型太复杂（比如高阶多项式）→ 换一批数据，`f̂` 会剧烈变化，因为它把每批数据的噪声都学进去了 → **低偏差、高方差**

### 2.2 推导

对某个固定的测试点 `x`，测试误差的期望（对训练集的随机性取期望，记为 `E_D`）：

```
E_D[(y - f̂(x))²]
```

先把 `y = f(x) + ε` 代入，并展开：

```
E_D[(f(x) + ε - f̂(x))²]
= E_D[(f(x) - f̂(x))²] + E[ε²] + 2·E[ε]·E_D[f(x) - f̂(x)]
```

`ε` 与训练集无关、均值为 0，交叉项消失，`E[ε²] = σ²`（噪声方差）。只需继续展开第一项。记 `f̄(x) = E_D[f̂(x)]`（模型预测在所有可能训练集上的平均）：

```
E_D[(f(x) - f̂(x))²]
= E_D[(f(x) - f̄(x) + f̄(x) - f̂(x))²]
= (f(x) - f̄(x))² + E_D[(f̄(x) - f̂(x))²] + 2(f(x)-f̄(x))·E_D[f̄(x)-f̂(x)]
```

最后一项里 `E_D[f̄(x) - f̂(x)] = f̄(x) - f̄(x) = 0`，所以交叉项为 0。最终得到分解：

```
E_D[(y - f̂(x))²] = (f(x) - f̄(x))²  +  E_D[(f̂(x) - f̄(x))²]  +  σ²
                    └──── Bias² ────┘   └──────  Variance ──────┘   └ Irreducible Error ┘
```

即：

```
总误差 = 偏差² + 方差 + 不可约噪声
```

三项含义：

| 项 | 含义 | 能否通过调模型消除 |
| --- | --- | --- |
| `Bias²` | 模型平均预测与真实函数的系统性差距 | 能，加大模型容量 |
| `Variance` | 模型预测随训练集抽样的波动程度 | 能，正则化/加数据/降容量 |
| `σ²`（不可约误差） | 数据本身的噪声 | 不能，这是数据生成过程的固有属性 |

### 2.3 模型复杂度与误差的关系

```
误差
 │  ╲                                    ╱
 │   ╲                                  ╱   ← Variance（随复杂度上升）
 │    ╲                                ╱
 │     ╲                              ╱
 │      ╲____                    ____╱
 │           ╲__________________╱          ← 总误差（U 形）
 │       ╲                     ╱
 │        ╲___________________╱             ← Bias²（随复杂度下降）
 │_____________________________________________ 模型复杂度
        欠拟合区    最优点      过拟合区
```

这就是经典的**偏差-方差权衡（bias-variance tradeoff）**：模型越复杂，偏差越小（更能拟合真实函数的细节），但方差越大（对训练集噪声越敏感）。总误差呈 U 形，最优复杂度在两者的平衡点。

### 2.4 数据量的影响

增加训练数据主要压低**方差**，对偏差几乎没有帮助：

- 数据越多，单次训练学到的 `f̂` 越接近"真实规律"而非"这批数据的噪声" → 不同训练集之间的 `f̂` 差异变小 → 方差下降
- 但如果模型容量本身不足（比如用直线拟合曲线），加多少数据 `f̂` 都无法逼近真实的曲线形态 → 偏差不变

这解释了一个常见误区："模型欠拟合，那就加数据"——如果是欠拟合（高偏差），加数据没用，该做的是加大模型容量或加特征；只有过拟合（高方差）时加数据才有效。

## 3. 双下降现象（Deep Double Descent）

### 3.1 经典理论 vs 现代观察

上面的 U 形曲线是统计学习理论的经典结论，隐含假设是"模型复杂度增加，方差单调上升"。但在深度学习（以及某些经典模型的特定设置）中观察到：**当模型复杂度继续增加、越过某个临界点后，测试误差会再次下降**，形成"下降 → 上升（尖峰）→ 再下降"的双下降曲线。

```
测试误差
 │  ╲
 │   ╲                    ╱╲
 │    ╲                  ╱  ╲
 │     ╲                ╱    ╲
 │      ╲______________╱      ╲________________
 │                     ↑        ╲______________╱ ← 过参数化区，误差再次下降
 │              插值阈值（interpolation threshold）
 │              模型刚好能把训练集完全拟合到 0 误差
 │_______________________________________________ 模型复杂度 / 参数数量
   经典 U 形区间          尖峰            现代过参数化区间
```

**插值阈值（interpolation threshold）**：模型参数数量刚好等于（或刚好够）完全拟合训练集的临界点。在这个点附近，模型"勉强"插值训练数据，对训练集里的噪声极度敏感，是任意一点扰动都会引起预测剧烈变化的区域——对应经典理论里方差爆炸的尖峰。

越过这个阈值后（过参数化，参数远多于样本），模型有无穷多种方式可以完全拟合训练集，但训练过程（比如最小范数插值、SGD 的隐式偏好）倾向于选择其中"更平滑"的那个解，反而降低了方差——这是双下降现象的核心解释方向之一。

> ⚠️ 待确认：双下降现象背后完整的理论机制（为何过参数化区间训练动态会偏好低方差解）目前仍是活跃研究领域，不同文献给出的解释角度不完全一致，这里只给可复现的现象和一种直觉性解释，不代表定论。

### 3.2 为什么这对现代大模型语境重要

大模型的参数量往往远超训练样本数量（严重过参数化），如果照搬经典 U 形理论，会得出"这类模型必然严重过拟合"的错误结论。但实践中过参数化的大模型往往泛化良好——双下降现象提示：**参数数量与泛化能力的关系不是简单单调的，"越过插值阈值继续增大模型"可能是有效的，而不是在重复过拟合的老问题**。这也是"为什么不能用小模型的直觉去理解大模型的容量-泛化关系"的一个理论依据。

## 4. 最小可运行实现

### 4.1 偏差-方差分解的数值验证

用多项式回归拟合 `sin(2πx) + 噪声`，对不同阶数重复多次抽样训练集，直接算出偏差²、方差，验证它们的和确实等于总误差（减去不可约噪声的部分）。

```python
import numpy as np


def true_fn(x):
    """真实函数：不含噪声的生成过程"""
    return np.sin(2 * np.pi * x)


def make_dataset(n, noise_std, seed):
    """从真实函数加噪声采样出一批训练集"""
    r = np.random.default_rng(seed)
    x = r.uniform(0, 1, n)
    y = true_fn(x) + r.normal(0, noise_std, n)
    return x, y


def fit_poly(x, y, degree, ridge=1e-8):
    """最小二乘拟合多项式，返回系数。
    加极小岭正则只是为了防止高阶 vander 矩阵条件数过差导致数值溢出，
    不影响"高阶模型方差更大"这一结论"""
    X = np.vander(x, degree + 1, increasing=True)
    XtX = X.T @ X + ridge * np.eye(degree + 1)
    coef = np.linalg.solve(XtX, X.T @ y)
    return coef


def predict_poly(coef, x):
    degree = len(coef) - 1
    X = np.vander(x, degree + 1, increasing=True)
    return X @ coef


x_test = np.linspace(0, 1, 50)
y_true = true_fn(x_test)
noise_std = 0.3
n_train = 20
n_trials = 200  # 重复抽样 200 次训练集，模拟 E_D[·]

for degree in [1, 3, 15]:
    preds = np.zeros((n_trials, len(x_test)))
    for t in range(n_trials):
        x_tr, y_tr = make_dataset(n_train, noise_std, seed=1000 + t)
        coef = fit_poly(x_tr, y_tr, degree)
        preds[t] = predict_poly(coef, x_test)

    mean_pred = preds.mean(axis=0)                        # f̄(x)：平均预测
    bias2 = np.mean((mean_pred - y_true) ** 2)             # Bias²
    variance = np.mean(preds.var(axis=0))                  # Variance
    total_err = np.mean((preds - y_true) ** 2)              # 直接算总误差（含噪声项）

    print(f"degree={degree:2d}  bias^2={bias2:.4f}  variance={variance:.4f}  "
          f"bias^2+var={bias2+variance:.4f}  total_mse={total_err:.4f}")
```

实测输出（numpy 2.4.4）：

```
degree= 1  bias^2=0.2133  variance=0.0349  bias^2+var=0.2482  total_mse=0.2482
degree= 3  bias^2=0.0062  variance=0.0327  bias^2+var=0.0389  total_mse=0.0389
degree=15  bias^2=0.0095  variance=29.6654  bias^2+var=29.6749  total_mse=29.6749
```

现象完全符合理论：

- `degree=1`（直线拟合正弦曲线）：偏差²明显偏高（0.21），模型表达能力不够
- `degree=3`：偏差和方差都很小，是这三者中综合误差最低的
- `degree=15`：偏差²很低（几乎能拟合到任意训练集的细节），但方差极高（29.67），说明模型对训练集的随机噪声极度敏感——这就是过拟合的数值表现

同时验证了 `bias² + variance` 与直接计算的 `total_mse` 几乎完全一致（差异仅来自有限次采样的统计误差），印证了第 2.2 节的推导。

### 4.2 双下降现象的最小复现

用线性回归在"参数数量 `p` 从远小于样本数 `n` 到远大于 `n`"的区间里观察测试误差，验证插值阈值附近的误差尖峰、以及越过阈值后误差反而下降。

```python
import numpy as np


def run_double_descent(n_train=40, n_test=200, true_dim=5, noise_std=0.5, seed=0):
    """固定训练样本数 n_train，扫描特征数（参数数）p，观察测试误差走势。
    p <= n_train 时用普通最小二乘（欠定/良定交界处极小岭正则防止病态）；
    p > n_train 时训练集变成欠定方程组，用伪逆取"最小范数插值解"——
    这正是过参数化区间测试误差反而下降的关键机制"""
    rng = np.random.default_rng(seed)
    beta_true = rng.normal(0, 1, true_dim)  # 真实关系只依赖前 true_dim 个特征

    def sample(n, p, r):
        X = r.normal(0, 1, (n, p))
        k = min(true_dim, p)  # p 可能小于 true_dim，截断保证维度匹配
        y = X[:, :k] @ beta_true[:k] + r.normal(0, noise_std, n)
        return X, y

    p_list = list(range(5, 12)) + list(range(12, 20)) + list(range(20, 81, 4))
    test_errs = []

    for p in p_list:
        r = np.random.default_rng(seed * 1000 + p)
        X_tr, y_tr = sample(n_train, p, r)
        X_te, y_te = sample(n_test, p, r)

        if p <= n_train:
            # 欠参数化 / 恰好插值区：普通最小二乘
            XtX = X_tr.T @ X_tr + 1e-6 * np.eye(p)
            w = np.linalg.solve(XtX, X_tr.T @ y_tr)
        else:
            # 过参数化区：欠定方程组，伪逆给出最小范数插值解
            w = np.linalg.pinv(X_tr) @ y_tr

        pred = X_te @ w
        test_errs.append(np.mean((pred - y_te) ** 2))

    return p_list, test_errs


if __name__ == "__main__":
    p_list, errs = run_double_descent()
    print(f"{'p(参数数)':>10} {'test_mse':>10}")
    for p, e in zip(p_list, errs):
        marker = "  <- 插值阈值附近 (p≈n=40)" if 36 <= p <= 44 else ""
        print(f"{p:>10} {e:>10.3f}{marker}")
```

## 5. 小结

| 要点 | 内容 |
| --- | --- |
| 判断过拟合 | 看训练-验证损失曲线的差距，不能只看训练损失 |
| 偏差-方差分解 | `总误差 = Bias² + Variance + 不可约噪声` |
| 偏差 | 模型平均预测与真实函数的系统性差距，反映模型容量是否足够 |
| 方差 | 模型预测随训练集抽样的波动程度，反映模型对噪声的敏感度 |
| 经典权衡 | 复杂度上升 → 偏差降、方差升，总误差呈 U 形 |
| 数据量的作用 | 主要压低方差，对偏差基本无效 |
| 双下降 | 越过插值阈值后，过参数化模型的测试误差可能再次下降，打破单纯的 U 形直觉 |
