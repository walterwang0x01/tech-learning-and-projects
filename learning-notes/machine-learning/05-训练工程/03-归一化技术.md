## 1. 问题：为什么需要归一化

深层网络训练时，每一层的输入分布会随着前面层参数的更新而不断变化——这一现象曾被称为**内部协变量偏移（Internal Covariate Shift, ICS）**：前面层的参数一旦更新，后面层看到的输入分布就变了，后面层要不断"追着"变化的输入分布调整，训练变慢、不稳定。

归一化层的做法是：在网络内部插入一个步骤，强制把某个维度上的激活值拉回到均值 0、方差 1（或类似的稳定范围）附近，从而稳定每一层看到的输入分布。

> ⚠️ **关于 ICS 的争议**：BatchNorm 最初提出时用 ICS 来解释其有效性，但后续有研究对这个解释提出质疑，认为 BatchNorm 的真正效果更多来自于让损失曲面更平滑（从而允许更大的学习率），而不是字面意义上的"减少协变量偏移"。具体是哪种机制主导、或者两者如何共同作用，目前没有完全一致的定论，这里只呈现有争议这一事实，不代表这篇笔记站队某一方解释。

## 2. BatchNorm

### 2.1 原理

BatchNorm（Batch Normalization）对每个特征维度，在**当前 mini-batch 内**的所有样本上计算均值和方差，归一化后再用可学习的 `gamma`（缩放）、`beta`（平移）还原一定的表达能力：

```
训练时（对 batch 维度求统计量）：
  batch_mean = mean(x, axis=batch)
  batch_var  = var(x, axis=batch)
  x_norm = (x - batch_mean) / sqrt(batch_var + eps)
  y = gamma * x_norm + beta
```

`gamma`、`beta` 是可学习参数，让网络能自己决定要不要保留归一化前的均值方差（如果 `gamma=sqrt(var)`、`beta=mean`，相当于撤销归一化）——这保证了 BatchNorm 至少不会让网络的表达能力变差。

### 2.2 训练与推理的差异：running statistics

推理时通常是单样本或小 batch，用"当前 batch"的统计量不稳定也不合理（比如 batch_size=1 时方差恒为 0）。BatchNorm 的解决办法是**在训练过程中额外维护一份全局的滑动平均统计量**（running mean / running variance），推理时直接用这份固定统计量，不再依赖当前输入：

```
训练时每一步，用滑动平均更新全局统计量：
  running_mean = (1 - momentum) * running_mean + momentum * batch_mean
  running_var  = (1 - momentum) * running_var  + momentum * batch_var

推理时：
  x_norm = (x - running_mean) / sqrt(running_var + eps)     ← 不再计算当前输入的统计量
  y = gamma * x_norm + beta
```

这是 BatchNorm 训练与推理**行为不同**的直接原因：训练依赖 batch 内统计，推理依赖训练期间积累的全局统计。忘记切换到 eval 模式（很多框架里是 `model.eval()`）会导致推理时仍使用当前小 batch 的统计量，在 batch_size 很小时输出会不稳定。

### 2.3 为什么在小 batch 和序列任务上失效

BatchNorm 的统计量是"跨样本"（沿 batch 维度）计算的，这带来两个问题：

**小 batch**：batch 内样本数太少时，`batch_mean`/`batch_var` 是对真实分布的高方差估计——比如 batch_size=2 时，均值方差几乎就是这两个样本本身的值，噪声极大，训练不稳定。

**序列任务（如 NLP）**：BatchNorm 沿 batch 维度统计，意味着它把"一个句子里第 3 个 token 的某个特征"和"另一个句子里第 3 个 token的同一特征"放在一起统计。但序列长度通常不同，且不同位置的 token 语义上并不对齐（padding 更是引入了无意义的统计量）。这种"跨样本、按位置对齐"的假设在 NLP 里通常不成立，所以 BatchNorm 在 RNN/Transformer 上效果不佳，这是 LayerNorm 被提出并成为序列模型标配的直接动机。

## 3. LayerNorm

### 3.1 原理

LayerNorm 换了一个统计轴：不跨样本统计，而是**对单个样本自身的特征维度**求均值方差：

```
对某个样本 x（形状为 [d]，即该样本在这一层的所有特征）：
  mean = mean(x)              沿特征维度求，不涉及其他样本
  var  = var(x)
  x_norm = (x - mean) / sqrt(var + eps)
  y = gamma * x_norm + beta
```

因为统计量只依赖单个样本自身，**LayerNorm 天然不受 batch size 的影响**（batch_size=1 也能算），也不涉及跨样本对齐问题，因此适合序列长度可变、batch size 可能很小的场景——这正是 Transformer 选择 LayerNorm 而不是 BatchNorm 的原因。同时 LayerNorm **不需要维护 running statistics**：训练和推理用的是同一套计算逻辑（都用当前样本自己的统计量），没有 BatchNorm 那种训练推理行为不一致的问题。

## 4. RMSNorm

### 4.1 原理：砍掉了什么

RMSNorm（Root Mean Square Normalization）是 LayerNorm 的简化版，直觉是：**归一化真正需要控制的是激活值的尺度（scale），不减均值也大体可行**。

```
LayerNorm:  x_norm = (x - mean(x)) / sqrt(var(x) + eps)      ← 减均值 + 除标准差
             y = gamma * x_norm + beta

RMSNorm:    rms = sqrt(mean(x²) + eps)                        ← 只算均方根，不减均值
             x_norm = x / rms
             y = gamma * x_norm                                ← 通常也不带 beta
```

RMSNorm 相比 LayerNorm 砍掉了两处：

1. **不减均值**（re-centering）：只做缩放（re-scaling），不做平移
2. **通常不带 `beta` 偏置项**：只有一个可学习的缩放参数 `gamma`

### 4.2 为什么现代 LLM 大多选它

- **计算更省**：不需要算均值这一步，只需要均方根，减少了一次统计量计算和一次减法，在参数量巨大、层数很深的模型里这个节省会被反复叠加放大
- **数值实践上足够好**：很多实践观察到去掉 re-centering 对效果影响很小，同时换来了实现更简单、速度更快
- **梳理依赖更少**：不需要 `beta`，参数量和计算图都更简洁

> ⚠️ 待确认：RMSNorm 相比 LayerNorm 的具体速度提升幅度、以及"去掉 re-centering 不影响效果"背后更严谨的理论解释，不同资料的表述细节不完全一致，这里只给出被广泛采用的工程结论，不做具体数值断言。

## 5. GroupNorm

GroupNorm 介于 BatchNorm 和 LayerNorm 之间：它不沿 batch 维度统计（所以不受 batch size 影响），但也不是对整个特征维度统计，而是把通道（channel）分成若干组，**在每一组内部**、单个样本上求统计量：

```
把 C 个通道分成 G 组，每组 C/G 个通道
对每个样本、每一组，沿"组内通道 + 空间维度"求 mean/var
```

GroupNorm 常用在卷积网络里，因为它不依赖 batch size，在 batch size 很小（比如目标检测等显存受限、只能塞下几张图的任务）时比 BatchNorm 更稳定，同时又保留了"按通道分组"这种更贴合卷积特征结构的归一化方式（不像 LayerNorm 对卷积网络那样把所有通道混在一起统计）。

## 6. Pre-LN vs Post-LN

Transformer 的每个子层（attention 或 FFN）都搭配一个残差连接和一个 LayerNorm，但归一化layer 放在残差连接的前面还是后面，对训练稳定性影响很大。

```
Post-LN（原始 Transformer 论文的设计）：
  x_out = LayerNorm(x + SubLayer(x))
  ┌─────────┐
x─┤ SubLayer├──►(+)──►LayerNorm──► x_out
  └─────────┘   ▲
  └──────────────┘ 残差直连

Pre-LN（后续被广泛采用的设计）：
  x_out = x + SubLayer(LayerNorm(x))
       ┌──────────┐   ┌─────────┐
x──┬──►│LayerNorm │──►│SubLayer │──►(+)──► x_out
   │   └──────────┘   └─────────┘   ▲
   └───────────────────────────────────┘ 残差直连（不经过任何归一化）
```

### 6.1 为什么这个选择直接关系到训练稳定性

**Post-LN 的问题**：残差直连的输出 `x + SubLayer(x)` 会先经过 LayerNorm 才继续往下传。这意味着**梯度反向传播时，那条"直通"的残差路径也会被 LayerNorm 的梯度影响**，残差连接原本"给梯度开一条不经过任何变换的高速通道"的作用被打破了（回顾 [反向传播推导](../04-神经网络原理/02-反向传播推导.md) 里残差连接 `∂y/∂x = 1 + ∂F/∂x` 那个恒等的 `1`——Post-LN 让这个恒等路径也被 LayerNorm 的非线性影响）。层数一深，这种效应累积起来容易导致训练初期梯度不稳定，Post-LN 结构的深层 Transformer 通常需要精心设计的 warmup 才能训练起来。

**Pre-LN 的改进**：LayerNorm 放在子层内部（在进入 attention/FFN 之前），残差连接 `x + SubLayer(LayerNorm(x))` 的主干路径 `x → x_out` 是纯粹的加法，没有任何归一化或非线性操作介入。梯度可以沿着这条路径几乎无衰减地传到最前面的层，这让深层 Transformer 的训练明显更稳定，对 warmup 策略的依赖也降低（但通常仍会用，见 [学习率调度与训练技巧](04-学习率调度与训练技巧.md)）。

这是目前主流大模型架构普遍采用 Pre-LN（或其变体）的直接原因。代价是 Pre-LN 在网络很深时，主干信号的数值范围会随层数增长而累积增大（因为每层都在直接往主干上加东西，没有归一化收着），需要额外的设计（比如最终输出前再加一次归一化）来兜底。

## 7. 最小可运行实现

### 7.1 BatchNorm 训练/推理的 running statistics 验证

用 numpy 手写 BatchNorm 的训练与推理逻辑，验证 running statistics 在多个 batch 后能收敛到真实的均值方差，且推理阶段单样本也能得到稳定输出。

```python
import numpy as np

rng = np.random.default_rng(0)


def batchnorm_train(x, gamma, beta, running_mean, running_var, momentum=0.1, eps=1e-5):
    """训练时：用当前 batch 的统计量归一化，同时滑动更新 running 统计量
    x 形状: (batch_size, features)"""
    batch_mean = x.mean(axis=0)
    batch_var = x.var(axis=0)

    x_norm = (x - batch_mean) / np.sqrt(batch_var + eps)
    out = gamma * x_norm + beta

    running_mean = (1 - momentum) * running_mean + momentum * batch_mean
    running_var = (1 - momentum) * running_var + momentum * batch_var
    return out, running_mean, running_var


def batchnorm_eval(x, gamma, beta, running_mean, running_var, eps=1e-5):
    """推理时：用训练阶段积累的 running 统计量，不依赖当前 batch"""
    x_norm = (x - running_mean) / np.sqrt(running_var + eps)
    return gamma * x_norm + beta


features = 4
gamma = np.ones(features)
beta_param = np.zeros(features)
running_mean = np.zeros(features)
running_var = np.ones(features)

# 真实分布的均值方差故意设得不是 0/1，观察 running 统计量能不能追上
true_mean = np.array([3.0, -2.0, 0.5, 10.0])
true_std = np.array([1.0, 2.0, 0.1, 5.0])

for step in range(200):
    batch = rng.normal(true_mean, true_std, (16, features))
    _, running_mean, running_var = batchnorm_train(
        batch, gamma, beta_param, running_mean, running_var
    )

print("训练后 running_mean:", np.round(running_mean, 2), " 真实均值:", true_mean)
print("训练后 running_std :", np.round(np.sqrt(running_var), 2), " 真实标准差:", true_std)

# 推理：单样本也应该稳定，因为不再依赖当前 batch 统计量
single_sample = rng.normal(true_mean, true_std, (1, features))
out_eval = batchnorm_eval(single_sample, gamma, beta_param, running_mean, running_var)
print("单样本推理输出:", np.round(out_eval, 3))
```

实测输出（numpy 2.4.4）：

```
训练后 running_mean: [ 3.03 -2.07  0.49  9.95]  真实均值: [ 3.  -2.   0.5 10. ]
训练后 running_std : [0.91 1.89 0.1  4.54]  真实标准差: [1.  2.  0.1 5. ]
单样本推理输出: [[ 2.041 -0.009 -0.43   0.676]]
```

`running_mean`/`running_std` 在 200 步滑动平均后已经非常接近真实的均值和标准差（`[3.03,-2.07,0.49,9.95]` vs 真实 `[3,-2,0.5,10]`），验证了 BatchNorm 依靠训练过程积累的全局统计量来支撑推理阶段——即使推理输入只有 1 个样本，也能得到稳定、确定性的输出。

### 7.2 LayerNorm vs RMSNorm 对比

验证 LayerNorm 会强制让每个样本的输出均值为 0、方差为 1；RMSNorm 不改变均值，只把均方根缩放到 1。

```python
import numpy as np

rng = np.random.default_rng(0)


def layer_norm(x, gamma, beta, eps=1e-5):
    """LayerNorm: 对每个样本自身的特征维度做归一化（减均值、除标准差）"""
    mean = x.mean(axis=-1, keepdims=True)
    var = x.var(axis=-1, keepdims=True)
    x_norm = (x - mean) / np.sqrt(var + eps)
    return gamma * x_norm + beta


def rms_norm(x, gamma, eps=1e-5):
    """RMSNorm: 只用均方根缩放，不减均值，也没有 beta 偏置项"""
    rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + eps)
    return gamma * (x / rms)


d = 6
x = rng.normal(5, 2, (3, d))  # 故意让均值不为 0，观察两种归一化的区别
gamma = np.ones(d)
beta = np.zeros(d)

ln_out = layer_norm(x, gamma, beta)
rms_out = rms_norm(x, gamma)

print("LayerNorm 输出每行均值(应≈0):", np.round(ln_out.mean(axis=-1), 4))
print("LayerNorm 输出每行方差(应≈1):", np.round(ln_out.var(axis=-1), 4))
print("RMSNorm  输出每行均值(不强制为0):", np.round(rms_out.mean(axis=-1), 4))
print("RMSNorm  输出每行均方(应≈1):", np.round((rms_out ** 2).mean(axis=-1), 4))
```

实测输出（numpy 2.4.4）：

```
LayerNorm 输出每行均值(应≈0): [-0. -0. -0.]
LayerNorm 输出每行方差(应≈1): [1. 1. 1.]
RMSNorm  输出每行均值(不强制为0): [0.99   0.9363 0.9122]
RMSNorm  输出每行均方(应≈1): [1. 1. 1.]
```

LayerNorm 严格把每个样本的输出拉到均值 0、方差 1；RMSNorm 的输出均值仍保留了输入原本"偏向正数"的趋势（`0.99, 0.94, 0.91` 均不为 0），但均方（`E[x²]`）被精确缩放到 1——这与"RMSNorm 只做缩放、不做平移"的数学定义完全一致。

## 8. 小结

| 方法 | 统计轴 | 训练/推理是否一致 | 典型场景 |
| --- | --- | --- | --- |
| BatchNorm | 跨样本（batch 维度） | 不一致，推理用 running statistics | CNN、大 batch 场景 |
| LayerNorm | 单样本内的特征维度 | 一致 | RNN、Transformer、序列任务 |
| RMSNorm | 单样本内的特征维度，只算均方根 | 一致 | 现代 LLM（计算更省） |
| GroupNorm | 单样本内，按通道分组统计 | 一致 | 小 batch 的卷积网络 |
| Pre-LN | — | — | 归一化在子层前，残差主干无衰减，深层更稳 |
| Post-LN | — | — | 归一化在残差后，深层易训练不稳，依赖 warmup |
