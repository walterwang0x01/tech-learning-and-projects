## 1. 正则化解决什么问题

上一篇讲到，过拟合的本质是模型方差过高——对训练集的噪声过于敏感。正则化的通用思路是：**在损失函数里加一个惩罚项，限制模型的自由度，用可控的偏差增加换取方差降低**。

```
L_regularized(θ) = L_data(θ) + λ · R(θ)
```

`R(θ)` 是对参数的惩罚，`λ` 控制惩罚力度。不同的 `R(θ)` 形式对应不同的正则化方法，效果和几何解释都不一样。

## 2. L1 / L2 正则化

### 2.1 数学形式

```
L2 (Ridge):  R(θ) = Σ θ_i²          即 ‖θ‖₂²
L1 (Lasso):  R(θ) = Σ |θ_i|         即 ‖θ‖₁
```

加入损失后，优化目标变为：

```
L2: min_θ  L_data(θ) + λ Σ θ_i²
L1: min_θ  L_data(θ) + λ Σ |θ_i|
```

### 2.2 几何解释：为什么 L1 产生稀疏解

把带约束的优化问题写成等价形式（拉格朗日对偶的直觉版本）：在约束 `R(θ) ≤ C` 下最小化 `L_data(θ)`。约束区域的形状决定了最优解落在哪里：

```
L2 约束区域（圆/球）              L1 约束区域（菱形/多面体）

        θ2                              θ2
         │                               │
      ⌢⌢⌢│⌢⌢⌢                          ╱ │ ╲
    ╱     │     ╲                     ╱   │   ╲
   │      │      │                   ╱    │    ╲
───┼──────┼──────┼─── θ1        ────┼─────┼─────┼──── θ1
   │      │      │                   ╲    │    ╱
    ╲     │     ╱                     ╲   │   ╱
      ⌣⌣⌣│⌣⌣⌣                          ╲ │ ╱
         │                               │
   等高线切点可以落在圆周任意位置      等高线切点大概率落在"角"上
   （包括坐标轴，但不是特别偏好）      （角就在坐标轴上，即某个 θ_i = 0）
```

`L_data(θ)` 的等高线（椭圆）向约束区域边界收缩，最优解出现在等高线与约束区域边界的切点：

- **L2 的约束区域是光滑的球面**，等高线切到球面上任意一点的概率是均匀的，切点几乎不会恰好落在坐标轴上——所以 L2 会让所有系数都变小，但很少让系数精确为 0
- **L1 的约束区域是带尖角的多面体（菱形）**，这些尖角本身就在坐标轴上。等高线的切点有很大概率恰好卡在某个角上——那个角对应某些坐标 `θ_i = 0`。这就是 L1 产生稀疏解的几何原因

另一个等价视角是看惩罚项在 `θ_i = 0` 处的导数行为：

```
L2 的导数在 0 附近: d/dθ(θ²) = 2θ  → θ→0 时导数也 →0，没有力把 θ 推向精确的 0
L1 的导数在 0 附近: d/dθ|θ| = sign(θ)  → 只要 θ≠0，惩罚的"拉力"恒定不减小，
                     会持续把小系数一直推到恰好 0（次梯度在 0 处允许停留）
```

L2 的惩罚力度随系数变小而变小（越接近 0 惩罚越弱），所以系数只会不断缩小却极少精确归零；L1 的惩罚力度不随系数大小衰减，会把不重要的系数直接推到 0——这就是"稀疏"的来源。

## 3. 权重衰减与 L2 的关系

### 3.1 在 SGD 下：等价

L2 正则化加入损失后，梯度下降的更新规则：

```
θ ← θ - η · ∇L_data(θ) - η · λ · θ · 2      （从 λθ² 求导得到 2λθ）
  = (1 - 2ηλ) · θ - η · ∇L_data(θ)
```

**权重衰减（weight decay）**是直接在参数更新里加一项衰减，不经过损失函数：

```
θ ← θ - η · ∇L_data(θ) - η · λ_wd · θ
  = (1 - η·λ_wd) · θ - η · ∇L_data(θ)
```

两者形式完全一样（只要令 `λ_wd = 2λ`），所以在**普通 SGD** 下，"L2 正则化"和"权重衰减"是同一件事的两种叫法。

### 3.2 在 Adam 下：不等价

区别出现在 Adam 这类自适应学习率优化器里。Adam 的更新规则大致是：

```
m ← β1·m + (1-β1)·g            （一阶矩，梯度的动量）
v ← β2·v + (1-β2)·g²           （二阶矩，梯度平方的动量）
θ ← θ - η · m / (√v + ε)       （用二阶矩缩放学习率）
```

**如果把 L2 正则加进损失函数**，惩罚项 `2λθ` 会混进梯度 `g`，一起被 `v`（梯度平方的滑动统计量）缩放：

```
g_total = ∇L_data(θ) + 2λθ
θ ← θ - η · Adam_scale(g_total)
```

问题在于：`v` 里混入了权重本身的量级信息，对不同参数的缩放不再是"纯粹的权重衰减"——一个梯度普遍偏小的参数（`v` 小），它的正则化力度会被 Adam 的自适应缩放意外放大；反之梯度普遍偏大的参数，正则化力度会被削弱。**正则化的强度变得和梯度统计量绑定，不再是稳定的 `λ`。**

**AdamW** 的做法是把权重衰减从梯度里剥离出来，直接作用在参数上，不经过 Adam 的自适应缩放：

```
m ← β1·m + (1-β1)·g                    （g 只是纯数据损失的梯度，不含正则项）
v ← β2·v + (1-β2)·g²
θ ← θ - η · [ m / (√v + ε)  +  λ_wd · θ ]     ← 衰减项直接加在最后，绕开 Adam 缩放
```

这样权重衰减的力度就和梯度的统计量无关，重新变回"稳定的 `λ`"。这是 AdamW 相对 Adam+L2 的核心区别，也是目前训练 Transformer 类模型时更常用 AdamW 的原因之一。

> ⚠️ 待确认：不同框架（如 PyTorch）里 `Adam` 优化器传入 `weight_decay` 参数时的具体实现方式，请以对应版本官方文档为准，本文只说明数学原理上的区别。

## 4. Dropout

### 4.1 原理

Dropout 在训练时，对每一层的输出，以概率 `p_drop` 随机将某些单元置零，剩下的单元乘以缩放系数：

```
训练时：
  mask_i ~ Bernoulli(1 - p_drop)     每个单元独立采样一个 0/1 掩码
  y_i = mask_i · x_i / (1 - p_drop)  丢弃的置零，保留的放大补偿
```

这被称为 **inverted dropout**（现在的标准实现方式）：放大补偿的目的是让训练时输出的**期望值**与不做 dropout 时一致：

```
E[y_i] = P(mask_i=1) · x_i/(1-p_drop) = (1-p_drop) · x_i/(1-p_drop) = x_i
```

### 4.2 训练与推理的处理差异

```
训练阶段：  y = mask · x / (1 - p_drop)      每次前向随机丢弃 + 缩放补偿
推理阶段：  y = x                            直接输出，不丢弃、不缩放
```

因为 inverted dropout 已经保证了训练时输出的期望等于原始输入 `x`，所以推理时只需直接用完整的 `x`，不需要再做任何变换——这也是"inverted"（把缩放挪到训练阶段而不是推理阶段）设计的意义：推理路径可以保持简单、确定性。

**如果推理时忘了关闭 dropout**：模型会引入不必要的随机性（同一个输入每次推理得到不同输出），且由于随机丢弃单元，等效于输出乘上一个期望为 1 但方差不为 0 的随机因子——预测会带噪声但均值上无系统性偏差（因为 inverted 缩放的存在）。反过来，**如果用了训练时的丢弃逻辑却忘了缩放**，输出的期望会系统性缩小为 `(1-p_drop)` 倍，这是更常见的错误。

### 4.3 直觉：为什么 dropout 能正则化

- 每次前向都在训练一个"随机子网络"，相当于用少量参数的子网络集合近似一个大网络的集成（ensemble）效果
- 强迫每个单元不能过度依赖某几个特定的其他单元（因为那些单元随时可能被丢弃），减少了单元间的"共谋"（co-adaptation），迫使表征更鲁棒、更分散

### 4.4 DropPath

DropPath（也叫 Stochastic Depth）是 dropout 思想在**残差分支**层级的推广：不是随机丢弃单个神经元，而是以一定概率整条跳过某个残差分支（比如 Transformer 的一层 attention 或 FFN 子层），让输入直接通过恒等连接：

```
标准残差：       y = x + F(x)
训练时 DropPath： y = x + mask · F(x) / (1 - p_drop)   （mask 是逐样本的整体 0/1，不是逐单元）
推理时：         y = x + F(x)                          （和 dropout 一样，推理不丢弃）
```

在深层网络（尤其是层数很多的 Transformer/ResNet）中，DropPath 相当于训练时随机让网络变"浅"，缓解深层网络的过拟合，同时因为有恒等连接兜底，即使丢弃了某个分支梯度也能沿着 `+x` 这条路径继续传播。

## 5. 早停（Early Stopping）

回到上一篇的训练-验证曲线：验证损失出现"先降后升"的拐点后，继续训练只会让方差进一步上升（过拟合加深）。**早停**就是监控验证集损失，当它连续若干轮不再改善时，停止训练并保留验证损失最低点的那个checkpoint。

```
if val_loss 连续 patience 轮没有创新低:
    停止训练，回滚到历史最优 checkpoint
```

早停本质上是**用训练轮数间接控制模型复杂度**——训练越久，模型越倾向于拟合训练集里的细节（包括噪声），早停就是在方差开始明显上升之前踩下刹车。它几乎零额外计算成本，是最常用的正则化手段之一。

## 6. 数据增强作为隐式正则

数据增强（data augmentation）不修改模型或损失函数，而是通过对训练样本做保持标签不变的随机变换（如图像的旋转、裁剪、颜色扰动；文本的同义词替换等），人为扩大训练分布的多样性。

它属于**隐式正则化**：不是显式惩罚参数，而是通过让模型在训练时见到更多"变体"，迫使模型学习对这些变换不敏感的特征，本质上和显式正则化一样，都是在用可控的偏差换方差下降——只是作用路径是"扩充数据分布"而不是"惩罚参数"。

## 7. 标签平滑（Label Smoothing）

分类任务通常用 one-hot 标签训练交叉熵损失，让模型对正确类别的输出概率逼近 1、其余逼近 0。这会驱使模型的 logits 差距越来越大（因为 softmax 要逼近 0/1 需要极端的 logits），容易导致过度自信（overconfident）且加剧过拟合。

标签平滑把 one-hot 标签软化：

```
硬标签：       y = [0, 0, 1, 0]
平滑后标签：   y' = (1-ε)·y + ε/K            （K 是类别数）
```

例如 `K=4, ε=0.1` 时，`[0,0,1,0]` 变成 `[0.025, 0.025, 0.925, 0.025]`。模型不再被要求把正确类别的概率推到 1，而是留一点概率余量给其他类别，防止 logits 无限增大、防止模型对训练集标签噪声过度信任。

## 8. 最小可运行实现

### 8.1 L1 vs L2：稀疏解的数值验证

用坐标下降手写 Lasso（L1）求解器，与闭式解的 Ridge（L2）对比，在同一份"稀疏真实信号"数据上验证 L1 能精确恢复稀疏解、L2 不能。

```python
import numpy as np

rng = np.random.default_rng(0)
n, p = 60, 20
true_support = 5  # 只有前 5 个特征真正有用，其余 15 个是噪声特征

X = rng.normal(0, 1, (n, p))
beta_true = np.zeros(p)
beta_true[:true_support] = rng.normal(2, 0.5, true_support)
y = X @ beta_true + rng.normal(0, 0.5, n)


def ridge_fit(X, y, lam):
    """L2 正则的闭式解：(XᵀX + λI)⁻¹Xᵀy"""
    p = X.shape[1]
    return np.linalg.solve(X.T @ X + lam * np.eye(p), X.T @ y)


def soft_threshold(x, t):
    """L1 次梯度对应的软阈值算子：|x|<t 时直接置零，否则往 0 方向收缩 t"""
    return np.sign(x) * np.maximum(np.abs(x) - t, 0)


def lasso_fit(X, y, lam, n_iter=500):
    """坐标下降求 Lasso：固定其余坐标，单坐标闭式解 = 软阈值"""
    n, p = X.shape
    beta = np.zeros(p)
    col_norm2 = np.sum(X ** 2, axis=0)
    for _ in range(n_iter):
        for j in range(p):
            residual = y - X @ beta + X[:, j] * beta[j]  # 剔除第 j 列贡献后的残差
            rho = X[:, j] @ residual
            beta[j] = soft_threshold(rho, lam) / col_norm2[j] if col_norm2[j] > 0 else 0
    return beta


beta_ridge = ridge_fit(X, y, lam=5.0)
beta_lasso = lasso_fit(X, y, lam=8.0)

print("真实系数非零个数:", np.sum(np.abs(beta_true) > 1e-6))
print("Ridge 非零个数(|beta|>0.01):", np.sum(np.abs(beta_ridge) > 0.01))
print("Lasso 非零个数(|beta|>0.01):", np.sum(np.abs(beta_lasso) > 0.01))
```

实测输出（numpy 2.4.4）：

```
真实系数非零个数: 5
Ridge 非零个数(|beta|>0.01): 18
Lasso 非零个数(|beta|>0.01): 5
```

Lasso 恢复出的非零系数个数（5）与真实支撑集完全一致；Ridge 把 20 个特征里的 18 个都留了非零权重（哪怕真实值是 0），完全符合"L2 缩小但不置零，L1 直接产生稀疏解"的理论。

### 8.2 Dropout 训练/推理差异验证

验证 inverted dropout 缩放是否真的让训练时输出的期望值等于原始输入（即推理时不做任何处理是自洽的）。

```python
import numpy as np

rng = np.random.default_rng(0)


def dropout_train(x, p_drop):
    """训练时：以概率 p_drop 随机置零，保留的单元做 inverted 缩放 1/(1-p_drop)，
    让训练输出的期望值与原始输入一致"""
    mask = (rng.uniform(size=x.shape) > p_drop).astype(x.dtype)
    return x * mask / (1.0 - p_drop)


def dropout_eval(x, p_drop):
    """推理时：不丢弃任何单元，直接原样输出"""
    return x


x = np.ones(200000)  # 用大量重复单元的均值近似"多次前向的期望"
p_drop = 0.3

train_out = dropout_train(x, p_drop)
eval_out = dropout_eval(x, p_drop)

print(f"输入值: {x[0]}")
print(f"训练输出均值(近似期望): {train_out.mean():.4f}")
print(f"推理输出均值: {eval_out.mean():.4f}")
print(f"理论期望: 1.0000 (保留概率 {1-p_drop} * 缩放 {1/(1-p_drop):.4f})")
```

实测输出（numpy 2.4.4）：

```
输入值: 1.0
训练输出均值(近似期望): 1.0003
推理输出均值: 1.0000
理论期望: 1.0000 (保留概率 0.7 * 缩放 1.4286)
```

训练输出均值 1.0003 与推理输出 1.0000 几乎一致（误差来自有限样本的采样波动），验证了 inverted dropout 缩放确实让训练期望对齐推理值——这正是推理时可以直接跳过 dropout 计算的数学依据。

## 9. 小结

| 方法 | 作用机制 | 关键特性 |
| --- | --- | --- |
| L2 (Ridge) | 惩罚 `Σθ²`，约束区域是球 | 系数普遍缩小，几乎不产生精确 0 |
| L1 (Lasso) | 惩罚 `Σ\|θ\|`，约束区域有尖角 | 产生稀疏解，可用于特征选择 |
| 权重衰减 | 直接在参数更新里衰减 | SGD 下等价 L2；Adam 下需要 AdamW 才能保持等价 |
| Dropout | 训练随机丢弃+缩放，推理原样输出 | 近似模型集成，防止单元共谋 |
| DropPath | 训练随机跳过整条残差分支 | 深层网络的"随机变浅"，配合恒等连接保梯度通路 |
| 早停 | 验证损失不再改善时停止训练 | 零成本，用训练轮数间接控制复杂度 |
| 数据增强 | 扩充训练分布的多样性 | 隐式正则，不改损失函数 |
| 标签平滑 | 软化 one-hot 标签 | 防止 logits 过度自信，缓解标签噪声影响 |
