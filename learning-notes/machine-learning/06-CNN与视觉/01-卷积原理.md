## 1. 全连接处理图像：参数爆炸问题

假设输入是一张 `32×32×3`（宽 32、高 32、3 个颜色通道）的小图，接一个全连接层输出同样大小的 `32×32×64` 特征图。全连接层里每个输出神经元都要跟输入的每个像素连一条权重，参数量是：

```
参数量 = (H·W·Cin) × (H·W·Cout)
       = (32·32·3) × (32·32·64)
```

这个乘积轻松突破数十亿——而这只是一张很小的图、一层网络。如果输入换成常见的 `224×224` 图像，参数量会再涨几个量级，训练和存储都不可行。更本质的问题是：全连接层对图像的空间结构一无所知，它把每个像素当作独立无关的特征，既学不动、也学不好（同一个物体出现在图像不同位置，全连接层要重新学一套权重）。

## 2. 卷积的两个核心假设：局部连接与权值共享

卷积层用两个假设解决了这个问题：

**局部连接（local connectivity）**：输出的每个位置只依赖输入的一个局部区域（卷积核大小 `k×k`），而不是整张图。一个 `3×3` 的卷积核，无论输入多大，每个输出位置只看输入的 9 个像素（乘以通道数）。

**权值共享（weight sharing）**：同一个卷积核在整张图的所有位置上滑动使用同一组参数，而不是每个位置学一套独立的权重。这背后隐含一个假设——图像中某种局部模式（边缘、纹理）的检测方式，不应该因为它出现在图像的哪个位置而改变。

两个假设叠加后，一层卷积的参数量变成：

```
参数量 = k · k · Cin · Cout（不含 bias）
```

与输入的 `H、W` 完全无关。仍以 `Cin=64, Cout=64, k=3` 为例：`3×3×64×64 = 36,864`，比全连接的数十亿量级低了 5 个数量级——这就是卷积能训练、能堆深层的前提。

## 3. 感受野：逐层扩大的"视野"

**感受野（receptive field）** 指输出特征图上一个点，实际能"看到"原始输入图像上多大的区域。单层 `k×k` 卷积的感受野就是 `k×k`；堆叠多层后，感受野会逐层累加扩大。第 `L` 层（stride 全为 1）的感受野递推公式：

```
RF_L = RF_{L-1} + (k_L - 1) · dilation_L

RF_0 = 1（输入层，每个像素只看自己）
```

例如连续堆 3 层 `3×3` 卷积（stride=1, dilation=1）：`RF_1=3, RF_2=5, RF_3=7`——3 层 `3×3` 卷积的感受野等价于 1 层 `7×7` 卷积，但参数量和计算量都远小于直接用大卷积核（这正是 VGG 系列"堆小卷积核代替大卷积核"的核心动机，后续网络演进篇会展开）。如果中间有 stride>1 的下采样层，后续层的感受野增长会被放大（因为下采样后特征图上一步移动对应原图上更大的跨度）。

## 4. stride / padding / dilation 对输出尺寸的影响

三个超参数共同决定卷积输出的空间尺寸，统一公式：

```
out = floor((in + 2·padding - dilation·(k-1) - 1) / stride) + 1
```

- **stride（步长）**：卷积核每次滑动的像素数。stride 越大，输出尺寸越小，等效于在卷积的同时做下采样。
- **padding（填充）**：在输入边缘补零的层数。padding 的常见用途是让输出尺寸与输入尺寸保持一致（"same" 卷积），避免网络越深、特征图边缘信息损失越严重。
- **dilation（空洞率）**：卷积核内部元素之间插入的空隙数。dilation=2 时，`3×3` 核实际覆盖 `5×5` 的范围（元素间隔一个空位），但参数量仍是 `3×3`——用于在不增加参数、不下采样的前提下扩大感受野（常见于语义分割等需要保持分辨率的任务）。

## 5. 池化：下采样与争议

**池化（pooling）** 通常紧跟在卷积之后，对局部区域做聚合（max pooling 取最大值，average pooling 取平均值），作用是降低特征图分辨率、减少后续计算量，同时提供一定程度的**平移不变性**（下面第 6 节详细区分）。

池化的争议在于：它是一种确定性、不可学习的下采样方式，会丢弃被聚合区域内除最大值/平均值以外的所有信息。这对于分类任务（只关心"有没有这个特征"）通常无害甚至有利，但对于需要精确空间信息的任务（如姿态估计、密集预测）可能损失关键细节。这也是为什么后期一些网络架构（如 ResNet 之后的部分变体）倾向于用**带 stride 的卷积**替代池化层——用可学习的方式完成下采样，而不是固定规则的聚合。

## 6. 平移等变性 vs 平移不变性

这两个概念经常被混用，但含义不同：

**平移等变性（translation equivariance）**：输入平移后，输出会按相同方式平移——特征"跟着动"。卷积操作本身具有这个性质：如果输入图像里的物体往右移动 5 个像素，卷积输出的特征图上对应的激活位置也会往右移动 5 个像素（因为权值共享，同一个模式无论出现在哪个位置都会被同样的卷积核检测出来）。

**平移不变性（translation invariance）**：输入平移后，输出基本不变——特征"不跟着动"，只关心"有没有"不关心"在哪"。这个性质主要来自**池化**（尤其是全局池化）：无论最大值出现在局部区域的哪个位置，max pooling 的输出都一样。

结论：**卷积层提供的是等变性，不变性主要靠池化（或全局平均池化）在网络后段逐步引入**。分类任务最终需要不变性（判断"图里有没有猫"，不关心猫在图像哪个角落），但检测、分割等需要精确定位的任务，过早引入太强的不变性会损害定位精度。

## 7. 分组卷积与深度可分离卷积：进一步压参数

**分组卷积（grouped convolution）**：把输入通道和输出通道都分成 `g` 组，每组内部独立做标准卷积，组间不连接。参数量从标准卷积的 `k·k·Cin·Cout` 降到 `g · (k·k·(Cin/g)·(Cout/g)) = k·k·Cin·Cout/g`——直接除以组数 `g`。代价是组间信息不再直接交互，需要额外机制（如 ShuffleNet 的通道打乱）弥补。

**深度可分离卷积（depthwise separable convolution）**：把标准卷积拆成两步——先做 **depthwise 卷积**（每个输入通道独立卷积，不跨通道混合，参数量 `k·k·Cin`），再做 **pointwise 卷积**（`1×1` 卷积，负责混合通道信息，参数量 `1·1·Cin·Cout`）。这是 MobileNet 系列的核心组件（后续网络演进篇会展开），总参数量 `k·k·Cin + Cin·Cout`，相比标准卷积的压缩比接近 `1/Cout`（当 `k·k` 远小于 `Cout` 时）。

## 8. 1x1 卷积的作用

`1×1` 卷积核不覆盖任何空间邻域（感受野还是 `1×1`），看起来"什么都没做"，但它有两个关键作用：

1. **跨通道信息混合与降维/升维**：`1×1` 卷积对每个空间位置上的 `Cin` 个通道值做一次线性组合，输出 `Cout` 个通道——相当于在通道维度上做了一次全连接。Inception 系列用它在计算量大的 `3×3`、`5×5` 卷积之前先降通道数，大幅减少计算量。
2. **增加非线性**：`1×1` 卷积后接激活函数，可以在不改变空间分辨率的前提下给网络增加一层非线性变换，提升表达能力。

## 9. 最小可运行实现：手写 conv2d 验证尺寸公式与参数量

```python
"""
手写 conv2d，验证：
  1. 卷积输出尺寸公式：out = floor((in + 2*pad - dilation*(k-1) - 1) / stride) + 1
  2. 全连接 vs 卷积 vs 分组卷积 vs 深度可分离卷积的参数量对比
"""
import numpy as np


def conv2d(x, w, stride=1, padding=0, dilation=1):
    """单通道输入输出的简化 conv2d，x: (H,W)，w: (kh,kw)"""
    if padding > 0:
        x = np.pad(x, ((padding, padding), (padding, padding)))
    H, W = x.shape
    kh, kw = w.shape
    eff_kh = dilation * (kh - 1) + 1
    eff_kw = dilation * (kw - 1) + 1
    out_h = (H - eff_kh) // stride + 1
    out_w = (W - eff_kw) // stride + 1
    out = np.zeros((out_h, out_w))
    for i in range(out_h):
        for j in range(out_w):
            r0, c0 = i * stride, j * stride
            patch = x[r0:r0 + eff_kh:dilation, c0:c0 + eff_kw:dilation]
            out[i, j] = np.sum(patch * w)
    return out


def output_size(in_size, k, stride=1, padding=0, dilation=1):
    eff_k = dilation * (k - 1) + 1
    return (in_size + 2 * padding - eff_k) // stride + 1


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    x = rng.normal(size=(8, 8))
    w = rng.normal(size=(3, 3))

    print("=== 输出尺寸公式验证 ===")
    for stride, padding, dilation in [(1, 0, 1), (2, 0, 1), (1, 1, 1), (1, 0, 2)]:
        out = conv2d(x, w, stride=stride, padding=padding, dilation=dilation)
        formula = output_size(8, 3, stride, padding, dilation)
        print(f"stride={stride}, padding={padding}, dilation={dilation}: "
              f"实际输出形状={out.shape}, 公式计算={formula}, 一致={out.shape[0] == formula}")

    print("\n=== 参数量对比：输入 32x32x64 -> 输出 32x32x64 ===")
    H, W, Cin, Cout, k = 32, 32, 64, 64, 3
    fc_params = (H * W * Cin) * (H * W * Cout)
    conv_params = k * k * Cin * Cout
    groups = 4
    # 分组卷积：输入输出通道各分成 groups 组，每组内部做标准卷积，组间不连接
    group_conv_params = groups * (k * k * (Cin // groups) * (Cout // groups))
    dw_params = k * k * Cin  # depthwise：每个输入通道独立卷积，不跨通道混合
    pw_params = 1 * 1 * Cin * Cout  # pointwise：1x1 卷积混合通道信息
    dsc_params = dw_params + pw_params

    print(f"全连接: {fc_params:,}")
    print(f"标准卷积 (3x3): {conv_params:,}")
    print(f"分组卷积 (groups=4): {group_conv_params:,}")
    print(f"深度可分离卷积 (depthwise+pointwise): {dsc_params:,}")
    print(f"标准卷积/分组卷积 参数比: {conv_params / group_conv_params:.2f}")
    print(f"标准卷积/深度可分离卷积 参数比: {conv_params / dsc_params:.2f}")
```

实测输出（numpy 2.4.4）：

```
=== 输出尺寸公式验证 ===
stride=1, padding=0, dilation=1: 实际输出形状=(6, 6), 公式计算=6, 一致=True
stride=2, padding=0, dilation=1: 实际输出形状=(3, 3), 公式计算=3, 一致=True
stride=1, padding=1, dilation=1: 实际输出形状=(8, 8), 公式计算=8, 一致=True
stride=1, padding=0, dilation=2: 实际输出形状=(4, 4), 公式计算=4, 一致=True

=== 参数量对比：输入 32x32x64 -> 输出 32x32x64 ===
全连接: 4,294,967,296
标准卷积 (3x3): 36,864
分组卷积 (groups=4): 9,216
深度可分离卷积 (depthwise+pointwise): 4,672
标准卷积/分组卷积 参数比: 4.00
标准卷积/深度可分离卷积 参数比: 7.89
```

四组尺寸公式测试全部与手写 conv2d 的实际输出一致，验证了第 4 节公式的正确性。参数量对比中，全连接达到 43 亿量级，标准卷积把参数量压到 3.7 万——降了近 5 个数量级；分组卷积（`groups=4`）参数量正好是标准卷积的 `1/4`，与第 7 节推导的 `1/g` 结论吻合；深度可分离卷积进一步压缩到约 `1/7.89`，因为 `Cout=64` 较大时 pointwise 项 `Cin·Cout` 占主导，压缩比接近但略小于 `Cout/(k·k)` 的理论上限（因为还叠加了 depthwise 项）。

## 10. 小结

| 概念 | 一句话总结 |
| --- | --- |
| 局部连接 | 输出只依赖输入的局部区域，不看整张图 |
| 权值共享 | 同一卷积核滑动复用，参数量与输入尺寸无关 |
| 感受野 | 逐层累加扩大，多层小卷积核可等效大卷积核 |
| stride/padding/dilation | 共同决定输出尺寸，分别控制下采样/边缘保留/空洞扩视野 |
| 池化 | 提供平移不变性，但丢弃细节，密集预测任务需谨慎使用 |
| 等变性 vs 不变性 | 卷积给等变性（跟着动），池化给不变性（不跟着动） |
| 分组卷积/深度可分离卷积 | 用结构化稀疏换参数量，是轻量化网络的核心手段 |
| 1x1 卷积 | 不看空间邻域，只做通道混合与降维/升维 |
