# 经典网络演进：从 LeNet 到 EfficientNet 的设计脉络

> Author: Walter Wang

> **读完你能回答的 3 个问题**
>
> 1. VGG "堆小卷积核"和 Inception "多尺度并行"分别解决了什么问题？两者的设计哲学有何不同？
> 2. 为什么残差连接能让网络训练到上百层不退化？从梯度回传的角度具体解释加法路径起了什么作用？
> 3. MobileNet 和 EfficientNet 分别从什么维度做轻量化/scaling？这条演进线有什么共同规律？

## 1. LeNet / AlexNet：卷积网络的起点

LeNet 是最早把卷积、池化、全连接组合成端到端可训练网络的代表性架构之一，确立了"卷积提特征 + 池化降维 + 全连接分类"的基本范式——这个范式直到今天仍是很多网络的骨架结构。

AlexNet 在这个范式上做了几件关键的事：用 ReLU 替代 sigmoid/tanh 缓解梯度消失（详见 [激活函数](../04-神经网络原理/04-激活函数.md)）、用 dropout 缓解过拟合、在更大规模数据和更深的网络上验证了"深度带来收益"这一方向是可行的。它的意义更多在于**证明了这条路能走通**，而不是某个具体组件的精巧设计——后续网络演进的很多改进方向（更深、更小的卷积核、更好的正则化）都是在这个基础上展开的。

## 2. VGG：堆小卷积核

VGG 的核心思想很单一：**用多层堆叠的 `3×3` 卷积核替代单层大卷积核**。回顾卷积原理篇的感受野公式，3 层 `3×3` 卷积（stride=1）的感受野等价于 1 层 `7×7` 卷积，但参数量和计算量的对比：

```
1 层 7x7 卷积参数量:  7·7·Cin·Cout   = 49·Cin·Cout
3 层 3x3 卷积参数量:  3·(3·3·Cin·Cout) = 27·Cin·Cout（假设通道数不变）
```

3 层小卷积核不仅参数更少，还在中间多插入了两次非线性激活（每层卷积后都接激活函数），表达能力比单层大卷积核更强。这个"用多层小核换等效感受野，同时增加非线性"的思路后来成为几乎所有卷积网络设计的默认选项。VGG 的代价是全部用统一的 `3×3` 卷积堆叠导致层数增加、整体参数量和计算量仍然很大（尤其是末端全连接层）。

## 3. Inception：多尺度并行

Inception 系列反对"只用一种卷积核尺寸"的单一化设计，核心思想是**在同一层内并行放置多个不同尺寸的卷积核（如 `1×1`、`3×3`、`5×5`）和池化操作，把它们的输出在通道维度拼接**，让网络自己去学习在这一层更应该关注哪种尺度的特征，而不是由人工预先固定卷积核大小。

多尺度并行带来的计算量问题（`5×5` 卷积本身开销大，多路并行更是叠加开销）用卷积原理篇提到的 **`1×1` 卷积降维**解决：在每条 `3×3`、`5×5` 分支之前先用 `1×1` 卷积把通道数压下来，再做大卷积核运算，大幅降低计算量而不改变多尺度并行的结构。

## 4. ResNet：残差连接为什么能让网络变深

在 Inception 之后，一个直接的问题是：网络能不能继续堆深？实践发现单纯堆叠层数到一定深度后，训练误差反而上升——不是过拟合，是**优化本身变难了**（深层网络更难训练到收敛，这被称为退化问题）。

ResNet 的解法是给每个模块加一条**恒等跳连（identity shortcut）**：

```
y = x + F(x)

x: 输入，F(x): 若干层卷积构成的残差分支，y: 输出
```

从梯度回传的角度看这为什么有效。对一个不带残差的普通堆叠网络，链式法则会让梯度逐层相乘：

```
∂L/∂x_0 = ∂L/∂x_L · ∏_{i=1}^{L} ∂x_i/∂x_{i-1}
```

如果每一层的局部梯度 `∂x_i/∂x_{i-1}` 数值上小于 1（这在深层网络里很常见——权重初始化偏小、激活函数导数本身小于 1），经过很多层连乘后，传回浅层的梯度会指数级衰减，这正是梯度消失的成因（[反向传播推导](../04-神经网络原理/02-反向传播推导.md)中已给出连乘的一般结论）。

加上残差连接后，每一层的局部梯度变成：

```
y = x + F(x)  =>  ∂y/∂x = I + ∂F(x)/∂x
```

多了一个恒等矩阵 `I`。这意味着梯度回传路径中，**"跳过 F(x) 直接传回"这条恒等路径永远存在，梯度至少能以 1 的系数原样传回上一层，不会被 `∂F(x)/∂x` 的连乘完全压制**。哪怴 `F(x)` 分支的梯度很小甚至接近 0，恒等路径也能保证梯度不会消失到训练不动的程度——这是残差连接允许网络堆到上百层仍能训练的核心机制。

## 5. DenseNet：特征复用

DenseNet 把残差连接的"跳连"思想推向极致：**每一层的输入是前面所有层输出的拼接（concatenate），而不只是加上前一层**。这样设计的好处是每一层都能直接访问前面所有层提取的特征（特征复用），梯度也可以直接从深层传回任意浅层（不需要逐层连乘）。代价是随着层数增加，拼接后的通道数增长很快，需要额外的过渡层（transition layer）周期性压缩通道数来控制计算量。

## 6. MobileNet：轻量化的思路

MobileNet 面向的场景是资源受限的移动/嵌入式设备，核心手段是把卷积原理篇提到的**深度可分离卷积（depthwise separable convolution）** 作为基本构建块，替代标准卷积。深度可分离卷积把"空间卷积"和"通道混合"拆成两步（depthwise 负责空间、pointwise 负责通道），用远小于标准卷积的参数量和计算量逼近标准卷积的表达能力。后续版本还引入了可调节的宽度系数（缩放每层通道数）等手段，让同一套架构可以按算力预算伸缩。

## 7. EfficientNet：复合缩放

在 MobileNet 之后一个自然的问题是：如果要把一个基础网络放大（换更大算力预算），应该往哪个维度放大——加深度（更多层）、加宽度（更多通道）、还是加输入分辨率（更大图像）？EfficientNet 的核心观察是**这三个维度不该单独放大，而应该按一个统一的比例同时放大（compound scaling）**，用一个复合系数联动控制深度、宽度、分辨率的缩放比例，而不是像早期工作那样只调其中一个维度。这个思路本质上是把"网络该多大"这个架构设计问题，转化成了一个更系统化的缩放规则问题。

## 8. 这条演进线的共同规律

回看 LeNet → AlexNet → VGG → Inception → ResNet → DenseNet → MobileNet → EfficientNet 这条线，能看到几条重复出现的规律：

- **参数效率优先于蛮力堆参数**：VGG 用小核堆叠代替大核，MobileNet 用深度可分离代替标准卷积，EfficientNet 用系统化缩放代替盲目加深——每一步都是在"用更少参数/计算量做到同样甚至更好效果"上做文章。
- **让优化本身变得更容易，而不只是让模型变得更复杂**：ResNet 的残差连接、DenseNet 的密集连接，核心不是增加表达能力（`F(x)` 本身没变复杂），而是改善了梯度回传路径，让深层网络"训练得动"。
- **1×1 卷积和多尺度设计反复出现**：Inception 的降维、ResNet 瓶颈结构（bottleneck，先用 `1×1` 降维再做 `3×3`，之后再用 `1×1` 恢复通道数）都在用 `1×1` 卷积控制计算量。

## 9. 最小可运行实现：验证残差连接对梯度传递的影响

```python
"""
用 numpy 验证残差连接对梯度传递的影响：
构造深层"玩具网络"，每层 y = f(x)（无残差）或 y = x + f(x)（有残差），
f 是固定的小权重线性层 + tanh（权重谱范数明显小于 1，制造梯度消失场景），
观察梯度反传到第一层时的量级随深度变化的趋势。
"""
import numpy as np

rng = np.random.default_rng(0)


def forward_plain(x, weights):
    """普通堆叠：y = tanh(W @ x)，逐层前向并记录每层的加权输入 z=Wx"""
    zs = []
    for W in weights:
        z = W @ x
        zs.append(z)
        x = np.tanh(z)
    return zs


def forward_residual(x, weights):
    """残差堆叠：y = x + tanh(W @ x)，逐层前向并记录每层的加权输入 z=Wx"""
    zs = []
    for W in weights:
        z = W @ x
        zs.append(z)
        x = x + np.tanh(z)
    return zs


def backward_plain(zs, weights):
    """普通网络反传：grad = W^T @ diag(1-tanh(z)^2) @ grad，逐层连乘"""
    dim = weights[0].shape[0]
    grad = np.ones(dim)
    for i in range(len(weights) - 1, -1, -1):
        W = weights[i]
        tanh_grad = 1 - np.tanh(zs[i]) ** 2
        grad = W.T @ (grad * tanh_grad)
    return grad


def backward_residual(zs, weights):
    """残差网络反传：grad = grad + W^T @ diag(1-tanh(z)^2) @ grad，恒等项 '+1' 保底"""
    dim = weights[0].shape[0]
    grad = np.ones(dim)
    for i in range(len(weights) - 1, -1, -1):
        W = weights[i]
        tanh_grad = 1 - np.tanh(zs[i]) ** 2
        grad = grad + W.T @ (grad * tanh_grad)
    return grad


if __name__ == "__main__":
    dim = 16
    scale = 0.3  # 权重量级偏小，模拟容易梯度消失的场景
    x0 = rng.normal(size=dim)

    print(f"设置：每层权重按 N(0, {scale}^2) 采样，输入维度={dim}")
    print("=== 不同深度下，传回第一层的梯度范数 ===")
    print(f"{'深度':>4} | {'普通堆叠':>14} | {'残差连接':>14} | {'比值(残差/普通)':>16}")
    for n in [5, 10, 20, 40, 80]:
        rng_local = np.random.default_rng(42)  # 固定种子保证权重可复现
        weights = [rng_local.normal(0, scale, (dim, dim)) for _ in range(n)]

        zs_plain = forward_plain(x0, weights)
        zs_res = forward_residual(x0, weights)

        gp = np.linalg.norm(backward_plain(zs_plain, weights))
        gr = np.linalg.norm(backward_residual(zs_res, weights))

        print(f"{n:>4} | {gp:>14.6e} | {gr:>14.6e} | {gr / gp:>16.2f}")
```

实测输出（numpy 2.4.4）：

```
设置：每层权重按 N(0, 0.3^2) 采样，输入维度=16
=== 不同深度下，传回第一层的梯度范数 ===
  深度 |           普通堆叠 |           残差连接 |        比值(残差/普通)
   5 |   9.932500e-01 |   6.712394e+00 |             6.76
  10 |   6.907066e-01 |   1.538639e+01 |            22.28
  20 |   1.580139e+00 |   1.081657e+01 |             6.85
  40 |   3.968372e-01 |   9.847199e+01 |           248.14
  80 |   5.387559e-01 |   3.609900e+02 |           670.04
```

结果印证了第 4 节的推导：普通堆叠的梯度范数随深度增加**没有累积增长**，始终在 0.4~1.6 之间小幅波动——因为每层局部梯度小于 1，连乘之后信号被持续压制，深度再增加也无法让梯度显著变大（这正是梯度消失的表现：深层梯度信号无法有效累积）。残差连接的梯度范数则随深度**稳定增长**：深度 40 层时是普通堆叠的 248 倍，80 层时达到 670 倍——因为每层都多了一条恒等路径 `I`，梯度可以绕过容易衰减的 `F(x)` 分支直接传回，深度越深，恒等路径贡献的"保底梯度"累积效应越明显。这与第 4 节"残差连接让梯度至少能以系数 1 传回上一层"的结论一致。

## 10. 小结

| 网络 | 核心思想 | 解决的问题 |
| --- | --- | --- |
| LeNet/AlexNet | 卷积+池化+全连接范式，ReLU+dropout | 验证深度卷积网络可训练 |
| VGG | 堆叠小卷积核 | 用更少参数达到等效感受野，增加非线性 |
| Inception | 多尺度并行 + 1x1 降维 | 让网络自适应选择特征尺度，控制计算量 |
| ResNet | 恒等跳连 `y=x+F(x)` | 缓解深层梯度消失，网络可堆到上百层 |
| DenseNet | 密集拼接前面所有层输出 | 特征复用，梯度可直接传回浅层 |
| MobileNet | 深度可分离卷积 | 大幅降低参数量和计算量，适配移动端 |
| EfficientNet | 深度/宽度/分辨率复合缩放 | 系统化地放大网络规模，而非单维度调参 |

共同规律：**追求参数效率而非蛮力堆参数，改善优化路径而非只增加复杂度**。
