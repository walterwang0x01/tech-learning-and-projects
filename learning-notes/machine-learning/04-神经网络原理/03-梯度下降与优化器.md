## 1. 梯度下降的三种形态

反向传播（见 [反向传播推导](02-反向传播推导.md)）负责算出梯度 `∂L/∂w`，但拿到梯度之后**用多少数据算这一次梯度、多久更新一次参数**，是梯度下降算法本身要回答的问题。

```
BGD（全量）:       g = (1/N)·Σ_{i=1}^{N} ∇L(w; x_i, y_i)     # 用全部N个样本
SGD（随机）:       g = ∇L(w; x_i, y_i)                        # 随机取一个样本i
Mini-batch（小批）: g = (1/B)·Σ_{i∈batch} ∇L(w; x_i, y_i)     # 用一小批B个样本(如32~512)

统一更新规则:  w ← w - η · g
```

### 1.1 三者对比：梯度质量 vs 更新频率的权衡

| 维度 | BGD | SGD | Mini-batch |
| --- | --- | --- | --- |
| 每次更新用的样本数 | 全部 `N` | 1 | `B`（如 32~512） |
| 梯度估计方差 | 0 | 高 | 中（按 `1/B` 收缩） |
| 单步计算成本 | 高 | 极低 | 低 |
| 每 epoch 更新次数 | 1 | `N` | `N/B` |
| GPU 矩阵并行 | 可以但显存吃紧 | 无法有效利用 | 能，唯一适配现代硬件的 |
| 逃离鞍点能力 | 弱 | 强（噪声有正则效果） | 中等 |

**核心权衡**：梯度的方差和更新频率此消彼长。BGD 梯度最准但更新最少最慢；SGD 更新最快但噪声大到可能不收敛到精确最优点；Mini-batch 用适中的 batch size 把方差压到可接受范围，同时保持较高更新频率并利用 GPU 矩阵并行，是工程实践的甜点。

**"增大 batch size"不是免费的午餐**：方差降低了，但每个 epoch 的更新次数变少，且 SGD 噪声本身有一定正则化效果，batch 太大有时反而损害泛化，需配合调大学习率或用 warmup 补偿。

## 2. 动量法与 Nesterov

Mini-batch 解决了效率问题，但没解决**梯度方向本身震荡**的问题——尤其在损失函数呈"狭长峡谷"形状时（一个方向陡峭、一个方向平缓），普通梯度下降会在陡峭方向来回震荡，在平缓方向前进很慢。

### 2.1 动量法（Momentum）

给参数更新引入"惯性"，用历史梯度的指数加权平均代替当前梯度：

```
v ← β · v + (1 - β) · g          # 或写成 v ← β·v + g，效果等价
w ← w - η · v
```

`β` 通常取 0.9，表示"记住过去约 10 步的梯度方向"。震荡方向上历史梯度正负交替，累加后相互抵消；一致方向上历史梯度符号相同，累加后被放大、加速前进。就像小球滚下峡谷，靠惯性冲过局部坡坑。

### 2.2 Nesterov 动量（NAG）

普通动量先算当前位置梯度再叠加历史动量；Nesterov 改为**先按动量方向探一步，在预估位置算梯度**：

```
w_lookahead = w - η · β · v              # 先按动量方向"探路"
g = ∇L(w_lookahead)                       # 在探路位置算梯度
v ← β · v + (1 - β) · g
w ← w - η · v
```

普通动量像"闭眼冲下去，冲远了才修正"；Nesterov 像"先探路再决定走法"，能更早修正方向，减少过冲。

## 3. 自适应学习率优化器

动量解决的是"方向"问题，接下来的几个优化器解决的是**每个参数该用多大学习率**的问题——不同参数的梯度尺度可能差异巨大（比如词向量里高频词和低频词对应的梯度稀疏程度完全不同），统一用一个全局学习率并不合理。

### 3.1 AdaGrad：按历史梯度平方和缩放

```
r ← r + g²                          # 累加梯度平方（逐参数、逐元素）
w ← w - η / (√r + ε) · g
```

`r` 是每个参数各自累积的历史梯度能量。梯度经常很大的参数学习率自动变小，梯度一直很小（稀疏特征）的参数学习率相对更大，加快稀疏特征的学习。

**致命缺陷**：`r` 只增不减，训练越久 `r` 越大，`η/√r` 越接近 0，学习率单调衰减到几乎停止更新——即使后期还需要学习。这对长时间训练的深度网络不可接受。

### 3.2 RMSProp：把"累加"换成指数加权移动平均

RMSProp 只改一处：不再无限累加梯度平方，用指数衰减的移动平均让久远的梯度信息逐渐被遗忘：

```
r ← ρ · r + (1 - ρ) · g²            # ρ 通常取 0.9 或 0.99
w ← w - η / (√r + ε) · g
```

这修复了 AdaGrad 学习率衰减到 0 的问题：`r` 现在反映"最近一段时间"的梯度能量，会随梯度变化动态调整。

### 3.3 Adam：动量 + RMSProp 的结合

Adam（Adaptive Moment Estimation）同时维护梯度的**一阶矩**（均值，即动量）和**二阶矩**（未中心化方差，即 RMSProp 的 `r`）：

```
m ← β1 · m + (1 - β1) · g              # 一阶矩：梯度的移动平均（方向）
v ← β2 · v + (1 - β2) · g²             # 二阶矩：梯度平方的移动平均（尺度）

m̂ = m / (1 - β1^t)                     # 偏差修正
v̂ = v / (1 - β2^t)

w ← w - η · m̂ / (√v̂ + ε)
```

`t` 是当前时间步（从 1 开始），`β1` 通常取 0.9，`β2` 通常取 0.999。

**为什么需要偏差修正**：`m` 和 `v` 初始化为 0，训练刚开始时 `m=(1-β1)·g_1`，相比真实梯度均值明显偏小（被初始 0 拖累，是有偏估计）。除以 `(1-β1^t)` 修正：`t` 小时 `β1^t` 接近 1，除以小的 `(1-β1^t)` 把 `m` 放大到接近真实尺度；`t` 变大后 `β1^t→0`，修正因子趋近 1，修正效果自动消失。

| 矩 | 类比 | 解决的问题 |
| --- | --- | --- |
| 一阶矩 `m` | 动量 | 震荡抑制、加速一致方向 |
| 二阶矩 `v` | RMSProp 的 `r` | 逐参数自适应学习率 |

Adam 是两个问题都要解决的直接融合，这也是它成为默认选择的原因——大多数场景不需精调就有不错效果。

### 3.4 Adam 与 AdamW 的权重衰减差异（重点）

**权重衰减（weight decay）** 是一种正则化手段，目的是让参数不要变得过大，缓解过拟合。数学上等价于在损失函数里加一个 L2 惩罚项：

```
L_reg(w) = L(w) + (λ/2) · ||w||²
```

对这个新损失求梯度：

```
∇L_reg(w) = ∇L(w) + λ·w
```

### 3.4.1 Adam 里"L2 正则"是怎么被错误处理的

在原始 Adam 论文的实现里，权重衰减是通过**把 `λ·w` 加进梯度 `g` 里**实现的：

```
g ← ∇L(w) + λ·w        # 先把 L2 惩罚项混入梯度
m ← β1·m + (1-β1)·g
v ← β2·v + (1-β2)·g²
w ← w - η · m̂ / (√v̂ + ε)
```

**问题**：`λ·w` 混入 `g` 后会被二阶矩 `v` 一起做自适应缩放——权重衰减力度被 `1/√v̂` 影响：梯度历史大的参数衰减被削弱，梯度历史小的参数衰减被放大。这不是权重衰减本该有的行为：它应该对所有参数施加统一比例的收缩，不该被自适应机制稀释或放大。这就是"Adam 里 L2 正则和权重衰减不等价"的根源——在 SGD 里两者数学等价，但二阶矩的存在打破了这个等价性。

### 3.4.2 AdamW 的修正：把权重衰减从梯度自适应机制里"解耦"出来

AdamW（Decoupled Weight Decay）的做法是：**权重衰减不进入梯度、不参与一阶矩二阶矩的计算，而是在参数更新这一步单独、直接地施加**：

```
m ← β1·m + (1-β1)·g                          # g 只是原始损失梯度，不含 λw
v ← β2·v + (1-β2)·g²
m̂ = m / (1-β1^t)
v̂ = v / (1-β2^t)
w ← w - η · [ m̂ / (√v̂ + ε) + λ·w ]           # 权重衰减单独加，不经过自适应缩放
```

### 3.4.3 对比表

| | Adam（混入梯度的 L2） | AdamW（解耦权重衰减） |
| --- | --- | --- |
| `λ·w` 加在哪 | 加进 `g`，被 `m,v` 累积和缩放 | 更新公式单独一项，不经过 `m,v` |
| 是否被自适应学习率缩放 | 是（力度不均匀） | 否（对所有参数一致比例收缩） |
| 现代实践 | 基本弃用 | Transformer/LLM 训练的标准选择 |

**这是实践中最容易踩的坑**：很多人以为"用了 Adam 加 `weight_decay` 就等于加了正则化"，但如果框架用的是原始 Adam 实现（而非 AdamW），正则化力度会被自适应机制扭曲。PyTorch 里 `torch.optim.Adam(weight_decay=...)` 和 `torch.optim.AdamW(weight_decay=...)` 是两个不同实现，混用会导致"调了 weight_decay 却没什么效果"的困惑。

## 4. 优化器选型建议

| 场景 | 建议 | 理由 |
| --- | --- | --- |
| 默认起点 | Adam 或 AdamW | 收敛快、对学习率不敏感、鲁棒性好 |
| 需要权重衰减/L2正则 | AdamW，不用 Adam 的 `weight_decay` | 3.4 节的解耦问题 |
| 大模型/Transformer 训练 | AdamW | 行业标准配置 |
| 追求泛化、可承受调参成本 | SGD + Momentum，配合仔细调的学习率衰减 | 部分场景报告过更好的泛化，但不普适，依赖调参质量 |
| 梯度非常稀疏（如推荐系统embedding） | AdaGrad 或 Adam | 自适应学习率对稀疏梯度更友好 |
| 调参资源有限 | Adam（默认 `β1=0.9, β2=0.999` 基本能用） | 对超参数不敏感 |

> ⚠️ 待确认：不同优化器在具体任务上的精度/收敛速度排名依赖任务、模型结构和数据规模，不给出具体性能数字对比，只给方法论层面的选型依据。

## 5. 最小可运行实现

用 NumPy 实现 SGD、Momentum、RMSProp、Adam、AdamW 五种优化器，在同一个简单的二次函数（模拟"窄峡谷"损失面）上对比收敛轨迹，直观展示动量抑制震荡、自适应学习率加速收敛的效果。

```python
import numpy as np


def loss_and_grad(w):
    """狭长峡谷型损失函数 L=0.5*w1^2+25*w2^2：w1方向平缓，w2方向陡峭"""
    loss = 0.5 * w[0] ** 2 + 25 * w[1] ** 2
    grad = np.array([w[0], 50 * w[1]])
    return loss, grad


def run_sgd(w0, steps=60, lr=0.02):
    w = w0.copy(); path = [w.copy()]
    for _ in range(steps):
        _, g = loss_and_grad(w)
        w = w - lr * g
        path.append(w.copy())
    return np.array(path)


def run_momentum(w0, steps=60, lr=0.02, beta=0.9):
    w = w0.copy(); v = np.zeros_like(w); path = [w.copy()]
    for _ in range(steps):
        _, g = loss_and_grad(w)
        v = beta * v + (1 - beta) * g
        w = w - lr * v
        path.append(w.copy())
    return np.array(path)


def run_rmsprop(w0, steps=60, lr=0.05, rho=0.9, eps=1e-8):
    w = w0.copy(); r = np.zeros_like(w); path = [w.copy()]
    for _ in range(steps):
        _, g = loss_and_grad(w)
        r = rho * r + (1 - rho) * g ** 2
        w = w - lr * g / (np.sqrt(r) + eps)
        path.append(w.copy())
    return np.array(path)


def run_adam(w0, steps=60, lr=0.1, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.0, decoupled=False):
    """decoupled=False 为原始Adam的L2混入梯度方式；decoupled=True 即 AdamW"""
    w = w0.copy()
    m = np.zeros_like(w)
    v = np.zeros_like(w)
    path = [w.copy()]
    for t in range(1, steps + 1):
        _, g = loss_and_grad(w)
        if weight_decay > 0 and not decoupled:
            g = g + weight_decay * w  # Adam方式：L2混入梯度，被v自适应缩放

        m = beta1 * m + (1 - beta1) * g
        v = beta2 * v + (1 - beta2) * g ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)

        update = m_hat / (np.sqrt(v_hat) + eps)
        if weight_decay > 0 and decoupled:
            update = update + weight_decay * w  # AdamW方式：权重衰减独立于m,v

        w = w - lr * update
        path.append(w.copy())
    return np.array(path)


if __name__ == "__main__":
    w0 = np.array([1.0, 1.0])  # 起点，w2 方向陡峭
    paths = {"SGD": run_sgd(w0), "Momentum": run_momentum(w0),
             "RMSProp": run_rmsprop(w0), "Adam": run_adam(w0)}

    print("对比4种优化器在窄峡谷损失面上的收敛效果（起点[1.0,1.0]，60步后）：")
    print(f"{'优化器':<10}{'最终w1':>10}{'最终w2':>10}{'最终loss':>12}")
    for name, path in paths.items():
        final = path[-1]
        loss, _ = loss_and_grad(final)
        print(f"{name:<10}{final[0]:>10.4f}{final[1]:>10.4f}{loss:>12.6f}")

    print("\n验证Adam与AdamW权重衰减差异（起点[3.0,3.0]，weight_decay=0.1，100步后）：")
    w_start = np.array([3.0, 3.0])
    path_adam_l2 = run_adam(w_start, steps=100, lr=0.05, weight_decay=0.1, decoupled=False)
    path_adamw = run_adam(w_start, steps=100, lr=0.05, weight_decay=0.1, decoupled=True)
    print(f"{'':<12}{'w1终值':>12}{'w2终值':>12}")
    print(f"{'Adam(L2)':<12}{path_adam_l2[-1][0]:>12.6f}{path_adam_l2[-1][1]:>12.6f}")
    print(f"{'AdamW':<12}{path_adamw[-1][0]:>12.6f}{path_adamw[-1][1]:>12.6f}")
```

实测输出（numpy 2.4.4）：

```
对比4种优化器在窄峡谷损失面上的收敛效果（起点[1.0,1.0]，60步后）：
优化器          最终w1      最终w2        最终loss
SGD            0.2976    0.0000    0.044269
Momentum       0.2951    0.0381    0.079763
RMSProp        0.0000    0.0000    0.000000
Adam          -0.0347   -0.0347    0.030627

验证Adam与AdamW权重衰减差异（起点[3.0,3.0]，weight_decay=0.1，100步后）：
              w1终值        w2终值
Adam(L2)     0.056599    0.056599
AdamW       -0.005672   -0.005672
```

结果验证两点：一是 RMSProp 在此二次损失面上收敛最彻底（两方向都精确到0）；SGD 因无自适应机制，`w2` 已收敛时 `w1` 仍停留在0.298；Momentum 在此学习率下于 `w2` 方向轻微超调（0.038），是动量惯性的代价；Adam 因偏差修正在起步阶段的影响，60步内未追上 RMSProp 精度。二是 Adam(L2) 与 AdamW 权重衰减后的参数值符号和量级不同（`0.0566` vs `-0.0057`），印证两种方式的收缩效果本质不同——AdamW 的解耦收缩更接近"统一比例衰减"的设计意图。

> 不同优化器超参数的选择对收敛轨迹影响很大，"谁更快"不是绝对的，本例目的是展示机制差异，不是性能排名。

## 6. 小结

| 要点 | 内容 |
| --- | --- |
| BGD/SGD/Mini-batch | 梯度方差与更新频率的权衡，Mini-batch 是工程实践的平衡点 |
| Momentum | 用历史梯度指数加权平均抑制震荡、加速一致方向 |
| Nesterov | 先按动量探路再算梯度，比普通动量更早修正方向 |
| AdaGrad | 逐参数按历史梯度平方和缩放学习率，但学习率单调衰减到 0 |
| RMSProp | 用指数加权移动平均替代 AdaGrad 的无限累加，修复衰减到 0 的问题 |
| Adam | 一阶矩（动量）+ 二阶矩（RMSProp）+ 偏差修正的融合，默认首选 |
| Adam 权重衰减问题 | L2 惩罚混入梯度，被二阶矩自适应缩放，力度不均匀且失真 |
| AdamW 的修正 | 权重衰减解耦，独立于 `m, v` 之外按固定比例收缩，是现代标准做法 |
