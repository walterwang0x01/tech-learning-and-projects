## 1. 为什么需要非线性激活函数

先明确一个前提：如果网络每一层都只做线性变换（`z = Wx + b`），不加任何非线性激活，无论堆多少层，整个网络等价于**一次**线性变换：

```
z2 = W2·(W1·x + b1) + b2 = (W2·W1)·x + (W2·b1 + b2) = W'·x + b'
```

多层的表达能力退化成了一层。这也呼应 [感知机与多层感知机](01-感知机与多层感知机.md) 的结论——MLP 解决 XOR 靠的正是隐藏层的**非线性**映射，如果去掉激活函数中的非线性部分，MLP 会退化回单层感知机的能力上限。激活函数的非线性正是深度网络表达能力的来源。

## 2. Sigmoid 与 Tanh 的饱和问题

### 2.1 Sigmoid

```
σ(z) = 1 / (1 + e^(-z))
σ'(z) = σ(z) · (1 - σ(z))
```

`σ'(z)` 的最大值在 `z=0` 处，值为 `0.25`；当 `|z|` 较大时（比如 `z > 4` 或 `z < -4`），`σ(z)` 已经非常接近 0 或 1，此时 `σ'(z) ≈ 0`。这个"输出趋于常数、导数趋于 0"的区域就叫**饱和区**。

**饱和的后果**：反向传播时，误差项要乘以 `σ'(z)`（见 [反向传播推导](02-反向传播推导.md) 第 3 节）。一旦某个神经元的输入落进饱和区，`σ'(z) ≈ 0`，这个神经元几乎不再接收到任何梯度信号——即使它的输出是错的，也没法通过梯度下降去纠正它，这个神经元实质上"死"在了当前状态。层数越多，这种效应通过连乘会被放大，这正是梯度消失的一个主要来源。

### 2.2 Tanh

```
tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z)) = 2σ(2z) - 1
tanh'(z) = 1 - tanh(z)²
```

Tanh 是 Sigmoid 的缩放平移版本，输出范围 `(-1, 1)`，零中心化（输出均值接近0），这比 Sigmoid 稍好——零中心化的输出让下一层输入分布更均衡，利于优化。但 Tanh 同样存在两端饱和问题：`|z|` 较大时 `tanh'(z)→0`，本质是同一个"S形曲线两端压平"的问题。

两者共同问题：

| 问题 | 具体表现 |
| --- | --- |
| 两端饱和 | `\|z\|` 大时导数趋于0，梯度传不下去 |
| 输出非零中心（Sigmoid） | 下一层输入总为正，权重更新方向受限 |
| 计算涉及指数运算 | 比 ReLU 的简单比较运算慢 |

## 3. ReLU 与死亡 ReLU

### 3.1 ReLU（Rectified Linear Unit）

```
ReLU(z) = max(0, z)
ReLU'(z) = { 1  if z > 0
           { 0  if z ≤ 0
```

**ReLU 解决了什么**：正区间的导数恒为 `1`，不存在"越乘越小"的衰减问题——这是 ReLU 能让深层网络训练起来的关键原因（对比第 2 节，Sigmoid 每层最多贡献 `0.25` 的衰减因子，10 层下来梯度剩不到百万分之一；ReLU 正区间完全没有这个衰减）。同时计算极简单（一次比较），没有指数运算，速度快。

### 3.2 死亡 ReLU（Dying ReLU）

**问题出在负区间**：一旦某个神经元的加权输入 `z` 因某次参数更新变成负数，`ReLU'(z)=0`，这个神经元的梯度就恒为 0——不管后续输入是什么，参数**再也不会被更新**，永久停在"输出恒为0"的状态。这就是死亡 ReLU。

常见诱因：学习率过大把权重推到对所有样本都输出负值的区域；初始化不当导致一开始就有大量神经元 `z<0`；数据分布导致某些神经元系统性地接收负输入。

**实际影响**：如果网络里相当比例的神经元"死亡"，等价于网络的有效容量在训练过程中不断萎缩，最终性能受损。

### 3.3 LeakyReLU / PReLU / ELU 的修复思路

三者共同目标：给负区间也留一点非零梯度，避免神经元彻底死亡。

**LeakyReLU**：负区间给一个很小的固定斜率 `α`（如 0.01）：

```
LeakyReLU(z) = { z        if z > 0
               { α·z      if z ≤ 0      (α 是固定小常数)
```

负区间导数恒为 `α`（非0），神经元进入负区间后仍能收到微弱梯度，有机会被救活。

**PReLU（Parametric ReLU）**：把固定的 `α` 换成**可学习参数**，让网络自己决定负区间斜率：

```
PReLU(z) = { z        if z > 0
           { α·z      if z ≤ 0      (α 通过梯度下降学习)
```

比 LeakyReLU 更灵活，但多了要学习的参数，也多了一点过拟合风险。

**ELU（Exponential Linear Unit）**：负区间是指数曲线，会**饱和到一个负常数** `-α`，而非线性发散：

```
ELU(z) = { z                  if z > 0
         { α·(e^z - 1)        if z ≤ 0
```

负区间在 `z→-∞` 时趋近 `-α`（有下界），输出均值更接近0（利于优化），负区间处处可导、非零。代价是含指数运算，比 ReLU/LeakyReLU 慢。

### 3.4 三者对比

| | 负区间形式 | 是否有下界 | 额外参数 | 计算成本 |
| --- | --- | --- | --- | --- |
| LeakyReLU | 固定小斜率线性 | 无下界 | 无（`α` 是超参数） | 低 |
| PReLU | 可学习斜率线性 | 无下界 | 有（`α` 参与训练） | 低 |
| ELU | 指数曲线，饱和到 `-α` | 有下界 | 无（`α` 是超参数，常固定为1） | 较高（有指数运算） |

## 4. GELU：Transformer 的标配

### 4.1 定义

```
GELU(z) = z · Φ(z)
```

`Φ(z)` 是标准正态分布的累积分布函数（CDF）。直觉上，GELU 可以理解为：**以一个和输入值大小相关的"概率" `Φ(z)` 来决定要不要让这个神经元通过**，而不是 ReLU 那种"大于0全通过、小于0全砍掉"的硬开关。

实践中 `Φ(z)` 没有闭式解，常用 tanh 近似计算：

```
GELU(z) ≈ 0.5 · z · [1 + tanh(√(2/π) · (z + 0.044715·z³))]
```

### 4.2 为什么 GELU 比 ReLU 更适合 Transformer

| 特性 | ReLU | GELU |
| --- | --- | --- |
| 负区间 | 硬截断为 0 | 平滑过渡，小负值仍有非零输出 |
| 在 0 附近的形状 | 尖角（不可导点） | 平滑曲线，处处可导 |
| "开关"逻辑 | 确定性（`z>0` 就通过） | 概率性（`z` 越大越可能通过） |

**关键区别是平滑性和非单调性**：ReLU 在 `z=0` 处有尖角（导数不连续），GELU 处处光滑。对于依赖大量堆叠自注意力和前馈层、靠梯度做精细优化的 Transformer 架构，光滑激活函数在实践中表现出更稳定的优化行为。同时 GELU 在负区间保留了少量"softly gated"信息，而不是像 ReLU 一样直接归零——类似给网络一种依概率决定"信息保留多少"的机制，而非简单的 0/1 开关。

> ⚠️ 待确认：GELU 相比 ReLU 在具体任务上的性能提升数字不在本文讨论范围，只说明设计动机差异。

## 5. SiLU / Swish

```
SiLU(z) = Swish(z) = z · σ(z)
```

`σ(z)` 是标准 Sigmoid。SiLU 和 GELU 长得很像——都是"`z` 乘以一个 0~1 之间的门控值"的形式，区别只是门控函数用 Sigmoid 还是正态 CDF。两者曲线形状高度相似，都是平滑、非单调（负区间会先降后升），都不是简单的分段线性函数。

`SiLU` 和 `Swish` 在大多数资料里指同一个函数（`Swish` 最初提出的形式还带可学习缩放参数 `β`：`z·σ(βz)`，`β=1` 时就是 `SiLU`）。

## 6. SwiGLU：现代 LLM 的门控变体

### 6.1 GLU（Gated Linear Unit）机制

在讲 SwiGLU 之前，先理解"门控（gating）"这个更通用的思路。GLU 的核心是**用一部分输入去控制另一部分输入能通过多少**：

```
GLU(x) = (x·W1) ⊙ σ(x·W2)
```

`⊙` 是逐元素相乘。`x·W1` 是"内容"分支，`σ(x·W2)` 是"门"分支（值在 0~1 之间），两者相乘实现"门控制内容通过比例"的效果。这比单纯过一个激活函数多了一路**可学习的、依赖输入内容的开关**。

### 6.2 SwiGLU 的定义

SwiGLU 把 GLU 里的门控激活换成 SiLU/Swish：

```
SwiGLU(x) = (x·W1) ⊙ SiLU(x·W2)
          = (x·W1) ⊙ [(x·W2) · σ(x·W2)]
```

在 Transformer 的前馈网络（FFN）里，SwiGLU 通常这样替换原来的两层 MLP：

```
传统 FFN:   FFN(x) = W2 · ReLU(W1·x + b1) + b2

SwiGLU FFN: FFN(x) = W2 · [SiLU(x·W_gate) ⊙ (x·W_up)] + b2
```

### 6.3 为什么要用三个权重矩阵（门控的代价与收益）

注意 SwiGLU 版本的 FFN 需要**三个**权重矩阵（`W_gate`、`W_up`、`W2` 对应"门控投影""内容投影""输出投影"），而传统 FFN 只需要两个（`W1`、`W2`）。为了保持总参数量大致持平，实践中会把隐藏层维度调小一些（比如常见做法是把中间维度设为原来的 `2/3` 左右）来补偿多出来的这一路投影，具体缩放系数依实现而定。

**收益**：门控机制让网络能够**学习"该保留多少信息"**，而不是激活函数结构固定死板地对所有输入一视同仁。`x·W_gate` 分支学习"控制信号"，`x·W_up` 分支学习"内容"，两者相乘赋予了模型更细粒度的信息流控制能力。这是"门控"这个思路（从 LSTM 的门、到 GLU、再到 SwiGLU）反复被证明有效的核心逻辑：**让网络自己学会控制信息流，而不是用固定规则强行截断或通过**。

> ⚠️ 待确认：SwiGLU 相比传统 FFN 在具体基准上的性能提升数字不在本文讨论范围，只说明其设计动机。

## 7. 激活函数选型对照表

| 激活函数 | 计算复杂度 | 是否存在饱和 | 负区间处理 | 典型使用场景 |
| --- | --- | --- | --- | --- |
| Sigmoid | 高（指数） | 两端饱和 | 输出趋于0 | 二分类输出层、门控（LSTM门） |
| Tanh | 高（指数） | 两端饱和 | 输出趋于-1 | RNN隐藏状态（历史常见） |
| ReLU | 极低（比较） | 仅负区间"饱和"（恒0） | 硬截断为0，可能死亡 | CNN、传统深层网络的默认起点 |
| LeakyReLU | 低 | 无 | 固定小斜率线性 | 担心死亡ReLU时的直接替代 |
| PReLU | 低（多可学习参数） | 无 | 可学习斜率线性 | 数据量足够支撑额外参数时 |
| ELU | 较高（指数） | 负区间饱和到-α | 指数曲线，有下界 | 需要零中心输出、可承受计算成本时 |
| GELU | 高 | 无硬饱和，平滑过渡 | 平滑软门控 | Transformer/LLM 前馈层的常见选择 |
| SiLU/Swish | 中（一次Sigmoid） | 无硬饱和 | 平滑软门控 | 部分 CV/LLM 架构的前馈层 |
| SwiGLU | 中高（含门控矩阵乘法） | 无硬饱和 | 可学习门控 | 现代主流 LLM 的前馈层 |

## 8. 最小可运行实现

用 NumPy 实现本文提到的全部激活函数，绘制数值对比表（用文本形式展示曲线形状差异），并演示死亡 ReLU 现象及 LeakyReLU 的修复效果。

```python
import numpy as np


def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
def tanh(z): return np.tanh(z)
def relu(z): return np.maximum(0, z)
def leaky_relu(z, alpha=0.01): return np.where(z > 0, z, alpha * z)
def elu(z, alpha=1.0): return np.where(z > 0, z, alpha * (np.exp(z) - 1))


def gelu_tanh_approx(z):
    """GELU 的 tanh 近似形式"""
    return 0.5 * z * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (z + 0.044715 * z ** 3)))


def silu(z):
    return z * sigmoid(z)


# ---- 1. 打印几个关键点的函数值，直观对比曲线形状 ----
z_test = np.array([-3.0, -1.0, -0.1, 0.0, 0.1, 1.0, 3.0])

print("激活函数在关键点的取值对比：")
print(f"{'z':>6}" + "".join(f"{name:>12}" for name in
      ["Sigmoid", "Tanh", "ReLU", "LeakyReLU", "ELU", "GELU", "SiLU"]))
for zi in z_test:
    vals = [sigmoid(zi), tanh(zi), relu(zi), leaky_relu(zi), elu(zi),
            gelu_tanh_approx(zi), silu(zi)]
    print(f"{zi:>6.1f}" + "".join(f"{v:>12.4f}" for v in vals))

# ---- 2. 验证 Sigmoid/Tanh 的饱和：导数在大 |z| 时趋于 0 ----
def sigmoid_grad(z):
    s = sigmoid(z)
    return s * (1 - s)


def tanh_grad(z): return 1 - tanh(z) ** 2


print("\n验证饱和现象：|z| 增大时导数趋近 0")
for zi in [0.0, 2.0, 4.0, 6.0, 10.0]:
    print(f"  z={zi:>5.1f}  sigmoid'(z)={sigmoid_grad(zi):.6f}  tanh'(z)={tanh_grad(zi):.6f}")

# ---- 3. 模拟死亡 ReLU：一旦权重把某神经元推入负区间，梯度恒为0 ----
print("\n模拟死亡 ReLU 现象：")
rng = np.random.default_rng(0)
x = rng.normal(0, 1, (100, 5))

w_dead = np.array([-5.0, -5.0, -5.0, -5.0, -5.0])  # 权重全负，模拟训练中被推向极端的情形
b_dead = -2.0

z_dead = x @ w_dead + b_dead
relu_out = relu(z_dead)
relu_grad_mask = (z_dead > 0).astype(float)
dead_ratio_relu = 1.0 - relu_grad_mask.mean()
print(f"  ReLU: {dead_ratio_relu*100:.1f}% 的样本落在负区间（该神经元对这些样本梯度为0）")

leaky_out = leaky_relu(z_dead)
neg_mask = z_dead <= 0
print(f"  LeakyReLU: 负区间梯度固定为 0.01（非0），该神经元仍可能被训练修正")
print(f"  ReLU在负区间的输出（前5个负样本): {np.round(relu_out[neg_mask][:5], 3)}")
print(f"  LeakyReLU在负区间的输出（前5个负样本): {np.round(leaky_out[neg_mask][:5], 3)}")
```

## 9. 小结

| 要点 | 内容 |
| --- | --- |
| 非线性必要性 | 无非线性激活，多层网络退化为一层线性变换 |
| Sigmoid/Tanh饱和 | `\|z\|`大时导数趋近0，是梯度消失的主要来源之一 |
| ReLU | 正区间导数恒为1，解决梯度消失，负区间硬截断可能导致神经元死亡 |
| LeakyReLU/PReLU/ELU | 分别用固定小斜率、可学习斜率、指数饱和曲线，给负区间保留非零梯度 |
| GELU | `z·Φ(z)`，平滑概率门控，Transformer前馈层常见选择 |
| SiLU/Swish | `z·σ(z)`，与GELU形状相似，均为平滑非单调 |
| SwiGLU | GLU机制+SiLU，可学习门控，现代LLM前馈层常见选择 |
| 选型原则 | 默认ReLU/GELU起步；关心死亡神经元用LeakyReLU/ELU；大模型前馈层考虑SwiGLU |
