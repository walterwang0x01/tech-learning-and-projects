### 小米招聘 Agent 上线，国产大模型开始把 API 嵌进自家业务

5 月 28 日，小米招聘官网正式上线「小米招聘 Agent」，依托 Xiaomi MiMo 大模型，提供政策解答、岗位智能推荐、招聘进展查询，用户上传简历后会被自动解析教育背景、项目经历和技能栈，再去匹配在招岗位。这条消息单看是一个 HR 工具升级，放进上下文却很关键：MiMo 系列上周刚把 API 永久降价 99% 对标 DeepSeek，一边压价拉开发者，一边把模型反向接到自家最高频的招聘场景。国产模型公司过去一年讲的故事是「便宜的 API」，今年明显在分裂——卷 API 的继续卷，做出自家产品的厂商开始用「场景化 Agent」证明模型真的能跑业务。如果你是国产模型选型方，可以重新看一眼这些公司的 demo 落地能力，而不是只比 token 单价。

### 黄仁勋评华为「韬定律」：是突破，但威胁不到台积电

ISCAS2026 上华为发表「韬定律」（Tau Scaling Law）一天后，黄仁勋 5 月 28 日在台北「万亿美元晚宴」之后接受台媒采访，对这套以「时间缩微」替代「几何缩微」的系统级路线给出第一手评价：「对华为来说是突破，但对台积电并不是威胁。」他的论据是台积电做芯片堆叠和 3D 封装已经接近 10 年，而华为这一套用超细混合键合（间距 1.5 微米）做 LogicFolding，可以在不缩线宽的情况下把麒麟 2026 的晶体管密度做到 +55%，从 PPT 走到流片是另一码事。两面信号都重要：技术上得到正面承认；但市场份额上，黄仁勋判断台积电护城河仍在。北大也在同期推出针对 LogicFolding 架构的国产 3D 芯片设计工具，国产侧已经开始把工具链补齐。如果你在跟踪国产算力替代节奏，这一周从 ISCAS 论文 → 黄仁勋表态 → 国产 EDA 工具，是一个完整事件链。

→ [IT之家原文](https://www.ithome.com/0/956/852.htm) / [Tom's Hardware 北大工具](https://www.tomshardware.com/tech-industry/semiconductors/peking-university-builds-3d-chip-design-tool-tailored-to-huaweis-logicfolding-architecture) / [Huang IEEE 演讲实录](https://substack.com/home/post/p-199457051)
