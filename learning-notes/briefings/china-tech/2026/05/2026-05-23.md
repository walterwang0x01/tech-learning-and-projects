### DeepSeek 700 亿融资创纪录，梁文锋摊牌：AGI 优先于商业化

DeepSeek 正在推进一轮高达 700 亿元人民币（约 100 亿美元）的融资，规模从最初的 500 亿元上调至 700 亿元，估值被外媒定到 450 亿美元上下，将是中国科技初创公司首轮融资的最高纪录。最受关注的不是钱，而是创始人梁文锋向投资者明牌：通用人工智能（AGI）的远大目标优先于短期商业化变现。配合昨天 DeepSeek 挂出 Harness 团队招聘、产品线代号 DeepSeek Code，由 ACM 金牌大神崔添翼挂帅，公式「Model + Harness = Agent」第一次有了产品落地路径——这家国内开源派系的领头羊不再只发模型权重，而是要把工程外壳自己做掉，正面对标 Claude Code。对国内做 LangGraph + MCP 的同学来说，DeepSeek Code 上线后是国产侧第一个真正能拿来对标 Claude Code 的 Coding Agent 产品。

→ [开源中国融资详情](https://www.oschina.net/news/444326) / [量子位 Code 团队披露](https://www.qbitai.com/2026/05/422624.html) / [Decrypt 解读](https://decrypt.co/368689/deepseek-code-harness-claude-code-alternative-china-ai)

### 智谱 GLM-5.1 高速版 400 tokens/s 破全球大模型 API 速度纪录

智谱 5/22 面向部分企业客户上线 GLM-5.1-highspeed API，输出速度做到 400 tokens/s，号称打破了全球大模型官方接口端到端速度纪录。资本市场反应直接：港股盘中飙涨 22% 以上，市值站稳 4500 亿港币。技术侧由智谱与 TileRT 团队联合的高性能推理引擎驱动，在保留旗舰 GLM-5.1 全部能力的前提下把首字延迟压到「即问即答」。这条线对国内做实时语音 / 实时编程 / 商业决策类 Agent 的团队意义直接——之前国产模型在长上下文任务里「回答得不错但等不起」的痛点，第一次有了顶速解法。同一天阿里云上线「千问云」www.qianwenai.com，把 Qwen / GLM / Kimi / DeepSeek 等 150+ 模型 API 全部封装成 Skills + CLI 给 Agent 调用——国内 AI Infra 战场从「卡」打到了「Token」打到了「Skill」。

→ [开源中国 GLM-5.1 高速版](https://www.oschina.net/news/444203) / [量子位评测](https://www.qbitai.com/2026/05/422511.html) / [InfoQ 千问云解读](https://www.infoq.cn/article/zvEY7iEgQOTcIlXDPJ0i)
