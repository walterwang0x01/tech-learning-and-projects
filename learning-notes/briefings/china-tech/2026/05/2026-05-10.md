## 📌 头条

### 百度文心 5.1 以 6% 预训练成本登顶 LMArena 搜索榜，Agent 能力超过 DeepSeek

5 月 9 日百度发布新一代基础大模型文心 5.1，核心卖点不是规模，是经济性——采用「多维弹性预训练」，**预训练成本仅为业界同规模模型的 6%**，却在 LMArena 搜索榜拿到国内第一，Agent、知识、推理和深度搜索四个维度都同步抬升，其中 Agent 能力被官方标注「超过 DeepSeek」。模型已全量上线百度千帆、文心官网，面向企业和开发者开放体验。放在这一周的国产头部节奏里看，这是一次很明显的打法分岔：DeepSeek 忙着融资 + 加快迭代节奏（V4.1 定在 6 月），蚂蚁在堆万亿参数，百度选择把训练成本这条曲线拉下来——对自部署预算有限的团队来说，6% 的成本数字意味着「复训练一次文心 5.1 只要 DeepSeek 的一个零头」，是一个该立刻跑 benchmark 对比的信号。

### 蚂蚁百灵开源万亿级思考模型 Ring-2.6-1T，可调节 Reasoning Effort

蚂蚁百灵同日放出 Ring-2.6-1T，一款面向真实复杂工作流的万亿级旗舰思考模型，权重开源，限时一周免费体验。和以往纯追 benchmark 的思路不同，这代模型核心亮点是「可调节 Reasoning Effort」机制：支持 high 和 xhigh 两档推理强度，让工程侧能按任务难度动态切换，避免每个 prompt 都烧满 token。OpenRouter 和 Hugging Face 同步上线（inclusionAI/Ring-2.6-1T），激活参数约 63B，走的是 hybrid linear attention + MoE 路线。对做 agent 工作流的团队最实际的价值是两点：一是开放权重终于把「可调推理强度」做到了自部署栈，二是万亿级模型在开源线上的密度又抬了一档——过去一周国产开源已经堆了 DeepSeek V4（1.6T）、腾讯 Hy3（295B）、Ring-2.6-1T（1T）三个巨头。这周值得对这三家的长推理任务做一次横评。

→ [开源中国](https://www.oschina.net/news/438166) / [OpenRouter](https://openrouter.ai/inclusionai/ring-2.6-1t:free) / [Hugging Face](https://huggingface.co/inclusionAI/Ring-2.5-1T)
