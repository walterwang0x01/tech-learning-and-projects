## 📌 头条

### 蚂蚁百灵把万亿参数推理模型 Ring-2.6-1T 直接开源，押注 Agent 执行力

5 月 15 日，蚂蚁百灵正式开源旗舰推理模型 Ring-2.6-1T，1 万亿参数 / 63B 激活的 MoE 架构，已上传 Hugging Face（[inclusionAI/Ring-2.6-1T](https://huggingface.co/inclusionAI/Ring-2.6-1T)）并接入 SiliconFlow、OpenRouter。和上一代不同，这次官方把卖点彻底从"刷分"切换到"真实复杂任务执行力"——AIME 26 拿到 95.83，PinchBench 87.60 超过 GPT-5.4 xHigh 与 Gemini-3.1-Pro，但更值得关注的是它内置了"动态思考强度"机制，可以按任务复杂度切档调度算力。结合同日 InfoQ 的解读"兼顾效率、成本与能力"，蚂蚁这一刀是冲着 agent 工作流里"长链路任务跑不动"的痛点去的。对国内做 LangGraph / Agent 编排的开发者，这是过去半年第一个值得直接拉下来跑工具链的国产开源旗舰，建议先在 OpenRouter 免费档跑一组多步推理基线再定。

### 阿里 Qoder 1.0：从 AI IDE 一步迈到"智能体自主开发工作台"

阿里正式发布 Qoder 1.0，定位也变了——不再是"在 IDE 里给你建议"，而是"Agent 团队自动驾驶完成需求"。Quest 从 IDE 内的一个模式升级为独立视窗，把任务管理、状态追踪、产物审查、知识调用做成一整套工作面板，开发者只负责定义需求，Agent 负责执行 + 验证 + 交付。Windows / macOS / Linux 三端同步开放下载（[qoder.com](https://qoder.com/en)）。1.0 版本同时引入"团队知识引擎"，官方宣称代码留存率提升 11%、对话轮次减少 33%。这是国内第一个把"agentic coding"从 IDE 助手位置抬到"独立工作台"位置的大厂产品，节奏上抢在了下周即将 GA 的 Spring AI 2.0 之前——对照同日 OpenAI Codex 进 ChatGPT 移动端、xAI 发布 Grok Build CLI，agentic coding 的产品形态正在快速分化为"独立工作台 / IDE 内嵌 / 移动端 / CLI"四条路。如果你已经在用 Claude Code 或 Cursor，值得花一晚把同一个真实任务在 Qoder 1.0 跑一遍做横向比较。
