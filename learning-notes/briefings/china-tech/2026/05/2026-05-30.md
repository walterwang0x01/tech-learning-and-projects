## 📌 头条

### 国家大基金领投 DeepSeek 首轮融资，投前估值 450 亿美元

成立三年、一直靠自有资金运转的 DeepSeek 终于打开了对外融资的大门，由国家集成电路产业投资基金（大基金）领投，投前估值约 450 亿美元，本轮规模约 700 亿元人民币。一个月内估值从约 100 亿美元一路飙到 450 亿，背后是腾讯、宁德时代等多方传闻入局。最值得读懂的不是数字本身，而是信号：当国家半导体平台亲自下场领投一家模型公司，说明 DeepSeek 已经被放进了「算力—芯片—模型」国家全栈战略里，而不只是一家明星创业公司。对开发者来说，一个不缺钱、又绑定国产算力的 DeepSeek，意味着后续开源模型的迭代节奏和长期投入更有保障。

→ [原文](https://www.oschina.net/news/448081) / [Reuters](https://www.reuters.com/world/asia-pacific/deepseek-nears-45-billion-valuation-chinas-big-fund-leads-investment-talks-ft-2026-05-06/)

### 阶跃星辰开源 Step 3.7 Flash，主打 Agent 生产化

阶跃星辰正式发布并开源 Step 3.7 Flash，采用稀疏 MoE 架构，总参数 196B、激活仅 11B，最高生成速度可达 400 Tokens/s，原生多模态可直接解析 UI 界面、图表和文档。官方把它明确定位为「面向 Agent 生产化阶段」的模型，主攻高频 Agent、Coding Agent、Search Agent 这类对延迟敏感的场景。模型已上架 Hugging Face，并提供 GGUF、NVFP4 量化版本，海光信息当天就完成了适配。对在做 Agent 的人来说，11B 激活参数 + 400 t/s 的组合意味着同样预算下能跑更多轮工具调用，把「能力够用」和「成本可控」往中间拉了一把。

→ [原文](https://www.oschina.net/news/447775) / [Hugging Face](https://huggingface.co/stepfun-ai/Step-3.7-Flash)
