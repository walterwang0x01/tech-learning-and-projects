## 📌 头条

### 阿里云峰会：Qwen3.7-Max 跑通 35 小时长程 Agent，平头哥镇午 M890 配套上线

通义实验室在 5/20 阿里云峰会上正式发布 Qwen3.7-Max，定位是国内首款专门面向智能体时代的旗舰基座，主打 35 小时内自主调用上千次工具的长程任务能力，盲测在国产模型里排第一。同步发布的还有平头哥镇午 M890 AI 芯片，官方披露 Qwen3.7-Max 在 M890 上完成 35 小时优化任务后性能提升 10 倍，超过 GLM 5.1 与 Kimi K2。这条线和昨天百度昆仑芯+文心 5.1 万卡训练是同一个剧本：国产芯片+国产模型+国产 Agent 栈正在彼此咬合。对在做 LangGraph + MCP 长程任务的同学，Qwen3.7-Max 上线 API 后可以直接拿来对标 Claude Sonnet 4.x，看长程稳定性和工具调用错误率。

→ [开源中国](https://www.oschina.net/news/443099) / [aibase 评测](https://news.aibase.com/news/28161) / [moomoo 峰会快讯](https://www.moomoo.com/news/post/70291620/alibaba-cloud-summit-launches-zhenwu-m890-ai-chip-and-debuts)

### DeepSeek 组建 Harness 团队，「Model + Harness = Agent」直面 Claude Code

DeepSeek 在 5/19 挂出 Harness 产品经理与研发工程师两个北京岗位，目标产品代号「DeepSeek Desktop Agent」，对外可能以「DeepSeek Code」品牌发布。招聘文本第一次把公司路线写成公式：Model + Harness = Agent，意思是不再单卷模型权重，而是要把上下文管理、工具调用、终端执行这层「工程外壳」自己做掉，正面对标 Claude Code、Cursor、Codex。这是国内开源派系第一次明牌做 Coding Agent 产品而非只发模型——结合昨天字节 veRL Uni-Agent、阿里 AgentScope Java 1.1.0 的 Harness 框架，2026 上半年国内 Agent 工程化的主战场已经从「编排框架」转到「桌面产品」。

→ [开源中国](https://www.oschina.net/news/443198) / [the-decoder 解读](https://the-decoder.com/deepseek-wants-to-take-on-claude-code-and-openais-codex-with-deepseek-code/) / [aibase 详情](https://news.aibase.com/news/28178)
