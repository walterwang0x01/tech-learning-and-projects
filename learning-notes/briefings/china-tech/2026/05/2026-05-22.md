### 千问 3.7-Max 登顶 Artificial Analysis 国产榜，全球第五超 Gemini 3.5 Flash

昨天阿里云峰会发布的 Qwen3.7-Max 这两天榜单结果出来了：在第三方独立评测 Artificial Analysis Intelligence Index 上拿到 56.6 分，位列全球第五、国产第一，把 Gemini 3.5 Flash 和 Claude Opus 4.6/4.7 一起甩在身后，比上一代 Qwen3 跳了 4.8 分。值得注意的是这次走的是闭源 + 付费 API 路线（即将上线阿里云百炼），定位明确就是面向「智能体时代」的旗舰，主打 35 小时长程自主运行 + 上千次工具调用。这条线和摩尔线程 MUSA 试图替代 CUDA 是同一个剧本——国产 AI 栈正在从「能用」向「比海外强」的位置爬，国内做 LangGraph + MCP 长程任务的同学，等 API 上线第一时间可以拿来对标 Claude Sonnet 看长程稳定性。

### 腾讯 Marvis 上线：操作系统级 AI 助手，每天 1000 万免费 Token

腾讯应用宝团队 5/21 把操作系统层级的 AI 助手 Marvis（马维斯）正式开放下载，Windows / Mac / Android 三端同步上线，无需邀请码，每位用户每天免费 1000 万 Token。Marvis 把终端系统、文件、应用、算力和跨端连接放进同一个 AI 中间层，主打 6 个常驻智能体 + 本地隐私模式 + 跨设备控制。这是国内继华为小艺、荣耀 YOYO、vivo 蓝心之后，第一个不绑死硬件、覆盖三大桌面/移动平台的 OS 级 Agent 入口——意味着腾讯不再只做应用层 AI，而是要在「应用商店之上、操作系统之下」插一层自己的 Agent 平面。对国内 ToC Agent 团队，可以重点观察 Marvis 的工具调用协议和 MCP 开放程度，会决定第三方能否在它上面接入。

→ [开源中国](https://www.oschina.net/news/443637) / [AIBase 详情](https://news.aibase.com/news/28191)
