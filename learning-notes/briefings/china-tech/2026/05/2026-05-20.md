### 百度 Q1：AI 业务收入 136 亿，昆仑芯 P800 跑通文心 5.1

百度 Q1 总营收 321 亿、AI 业务收入 136 亿（同比 +49%），其中 AI 云 88 亿（+79%）、GPU 云收入直接翻三倍（+184%）。最值得拎出来看的不是数字，是国产算力自闭环这件事——百度披露昆仑芯 P800 全国产集群完成了文心 5.1 重要版本训练，整集群有效训练率 97%、万卡线性扩展度超 85%。在 H200 还卡在出口管制的当下，这条线意味着「国产芯片+国产框架+国产模型」已经能把万卡级训练跑稳，而不只是 demo。对国内做企业落地的同学来说，下个季度的国产 GPU 报价和 vendor lock-in 风险都要重新算账。

### 字节 veRL 开源 Uni-Agent：把构建、运行、训练塞进一个框架

字节火山引擎 veRL 团队（就是那个 LLM RL 训练框架）放出了 Uni-Agent，主打通用 Agent 的构建-运行-训练一体化：开发者一份代码同时定义 agent 行为、Sandbox 运行和 RL 训练闭环，交互轨迹直接回灌强化学习。这是国内大厂第一次把 Agent 训练栈下沉到框架层——之前 LangGraph 解决编排、verl/TRL 解决训练，现在字节想合并成一个生态。对在做 LangGraph + MCP 的同学，可以把它当 Plan B 关注，看它在长程任务的稳定性和工具接入是否真比拼装方案省事。

→ [原文](https://www.oschina.net/news/442702) / [veRL GitHub](https://github.com/verl-project/verl)

## ⚡ 快讯

- **地平线 HoloMotion-1**：开源 4 亿参数的人形机器人「小脑」基础模型，MoE 稀疏激活 + KV-cache 推理，专攻全身控制和长时序运动一致性，给国内具身智能多了一个开箱可用的 baseline → [原文](https://www.oschina.net/news/442809) / [GitHub](https://github.com/HorizonRobotics/HoloMotion)
- **腾讯混元 Chronicles-OCR**：联合安阳师大、中科院信工所等机构发布业界首个覆盖「七体之变」的中国古文字 OCR 评测基准，2800 张专家标注图——结果 GPT-5、Gemini 3.1 Pro 在跨时代字符检测 H-mean 接近 0，最强模型甲骨文识别准确率仅 14% → [原文](https://www.oschina.net/news/442753)
- **小红书 Muse**：AICon 上披露的 vibe coding 平台架构，核心是高可用人机共创 Agentic 系统——把工程师从「写代码」改成「校对 Agent」，国内大厂里少见的把 agent 直接放到内部生产力工具的实践 → [原文](https://www.infoq.cn/article/0cMu1bsEszkZDf09OP2M)
- **DeepSeek**：官方下场回应近期争议：用户输入 `<think>` 等特殊字符触发奇怪回复，是模型幻觉而非「对话泄露」。值得关注的不是结论，是 DeepSeek 现在愿意为单次舆情发技术说明，国产大模型公关成熟度肉眼可见在升级 → [原文](https://www.oschina.net/news/442831)
- **摩尔线程 MT Lambda**：国产 GPU 公司发布国内首个全栈具身智能仿真平台，从硬件到仿真链路一体化——配合地平线、宇树这一波具身硬件，国内具身智能终于有了不依赖海外仿真器的选项 → [原文](https://www.qbitai.com/2026/05/420084.html)
- **openJiuwen JiuwenSwarm**：九问社区开源的蜂群 Agent 框架，提出 Coordination Engineering 范式：不再单 agent 卷能力，而是用群体协作把任务拆给 N 个 small agent。国内 multi-agent 工程化方向的新尝试 → [原文](https://www.qbitai.com/2026/05/419515.html) / [InfoQ 深度](https://www.infoq.cn/article/eyoS3WVdltWbqJXuygQi)
- **Erupt 1.14.3**：国产 Java 低代码框架更新，把 A2A 协作、跨会话记忆、浏览器直连服务器终端塞进了 Spring Boot 后台——国内中小团队想试 multi-agent 又不想脱离 Java 栈的，可以直接拿来用 → [原文](https://www.oschina.net/news/442811/erupt-1-14-3-released)
- **JeecgBoot AI Skill**：国产低代码平台 JeecgBoot 把代码生成器接入 Claude Code：一句话从建表到 Maven 模块到 Vue3 前端全套生成。Claude Code 在国内企业向工具里被当 backend 用的趋势越来越明显 → [原文](https://www.oschina.net/news/442708)
