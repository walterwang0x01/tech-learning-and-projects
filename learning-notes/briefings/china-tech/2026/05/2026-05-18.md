### 月之暗面 200 亿美元估值落地：Kimi 半年估值翻 4 倍，美团领投

月之暗面（Moonshot AI）这一轮 20 亿美元融资敲定，投后估值 200 亿美元，由美团旗下龙珠资本领投，距上一轮 43 亿美元估值仅过去半年。LatePost 披露 Kimi 4 月 ARR 已突破 2 亿美元，订阅和 API 双轮在跑。这条线值得关注的是：在 DeepSeek V4-Preview 把 API 价格压到 GPT-5.5 的十分之一、智谱 GLM-5.1 拿下 SWE-Bench Pro 开源第一之后，"国产大模型靠定价和开源走规模化"的故事正在被资本端重新定价——杨植麟选了"闭源 + 高端订阅"的路，反而跑出了中国 LLM 创业公司单轮最大融资。如果你在做 AI agent 产品选型，国产模型这条线短期内的价格战和能力迭代节奏会更快，建议把 Kimi K2.5、GLM-5.1、DeepSeek V4-Flash 都接入做 A/B。

### 三部委联合发文：中国首个 AI agent 治理框架落地

网信办、发改委、工信部 5 月 8 日联合发布 AI agent 实施指南，明确把 agent 定义成"具备自主感知、记忆、决策、交互、执行能力，正在与赛博空间和物理世界深度融合的智能系统"，并配套 19 类示范应用场景。这是国内第一次把 agentic AI 当作"未来数字基础设施"而非"大模型上的一层应用"来管，意味着备案、安全评估、深度合成标识等一系列原本只针对生成式 AI 的合规要求，会按 agent 的形态再做一遍延伸。5 月 14 日新华社又跟了一篇"加速 AI agent 治理应对新兴安全风险"，把开源 agent 框架的漏洞作为重点提示——MCP / LangGraph / CrewAI 这类技术栈在国内落地，要提前把模型出处、工具调用日志、人工审计链路这几件事补上。

## 📈 趋势

- 🔺 **国产开源模型连续登顶国际 Coding Agent 基准**（GLM-5.1 / DeepSeek V4 / MiniMax M2.1）— 中国厂商把"开源 + 低价 + 长上下文"组合打成了出海标配，闭源厂商的护城河被压缩到极少数前沿能力上
- 🔺 **国产大模型估值再分化**（Kimi 半年估值 ×4）— 在开源派打价格战的同时，闭源订阅派靠 ARR 和 agent 产品力跑出更陡的估值曲线，月之暗面、阶跃、MiniMax 三家定位差异越来越清晰
- 🆕 **AI agent 治理升级为"数字基础设施"层级** — 三部委文件首次把 agent 当独立监管对象，备案、深度合成标识、工具调用审计会逐步落到 LangGraph / MCP / CrewAI 这类技术栈
- 🔺 **燃油车价格战白热化** — 合资品牌降幅 20%-30%，新能源把战火烧到油车主战场，消费侧短期受益但产业链中下游利润被进一步压扁
