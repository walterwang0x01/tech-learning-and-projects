## 📌 头条

### 昆仑万维天工开源 SkyClaw-v1.0，把国产 Agent 模型推进全球第一梯队

5 月 26 日昆仑万维天工 AI 正式发布 SkyClaw-v1.0 与轻量版 SkyClaw-v1.0-lite，对外开放 2 至 4 周免费试用。模型支持百万 token 上下文，重点优化复杂工具调用、多轮任务执行、代码生成、文件编辑、交互式应用构建与研究型数据分析，能直接跑在 OpenClaw、Hermes、Nanobot 等主流 Agent 环境里，也适配 Claude Code、Codex 这类代码 Agent 框架。官方放出的 benchmark 显示 SkyClaw-v1.0 在 PinchBench-v2 拿 87.2 分、Claw-Eval 平均 59.7，号称在 OpenClaw 系任务上接近 DeepSeek V4 Pro、Claude Opus 4.6、Qwen 3.6 Plus 这类更大的闭源模型。这是国产厂商第一次明确把模型按「Agent 模型 + Agent framework 组合」来定位——模型不再只是回答问题，而是被放进读仓库、调工具、改文件、跑测试、看反馈的完整执行环境里持续推进任务。对国内做编码 / 办公 / 研究类 agent 的团队，SkyClaw 是新一档可以直接接入 Claude Code 兼容栈的国产底模选项。

→ [开源中国发布通稿](https://www.oschina.net/news/446248) / [量子位报道](https://www.qbitai.com/2026/05/424851.html) / [SkyClaw 官方页面（含 benchmark）](https://skyworkai.github.io/skyclaw/) / [36 氪深度](https://36kr.com/p/3825882266407815?f=rss)

### 面壁联合清华开源 BitCPM-CANN，1.58-bit 端侧大模型在昇腾上原生跑通

面壁智能联合清华大学、OpenBMB 开源社区，在清华鲲鹏昇腾科教创新卓越中心支持下发布 BitCPM-CANN，从量化算子、训练算法到全链路框架全部在华为昇腾上原生完成，是国内首个端到端 1.58-bit（三值，权重只有 -1/0/1）大模型训练系统。这次一次开放 0.5B、1B、3B、8B 四个尺寸，模型能力保留率维持在 90%~97.2%，三个主力尺寸在 95.7%~97.2% 之间，相当于把内存占用压到原 16-bit 的九分之一附近，权重和未量化的 QAT checkpoint 都已上 Hugging Face 开放下载。这件事的意义不在「又开源一个小模型」——它给国内端侧场景（手机、PC、车机、本地工业设备）提供了一条「不依赖英伟达 + 不依赖 GGUF 间接量化」的原生路径，把昇腾从「能跑」推到「能从头训」。配合本周《人工智能应用伦理安全指引 1.0》对国产链路的合规倾向，端侧 1.58-bit 在国内 To B 场景的优先级会被显著拉高。

→ [开源中国报道](https://www.oschina.net/news/446114) / [BitCPM-CANN-8B-gguf 模型卡](https://huggingface.co/openbmb/BitCPM-CANN-8B-gguf) / [Hugging Face Collection](https://huggingface.co/collections/openbmb/bitcpm-cann)

## ⚡ 快讯

- **阿里云**：在 2026 阿里云峰会上正式开源面向企业 AI 的对象图语义运行时 UModel，同步发起「企业通用语义标准」（Universal Semantic Standard, USS）行业倡议，瞄准的是企业数据语义割裂这层 AI 规模化落地的底座障碍，等于阿里把「企业知识图谱 / 数据平台」这块抢在国内同行前先立了规则。 → [开源中国](https://my.oschina.net/u/3874284/blog/19681635) / [阿里云官方博客（英文版）](https://www.alibabacloud.com/blog/building-a-unified-entity-search-engine-by-using-umodel-for-observability-scenarios_602813)
- **小米汽车**：发布 Xiaomi Auto World Model 框架，把重建模块（WorldRec，维护随观测增量扩展的 4D Gaussian 全局表示）和生成模块（WorldGen）深度耦合，让两者结构上互相约束。这是国内车企里少见的把世界模型当工程框架而不是 demo 推出的尝试，直接对标海外 Wayve、Tesla 的世界模型路线。 → [开源中国](https://www.oschina.net/news/446227)
- **网安标委**：正式发布《人工智能应用伦理安全指引 1.0》，给出 AI 应用伦理安全理念与原则，明确开发、服务提供、使用三端的安全指引。起草单位包括清华、中国电子技术标准化研究院、上海交大、阿里巴巴、华为等，是国内 AI 应用层「合规底线」的一份标准化模版，To B 项目尽快对照自查。 → [开源中国](https://www.oschina.net/news/446092)
- **字节跳动 Seed**：本月向 Seed AI 部门员工开放与该部门挂钩的低价股票期权，是字节首次针对特定业务单元发行股权，俗称「豆包股」。这是大厂在算力 / 算法人才战里把激励与具体 BU 绑定的明确信号——员工分享的是 Seed 自身的成长收益，不被其他业务线稀释。 → [36 氪氪星晚报](https://36kr.com/p/3825928694846085?f=rss)
- **阿里千问**：Qwen 3.7 在编程权威榜单上仅次于 Claude，跻身全球编程模型第一梯队，阿里自家上下文里这是国产模型在 coding agent 维度第一次明确摸到全球第二的位置。 → [量子位](https://www.qbitai.com/2026/05/425150.html)
- **华为**：2026 阿里云峰会同期发布 AI DC 数据基础设施全栈方案，把昇腾算力 + 网络 + 存储 + 调度打包成一体化解决方案对外推。和上面 BitCPM-CANN 的端侧路径形成「云上全栈 + 端侧原生量化」的两端配合。 → [量子位](https://www.qbitai.com/2026/05/425296.html)
- **光轮智能**：完成由蚂蚁领投的新一轮融资，定位「物理 AI」。InfoQ 的判断是物理 AI 价值中心已经从单纯的仿真数据生成转向「世界模型 + 真实-仿真闭环」，蚂蚁这一笔是国内大厂在具身 / 物理 AI 数据层的明确下注。 → [InfoQ](https://www.infoq.cn/article/bdsq4OUrTNJdvCLaxo0u)
- **观猹（红杉、华兴投）**：02 年创始人做的「AI 产品大众点评」社区拿到红杉、华兴投资。这一笔的看点不是估值而是赛道——国内 AI 应用层至今缺一个独立的评测/口碑入口，机构选这个时点出手，等于押注 AI 应用「大众市场化」节点已到。 → [36 氪](https://36kr.com/p/3826385821192841?f=rss)
