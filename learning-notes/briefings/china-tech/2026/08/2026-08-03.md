### DeepSeek V4-Flash 转正，只重做了一遍后训练

DeepSeek 在 7 月 31 日把 deepseek-v4-flash 推入正式公测。多家跟踪站点转述的官方口径很朴素：模型串和调用方式都不变，照旧写 deepseek-v4-flash 就切到最新版；真正变的是后训练。第三方整理称 0731 这版把 Agent 类基准推过了此前的 V4-Pro-Preview（Terminal Bench 2.1 到 82.7、Cybergym 76.7），输入输出定价仍是 $0.14 / $0.28 每百万 token，同时补上了 Responses API 与 Codex 兼容——这些基准数字目前只有第三方汇总，官方没放完整表格，引用时留个余量。同一个 284B 总参、13B 激活的 MoE，架构没动、价格没涨，光靠再跑一遍后训练就换出一档能力，这对国内做 Agent 的团队比再发一个新模型更有信息量：便宜档位的天花板还在往上抬。分发侧的动作同样值得留意，8 月 2 日国家超算互联网上线了 DeepSeek-V4-Flash-0731 的 API 调用服务与模型文件，国产算力平台这次几乎是零时差跟上。如果你的 Agent 链路正跑在 v4-flash 上，这周值得把 eval 重跑一遍——模型串没变，行为变了。

### 清华 00 后博士拿千万种子轮，要给 Agent 建组织

奇点逃逸完成千万级种子轮融资，星连资本与水木创投联合领投，奇绩创坛跟投。创始人兼 CEO 薛传奕本科与博士都在清华，研究方向是强化学习与多智能体，在商汤、鉴智机器人实习期间做过自动驾驶算法研发与实车部署。产品 Nexus 定位「AI 原生团队协作操作系统」，让人、Agent、任务、知识和工具跑在同一份组织状态上。他描述的问题很具体：产品经理让一个 Agent 梳理需求，研发让另一个改代码，运营在第三个窗口研究发布方案，几小时后每个 Agent 都干完了自己那块、也各自攒了一段完整上下文，但要合并时没人清楚另一个 Agent 做过什么、为什么这么做，人于是又被打回信息中转站的位置。这个切口对用 LangGraph 一类框架搭多 Agent 的人应该很熟——单个 Agent 的能力早就够用，缺的是跨 Agent 的共享状态和可追溯的决策记录。官方还有一句「让系统从每一次协作中有证据地变强」，怎么算「有证据」目前没有公开细节，等产品出来再验。
