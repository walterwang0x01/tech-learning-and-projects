## 📌 头条

### 阿里成立 Token Foundry 事业部，吴泳铭亲自挂帅

阿里巴巴宣布合并通义大模型事业部和未来生活实验室，成立 Token Foundry 事业部，由集团 CEO 吴泳铭直管。新事业部归属同步新设的 Alibaba Token Hub（ATH）业务集群，统管模型研发、MaaS 服务、Qwen 应用及企业 AI 产品。这是阿里半年内第三次调整 AI 组织架构，信号很明确：大模型从实验阶段进入全面商业化阶段，CEO 直管意味着这是集团一号位工程。对开发者来说，Qwen 系列的产品化节奏和 API 定价策略值得持续关注。

→ [SCMP 报道](https://amp.scmp.com/tech/article/3356408/alibaba-forges-token-foundry-it-hammers-ai-ambitions-shape) / [PYMNTS](https://www.pymnts.com/artificial-intelligence-2/2026/alibaba-ceo-takes-direct-control-of-new-ai-business-unit/)

### DeepSeek 首轮融资接近 500 亿元，估值最高 590 亿美元

多家媒体确认，DeepSeek 正在完成约 500 亿元人民币（约 74 亿美元）的首轮外部融资，投后估值 3500–4000 亿元。腾讯和宁德时代预计成为最大外部投资方，网易、京东也将参与。这是 DeepSeek 创立以来首次接受外部资本，创始人梁文锋表态将优先投入开源 AI 研发而非短期变现。从 V4-Pro/V4-Flash 的发布到这轮巨额融资，DeepSeek 正从技术明星向产业巨头加速转型。

→ [Semafor](https://www.semafor.com/article/06/04/2026/deepseek-nears-7-billion-haul-in-first-raise) / [Yahoo Finance](https://finance.yahoo.com/sectors/technology/articles/deepseek-eyes-7-4-billion-123039218.html)
