## 📌 头条

### Cloudflare 收购 VoidZero，尤雨溪和 Vite 正式「上岸」

Cloudflare 宣布收购尤雨溪创办的 VoidZero，这家公司不到两年就完成了从独立开源到被收购的全历程。Vite 生态将嵌入 Cloudflare 的 AI-Native Web 战略，同时承诺项目继续开源、团队继续领导。这是国内独立开源作者最完美的退出样本——把开源做成公司，让公司被收购，收购后项目不死。对国内开源圈是巨大的信心注入。

→ [开源中国详解](https://my.oschina.net/u/4487475/blog/19695195) / [Cloudflare 公告](https://www.businesswire.com/news/home/20260604108073/en/Cloudflare-Acquires-VoidZero-to-Build-the-Future-of-the-AI-Native-Web)

### DeepSeek 首轮融资 70 亿美元，腾讯宁德时代领投

DeepSeek 正在完成成立以来的首次外部融资，规模约 500 亿元人民币，投后估值 3500-4000 亿元。腾讯和宁德时代有望成为最大外部投资者，网易、京东也计划参与。创始人梁文锋表示将优先开源而非短期变现。这标志着中国 AI 独角兽的估值天花板再次被抬高，DeepSeek 从「效率神话」正式走向「重资本」路线。

→ [Semafor 报道](https://www.semafor.com/article/06/04/2026/deepseek-nears-7-billion-haul-in-first-raise) / [Yahoo Finance](https://finance.yahoo.com/sectors/technology/articles/deepseek-eyes-7-4-billion-123039218.html)

## ⚡ 快讯

- **字节豆包**：推出付费订阅后月活减少 610 万，分析认为在中国免费 AI 服务时代远未结束时过早商业化，可能让豆包在消费端失去先发优势。 → [36氪](https://36kr.com/p/3840996342073604?f=rss)
- **微信 A2A**：腾讯确认微信已通过 A2A（Agent-to-Agent）协议接入华为小艺、小米小爱、荣耀 YOYO 等手机系统 AI 助手，荣耀率先上线，用户可用语音助手直接发微信、打视频通话。 → [财新报道](https://www.caixinglobal.com/2026-06-04/tencent-opens-wechat-to-handset-makers-ai-assistants-102451051.html)
- **阿里 Open Code Review**：阿里将内部使用两年、服务数万开发者的 AI 代码审查工具开源为 CLI，已发现数百万代码缺陷，支持 CI/CD 集成——对用 GitHub Actions 的团队来说是个免费的质量门禁。 → [开源中国](https://www.oschina.net/news/452693) / [GitHub](https://github.com/raye-deng/open-code-review)
- **腾讯混元 PlanningBench**：联合人大高瓴开源 PlanningBench，覆盖 30+ 规划任务类型的可扩展评测框架，专门检验大模型「会不会规划」而非只会聊天。 → [开源中国](https://www.oschina.net/news/452603)
- **华为云 Agentic AI**：发布 Agentic AI 系列新品，CEO 周跃峰表态：不卷 Token 总量，只看 Token 是否真正代表生产力提升——走出了与火山引擎/阿里价格战不同的第三条路。 → [量子位](https://www.qbitai.com/2026/06/431027.html) / [36氪深度](https://36kr.com/p/3840016255126016?f=rss)
- **百度 nettools 开源**：面向大规模数据中心的物理网络监控工具集，能捕捉传统 ping/traceroute 发现不了的微秒级丢包和比特翻转，适合运维大规模 GPU 集群。 → [开源中国](https://www.oschina.net/news/452720)
- **腾讯云 WorkBuddy 企业版**：定位企业 AI 效率工具，从「超级个体」扩展到「超级团队」协作场景，正式对标钉钉 AI 和飞书智能伙伴。 → [量子位](https://www.qbitai.com/2026/06/430758.html)
