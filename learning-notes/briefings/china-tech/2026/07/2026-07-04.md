### 阿里内部全面禁用 Claude Code

阿里巴巴内部宣布，因 Claude Code 被曝存在植入后门的安全风险，公司已将其列入高风险软件名单，禁令于 7 月 10 日正式生效，全员被要求卸载 Anthropic 相关产品（涵盖 Sonnet、Opus、Fable 等模型系列及 Claude Code 等 Agent 产品），并推荐内部编程工具 Qoder 作为替代方案。值得注意的反差是，此前阿里为鼓励员工用 AI 提效，不仅给内部模型发免费额度，还对外部模型使用给过大额报销政策，态度从鼓励到反向禁用只用了半年。这不只是一次安全事件处理，更像是大厂在 Agent 工具供应链上的一次风险再评估：当 Coding Agent 深度接入内部代码库和研发流程，它本身就成了新的攻击面，谁的工具能进公司防火墙，正在变成一道政治正确题。

### 全球首款神经动力学芯片问世

北京大学集成电路学院杨玉超团队联合中国科学院上海微系统所宋志棠团队，研制出全球首款基于相变忆阻器的神经动力学系统芯片，把这类复杂运算的单步时延压缩到 2.12 毫秒，在脑皮层重建等任务上比当前最先进的 GPU 提速 50 到 478 倍，一举突破了困扰这个领域近半个世纪的实时计算瓶颈。相关成果 7 月 3 日凌晨发表于《科学》（Science）。这类芯片的意义不在跑分，而在于让脑机接口、类脑计算这些长期停留在实验室仿真阶段的方向，第一次有了能实时响应的硬件底座——忆阻器路线又添一个国产硬核案例。
