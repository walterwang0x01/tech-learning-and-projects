### Cloudflare 让 DNSSEC 旁路可观测

阿尔巴尼亚国家域 .AL 因 DNSSEC 密钥轮换失败一度瘫痪；Cloudflare 用 Negative Trust Anchor 恢复解析，并把这次「不得不绕过校验」的事实通过新的 DNS 扩展错误码 EDE 33 回传给客户端。也就是说 1.1.1.1 不再只是「替你修好了」，还会明确告诉你：此刻校验被绕过了、信任锚被临时降级了。对做 DNS、零信任接入或安全监控的人来说，可观测性终于追上了运维权宜之计——别再盲目把「解析成功」当成「密码学上安全」。

→ [原文](https://blog.cloudflare.com/dnssec-nta-ede-33)

### 微软开源 SymCrypt Rust 证明

Microsoft Research 公开 SymCrypt 中用 Safe Rust + Lean/Aeneas 做密码算法形式化验证的路线：内存安全由 Rust 兜底，功能正确性由对照标准写出的 Lean 规格与证明背书。首批已覆盖正在 Windows Insider 构建中使用的 ML-KEM 与 SHA3 Rust 实现，并计划扩展到 AES-GCM、FrodoKEM、ML-DSA 等。后量子算法实现复杂、踩坑成本高——把「可审计的证明工件」和产品级密码库放在同一仓库，是工程可信度从文档承诺走向可复现的信号。

→ [Microsoft Research](https://www.microsoft.com/en-us/research/blog/verifying-rust-cryptography-in-symcrypt-from-standards-to-code/)
