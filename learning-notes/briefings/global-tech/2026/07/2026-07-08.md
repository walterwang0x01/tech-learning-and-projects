## 📌 头条

### GitHub 跨境开源协作创近年新高

GitHub 发布 Q1 2026 Innovation Graph 更新：跨境协作指标（一国开发者向另一国公开仓库推送的 git push 与 PR 总量）环比 Q4 2025 增长 16%，为 2020 年以来第二高季度增速，仅次于 2020 年 Q2 疫情居家潮的 21%。数据覆盖全球各经济体开发者轨迹，叙利亚等地区贡献在制裁放松后出现明显回升。GitHub 同时回应「开源 Eternal September」现象——贡献量暴涨让维护者承压——推出 PR 数量上限、Issue 置顶评论、大 PR diff 响应提速最高 67% 等工具。对参与跨国开源协作的开发者而言，这意味着全球贡献池仍在扩张，但提 PR 前更需要尊重维护者节奏与仓库规范。

→ [GitHub Blog](https://github.blog/news-insights/policy-news-and-insights/q1-2026-innovation-graph-update-open-source-collaboration-is-accelerating-worldwide/) / [Innovation Graph](https://innovationgraph.github.com/global-metrics/economy-collaborators)

### Linux 容器生态全面「胜出」

Reddit 热帖「Linux has officially won」不到 24 小时获 1600+ 赞，论据并非桌面份额，而是两大巨头拥抱 Linux 容器：Apple 6 月发布 Container v1.0.0 作为 macOS 原生 Linux 容器运行时，微软则在 WSL 中推出 Containers 预览，让 Windows 开发者无需虚拟机即可跑 Linux 容器。讨论认为，容器已成为跨平台开发的事实标准——无论底层是 Darwin 还是 NT 内核，工作负载最终都落在 Linux 用户态。如果你在规划 CI/CD 或本地开发环境，可以开始把「Linux 容器优先」当作默认假设，而非某类平台的妥协方案。

→ [讨论汇总](https://www.oschina.net/news/471522) / [Apple Container](https://github.com/apple/container)
