## 📌 头条

### AsyncAPI npm 供应链被攻陷

7 月 14 日，攻击者利用 AsyncAPI generator 仓库误配的 pull_request_target 工作流窃取高权限 token，再借项目自有 GitHub Actions 发布流水线，把带后门的版本推上 npm——还带着合法 OIDC  provenance。受影响包括 @asyncapi/generator@3.3.1、generator-helpers@1.1.1、generator-components@0.7.1 以及 @asyncapi/specs@6.11.2（含 alpha）。载荷在 import/require 时触发，从 IPFS 拉 Miasma 变种，而不是装包钩子。Provenance 只能证明「谁发的」，证明不了「源码当时可信」；立刻回退到 3.3.0 / 6.11.1 等安全版本，清 lockfile 与镜像缓存，并对曾加载过恶意版本的 CI/开发机做凭证轮换。

→ [Chainguard](https://www.chainguard.dev/unchained/asyncapi-supply-chain-compromise-npm-packages-backdoored-via-github-actions) / [Socket](https://socket.dev/blog/asyncapi-supply-chain-attack)

### TypeScript 7 原生编译器上线

微软正式放出 TypeScript 7.0：用 Go 重写的原生端口，完整构建常见可拿到约 8–12 倍加速（VS Code 仓库约 11.9x），编辑器首错反馈从十几秒压到约 1 秒量级，并支持共享内存多线程。升级路径走 npm install -D typescript；过渡期可用 @typescript/typescript6 的 tsc6 与旧 API 并存。对大型 TS/React 单体仓和 CI 类型检查预算紧张的团队，这是今年最值得立刻试点的工具链换代——先在 CI 与编辑器各开一条旁路对比诊断一致性，再切主线。

→ [官方公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) / [InfoWorld](https://www.infoworld.com/article/4196378/go-based-typescript-7-0-arrives.html)

## 📈 趋势

- 🆕 CI 身份 ≠ 包可信 — AsyncAPI 事件证明：合法 provenance / OIDC 只能锚定「流水线身份」，防不住被劫持的源分支与 pwn-request 类 Actions 误配。
