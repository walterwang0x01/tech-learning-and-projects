## 📌 头条

### Bun 官宣用 Rust 重写核心运行时

Bun 团队宣布用 Rust 重写核心运行时的关键部分，这条消息很快冲上 Hacker News，Zig 语言作者 Andrew Kelley 亲自撰文回应，讨论帖拿到 656 分、567 条评论，原始报道也有 33 分。争论的焦点不是「Zig 不行」，而是 Rust 生态的库、工具链和招聘池更成熟，这对一个要长期商业化维护的 JS 运行时更实际。差不多同一时间，一个把 Postgres 用 Rust 重写、并已 100% 通过官方回归测试的 pgrust 项目也冲上 404 分，说明「系统级基础设施用 Rust 重写」正从个人玩具项目变成严肃选项。如果你维护性能敏感的基础设施，这轮讨论值得看看社区在 Rust / Zig / C++ 之间的真实取舍。

→ [Bun 重写观点](https://andrewkelley.me/post/my-thoughts-bun-rust-rewrite.html) / [原始报道](https://simonwillison.net/2026/Jul/8/rewriting-bun-in-rust)

### 欧洲议会通过 Chat Control 法案

欧洲议会投票通过了俗称「Chat Control 1.0」的法案，这是欲监管加密通讯、扫描私信内容立法的最新进展，消息在 Hacker News 拿到 1023 分、493 条评论，是本周热度最高的科技相关话题之一。发起联署反对的欧洲议员 Patrick Breyer 认为该法案会削弱端到端加密，反而伤害它本要保护的儿童群体；支持者则强调这是打击儿童性虐待材料传播的必要手段。对于做欧洲市场、尤其是消息类和加密类产品的团队，需要开始关注后续实施细则和潜在合规成本。

→ [Breyer 博文](https://www.patrick-breyer.de/en/eu-parliament-greenlights-chat-control-1-0-breyer-our-children-lose-out)
