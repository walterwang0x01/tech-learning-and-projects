## 📌 头条

### NVIDIA RTX Spark 发布：ARM 超级芯片正式杀入消费级 PC

Computex 2026 上，NVIDIA 联合微软、联发科发布 RTX Spark 超级芯片，将 Blackwell GPU（6144 CUDA 核心）与 20 核 ARM Grace CPU、128GB 统一内存整合为单芯片方案，首次在消费级 Windows PC 上实现 1 Petaflop AI 算力。微软 Surface Laptop Ultra 和 Surface RTX Spark Dev Box 率先搭载，Dell、HP、ASUS、Lenovo 等六家 OEM 将于今年秋季跟进。Jensen Huang 称这是「40 年来 PC 的首次彻底重构」——对开发者而言，意味着 120B 参数的模型可以完全在本地跑，无需云端。

→ [Tom’s Hardware 详解](https://www.tomshardware.com/laptops/nvidia-unveils-rtx-spark-superchip-at-computex-2026-new-platform-promises-to-turn-windows-into-an-agentic-ai-os-with-arm-cpu-blackwell-gpu-and-128gb-unified-memory) / [NVIDIA 官方博客](https://blogs.nvidia.com/blog/rtx-ai-garage-computex-spark-local-agents/)

### Microsoft Build 2026：自研模型、Scout 助手、量子芯片全面亮相

微软在 Build 2026 上发布了首个旗舰推理模型 MAI-Thinking-1，标志着减少对 OpenAI 依赖的战略转向。同时推出基于 OpenClaw 的全天候 AI 助手 Scout，定位为 Microsoft 365 生态的个人自治代理。量子计算方面，Majorana 2 拓扑量子芯片发布，可缩短有用量子计算的时间线。对开发者影响最大的是 MXC（Execution Containers）——让 Windows 原生支持沙箱化 Agent 运行时。

→ [The Verge 汇总](https://www.theverge.com/tech/941738/microsoft-build-2026-biggest-announcements) / [Ars Technica](https://arstechnica.com/gadgets/2026/06/microsoft-plans-linux-tools-and-an-rtx-spark-desktop-for-windows-developers/)
