## 📌 头条

### TypeScript 7.0 RC 发布：编译器用 Go 重写，类型检查提速 10 倍

微软发布 TypeScript 7.0 RC，核心变化是编译器从 JavaScript 完整移植到 Go。在 VS Code 150 万行代码基准测试中，类型检查从 77.8 秒降至 7.5 秒，编辑器加载时间从 9.6 秒降到 1.2 秒。这不只是「快了」，而是开发体验质变——大型项目的卡顿感将基本消失。注意 strict 默认开启、多个废弃 flag 变为硬错误，升级前需检查 tsconfig。

→ [微软官方公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0-rc)

---

### Cloudflare 联合三大浏览器推出 PACT 协议，要用密码学令牌取代 CAPTCHA

Cloudflare 宣布与 Chrome、Firefox、Edge 及 Shopify 共同开发 Private Access Control Tokens（PACT）协议并提交标准化。PACT 使用匿名密码学证明来区分合法流量与恶意请求，不泄露个人数据，不需要用户点图片验证。这是继 Privacy Pass 之后，业界对抗 bot 滥用的又一次隐私优先尝试，若标准化成功将显著改善浏览体验。

→ [Cloudflare 公告](https://www.cloudflare.com/press/press-releases/2026/cloudflare-collaborates-with-leading-browsers-to-develop-a-privacy-first-protocol-for-the-global-internet/) / [The Register 报道](https://www.theregister.com/software/2026/06/22/cloudflare-teams-up-with-big-browsers-to-help-websites-tell-welcome-from-unwelcome-visitors/5259782)
