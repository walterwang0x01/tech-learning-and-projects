## 📌 头条

### WWDC 2026：Siri AI 登场，Apple 全面接入 Gemini

苹果在 WWDC 2026 上发布了 iOS 27、macOS 27 Golden Gate 等全线操作系统更新，核心焦点是全新的 Siri AI。这是 Siri 诞生以来最大一次重构——它现在由 Apple Intelligence 驱动，底层接入 Google Gemini 大模型，支持多轮自然对话、屏幕上下文理解、跨 App 操作，并拥有独立 App。macOS 27 正式抛弃 Intel Mac，仅支持 Apple Silicon（M1+）。苹果还宣布为小开发者免除云端 AI API 费用（低于 200 万首次下载量），以及用 AI 让用户自己 vibe-code Safari 扩展。因 DMA 限制，Siri AI 将延迟在欧盟上线。

→ [Apple Newsroom](https://www.apple.com/apple-intelligence) / [Ars Technica 综述](https://arstechnica.com/gadgets/2026/06/apples-ios-27-macos-27-golden-gate-and-other-updates-focus-on-refinement) / [TechCrunch 汇总](https://techcrunch.com/2026/06/08/wwdc-2026-everything-announced-on-siri-ai-os-27-apple-intelligence-and-more)

### Microsoft 开源仓库遭供应链投毒，窃取 AI 开发者凭证

TechCrunch 报道，Microsoft 关闭了数十个 Azure 和 AI 编码工具的 GitHub 仓库，原因是被植入了凭证窃取恶意代码。Ars Technica 进一步披露，这已是两周内第二次，共 73 个 npm 包在被 AI agent 打开时即执行自复制窃密程序。对于日常依赖 Microsoft AI 工具链（如 Semantic Kernel、AutoGen）的开发者来说，这是一个值得立即排查的供应链安全事件。

→ [TechCrunch](https://techcrunch.com/2026/06/08/microsofts-open-source-tools-were-hacked-to-steal-passwords-of-ai-developers) / [Ars Technica](https://arstechnica.com/security/2026/06/for-the-2nd-time-in-weeks-microsoft-packages-laced-with-credential-stealer)
