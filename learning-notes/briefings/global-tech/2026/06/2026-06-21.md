## 📌 头条

### TypeScript 7.0 RC 发布：Go 重写带来 10 倍编译提速

微软正式发布 TypeScript 7.0 Release Candidate，这是编译器从 JavaScript 迁移到 Go 的里程碑版本。VS Code 150 万行代码的类型检查从 77 秒降至 7.5 秒，编辑器项目加载时间从 9.6 秒降至 1.2 秒，内存占用减半。新版默认开启 strict 模式，module 默认改为 esnext，多项已废弃选项将报硬错误。这意味着前端生态将迎来一波迁移适配工作，但开发体验会有质的飞跃。

→ [官方公告](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0-rc/)

---

### Linux 7.2 彻底移除 strncpy：历时六年、360 个补丁

Linux 内核在 7.2 版本中终于完全淘汰了 strncpy API。这项工作跨越六年，涉及 360 个补丁，旨在消除这个因不保证 NUL 终止而臭名昭著的 C 字符串函数带来的安全隐患。内核开发者将所有调用点替换为更安全的替代方案。这是内核安全加固的标志性进展，也反映了大型开源项目中「还技术债」的艰辛程度。HN 111 分。

→ [Phoronix](https://www.phoronix.com/news/Linux-7.2-Drops-strncpy)
