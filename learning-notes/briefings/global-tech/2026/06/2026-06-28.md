### 匿名账号在 GitHub 批量公开 0day 漏洞

一个匿名 GitHub 账号（exploitarium）开始批量抛出此前未披露的 0day，HN 上冲到 729 分、近 300 条讨论。这类「未协调披露」意味着厂商还没来得及修补，攻击者却已经拿到了现成武器，软件供应链瞬间多出一批暴露面。如果你在自建或自托管服务，最实际的动作是盯紧依赖组件的安全公告、尽快打补丁，别等被点名才动手。

→ [原文](https://github.com/bikini/exploitarium) / [讨论](https://news.ycombinator.com/item?id=48698617)

### Apple 一边涨价，一边求购被列黑名单的中国内存厂

The Verge 的两条消息拼出同一张图：Tim Cook 把这轮涨价（16 寸 MacBook Pro 涨 300 美元、iPad Air 从 599 涨到 749 美元）归咎于 AI 推高的内存与存储成本，直言当前定价「不可持续」；与此同时，Apple 正向特朗普政府申请豁免，希望从被五角大楼列入黑名单的中国厂商 CXMT 采购 RAM 来缓解供应压力。一边是成本传导到消费者，一边是地缘政治卡住供应链，硬件成本正在变成科技巨头绕不开的难题。

→ [涨价](https://www.theverge.com/report/958678/apple-consumer-price-increase-ai-big-tech) / [求购 CXMT](https://www.theverge.com/tech/958707/apple-ram-buy-memory-blacklisted-china-cxmt)
