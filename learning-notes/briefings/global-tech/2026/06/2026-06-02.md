## 📌 头条

### NVIDIA 发布 RTX Spark：ARM 架构正式进军 PC 市场

NVIDIA 在 Computex 2026 发布 RTX Spark 超级芯片，将 20 核 Grace CPU（与 MediaTek 合作）和 6144 个 Blackwell GPU 核心集成在一颗 SoC 上，支持最高 128GB 统一内存。Microsoft 随即发布搭载该芯片的 Surface Laptop Ultra，定位为 MacBook Pro 竞品。这是 NVIDIA 首次进入消费级 PC 处理器市场，Dell、HP 等六家 OEM 将在今秋推出相关设备。HN 324 分、142 分讨论热度极高，标志着 Windows on ARM 进入高性能时代。

→ [NVIDIA 官方](https://www.nvidia.com/en-us/products/rtx-spark) / [Ars Technica](https://arstechnica.com/gadgets/2026/06/nvidia-gets-into-the-arm-pc-business-with-new-high-end-rtx-spark-processor)

### Red Hat npm 包遭供应链攻击，32 个包 72 秒内被植入后门

安全研究人员发现 @redhat-cloud-services 命名空间下 32 个 npm 包被植入名为 Miasma 的凭证窃取蠕虫，攻击者通过入侵 CI/CD 流水线（GitHub Actions OIDC）在 72 秒内完成全部投毒。该恶意软件在 npm install 时自动执行，窃取 CI secrets、云凭证和 SSH 密钥。每周下载量约 8 万次，影响面广。如果你使用了受影响版本，应立即轮换所有凭证。HN 727 分。

→ [GitHub Issue](https://github.com/RedHatInsights/javascript-clients/issues/492) / [Ars Technica](https://arstechnica.com/security/2026/06/dozens-of-red-hat-packages-backdoored-through-its-offical-npm-channel)
