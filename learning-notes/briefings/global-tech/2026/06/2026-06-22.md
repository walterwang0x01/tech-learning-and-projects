## 📌 头条

### 微软六月补丁修复 206 个漏洞，含三个零日和 HTTP.sys 高危 RCE

微软发布了史上最大规模的月度安全更新，修复 206 个 CVE（含第三方修复总计超 500 个）。其中 CVE-2026-47291 是 HTTP.sys 内核驱动的未认证远程代码执行漏洞（CVSS 9.8），攻击者仅需发送精心构造的 HTTP 包即可完全接管服务器。此外还有 CTF 本地提权零日与 HTTP/2 Bomb 漏洞（CVE-2026-49160）。更新已引发回收站异常、BitLocker 驱动锁定等副作用，IT 团队需在安全风险和稳定性之间快速决策。

→ [CrowdStrike 分析](https://www.crowdstrike.com/en-us/blog/patch-tuesday-analysis-june-2026/) / [Computerworld](https://www.computerworld.com/article/4184571/for-june-patch-tuesday-means-an-it-scramble.html)

---

### Rust 1.96 发布：新 Copy 友好 Range 类型与 Cargo 安全修复

Rust 1.96 稳定版上线，核心亮点是引入新的 Copy 友好 Range 类型，解决了长期以来 Range 不能 Copy 的痛点。同时稳定了断言宏、调整了 WebAssembly linker 行为，并修复了两个影响第三方 registry 的 Cargo 安全漏洞。对维护跨平台 CLI 工具和 WASM 项目的开发者尤为重要。

→ [Linuxiac 报道](https://linuxiac.com/rust-1-96-introduces-new-copy-friendly-range-types/) / [Release Notes](https://releases.rs/docs/1.96.0/)
