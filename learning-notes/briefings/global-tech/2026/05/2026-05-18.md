## 📌 头条

### BitLocker 默认配置被零日打穿，研究员选在 Patch Tuesday 之后公开

一个化名 Chaotic Eclipse 的安全研究员发布了 YellowKey 和 GreenPlasma 两个 Windows 零日。前者只要拿到物理访问权限，借助 Windows 恢复环境（WinRE）就能在几秒内绕过默认 BitLocker 加密拿到完整磁盘内容，受影响范围是 Windows 11、Server 2022/2025；后者把任意普通用户提权到 SYSTEM。研究员此前因为漏洞奖励纠纷已经放出过三个 Defender 级别的零日，这次刻意卡在五月 Patch Tuesday 之后丢出 PoC，明显是冲着 Microsoft 来的。对企业用户来说短期内只能依赖 TPM+PIN 这种非默认强化配置，单盘加密资产不能再当成"上锁了就安全"。

→ [Ars Technica 报道](https://arstechnica.com/security/2026/05/zero-day-exploit-completely-defeats-default-windows-11-bitlocker-protections) / [TechSpot/HN 讨论](https://www.techspot.com/news/112410-security-researcher-microsoft-secretly-built-backdoor-bitlocker-releases.html)

### Bun 把一百万行 Rust 一次性合进主干，Zig 版本就此谢幕

Bun 维护者 Jared Sumner 三天前还在 X 上说"这堆代码很可能整个被扔掉"，结果 Bun 1.3.14 发布的同时，那条把整个运行时从 Zig 重写成 Rust 的 PR 直接合进了 main 分支，Linux x64 glibc 上 99.8% 的旧测试已经能跑通。这意味着 1.3.14 是最后一个 Zig 版本，下一版起 Bun 完全 Rust 化。背后的故事是 Anthropic 团队全程在用 AI 协作做这种规模的语言迁移，让"AI 辅助下的大规模重写"从概念变成可见的工程动作；对运行时生态而言，JS 工具链从 Zig/C++ 转向 Rust 的趋势又添一例。如果你在生产里用 Bun，建议先盯几天 issue 区再升 1.3.15。

→ [The Register 报道](https://www.theregister.com/devops/2026/05/14/anthropics-bun-rust-rewrite-merged-at-speed-of-ai/5240381)
