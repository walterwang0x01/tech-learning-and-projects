## 📌 头条

### Anthropic 收购 Stainless：把 SDK 工具链从公共基础设施收编为自家武器

Stainless 这家成立于 2022 年的纽约创业公司，过去几年悄悄成了 AI 行业的「隐形管道」——OpenAI、Google、Cloudflare 的官方 SDK 都用它自动生成与维护。Anthropic 周一宣布把这家公司买下来，The Information 报道交易价值超过 3 亿美元。Anthropic 的官方说法是「前沿正从能回答问题的模型，转向能采取行动的 agent，而 agent 的能力上限取决于它能连到哪里」。

这桩并购的真正信号是：当大家都在卷模型本身时，Anthropic 选择把战场推向「模型与外部世界的连接层」。Stainless 同时是 MCP server 工具的核心维护者，意味着 MCP 生态的话语权进一步向 Anthropic 集中。对竞争对手而言，原本共享的开发者基础设施，明天可能就要换供应商或自己重做。

→ [Anthropic 公告](https://anthropic.com/news/anthropic-acquires-stainless) / [TechCrunch 报道](https://techcrunch.com/2026/05/18/anthropic-has-acquired-the-dev-tools-startup-used-by-openai-google-and-cloudflare)

### Cloudflare Project Glasswing：前沿模型已经能自己串起漏洞链做出 PoC

Cloudflare 公开了过去几个月内部用 Anthropic 未发布的 Claude Mythos 2 Preview 做漏洞研究的实战记录。最颠覆的发现：Mythos 不再像旧模型那样「找到一个可疑点就停下」，而是能生成 PoC 代码、扔进沙箱里跑、根据失败调整假设、再试。这是攻击者视角下「自动化漏洞研究」的临界点。

Cloudflare 文章里反复强调的是 harness 而不是模型——围绕模型设计的 7 阶段 agent 流水线（任务分解、扫描、复现、验证、缓解建议）才是工程上真正可复用的部分。Anthropic 同步上线了 Project Glasswing，跟关键基础设施方合作把这套能力先给防守方用。换句话说：你接下来构建任何安全相关 agent 时，要默认假设对手也有同等火力。

→ [Cloudflare 博客](https://blog.cloudflare.com/cyber-frontier-models) / [Anthropic Glasswing](https://www.anthropic.com/glasswing) / [HN 讨论 277 分](https://news.ycombinator.com/item?id=48179732)
