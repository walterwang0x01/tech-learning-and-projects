### 2. Bun 开始从 Zig 迁移到 Rust，HN 409+464 分双帖爆发

- **来源**：[Bun is being ported from Zig to Rust](https://github.com/oven-sh/bun/commit/46d3bc29f270fa881dd5730ef1549e88407701a5)
- **标签**：`Bun` `Zig` `Rust` `JavaScript 运行时` `重写`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 4 = 总分 19
- **摘要**：Bun 团队开始将核心代码从 Zig 迁移到 Rust。同日另一篇"I am worried about Bun"文章获得 464 分 / 311 评论，讨论 Bun 的技术方向和可持续性。背景：Zig 社区强化了 LLM 贡献禁令，而 Bun 的一个 4 倍编译加速优化因使用了 AI 辅助而无法上游到 Zig。
- **影响**：这是 JavaScript 运行时生态的重大技术决策。Zig → Rust 的迁移反映了 Rust 在系统编程领域的持续扩张，也暴露了 Zig 社区 AI 禁令对下游项目的实际影响。对使用 Bun 的项目来说，短期可能面临稳定性波动。
- **行动建议**：如果生产环境使用 Bun，关注迁移进度和稳定性；评估是否需要备选方案

### 3. Microsoft Edge 启动时将所有密码以明文存储在内存中，HN 506 分

- **来源**：[Microsoft Edge stores all passwords in memory in clear text](https://twitter.com/L1v1ng0ffTh3L4N/status/2051308329880719730)
- **标签**：`安全` `Microsoft Edge` `密码` `漏洞` `浏览器`
- **评分**：时效 5 / 一手 5 / 相关 5 / 实用 5 = 总分 20
- **摘要**：安全研究员披露 Microsoft Edge 在启动时解密所有保存的密码到进程内存中，以明文形式保留整个会话期间——即使用户从未访问这些密码对应的网站。HN 获得 506 分 / 181 条评论。这意味着任何能读取 Edge 进程内存的恶意软件都能一次性获取所有密码。
- **影响**：这是一个严重的浏览器安全设计缺陷。对所有使用 Edge 内置密码管理器的用户来说，风险显著。建议迁移到专用密码管理器（1Password、Bitwarden 等）。
- **行动建议**：立即评估是否使用 Edge 密码管理器；考虑迁移到独立密码管理器；关注 Microsoft 的修复时间线
