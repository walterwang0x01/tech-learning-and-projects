## 📌 头条

### Python 3.14/3.15 将回滚增量 GC，恢复代际式架构

Python 核心开发者 Hugo van Kemenade 宣布，Python 3.14 和 3.15 将同时回滚增量垃圾回收器，恢复至 3.13 时期的代际式 GC。增量 GC 原本旨在降低暂停时间、提升实时响应能力，但上线后大量生产环境报告显示其导致了显著的内存压力。这是 CPython 近年来罕见的"发布后回滚"决策，意味着依赖 3.14 新 GC 行为的项目需要重新评估内存管理策略。

→ [原文](https://www.oschina.net/news/440466)

### Microsoft 五月 Patch Tuesday：30 个严重漏洞，含 CVSS 10 分

Microsoft 发布了 5 月安全更新，修复 137 个 CVE，其中 30 个被评为 Critical 级别，14 个 CVSS 评分达 9.0 以上，包括一个满分 10 的 Azure DevOps 信息泄露漏洞（CVE-2026-42826）。Windows Netlogon 栈溢出（CVE-2026-41089，CVSS 9.8）和 DNS 客户端堆溢出（CVE-2026-41096，CVSS 9.8）尤其值得关注——前者可直接获取域控权限，后者可能导致企业网络大规模沦陷。

→ [Krebs on Security](https://krebsonsecurity.com/2026/05/patch-tuesday-may-2026-edition/) / [The Register](https://theregister.com/patches/2026/05/13/doozy-of-a-patch-tuesday-includes-30-critical-microsoft-cves/5239224)
