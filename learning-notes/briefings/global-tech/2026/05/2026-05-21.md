### GitHub 自爆：员工装了一个 VS Code 恶意扩展，3800 个内部仓库被偷

GitHub 本周二夜间公开承认：5 月 19 日检测到一名员工的设备被一个被投毒的 VS Code 扩展拿下，攻击者借此横向访问了大约 3800 个 GitHub 自己的内部仓库。声称行凶的是与 Shai-Hulud 蠕虫有关联的 TeamPCP，已经在暗网论坛挂牌叫卖、要价 5 万美元。GitHub 强调客户代码与平台数据未受影响，但这层表态本身就承认了——一个 VS Code 扩展能直接打穿全球最大代码托管平台的内网。

最值得让人冒汗的不是代码外泄本身，而是攻击链：单个开发者插件 → 员工本机 → 内部 git。这条路径每天在 200 万开发者机器上都是开放的，没有任何 OS 级 sandbox。继昨天 Grafana 被 GitHub Actions 注入、CISA 把 GovCloud 密钥推到公开仓库之后，这是同一周内第三起「开发者工具链就是攻击面」的工业级事件。今晚就该问自己两件事：本机 VS Code 跑了多少没审过的扩展？公司内网的 Git 凭证有没有跟开发机绑死？

### SpaceX 同一天交了史上最大 IPO 申请，今晚押 V3 首飞

5 月 20 日 SpaceX 把 S-1 招股说明书正式递到 SEC，准备以 SPCX 上 Nasdaq，传出来的目标募资规模最高 750 亿美元——如果落定就是史上最大 IPO。第一次公开的财务也很戏剧：2025 全年收入 187 亿（同比从 140 亿增长），Starlink 一家就贡献 114 亿收入、44 亿运营利润；但 2026 Q1 收入 47 亿同时净亏 43 亿——投入端在烧。Musk 通过双层股权保留全部投票权控制。同一天，SpaceX 把 Starship V3 完成堆叠，今晚（美东 5/21 18:30）准备进行 Flight 12，是 V3 这个史上最大火箭的首次入轨级试飞。

把这两件事放在同一天看就明白这次 IPO 的故事框架：Starlink 已经是赚现金的成熟资产负责估值锚，Starship 是带着 28.5 万亿美元 TAM 故事和「让人类多行星化」的远景叙事负责拉倍数。资本市场以前要么是看 ARR 的 SaaS，要么是看储量的能源；SpaceX 是第一家用「火箭试飞节奏」直接驱动估值曲线的发行人。今晚试飞如果成或炸都会立刻被画进路演 deck。
