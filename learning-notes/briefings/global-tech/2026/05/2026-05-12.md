### Google GTIG 首次记录 "AI 加持"零日：2FA 绕过、针对开源运维工具、差点成规模化利用事件

Google Threat Intelligence Group 5 月 11 日发出的报告坐实了一件所有人之前只敢假设的事——**真实世界里已经出现由 AI 辅助开发的零日漏洞**，目标是一个未公开名字的开源 web 管理工具，攻击者原本要把它做成 "mass exploitation event"、绕过 2FA 去批量接管。Google 说他们是通过 Gemini + GTIG + Mandiant 的三层遥测捕到，然后在爆发前通知了上游厂商把洞堵上。Forbes 披露细节：开发这个 exploit 的威胁组织属于 "knowledgeable cybercrime" 级别，并非国家行为体；CSO Online 和 SecurityWeek 都跟进了"第一次 in-the-wild AI-crafted zero-day"这个定性。这条的重量不在漏洞本身，而在**门槛被拉平了**——过去零日属于有专门漏洞团队的国家和 APT，现在 AI 辅助工具让中等规模犯罪团伙也能把 exploit 工程化。配合 Guardian 同日 "AI-powered hacking 已成为工业级威胁"那份报告，以及 Anthropic 几周前关于 Mythos 找到数万 CVE 的豪言，**2026 下半年的甲方安全预算很可能会被重写**：SAST/DAST 吃 AI、蓝队的 patch SLA 从周压到天、BYOD/SSO 的 2FA 策略重做。短期可做的动作：检查你依赖的 web admin panel 是否暴露到公网，把 2FA 从 SMS/TOTP 升级到 WebAuthn/Passkey，把内部管理工具塞到 ZTNA 后面。

→ [The Verge 报道](https://www.theverge.com/tech/928007/google-ai-zero-day-exploit-stopped) / [GTIG 原文](https://cloud.google.com/blog/topics/threat-intelligence/ai-vulnerability-exploitation-initial-access) / [Forbes 细节](https://www.forbes.com/sites/thomasbrewster/2026/05/11/cybercriminals-make-powerful-zero-day-hack-with-ai-google-warns/) / [The Hacker News 技术复盘](https://thehackernews.com/2026/05/hackers-used-ai-to-develop-first-known.html)

### GitLab 宣布"agentic era"重组：裁员 + 拍平管理层 + 60 个自治 R&D 小队，HN 冲到 294 分

GitLab CEO Bill Staples 5 月 11 日发内部信同日对外发文：公司要为"AI 代理时代"重构组织，动作清单非常具体——**拍平管理层、把 R&D 拆成 60 个自治小队、国家覆盖面削减 30%、用 AI agent 自动化内部评审/审批/交接**，至于实际裁多少人要到 6 月 2 日财报日才公布。股价盘后下跌，HN 那边 294 分、294 评论，讨论焦点是 CREDIT（Collaboration / Results / Efficiency / Diversity / Iteration / Transparency）六个老价值观里的 "CREDIT" 这组缩写也被官方埋掉。Business Insider 拿到的原始 memo 里 Staples 坦承"接下来几周对团队来说是真正的 unclear period"。放到行业里看，GitLab 不是第一个也不是最后一个——GM 同日宣布砍 500–600 名 IT 员工、Fortune 同日引 Gartner 数据说 80% 试点 AI/自动化的公司确实裁了人、但多数"无论 ROI 如何都照裁"。**对 Walter 这种关注 LangGraph/MCP/CrewAI 链路的工程师来说**，这波重组的信号是：开发者工具公司的商业模型正从"订阅席位"滑向"订阅 agent workflow 次数"，GitLab Duo / GitHub Copilot / Cursor 大家都在抢同一个 P&L 结构；HN 评论里一条高赞提醒是，"把 R&D 拍平成 60 个小队"本质是把 engineering manager 层替换成 AI 编排层，这对传统中层的职业曲线是直接冲击。

→ [GitLab 官方博文](https://about.gitlab.com/blog/gitlab-act-2) / [HN 讨论](https://news.ycombinator.com/item?id=48100500) / [Business Insider CEO memo 全文](https://www.businessinsider.com/gitlab-layoffs-memo-2026-5) / [TheNextWeb 分析](https://thenextweb.com/news/gitlab-layoffs-agentic-era-devops-ai)
