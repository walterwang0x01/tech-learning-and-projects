## 📌 头条

### Cloudflare Agents Week 开幕：Workers 跨语言 RPC、原生 TCP/gRPC 全面开放

Cloudflare 于 8 月 3 日启动 Agents Week，一口气推出多项面向 Agent 原生基础设施的能力。Workers RPC 现在支持 Python 与 JavaScript 之间直接调用对象方法，无需定义 API schema 或序列化逻辑；Workers 和 Containers 新增入站 TCP 连接（通过 Spectrum）及原生 gRPC 支持，开发者可以直接在 Workers 中跑全双工 gRPC 应用。同时发布的 @cloudflare/computer 包将 isolate 和完整 Linux 容器编排合一，为每个 Agent 提供按需计算环境。此外还有面向 FinOps 的 Billable Usage API（基于 FOCUS 规范），统一暴露所有自助产品的用量与成本数据。

→ [Workers RPC 跨语言](https://blog.cloudflare.com/python-workers-rpc) / [TCP/gRPC 支持](https://blog.cloudflare.com/grpc-workers) / [@cloudflare/computer](https://blog.cloudflare.com/cloudflare-computer) / [Billable Usage API](https://blog.cloudflare.com/billable-usage-api)

### Andy Pavlo 加入 ClickHouse，创立 ClickHouse Labs 研究组

CMU 数据库系统教授 Andy Pavlo 宣布以 VP of Database Research 身份加入 ClickHouse，创建 ClickHouse Labs 研究团队。Pavlo 是数据库学术界最具影响力的人物之一，长期维护 CMU 的数据库系统基准测试和课程，此举标志着 ClickHouse 正式在学术-工业结合方向押注。HN 评论 269 分、56 条讨论，社区反响强烈。

→ [Pavlo 本人公告](https://clickhouse.com/blog/andy-pavlo-joins-clickhouse) / [ClickHouse 官宣](https://clickhouse.com/blog/andy-pavlo-founding-clickhouse-labs)

## ⚡ 快讯

- **EU AI Act 透明义务**：8 月 2 日起，EU AI Act 第 50 条正式生效：聊天机器人必须告知用户正在与 AI 交互，生成式 AI 内容须附机器可读标记，深伪内容须明确标注。违规罚款最高 1500 万欧或全球营收 3%。 → [欧盟委员会公告](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1714)
- **Rust 2026 项目目标**：Rust 官方公布 Move trait 和 guaranteed destructors 提案为 2026 年度项目目标——让所有类型默认可移动的假设变为显式 trait，为 self-referential struct 和安全析构铺路。HN 233 分讨论激烈。 → [提案全文](https://github.com/rust-lang/rust-project-goals/blob/main/src/2026/move-trait.md)
- **Kubernetes Gateway API v1.6**：TCPRoute 和 UDPRoute 正式从 Experimental 晋升为 Standard（v1 API），Gateway API 补齐 L4 路由最后一块拼图。v1alpha2 版本已标记弃用。 → [官方博客](https://kubernetes.io/blog/2026/08/03/gateway-api-v1-6-release)
- **"Devtools Must Be Open Source"**：exe.dev 发表的文章登上 HN 头条（496 分、177 条评论），论点是开发者工具的信任基础在于源码可审计，闭源 devtools 最终会失去开发者心智份额。 → [原文](https://blog.exe.dev/devtools-must-be-open-source)
- **Horizon3 E 轮 $2.5 亿**：AI 渗透测试安全公司 Horizon3 完成 $2.5 亿 Series E，估值 $20 亿。核心卖点是用 AI 做持续安全验证（autonomous pentesting）取代传统年度人工渗透测试。 → [TechCrunch](https://techcrunch.com/2026/08/03/horizon3-hits-2-billion-valuation-with-250m-series-e-as-ai-threats-escalate)
- **Valar Atomics 核能融资 $10 亿**：Sequoia 领投核能初创 Valar Atomics $10 亿 B 轮，估值 $60 亿，6 月已与 Nvidia 签订开发协议。AI 基础设施对清洁能源的需求继续推高核能赛道估值。 → [TechCrunch](https://techcrunch.com/2026/08/03/sequoias-shaun-maguire-leads-1b-round-for-nuclear-startup-valar-atomics)
- **Arch Linux 十年核心维护者离职**：Morten Linderud（Foxboron）在担任 Arch Linux 开发者、包维护者和安全团队成员约十年后宣布离开。他是 WPA_Supplicant 等包的唯一维护者，也是 Git 迁移的初始推动者。 → [开源中国报道](https://www.oschina.net/news/486320)
