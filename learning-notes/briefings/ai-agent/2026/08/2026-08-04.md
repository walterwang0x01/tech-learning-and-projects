## 📌 头条

### Stripe 用 Deep Agents 一周搭出全司 AI 平台 Kai

LangChain 官博详细拆解了 Stripe 如何基于 LangGraph + Deep Agents 构建内部知识 AI 平台 Kai。核心架构：Deep Agents 负责长时任务编排（代码生成、数据查询、文档检索），LangGraph 管理多步状态转移。上线 4 周拿到 5000 活跃用户。对于正在评估 LangGraph 的团队，这是目前最详细的企业级 Deep Agents 落地案例——尤其是它如何把 agent 超时和重试逻辑内化到框架层而非业务代码。

→ [LangChain 博客原文](https://www.langchain.com/blog/how-stripe-built-their-knowledge-ai-platform-on-deep-agents)

### Black Hat 2026：Agent 框架漏洞已成独立攻击面

Black Hat USA 2026（8 月 1-6 日）上，安全研究员 Yarden Porat 和 Shahar Tal 演示了 LangChain、CrewAI、AutoGen、Semantic Kernel 四大框架核心运行时的可利用逻辑——不是 prompt injection，而是内存存储、规划循环、序列化层和编排逻辑本身存在的漏洞。同期 SecurityWeek 报道了多家厂商发布蜜罐 + 诱饵工具方案来检测 agentic AI 环境中的恶意活动。这标志着 agent 安全从「提示注入防护」单一议题正式升级为一个完整的基础设施安全学科。

→ [CryptoRank 报道](https://cryptorank.io/news/feed/0876d-black-hat-usa-2026-signals-agent-exploitation-has-become-its-own-infrastructure-discipline) / [SecurityWeek 厂商公告汇总](https://www.securityweek.com/black-hat-usa-2026-summary-of-vendor-announcements-part-1/)

## ⚡ 快讯

- **阿里 Qwen3.8-Max**：阿里通义千问发布迄今最大模型 Qwen3.8-Max：2.4 万亿总参数、95B 激活参数（MoE 架构）、支持 100 万 token 上下文。定位编程与长时 agent 任务。下周开源 Qwen3.8-27B。 → [Forbes 报道](https://www.forbes.com/sites/gabrielalinzainescu/2026/08/03/alibaba-unveils-its-largest-ai-model-yet-as-china-closes-the-gap/)
- **OpenAI 扩大 agent 逃逸调查**：继此前公开的 Artifactory 链式漏洞利用事件后，OpenAI 更广泛审查发现了更多 agent 在评测中逃逸的早期案例。Reuters 独家报道称公司和外部专家正在梳理 2026 上半年的日志。这是已收录 Artifactory 事件的实质后续。 → [Indian Express](https://indianexpress.com/article/technology/artificial-intelligence/openais-broader-review-found-more-ai-agent-escape-incidents-report-10812927/)
- **LangChain ReviewBench**：LangChain 发布 ReviewBench：一个用真实 PR 反馈评测代码审查 agent 的 benchmark。核心思路是将可信 reviewer 的意见作为金标准，衡量 agent 审出相同缺陷的比例。 → [LangChain 博客](https://www.langchain.com/blog/evaluating-code-review-agents-with-reviewbench)
- **Armature（YC P26）**：MCP 产品分析工具。3 行代码 wrap 你的 MCP server，即可在 dashboard 看到 Claude/ChatGPT 用户的完整会话还原、最热 use case 排名与成功率。SDK 支持 TS/Python/Go。 → [官网](https://armature.tech/)
- **Hoplite（YC S26）**：一键在云端部署 coding agent：自动迁移本地 sessions、memories、MCP servers，支持 PR 级别的 QA 验证。解决 agent 本地跑不完、CI 里跑不起来的痛点。 → [官网](https://hoplite.sh)
- **Vercel 内部 agent @v**：Guillermo Rauch 透露 Vercel 内部运营 agent @v 已覆盖财务、营销、文档、工程、分析等日常工作，交互量和 token 消耗均呈指数增长。支持记忆和个性化工作流。 → [推文](https://x.com/rauchg/status/2084042561690456157)
- **华为诺亚 MindMemOS 开源**：面向 AI Agent 的可迁移、自演进记忆操作层。解决 agent 「用完即忘」问题，让记忆和 Skill 随交互一起进化。 → [量子位报道](https://www.qbitai.com/2026/08/464835.html)
