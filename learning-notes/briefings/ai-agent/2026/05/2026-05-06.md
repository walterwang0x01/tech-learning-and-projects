### Chrome 静默装下 4GB Gemini Nano，Agent 时代的"默认信任"被击穿

一位隐私研究员发现 Chrome 在用户毫不知情的情况下把 Gemini Nano 的 weights.bin 静默下载到 `OptGuideOnDeviceModel` 目录，删掉会被自动再装一次，设置里找不到直接的 opt-out，只能通过 `chrome://flags` 关闭 Optimization Guide on Device Model 和 Prompt API。HN 上一天内冲到 1247 分、841 条评论，是本月最大的一次 AI 信任危机事件。问题不在模型本身，而在交付方式——当浏览器把 4GB 的 LLM 当作"合法更新"推送时，它重新定义了桌面软件与用户之间的边界。如果你在做端侧 Agent 或隐私敏感的 AI 产品，今天就该检查一下用户设备上到底多了哪些你没解释清楚的二进制。

→ [研究员原文](https://www.thatprivacyguy.com/blog/chrome-silent-nano-install/) / [HN 讨论](https://news.ycombinator.com/item?id=48019219) / [Techspot 复现](https://www.techspot.com/news/112309-google-chrome-has-silently-pushing-4gb-ai-model.html)

### Anthropic 连夜发金融 Agent 模板，把前一天的 15 亿美元 JV 变成能卖的东西

昨天刚宣布和 Blackstone、Goldman Sachs 成立 15 亿美元合资企业，Anthropic 今天就端出 10 个开箱即用的金融 Agent 模板——覆盖 pitchbook 生成、信贷备忘、KYC 筛查、财报审计等核心流程，能直接插在 Claude Code 和 Cowork 之上并按客户合规策略定制。同一天 Dario Amodei 和 Jamie Dimon 首次同台，公开讲 Anthropic 在华尔街的"两条腿"战略：大机构用 API 自建、中型企业用 JV 交付。这是 AI 公司从"卖能力"滑向"卖工作流"的最清晰案例——模板不是炫技，是告诉投资人"我们今天就能收到钱"。如果你在做行业垂直 Agent，值得把这 10 个模板的任务划分当作参考框架。

→ [Anthropic 官方](https://www.anthropic.com/news/finance-agents) / [Reuters](https://www.reuters.com/business/finance/anthropic-deepens-finance-push-with-10-new-ai-agents-banks-insurers-2026-05-05/) / [Fortune 现场](https://fortune.com/2026/05/05/anthropic-wall-street-financial-services-agents-jamie-dimon/)
