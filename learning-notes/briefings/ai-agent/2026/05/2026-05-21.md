### Google I/O 2026：Gemini 3.5 Flash 与 Antigravity 一起押注 Agent

Google 同时甩出了三件事：模型 Gemini 3.5 Flash、SDK Antigravity（20 行 Python 起一个本地 Agent）、以及把 Gemini CLI 改名为 Antigravity CLI 并升级成 Agent 优先的统一开发平台。Flash 这次的主战场是 agentic：Terminal-Bench 2.1 76.2%、MCP Atlas 83.6%、SWE-Bench / OSWorld 都领跑，比上一代 3 Flash 在复杂知识工作任务上提升 12 个百分点（Box AI 实测）。配合 Android Studio 内置 Claude Code / Codex / Antigravity / Gemini 多 Agent 集成，Google 这一轮等于把整条工具链一次性 agent 化，对个人开发者最直接的动作是装一下 Antigravity CLI、用 SDK 起个本地 demo 感受下延迟差。

→ [Google 官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5) / [Antigravity SDK](https://www.oschina.net/news/443108/google-antigravity-sdk) / [CLI 更名](https://www.oschina.net/news/443081/google-transitioning-gemini-cli-to-antigravity-cli) / [Matt Turck 评价](https://x.com/mattturck/status/2056834038946775343)

### Karpathy 加盟 Anthropic，DeepSeek 同步组 Harness 团队

> ⚠️ 待确认：Karpathy 加入 Anthropic 截至发稿仅见 X 推文与多方转载，未见 Anthropic 官方公告。

Andrej Karpathy 在 X 宣布加入 Anthropic（推文 1.5 万转、11.9 万赞、近 1600 万浏览），他自己定调「未来几年是 LLM 关键塑形期」。同一天 DeepSeek 公开招聘 Agent Harness 产品经理，公式直白：Model + Harness = Agent，承认要补的不是模型而是工程外壳——记忆、工具调用、长任务可靠性那一层。两件事拼一起的信号很清楚：第一线选手都在押 Agent 这条线，分化点是给底座包什么样的工程化外壳。Walter 这边可以重点观察 Anthropic 接下来在 Claude Code / Routines 上的迭代节奏。

## 📈 趋势

- 🔺 Agent-first 工具链：Google 把 CLI / SDK / Studio 一次性切换到 Agent 形态，Anthropic 用 Routines 加云端调度，开发者侧的「写代码」正变成「编排 agent」
- 🔺 Harness 比模型更值钱：DeepSeek 公开招聘把 Model + Harness = Agent 写在了招聘公式里，Cursor Composer 2.5 也用工程层把成本压到 Opus 1/10
- 🆕 长程 Agent 评测起势：DecisionBench / TwinRouterBench / RecoAtlas 一周内连发，社区终于开始把单 prompt 评测换成多步、多模型、带成本的真实工作流
- 🔺 Agent 安全研究爆发：prompt injection（ESLD）、记忆中毒（OEP）、多轮多模态攻击（Surviving the Unseen）、工作隐私越界（PrivScope）这周同时出现在 arXiv，说明 agent 部署侧的攻击面已经暴露
