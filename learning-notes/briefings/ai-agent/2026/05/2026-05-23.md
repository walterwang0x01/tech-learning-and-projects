## 📌 头条

### Anthropic 给 Claude Managed Agents 加 MCP 隧道，私网工具不再上公网

Anthropic 这一波给 Claude Managed Agents 同时上线了两个新东西：自托管 sandbox（公开 beta）和 MCP 隧道（research preview）。最关键的是 MCP 隧道——出站、加密的轻量网关，让 agent 能调企业内网的私有 MCP 服务器（数据库、票务系统、知识库），但凭据始终不进入 agent 的上下文，编排循环还跑在 Anthropic 这边。这等于给「企业愿意接入」拆掉了最后一道安全顾虑：以前要么把内部 API 暴露到公网、要么自己整套自托管，现在中间多了一条出站隧道。如果你在做企业 MCP 集成，今天就该去申请 research preview 把方案改成隧道形态，别再做反向代理那一套了。

→ [Anthropic 公告](https://claude.com/de/blog/claude-managed-agents-updates) / [InfoQ 中文](https://www.infoq.cn/article/jvoDNDaa2bRzwrHQy7lT) / [凭据隔离分析](https://brightbean.xyz/blog/anthropic-mcp-tunnels-credentials-claude-agents/)

### Gemini 3.5 砍半定价、4 倍提速强势入场

Google I/O 2026 把 Gemini 3.5 端上来了：相比 3.0 推理速度快 4 倍、定价直接砍半，皮查伊在台上算账说光是谷歌内部一年就能省下 10 亿美元的推理成本。这不是单纯的版本号迭代，是把「前沿智能 + 极速推理」当作 agent 时代的胜负手——agent 的 token 消耗是 chat 的几十倍，谁的推理便宜谁就能跑得起更长的上下文和更多步骤。Claude Opus 4.7 这边在限速争议里还在解释「最挑剔的用户最离不开我们」，对比之下压力肉眼可见。如果你的 agent pipeline 还卡在 token 预算，本周就该把 Gemini 3.5 拉进 A/B 跑一遍。

→ [InfoQ 拆解](https://www.infoq.cn/article/COda3jCSAliReaA4YVJc) / [开源中国对照分析](https://www.oschina.net/news/444145)
