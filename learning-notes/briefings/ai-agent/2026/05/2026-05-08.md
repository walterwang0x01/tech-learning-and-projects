## 📌 头条

### OpenAI GPT-5.5-Cyber 限量发布，Anthropic 把 Petri 捐给独立非营利

过去 24 小时，头部实验室在「可信代理」这条赛道同时出牌。OpenAI 把 GPT-5.5 的网络安全变体 GPT-5.5-Cyber 通过「Trusted Access for Cyber」框架交给经过审核的防御团队——本质上是用身份认证换更宽松的能力边界，正面对标一个月前 Anthropic 的 Claude Mythos Preview。几乎同时，Anthropic 宣布把开源对齐审计工具 Petri 升级到 3.0 并整建制捐给新成立的 Meridian Labs，让它脱离厂商立场变成行业中立评测标准。对做 agent 的人来说，这意味着两件事：一是「能力分层放开」会是 2026 下半年 API 的常态，你需要评估自己的业务是否值得走认证通道；二是 Petri 作为中立工具链稳定下来后，对自己的 agent 做 deception/sycophancy 审计的门槛进一步降低。

→ [GPT-5.5-Cyber](https://openai.com/index/gpt-5-5-with-trusted-access-for-cyber) / [Petri 捐赠公告](https://www.anthropic.com/research/donating-open-source-petri)

### OpenAI 一次扔出三个 Realtime 语音模型，把 voice agent 推过拐点

同一天 OpenAI 在 API 里上线 GPT-Realtime-2、GPT-Realtime-Translate、GPT-Realtime-Whisper 三件套。关键升级在 Realtime-2——带 GPT-5 级推理，能边说边调工具、处理打断，而不是退化到命令-响应式对话；Translate 覆盖 70+ 输入语种对 13 种输出；Whisper 做高保真 ASR。去年做 voice agent 最大的痛点是「推理一开，延迟就崩」，这次把推理塞进 realtime 管道本身，意味着后续所有 Realtime API 接入方都能吃到能力红利。如果你之前搁置过语音场景，现在值得重新跑一轮 playground 的 E2E 延迟测试。

→ [OpenAI 公告](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/) / [TechCrunch](https://techcrunch.com/2026/05/07/openai-launches-new-voice-intelligence-features-in-its-api/)
