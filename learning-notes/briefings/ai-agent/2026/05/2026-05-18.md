### OpenAI 周末大重组：Brockman 接管产品，ChatGPT 与 Codex 并成"单一 agentic 平台"

周五的内部备忘录被 Wired 拿到、整个周末在 X 和媒体上发酵：Greg Brockman 正式从临时位置转正，接过 OpenAI 全部产品线；同时官方决定停掉所谓的 "side quests"，把 ChatGPT、Codex、Developer API "consolidate" 成一个 unified agentic platform，由一个核心产品团队统一支撑。这是 OpenAI 第一次把组织阵型完全押在 agent 而不是聊天机器人或单点工具上——含义是 ChatGPT 后续会是 agent 主线、Codex 不再是平行品牌、API 表面也会被规整。Steinberger 周末同时在 X 喊"deslop your Claude code if you haven't yet switched to Codex"，从 builder 侧也能感觉到风向。对正在做 multi-agent / agentic CLI 的团队，这周该做两件事：把还在用的旧 Codex CLI 入口梳理一遍预计哪些会合并或弃用，把现有 OpenAI API 调用按照"未来都是 agent endpoint"的假设重新审计权限边界。

### Microsoft 安全实验室：当 prompt 变成 shell — Agent 框架级 RCE 漏洞披露

微软安全博客上周四发布的《When prompts become shells》在周末持续刷屏：研究员在多家主流 agent 框架里复现了从 prompt injection 直接落到 RCE 的链路——攻击者只要能控制注入到工具插件参数里的字符串，agent 就可能"被"执行远超预设范围的动作。同期 The Next Web 披露 Anthropic、Google、Microsoft 三家都已经为类似 agent 漏洞悄悄付了 bug bounty，但都没有公开 advisory、也没有分配 CVE，导致用户根本不知道自己版本有没有问题。再叠加 Google 4 月那份 Common Crawl 调研：从 2025 年 11 月到 2026 年 2 月间恶意 indirect prompt injection 增长 32%，整条 agent 安全曲线已经从理论威胁变成生产事故。Walter 这边今天该做的最小动作：把生产里 agent 工具调用过一遍，把高权限 tool（文件系统、shell、数据库写入）从默认全允许改为白名单+人 audit，把 outbound HTTP 工具加上 allowlist 域名限制，再把日志做到能溯源到具体 user prompt。

→ [微软原文](https://www.microsoft.com/en-us/security/blog/2026/05/07/prompts-become-shells-rce-vulnerabilities-ai-agent-frameworks/) / [The Next Web 三家厂商隐藏赔款](https://thenextweb.com/news/ai-agents-hijacked-prompt-injection-bug-bounties-no-cve) / [TechRepublic IPI 实战化](https://www.techrepublic.com/article/news-ai-agents-prompt-injection-data-security/)
