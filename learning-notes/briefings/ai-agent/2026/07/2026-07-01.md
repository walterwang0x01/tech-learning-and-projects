## 📌 头条

### Anthropic 发布 Claude Sonnet 5，Agent 成本大降

Anthropic 正式推出 Claude Sonnet 5，主打更强的 agentic 能力、更低定价和改进的安全性。官方将其定位为 Opus、GPT-5.5 和 Gemini Pro 的低成本替代方案——同一天 Claude Science（科研工作台）也正式上线。这意味着跑 agent 循环的 token 开销显著下降，尤其适合需要长上下文多轮交互的场景。如果你在用 Claude API 做 agent 编排，现在是切换到 Sonnet 5 跑 benchmark 的好时机。

→ [TechCrunch 报道](https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents) / [Anthropic 官方](https://www.anthropic.com/news/claude-sonnet-5)

---

### X（Twitter）上线官方 MCP Server

X 正式发布托管式 MCP server，让开发者可以通过 Model Context Protocol 将 AI 应用直接连接 X 的 API。这是继 GitHub、Slack 之后又一个主流平台原生支持 MCP。对于做 social agent 或信息聚合工具的开发者来说，不再需要自己维护 OAuth + 爬虫的拼装方案了。MCP 生态的 network effect 在加速，值得关注哪些平台还没接入。

→ [TechCrunch 报道](https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use)

## ⚡ 快讯

- **DeepSeek V4**：正式版将于 7 月中旬上线，首次引入峰谷定价——北京时间 9-12 点和 14-18 点价格翻倍，其余时段维持基准价。对高频 API 调用者有直接成本影响。 → [详情](https://www.oschina.net/news/470031)
- **Ornith-1 开源**：DeepReinforce 团队基于 Qwen 3.5 + RL post-training 的编码 Agent，SWE-bench 达 82.4%（同尺寸最佳），四个规格 9B/31B/35B MoE/397B MoE，MIT 许可。 → [详情](https://www.oschina.net/news/470235/ornith-1-0)
- **LangChain Deep Agents**：发布无沙箱运行不可信代码方案：WASM + QuickJS 进程内隔离 + 最小权限 capabilities + 快照持久化暂停，替代传统容器沙箱。 → [博客](https://www.langchain.com/blog/running-untrusted-agent-code-without-a-sandbox)
- **Claude Code 隐私争议**：Reddit 用户逆向发现 Claude Code v2.1.91 存在隐蔽的代理检测和时区扫描行为，国产替代 SolonCode 借势宣传隐私优先设计。 → [详情](https://www.oschina.net/news/470553)
- **Claude 入驻 Microsoft Foundry**：Claude Opus 4.8 和 Haiku 4.5 在 Azure 上 GA，支持 prompt caching 和 extended thinking，Azure 认证和账单体系直通。 → [推文](https://x.com/claudeai/status/2071653958905467027)
- **Codex 权限沙箱升级**：OpenAI 为 Codex 上线可复用、可继承的权限 profiles：OS 级文件读/写/拒绝规则（含 **/*.env 通配）+ 域名级网络策略 + fail-closed 管理员白名单。 → [推文](https://x.com/thsottiaux/status/2071636285807059315)
- **agency-agents**：一个纯 Shell 脚本实现的 AI agent 编排工具，一天涨了 1425 GitHub stars，登顶 trending。极简主义路线的又一验证。 → [详情](https://www.oschina.net/news/469945)
- **AWS CloudFormation Express**：新 Express mode 将基础设施部署速度提升最多 4 倍，官方明确提及为 AI agent 快速迭代场景设计，所有商业 Region 免费可用。 → [AWS Blog](https://aws.amazon.com/blogs/aws/accelerate-your-infrastructure-deployments-by-up-to-4x-with-aws-cloudformation-express-mode)
