## 📌 头条

### OpenAI 发布 Presence 企业 Agent 部署平台

OpenAI 于 7 月 22 日正式发布 Presence，面向企业客户的 AI Agent 部署产品，覆盖语音和文本双通道。Presence 已在 OpenAI 自有 1-800-CHATGPT 热线上线运行，官方声称 75% 的来电问题无需人工介入即可解决。平台内置权限策略、知识接入和系统集成能力，企业可将 Agent 部署到客服、销售、内部流程等场景。这标志着 OpenAI 从 API 供应商向 Agent-as-a-Service 平台商转型的重要一步。如果你在做企业级 Agent 方案选型，Presence 的白手套交付模式和定价值得跟进。

→ [官方博客](https://openai.com/index/introducing-openai-presence/)

### Anthropic Claude 语音模式升级：支持 Opus/Sonnet + 跨应用操作

Anthropic 7 月 23 日宣布 Claude 语音模式重大更新：首次支持 Opus 和 Sonnet 模型（此前仅限 Haiku），用户可在对话中实时切换模型级别。更重要的是新增跨应用生态能力——语音模式可直接操作 Gmail、Slack、日历等第三方应用，实现 "用嘴说就能帮你干活" 的 Agentic 体验。免费用户仍限 Haiku + 单个连接器，Pro/Max 用户解锁全部能力。这把 Claude 的语音模式从 "聊天" 推进到了 "执行"。

→ [The Verge](https://www.theverge.com/ai-artificial-intelligence/970065/anthropic-voice-mode-claude-opus-sonnet-haiku-ai) / [TechCrunch](https://techcrunch.com/2026/07/23/anthropic-updates-claude-voice-mode-with-more-capable-models/)
