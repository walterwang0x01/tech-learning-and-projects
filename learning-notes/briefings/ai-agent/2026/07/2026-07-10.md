## 📌 头条

### GPT-5.6 全量发布，ChatGPT Work 上线

OpenAI 昨天正式结束了 GPT-5.6 的"政府批准限制预览"，全量开放 Sol / Terra / Luna 三档模型，并同步推出 ChatGPT Work——一个能跨应用跨文件干活、可以连续跑几个小时、把目标拆解成步骤自己执行的 Agent。它本质上是把 Codex 的能力开放给不写代码的人：连上 Slack、Gmail、Google Drive、日历和 CRM 之后，能直接产出文档、表格、幻灯片甚至网页。桌面版对所有用户（包括 Free）开放，Pro / Enterprise / Edu 用户在网页和移动端优先拿到权限。GPT-5.6 同时也成了 Microsoft 365 Copilot 的默认模型，说明"通用 Agent 底座"的竞争已经进入基础设施层，值得亲自装上跑一遍自己最常用的工作流。

→ [原文](https://openai.com/index/chatgpt-for-your-most-ambitious-work/) / [GPT-5.6 详情](https://openai.com/index/gpt-5-6/)

### MCP 企业统一授权 EMA 转正式

Model Context Protocol 团队把「Enterprise-Managed Authorization」扩展升级为稳定版，核心是把 MCP Server 的授权决策权交给企业身份提供商（IdP）：员工用公司账号登录一次，就能按角色和组自动拿到已批准的 MCP Server 权限，不用再对着每个 Server 点一遍 OAuth 同意框。技术上基于 ID-JAG（Identity Assertion JWT Authorization Grant），管理员在 IdP 后台就能统一定策略、统一审计、统一吊销。Anthropic（Claude / Claude Code / Cowork）、Microsoft（VS Code）和 Okta 已经接入，Asana、Atlassian、Canva、Figma、Granola、Linear、Supabase 等 Server 端也已支持，Slack 在路上。如果你在给团队搭 MCP 网关，这是目前最值得优先适配的企业级授权方案。

→ [官方博客](https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/) / [InfoQ 报道](https://www.infoq.com/news/2026/07/mcp-ema-enterprise-auth/)

## ⚡ 快讯

- **xAI / SpaceXAI**：Grok 4.5 发布，主打的不是跑分第一而是"每任务成本"：SWE-Bench Pro 上它平均只用 15,954 个输出 token 完成任务，Opus 4.8 需要 67,020 个，效率差 4.2 倍；配合 $2 / $6 每百万 token 的定价，加上与 Cursor 联合训练的底子，单任务成本压到 2.49 美元，远低于 Codex 的 5.07 美元和 Claude Code 的 11.80 美元，但在 SWE-Bench Pro 准确率上仍落后 Opus 4.8 和 Fable 5。 → [Appwrite 分析](https://appwrite.io/blog/post/grok-45-coding-model) / [The Decoder](https://the-decoder.com/grok-4-5-is-so-cheap-compared-to-fable-5-and-gpt-5-5-that-benchmark-gaps-may-not-matter-much/)

## 📈 趋势

- 🔺 Agent 安全与身份治理正在从"模型能力"下沉到"基础设施"：MCP EMA 转正、记忆投毒攻击研究、行动分级安全评分体系同时出现，说明可信落地的重心已经转移到权限和审计层。
- 🆕 "Harness 经济学"成为新叙事：token 单价下降但总消耗涨得更快，编排层设计而不是模型选择，成了控制企业级 Agent 成本的关键变量。
- 🔺 前沿模型的竞争维度从"跑分第一"转向"每任务成本"：Grok 4.5 用四分之一的 token 做完同样的事，价格战正在从每 token 单价打到任务级效率。
- 🆕 国产开源 Agent 生态多点开花：qKnow 补平台、MoonBit Skills Marketplace 补工具分发、中国移动新消息 Claw 补终端触达，三个方向合起来把 Agent 落地的最后一公里连上了。
