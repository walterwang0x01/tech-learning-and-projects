## 📌 头条

### MCP 迎最大改版，7月28日转向无状态架构

MCP（Model Context Protocol）即将完成协议诞生以来最大的一次版本升级，发布候选已于 5 月锁定，最终规范将于 2026 年 7 月 28 日正式发布，给旧版本留出 12 个月过渡期。核心变化是协议层从有状态转向无状态：不再依赖 sticky session 和共享会话存储，MCP server 可以直接跑在普通轮询负载均衡器后面，同时新增 MCP Apps（服务端渲染 UI）和 Tasks（长任务）扩展，认证也向 OAuth/OIDC 靠拢。Akamai 安全团队提醒，无状态化消除了 session 劫持等旧风险，但引入了预测性 tracking ID 被劫持、MCP-Method 等新 header 泄露密钥、长任务被单次请求触发拒绝服务等新攻击面——协议本身更安全了，但安全责任下沉到了每个 server 实现方。如果你在生产环境跑自建 MCP server，现在就该按新规范做迁移测试，别等到 7 月 28 日截止日才动手。

→ [MCP 官方博客](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) / [SecurityWeek 安全分析](https://www.securityweek.com/new-enterprise-ready-mcp-specification-brings-new-security-challenges/)

### 无问芯穹发布 Agentic Infra 战略体系

7 月 20 日世界人工智能大会上，无问芯穹 CEO 夏立雪公布了「前店后厂一中心」Agentic Infra 战略，把异构算力聚合、Token 生产、行业解决方案打包成一套体系。技术亮点是跨集群异构 PD 分离架构（PDD）：把 Prefill 和 Decode 任务分给「偏科」最强的芯片集群处理，再用 RelayDecode 掩盖跨集群 KV Cache 传输延迟，实测首 Token 延迟降低 51.5%、单 Token 成本降低 37.5%。该系统目前已在全国部署触达超 37,000P 算力、覆盖 16 种芯片，服务 Kimi、智谱、Minimax 等头部大模型企业，平台单日 Token 调用量较去年 12 月增长 40 倍。对做 agent infra 选型的人来说，这是国内异构算力聚合 + 推理优化路线的一个具体样本，值得跟进其后续开源和落地进展。

→ [InfoQ 原文](https://www.infoq.cn/article/AWhEVVgvNquuiKZdRQ0H)

## ⚡ 快讯

- **LangGraph**：v1 迎来以稳定性为主的更新：核心 graph API 和执行模型保持不变，重点打磨类型安全和开发者体验，同时正式弃用 create_react_agent 等旧接口，统一迁移到 langchain.agents.create_agent。 → [迁移指南](https://docs.langchain.com/oss/javascript/releases/langgraph-v1)
- **CrewAI**：7 月更新新增 inline skill definitions 和新的 Flow protocol 支持，继续在多智能体编排里强调角色协作和企业级治理能力。 → [Changelog](https://docs.crewai.com/changelog)
- **LangChain**：发布长文《Building Governed Agents》，把 LLM Gateway 定位成企业 agent 的运行时控制平面——统一管控 LLM 调用、工具调用、MCP 调用和 agent-to-agent 交互的成本、权限与合规审计。 → [原文](https://www.langchain.com/blog/building-governed-agents-a-framework-for-cost-control-and-compliance)
- **LangSmith Engine**：团队公开内部评测基准 IssueBench：15 个合成任务覆盖 SRE、软件工程、客服三个领域，验证 Engine 能否把 agent trace 里的失败正确分类并归并成可处理的 issue，而不是简单标记「有问题」。 → [原文](https://www.langchain.com/blog/issuebench-how-we-evaluate-engine)
- **Zadig**：MCP Server 版本更新聚焦接入更稳、调用更准、审计排障更清晰三个方向，是国内 DevOps 工具链接入 MCP 生态的一次典型迭代。 → [更新说明](https://my.oschina.net/koderover/blog/19721057)
- **Agents-Flex**：发布 Skill Runtime，给 Java Agent 生态补上执行层：Skill 不再只是 Prompt，还能打包 Shell/Python/模板/校验规则，支持 Sandbox 隔离执行和 Kubernetes 下的 Artifact 分发，主打「从会回答到能交付」。 → [开源中国](https://www.oschina.net/news/475598)
- **Kimi**：因用户请求量激增、算力集群逼近承载上限，宣布暂停 C 端新用户订阅并启动算力扩容，同时把「Kimi 主权益」和「Kimi Code 权益」拆分管理——国产大模型的算力瓶颈已经直接影响到 agent 类产品的可用性。 → [开源中国](https://www.oschina.net/news/474866)

## 📈 趋势

- 🆕 MCP 协议迎来自诞生以来最大改版，7 月 28 日定案后进入 12 个月过渡期，协议层转向无状态架构，安全责任同步下沉到每个 server 实现方。
- 🔺 Agent Runtime 层成为新战场——Java 生态（Agents-Flex）补执行层，LangChain（Governed Agents）补治理层，行业共识从「agent 会回答」转向「agent 能交付、可审计」。
- 🔺 多智能体安全研究从「人机对齐」扩展到「机机关系」——Manager Coercion Benchmark 开始测量 AI 管理者对 AI 下属的胁迫和欺骗行为。
- 🔻 国内大模型算力紧缺信号浮现（Kimi 暂停 C 端新订阅），agent 规模化落地的瓶颈正从模型能力转移到底层算力供给。
