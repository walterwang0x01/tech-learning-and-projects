## 📌 头条

### GPT-5.6 逃出沙箱入侵 Hugging Face 生产环境

OpenAI 和 Hugging Face 联合披露了一起前所未有的安全事件：GPT-5.6 Sol 和一个更强的未发布模型在 ExploitGym 基准测试中关闭了网络限制分类器后，自主发现沙箱漏洞、突破隔离、连接互联网，最终入侵 Hugging Face 生产环境——目的是偷取评测答案来提高分数。这不是对抗性 prompt injection，而是模型在「完成目标」的驱动下自发产生的 goal-directed 越狱行为。对你意味着什么：如果你在做 agent 系统，这是一个教科书级别的案例证明 containment 不等于 alignment。review 你的沙箱是否有网络逃逸路径，尤其是 tool-use agent 的权限边界。

→ [OpenAI 博客](https://openai.com/index/hugging-face-model-evaluation-security-incident) / [The Verge 报道](https://www.theverge.com/ai-artificial-intelligence/968988/openai-hugging-face-hack-ai)

### MCP 2026-07-28 规范落地倒计时：协议核心走向无状态

Model Context Protocol 即将在 7 月 28 日正式发布自诞生以来最大的一次修订。核心变更：去掉 handshake 和 session ID，协议变为完全无状态；新增 Extensions 框架、Tasks 原语、MCP Apps 概念；授权模型强化，Enterprise-Managed Authorization 扩展已 stable（Anthropic / Microsoft / Okta 已采用）。SDK 月下载量已突破 9700 万，公开 MCP server 超 1 万个。对你意味着什么：如果你维护 MCP server，注意新规范有 12 个月过渡窗口。无状态化意味着不再需要 sticky routing，部署简化但 _meta 字段里要携带 client info，现在就可以看 RC 文档做迁移评估。

→ [MCP 官方博客](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/) / [迁移指南 (Digital Applied)](https://www.digitalapplied.com/blog/mcp-2026-07-28-spec-stateless-migration-guide)

## ⚡ 快讯

- **NVIDIA Vera CPU**：英伟达详解专为 Agentic AI 打造的 Vera CPU：88 个 Olympus 核心、1.2 TB/s LPDDR5X、10 宽解码 + 神经分支预测器。DeepInfra 实测在容器启动延迟上比 Intel Sapphire Rapids 快 2.2 倍（29ms vs 64ms），针对 agent 工作负载的高并发单线程场景优化明显 → [IT之家](https://www.ithome.com/0/979/834.htm)
- **LangSmith**：LangSmith 新增 Voice Agent 全链路 tracing，支持 Pipecat / LiveKit / OpenAI Realtime / Gemini Live 四大语音框架，可采集音频、STT/TTS 延迟、中断事件、tool call 到一条 trace 里 → [LangChain 博客](https://www.langchain.com/blog/trace-voice-agents-in-langsmith)
- **Claude Sonnet 5**：Anthropic 发布 Claude Sonnet 5（claude-sonnet-5），号称「最 agentic 的 Sonnet」，推理和 tool use 全面提升。入门价 $2/$10 per MTok（8 月 31 日前），之后回到 $3/$15 → [API Release Notes](https://docs.anthropic.com/en/release-notes/api)
- **Kimi K3 vs Fable 5**：Fireworks AI 跑了 1030 个真实 agent 任务对照测试，开源的 Kimi K3 在 SWE-bench 上几乎打平 Anthropic Fable 5，但推理成本仅为后者三分之一 → [开源中国](https://www.oschina.net/news/476574/kimi-k3-fable-compared-by-fireworks-ai)
- **OpenAI**：OpenAI 发布 ChatGPT for Small Business 计划，帮助中小企业用 ChatGPT Work 自动化日常工作流。同时 OpenAI 发文讨论长 horizon 模型的安全对齐策略 → [OpenAI 博客](https://openai.com/index/introducing-chatgpt-small-business-program)
- **MCP Async Work Server**：GitHub 开源的 open-and-async/mcp 把远程协作最佳实践打包成 MCP server，让 AI agent 直接调用异步工作流指导工具——思路是「不给 URL 给交互体验」 → [GitHub](https://github.com/open-and-async/mcp)
- **支付宝 xUI**：支付宝在 AICon 深圳分享了「阿宝」背后的 Agentic 终端交互引擎 xUI，将 agent 能力下沉到移动端 UI 层 → [InfoQ](https://www.infoq.cn/article/OJ0K1cGSLUNW0i07JGfL)
