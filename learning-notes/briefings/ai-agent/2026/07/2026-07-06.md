## 📌 头条

### GPT-5.6 Sol 政府管控下限量预览

OpenAI 于 6 月 26 日放出 GPT-5.6 系列（Sol / Terra / Luna），却没走常规公开发布路径——目前只有约 20 家经美国政府审核的合作机构能通过 API 和 Codex 访问。原因是旗舰模型 Sol 在 OpenAI 内部网络攻击测试中拿到 96.7% 分数，首次跨过 Preparedness Framework 定义的“高风险”网络安全红线，白宫网络安全办公室因此要求限制早期访问范围。技术层面，Sol 新增“最大推理强度”档位和依赖子 agent 并行处理的 Ultra 模式，在 Terminal-Bench 2.1 上跑到 91.9%，主打多步骤自主编码任务的完成率提升。对经常用 Codex 写代码的你来说，短期内摸不到，但值得盯紧它计划在 Cerebras 上做到 750 tokens/秒 的推理部署——一旦开放，交互式 agentic 编码体验会有质的变化。

→ [OpenAI 官方](https://openai.com/index/previewing-gpt-5-6-sol/) / [HN 讨论](https://news.ycombinator.com/item?id=48799614)

### 中国大厂智能体功能集体收缩

过去一周，中国几家大厂同时对“智能体”功能踩了刹车：豆包和千问相继关停智能体入口（豆包此前已在 5 月 31 日悄悄下线“应用生成”功能），美团限制内部使用豆包，阿里巴巴则直接禁用 Claude Code。单看是几条独立新闻，连起来看更像是行业对智能体安全边界、合规成本和实际产出比的一次集体重新评估——尤其是在“数字员工”“Agent Harness”这类概念被吹了一年之后。如果你的团队也在评估内部智能体工具链，这是一个值得对照检查权限边界和数据出口的时间点。

→ [InfoQ AI周报](https://www.infoq.cn/article/rs0HJTRdN6Pl88LIFh1a) / [少数派早报](https://sspai.com/post/111973)

- **LangChain**：过去一周密集放出四条更新：自动生成代码库 Wiki 的 OpenWiki、与 Harbor 集成做长时状态化 Agent 评测、Deep Agents 里新增可编程调用的动态 subagent（6 种常见调用方式）、以及 Prompt Caching 优化。LangGraph 本体同步升级到 1.2.7，修复了几个 checkpoint 相关的稳定性问题。 → [LangChain Blog](https://www.langchain.com/blog/introducing-dynamic-subagents-in-deep-agents)
