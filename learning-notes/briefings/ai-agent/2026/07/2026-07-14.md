## 📌 头条

### ChatGPT Work：跨应用多小时自主交付整份工作

OpenAI 于 7 月 9 日同步推出 GPT-5.6（Sol/Terra/Luna）与 ChatGPT Work：后者不再只回答问题，而是跨邮件、Slack、日历、文件与 MCP插件目录，把目标拆解成多步任务并可持续运行数小时，产出文档、表格、幻灯片乃至 Web App。Sol 新增 ultra 模式，可并行调度多个 agent 加速重任务；这是 Operator 等能力收敛后的统一产品面。对你意味着：Paid 计划可立刻用「自己熟的任务」压力测试交付质量与审批边界，自建工具优先做成 MCP 插件以进目录。

→ [原文](https://openai.com/index/chatgpt-for-your-most-ambitious-work/) / [GPT-5.6](https://openai.com/index/gpt-5-6/)

### Cloudflare Precursor：会话行为识破 Agentic Bot

Cloudflare 发布 Precursor：把整段用户旅程的客户端连续信号沉淀为 bot 检测特征，专门对付「像人一样点、其实是 agent」的高级自动化。相对单次指纹，它强调会话级行为模式，在提高检出精度的同时降低真人摩擦。跑对外业务或开放 MCP/插件入口的团队，值得对照现有 WAF/Bot 规则是否覆盖 agentic 会话路径，而不是只拦旧式爬虫。

→ [原文](https://blog.cloudflare.com/introducing-precursor)
