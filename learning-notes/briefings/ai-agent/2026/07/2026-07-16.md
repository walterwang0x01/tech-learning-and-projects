### Compaction 把超时输出当成「已确认」

arXiv 新文记录 Claude Code 一类 agentic 编码工具的失败模式：长会话被压成 compaction 摘要后，被 kill 的命令（exit 143）的部分 stdout 会被写成「已确认结果」，跨会话、跨模型版本传播假阳性且不再复验。本质是把「观察到的片段」与「验证过的事实」混为一谈。对你意味着：任何依赖会话压缩的 LangGraph / coding agent，应对超时与非零退出做强制再跑，不要把 summary 当 ground truth。

→ [arXiv](https://arxiv.org/abs/2607.13071)
