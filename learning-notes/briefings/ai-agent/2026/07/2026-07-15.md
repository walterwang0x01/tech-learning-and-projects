## 📌 头条

### OpenAI：用「有用工作/$」管 Agentic 投资

OpenAI 7 月 14 日发布企业指南：token 单价从 GPT-4 到 GPT-5.4 已降约 97%，但真正该看的是 useful work per dollar——任务完成量、节省时间、决策质量与可规模化工作流。ChatGPT Work 把多步 agent 用量推高后，Admin Console 需要按 workspace/团队/产品·模型分层看用量与支出；评测应以「可接受结果的全成本」（重试、审查、时延）而非单纯 token 价选模型。对你意味着：把高价值工作流做成可观测、有审批边界的生产单元，再用 Guaranteed Capacity / Scale Tier 等匹配已验证需求，而不是全面抬额。

→ [原文](https://openai.com/index/managing-ai-investments-in-agentic-era)

### LangChain×NVIDIA：NemoClaw Deep Agents 蓝图

LangChain 与 NVIDIA 联合发布 NemoClaw for Deep Agents：把 Nemotron 3 Ultra（开源模型）、Deep Agents Code / dcode（规划·工具·记忆 harness）与 OpenShell（沙箱策略运行时）捆成可自托管的治理型 agent 栈。官方 agent eval 套件上 Nemotron 3 Ultra + 调优 harness 聚合分 0.86、成本约 $4.48，对比次优约 $43.48（约 10× 推理成本差）。核心论点是模型、harness、eval 与 runtime 必须一起调。对你意味着：若在仓内跑 LangGraph/Deep Agents，可对照这套开源路径做 cost-quality 基线，而不是默认闭源托管 agent。

→ [原文](https://www.langchain.com/blog/langchain-and-nvidia-launch-the-nemoclaw-deep-agents-blueprint)
