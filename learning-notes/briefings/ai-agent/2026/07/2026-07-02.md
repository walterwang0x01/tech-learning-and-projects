## 📌 头条

### Anthropic 发布 Sonnet 5：最强 agentic 中端模型

Anthropic 于 6 月 30 日发布 Claude Sonnet 5，定位为"有史以来最 agentic 的 Sonnet"。它能自主制定计划、操作浏览器和终端，性能逼近 Opus 4.8 同时价格仅为入门价 $2/M input、$10/M output（8 月 31 日前）。Box 企业评测显示 Sonnet 5 在 Energy (+4.7pp)、Retail (+4.4pp) 等垂直领域显著超越 Sonnet 4.6。同日美国商务部解除 Fable 5 和 Mythos 5 出口管制，Anthropic 全线产品重新可用。对你意味着什么：如果你在跑 agent 工作负载，现在就可以把 Sonnet 4.6 换成 Sonnet 5 测试——同等成本下 agentic 完成率会明显提升。

→ [Anthropic 官方](https://anthropic.com/news/claude-sonnet-5) / [TechCrunch](https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/)

### Cloudflare 推出 Monetization Gateway：x402 协议让 AI Agent 直接付费

Cloudflare 开放 Monetization Gateway 候补名单，允许开发者对任何网页、数据集、API 或 MCP 工具收费。支付通过 x402 开放协议以稳定币结算，无需自建支付栈。这意味着 AI Agent 在调用外部 API/MCP 工具时可以自主完成微支付——agentic Internet 的商业模型正式落地。配套发布的 agentic bot 报告显示，自主 AI Agent 正在颠覆传统搜索引荐模式。对你意味着什么：如果你在构建对外 MCP 服务，关注 x402 协议集成——Cloudflare Agents SDK 已内置付费 MCP client。

→ [官方博客](https://blog.cloudflare.com/monetization-gateway) / [Agentic Internet 报告](https://blog.cloudflare.com/agentic-internet-bot-report)

- **Apple Safari**：Safari Technology Preview 247 引入官方 MCP Server，编程 agent 可直接检查网页、读取 console/network 日志、截图并交互——配置后 agent 能自动调试 Safari 兼容性问题 → [9to5Mac](https://9to5mac.com/2026/07/01/safaris-new-mcp-server-lets-coding-agents-inspect-and-debug-websites/)

- **LangChain RLM**：LangChain 博客发布 RLM（Recursive Language Models）在 Deep Agents 中的实践：agent 编写代码对上下文分块递归调用子 agent，在 OOLONG 长上下文推理基准上表现稳定超越逐轮 agent → [博客](https://www.langchain.com/blog/how-to-use-rlms-in-deep-agents)
- **LangChain OpenWiki**：开源项目 OpenWiki 发布——自动为代码仓库生成文档 wiki 并更新 agent 指令文件，让 coding agent 无需全量加载就能发现 repo 上下文 → [博客](https://www.langchain.com/blog/introducing-openwiki-an-open-source-agent-for-repo-documentation)
- **软银 × OpenAI**：软银通过 Vision Fund 2 完成对 OpenAI 第二笔 $100 亿追加投资，$300 亿计划已过 2/3，第三笔 $100 亿预计 10 月到账（若 OpenAI IPO 可提前） → [软银官方](https://group.softbank/en/news/press/20260701)
- **ACE 论文**：arXiv 论文 ACE（Adaptive Context Elasticizer）提出可插拔的 agent 上下文弹性管理：信息丢弃可逆、按需恢复，解决固定窗口下 trajectory 增长难题 → [arXiv](https://arxiv.org/abs/2606.31564)
- **Session-Level RAG**：论文提出 co-occurrence-aware KB 重组方案，单次检索覆盖 session 级信息需求从 41% 大幅提升——对多轮对话 RAG 系统有直接参考价值 → [arXiv](https://arxiv.org/abs/2606.31156)
