## 📌 头条

### Gemini Managed Agents 补齐生产级能力

Google 宣布 Gemini API 的 Managed Agents 新增四项关键能力：background execution 让长任务异步跑在服务端，客户端用 interaction ID 轮询或断线重连；remote MCP 可在 interaction 时直接挂载 Streamable HTTP 的 MCP server，与 Google Search、代码执行等内置工具混用；还支持自定义 function calling 与跨 interaction 的 credential refresh，换 token 时 sandbox 文件系统状态不丢。对 Walter 来说，这意味着不必再写一层 MCP 代理就能把内网数据库/私有 API 接到托管 agent 上——值得拿 antigravity-preview agent 配一个现有 MCP server 跑通端到端。

→ [Google 官方博客](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api) / [Background execution 文档](https://ai.google.dev/gemini-api/docs/background-execution)

### RAG 遭遇多形态 Sybil 投毒新威胁

arXiv 新论文提出 polymorphic sybil poisoning：攻击者投放 6 条表面各异、语义一致的毒文档占满 top-10 检索位，可绕过近重复过滤器——单形态攻击 hijack 率仅 4.0%，多形态版飙至 22.8%（+18.8pp）。更关键的是，作者用 gold/hijack/abstention/drift 四分类框架证明：传统 ASR 指标会把 47–66% 的输出质量差异掩盖掉，两个 reader ASR 相差 0.2pp 时 abstention 可差 16.5pp。若你在做 RAG Agent，别只盯检索命中率，该用这套 Forced Exposure 协议压测 reader 侧冲突消解。

→ [arXiv 论文](https://arxiv.org/abs/2607.03739) / [HTML 全文](https://arxiv.org/html/2607.03739)

## ⚡ 快讯

- **LangChain**：Vivek Trivedi 发文论证 agent 改进本质是数据挖掘：从 trace 中挖信号、蒸馏开源 judge 模型批量处理百万 token 级轨迹，再以 eval 为训练数据做 harness engineering → fine-tuning 漏斗式迭代，Terminal Bench 2.0 上仅靠 harness 调优就拿到 +13.7% 提升 → [博客](https://www.langchain.com/blog/improving-agents-is-a-data-mining-problem)
- **SPORK**：Self-Speculative Forking 论文提出 agent 推理加速：在关键决策点 fork 多条推测路径并行验证，减少串行 tool-call 等待，面向高并发 agent 部署场景 → [arXiv](https://arxiv.org/abs/2607.03333)
- **CAGE-1**：企业级 agent 治理评测框架 CAGE-1 发布，从 Control、Assurance、Governance 三维度量化 agent 系统的合规与可控性，填补生产落地前的审计空白 → [arXiv](https://arxiv.org/abs/2607.03510)
- **Agentic TTT**：No Time Like the Present 提出 agentic test-time training：agent 在推理阶段根据环境反馈即时微调策略，而非依赖离线训练集，适合非平稳任务分布 → [arXiv](https://arxiv.org/abs/2607.03441)
- **CSDI 峰会**：开源中国报道 CSDI 峰会观点：Agentic AI 正从试点进入产业渗透期，智能体将演化为「AI 操作系统」形态——用户下达任务，系统自动拆解并编排多 agent 协同 → [报道](https://www.oschina.net/news/471531)
- **Claude Code**：Anthropic 官方回顾 Claude Code 诞生历程：从内部开发工具到支撑研究、笔记、视频制作等通用 agent 循环，并正式将 Claude Code SDK 更名为 Claude Agent SDK → [Claude 博客](https://claude.com/blog/building-agents-with-the-claude-agent-sdk)
- **Governed MCP**：Governed MCP 论文在 kernel 层用 logit-based 策略做 tool governance，为 MCP 工具调用增加细粒度权限控制，回应 agent 安全热点 → [arXiv](https://arxiv.org/abs/2604.16870)

## 📈 趋势

- 🆕 托管 agent 平台（Gemini Managed Agents、Claude Agent SDK）正把 background execution + remote MCP 打包成开箱即用的生产基建，自托管 orchestrator 的差异化在收窄

- 🔺 「改进 agent = 挖 trace」成为 LangChain 等厂商共识：observability → eval 即训练数据 → harness/fine-tune 漏斗，持续学习闭环产品化加速
- 🔻 纯 prompt engineering 在复杂 agent 任务上触及天花板，论文与工程实践均转向 harness-aware co-evolution 与 test-time training 寻求突破
