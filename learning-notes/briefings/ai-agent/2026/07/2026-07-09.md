### MCP 审批视图藏隐形 Unicode 投毒

arXiv 新论文系统验证了 MCP tools/list 元数据中的 approval-view fidelity gap：攻击者在 tool description 或 JSON schema 里嵌入 Unicode TAG-block（U+E0000–U+E007F）字符，人类审批对话框完全看不见，但 LLM 每轮都收到完整 payload。作者在 3 个独立 MCP client 实现上测试 8 种投毒技术，全部能到达模型上下文，其中 T7（TAG-block 编码）是唯一同时绕过自动 sanitizer 和人类审批视图的方案。更麻烦的是 MCP 协议不要求审批渲染与注入字节一致，也不强制元数据变更后重新授权。若你在用 Claude Code/Cursor 挂载第三方 MCP server，建议在 CI 里加 NFKC 归一化 + TAG-block 字符拒绝，并关闭 tool auto-approve。

→ [arXiv 论文](https://arxiv.org/abs/2607.05744) / [HTML 全文](https://arxiv.org/html/2607.05744v1)
