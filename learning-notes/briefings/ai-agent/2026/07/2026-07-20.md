## 📌 头条

### GPT-5.6 正式公开，ChatGPT Work 同日上线

OpenAI 在获得美国政府批准后，将此前限量预览的 GPT-5.6 全面开放给公众，同时推出 ChatGPT Work——一个独立的企业级 agentic 工作模式，用户可在全局切换器中选择 Chat（快速问答）或 Work（端到端任务执行）。此前 o3 已宣布将于 8 月 26 日退役，GPT-4.5 也已在 6 月 27 日下线，OpenAI 正在激进收拢模型线。如果你的 agent 管线还在调用旧模型 endpoint，现在是迁移到 GPT-5.6 系列的最后窗口期。

→ [Yahoo Tech](https://tech.yahoo.com/ai/chatgpt/article/openai-launches-both-gpt-56-and-chatgpt-work-today-after-approval-from-the-us-government-150044321.html) / [OpenAI 模型说明](https://help.openai.com/en/articles/9624314-model-release-notes)

### MCP 安全现状：40% 服务器零认证

Microsoft Security 本月发布 MCP 安全态势报告，结合 Zuplo 审计和 Trend Micro 扫描数据画出一幅触目惊心的图景：40% 的 MCP 服务器无任何认证、43% 存在命令注入漏洞、79% 明文处理凭据；Trend Micro 更发现 492 台公开暴露的 MCP 服务器提供了 1402 个工具的直接访问，其中 90% 允许读取权限。2026 年 1-4 月已披露超过 40 个 CVE，涵盖 Python/TypeScript/Java/Rust 全部官方 SDK。Tool poisoning（在工具描述中藏恶意指令）被确认为最锋利的攻击面。如果你在生产环境跑 MCP server，现在就该加上认证层和工具白名单。

→ [Microsoft 报告](https://techcommunity.microsoft.com/blog/microsoft-security-blog/the-state-of-mcp-security-in-2026/4531327) / [Medium 分析](https://medium.com/@rudraneel93/the-mcp-security-gap-nobodys-closing-and-why-it-s-your-problem-now-677241289efa)

## ⚡ 快讯

- **LangGraph**：LangGraph 升级至 1.2.8（7 月 6 日发布），持续修复 checkpoint 稳定性问题；企业级框架对比评测显示 LangGraph + MCP 已成 2026 年生产环境部署的默认组合。 → [GitHub](https://github.com/langchain-ai/langgraph)
- **CrewAI**：7 月更新引入 inline skill definitions 和新 Flow protocol 支持，multi-agent benchmark 显示 CrewAI 较 LangGraph 每任务输出少耗 23% token，但速度慢 2.4 倍。 → [Changelog](https://docs.crewai.com/changelog)
- **Anthropic Cowork**：Claude Cowork 扩展到 web 和移动端，支持 remote sessions、跨设备同步文件，并新增 Microsoft 365 集成——可直接起草邮件、管理日历、操作 OneDrive/SharePoint 文件。 → [Anthropic 更新](https://releasebot.io/updates/anthropic)
- **OpenAI Realtime**：OpenAI 发布 GPT-Realtime-2.1 及 mini 版，改善了字母数字识别、静默/噪音处理和打断行为，是实时语音 agent 的核心推理模型升级。 → [API Changelog](https://developers.openai.com/api/docs/changelog)
- **AI Agent Handbook**：GitHub 新项目系统梳理 30+ agent 框架的底层运作：context rot、compaction、system prompt assembly、agent loops、memory systems、tool sprawl、MCP 等核心机制的工程实践指南。 → [GitHub](https://github.com/vasilyevdm/ai-agent-handbook)
- **fast-agent**：evalstate/fast-agent 持续迭代，新增 SEP-2640 skills-over-MCP 安装路径加固，定位是用 MCP 原生方式快速构建和评估 agent。 → [GitHub](https://github.com/evalstate/fast-agent)

## 📈 趋势

- 🆕 ChatGPT Work 模式标志 agent 从「聊天插件」升级为「独立工作空间」——OpenAI 将 agentic 执行作为一等公民产品化，与 Anthropic Cowork 形成正面竞争。
- 🔺 MCP 安全问题进入「系统性治理」阶段——Microsoft、Trend Micro、学术界同步产出分析报告，40+ CVE 和 492 台公开暴露服务器的数据推动行业从个案修补走向协议层安全加固。
- 🔺 Agent 框架格局稳定为三极：LangGraph（生产状态机）+ CrewAI（角色编排）+ MCP（工具协议），AutoGen 进入维护模式后由 Microsoft Agent Framework 接棒。
- 🔻 旧模型加速退役——o3 宣布 8 月退役、GPT-4.5 已下线，agent 管线需要主动迁移而非被动等待 deprecation 通知。
