## 📌 头条

### Anthropic 警告递归自我改进临界点已至

Anthropic 发布博文披露：截至 2026 年 5 月，Claude 已编写其生产代码库 80% 以上的代码，而 16 个月前这个数字还是个位数。公司联合创始人 Jack Clark 与 Anthropic Institute 负责人 Marina Favaro 呼吁全球顶尖 AI 实验室考虑「可协调、可验证的暂停」。他们定义的递归自我改进——AI 独立设计、训练、部署后继模型——可能在数月内出现。对你来说，这意味着 agent 编排链条中的任何自动化 fine-tuning 或 self-play 环节，都需要加上硬性 human-in-the-loop 断点。

→ [Scientific American 报道](https://www.scientificamerican.com/article/anthropic-warns-ai-may-soon-begin-recursive-self-improvement/) / [开源中国摘要](https://www.oschina.net/news/452519)

### LangChain：每个 Agent 都需要自己的电脑

LangChain 发布架构博文阐述 agent sandbox 的基础设施范式转移：agent 不再共享宿主文件系统，而是各自运行在硬件虚拟化 microVM 中（LangSmith Sandboxes 已 GA）。推荐模式是 agent 在你的服务器运行、sandbox 作为远程工具调用——API key 留在外面，只为执行时间付费。如果你在用 LangGraph 构建 tool-use agent，现在可以把 code execution 节点接入 LangSmith Sandbox，获得内核级隔离而非容器级。

→ [LangChain 博文](https://www.langchain.com/blog/give-your-ai-agent-its-own-computer)

## ⚡ 快讯

- **Claude Cowork**：Anthropic 将 Cowork 用量限额翻倍至 7 月 5 日，适用所有付费计划，适合跑大型多步任务（研究、报告、收件箱分类）。 → [公告](https://x.com/claudeai/status/2063018337567670285)
- **Anthropic 开源漏洞发现 Agent**：开源 Defending Code Reference Harness，基于 Claude 的自主化漏洞扫描与修复参考实现；同时 Project Glasswing 已发现超 10,000 个高危漏洞。 → [开源中国](https://www.oschina.net/news/452400) / [CSO Online](https://www.csoonline.com/article/4176865/project-glasswing-has-uncovered-10000-vulnerabilities-anthropic.html)
- **Vercel Skills API**：skills.sh API 正式上线，60 万+ 开源 agent skills 可通过 OIDC token 查询，Guillermo Rauch 称之为「agent 能力的 npm registry」。 → [Changelog](https://vercel.com/changelog/the-skills-sh-api-is-now-available)
- **MCP 运行时故障分类学**：arXiv 新论文首次对 MCP Server 运行时故障进行系统实证分类——配置参数被接受却未在运行时生效的「静默降级」问题值得所有 MCP 集成方注意。 → [论文](https://arxiv.org/abs/2606.05339)
- **CUA 安全基准**：793 集 CUA-HandCrafted 基准发布：针对当前前沿 Computer-Using Agent 复现 prompt injection 攻击，发现旧红队模板对新模型成功率显著下降。 → [论文](https://arxiv.org/abs/2606.05233)
- **AdaMEM：测试时自适应记忆**：提出 Adaptive Memory Agent 框架，打破「仅在 episode 开始时检索」的限制，在长时间任务执行过程中动态更新 agent 记忆。 → [论文](https://arxiv.org/abs/2606.05684)
- **Thousand Token Wood**：Hugging Face hackathon 项目在 Qwen2.5-3B 上跑出了 5 个 agent 的微型经济体——泡沫、崩盘、贫富分化自然涌现，证明小模型多 agent 交互的可行性。 → [博文](https://huggingface.co/blog/build-small-hackathon/thousand-token-wood-sim)
