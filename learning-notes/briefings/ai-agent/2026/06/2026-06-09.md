### Anthropic 发布生物学 Agent 研究：为什么 AI 在编程之外还很难

Anthropic 发表研究论文「Paving the way for agents in biology」，系统分析了为什么 AI agent 在生物学领域进展远慢于编码领域。核心发现：Claude Sonnet 4 从公共生物数据库检索时返回高度不一致的数据，根因在于遗留数据库基础设施不适配 agent 调用。他们开源了 gget virus 工具作为解决方案起点。这为所有想把 agent 落地到垂直领域（医疗、材料、化学）的团队敲响警钟——确定性检索工具是 agent 可靠性的关键，数据库需要为 agent 重新设计 API。

→ [Anthropic Research](https://www.anthropic.com/research/agents-in-biology)
