## 📌 头条

### LangChain 发布 Dynamic Subagents：用代码编排取代逐轮工具调用

LangChain 今天在 Deep Agents 中推出 Dynamic Subagents，agent 不再逐步调用 tool，而是直接写一段轻量脚本（JS 循环、分支、并发）来编排和调度子 agent，由内置 interpreter 执行。这意味着确定性的 fan-out 和 coverage guarantee——你不用祈祷模型「记得」发起所有并发调用了。对你意味着什么：如果你在用 Deep Agents 做批量处理或研究类 pipeline，升级到最新版后可以把 tool-call-one-by-one 模式替换成 programmatic orchestration，throughput 会有本质提升。

→ [原文](https://www.langchain.com/blog/introducing-dynamic-subagents-in-deep-agents)

### Ornith-1.0 开源：self-scaffolding 让模型自己写训练 harness

DeepReinforce AI 发布 Ornith-1.0，一个专为 agentic coding 设计的开源模型家族（9B/31B Dense + 35B/397B MoE），MIT 许可无地域限制。核心创新是 self-scaffolding：RL 训练中模型不仅生成解题 rollout，还生成驱动 rollout 的编排脚手架本身。397B 版在 Terminal-Bench 2.1 拿到 77.5、SWE-Bench Verified 82.4，逼近闭源 frontier。基于 Qwen 3.5 和 Gemma 4 post-train，9B 版可以跑在边缘设备上。如果你在评估 open-weight coding agent 替代方案，这是目前性价比最高的选择。

→ [GitHub](https://github.com/deepreinforce-ai/Ornith-1) / [技术报告](https://deep-reinforce.com/ornith_1_0.html)
