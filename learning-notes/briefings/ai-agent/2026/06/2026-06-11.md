## 📌 头条

### Claude Fable 5 发布：首个公开的 Mythos 级模型

Anthropic 6月9日正式发布 Claude Fable 5，首次将 Mythos 级能力向公众开放。Fable 5 与 Mythos 5 共享同一底层模型，但加装了安全护栏（网安/生物/化学领域降级回退到 Opus 4.8）。API 定价 $10/M input、$50/M output，不到 Mythos Preview 的一半。Karpathy 评价「这是自 Claude 4.5 以来同级别的跨越」，Boris Cherny 直接卸载了 IDE 全天用终端写代码。对你意味着什么：立刻把 Claude Code 升级到 Fable，用 xhigh effort 跑你最难的任务；如果你有 CLAUDE.md 或 skills 文件，删掉旧指令让模型自己判断。

→ [Anthropic 官宣](https://anthropic.com/news/claude-fable-5-mythos-5)

---

### OpenAI 宣布 ChatGPT 史上最大改版：Chat is Dead

据《金融时报》曝光，OpenAI 正准备将 ChatGPT 从聊天机器人转型为 Agent 超级应用。新版将合并 ChatGPT、Codex、Atlas 浏览器为一体，聊天框让位于 AI Agent 执行实际任务的工作流。同时 GPT-5.6 代号 iris-alpha 已在 Codex 后端日志中出现，Polymarket 预测本月发布概率超 85%。这意味着 OpenAI 正式从对话范式切换到 Agentic 范式，所有做 wrapper 产品的团队需要重新评估护城河。

→ [Ars Technica 报道](https://arstechnica.com/ai/2026/06/chat-is-dead-openai-preps-overhaul-of-chatgpt/)
