## 📌 头条

### Anthropic 研究：40万 Claude Code 会话揭示人类专家依然不可替代

Anthropic 发布了基于约 40 万次 Claude Code 会话（2025.10-2026.04，23.5 万用户）的研究报告。核心发现：用户做出 70% 的规划决策，Claude Code 执行 80% 的具体任务；专家用户在 action 和 output 维度显著优于新手；7 个月内调试时间下降近一半，工作流从调试转向部署。这意味着 agentic coding 并不是「全自动」，而是把人类从执行中解放出来，让规划和架构判断的价值更突出。对你意味着什么：如果你在用 Claude Code，把精力投入在 PLAN.md 和架构约束上，执行交给 agent。

→ [原文](https://www.anthropic.com/research/claude-code-expertise)

### DeepSeek 完成 74 亿美元首轮融资，估值超 500 亿

据 Reuters 和 The Information 报道，DeepSeek 于 6 月 16 日完成了成立以来首轮外部融资，总额超过 500 亿人民币（约 74 亿美元），投后估值 520-590 亿美元。投资方包括腾讯、宁德时代、网易、京东及国家 AI 产业投资基金。独特之处在于 LP 结构——创始人梁文锋自投 29 亿美元并以有限合伙方式保留完全控制权，外部投资者不获得投票权。这是中国 AI 行业迄今最大单轮融资，信号明确：开源模型商业化路径被资本认可。

→ [Reuters](https://www.reuters.com/world/asia-pacific/chinas-deepseek-closes-over-7-billion-funding-with-unusual-deal-structure-2026-06-16/)
