## 📌 头条

### 白宫要求 OpenAI 分阶段发布 GPT-5.6

特朗普政府以安全顾虑为由，要求 OpenAI 将 GPT-5.6 先以受限预览形式交付一小批政府审批的企业客户，逐客户授权。Sam Altman 在全员会上表示预览期顺利后将在数周内全面开放。这是美国政府首次在模型发布前设置行政审批环节，意味着前沿模型的发布节奏将受政策直接影响。如果你依赖最新模型做产品，需要开始考虑多模型供应策略和发布延迟的缓冲方案。

→ [TechCrunch 报道](https://techcrunch.com/2026/06/25/the-white-house-is-asking-openai-to-slow-roll-the-release-of-its-new-model-over-safety-concerns/) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/957372/openai-will-delay-gpt-5-6-after-trump-administration-request)

### GitHub 公布 Copilot Agentic Harness 跨模型评测

GitHub 官方博客详细公开了 Copilot agentic harness 在多个 benchmark 上的表现——在支持 20+ 模型的前提下，harness 的 token 效率领先同类方案，任务完成率持平甚至优于单模型原生方案。内部路由器 HyDRA 负责自动选模型。对 Agent 开发者的启示：好的 harness 工程（上下文管理 + 模型路由）带来的提升可能比换模型更显著。

→ [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/evaluating-performance-and-efficiency-of-the-github-copilot-agentic-harness-across-models-and-tasks/)
