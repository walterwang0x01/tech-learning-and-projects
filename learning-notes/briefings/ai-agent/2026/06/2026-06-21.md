## 📌 头条

### GPT-5.6 本周发布在即，聚焦 Agent 工作流

OpenAI 首席科学家 Jakub Pachocki 内部确认 GPT-5.6 是 GPT-5.5 的「有意义提升」，代号 kindle-alpha 已现身 Codex 路由日志。Polymarket 合约定价 6 月 22-28 窗口释放概率 83-89%。核心改进方向：agentic workflow、token 效率提升 10-15%、上下文窗口扩展至 1.5M tokens（较 GPT-5.5 增加 43%）。对你的行动建议：如果你在用 Codex / ChatGPT API 做 Agent，准备好迁移测试——新模型定价约为 Claude Fable 5 的三分之一，性价比将进一步拉开。

→ [TechTimes 报道](https://www.techtimes.com/articles/318492/20260616/gpt-56-openai-chief-scientist-calls-it-meaningful-leap-june-launch-nears.htm) / [AI Weekly 分析](https://aiweekly.co/alerts/openai-plans-june-gpt-56-as-meaningful-improvement)

### MCP 企业授权扩展正式稳定，Anthropic+Okta 首发

6 月 18 日 MCP Enterprise-Managed Authorization (EMA) 扩展宣布稳定。企业 IT 管理员可通过 Okta 等 IdP 一次性配置 MCP Connector 权限，员工首次登录即自动继承——不再逐人弹 OAuth 确认。Anthropic 在 Claude 中首发实现，C1 宣布原生支持。这标志着 MCP 从「开发者协议」正式迈入「企业级基础设施」。对你的行动建议：如果你在企业内部署 MCP Server，现在可以用 EMA 替换手动 token 发放流程。

→ [MCP 官方博客](https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/) / [Anthropic 公告](https://claude.com/blog/enterprise-managed-auth)

## ⚡ 快讯

- **Vercel eve**：Vercel 发布 eve 开源 Agent 框架——以文件系统为中心（Markdown 定义 instructions/skills，TypeScript 写 tools），一行 vercel 命令部署。支持持久执行、沙箱计算、human-in-the-loop、子 Agent 和多渠道接入。 → [官方博客](https://vercel.com/blog/introducing-eve)
- **Claude Design 大更新**：Anthropic 重构 Claude Design：新增 GitHub 设计系统导入、与 Claude Code 双向同步、/design 终端命令、画布直接编辑、企业品牌控制。从研究预览升级为受治理的企业工作区。 → [报道](https://www.technobezz.com/news/anthropic-launches-claude-design-update-with-direct-pipeline-to-claude-code)
- **OpenAI 收购 Ona**：OpenAI 宣布收购云编排平台 Ona，将其持久化执行和安全编排技术整合进 Codex 生态系统，为 Agent 提供更可靠的 runtime。 → [OpenAI 公告](https://openai.com/news/company-announcements/)
- **ECC 达 210K stars**：Everything Claude Code（ECC）——开源 Agent harness 性能优化系统——GitHub stars 突破 210K，支持 Claude Code / Codex / Cursor，内置 28 个专用 Agent、119 个 skills。 → [详情](https://www.augmentcode.com/learn/everything-claude-code-github)
- **MCP 安全告警**：CYFIRMA 报告：截至 2026 年中已有 9,400+ 公开 MCP Server、1.5 亿次 MCP 工具下载，攻击面快速扩大。NSA 此前已发布 MCP 安全设计指南。 → [CYFIRMA 报告](https://www.cyfirma.com/research/exploitation-of-model-context-protocol-in-agentic-ai-deployments/)
- **Deontic Policies 论文**：新论文提出用义务逻辑（deontic logic）约束 Agent 运行时行为：不仅靠认证和访问控制，还需显式声明 Agent 被允许/禁止/必须做什么——对跨组织多 Agent 系统尤为关键。 → [arXiv](https://arxiv.org/abs/2606.19464)
- **CrewAI v1.14+ 进展**：CrewAI 六月更新新增 pluggable defaults、Chat API for conversational flows、Snowflake Cortex 原生支持、更丰富的 LLM 事件数据。当前版本 v1.14.5，40K+ GitHub stars。 → [Changelog](https://docs.crewai.com/en/changelog)
- **Context Engineering 成为主流**：Aaron Levie (Box CEO) 本周强调：Agent 成功的首要变量是能否给 Agent 提供足够 context，文件系统作为人-Agent 共享工作区是关键趋势。多篇实践指南指出 context engineering 可将 Agent 任务完成率从 30% 提升至 90%。 → [Aaron Levie 原推](https://x.com/levie/status/2068068247413694532)
