## 📌 头条

### LangGraph 三漏洞链可远程执行代码，自托管用户速升级

Check Point Research 6月12日公开披露三个 LangGraph 安全漏洞，其中 CVE-2026-28277（CVSS 6.8）利用 SQLite checkpointer 的 SQL 注入 + 不安全 msgpack 反序列化，实现 checkpoint 加载时的任意代码执行。攻击者一旦获得持久化层写权限，就能控制整个 agent 基础设施。这对自托管 LangGraph 部署是实打实的风险——如果你跑 LangGraph Platform 自管版本，立刻升级到修复版本（langgraph-checkpoint ≥ 2.0.18）。同时建议审计 checkpoint 存储后端的访问控制。

→ [The Hacker News 报道](https://thehackernews.com/2026/06/langgraph-flaw-chain-exposes-self.html) / [Check Point 原文](https://research.checkpoint.com/2026/from-sqli-to-rce-exploiting-langgraphs-checkpointer/)

### 美国政府出口管制令 Anthropic 全球禁用 Fable 5 / Mythos 5

6月14日，Anthropic 宣布应美国政府出口管制指令，全面禁用其最强模型 Fable 5 与 Mythos 5 的外国用户访问。这是美国首次以国家安全为由对已公开发布的商用 AI 模型实施访问限制。消息一出，开源权重模型成为最大受益者——Aaron Levie 等多位创始人指出，此事件将加速企业对开源/开放权重模型的投入。如果你的 agent 工作流依赖 Claude 最新模型，现在是时候做 fallback 方案了。

→ [CNBC 报道](https://www.cnbc.com/2026/06/15/anthropic-mythos-trump-ai.html) / [The Hacker News](https://thehackernews.com/2026/06/us-orders-anthropic-to-suspend-fable-5.html)
