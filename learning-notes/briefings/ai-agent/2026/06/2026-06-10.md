## 📌 头条

### Anthropic 发布 Claude Fable 5：首个公开 Mythos 级模型

Anthropic 于 6 月 9 日正式推出 Claude Fable 5——首个面向公众的 Mythos 级模型。它在网络安全和生物领域加入了专门的安全护栏，阻止高风险输出，同时保留了 Mythos 级的推理与编码能力。Pro、Max、Team 和 Enterprise 用户即日起可用（6 月 23 日后需消耗 usage credits）。与此同时，Claude Mythos 5 仅通过 Project Glasswing 向美国政府和可信研究机构开放。对你来说：如果在做 agent 开发，现在是测试 Fable 5 编码/推理能力的窗口期——趁免费阶段多跑 benchmark。

→ [Anthropic 官方公告](https://www.anthropic.com/news/claude-fable-5-mythos-5) / [AWS Bedrock 可用](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available)

### Miasma 蠕虫攻击 73 个微软 GitHub 仓库：AI 编码工具供应链告急

6 月 5 日，自复制蠕虫 Miasma 感染了微软旗下 Azure、Azure-Samples、Microsoft、MicrosoftDocs 四个组织的 73 个仓库，GitHub 在 105 秒内紧急下线。攻击者通过注入凭证窃取恶意代码，受影响工具包括与 Claude Code、Gemini CLI、VS Code 相关的仓库。这是 2026 年规模最大的开源供应链攻击之一。同期微软安全团队还披露了 Claude Code GitHub Action 的 prompt injection 漏洞（可通过 Issue/PR 内容泄露 CI/CD secrets）。对你来说：立刻审计你的 MCP server 和 GitHub Actions 的依赖锁定策略。

→ [TechCrunch 报道](https://techcrunch.com/2026/06/08/microsofts-open-source-tools-were-hacked-to-steal-passwords-of-ai-developers) / [微软安全博客 (Claude Code Action)](https://www.microsoft.com/en-us/security/blog/2026/06/05/securing-ci-cd-in-agentic-world-claude-code-github-action-case/)

## ⚡ 快讯

- **context-mode**：登顶 GitHub/HN 的 MCP 上下文优化插件，将 AI 编程 token 消耗压缩 98%（315KB→5.4KB），模型记忆从 30 分钟延长至 3 小时。跨国小团队背景，核心是 SQLite 追踪 + sandbox 工具隔离策略。 → [36氪报道](https://36kr.com/p/3845645258541319?f=rss)
- **VATS 论文**：arXiv 新论文揭示 MCP 工具调用中的隐藏攻击面：error-handling loop。错误消息拥有「隐式权威」，可触发纠错推理模式、绕过安全启发式。VATS 框架通过突变驱动方式系统性生成对抗 payload。 → [arXiv](https://arxiv.org/abs/2606.07992)
- **LangChain**：LangChain 博客发布「Give your agent its own computer」（6/5）和「Why Model Neutrality Matters」（6/4），Deep Agents 支持非阻塞后台子 agent 任务。Delta Channels 改进长时运行 agent 的 runtime。 → [LangChain Blog](https://blog.langchain.com/)
- **OpenAI Codex**：OpenAI 连发两篇案例：Notion 用 Codex 一键生成 spec 并构建 AI Voice Input；Nextdoor 工程师用 Codex 从「想怎么实现」转为「想要什么结果」。Codex 正从开发工具进化为 agentic super-app。 → [Notion 案例](https://openai.com/index/notion) / [Nextdoor 案例](https://openai.com/index/nextdoor)
- **Instruction Hierarchy 论文**：arXiv 新论文诊断推理模型在 agentic workflow 中的指令层级遵循失败模式——不只看最终是否合规，而是拆解出识别、优先级排序、执行三个独立失败点。对 prompt 安全设计有直接参考价值。 → [arXiv](https://arxiv.org/abs/2606.07808)
- **Syll**：开源自托管多模态 agent 框架，统一 MCP/API 工具、CLI 执行和 GUI 视觉控制。支持用户 teaching 和审计，目标是跨异构 surface 的个人自动化。 → [arXiv](https://arxiv.org/abs/2606.07594)
- **SearchSwarm**：面向 long-horizon deep research 的 agent delegation 架构：主 agent 分解任务→子 agent 执行→仅返回摘要结果，节省主 agent context budget。研究 delegation intelligence 问题。 → [arXiv](https://arxiv.org/abs/2606.09730)
