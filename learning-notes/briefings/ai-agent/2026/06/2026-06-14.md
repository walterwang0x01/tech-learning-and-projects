### 美国政府紧急叫停 Anthropic Fable 5 / Mythos 5

美国商务部 6 月 12 日晚间向 Anthropic 发出出口管制紧急指令，要求立即禁止所有外国国民（无论身处美国境内外）访问 Fable 5 和 Mythos 5。Anthropic 无法精准区分用户身份，选择对所有用户全面关停。据《华尔街日报》报道，事件起因是 Amazon CEO Andy Jassy 将内部安全研究结果上报白宫——研究称 Fable 5 存在一条可被利用获取网络攻击信息的 jailbreak 路径。Anthropic 公开表示不同意这一决定，认为'因一条窄范围越狱就召回服务上亿用户的商业模型，是对出口管制权的过度行使'。对你意味着什么：如果你的生产系统依赖 Fable 5 API，现在就该启动多模型 fallback 方案；同时关注后续是否恢复访问，预计最快需 1-2 周完成合规审查。

→ [The Verge 报道](https://www.theverge.com/ai-artificial-intelligence/949553/anthropic-fable-5-mythos-5-government-national-security) / [WSJ: Amazon CEO 举报细节](https://www.wsj.com/tech/ai/amazon-ceos-talks-with-u-s-officials-triggered-crackdown-on-anthropic-models-dcc90578) / [TechCrunch 分析](https://techcrunch.com/2026/06/12/anthropics-safety-warnings-may-have-just-backfired-the-government-has-pulled-the-plug-on-its-most-powerful-ai)

### Vercel AI SDK 7 发布 HarnessAgent：一个 API 切换所有 Agent Harness

Vercel 发布 AI SDK 7，核心新增 HarnessAgent 抽象层——用一套 API 即可编排 Claude Code、Codex、Pi 等主流 agent harness，就像之前切换 LLM provider 一样无缝切换底层 agent 引擎。这标志着 'agent 可移植性' 从模型层延伸到了执行层。对你意味着什么：如果你在用 AI SDK 构建应用，升级到 v7 后可以在 Claude Code 和 Codex 之间做 A/B 测试，无需重写 orchestration 代码。

→ [Vercel Changelog](https://vercel.com/changelog/program-agent-harnesses-with-ai-sdk) / [@rauchg 推文](https://x.com/rauchg/status/2065520041894756480)

## ⚡ 快讯

- **Google 搜索**：Information Agents 正式在 AI Mode 上线，面向 AI Ultra 订阅用户开放。它会 24/7 在后台监控网络信息并主动推送更新，覆盖房源、球鞋上架等长尾场景——搜索从被动查找变成主动追踪。 → [9to5Google](https://9to5google.com/2026/06/12/google-information-agents/)
- **LangGraph 安全**：Check Point Research 披露 LangGraph 持久层三漏洞链（CVE-2026-28277 等）：SQL 注入 → checkpoint 数据篡改 → msgpack 反序列化 RCE。自托管 agent 基础设施需立即升级到 LangGraph >= 4.0.0 并审计数据库访问权限。 → [The Hacker News](https://thehackernews.com/2026/06/langgraph-flaw-chain-exposes-self.html) / [Check Point 原文](https://research.checkpoint.com/2026/from-sqli-to-rce-exploiting-langgraphs-checkpointer/)
- **智谱 ZCode 3.0**：全面切换自研 ZCode Agent 内核，深度适配 GLM-5.2（支持 1M 上下文），新增分组式任务工作区和可视化 Git 分支图谱。官方表示后续不再维护第三方 Agent 适配。 → [IT之家](https://www.ithome.com/0/963/985.htm)
- **OpenAI**：秘密提交 IPO 申请，估值 $8520 亿；同期完成 $1220 亿融资。GPT-5.5 和 Codex 也正式登陆 Amazon Bedrock。此外，多州总检察长已对 OpenAI 展开调查，涉及广告政策和健康数据处理。 → [TechCrunch: IPO](https://techcrunch.com/2026/06/08/following-anthropic-openai-files-confidentially-for-ipo/) / [InfoQ: GPT-5.5 on Bedrock](https://www.infoq.cn/article/FuhAEYbk8T0b0GQZyq4c)
- **OpenAI Codex**：产品负责人宣布用量重置策略调整——下次按钮重置时用户可自选生效时间，不再突然归零。小改善，体验好很多。 → [@thsottiaux](https://x.com/thsottiaux/status/2065468501750649006)
- **CrewAI**：发布 Conversational Flow Tracing + Chat API，支持对话式 agent 流程追踪和实时事件数据（finish_reason、sampling parameters）。框架已到 v1.14，月执行 4.5 亿 workflow。 → [Changelog](https://docs.crewai.com/changelog)
