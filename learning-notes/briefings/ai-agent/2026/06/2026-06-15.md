## 📌 头条

### 美国紧急出口管制：Anthropic 全面停供 Fable 5 / Mythos 5

美国商务部以国家安全为由，向 Anthropic 发出紧急出口管制指令，禁止任何外籍人士（包括 Anthropic 自己的海外员工）使用 Fable 5 和 Mythos 5。Anthropic 被迫对所有用户「突然禁用」这两个旗舰模型。据华尔街日报报道，Amazon CEO Andy Jassy 向白宫提交了一份关于 Fable 5 可被 jailbreak 的安全研究报告，是触发此次禁令的关键因素之一。欧盟随后发声称正在评估影响，并强调此类措施不应歧视合作伙伴。对开发者而言：如果你的 agent 管线依赖 Fable/Mythos，现在就该确认 fallback 模型策略——模型路由层正在从可选变为刚需。

→ [Anthropic 官方声明](https://www.wired.com/story/anthropic-says-us-government-ordered-it-to-shut-down-mythos-models) / [Amazon 安全研究细节](https://www.theverge.com/ai-artificial-intelligence/949601/amazon-anthropic-fablemythos-government-ban) / [Ars Technica 报道](https://arstechnica.com/ai/2026/06/anthropic-shuts-down-fable-mythos-models-following-trump-admin-directive)

### OpenAI 发布 Partner Network，投 $1.5 亿培训 30 万顾问

OpenAI 正式推出 Partner Network 生态计划，预投 1.5 亿美元，目标在 2026 年底培训 30 万名 OpenAI 认证顾问。同期数据显示 Codex 周活用户已达 300 万，API 处理量超 150 亿 token/分钟。这标志着 OpenAI 从 API 供应商转向企业平台公司——如果你是 agent 集成商或咨询方，这个认证体系值得尽早关注。

→ [OpenAI 官方博客](https://openai.com/index/introducing-openai-partner-network) / [CRN 详细报道](https://www.crn.com/news/ai/2026/openai-unveils-partner-program-150m-investment-channel-chief-sees-massive-opportunity-ahead)

## 📈 趋势

- 🆕 模型路由层从可选变刚需——Fable 禁令后，单模型依赖被证明是生产环境的单点故障
- 🔺 Context engineering 取代 prompt engineering 成为 agent 开发核心技能，多篇 2026 实战指南密集发布
- 🔺 MCP 安全进入官方议程：NSA 发布设计指引、OWASP MCP Top 10 出炉、OX Security 披露 SDK 级 RCE
- 🔻 闭源模型可用性不确定性上升——出口管制风险倒逼企业在 agent 架构中预留开源 fallback
