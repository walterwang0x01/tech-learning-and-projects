## 📌 头条

### OpenAI 推出 Lockdown Mode 对抗 prompt injection

OpenAI 正式发布 ChatGPT Lockdown Mode，通过限制出站网络请求来防止 prompt injection 攻击导致的数据外泄。开启后将禁用实时网页浏览、agent mode、deep research、图片检索和文件下载等功能。该功能面向所有用户开放，个人用户可在 Settings > Security 中手动启用。OpenAI 坦承该模式无法保证完全防护新型攻击，但目标是大幅降低数据被窃取的概率。

→ [OpenAI 官方博客](https://openai.com/index/introducing-lockdown-mode-and-elevated-risk-labels-in-chatgpt/) / [TechCrunch 报道](https://techcrunch.com/2026/06/06/openai-unveils-lockdown-mode-to-protect-sensitive-data-from-prompt-injection-attacks)

### Flowise MCP 实现被曝一键 RCE 漏洞

Obsidian Security 研究人员披露了 Flowise 自托管部署中通过 MCP stdio server 实现一键远程代码执行（RCE）的漏洞。攻击者可利用 MCP 的设计缺陷执行幽灵命令。这是继 4 月 OX Security 曝出 MCP 架构级 "by design" 漏洞后，又一个影响生产环境的实际案例。此前 NSA 也已发布 MCP 安全设计指南，提醒注意序列化风险和信任边界问题。

→ [CSO Online 报道](https://www.csoonline.com/article/4179309/flowises-mcp-implementation-can-run-ghost-commands.html) / [NSA MCP 安全指南](http://www.nsa.gov/Press-Room/Press-Releases-Statements/Press-Release-View/Article/4496698/nsa-releases-security-design-considerations-for-ai-driven-automation-leveraging/)
