## 📌 头条

### Anthropic Fable 5 / Mythos 5 遭美国出口管制封禁

6 月 12 日美国商务部发出紧急出口管制指令，要求 Anthropic 立即禁止所有外国公民（含境内外国籍员工）访问 Fable 5 和 Mythos 5。Anthropic 被迫在模型发布仅 3 天后全球下线。这是美国政府首次以国籍为标准针对前沿模型实施访问限制，标志着 AI 出口管制进入「模型级精确打击」阶段。对开发者而言，如果你的 agent 管线依赖 Claude Fable/Mythos 系列，现在需要准备 fallback 到 Opus 4.8 或其他模型——API 端点已不可用，恢复时间未定。

→ [Anthropic 官方声明](https://www.anthropic.com/news/fable-mythos-access) / [The Verge 跟踪报道](https://www.theverge.com/ai-artificial-intelligence/950026/anthropic-fable-mythos-ban-ai-shutdown)

### LangGraph 曝三漏洞可链式 RCE，自托管部署须立即升级

Check Point Research 披露 LangGraph 自托管部署中的三个安全漏洞（CVE-2025-67644、CVE-2026-28277、CVE-2026-27022），从 SQL 注入到远程代码执行形成完整攻击链，可泄露 agent 记忆、API key 和对话历史。影响 langgraph-checkpoint-sqlite < 3.0 等组件。如果你跑自托管 LangGraph Server，立即 pip install --upgrade langgraph-checkpoint-sqlite langgraph-checkpoint-postgres 到修复版本。

→ [漏洞详情](https://dailysecurityreview.com/cyber-security/three-langgraph-flaws-chain-to-remote-code-execution/) / [补丁指南](https://fixitphill.com/security/langgraph-cve-2025-67644-ai-agent-server-patch-guide/)
