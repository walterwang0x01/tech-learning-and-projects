## 📌 头条

### OpenAI 推出 Lockdown Mode 防御 prompt injection

OpenAI 正式上线 Lockdown Mode，一个可选的高级安全设置，通过限制 ChatGPT 的出站网络请求来降低 prompt injection 导致的数据泄露风险。代价是禁用或限制部分联网功能（网页浏览、外部服务调用）。Free、Go、Plus、Pro 和 Business 计划均可在 Settings > Security 中手动开启。对于构建 agent 系统的开发者来说，这意味着 OpenAI 正式承认了 tool-use 场景下的 prompt injection 是一等威胁，agent 集成方应评估自己的出站请求面。

→ [OpenAI 公告](https://openai.com/index/introducing-lockdown-mode-and-elevated-risk-labels-in-chatgpt/) / [The Hacker News](https://thehackernews.com/2026/06/new-chatgpt-lockdown-mode-limits-tools.html)

### 微软披露 Claude Code GitHub Action 凭证窃取漏洞

微软安全博客详细披露了 Anthropic Claude Code GitHub Action 中的一个 prompt injection 漏洞：攻击者仅需在公开仓库提交一条恶意 issue 或 PR 评论，即可让 agent 的 Read 工具绕过沙箱读取 CI/CD workflow secrets，窃取 GitHub 凭证。根因是 Read tool 未纳入子进程环境清洗逻辑。Anthropic 已修复（claude-code-action v1），但该案例清晰展示了 AI agent 在 CI/CD 管线中处理不可信内容时的攻击面。

→ [微软安全博客](https://www.microsoft.com/en-us/security/blog/2026/06/05/securing-ci-cd-in-agentic-world-claude-code-github-action-case/) / [Flatt Security 原始报告](https://flatt.tech/research/posts/poisoning-claude-code-one-github-issue-to-break-the-supply-chain/)
