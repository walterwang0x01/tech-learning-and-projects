## 📌 头条

### OpenAI 收购 Ona，为 Codex 注入持久化 Agent 基础设施

OpenAI 宣布收购云执行与编排初创公司 Ona，其技术将为 Codex 提供安全、客户可控的持久化云环境，使 AI Agent 能执行跨数小时甚至数天的长周期任务。此前 Codex 受限于会话生命周期，只能处理短任务。收购后 Ona 团队将并入 Codex 部门，核心目标是让 Agent 不仅能写代码，还能部署、监控、迭代整个软件生命周期。如果你在用 Codex 做工程任务，接下来值得关注它对 long-running agent workflow 的支持变化。

→ [OpenAI 官方公告](https://openai.com/index/openai-to-acquire-ona)

### Check Point 披露 LangGraph 持久层关键漏洞链

Check Point Research 对月下载量超 4600 万的 LangGraph 框架进行安全审计，发现其 checkpointer 持久层存在三个可串联的漏洞（含 CVE-2026-27794 RCE），攻击者可从 SQLi 一路提权到远程代码执行，窃取 Agent 对话历史、API 密钥等敏感数据。LangGraph 4.0.0 已修复，但低版本仍在大量生产环境运行。如果你的 Agent 用了 LangGraph 的 SQLite/Postgres checkpointer，请立即升级到 4.0+ 并审计数据库访问权限。

→ [Check Point 研究报告](https://research.checkpoint.com/2026/from-sqli-to-rce-exploiting-langgraphs-checkpointer/)
