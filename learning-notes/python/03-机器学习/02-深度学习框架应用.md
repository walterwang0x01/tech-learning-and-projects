### 2.3 构建神经网络

```python
class NeuralNetwork(nn.Module):
    def __init__(self):
        super(NeuralNetwork, self).__init__()
        self.fc1 = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.2)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)
        x = self.relu(x)
        x = self.fc3(x)
        return x

# 创建模型
model = NeuralNetwork()
criterion = nn.CrossEntropyLoss()

for epoch in range(10):

        optimizer.step()
```

### 3.2 PyTorch CNN

```python
class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3)
        self.pool = nn.MaxPool2d(2, 2)
        self.conv2 = nn.Conv2d(32, 64, 3)
        self.fc1 = nn.Linear(64 * 5 * 5, 128)
        self.fc2 = nn.Linear(128, 10)
    
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(-1, 64 * 5 * 5)
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

## 4. 循环神经网络（RNN/LSTM）

### 4.1 LSTM 实现

```python
# TensorFlow
model = models.Sequential([
    layers.LSTM(50, return_sequences=True, input_shape=(timesteps, features)),
    layers.LSTM(50),
    layers.Dense(1)
])

# PyTorch
class LSTMNet(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers):
        super(LSTMNet, self).__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, 1)
    
    def forward(self, x):
        out, _ = self.lstm(x)
        out = self.fc(out[:, -1, :])
        return out
```

### 8.2 PyTorch 2.11 关键能力

#### Differentiable Collectives（可微分集合通信）

让分布式训练中 `all_reduce`、`all_gather` 等通信操作的梯度自动反向传播，不需要手写 hook。简化模型并行 / 流水线并行的实现。

```python
# PyTorch 2.11+：可微分 all_reduce
import torch
import torch.distributed as dist

# 张量参与前向传播后，all_reduce 的梯度会自动反向传播
output = torch.nn.functional.all_reduce(local_tensor, op=dist.ReduceOp.SUM)
loss = output.sum()
loss.backward()  # 梯度自动通过通信链路回传
```

#### FlexAttention + FlashAttention-4 后端

`torch.nn.attention.flex_attention` 在 Hopper（H100）和 Blackwell（B200）GPU 上自动启用 FlashAttention-4 后端，相比 FA-2 在长序列下提速 1.5-2x。

```python
from torch.nn.attention.flex_attention import flex_attention

# FA-4 后端自动启用（需 Hopper/Blackwell）
def alibi_score(score, b, h, q_idx, kv_idx):
    return score - 0.1 * (q_idx - kv_idx).abs()

output = flex_attention(query, key, value, score_mod=alibi_score)
```

#### MPS（Apple Silicon）算子全面扩展

PyTorch 2.11 完成了 MPS 后端的算子覆盖率提升，主流模型（Llama / Stable Diffusion / Whisper）在 M3/M4 芯片上无需算子回退到 CPU。

```python
# 检查 MPS 是否可用并覆盖所需算子
if torch.backends.mps.is_available():
    device = torch.device("mps")
    model = model.to(device)
    # 2.11 起 nn.RNN / nn.LSTM 在 MPS 上原生支持
```

### 8.3 PyTorch 2.7 Mega Cache（端到端可移植编译缓存）

`torch.compile` 在 2.0 引入后，编译产物只能在同一台机器复用。Mega Cache 让缓存可以打包后跨机器、跨 CI 节点复用，大幅缩短 CI 中模型编译的冷启动时间。

```python
import torch

# 启用 Mega Cache（2.7+）
torch.compiler.config.cache_dir = "/shared/torch_compile_cache"

# 导出可移植缓存
artifacts = torch._inductor.codecache.export_compile_cache("/tmp/cache.tar")

# 在另一台机器加载
torch._inductor.codecache.load_compile_cache("/tmp/cache.tar")
```

### 8.4 ExecuTorch 并入 PyTorch Core（2026-04）

PyTorch Conference Europe 2026 宣布 ExecuTorch 成为 PyTorch Core 的一部分，成为官方边缘 / 端侧推理路径。这意味着移动端、嵌入式、桌面 / 笔记本本地推理拥有统一工具链：

```python
# PyTorch → ExecuTorch（边缘推理标准路径）
import torch
from executorch.exir import to_edge

model = MyModel().eval()
example_inputs = (torch.randn(1, 3, 224, 224),)

# 1. torch.export 捕获计算图
exported = torch.export.export(model, example_inputs)

# 2. 转 Edge Dialect
edge = to_edge(exported)

# 3. 序列化为 .pte 文件，部署到移动端 / 嵌入式
executorch_program = edge.to_executorch()
with open("model.pte", "wb") as f:
    f.write(executorch_program.buffer)
```

来源：[PyTorch April 2026 Newsletter](https://pytorch.org/newsletter/april-2026/)

### 8.5 PyTorch Foundation 2026 新增项目

| 项目 | 来源 | 定位 |
| ---- | ---- | ---- |
| **ExecuTorch** | Meta | 边缘 / 端侧推理（已并入 Core） |
| **Helion** | Meta | Python DSL，简化 ML kernel 编写，autotune 跨后端可移植 |
| **Safetensors** | Hugging Face | 安全的模型权重格式，避免 pickle RCE 风险，多 GPU/多节点快速加载 |

Safetensors 替代传统 `.pt` / pickle 格式，是 2026 年生产环境模型分发的推荐方式：

```python
# 推荐：safetensors 替代 torch.save（pickle 有 RCE 风险）
from safetensors.torch import save_file, load_file

# 保存
save_file(model.state_dict(), "model.safetensors")

# 加载（无 pickle，安全）
state_dict = load_file("model.safetensors")
model.load_state_dict(state_dict)
```
