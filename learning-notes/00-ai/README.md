## 前置：Python

如果 Python 不熟（或完全零基础），先走 `01-languages/python/`：
- `00-Python基础/` 选 8 篇（变量、分支、循环、列表、字典、函数）
- `02-数据分析/02-NumPy应用.md` ★（所有原理笔记的代码都用 numpy）

已经会的直接跳过。判断标准：能写一个接收 numpy 数组的函数，做矩阵乘法、算均值方差。

## 推荐学习路线

```
00-入门准备（全景认知）
    │
    ▼
01-machine-learning/04-神经网络原理 + 05-训练工程（核心地基）
    │
    ▼
02-llm（Transformer → 分词 → 预训练 → 微调 → 推理优化）
    │
    ▼
03-实战项目（动手验证理论）
    │
    ▼
01-machine-learning/01~03（经典 ML：回归、树、集成、SVM、聚类、降维）
    │
    ▼
04-ai-agent（应用层：从框架选型到生产级系统）
```

**注意**：`01-machine-learning/00-数学基础/` 是**按需查阅**的参考资料，不要试图先读完再往下走。遇到公式看不懂时回来翻对应章节即可。
