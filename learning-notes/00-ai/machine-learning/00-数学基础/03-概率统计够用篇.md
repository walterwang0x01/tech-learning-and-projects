## 0. 这篇的定位

**这不是概率论教材。** 不讲测度论、不推分布的矩、不做假设检验的计算题。

目标：让你看懂 AI 里的概率符号，理解「为什么损失函数长这样」。

符号速查：

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| `P(A)` | | 事件 A 的概率 |
| `P(A\|B)` | P A given B | 在 B 已发生的条件下，A 的概率 |
| `E[X]` | expectation of X | X 的期望（平均值） |
| `Var[X]` | variance of X | X 的方差（波动程度） |
| `σ` | sigma | 标准差（方差的平方根） |
| `∏` | pi（大写） | 连乘（对应 `Σ` 是连加） |
| `~` | | 服从某分布，如 `X ~ N(0,1)` |
| `θ` | theta | 通常指模型参数 |

## 1. 概率分布：可能性怎么分配

分布就是「各种结果分别有多大可能」。

### 离散 vs 连续

| | 离散分布 | 连续分布 |
| --- | --- | --- |
| 取值 | 可数（0/1、1~6 点） | 连续（身高、温度） |
| 描述 | 概率质量：每个值多大概率 | 概率密度：某区间多大概率 |
| AI 例子 | 分类输出（各类别概率） | 权重初始化、噪声 |

```
离散（骰子）                 连续（正态分布）
                                  
  ▮ ▮ ▮ ▮ ▮ ▮                    ╱▔▔╲
  1 2 3 4 5 6                  ╱      ╲
每个 1/6                     ╱          ╲
                          ──┴────────────┴──
```

**要点**：离散分布所有概率加起来 = 1；连续分布曲线下总面积 = 1。

这条约束解释了 softmax 为什么要除以总和——为了让输出满足「加起来等于 1」，才能被称为概率分布。

## 2. 期望与方差：平均值和波动

```
期望 E[X] = Σ (每个取值 × 它的概率)        ← 长期平均会落在哪
方差 Var[X] = E[(X - E[X])²]              ← 平均偏离中心多远
标准差 σ = √Var[X]                        ← 方差开根号，单位和 X 一致
```

**直觉**：

```
  两个分布，期望相同，方差不同

  方差小（稳定）              方差大（波动大）
        ▮                        ▮
       ▮▮▮                     ▮ ▮ ▮
      ▮▮▮▮▮                  ▮ ▮ ▮ ▮ ▮
  ────┴┴┴┴┴────           ──┴─┴─┴─┴─┴──
       均值                      均值
```

**在 AI 里的三个用处**：

| 用处 | 说明 |
| --- | --- |
| 权重初始化 | 要控制每层输出的方差，否则信号会逐层放大或消失 |
| 归一化 | BatchNorm/LayerNorm 就是把数据调成「均值 0、方差 1」 |
| 实验报告 | 单次结果没意义，要报「多次运行的均值 ± 标准差」 |

第一条详见 [感知机与多层感知机](../04-神经网络原理/01-感知机与多层感知机.md)，第二条详见 [归一化技术](../05-训练工程/03-归一化技术.md)，第三条是本篇第 6 节的重点。

## 3. AI 里最常见的四个分布

不用记公式，认识名字和用途就行。

| 分布 | 描述什么 | 在 AI 里 |
| --- | --- | --- |
| **伯努利** | 一次二选一（抛硬币） | 二分类的输出 |
| **多项式/类别分布** | 一次多选一（掷骰子） | 多分类的输出（softmax 结果） |
| **正态（高斯）** | 钟形曲线，中间多两边少 | 权重初始化、噪声、扩散模型 |
| **均匀** | 每个值等可能 | 随机采样、Dropout 的掩码 |

### 为什么正态分布到处都是

三个现实原因：

1. **中心极限定理**：大量独立随机因素叠加，结果趋向正态。现实世界的很多量（身高、测量误差）都是这样
2. **数学性质好**：正态分布的和、线性变换还是正态，方便推导
3. **最大熵**：在只知道均值和方差的情况下，正态是「最不做额外假设」的分布

第三点对理解扩散模型有帮助——它的前向过程就是不断加正态噪声，详见 [扩散模型原理](../../llm/06-多模态/02-扩散模型原理.md)。

## 4. 条件概率与贝叶斯定理

### 条件概率

```
P(A|B) = 「已知 B 发生了，A 的概率是多少」
```

**关键理解**：条件概率是在「缩小了的样本空间」里算概率。

```
全部人群                   已知「是程序员」这个条件后
┌─────────────────┐              ┌──────────┐
│  ● ● ○ ● ○ ○   │              │ ● ● ●    │  样本空间缩小了
│  ○ ● ○ ○ ● ●   │   ──────►    │ ● ○      │  分母变成「程序员总数」
│  ● ○ ● ○ ○ ●   │              └──────────┘
└─────────────────┘
```

### 贝叶斯定理

```
P(A|B) = P(B|A) · P(A) / P(B)
```

**它解决什么问题**：把「难算的方向」换成「好算的方向」。

用一个具体例子（这个例子值得认真看，它是理解朴素贝叶斯的钥匙）：

```
问题：一封邮件包含「中奖」这个词，它是垃圾邮件的概率多大？
     也就是求 P(垃圾 | 含"中奖")   ← 这个不好直接统计

贝叶斯换个方向：
     P(垃圾|含"中奖") = P(含"中奖"|垃圾) × P(垃圾) / P(含"中奖")
                          ↑                ↑
                    这个好统计！        这个也好统计！
                （在垃圾邮件里数    （垃圾邮件占比）
                 有多少含"中奖"）
```

三个术语（会在笔记里反复出现）：

| 术语 | 对应项 | 含义 |
| --- | --- | --- |
| **先验** prior | `P(垃圾)` | 还没看邮件内容前的判断 |
| **似然** likelihood | `P(含"中奖"\|垃圾)` | 如果是垃圾邮件，出现这个证据的可能性 |
| **后验** posterior | `P(垃圾\|含"中奖")` | 看了证据后更新的判断 |

**一句话总结贝叶斯**：用新证据更新旧判断。完整应用见 [朴素贝叶斯](../02-经典算法/05-朴素贝叶斯.md)。

## 5. 最大似然估计：交叉熵损失的来源

这一节是本篇最重要的部分。**它回答了「为什么分类要用交叉熵损失」这个问题**。

### 思路

> **最大似然估计（MLE）：调参数，让「模型认为已观测数据出现的概率」最大。**

```
你手上有一批数据（已经发生的事实）
        ↓
问：什么样的参数 θ，会让这批数据「最有可能发生」？
        ↓
那个 θ 就是最优参数
```

### 从 MLE 推到交叉熵（关键四步）

假设有 N 个样本，模型对第 i 个样本给出的正确类别概率是 `pᵢ`。

**第 1 步**：所有样本都被正确预测的联合概率（假设独立，所以是连乘）

```
L(θ) = p₁ × p₂ × ... × pₙ = ∏ pᵢ
```

**第 2 步**：连乘有两个工程问题——数值下溢（几百个小于 1 的数相乘会变成 0），且不好求导。取对数把连乘变连加：

```
log L(θ) = log p₁ + log p₂ + ... = Σ log pᵢ
```

取对数为什么不改变最优解：`log` 是单调递增函数，让 `L` 最大的 θ 也让 `log L` 最大。

**第 3 步**：优化器习惯做最小化，所以加个负号，并除以 N 取平均：

```
Loss = -(1/N) Σ log pᵢ
```

**第 4 步**：这个式子就是**交叉熵损失**。

```
     MLE（最大化似然）
          ↓ 取对数
     最大化 Σ log pᵢ
          ↓ 加负号变最小化
     最小化 -Σ log pᵢ
          ↓
     这就是交叉熵损失
```

**所以「分类用交叉熵」不是拍脑袋定的约定，是最大似然估计的直接推论。** 这也解释了 [损失函数](../04-神经网络原理/05-损失函数.md) 里为什么说分类不该用 MSE——MSE 对应的是「假设误差服从正态分布」的最大似然，那是回归问题的假设，不是分类。

信息论视角的另一种解释（同一个式子的不同来路）见 [信息论够用篇](04-信息论够用篇.md)。

## 6. 采样与方差：为什么单次实验不可信

这一节直接关系到你怎么判断「模型改进是真的还是碰巧」。

### 核心事实

你训练一次得到的准确率，**是一个随机变量的一次采样**，不是真值。随机来源包括：

- 权重随机初始化
- 数据打乱顺序
- Dropout 的随机掩码
- 数据增强的随机性
- GPU 浮点运算的非确定性

### 后果

```
改进前跑一次: 准确率 87.2%
改进后跑一次: 准确率 88.1%
        ↓
"提升了 0.9%，我的改进有效！"
        ↓
但如果改进前跑 5 次是 86.1 / 87.2 / 88.4 / 86.8 / 87.9（波动 ±1.2%）
那这 0.9% 完全在噪声范围内 —— 什么也没证明
```

### 正确做法

| 做法 | 说明 |
| --- | --- |
| 跑多个随机种子 | 至少 3~5 个，报「均值 ± 标准差」 |
| 看标准误 | `SEM = 标准差 / √n`，跑的次数越多，均值越可信 |
| 判断显著性 | 改进幅度要明显大于标准差，否则不能声称有效 |

标准误那条公式解释了一个反直觉的事：**要把结论的不确定性减半，需要跑 4 倍次数**（因为是 `√n`）。所以实验预算要花在刀刃上。

详细的实验设计方法见 [实验设计与可复现性](../01-机器学习基础/03-实验设计与可复现性.md)。

## 7. 最小可运行验证

```python
import numpy as np

print("=" * 58)
print("验证 1：期望与方差——两个分布均值相同但波动不同")
print("=" * 58)

rng = np.random.default_rng(42)
n = 100000
stable = rng.normal(loc=10.0, scale=1.0, size=n)    # 标准差 1
volatile = rng.normal(loc=10.0, scale=5.0, size=n)  # 标准差 5

for name, d in [("稳定(σ=1)", stable), ("波动(σ=5)", volatile)]:
    print(f"  {name}  均值={d.mean():7.4f}  方差={d.var():7.4f}  标准差={d.std():7.4f}")
print()
print("  → 均值几乎一样，但方差差 25 倍。只看均值会漏掉关键信息")

print()
print("=" * 58)
print("验证 2：softmax 为什么要除以总和——为了满足「概率和为1」")
print("=" * 58)

logits = np.array([2.0, 1.0, 0.1])

def softmax(z):
    z = z - np.max(z)          # 减最大值防溢出，不改变结果
    e = np.exp(z)
    return e / e.sum()

probs = softmax(logits)
print(f"  模型原始输出 logits = {logits}")
print(f"  exp 之后            = {np.round(np.exp(logits - logits.max()), 4)}  ← 都变正数了，但和不为 1")
print(f"  再除以总和 (softmax) = {np.round(probs, 4)}")
print(f"  概率之和            = {probs.sum():.6f}")
print()
print("  → 除以总和这一步，是「让输出成为合法概率分布」的必要操作")

print()
print("=" * 58)
print("验证 3：贝叶斯定理——垃圾邮件例子")
print("=" * 58)

# 造一批带标签的邮件
N = 10000
p_spam = 0.3                                 # 先验：30% 是垃圾邮件
is_spam = rng.random(N) < p_spam
# 垃圾邮件 60% 含"中奖"，正常邮件只有 2% 含
has_word = np.where(is_spam, rng.random(N) < 0.60, rng.random(N) < 0.02)

# 直接统计后验（真值）
mask = has_word
posterior_direct = is_spam[mask].mean()

# 用贝叶斯公式算
p_word_given_spam = has_word[is_spam].mean()
p_spam_prior = is_spam.mean()
p_word = has_word.mean()
posterior_bayes = p_word_given_spam * p_spam_prior / p_word

print(f"  先验 P(垃圾)              = {p_spam_prior:.4f}")
print(f"  似然 P(含'中奖'|垃圾)     = {p_word_given_spam:.4f}")
print(f"  证据 P(含'中奖')          = {p_word:.4f}")
print()
print(f"  贝叶斯公式算出的后验      = {posterior_bayes:.4f}")
print(f"  直接统计得到的后验        = {posterior_direct:.4f}")
print(f"  → 一致（差 {abs(posterior_bayes - posterior_direct):.2e}）")
print()
print(f"  含义：看到'中奖'前判断有 {p_spam_prior*100:.0f}% 可能是垃圾，")
print(f"        看到之后升到 {posterior_bayes*100:.0f}% —— 这就是「用证据更新判断」")

print()
print("=" * 58)
print("验证 4：最大似然估计 = 最小化交叉熵（同一件事）")
print("=" * 58)

# 3 分类，5 个样本
true_labels = np.array([0, 2, 1, 0, 2])
logits_batch = np.array([
    [3.0, 0.5, 0.2],
    [0.1, 0.3, 2.8],
    [0.2, 2.5, 0.4],
    [2.0, 1.0, 0.5],
    [0.3, 0.2, 1.9],
])
P = np.array([softmax(row) for row in logits_batch])
p_correct = P[np.arange(len(true_labels)), true_labels]

likelihood = np.prod(p_correct)                     # 连乘
log_likelihood = np.sum(np.log(p_correct))          # 取对数变连加
cross_entropy = -np.mean(np.log(p_correct))         # 加负号、取平均

print(f"  各样本正确类别的概率 = {np.round(p_correct, 4)}")
print()
print(f"  似然（连乘）          = {likelihood:.8f}   ← 样本一多会下溢，见下方演示")
print(f"  对数似然（连加）      = {log_likelihood:.6f}")
print(f"  交叉熵损失 = -平均对数似然 = {cross_entropy:.6f}")
print()
print(f"  验证关系: -log_likelihood / N = {-log_likelihood / len(true_labels):.6f}")
print(f"            交叉熵            = {cross_entropy:.6f}")
print(f"  → 完全相等: {np.isclose(-log_likelihood / len(true_labels), cross_entropy)}")
print()
print("  → 「最大化似然」和「最小化交叉熵」是同一个优化目标的两种说法")

# 演示为什么必须取对数
print()
print("  为什么必须取对数（数值下溢演示）:")
print("  真实场景里每个样本的概率常远小于 1，连乘很快就撑不住")
for p_each, ms in [(0.5, [100, 500, 1100]), (0.1, [100, 200, 400])]:
    print(f"    每样本概率 {p_each}:")
    for m in ms:
        v = 1.0
        for _ in range(m):
            v *= p_each          # 朴素顺序连乘，真实代码里最常见的写法
        flag = "   ← 已下溢为 0，似然彻底失去意义" if v == 0.0 else ""
        print(f"      {m:5d} 个连乘 = {v:.4e}{flag}")

print()
print("=" * 58)
print("验证 5：单次实验不可信——同样的「模型」跑多次结果波动")
print("=" * 58)

def fake_train(seed):
    """模拟一次训练：同样的超参，只有随机种子不同"""
    r = np.random.default_rng(seed)
    true_acc = 0.87                       # 这个「模型」的真实水平
    return true_acc + r.normal(0, 0.012)  # 观测到的准确率带噪声

accs = np.array([fake_train(s) for s in range(10)])
print(f"  同一套配置跑 10 次的准确率:")
print(f"    {np.round(accs * 100, 2)}")
print()
print(f"  最低 = {accs.min()*100:.2f}%   最高 = {accs.max()*100:.2f}%   极差 = {(accs.max()-accs.min())*100:.2f}%")
print(f"  均值 = {accs.mean()*100:.2f}%   标准差 = {accs.std(ddof=1)*100:.2f}%")
print()
print("  假设有人「改进」后跑一次拿到 88.0%，对比别人的 86.5%：")
print(f"  → 这 1.5% 完全落在上面 {(accs.max()-accs.min())*100:.2f}% 的自然波动里，什么也没证明")

print()
print("  标准误随次数下降（要把不确定性减半，需要 4 倍次数）:")
for k in [1, 4, 16, 64]:
    sub = np.array([fake_train(s) for s in range(k)])
    sem = sub.std(ddof=1) / np.sqrt(k) if k > 1 else float("nan")
    print(f"    跑 {k:3d} 次  均值={sub.mean()*100:6.2f}%  标准误={'  N/A' if k == 1 else f'{sem*100:.3f}%'}")
```

  为什么必须取对数（数值下溢演示）:
  真实场景里每个样本的概率常远小于 1，连乘很快就撑不住
    每样本概率 0.5:
        100 个连乘 = 7.8886e-31
        500 个连乘 = 3.0549e-151
       1100 个连乘 = 0.0000e+00   ← 已下溢为 0，似然彻底失去意义
    每样本概率 0.1:
        100 个连乘 = 1.0000e-100
        200 个连乘 = 1.0000e-200
        400 个连乘 = 0.0000e+00   ← 已下溢为 0，似然彻底失去意义

==========================================================
验证 5：单次实验不可信——同样的「模型」跑多次结果波动
==========================================================
  同一套配置跑 10 次的准确率:
    [87.15 87.41 87.23 89.45 86.22 86.04 88.26 87.   84.91 86.04]

  最低 = 84.91%   最高 = 89.45%   极差 = 4.54%
  均值 = 86.97%   标准差 = 1.28%

  假设有人「改进」后跑一次拿到 88.0%，对比别人的 86.5%：
  → 这 1.5% 完全落在上面 4.54% 的自然波动里，什么也没证明

  标准误随次数下降（要把不确定性减半，需要 4 倍次数）:
    跑   1 次  均值= 87.15%  标准误=  N/A

## 8. 小结

| 概念 | 一句话 | 在 AI 里的位置 |
| --- | --- | --- |
| 概率分布 | 可能性怎么分配，总和为 1 | softmax 输出必须满足这个约束 |
| 期望 / 方差 | 平均值 / 波动程度 | 权重初始化、归一化、实验报告 |
| 正态分布 | 钟形，中间多两边少 | 初始化、噪声、扩散模型 |
| 条件概率 | 缩小样本空间后的概率 | 一切「已知 X 求 Y」 |
| **贝叶斯定理** | 用新证据更新旧判断 | 朴素贝叶斯、概率建模 |
| **最大似然估计** | **调参数让已观测数据最可能发生** | **交叉熵损失的来源** |
| 采样方差 | 单次结果是随机变量的一次采样 | 实验必须报多种子均值±标准差 |

**如果只记两件事**：交叉熵损失 = 最大似然估计取对数加负号（不是拍脑袋的约定）；单次实验结果不能用来声称改进有效。
