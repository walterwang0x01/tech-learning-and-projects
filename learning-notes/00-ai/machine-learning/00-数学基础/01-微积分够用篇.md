## 0. 这篇的定位

**这不是微积分教材。** 目标只有一个：让你看到 AI 笔记里的公式时，能认出它在说什么。

三条明确的边界：

- **不讲证明**。极限的严格定义、中值定理，一概不提
- **不出习题**。你不需要会手算导数，代码里 numpy / PyTorch 会算
- **不背导数表**。需要时查即可

每个概念只回答三件事：直觉上在说什么、在 AI 里长什么样、numpy 怎么算。

先给个符号速查表，后面遇到不认识的符号回来看：

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| `dy/dx` | d y d x | y 对 x 的导数 |
| `∂L/∂w` | partial L partial w | L 对 w 的**偏**导数（多变量时用这个） |
| `∇L` | nabla L | L 的梯度（所有偏导打包成的向量） |
| `Σ` | sigma | 求和 |
| `⊙` | 圆点 | 逐元素相乘（Hadamard 积） |
| `≈` | | 近似等于 |

## 1. 导数：变一点，跟着变多少

忘掉「切线斜率」这种说法，换个更有用的理解：

> **导数回答的是：输入动一点点，输出会跟着动多少。**

```
        输入 x 增加一个极小量 ε
                  ↓
        输出 y 变化了多少？
                  ↓
        变化量 / ε  就是导数
```

写成式子：

```
dy/dx ≈ [ f(x + ε) - f(x) ] / ε        （ε 是极小量）
```

**为什么 AI 需要它**：训练模型的全部工作，就是不停问「这个参数调大一点，损失会变小还是变大？」——这就是导数。

### 三个直觉

| 导数值 | 含义 | 训练时怎么做 |
| --- | --- | --- |
| `dy/dx > 0` | x 增大，y 也增大 | 想让 y 变小 → 把 x 调**小** |
| `dy/dx < 0` | x 增大，y 反而减小 | 想让 y 变小 → 把 x 调**大** |
| `dy/dx = 0` | x 动了 y 不动 | 到了平地，可能是谷底（也可能是山顶或鞍点） |

注意第三行的「想让 y 变小就往导数的反方向调」——这就是梯度下降的全部思想，第 4 节会展开。

### 几个 AI 里会碰到的导数

不用背，眼熟就行：

| 函数 | 导数 | 在哪出现 |
| --- | --- | --- |
| `f(x) = x²` | `2x` | MSE 损失 |
| `f(x) = eˣ` | `eˣ` | softmax、指数族 |
| `f(x) = ln(x)` | `1/x` | 交叉熵、对数似然 |
| `σ(x) = 1/(1+e⁻ˣ)`（sigmoid） | `σ(x)·(1-σ(x))` | 激活函数 |
| `f(x) = max(0, x)`（ReLU） | x>0 时为 1，x<0 时为 0 | 最常用的激活函数 |

ReLU 那一行值得多看一眼：它的导数在正区间**恒等于 1**。这个「1」是 ReLU 能缓解梯度消失的原因——详见 [激活函数](../04-神经网络原理/04-激活函数.md)。

## 2. 偏导数：多个旋钮，只转一个

神经网络有几百万个参数。要问「损失对**某一个**参数的敏感度」，就得用偏导数。

> **偏导数 `∂L/∂w`：把其他所有参数按住不动，只让 w 变一点点，看 L 变多少。**

```
调音台类比：
┌─────────────────────────────────┐
│  ▮  ▮  ▮  ▮  ▮  ▮  ▮  ▮  ▮   │  ← 几百万个旋钮（参数）
│  ↑                              │
│  只转这一个，其他按住不动         │
└─────────────────────────────────┘
        听音量（损失）变了多少 = ∂L/∂w
```

符号从 `d` 换成 `∂`，唯一的意思就是：**这是多变量场景，我只关心其中一个**。

## 3. 链式法则：AI 里最重要的一条

如果这篇只能记一件事，记这个。**反向传播就是链式法则**。

### 直觉

链式法则处理的是「层层传递的影响」：

```
拧水龙头  →  水流量变化  →  水池水位变化
   ↓             ↓              ↓
  转动 x       流量 u         水位 y

水龙头多转 1 度，水位涨多少？
= (每度带来多少流量) × (每单位流量带来多少水位)
= du/dx × dy/du
```

写成式子：

```
dy/dx = dy/du · du/dx
```

**关键洞察：整条链的影响 = 每一环影响的乘积。**

### 在神经网络里长什么样

一个最小的网络：

```
w ──► z = w·x + b ──► a = σ(z) ──► L = (a - y)²
```

要求 `∂L/∂w`（损失对权重的敏感度），直接求很难，但沿着链条拆开就很容易：

```
∂L     ∂L     ∂a     ∂z
──── = ──── · ──── · ────
∂w     ∂a     ∂z     ∂w
       ↑      ↑      ↑
    损失对   激活对  线性层对
    激活的   输入的  权重的
    导数     导数    导数
```

每一项单独看都很简单：

| 项 | 值 | 来源 |
| --- | --- | --- |
| `∂L/∂a` | `2(a - y)` | `x²` 的导数是 `2x` |
| `∂a/∂z` | `σ'(z)` | 激活函数的导数 |
| `∂z/∂w` | `x` | `w·x` 对 w 求导就是 x |

乘起来：`∂L/∂w = 2(a-y) · σ'(z) · x`

**这就是反向传播的核心式子。** 完整推导见 [反向传播推导](../04-神经网络原理/02-反向传播推导.md)。

### 为什么叫「反向」

注意上面那串乘法的顺序：从 `∂L/∂a`（最靠近损失的一项）开始，往输入方向倒着乘。前向计算是 `w → z → a → L`，求导是 `L → a → z → w`，方向相反。

这也解释了为什么深层网络会梯度消失：几十层就是几十个数连乘，如果每项都小于 1，乘到最后就趋近于 0。

## 4. 梯度：所有偏导打包成一个向量

有几百万个参数，就有几百万个偏导数。把它们按顺序装进一个向量，就是**梯度**，记作 `∇L`（读 nabla L）。

```
∇L = [ ∂L/∂w₁, ∂L/∂w₂, ∂L/∂w₃, ..., ∂L/∂wₙ ]
```

### 梯度的关键性质

> **梯度指向函数上升最快的方向。**

所以想让损失下降最快，就往**反**方向走：

```
w ← w - η · ∇L
        ↑     ↑
     学习率  梯度
    （步子多大）
```

那个减号就是「反方向」的全部含义。这一行式子就是**梯度下降**，是几乎所有模型训练的基础。

```
损失函数的地形（想象在山上找最低点）

  损失
   ↑
   │╲                    ╱
   │ ╲     你在这里      ╱
   │  ╲       ●         ╱
   │   ╲     ↓         ╱      ● 处的梯度指向右上（上升最快）
   │    ╲   走这边     ╱       所以你该往左下走（梯度反方向）
   │     ╲___________╱
   └──────────────────────► 参数 w
              ↑
            谷底（梯度为 0）
```

学习率 `η`（读 eta）的选择很关键：太小走不动，太大会在谷底来回跨越。详见 [学习率调度与训练技巧](../05-训练工程/04-学习率调度与训练技巧.md)。

## 5. 驻点、极值、鞍点：为什么训练不保证最优

梯度为 0 的点叫**驻点**，但驻点不一定是谷底：

```
   谷底（极小值）      山顶（极大值）        鞍点
                                        
    ╲     ╱              ╱╲             ╲  ╱   ← 一个方向是谷
     ╲   ╱              ╱  ╲             ╲╱
      ╲_╱              ╱    ╲            ╱╲    ← 另一个方向是峰
       ●                ●                 ●
    梯度=0            梯度=0            梯度=0
```

### 凸 vs 非凸

| | 凸函数 | 非凸函数 |
| --- | --- | --- |
| 长相 | 像一个碗，只有一个谷底 | 崎岖山地，很多谷底 |
| 保证 | 找到的驻点**一定**是全局最优 | 找到的可能只是局部最优 |
| 例子 | 线性回归、逻辑回归、SVM | **所有神经网络** |

**这解释了一个重要事实**：神经网络训练没有「找到最优解」的数学保证。同样的代码跑两次，因为随机初始化不同，可能落进不同的谷底、得到不同的结果。

这不是 bug，是非凸优化的本质。相关讨论见 [实验设计与可复现性](../01-机器学习基础/03-实验设计与可复现性.md)。

好消息是：实践中发现，高维空间里的局部最优往往「足够好」，而鞍点比局部最优更常见——现代优化器（Adam 等）主要在对付鞍点，详见 [梯度下降与优化器](../04-神经网络原理/03-梯度下降与优化器.md)。

## 6. 矩阵求导：只需要认识形状

真实的神经网络不是对单个数求导，是对矩阵求导。你**不需要**会推矩阵求导公式，只需要一条规则：

> **梯度的形状，永远和被求导的东西一样。**

```
如果  W 的形状是 (输出维度, 输入维度) = (4, 3)
那么  ∂L/∂W 的形状也是 (4, 3)
```

这条规则的实用价值：写代码时形状不匹配报错，检查一下梯度形状是否等于参数形状，八成能定位问题。

几个常用结论（眼熟即可，不必记）：

| 前向 | 对 W 的梯度 |
| --- | --- |
| `z = W·x` | `∂L/∂W = δ · xᵀ` |
| `z = W·x + b` | `∂L/∂b = δ` |

其中 `δ = ∂L/∂z`，`xᵀ` 是 x 的转置。转置见 [线性代数够用篇](02-线性代数够用篇.md)。

## 7. 最小可运行验证

不手算，用代码验证前面的每个结论。核心手法是**数值微分**：用「变一点看变多少」的定义直接算，和解析解对比。

```python
import numpy as np


def numerical_derivative(f, x, eps=1e-6):
    """数值微分：直接用导数的定义算
    用中心差分 [f(x+ε) - f(x-ε)] / 2ε，比单侧差分更准
    """
    return (f(x + eps) - f(x - eps)) / (2 * eps)


print("=" * 52)
print("验证 1：常见函数的导数")
print("=" * 52)

cases = [
    ("x²",        lambda x: x ** 2,               lambda x: 2 * x,                        3.0),
    ("eˣ",        lambda x: np.exp(x),            lambda x: np.exp(x),                    1.0),
    ("ln(x)",     lambda x: np.log(x),            lambda x: 1 / x,                        2.0),
    ("sigmoid",   lambda x: 1 / (1 + np.exp(-x)), lambda x: (lambda s: s * (1 - s))(1 / (1 + np.exp(-x))), 0.5),
    ("ReLU(正)",  lambda x: np.maximum(0, x),     lambda x: 1.0,                          2.0),
    ("ReLU(负)",  lambda x: np.maximum(0, x),     lambda x: 0.0,                         -2.0),
]

for name, f, df, x0 in cases:
    num = numerical_derivative(f, x0)
    ana = df(x0)
    print(f"  {name:9s} x={x0:5.1f}  数值={num:9.6f}  解析={ana:9.6f}  差={abs(num-ana):.2e}")

print()
print("=" * 52)
print("验证 2：链式法则（神经网络那个例子）")
print("=" * 52)

# w ──► z = w·x + b ──► a = σ(z) ──► L = (a - y)²
w, x, b, y = 0.8, 2.0, 0.1, 1.0

def sigmoid(t):
    return 1 / (1 + np.exp(-t))

def loss_of_w(w_val):
    """完整前向：给定 w，算出损失"""
    z = w_val * x + b
    a = sigmoid(z)
    return (a - y) ** 2

# 方式一：数值微分（把整条链当黑盒）
num_grad = numerical_derivative(loss_of_w, w)

# 方式二：链式法则逐项相乘
z = w * x + b
a = sigmoid(z)
dL_da = 2 * (a - y)          # 损失对激活
da_dz = a * (1 - a)          # sigmoid 的导数
dz_dw = x                    # 线性层对权重
chain_grad = dL_da * da_dz * dz_dw

print(f"  前向: w={w} → z={z:.4f} → a={a:.4f} → L={(a-y)**2:.6f}")
print()
print(f"  ∂L/∂a = 2(a-y)     = {dL_da:9.6f}")
print(f"  ∂a/∂z = a(1-a)     = {da_dz:9.6f}")
print(f"  ∂z/∂w = x          = {dz_dw:9.6f}")
print(f"  三项相乘（链式法则）= {chain_grad:9.6f}")
print(f"  数值微分（黑盒验证）= {num_grad:9.6f}")
print(f"  → 两者一致，误差 {abs(chain_grad - num_grad):.2e}")

print()
print("=" * 52)
print("验证 3：梯度指向上升方向，所以要往反方向走")
print("=" * 52)

# 一个简单的碗形函数：L(w) = (w - 3)²，谷底在 w=3
def bowl(w_vec):
    return np.sum((w_vec - 3.0) ** 2)

def bowl_grad(w_vec):
    return 2 * (w_vec - 3.0)

w_now = np.array([0.0, 0.0])
g = bowl_grad(w_now)
step = 0.3

print(f"  当前位置 w = {w_now}, 损失 = {bowl(w_now):.4f}")
print(f"  梯度 ∇L = {g}（指向损失上升最快的方向）")
print()
print(f"  沿梯度正方向走: w = {w_now + step * g}  损失 = {bowl(w_now + step * g):.4f}  ← 变大了")
print(f"  沿梯度反方向走: w = {w_now - step * g}  损失 = {bowl(w_now - step * g):.4f}  ← 变小了")
print()
print("  这就是 w ← w - η·∇L 里那个减号的理由")

print()
print("=" * 52)
print("验证 4：梯度形状永远等于参数形状")
print("=" * 52)

rng = np.random.default_rng(0)
W = rng.normal(0, 1, (4, 3))     # 权重：4 个输出，3 个输入
x_in = rng.normal(0, 1, (3, 1))  # 一个样本
delta = rng.normal(0, 1, (4, 1)) # 假设已知 ∂L/∂z

grad_W = delta @ x_in.T          # ∂L/∂W = δ · xᵀ

print(f"  W 形状      = {W.shape}")
print(f"  ∂L/∂W 形状  = {grad_W.shape}")
print(f"  → 一致：{W.shape == grad_W.shape}")
print()
print("  实用价值：代码报形状错误时，先检查梯度形状是否等于参数形状")

print()
print("=" * 52)
print("验证 5：非凸函数有多个谷底（同样的代码可能落进不同的谷）")
print("=" * 52)

# 一个有两个谷底的非凸函数
def bumpy(w):
    return w ** 4 - 4 * w ** 2 + 0.5 * w

def bumpy_grad(w):
    return 4 * w ** 3 - 8 * w + 0.5

for start in [-2.0, 2.0]:
    w_cur = start
    for _ in range(200):
        w_cur -= 0.02 * bumpy_grad(w_cur)
    print(f"  从 w={start:5.1f} 出发 → 收敛到 w={w_cur:7.4f}, 损失={bumpy(w_cur):8.4f}")

print()
print("  同一个函数、同一套代码，起点不同就落进不同的谷底。")
print("  这是非凸优化的本质，不是 bug——所以实验必须报多种子结果。")
```

## 8. 小结

| 概念 | 一句话 | 在 AI 里的位置 |
| --- | --- | --- |
| 导数 `dy/dx` | 输入变一点，输出跟着变多少 | 一切训练的基础 |
| 偏导 `∂L/∂w` | 按住其他参数，只动 w | 每个参数各自的更新依据 |
| **链式法则** | 整条链的影响 = 各环影响的乘积 | **就是反向传播** |
| 梯度 `∇L` | 所有偏导打包成向量，指向上升最快方向 | 梯度下降往它的反方向走 |
| 驻点 | 梯度为 0，可能是谷底/山顶/鞍点 | 训练停下来的地方 |
| 凸 vs 非凸 | 凸有唯一谷底，非凸有很多 | 神经网络都是非凸，无最优保证 |
| 矩阵求导 | 只需记：梯度形状 = 参数形状 | 调试形状错误的抓手 |

**如果只记一件事**：`∂L/∂w` 读作「w 动一点，损失跟着动多少」，而链式法则让这个量可以逐层往回算——这就是深度学习能训练的全部数学基础。
