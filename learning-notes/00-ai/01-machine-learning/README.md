# 机器学习与深度学习原理

> Author: Walter Wang

本目录补齐仓库原先缺失的**模型原理层**。与 `../python/03-机器学习/`（Python 生态实操）、`../ai-agent/`（Agent 应用工程）的分工是：

| 目录 | 视角 | 回答的问题 |
| --- | --- | --- |
| `machine-learning/`（本目录） | **原理** | 模型内部为什么这样运作 |
| `../llm/` | **大模型原理** | Transformer 与 LLM 的机制细节 |
| `../python/03-机器学习/` | 工程实操 | 用 Python 怎么跑起来 |
| `../ai-agent/` | 应用工程 | 怎么用模型造系统 |

每篇笔记的约定：开头列「读完你能回答的 3 个问题」作自测锚点，正文含**可运行的 numpy 实现**（不依赖框架），结尾有小结表格。单篇控制在 15KB 左右，约 20 分钟读完一轮。

## 建议阅读顺序

> **数学卡住时**：不要先补完数学再开始。直接读，卡在哪个符号就查 `00-数学基础/` 对应那一节，
> 或者直接问 AI。理由见 [学习路线与常见误区](../00-入门准备/03-学习路线与常见误区.md) 第 1 节。

如果目标是**读懂大模型行为**（推荐路径）：

```
04-神经网络原理/02-反向传播推导
        ↓
04-神经网络原理/03-梯度下降与优化器
        ↓
05-训练工程/02-正则化 → 03-归一化 → 04-学习率调度
        ↓
../llm/01-Transformer原理/  （进入大模型原理）
```

如果目标是**补齐经典 ML**（面试、数据类任务）：

```
01-机器学习基础/01-学习范式与泛化
        ↓
02-经典算法/01 → 02 → 03（回归 → 树 → 集成，这条线最实用）
        ↓
03-特征工程/01-特征工程方法论
```

如果目标是**理解多模态与序列模型**：

```
06-CNN与视觉/01 → 02 → 03
07-RNN与序列/01 → 02
        ↓
../llm/06-多模态/
```
