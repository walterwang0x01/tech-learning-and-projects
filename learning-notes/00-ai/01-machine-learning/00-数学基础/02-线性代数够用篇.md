## 0. 这篇的定位

**这不是线性代数教材。** 不讲行列式怎么手算、不讲高斯消元、不证明定理。

目标：让你看到 AI 代码和公式里的向量、矩阵、点积、范数、特征值时，知道它们在干什么。

符号速查：

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| `x` 或 `**x**` | | 向量（一列数） |
| `W` | | 矩阵（一个二维数组） |
| `xᵀ` | x transpose | 转置（行变列、列变行） |
| `a · b` 或 `aᵀb` | 点积 | 两个向量的点积，结果是**一个数** |
| `A @ B` | | 矩阵乘法（Python 里的写法） |
| `‖x‖` | norm x | 范数（向量的「长度」） |
| `‖x‖₂` / `‖x‖₁` | L2 / L1 范数 | 两种不同的长度定义 |

## 1. 向量：一组数，也是一个方向

向量就是一组按顺序排列的数：

```python
x = [3, 4]          # 二维向量
e = [0.2, -0.5, 0.8, 0.1, ...]   # 768 维的词向量
```

**两种理解方式，AI 里都用得到**：

| 理解 | 说明 | 用在哪 |
| --- | --- | --- |
| 一组数 | 就是若干个特征值排在一起 | 一条数据的特征、一个样本 |
| 一个方向 | 从原点出发指向某处的箭头 | 词向量、embedding、语义方向 |

```
        ↑ y
      4 │      ● (3,4)
        │     ╱
        │    ╱   向量 [3,4]：
        │   ╱     既是「两个数 3 和 4」
        │  ╱      也是「指向右上方的一个箭头」
        │ ╱
        └────────────→ x
       0      3
```

**为什么 AI 里到处是向量**：一个词、一张图、一个用户，都被表示成一个高维向量（embedding）。「语义相似」就变成了「向量方向接近」——这是整个现代 AI 的表示基础。详见 [词向量演进](../../02-llm/02-分词与表示/02-词向量演进.md)。

## 2. 点积：衡量「同方向程度」

点积把两个向量变成**一个数**：

```
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ        （逐位相乘再全部加起来）
```

### 直觉：点积在测什么

> **点积大 = 两个向量方向接近；点积小甚至为负 = 方向不同甚至相反。**

```
方向相同           方向垂直            方向相反
                                    
  →  →              →                →  ←
  a  b              a                a  b
                    ↑ b
                    
点积 = 大正数      点积 = 0        点积 = 负数
（很相关）        （无关）         （反相关）
```

**这就是注意力机制用点积的原因**。`Q·Kᵀ` 在问：「查询向量 Q 和键向量 K 的方向有多接近？」接近就说明相关，该多分配注意力。详见 [注意力机制推导](../../02-llm/01-Transformer原理/01-注意力机制推导.md)。

### 余弦相似度：点积的归一化版本

点积有个问题：向量越长，点积越大，哪怕方向没变。所以要除掉长度：

```
cos(a, b) = (a · b) / (‖a‖ · ‖b‖)
```

结果在 `-1` 到 `1` 之间：

| 值 | 含义 |
| --- | --- |
| `1` | 方向完全相同 |
| `0` | 垂直，无关 |
| `-1` | 方向完全相反 |

**这是向量检索的核心度量**。RAG 系统里「找最相关的文档」，就是算查询向量和所有文档向量的余弦相似度，取最高的几个。详见 [向量数据库选型](../../04-ai-agent/06-RAG进阶/02-向量数据库选型.md)。

## 3. 矩阵乘法：两种理解都要有

矩阵乘法是 AI 里最高频的运算。它有两种理解，各自解释不同的场景。

### 理解一：批量点积

```
A @ B 的第 (i,j) 个元素 = A 的第 i 行 与 B 的第 j 列 的点积
```

```
      B 的列
       ↓
  ┌───┬───┐        ┌─────┬─────┐
  │ b₁│ b₂│        │a₁·b₁│a₁·b₂│  ← A 第1行分别和 B 各列点积
  └───┴───┘        ├─────┼─────┤
                   │a₂·b₁│a₂·b₂│  ← A 第2行分别和 B 各列点积
  A 的行 →          └─────┴─────┘
```

**这个理解解释了注意力机制**：`Q @ Kᵀ` 一次算出「每个查询」和「每个键」的所有点积，得到一个相关性矩阵。

### 理解二：空间变换

一个矩阵可以看成一个「变换器」：输入一个向量，输出另一个向量。

```
  输入向量 x        矩阵 W          输出向量 z
  ┌─────┐        ┌───────┐       ┌─────┐
  │ 3 维 │  ───► │ 4 × 3 │ ───►  │ 4 维 │
  └─────┘        └───────┘       └─────┘
                     ↑
              把 3 维空间的点，映射到 4 维空间
```

**这个理解解释了神经网络的每一层**：`z = W·x + b` 就是「先做一次空间变换，再平移一下」。多层堆叠 = 多次变换，把数据一步步扭到线性可分的形状。详见 [感知机与多层感知机](../04-神经网络原理/01-感知机与多层感知机.md)。

### 形状规则：AI 代码最常报的错

```
(m, n) @ (n, p) = (m, p)
     ↑     ↑
   这两个必须相等，否则报错
```

**记忆方法**：内侧对齐，外侧留下。

```
(4, 3) @ (3, 1) → (4, 1)     ✅  内侧 3 = 3
                ↑
             3 和 3 相等，消掉

(4, 3) @ (4, 1) → ❌ 报错     内侧 3 ≠ 4
```

调试技巧：报形状错误时，先把每个张量的 `.shape` 打出来，对着上面的规则看内侧是否相等。这条规则能解决八成的形状 bug。

## 4. 转置：行列互换

```
       A                    Aᵀ
  ┌───┬───┬───┐        ┌───┬───┐
  │ 1 │ 2 │ 3 │        │ 1 │ 4 │
  ├───┼───┼───┤   →    ├───┼───┤
  │ 4 │ 5 │ 6 │        │ 2 │ 5 │
  └───┴───┴───┘        ├───┼───┤
     (2, 3)            │ 3 │ 6 │
                       └───┴───┘
                         (3, 2)
```

**为什么 AI 里到处是转置**：就是为了让形状对上。比如 `Q @ Kᵀ`——Q 和 K 形状都是 `(序列长度, 维度)`，直接相乘内侧对不上，K 转置后变成 `(维度, 序列长度)`，内侧就对齐了。

## 5. 范数：向量的「长度」有多种定义

范数就是「这个向量有多大」，但「大」有不同定义方式：

| 范数 | 公式 | 直觉 |
| --- | --- | --- |
| **L2 范数** `‖x‖₂` | `√(x₁² + x₂² + ...)` | 直线距离（勾股定理） |
| **L1 范数** `‖x‖₁` | `\|x₁\| + \|x₂\| + ...` | 曼哈顿距离（只能沿街道走） |

```
从 O 到 P 的距离：

     P
     ●
     │╲
   3 │ ╲ 5     L2（直线）= √(3²+4²) = 5
     │  ╲      L1（走街道）= 3 + 4 = 7
     └───●
   O   4
```

**为什么 AI 里区分这两个**：它们对应两种正则化，效果完全不同。

| | L2 正则 | L1 正则 |
| --- | --- | --- |
| 惩罚项 | `λ‖w‖₂²` | `λ‖w‖₁` |
| 效果 | 权重普遍变小但不为 0 | **很多权重恰好变成 0**（稀疏） |
| 别名 | 权重衰减、Ridge | Lasso |

L1 为什么产生稀疏解，涉及几何解释，详见 [正则化技术](../05-训练工程/02-正则化技术.md)。

## 6. 特征值与特征向量：不改方向，只缩放

这是本篇唯一稍抽象的概念，但 PCA、谱分析都靠它，值得花五分钟。

### 直觉

矩阵是变换器，大多数向量经过变换后**方向会改变**。但有些特殊向量，变换后**方向不变，只是被拉长或压短**——这些就是特征向量，拉伸的倍数就是特征值。

```
一般向量：方向变了
    变换前  →→→          变换后  ↗↗↗
    
特征向量：方向没变，只是变长了
    变换前  →→→          变换后  →→→→→→
                                （长度 × 2，特征值 = 2）
```

写成式子：

```
A · v = λ · v
      ↑     ↑
   矩阵作用  只是缩放了 λ 倍
```

`v` 是特征向量，`λ`（读 lambda）是特征值。

### 为什么 PCA 用它

PCA 要找「数据变化最大的方向」。数学上可以证明：**数据协方差矩阵的特征向量，就是这些方向；对应的特征值，就是该方向上的方差大小**。

```
        数据云
      ●   ●  ●
    ●  ● ●  ●  ●        ↗ 特征值大的方向（数据在这个方向上很分散）
   ●  ●●●● ● ●
    ● ● ●● ●          ↖ 特征值小的方向（数据在这个方向上很集中）
      ●  ● ●
```

所以降维就是：算出特征值，按大小排序，保留特征值大的那几个方向，丢掉小的。丢掉的那些方向数据本来就没什么变化，丢了损失小。完整推导见 [降维](../02-经典算法/07-降维.md)。

## 7. 广播机制：numpy 的形状自动扩展

这不是数学概念，是 numpy 的一个特性，但你读我的所有代码都会碰到，必须知道。

```python
A = np.ones((3, 4))    # 形状 (3, 4)
b = np.array([1, 2, 3, 4])   # 形状 (4,)
A + b                  # 能算！b 被自动复制成 3 行
```

规则（从右往左对齐，每个维度满足其一即可）：

1. 两个维度相等
2. 其中一个是 1
3. 其中一个不存在（缺的维度当成 1）

```
  (3, 4)
+    (4,)      ← 右对齐后，4 对 4 ✅，左边缺的当 1 ✅
= (3, 4)

  (3, 4)
+ (3,)         ← 右对齐后，4 对 3 ❌ 报错
```

**常见坑**：想让 `(3,4)` 每行加不同的数，得写成 `(3,1)` 而不是 `(3,)`。

## 8. 最小可运行验证

```python
import numpy as np

print("=" * 56)
print("验证 1：点积衡量方向接近程度")
print("=" * 56)

cases = [
    ("方向相同",   np.array([1.0, 0.0]), np.array([2.0, 0.0])),
    ("方向接近",   np.array([1.0, 0.0]), np.array([1.0, 0.3])),
    ("互相垂直",   np.array([1.0, 0.0]), np.array([0.0, 1.0])),
    ("方向相反",   np.array([1.0, 0.0]), np.array([-1.0, 0.0])),
]
for name, a, b in cases:
    dot = np.dot(a, b)
    cos = dot / (np.linalg.norm(a) * np.linalg.norm(b))
    print(f"  {name}  a={a}  b={b}  点积={dot:6.2f}  余弦={cos:6.3f}")

print()
print("  → 点积/余弦越大方向越接近。这就是注意力机制用点积算相关性的理由")

print()
print("=" * 56)
print("验证 2：长度会污染点积，所以要用余弦相似度")
print("=" * 56)

q = np.array([1.0, 1.0])
doc_a = np.array([1.0, 1.0])          # 方向完全一致，但很短
doc_b = np.array([10.0, -5.0])        # 方向不太一致，但很长

for name, d in [("方向一致但短", doc_a), ("方向不一致但长", doc_b)]:
    dot = np.dot(q, d)
    cos = dot / (np.linalg.norm(q) * np.linalg.norm(d))
    print(f"  {name:16s} 点积={dot:7.2f}  余弦={cos:7.3f}")

print()
print("  → 按点积排，「长」的那个赢了；按余弦排，「方向对」的那个赢了")
print("  → 向量检索必须用余弦（或先归一化），否则长文档会不公平地占优")

print()
print("=" * 56)
print("验证 3：矩阵乘法的形状规则（内侧对齐，外侧留下）")
print("=" * 56)

trials = [((4, 3), (3, 1)), ((4, 3), (3, 5)), ((4, 3), (4, 1))]
for s1, s2 in trials:
    A, B = np.ones(s1), np.ones(s2)
    try:
        out = (A @ B).shape
        print(f"  {s1} @ {s2} = {out}   ✅  内侧 {s1[1]}={s2[0]}")
    except ValueError:
        print(f"  {s1} @ {s2} → 报错  ❌  内侧 {s1[1]}≠{s2[0]}")

print()
print("=" * 56)
print("验证 4：矩阵乘法 = 批量点积（注意力机制的算法）")
print("=" * 56)

rng = np.random.default_rng(0)
Q = rng.normal(0, 1, (2, 4))    # 2 个查询，每个 4 维
K = rng.normal(0, 1, (3, 4))    # 3 个键，每个 4 维

scores_matmul = Q @ K.T          # 一次算完所有组合

# 手动逐个点积对照
scores_manual = np.zeros((2, 3))
for i in range(2):
    for j in range(3):
        scores_manual[i, j] = np.dot(Q[i], K[j])

print(f"  Q 形状 {Q.shape}，K 形状 {K.shape}，Q @ K.T 形状 {scores_matmul.shape}")
print(f"  矩阵乘法结果:\n{scores_matmul}")
print(f"  逐个点积结果:\n{scores_manual}")
print(f"  → 完全一致: {np.allclose(scores_matmul, scores_manual)}")
print("  → 一次矩阵乘法 = 所有「查询×键」的点积。这就是注意力的第一步")

print()
print("=" * 56)
print("验证 5：L1 与 L2 范数的差异")
print("=" * 56)

vecs = [
    ("能量集中在一个分量", np.array([5.0, 0.0, 0.0, 0.0])),
    ("能量均匀分散",       np.array([1.25, 1.25, 1.25, 1.25])),
]
for name, v in vecs:
    print(f"  {name:20s} {v}  L1={np.abs(v).sum():5.2f}  L2={np.linalg.norm(v):5.2f}")

print()
print("  → 两个向量 L1 相同（都是 5），但 L2 不同（5.00 vs 2.50）")
print("  → L2 惩罚「大分量」更狠，倾向把权重摊平；L1 对稀疏更友好")

print()
print("=" * 56)
print("验证 6：特征向量——方向不变，只被缩放")
print("=" * 56)

A = np.array([[3.0, 1.0],
              [0.0, 2.0]])
eigvals, eigvecs = np.linalg.eig(A)

print(f"  矩阵 A =\n{A}")
print(f"  特征值 = {eigvals}")
print()
for i in range(len(eigvals)):
    v = eigvecs[:, i]
    Av = A @ v
    lam = eigvals[i]
    print(f"  特征向量 v{i+1} = {np.round(v, 4)}")
    print(f"    A @ v  = {np.round(Av, 4)}")
    print(f"    λ * v  = {np.round(lam * v, 4)}    （λ={lam:.2f}）")
    print(f"    → 相等: {np.allclose(Av, lam * v)}  说明方向没变，只缩放了 {lam:.2f} 倍")
    print()

# 对照：普通向量方向会变
ordinary = np.array([1.0, 1.0])
print(f"  对照，普通向量 {ordinary}:")
print(f"    A @ v = {A @ ordinary}  ← 方向变了，不是原向量的倍数")

print()
print("=" * 56)
print("验证 7：PCA 里特征值 = 该方向的方差")
print("=" * 56)

# 造一批在某个方向上明显更分散的数据
rng2 = np.random.default_rng(7)
n = 500
base = rng2.normal(0, 1, n)
data = np.column_stack([
    base * 3.0 + rng2.normal(0, 0.3, n),   # 这个方向方差大
    base * 0.5 + rng2.normal(0, 0.3, n),   # 这个方向方差小
])
data = data - data.mean(axis=0)            # 中心化（PCA 必须做）

cov = np.cov(data.T)
vals, vecs = np.linalg.eigh(cov)
order = np.argsort(vals)[::-1]             # 从大到小
vals, vecs = vals[order], vecs[:, order]

print(f"  协方差矩阵特征值（已降序）= {np.round(vals, 3)}")
print(f"  占比 = {np.round(vals / vals.sum() * 100, 1)} %")
print()
print(f"  第一主成分方向 = {np.round(vecs[:, 0], 3)}")
print(f"  → 只保留第一个主成分，就留住了 {vals[0]/vals.sum()*100:.1f}% 的方差")
print("  → 这就是降维：丢掉特征值小的方向，损失很小")

print()
print("=" * 56)
print("验证 8：广播机制的坑")
print("=" * 56)

A2 = np.ones((3, 4))
print(f"  A 形状 {A2.shape}")
for b_shape in [(4,), (3,), (3, 1)]:
    b = np.arange(1, np.prod(b_shape) + 1).reshape(b_shape).astype(float)
    try:
        r = (A2 + b).shape
        print(f"  A + b{b_shape}  → {r}  ✅")
    except ValueError:
        print(f"  A + b{b_shape}  → 报错 ❌  （想按行加，要写成 (3,1) 不是 (3,)）")
```

```
 [-0.85421161 -1.15185061  1.7012811 ]]
  → 完全一致: True
  → 一次矩阵乘法 = 所有「查询×键」的点积。这就是注意力的第一步

========================================================
验证 5：L1 与 L2 范数的差异
========================================================
  能量集中在一个分量            [5. 0. 0. 0.]  L1= 5.00  L2= 5.00
  能量均匀分散               [1.25 1.25 1.25 1.25]  L1= 5.00  L2= 2.50

  → 两个向量 L1 相同（都是 5），但 L2 不同（5.00 vs 2.50）
  → L2 惩罚「大分量」更狠，倾向把权重摊平；L1 对稀疏更友好

========================================================
验证 6：特征向量——方向不变，只被缩放
========================================================
  矩阵 A =
[[3. 1.]
 [0. 2.]]
  特征值 = [3. 2.]

  特征向量 v1 = [1. 0.]
    A @ v  = [3. 0.]
    λ * v  = [3. 0.]    （λ=3.00）
    → 相等: True  说明方向没变，只缩放了 3.00 倍

  特征向量 v2 = [-0.7071  0.7071]
    A @ v  = [-1.4142  1.4142]
    λ * v  = [-1.4142  1.4142]    （λ=2.00）
    → 相等: True  说明方向没变，只缩放了 2.00 倍

  对照，普通向量 [1. 1.]:
    A @ v = [4. 2.]  ← 方向变了，不是原向量的倍数

========================================================
验证 7：PCA 里特征值 = 该方向的方差
========================================================
  协方差矩阵特征值（已降序）= [8.215 0.101]
  占比 = [98.8  1.2] %

  第一主成分方向 = [-0.987 -0.162]
  → 只保留第一个主成分，就留住了 98.8% 的方差
  → 这就是降维：丢掉特征值小的方向，损失很小

========================================================
验证 8：广播机制的坑
========================================================
  A 形状 (3, 4)
  A + b(4,)  → (3, 4)  ✅
  A + b(3,)  → 报错 ❌  （想按行加，要写成 (3,1) 不是 (3,)）
  A + b(3, 1)  → (3, 4)  ✅
```

## 9. 小结

| 概念 | 一句话 | 在 AI 里的位置 |
| --- | --- | --- |
| 向量 | 一组数，也是一个方向 | embedding、样本特征 |
| **点积** | **测两个向量方向有多接近** | **注意力机制的核心** |
| 余弦相似度 | 点积除掉长度影响 | 向量检索、RAG |
| 矩阵乘法 | 批量点积 / 空间变换 | 神经网络每一层 |
| 形状规则 | 内侧对齐，外侧留下 | 调试形状 bug 的抓手 |
| 转置 | 行列互换 | 让形状对上（如 `Q @ Kᵀ`） |
| L1 / L2 范数 | 两种「长度」定义 | 对应两种正则化 |
| 特征值/特征向量 | 变换后方向不变，只缩放 | PCA 降维的原理 |
| 广播 | numpy 自动扩展形状 | 读代码必知 |

**如果只记两件事**：点积测方向相似度（所以注意力用它）；矩阵乘法内侧维度必须相等（所以到处是转置）。
