## 0. 这篇的定位

**这不是信息论教材。** 不讲编码定理、不推信道容量。

目标：让你看懂 AI 里三个高频概念——**熵、交叉熵、KL 散度**，以及从它们衍生的**困惑度**。

**为什么这篇很重要**：这三个概念是下面这些东西的公共语言，绕不过去：

| 你会在哪碰到 | 用到哪个概念 |
| --- | --- |
| 分类损失函数 | 交叉熵 |
| 语言模型评估指标 | 困惑度（交叉熵的指数） |
| RLHF 的惩罚项 | KL 散度 |
| DPO 的推导 | KL 散度 |
| 知识蒸馏的损失 | KL 散度 + 温度 |
| 对比学习 InfoNCE | 互信息 |

符号速查：

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| `H(P)` | 熵 | 分布 P 的不确定性 |
| `H(P, Q)` | 交叉熵 | 用 Q 去描述 P 的代价 |
| `D_KL(P‖Q)` 或 `KL(P‖Q)` | KL 散度 | P 和 Q 差多少 |
| `log` | | AI 里默认自然对数（以 e 为底） |
| `‖` | | 分隔符，不是范数 |

## 1. 信息量：越意外，信息越多

先建立一个直觉：

> **一件事越出乎意料，它携带的信息就越多。**

```
"明天太阳从东边升起"     →  概率 ≈ 1     →  信息量 ≈ 0（废话）
"明天下雨"               →  概率 = 0.3   →  有一些信息
"明天下雪"（在广州）      →  概率 = 0.001 →  信息量巨大
```

数学上，概率为 `p` 的事件，信息量定义为：

```
I = -log p
```

为什么这么定义（三条都符合直觉）：

| 性质 | 验证 |
| --- | --- |
| 概率越小，信息越大 | `p=1` 时 `I=0`；`p→0` 时 `I→∞` |
| 信息量非负 | `p ≤ 1` 所以 `log p ≤ 0`，加负号变正 |
| 独立事件信息可加 | `-log(p₁p₂) = -log p₁ - log p₂` |

第三条是取对数的关键理由：**概率相乘，信息相加**。这和 [概率统计够用篇](03-概率统计够用篇.md) 里「连乘取对数变连加」是同一个技巧。

## 2. 熵：平均信息量 = 不确定性

熵是「信息量的期望」——所有可能结果的信息量，按概率加权平均：

```
H(P) = -Σ P(x) · log P(x)
        ↑         ↑
      每种结果   它的信息量
      的概率
```

### 直觉：熵在测「有多难猜」

```
硬币 A（公平）              硬币 B（作弊，99% 正面）
  正 50%  反 50%              正 99%   反 1%
      ▮▮▮ ▮▮▮                    ▮▮▮▮▮▮  ▯
                                
  完全猜不准                   几乎肯定是正面
  熵 = 最大                    熵 ≈ 0
```

**关键结论**：

| 分布 | 熵 |
| --- | --- |
| 均匀分布（各选项等可能） | **最大**（最难猜） |
| 一头独大（某个选项概率 1） | **0**（完全确定） |

这解释了为什么正态分布常被称为「最大熵分布」——在只知道均值和方差的约束下，正态是「最不额外假设」的选择。

## 3. 交叉熵：用错误的分布去描述真实分布，要多付多少

这是分类损失的直接来源。

```
H(P, Q) = -Σ P(x) · log Q(x)
           ↑            ↑
        真实分布     模型预测的分布
```

### 直觉：一个编码类比

假设你要给一堆消息编码：

```
真实情况 P：  A 出现 90%，B 出现 10%
                    
方案一（按真实分布 P 编码）：给 A 短码，给 B 长码  →  平均长度短  = H(P)
方案二（按错误分布 Q 编码）：以为 B 常见，给 B 短码  →  平均长度长  = H(P,Q)
                                                              ↑
                                                    多付的代价就是 KL 散度
```

**所以交叉熵 = 真实分布的固有不确定性 + 因为模型不准而多付的代价**：

```
H(P, Q) = H(P) + D_KL(P ‖ Q)
   ↑        ↑          ↑
交叉熵   固有熵    模型不准的额外代价
        （常数）    （这才是我们能优化的）
```

**这个式子很重要**：因为 `H(P)` 是数据自带的常数，**最小化交叉熵 ≡ 最小化 KL 散度**。

### 分类任务里的简化

分类任务里真实标签是 one-hot（正确类别概率 1，其他 0），代入交叉熵：

```
H(P, Q) = -[0·log q₁ + ... + 1·log q_正确 + ... + 0·log qₙ]
        = -log q_正确
```

**所有项都消掉了，只剩正确类别的那一项。** 这就是为什么代码里交叉熵损失往往只有一行 `-log(p_correct)`。

和 [概率统计够用篇](03-概率统计够用篇.md) 第 5 节的最大似然推导对照——两条完全不同的路（信息论 vs 统计），得到同一个损失函数。这不是巧合，是同一个数学结构的两种解释。

## 4. KL 散度：两个分布差多少

```
D_KL(P ‖ Q) = Σ P(x) · log [ P(x) / Q(x) ]
```

### 三个必须知道的性质

| 性质 | 说明 | 实践含义 |
| --- | --- | --- |
| **非负** | `D_KL ≥ 0`，等于 0 只当 P=Q | 可以当「距离」用 |
| **不对称** | `D_KL(P‖Q) ≠ D_KL(Q‖P)` | **不是真正的距离！顺序写反意义就变了** |
| 分母为 0 会爆 | `Q(x)=0` 而 `P(x)>0` 时趋于无穷 | 工程上要加平滑或 clip |

第二条最容易踩坑。两个方向的含义完全不同：

```
D_KL(P ‖ Q)  「前向 KL」：P 有的地方 Q 必须也有
              → 逼迫 Q 覆盖 P 的所有模式（Q 会变宽、变模糊）

D_KL(Q ‖ P)  「反向 KL」：Q 有的地方 P 必须也有
              → 逼迫 Q 聚焦在 P 的高概率区（Q 会变窄、更尖锐）
```

生成模型里选哪个方向，直接决定输出是「多样但平庸」还是「精准但单调」。

### KL 散度在 AI 里的三个高频场景

**场景一：RLHF 的 KL 惩罚**

```
优化目标 = 最大化奖励 - β · D_KL(新策略 ‖ 原始SFT模型)
                              ↑
                    这一项在拽住模型别跑偏
```

不加会出什么问题：模型会找到「奖励模型的漏洞」——输出一些奖励模型给高分但人类看着荒谬的内容（reward hacking），同时把语言能力搞坏。KL 项相当于一根皮筋，允许模型改进但不允许它离原始模型太远。详见 [RLHF 全链路](../../02-llm/04-微调与对齐/03-RLHF全链路.md)。

**场景二：DPO 的推导**

DPO 之所以能绕开显式奖励模型，关键一步就是利用「带 KL 约束的最优策略有闭式解」这个数学事实。详见 [DPO 与免 RL 对齐](../../02-llm/04-微调与对齐/04-DPO与免RL对齐.md)。

**场景三：知识蒸馏**

```
蒸馏损失 = KL( 学生分布 ‖ 教师分布 )   ← 让学生的整个分布逼近教师
```

对比硬标签训练（只告诉学生「正确答案是猫」）：

```
硬标签: [0, 1, 0, 0]              ← 只说「是猫」
软标签: [0.05, 0.7, 0.22, 0.03]   ← 说「是猫，但有点像狗，绝不是汽车」
                    ↑
            这个「像狗」的信息，硬标签里完全没有
```

**软标签多出来的信息就是「类别之间的相似结构」**，这是蒸馏能让小模型学到大模型「判断力」的原因。详见 [蒸馏与剪枝](../../02-llm/05-推理优化/03-蒸馏与剪枝.md)。

## 5. 困惑度：语言模型的标准评估指标

> ⚠️ 这个概念在本库其他笔记里被反复用到但一直没有解释，本节补上。

### 定义

```
Perplexity = exp( 交叉熵 )     （交叉熵用自然对数时）
```

就这么简单——**困惑度就是交叉熵取指数**。

### 为什么要多这一步

因为交叉熵的数值不直观（0.8？2.5？好还是坏？），而困惑度有一个非常具体的解释：

> **困惑度 = 模型在每一步预测时，「等效于在多少个选项里瞎猜」。**

```
困惑度 = 1      →  每次都能确定预测出下一个词（完美，实际不可能）
困惑度 = 10     →  相当于每次在 10 个词里犹豫
困惑度 = 100    →  相当于每次在 100 个词里犹豫
困惑度 = 词表大小 →  完全没学到东西（等于随机猜）
```

所以**困惑度越低越好**，而且它有明确的上界参考：如果词表 5 万，困惑度接近 5 万说明模型什么也没学到。

### 一个直觉验证

假设模型对每个位置都是「均匀地在 k 个词里猜」：

```
每步概率 = 1/k
交叉熵 = -log(1/k) = log k
困惑度 = exp(log k) = k        ← 正好等于「候选个数」
```

这就是「等效候选数」这个解释的来源。

### 实践注意

| 注意点 | 说明 |
| --- | --- |
| 不能跨 tokenizer 比较 | 分词方式不同，每个 token 承载的信息量不同，困惑度不可比 |
| 不能跨数据集比较 | 在简单文本上困惑度天然更低 |
| 低困惑度 ≠ 好用 | 困惑度只衡量「预测下一个词的准度」，不衡量有用性、安全性、指令遵循 |

最后一条很关键：**这也是为什么现代模型评估不只看困惑度，还要做人工评估和任务基准**。详见 [模型评估与度量选择](../01-机器学习基础/02-模型评估与度量选择.md)。

## 6. 互信息：两个变量共享多少信息

```
I(X; Y) = H(X) - H(X|Y)
           ↑        ↑
        X 的不确定性  知道 Y 后 X 还剩多少不确定性
```

**直觉**：知道 Y 之后，对 X 的不确定性减少了多少。

| 情况 | 互信息 |
| --- | --- |
| X 和 Y 完全独立 | 0（知道 Y 对猜 X 毫无帮助） |
| Y 完全决定 X | `= H(X)`（知道 Y 就完全知道 X） |

**在 AI 里的位置**：对比学习的 InfoNCE 损失，本质是在最大化「正样本对之间的互信息」——让配对的图文向量互相包含更多对方的信息。详见 [CLIP 与对比学习](../../02-llm/06-多模态/01-CLIP与对比学习.md)。

## 7. 最小可运行验证

```python
import numpy as np

EPS = 1e-12   # 防 log(0)


def entropy(p):
    """熵：-Σ p log p"""
    p = np.asarray(p, dtype=float)
    return -np.sum(p * np.log(p + EPS))


def cross_entropy(p, q):
    """交叉熵：-Σ p log q"""
    p, q = np.asarray(p, float), np.asarray(q, float)
    return -np.sum(p * np.log(q + EPS))


def kl_div(p, q):
    """KL 散度：Σ p log(p/q)"""
    p, q = np.asarray(p, float), np.asarray(q, float)
    return np.sum(p * np.log((p + EPS) / (q + EPS)))


print("=" * 60)
print("验证 1：熵——均匀分布熵最大，一头独大熵最小")
print("=" * 60)

dists = [
    ("公平硬币      ", [0.5, 0.5]),
    ("作弊硬币 90/10", [0.9, 0.1]),
    ("作弊硬币 99/1 ", [0.99, 0.01]),
    ("几乎确定      ", [0.9999, 0.0001]),
    ("均匀四选一    ", [0.25] * 4),
    ("四选一但一头大", [0.97, 0.01, 0.01, 0.01]),
]
for name, p in dists:
    print(f"  {name}  {str(np.round(p,4)):28s}  熵 = {entropy(p):.4f}")

print()
print(f"  二分类熵的理论最大值 = log(2) = {np.log(2):.4f}  ← 公平硬币正好达到")
print(f"  四分类熵的理论最大值 = log(4) = {np.log(4):.4f}  ← 均匀四选一正好达到")
print("  → 越均匀越难猜，熵越大；越一头独大，熵越接近 0")

print()
print("=" * 60)
print("验证 2：交叉熵 = 熵 + KL 散度")
print("=" * 60)

P = np.array([0.7, 0.2, 0.1])          # 真实分布
Qs = [
    ("模型很准",   np.array([0.68, 0.22, 0.10])),
    ("模型一般",   np.array([0.50, 0.30, 0.20])),
    ("模型很差",   np.array([0.10, 0.20, 0.70])),
]
print(f"  真实分布 P = {P}   固有熵 H(P) = {entropy(P):.6f}")
print()
for name, Q in Qs:
    ce, h, kl = cross_entropy(P, Q), entropy(P), kl_div(P, Q)
    print(f"  {name}  Q = {Q}")
    print(f"    交叉熵 H(P,Q) = {ce:.6f}")
    print(f"    H(P) + KL     = {h:.6f} + {kl:.6f} = {h + kl:.6f}")
    print(f"    → 相等: {np.isclose(ce, h + kl)}")
    print()

print("  → H(P) 是常数，所以「最小化交叉熵」等价于「最小化 KL 散度」")

print()
print("=" * 60)
print("验证 3：分类任务里交叉熵简化成 -log(正确类别概率)")
print("=" * 60)

true_label = 1
onehot = np.array([0.0, 1.0, 0.0])
pred = np.array([0.15, 0.75, 0.10])

full = cross_entropy(onehot, pred)
simple = -np.log(pred[true_label])

print(f"  one-hot 真实标签 = {onehot}")
print(f"  模型预测         = {pred}")
print()
print(f"  完整交叉熵公式算 = {full:.6f}")
print(f"  只算 -log(p正确) = {simple:.6f}")
print(f"  → 相等: {np.isclose(full, simple)}")
print("  → one-hot 让其他项都乘 0 消掉了，这就是代码里只写一行的原因")

print()
print("=" * 60)
print("验证 4：KL 散度不对称——顺序写反含义就变了")
print("=" * 60)

A = np.array([0.9, 0.05, 0.05])
B = np.array([0.34, 0.33, 0.33])

print(f"  A（尖锐）= {A}")
print(f"  B（平坦）= {B}")
print()
print(f"  KL(A‖B) = {kl_div(A, B):.6f}")
print(f"  KL(B‖A) = {kl_div(B, A):.6f}")
print(f"  → 两者不等，差 {abs(kl_div(A,B) - kl_div(B,A)):.6f}")
print()
print("  所以 KL 不是「距离」，写公式时顺序必须对——RLHF 里写成")
print("  KL(新策略‖参考模型) 而不是反过来，是有明确含义的")

print()
print("  KL 恒非负，只在两分布相同时为 0:")
for name, q in [("完全相同", A), ("略有不同", np.array([0.85, 0.08, 0.07]))]:
    print(f"    KL(A‖{name}) = {kl_div(A, q):.8f}")

print()
print("=" * 60)
print("验证 5：困惑度 = exp(交叉熵)，含义是「等效候选数」")
print("=" * 60)

print("  情形一：模型均匀地在 k 个词里猜")
for k in [2, 10, 100, 1000, 50000]:
    ce = -np.log(1.0 / k)
    ppl = np.exp(ce)
    print(f"    在 {k:6d} 个词里均匀猜  交叉熵 = {ce:8.4f}  困惑度 = {ppl:11.2f}")
print()
print("  → 困惑度精确等于候选个数，这就是「等效在多少个选项里瞎猜」的来源")

print()
print("  情形二：一段真实序列的困惑度计算")
# 模拟模型对 8 个位置的预测：给正确 token 的概率
p_correct_seq = np.array([0.42, 0.18, 0.65, 0.07, 0.33, 0.51, 0.12, 0.28])
ce_seq = -np.mean(np.log(p_correct_seq))
ppl_seq = np.exp(ce_seq)
print(f"    各位置正确 token 概率 = {p_correct_seq}")
print(f"    平均交叉熵 = {ce_seq:.4f}")
print(f"    困惑度     = {ppl_seq:.4f}")
print(f"    → 解读：模型平均相当于在约 {ppl_seq:.1f} 个候选里犹豫")

print()
print("  情形三：模型变好，困惑度怎么变")
for label, arr in [
    ("很差", np.full(8, 0.05)),
    ("一般", np.full(8, 0.20)),
    ("较好", np.full(8, 0.50)),
    ("很好", np.full(8, 0.90)),
]:
    ce_x = -np.mean(np.log(arr))
    print(f"    {label}（每步正确概率 {arr[0]:.2f}）  交叉熵={ce_x:.4f}  困惑度={np.exp(ce_x):8.3f}")
print("  → 困惑度越低越好；接近词表大小说明什么都没学到")

print()
print("=" * 60)
print("验证 6：软标签比硬标签信息量大（知识蒸馏的根据）")
print("=" * 60)

hard = np.array([0.0, 1.0, 0.0, 0.0])                  # 只说「是第2类」
soft = np.array([0.05, 0.70, 0.22, 0.03])              # 还透露了类间相似结构

print(f"  硬标签 = {hard}   熵 = {entropy(hard):.6f}")
print(f"  软标签 = {soft}   熵 = {entropy(soft):.6f}")
print()
print("  硬标签熵为 0 —— 它只断言一个事实，不含任何「类间关系」信息")
print("  软标签熵 > 0 —— 多出来的信息是：第3类(0.22)比第4类(0.03)更像正确答案")
print()
print("  蒸馏温度 T 的作用（T 越大分布越平缓，暴露更多类间结构）:")
logits = np.array([1.0, 4.0, 2.8, 0.5])
for T in [1.0, 2.0, 5.0, 10.0]:
    z = logits / T
    z = z - z.max()
    q = np.exp(z) / np.exp(z).sum()
    print(f"    T={T:5.1f}  分布={np.round(q,4)}  熵={entropy(q):.4f}")
print("  → 提高温度后熵变大，类间相似信息被放大，学生能学到更多")

print()
print("=" * 60)
print("验证 7：互信息——知道 Y 后 X 的不确定性减少了多少")
print("=" * 60)

# 联合分布 P(X,Y)，X、Y 各 2 取值
joints = [
    ("完全独立", np.array([[0.25, 0.25], [0.25, 0.25]])),
    ("强相关  ", np.array([[0.45, 0.05], [0.05, 0.45]])),
    ("完全决定", np.array([[0.50, 0.00], [0.00, 0.50]])),
]
for name, J in joints:
    px = J.sum(axis=1)
    py = J.sum(axis=0)
    # I(X;Y) = Σ p(x,y) log[ p(x,y) / (p(x)p(y)) ]
    mi = 0.0
    for i in range(2):
        for j in range(2):
            if J[i, j] > 0:
                mi += J[i, j] * np.log(J[i, j] / (px[i] * py[j]))
    print(f"  {name}  H(X)={entropy(px):.4f}  互信息 I(X;Y)={mi:.4f}")

print()
print("  → 独立时互信息为 0；完全决定时互信息 = H(X)")
print("  → 对比学习(InfoNCE)就是在最大化配对样本间的互信息")
```

## 8. 小结

| 概念 | 一句话 | 在 AI 里的位置 |
| --- | --- | --- |
| 信息量 `-log p` | 越意外信息越多 | 一切的起点 |
| 熵 `H(P)` | 平均信息量 = 有多难猜 | 均匀分布熵最大 |
| **交叉熵 `H(P,Q)`** | **用 Q 描述 P 的总代价** | **分类损失函数** |
| 关键分解 | `H(P,Q) = H(P) + KL(P‖Q)` | 所以最小化交叉熵 ≡ 最小化 KL |
| **KL 散度** | 两个分布差多少，**不对称** | **RLHF 惩罚项、DPO 推导、蒸馏损失** |
| **困惑度** | `exp(交叉熵)`，等效候选数 | **语言模型标准评估指标，越低越好** |
| 互信息 | 知道 Y 后 X 少了多少不确定性 | 对比学习 InfoNCE |

**如果只记三件事**：
1. 交叉熵损失和 KL 散度只差一个常数，优化它们等价
2. KL 散度**不对称**，`KL(P‖Q) ≠ KL(Q‖P)`，写公式时顺序有明确含义
3. 困惑度就是交叉熵取指数，读作「等效在多少个选项里瞎猜」
