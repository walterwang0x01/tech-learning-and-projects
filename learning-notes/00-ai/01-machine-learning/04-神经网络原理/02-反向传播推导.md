# 反向传播推导

> Author: Walter Wang

> **读完你能回答的 3 个问题**
>
> 1. 为什么训练神经网络不能直接用"逐个参数试一遍"的方式求梯度？反向传播省掉了什么？
> 2. 链式法则在计算图上是怎么变成"从后往前逐层传递误差"的？
> 3. 为什么深层网络会梯度消失/爆炸，这个现象在反向传播公式的哪一项里体现？

## 1. 问题：梯度从哪来

训练神经网络的目标是最小化损失函数 `L`。用梯度下降更新参数：

```
w ← w - η · ∂L/∂w
```

那么核心问题就是：**如何算出 `∂L/∂w`（损失对每个参数的偏导）**。

### 朴素做法为什么不可行

最直觉的方法是数值微分——把某个参数 `w` 加一个极小量 `ε`，看损失变化多少：

```
∂L/∂w ≈ [L(w + ε) - L(w)] / ε
```

问题在成本。假设网络有 `N` 个参数：

- 每算一个参数的偏导，需要做 1 次完整的前向传播
- 算完所有参数，需要 `N` 次前向传播

一个 1 亿参数的模型，单步更新就要 1 亿次前向传播。完全不可行。

**反向传播的价值**：只需 **1 次前向 + 1 次反向**，就能一次性拿到全部 `N` 个参数的梯度。成本从 `O(N)` 次前向降到 `O(1)` 次前向的量级。

这是深度学习能落地的根本前提之一。

## 2. 计算图视角

反向传播的本质就是**链式法则在计算图上的系统化应用**。

先看一个最小例子。设：

```
z = w · x + b        (线性变换)
a = σ(z)             (激活)
L = (a - y)²         (损失)
```

画成计算图：

```
        w ──┐
            ├──► z ──► a ──► L
        x ──┤        ▲
            │        │
        b ──┘        y
```

要求 `∂L/∂w`，直接求很麻烦，但用链式法则可以拆成局部导数的乘积：

```
∂L     ∂L     ∂a     ∂z
──── = ──── · ──── · ────
∂w     ∂a     ∂z     ∂w
```

每一项都很容易单独算：

| 项 | 值 | 说明 |
| --- | --- | --- |
| `∂L/∂a` | `2(a - y)` | 损失对激活输出的导数 |
| `∂a/∂z` | `σ'(z)` | 激活函数的导数 |
| `∂z/∂w` | `x` | 线性层对权重的导数 |

所以：

```
∂L/∂w = 2(a - y) · σ'(z) · x
```

**关键观察**：这三项里，`a`、`z`、`x` 都是前向传播时已经算出来的中间值。所以只要前向时把它们缓存下来，反向时直接取用即可——这就是为什么训练比推理更耗显存（需要存中间激活值）。

## 3. 多层网络的一般形式

把上面推广到 `L` 层网络。记第 `l` 层：

```
z^(l) = W^(l) · a^(l-1) + b^(l)
a^(l) = σ(z^(l))
```

定义**误差项** `δ^(l) = ∂L/∂z^(l)`（损失对该层线性输出的偏导）。引入这个中间量是反向传播的核心技巧，因为它能递推。

### 输出层的 δ

对最后一层 `L`：

```
δ^(L) = ∂L/∂z^(L) = ∂L/∂a^(L) ⊙ σ'(z^(L))
```

`⊙` 表示逐元素相乘（Hadamard 积）。

### 递推公式：δ 如何往前传

这是整个推导的关键一步。第 `l` 层的误差可以由第 `l+1` 层的误差算出：

```
δ^(l) = [(W^(l+1))ᵀ · δ^(l+1)] ⊙ σ'(z^(l))
```

推导思路：`z^(l)` 通过 `a^(l)` 影响 `z^(l+1)`，再影响 `L`。所以

```
∂L/∂z^(l) = Σ_k [∂L/∂z_k^(l+1) · ∂z_k^(l+1)/∂z^(l)]
```

而 `z^(l+1) = W^(l+1) · σ(z^(l)) + b^(l+1)`，因此 `∂z_k^(l+1)/∂z^(l) = W_k^(l+1) · σ'(z^(l))`。代入即得递推式。

### 从 δ 到参数梯度

拿到每层的 `δ` 后，参数梯度就是直接的：

```
∂L/∂W^(l) = δ^(l) · (a^(l-1))ᵀ
∂L/∂b^(l) = δ^(l)
```

### 完整流程

```
前向传播：
  a^(0) = x
  for l = 1 to L:
      z^(l) = W^(l)·a^(l-1) + b^(l)     ← 缓存 z^(l)
      a^(l) = σ(z^(l))                  ← 缓存 a^(l)
  计算 L(a^(L), y)

反向传播：
  δ^(L) = ∂L/∂a^(L) ⊙ σ'(z^(L))
  for l = L down to 1:
      ∂L/∂W^(l) = δ^(l) · (a^(l-1))ᵀ
      ∂L/∂b^(l) = δ^(l)
      δ^(l-1) = [(W^(l))ᵀ·δ^(l)] ⊙ σ'(z^(l-1))
```

注意方向：前向是 `1 → L`，反向是 `L → 1`。"反向"这个名字就来自这里。

## 4. 最小可运行实现

不依赖任何框架，用 NumPy 手写一个两层网络的反向传播，并与数值微分对比验证正确性。

```python
import numpy as np


def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))


def sigmoid_grad(z):
    """sigmoid 的导数：σ'(z) = σ(z)·(1 - σ(z))"""
    s = sigmoid(z)
    return s * (1.0 - s)


class TwoLayerNet:
    """输入 → 隐藏层(sigmoid) → 输出层 → MSE 损失"""

    def __init__(self, n_in, n_hidden, n_out, seed=0):
        rng = np.random.default_rng(seed)
        # 用较小的初始值，避免 sigmoid 一开始就饱和
        self.W1 = rng.normal(0, 0.5, (n_hidden, n_in))
        self.b1 = np.zeros((n_hidden, 1))
        self.W2 = rng.normal(0, 0.5, (n_out, n_hidden))
        self.b2 = np.zeros((n_out, 1))

    def forward(self, x):
        """前向传播，同时缓存反向要用的中间值"""
        self.x = x
        self.z1 = self.W1 @ x + self.b1
        self.a1 = sigmoid(self.z1)
        self.z2 = self.W2 @ self.a1 + self.b2
        self.a2 = self.z2  # 输出层不加激活
        return self.a2

    def loss(self, y):
        """MSE 损失（对样本数取平均）"""
        m = y.shape[1]
        return np.sum((self.a2 - y) ** 2) / m

    def backward(self, y):
        """反向传播，返回各参数梯度"""
        m = y.shape[1]

        # 输出层误差：∂L/∂z2
        # L = Σ(a2-y)²/m，输出层无激活，故 ∂L/∂z2 = ∂L/∂a2 = 2(a2-y)/m
        delta2 = 2.0 * (self.a2 - y) / m

        grad_W2 = delta2 @ self.a1.T
        grad_b2 = np.sum(delta2, axis=1, keepdims=True)

        # 误差往前传一层：δ1 = (W2ᵀ·δ2) ⊙ σ'(z1)
        delta1 = (self.W2.T @ delta2) * sigmoid_grad(self.z1)

        grad_W1 = delta1 @ self.x.T
        grad_b1 = np.sum(delta1, axis=1, keepdims=True)

        return {"W1": grad_W1, "b1": grad_b1, "W2": grad_W2, "b2": grad_b2}


def numerical_grad(net, x, y, param_name, eps=1e-6):
    """数值微分：用于验证反向传播是否算对"""
    param = getattr(net, param_name)
    grad = np.zeros_like(param)

    it = np.nditer(param, flags=["multi_index"])
    while not it.finished:
        idx = it.multi_index
        original = param[idx]

        param[idx] = original + eps
        net.forward(x)
        loss_plus = net.loss(y)

        param[idx] = original - eps
        net.forward(x)
        loss_minus = net.loss(y)

        grad[idx] = (loss_plus - loss_minus) / (2 * eps)
        param[idx] = original  # 恢复
        it.iternext()

    return grad


if __name__ == "__main__":
    rng = np.random.default_rng(42)
    net = TwoLayerNet(n_in=3, n_hidden=4, n_out=2)

    # 5 个样本，注意这里用列向量布局：每列是一个样本
    x = rng.normal(0, 1, (3, 5))
    y = rng.normal(0, 1, (2, 5))

    # 反向传播算梯度
    net.forward(x)
    grads = net.backward(y)

    # 与数值微分对比，验证实现正确
    print("梯度校验（相对误差应在 1e-7 量级以下）：")
    for name in ["W1", "b1", "W2", "b2"]:
        num = numerical_grad(net, x, y, name)
        ana = grads[name]
        # 相对误差，分母加小量防止除零
        rel_err = np.max(np.abs(num - ana) / (np.abs(num) + np.abs(ana) + 1e-12))
        print(f"  {name}: 相对误差 = {rel_err:.2e}")

    # 简单训练几步，确认损失在下降
    print("\n训练 500 步：")
    lr = 0.5
    for step in range(501):
        net.forward(x)
        loss = net.loss(y)
        grads = net.backward(y)
        for name in ["W1", "b1", "W2", "b2"]:
            setattr(net, name, getattr(net, name) - lr * grads[name])
        if step % 100 == 0:
            print(f"  step {step:3d}  loss = {loss:.6f}")
```

实测输出（numpy 2.4.4）：

```
梯度校验（相对误差应在 1e-7 量级以下）：
  W1: 相对误差 = 1.73e-08
  b1: 相对误差 = 5.24e-09
  W2: 相对误差 = 1.98e-09
  b2: 相对误差 = 1.75e-10

训练 500 步：
  step   0  loss = 2.067858
  step 100  loss = 0.069035
  step 200  loss = 0.015226
  step 300  loss = 0.003872
  step 400  loss = 0.079202
  step 500  loss = 0.000836
```

梯度校验相对误差在 `1e-8` ~ `1e-10` 量级，说明反向传播实现与数值微分一致。

注意 step 400 的损失从 0.0039 反弹到 0.079——这不是 bug，而是**学习率偏大导致的震荡**：接近极小值时步长仍是 0.5，会在谷底来回跨越。这正好是学习率调度存在的理由（详见 [学习率调度与训练技巧](../05-训练工程/04-学习率调度与训练技巧.md)）。把 `lr` 降到 0.1 再跑，下降曲线会平滑很多。

**梯度校验（gradient check）是调试自定义层的标准手段**——手写反向传播时符号写错是很常见的，用数值微分对比能立刻发现。生产训练中不用它（太慢），但实现新算子时应该跑一次。

## 5. 梯度消失与爆炸：公式里的哪一项

回看递推式：

```
δ^(l) = [(W^(l+1))ᵀ · δ^(l+1)] ⊙ σ'(z^(l))
```

从第 `L` 层传到第 1 层，误差要经过 `L-1` 次这样的变换。展开看，`δ^(1)` 里包含了这样的连乘：

```
δ^(1) ~ σ'(z^(1)) · W^(2)ᵀ · σ'(z^(2)) · W^(3)ᵀ · ... · σ'(z^(L-1)) · W^(L)ᵀ · δ^(L)
```

**问题就出在这个连乘上**：

| 情况 | 后果 | 原因 |
| --- | --- | --- |
| `σ'` 普遍 < 1 且权重较小 | **梯度消失**：`δ^(1)` 趋近 0，浅层几乎不更新 | 小于 1 的数连乘指数衰减 |
| 权重较大 | **梯度爆炸**：`δ^(1)` 数值溢出，训练发散 | 大于 1 的数连乘指数增长 |

sigmoid 的导数最大值只有 0.25（在 `z=0` 处），这意味着**每往前传一层，梯度至少衰减 4 倍**。10 层网络传到第一层，梯度只剩约 `0.25^10 ≈ 1e-6`。这就是为什么早期深层网络训练不起来。

对应的缓解手段（各自详见对应笔记）：

| 手段 | 作用在连乘的哪一项 |
| --- | --- |
| ReLU 及变体 | 让 `σ'` 在正区间恒为 1，消掉衰减因子 |
| 权重初始化（Xavier/He） | 控制 `W` 的尺度，让连乘不放大也不缩小 |
| 批归一化 / 层归一化 | 约束 `z` 的分布，避免激活饱和导致 `σ'≈0` |
| 残差连接 | 给梯度开一条 `∂L/∂x = ... + 1` 的直通路径，绕过连乘 |
| 梯度裁剪 | 不解决消失，但直接截断爆炸 |

残差连接值得单独强调：`y = x + F(x)` 的反向传播里，`∂y/∂x = 1 + ∂F/∂x`，那个常数 `1` 保证了即使 `∂F/∂x` 很小，梯度也能原样传下去。这是 ResNet 能堆到上百层、以及 Transformer 能堆到几十层的直接原因。

## 6. 与自动微分的关系

现代框架（PyTorch、TensorFlow）里你不用手写反向传播，写完前向就能调 `loss.backward()`。这背后是**自动微分（Automatic Differentiation, AD）**，具体是**反向模式 AD（reverse-mode AD）**。

反向传播可以看作反向模式 AD 在神经网络这一特定计算图上的应用。框架做的事：

1. 前向执行时，动态记录每个操作构成的计算图（PyTorch 的动态图）
2. 每个算子都注册了自己的局部导数规则（`backward` 方法）
3. 调 `backward()` 时，从损失出发按拓扑逆序遍历图，逐节点应用链式法则

```python
import torch

# 对照上面手写的版本，框架版只需写前向
x = torch.randn(5, 3)
y = torch.randn(5, 2)

W1 = torch.randn(3, 4, requires_grad=True)
b1 = torch.zeros(4, requires_grad=True)
W2 = torch.randn(4, 2, requires_grad=True)
b2 = torch.zeros(2, requires_grad=True)

# 前向
a1 = torch.sigmoid(x @ W1 + b1)
pred = a1 @ W2 + b2
loss = ((pred - y) ** 2).mean()

# 反向：一行搞定，梯度自动填到各张量的 .grad 属性
loss.backward()

print("W1 梯度形状:", W1.grad.shape)  # torch.Size([3, 4])
print("b2 梯度:", b2.grad)
```

**为什么还要理解手写版本**：

- 自定义算子、自定义损失时，需要知道该怎么实现 `backward`
- 排查 `nan`/梯度爆炸时，需要知道梯度是怎么流动的、可能在哪一层断掉
- 理解显存占用：训练显存主要花在缓存中间激活值上，这直接来自反向传播需要前向的中间结果
- 理解 `torch.no_grad()`、梯度检查点（gradient checkpointing）这类优化在省什么

## 7. 小结

| 要点 | 内容 |
| --- | --- |
| 核心价值 | 1 次前向 + 1 次反向拿到全部参数梯度，替代 `N` 次前向的朴素做法 |
| 数学基础 | 链式法则在计算图上的系统化应用 |
| 关键中间量 | 误差项 `δ^(l) = ∂L/∂z^(l)`，可在层间递推 |
| 递推式 | `δ^(l) = [(W^(l+1))ᵀ·δ^(l+1)] ⊙ σ'(z^(l))` |
| 参数梯度 | `∂L/∂W^(l) = δ^(l)·(a^(l-1))ᵀ` |
| 显存代价 | 必须缓存前向中间值，这是训练比推理更吃显存的原因 |
| 梯度消失/爆炸 | 来自跨层连乘，靠 ReLU、合理初始化、归一化、残差连接缓解 |
| 调试手段 | 梯度校验（数值微分对比），实现新算子时必做 |
