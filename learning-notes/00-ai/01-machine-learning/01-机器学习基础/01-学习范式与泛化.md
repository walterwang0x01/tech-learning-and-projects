## 1. 五种学习范式：本质区别在于"监督信号从哪来"

机器学习的范式划分，核心不是任务类型，而是**训练时能拿到什么样的监督信号**：

- **监督学习（supervised）**：每个样本都有人工标注的标签 `(x, y)`，直接优化预测 `y` 的误差。分类、回归都属于此类。
- **无监督学习（unsupervised）**：没有标签，只能从数据本身的结构里挖掘信息——聚类找分组、降维找低维结构、密度估计找分布形态。
- **自监督学习（self-supervised）**：没有人工标签，但**从数据自身构造出监督信号**，比如遮住句子中的一个词让模型预测（掩码语言建模）、预测图像被旋转的角度。本质上还是监督学习的训练方式，只是标签是自动生成的，不需要人工标注。
- **半监督学习（semi-supervised）**：少量有标签数据 + 大量无标签数据混合训练，用无标签数据的分布结构（如"相近的点应该同类"）辅助有标签数据训练出更好的决策边界。
- **强化学习（reinforcement learning）**：没有逐样本的标签，只有智能体（agent）与环境交互后延迟返回的**奖励信号（reward）**，需要通过试错学习一个策略（policy），最大化长期累积奖励。与前四种的关键区别是：数据不是静态给定的，而是由智能体自己的动作决定下一步能观察到什么。

这五种范式不是互斥的工程选择，而是**监督信息稀缺程度递增**的一条谱线：监督学习信息最充分，强化学习信息最稀疏、最延迟。

## 2. 经验风险最小化与结构风险最小化

模型训练的目标本质是最小化**期望风险（expected risk）**——模型在真实数据分布 `P(x,y)` 上的期望损失：

```
R(f) = E_{(x,y)~P} [L(f(x), y)]
```

但 `P(x,y)` 未知，只能用训练集近似，这就是**经验风险最小化（Empirical Risk Minimization, ERM）**：

```
R_emp(f) = (1/n) · Σ_{i=1}^{n} L(f(x_i), y_i)
```

问题是：如果模型足够复杂（比如深度很大的决策树、参数很多的神经网络），`R_emp(f)` 可以被压到接近 0，但这不代表 `R(f)` 也小——模型可能只是"记住"了训练集里的噪声，而不是学到了真实规律，这就是过拟合。

**结构风险最小化（Structural Risk Minimization, SRM）** 在经验风险上加一个衡量模型复杂度的惩罚项：

```
R_srm(f) = R_emp(f) + λ · Ω(f)

Ω(f): 模型复杂度（如参数的 L2 范数、树的深度）
λ: 权衡经验风险与复杂度的系数
```

L2 正则（岭回归）、L1 正则（Lasso）、决策树的剪枝、神经网络的 dropout，本质上都是结构风险最小化的具体实现——用不同方式给"复杂度"定义并施加惩罚。

## 3. 泛化误差的来源：偏差、方差与不可约误差

模型在**未见过的数据**上的误差叫泛化误差（generalization error），它不等于训练误差，两者之间的差距（generalization gap）来自三个来源：

- **偏差（bias）**：模型假设空间本身的表达能力不足，无法拟合真实规律（比如用线性模型拟合明显非线性的数据），欠拟合的根源。
- **方差（variance）**：模型对训练集的随机波动过于敏感，换一批训练数据学出的模型差异很大，过拟合的根源。
- **不可约误差（irreducible error）**：数据本身的噪声，任何模型都无法消除。

三者的定量关系见偏差-方差分解（详见延伸阅读）。泛化误差差距的直接来源可以概括为：**训练集是真实分布的有限采样，模型在有限采样上表现好，不代表在采样之外表现同样好**——采样越小、模型越复杂，这个差距就越容易被放大。

## 4. No Free Lunch 定理：没有万能算法

No Free Lunch（NFL）定理的直观表述是：**如果不对问题的结构做任何假设，那么在"所有可能的问题"这个集合上平均，任何两个算法的期望性能是一样的**——包括一个"聪明"的算法和一个随机猜测的算法。

这不是说"所有算法在实践中一样好"，而是在提醒一个更重要的事实：**一个算法在某类问题上表现好，一定是因为它对这类问题的结构做了某种假设（归纳偏置），并且这个假设恰好和真实规律相符**。脱离具体问题谈"哪个算法最好"没有意义，算法选择的本质是"你对问题结构的先验假设，和候选算法内置的假设是否匹配"。这也是为什么调参、模型选择必须结合具体任务和数据做实验，不存在一个不需要验证就能确定最优的算法。

## 5. 归纳偏置：模型"天生"的假设

**归纳偏置（inductive bias）** 指学习算法在没见到数据之前，就已经内置的对"什么样的规律更可能是对的"的假设。例子：

- 线性回归的归纳偏置是"输出是输入的线性组合"。
- 决策树的归纳偏置是"决策边界可以用若干个轴对齐的矩形区域近似"。
- CNN 的归纳偏置是"局部像素的组合模式很重要，且这种模式在图像不同位置应该共享（平移不变性）"。
- KNN 的归纳偏置是"相近的点应该有相近的标签"。

归纳偏置不是缺陷，而是必需品——根据 NFL 定理，没有归纳偏置的算法在具体问题上不会比随机猜测更好。归纳偏置与数据的匹配程度，直接决定了模型在有限数据下的泛化能力：偏置匹配真实规律时，模型能用更少的数据学到更好的效果；偏置不匹配时，无论用多少数据都会有系统性偏差。

## 6. 数据泄露：泛化能力评估中最隐蔽的陷阱

数据泄露（data leakage）指**验证/测试阶段能接触到本应只在训练阶段才知道的信息**，导致评估出的性能虚高，模型上线后实际表现远不如评估结果。典型场景：

- **先做特征工程再切分数据**：比如用全量数据计算均值/标准差做标准化，再切分训练/测试集——测试集的统计信息已经"泄露"进了训练过程用到的标准化参数里。正确做法是先切分，只用训练集的统计量去处理测试集。
- **时间序列"用未来预测过去"**：用普通 K 折交叉验证处理时间序列数据时，训练集可能包含验证点"未来"的样本，模型间接看到了不该看到的信息，验证误差被系统性低估。
- **样本重复/强相关**：同一个体产生的多条样本（比如同一用户的多次点击）被随机分到训练集和测试集，模型学到的是"记住这个用户"而不是泛化规律。
- **目标泄露（target leakage）**：某个特征本身是根据标签计算出来的（或与标签高度共线），训练时看起来效果拔群，上线后这个特征根本拿不到。

## 7. 交叉验证变体：按数据结构选择切分方式

- **K 折交叉验证（K-Fold）**：把数据随机切成 K 份，轮流用 K-1 份训练、1 份验证，取平均。假设是**样本之间独立同分布**。
- **分层 K 折（Stratified K-Fold）**：在切分时保证每一折的类别比例与整体一致，用于类别不平衡的分类任务，避免某一折里某个类别样本过少导致评估不稳定。
- **时间序列交叉验证（Time Series Split）**：始终用时间上更早的数据做训练、更晚的数据做验证，切分点随时间前移，绝不让训练集看到验证集"未来"的样本。**只要数据存在时间顺序依赖，就必须用这种切分方式**，否则会犯上一节说的数据泄露错误。

## 8. 最小可运行实现：验证结构风险最小化与时间序列数据泄露

```python
"""
两个实验：
  1. 岭回归（结构风险最小化）在特征数接近样本数时，对比强正则和弱正则下
     训练误差与验证误差的差距，观察正则化如何缩小泛化误差差距。
  2. 构造一个有自相关的时间序列，对比"普通 K 折（打乱顺序）"和
     "按时间顺序切分"两种交叉验证方式给出的验证误差，说明数据泄露的影响。
"""
import numpy as np

rng = np.random.default_rng(0)


def ridge_fit(X, y, lam=1.0):
    """岭回归闭式解：min ||Xw - y||^2 + lam * ||w||^2"""
    n_features = X.shape[1]
    A = X.T @ X + lam * np.eye(n_features)
    return np.linalg.solve(A, X.T @ y)


def mse(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)


# ---------- 实验 1：K 折交叉验证下，正则化强度对训练/验证误差差距的影响 ----------
n_samples, n_features = 40, 30
X = rng.normal(size=(n_samples, n_features))
true_w = rng.normal(size=n_features) * 0.1
y = X @ true_w + rng.normal(scale=0.5, size=n_samples)

k = 5
indices = np.arange(n_samples)
rng.shuffle(indices)
folds = np.array_split(indices, k)


def cross_val(lam):
    train_errs, val_errs = [], []
    for i in range(k):
        val_idx = folds[i]
        train_idx = np.concatenate([folds[j] for j in range(k) if j != i])
        w = ridge_fit(X[train_idx], y[train_idx], lam=lam)
        train_errs.append(mse(y[train_idx], X[train_idx] @ w))
        val_errs.append(mse(y[val_idx], X[val_idx] @ w))
    return np.mean(train_errs), np.mean(val_errs)

for lam in [0.01, 5.0]:
    tr, va = cross_val(lam)
    print(f"lam={lam:<5}: 训练 MSE={tr:.4f}, 验证 MSE={va:.4f}, 差距={va - tr:.4f}")

# ---------- 实验 2：时间序列数据，普通 K 折 vs 时间序列切分 ----------
n_time = 60
series = np.cumsum(rng.normal(scale=1.0, size=n_time)) + 0.05 * np.arange(n_time)
X_ts = np.stack([series[i:i + 3] for i in range(n_time - 3)])  # 用连续 3 步预测下一步
y_ts = series[3:]

idx_ts = np.arange(len(y_ts))
rng.shuffle(idx_ts)
kf_folds = np.array_split(idx_ts, k)
kfold_val_errs = []
for i in range(k):
    val_idx = kf_folds[i]
    train_idx = np.concatenate([kf_folds[j] for j in range(k) if j != i])
    w = ridge_fit(X_ts[train_idx], y_ts[train_idx], lam=0.1)
    kfold_val_errs.append(mse(y_ts[val_idx], X_ts[val_idx] @ w))

ts_val_errs = []
split_points = np.linspace(len(y_ts) // 2, len(y_ts) - 5, k, dtype=int)
for sp in split_points:
    train_idx = np.arange(0, sp)
    val_idx = np.arange(sp, min(sp + 5, len(y_ts)))
    if len(val_idx) == 0:
        continue
    w = ridge_fit(X_ts[train_idx], y_ts[train_idx], lam=0.1)
    ts_val_errs.append(mse(y_ts[val_idx], X_ts[val_idx] @ w))

print(f"\n普通 K 折（打乱顺序）验证 MSE: {np.mean(kfold_val_errs):.4f}")
print(f"时间序列切分（按时间顺序）验证 MSE: {np.mean(ts_val_errs):.4f}")
```

实测输出（numpy 2.4.4）：

```
lam=0.01 : 训练 MSE=0.0275, 验证 MSE=4.3707, 差距=4.3433
lam=5.0  : 训练 MSE=0.0847, 验证 MSE=0.8083, 差距=0.7236

普通 K 折（打乱顺序）验证 MSE: 1.3612
时间序列切分（按时间顺序）验证 MSE: 1.8745
```

实验 1 印证了第 2、3 节的核心结论：`lam=0.01` 时几乎是纯经验风险最小化，训练误差压到 0.0275 却在验证集上暴涨到 4.3707，泛化误差差距高达 4.34；加大正则到 `lam=5.0` 后训练误差略微上升（0.0847），但验证误差大幅下降到 0.8083，差距缩小到 0.72——结构风险最小化用可控的训练误差上升换来了泛化误差的大幅下降。实验 2 说明对存在自相关的时间序列，普通打乱切分给出的验证误差（1.3612）明显低于按时间顺序切分给出的验证误差（1.8745）：打乱切分让训练集里混入了与验证点时间相邻、高度相关的样本，模型"偷看"到了不该看到的信息，把泛化能力估计得过于乐观。

## 9. 小结

| 概念 | 核心含义 | 应对/意义 |
| --- | --- | --- |
| ERM | 只优化训练集上的平均损失 | 模型复杂时容易过拟合 |
| SRM | 训练损失 + 复杂度惩罚 | L2/L1 正则、剪枝、dropout 的理论基础 |
| 泛化误差差距 | 训练误差与真实误差的差距 | 由偏差、方差、不可约误差共同决定 |
| No Free Lunch | 不存在通用最优算法 | 算法要匹配问题结构才有效 |
| 归纳偏置 | 模型内置的先验假设 | 偏置与数据规律匹配度决定小样本泛化能力 |
| 数据泄露 | 验证阶段接触到不该有的信息 | 评估结果虚高，需先切分再处理特征 |
