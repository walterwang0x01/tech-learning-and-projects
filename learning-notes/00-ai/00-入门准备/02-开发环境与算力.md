## 0. 这篇解决什么问题

从 0 学 AI 的第一个现实障碍，不是数学也不是算法，而是：**代码在哪跑**。

```
教程说「运行这段代码训练模型」
        ↓
你的笔记本没有 NVIDIA 显卡
        ↓
pip install torch 下了半小时还没完
        ↓
装好了，运行报错 CUDA not available
        ↓
放弃
```

这篇给出一条能走通的路径，并且**优先考虑中国大陆的网络环境**——这一点很关键，很多英文教程默认你能用 Google Colab，而实测该服务从大陆访问不通。

> ⚠️ 本篇刻意**不写具体的免费额度数字和 GPU 型号**（比如「送多少小时」「给什么卡」）——这类信息各平台调整频繁，写死了会误导。请以各平台官网当时的说明为准。

## 1. 先搞清楚：你真的需要 GPU 吗

一个能省下很多折腾的判断：**学习阶段的大部分内容不需要 GPU**。

| 你要做的事 | 需要 GPU？ | 说明 |
| --- | --- | --- |
| 读本库的原理笔记、跑里面的 numpy 代码 | **不需要** | 本库所有原理篇的代码只依赖 numpy，纯 CPU 秒级完成 |
| 学经典机器学习（决策树、SVM、聚类） | **不需要** | 这类算法在 CPU 上跑得很好 |
| 训练小型神经网络（MNIST 手写数字级别） | 不需要 | CPU 几分钟能跑完 |
| 微调小模型（几亿参数级） | **需要** | 显存是硬门槛 |
| 训练/微调大模型 | **需要，且要多卡** | 个人基本不做这件事 |
| 调用大模型 API 做应用 | **不需要** | 算力在服务商那边 |

**结论**：你可以先用现有电脑走完「数学基础 → 神经网络原理 → 训练工程 → 经典算法」这一大段（本库 30+ 篇），完全不碰 GPU。等到真要微调模型时再解决算力问题。

不要一开始就卡在环境配置上——这是最常见的放弃点。

## 2. 三条算力路径

按「上手成本」从低到高：

```
路径 A：云端 Notebook（推荐起步）
  浏览器打开就能写代码，环境预装好，有免费 GPU 额度
  ✅ 零配置  ❌ 会话有时长限制，文件要自己存

路径 B：本地环境
  自己电脑装 Python + 库
  ✅ 稳定、随时可用、数据不外传  ❌ 无 NVIDIA 显卡就没 GPU 加速

路径 C：租用 GPU
  按小时付费的云 GPU
  ✅ 想要什么卡都有  ❌ 花钱，且要会 Linux 基本操作
```

### 路径 A：云端 Notebook（起步首选）

**国内可直接访问的平台**（均实测可达）：

| 平台 | 入口 | 特点 |
| --- | --- | --- |
| 百度 AI Studio | [aistudio.baidu.com](https://aistudio.baidu.com/) | 有免费 GPU 额度，中文界面，教程多 |
| 阿里天池 | [tianchi.aliyun.com](https://tianchi.aliyun.com/) | 竞赛平台自带 Notebook |
| 魔搭 ModelScope | [modelscope.cn](https://modelscope.cn/my/mynotebook) | 阿里的模型社区，有免费实例 |
| Kaggle | [kaggle.com/code](https://www.kaggle.com/code) | 国外平台但实测可访问，数据集资源极丰富 |
| 启智 OpenI | [openi.pcl.ac.cn](https://openi.pcl.ac.cn/) | 国内开源 AI 协作平台 |

**关于 Google Colab**：英文教程里最常推荐的免费 GPU 方案，但**实测从中国大陆访问不通**（需要 Google 账号且服务本身受限）。如果你看到教程说「打开 Colab 运行」，改用上面任一平台即可，操作逻辑基本一样。

**云端 Notebook 的通用注意事项**（不分平台）：

| 坑 | 应对 |
| --- | --- |
| 会话超时后环境重置，装的包全没了 | 把 `pip install` 写在 notebook 第一格，每次重跑 |
| 文件存在临时目录，断开就丢 | 重要文件存到平台提供的持久化目录，或下载到本地 |
| 免费 GPU 有排队和时长限制 | 长任务分段跑，定期存 checkpoint |
| 忘记关闭实例，额度被空转消耗 | 用完手动停止 |

第二条尤其重要——**训练中途断开是常态，必须存 checkpoint**，否则几小时的训练白费。

### 路径 B：本地环境

**先判断你的电脑能做什么**：

| 你的设备 | 深度学习加速 | 说明 |
| --- | --- | --- |
| Windows/Linux + NVIDIA 显卡 | ✅ CUDA | 最理想，装对驱动就能用 |
| Mac（M 系列芯片） | ⚠️ 部分支持 | PyTorch 支持 MPS 后端，比 CPU 快但不如 NVIDIA，且部分算子不兼容 |
| Mac（Intel） | ❌ 只有 CPU | 学原理够用，训模型很慢 |
| Windows/Linux + AMD 显卡 | ⚠️ 麻烦 | ROCm 支持有限，不建议初学者折腾 |

**Mac 用户注意**：M 系列芯片可以用 PyTorch 的 MPS 后端获得一定加速，写法是把 `device="cuda"` 换成 `device="mps"`。但要有预期：部分算子未实现会回落到 CPU，某些库不支持。学原理完全够用，认真训模型建议用云端。

### 路径 C：租 GPU

需要正式微调模型时再考虑。国内可用的按小时租用平台，比如 [AutoDL](https://www.autodl.com/)。

**租之前先算清楚**：

```
需要的显存 ≈ 模型参数量 × 每参数字节数 × 倍数
                                      ↑
              全参微调约 16 倍；LoRA 微调约 2~4 倍（估算，看具体配置）
```

显存不够会直接 OOM 报错，这是最常见的失败原因。省显存的方法（量化、LoRA、梯度检查点）见 [PEFT 参数高效微调](../llm/04-微调与对齐/02-PEFT参数高效微调.md)、[量化](../llm/05-推理优化/02-量化.md)。

## 3. 本地环境搭建（关键：镜像源）

### 第一步：Python 版本管理

**不要直接用系统自带的 Python**，也不要把所有包装进同一个环境——不同项目依赖冲突是常态。

两个主流方案：

| 工具 | 适合 | 官方文档 |
| --- | --- | --- |
| **uv**（推荐） | 现代、极快，一个工具管 Python 版本 + 依赖 | [docs.astral.sh/uv](https://docs.astral.sh/uv/) |
| Miniconda | 传统方案，科学计算生态成熟 | [docs.conda.io](https://docs.conda.io/projects/miniconda/en/latest/) |

uv 的基本用法：

```bash
# 创建一个独立环境（在项目目录下）
uv venv

# 激活
source .venv/bin/activate      # macOS / Linux
# .venv\Scripts\activate       # Windows

# 装包
uv pip install numpy pandas
```

conda 的基本用法：

```bash
conda create -n ai python=3.11
conda activate ai
pip install numpy pandas
```

**核心原则：一个项目一个环境。** 不要嫌麻烦——依赖冲突排查起来比创建环境麻烦十倍。

### 第二步：配置国内镜像源（**这一步能省你几小时**）

默认从境外源下载，慢且容易中断。`pip install torch` 要下载好几个 GB，不配镜像基本装不上。

**实测可用的镜像源**：

```bash
# 阿里云（实测可达）
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/

# 或上海交大
pip config set global.index-url https://mirror.sjtu.edu.cn/pypi/web/simple
```

> ⚠️ 待确认：清华 TUNA 源（`pypi.tuna.tsinghua.edu.cn`）实测返回 403，可能是该端点对 curl 探测的限制而非真正不可用。实际用 `pip` 访问可能正常，建议自己试一次。

配置好后验证：

```bash
pip config list          # 应显示你设置的 index-url
pip download numpy -d /tmp/test   # 看下载速度
```

**HuggingFace 模型下载慢**的问题，有国内镜像站 [hf-mirror.com](https://hf-mirror.com/)（实测可达），用法是设置环境变量：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### 第三步：装 PyTorch

**不要直接 `pip install torch`**——要按你的硬件选对版本。去官网选择器生成命令：

[pytorch.org/get-started/locally](https://pytorch.org/get-started/locally/)

页面上选你的操作系统、包管理器、CUDA 版本，它会给出准确的安装命令。

装完后**必须验证**：

```python
import torch
print("PyTorch 版本:", torch.__version__)
print("CUDA 可用:", torch.cuda.is_available())        # NVIDIA 用户看这个
print("MPS 可用:", torch.backends.mps.is_available()) # Mac M 系列看这个
```

如果 `cuda.is_available()` 是 `False` 但你有 NVIDIA 卡，通常是三种原因：装的是 CPU 版 torch、显卡驱动太旧、CUDA 版本不匹配。

## 4. 写代码用什么工具

| 工具 | 适合场景 |
| --- | --- |
| **Jupyter Notebook** | 探索性实验、边写边看结果、教程学习 |
| VS Code / Cursor / Kiro | 写正式代码、多文件项目、有 AI 辅助 |
| PyCharm | 大型 Python 项目，重构能力强 |

**建议组合**：学习阶段用 Notebook（能一格一格看中间结果，非常适合理解代码），做项目时转到 IDE。

Notebook 有个常见坑：**格子的执行顺序不等于从上到下**。你改了上面的格子没重跑，下面用的还是旧变量，会得到莫名其妙的结果。排查方法：`Restart & Run All` 从头跑一遍。

## 5. 一个可以立刻验证环境的脚本

装完环境后跑这个，它会告诉你当前环境能做什么、不能做什么：

```python
"""环境自检脚本：确认你的环境能跑什么

只依赖标准库和 numpy，其余库缺失会优雅报告而非报错崩溃。
"""

import platform
import sys


def section(title):
    print()
    print("=" * 56)
    print(title)
    print("=" * 56)


section("1. 基础信息")
print(f"  操作系统   : {platform.system()} {platform.release()}")
print(f"  CPU 架构   : {platform.machine()}")
print(f"  Python 版本: {sys.version.split()[0]}")
print(f"  解释器路径 : {sys.executable}")

# 判断是否在虚拟环境里（很多问题源于装到了错误的环境）
in_venv = sys.prefix != sys.base_prefix
print(f"  虚拟环境   : {'✅ 是' if in_venv else '⚠️ 否（建议用虚拟环境隔离依赖）'}")

section("2. 核心库检查")

libs = [
    ("numpy",        "数值计算，本库所有原理篇代码的唯一依赖"),
    ("pandas",       "表格数据处理"),
    ("matplotlib",   "画图"),
    ("sklearn",      "经典机器学习算法"),
    ("torch",        "深度学习框架"),
    ("transformers", "预训练模型库"),
]

available = {}
for name, desc in libs:
    try:
        mod = __import__(name)
        ver = getattr(mod, "__version__", "未知版本")
        available[name] = True
        print(f"  ✅ {name:14s} {ver:12s}  {desc}")
    except ImportError:
        available[name] = False
        print(f"  ❌ {name:14s} {'未安装':12s}  {desc}")

section("3. 算力检查")

if available.get("torch"):
    import torch
    print(f"  PyTorch 版本   : {torch.__version__}")

    cuda_ok = torch.cuda.is_available()
    print(f"  CUDA (NVIDIA)  : {'✅ 可用' if cuda_ok else '❌ 不可用'}")
    if cuda_ok:
        print(f"    显卡         : {torch.cuda.get_device_name(0)}")
        total = torch.cuda.get_device_properties(0).total_memory / 1024**3
        print(f"    显存         : {total:.1f} GB")

    mps_ok = getattr(torch.backends, "mps", None) and torch.backends.mps.is_available()
    print(f"  MPS (Mac M 系列): {'✅ 可用' if mps_ok else '❌ 不可用'}")

    if cuda_ok:
        device = "cuda"
    elif mps_ok:
        device = "mps"
    else:
        device = "cpu"
    print(f"  → 推荐使用 device = '{device}'")
else:
    print("  PyTorch 未安装，跳过")
    print("  → 但这不影响你学习：本库所有原理篇代码只需要 numpy")

section("4. 用 numpy 做一次实际计算")

if available.get("numpy"):
    import time
    import numpy as np

    # 矩阵乘法是深度学习最核心的运算，用它测一下 CPU 性能
    n = 800
    rng = np.random.default_rng(0)
    A = rng.normal(0, 1, (n, n))
    B = rng.normal(0, 1, (n, n))

    t0 = time.perf_counter()
    C = A @ B
    elapsed = time.perf_counter() - t0

    # 矩阵乘法的浮点运算次数约为 2 * n^3
    gflops = (2 * n ** 3) / elapsed / 1e9

    print(f"  {n}×{n} 矩阵乘法")
    print(f"    耗时      : {elapsed * 1000:.1f} ms")
    print(f"    等效算力  : {gflops:.1f} GFLOPS")
    print(f"    结果校验  : C 的形状 {C.shape}，均值 {C.mean():.4f}")
    print()
    print("  → 能跑出这个结果，说明你已经可以开始学本库的原理篇了")
else:
    print("  numpy 未安装。先执行: pip install numpy")

section("5. 下一步建议")

if not available.get("numpy"):
    print("  1. 装 numpy: pip install numpy")
    print("  2. 重跑本脚本")
elif not available.get("torch"):
    print("  当前环境足够学习本库全部原理篇（只需 numpy）。")
    print("  等你要训练真实模型时，再去 pytorch.org 按硬件选对版本安装。")
else:
    print("  环境完备。建议起点:")
    print("    数学基础 → 神经网络原理 → 训练工程")
```

## 6. 常见问题速查

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| `pip install` 极慢或中断 | 走境外源 | 配国内镜像（第 3 节） |
| `torch.cuda.is_available()` 是 False | 装了 CPU 版 / 驱动旧 / 版本不匹配 | 按官网选择器重装 |
| `CUDA out of memory` | 显存不够 | 减小 batch size、用梯度累积、上 LoRA/量化 |
| 装了包但 import 报找不到 | 装到了别的环境 | 用第 5 节脚本看「解释器路径」 |
| Notebook 结果诡异 | 格子执行顺序乱了 | Restart & Run All |
| 云端跑到一半断了，进度全无 | 没存 checkpoint | 定期保存模型状态 |
| Mac 上跑很慢 | 无 CUDA | 学原理够用；训模型转云端 |
| HuggingFace 下载模型卡住 | 境外源 | 设 `HF_ENDPOINT=https://hf-mirror.com` |

`CUDA out of memory` 是最高频的报错，系统性的省显存手段见 [学习率调度与训练技巧](../machine-learning/05-训练工程/04-学习率调度与训练技巧.md) 的梯度累积与混合精度部分。

## 7. 小结

| 要点 | 内容 |
| --- | --- |
| **先别卡在环境上** | 本库 30+ 篇原理笔记只需要 numpy，纯 CPU 就能全部跑完 |
| 三条算力路径 | 云端 Notebook（起步）→ 本地（稳定）→ 租 GPU（要微调时） |
| **Colab 在大陆访问不通** | 改用百度 AI Studio、天池、ModelScope、Kaggle、启智 |
| **必配镜像源** | 不配 pip 镜像，`install torch` 基本装不上 |
| 一个项目一个环境 | uv 或 conda，别把包全装进同一个环境 |
| PyTorch 要按硬件装 | 去官网选择器生成命令，装完必须验证 |
| Mac M 系列 | 可用 MPS 后端，有加速但不如 NVIDIA，学原理够用 |
| **训练必存 checkpoint** | 云端断开是常态，不存就白跑 |
