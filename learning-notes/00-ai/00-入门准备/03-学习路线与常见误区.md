## 0. 这篇解决什么问题

前两篇解决了「概念是什么」和「代码在哪跑」。这篇解决**怎么学**——具体的顺序、节奏、自检方法，以及一份「别人踩过的坑」清单。

本篇的所有建议都基于一个前提：**你是工作多年的程序员，数学多年没碰，时间碎片化。** 如果你是在校学生有整块时间，某些建议（比如「不要先补完数学」）可能不适用。

## 1. 核心原则：不要线性补完前置

最常见也最致命的错误：

```
❌ 错误路径
   先花两个月把数学补完
        ↓
   再花一个月学 Python
        ↓
   再开始学 AI
        ↓
   （实际结果：补数学补到一半就放弃了，因为看不到用处）
```

```
✅ 推荐路径
   直接读 AI 笔记
        ↓
   卡在某个公式 ──► 去查那一个概念 ──► 回来继续
        ↓
   在「有具体用处」的驱动下补数学，效率高得多
```

**原因**：脱离用途学数学，你不知道该学到什么深度、也没有反馈。而带着「我要看懂反向传播」这个具体目标去补链式法则，你会立刻知道够不够用。

本库的数学基础四篇就是按这个思路写的——它们是**查阅手册**，不是必须先读完的教材。详见 [微积分够用篇](../01-machine-learning/00-数学基础/01-微积分够用篇.md) 开头的定位说明。

## 3. 单篇怎么读：三遍法

一篇 15KB 的原理笔记，建议这么读：

```
第一遍（5 分钟）  只看标题、小结表格、代码的输出
                  目的：知道这篇讲什么、值不值得细读

第二遍（20 分钟） 正常读，卡住就记在卡点列，不硬啃
                  目的：理解主线

第三遍（10 分钟） 合上笔记，尝试回答开头的三个问题
                  目的：验证真的懂了
```

**第三遍是最容易被跳过、但最重要的一步。**「看着眼熟」和「能讲出来」之间差距巨大，而只有后者能在你实际用到时被调取出来。

### 自测标准

每篇笔记开头都有「读完你能回答的 3 个问题」。判定标准：

| 判定 | 标准 |
| --- | --- |
| ❌ 不算会 | 「我记得笔记里讲过这个」 |
| ❌ 不算会 | 能指出答案在哪一节 |
| ✅ 算会 | **合上笔记，用自己的话讲一遍，讲得通** |

用 [ai-learning-progress.md](../ai-learning-progress.md) 记录状态，它有专门的三格自测栏。

### 关于代码

本库所有原理篇都配了可运行的 numpy 代码。**建议至少跑一遍，最好敲一遍。**

原因很实际：读公式时你可能觉得「大概懂了」，但敲代码时会被迫面对每一个细节——形状怎么对齐、符号在哪、为什么要转置。这些细节正是「懂」和「以为懂」的分界线。

## 4. 卡住怎么办

卡住是常态，不是失败。按这个顺序处理：

```
1. 先记下来，不硬啃
   在进度文件的卡点列写具体位置：「§3 递推式那步不理解为什么能交换求和顺序」
        ↓
2. 跳过继续读
   很多时候后文会解释，或者读完全篇自然明白
        ↓
3. 攒 2~3 个卡点再一起处理
   集中攻破比逐个纠缠效率高
        ↓
4. 处理方式（按性价比）
   ├─ 查该篇的「延伸阅读」，通常前置篇里有解释
   ├─ 看该篇的「推荐视频资源」，3Blue1Brown 的可视化对数学卡点特别有效
   └─ 直接问 AI：贴上那段公式说「这一步看不懂」
```

**第 4 条的最后一项被严重低估。** 你现在有一个随时可问的对象，这比自己翻教科书快得多。具体问法：贴出原文那一段，说明你卡在哪个符号或哪一步推导，而不是笼统地问「反向传播是什么」。

## 5. 常见误区清单

这些是实际学习中反复出现的坑，按危害程度排：

### 🔴 会导致放弃的

| 误区 | 后果 | 正确做法 |
| --- | --- | --- |
| **先补完所有前置再开始** | 补到一半失去动力，最常见的放弃原因 | 直接开始，卡了再查 |
| **一开始就折腾环境和 GPU** | 几天耗在配置上，还没学到东西 | 本库原理篇只需 numpy，先跑起来 |
| **追最新的模型和框架** | 学的东西三个月就过时，且学不到本质 | 先学不过期的原理层（见第 6 节） |
| **只读不动手** | 读完感觉懂了，实际用不出来 | 每篇的代码至少跑一遍 |

### 🟠 会浪费时间的

| 误区 | 后果 | 正确做法 |
| --- | --- | --- |
| 数学学到「会做题」的程度 | 花几倍时间，收益很小 | 「看懂公式」就够，见数学四篇的定位说明 |
| 同时开五个方向 | 每个都浅尝辄止 | 一次一篇，读完自测再开下一篇 |
| 收藏大量教程不看 | 收藏夹变成焦虑来源 | 只留当前阶段用得上的 |
| 跟着教程复现但不改一行 | 复现成功≠理解 | 故意改参数，看结果怎么变、为什么 |

### 🟡 会造成认知偏差的

| 误区 | 实际情况 |
| --- | --- |
| 「深度学习淘汰了传统 ML」 | 表格数据上树模型至今常胜，且快得多 |
| 「模型越大越好」 | 很多任务小模型 + 好数据 + 微调完全够 |
| 「参数量决定能力」 | 数据质量、训练方法、对齐质量同样关键 |
| 「跑通了就是学会了」 | 跑通只证明环境对，不证明你理解 |
| 「单次实验结果能证明改进有效」 | 随机波动常常大于改进幅度，详见 [实验设计与可复现性](../01-machine-learning/01-机器学习基础/03-实验设计与可复现性.md) |
| 「幻觉是可以彻底修掉的 bug」 | 源于概率生成机制本身，只能缓解 |

倒数第二条值得强调：这是从「会跑代码」到「会做研究」的分水岭。改进前跑一次 87.2%、改进后跑一次 88.1%，看起来提升了 0.9%——但如果同一套配置跑 5 次的自然波动是 ±1.2%，这 0.9% 什么也没证明。

## 6. 关于「AI 日新月异」的焦虑

这是最值得单独说的一节，因为它决定你的时间投在哪。

### 分层看过期速度

```
                              过期速度        本库覆盖
┌────────────────────────────────────────────────────────┐
│ 数学、反向传播、PCA、贝尔曼方程    几乎不过期    34 篇   │  ← 80% 时间投这里
├────────────────────────────────────────────────────────┤
│ Transformer 结构、注意力机制      8 年仍主流    3 篇    │
├────────────────────────────────────────────────────────┤
│ 「现代 LLM 用 SwiGLU/RMSNorm」    半年~一年     已标记  │
├────────────────────────────────────────────────────────┤
│ 具体框架 API、模型榜单            数周~数月     应用层  │  ← 别在这里花大量时间
└────────────────────────────────────────────────────────┘
```

**关键判断：真正天天变的只有最底下那层。** 而那一层恰恰是最不值得系统学习的——它应该「用到时查文档」，而不是「提前背下来」。

### 具体建议

| 做法 | 理由 |
| --- | --- |
| **80% 时间投原理层** | 学会反向传播，十年后还是这个反向传播 |
| 框架 API 用到再查 | 记不住也不必记，文档随时在 |
| 用简报系统被动跟进 | 本库 `_briefings/` 每天采集三主题动态，扫标题即可 |
| 判断新东西时问「它属于哪一层」 | 底层创新值得学，上层封装扫一眼就够 |

本库已有的更新机制：`.kiro/hooks/41-tool-doc-update-check` 会增量更新笔记，并且**刻意设置了「原理层默认跳过」的策略**——因为给不会过期的内容加更新标记只会制造噪音。

### 一个判断新技术的实用问题

看到任何新框架、新模型、新概念，问一句：

> **它是解决了一个新问题，还是给旧问题换了个更好的包装？**

前者值得花时间理解原理；后者知道存在、会用就行。

举例：Transformer 出现时解决的是「RNN 无法并行」这个真问题，值得深入；而无数 Agent 框架本质都是「LLM + 工具调用循环」的不同封装，理解了 [Agentic 设计模式](../04-ai-agent/01-Agentic设计模式/02-Agentic设计模式大全.md) 之后，具体框架花半天就能上手。

## 7. 节奏建议

针对「工作多年、时间碎片化」的现实：

| 建议 | 说明 |
| --- | --- |
| 单篇预算 20~30 分钟 | 超时说明前置缺了，去补前置而不是硬扛 |
| 一次只推进一篇 | 读完立刻自测，不要连读三篇再回头 |
| 每周回看进度文件一次 | 看有没有卡点一直没解决——那通常指向真实的知识断层 |
| 允许跳过 | 遇到当前用不上的（比如 SVM 对偶推导），标记后置，不要卡在那 |
| 阶段 1 尽量连续 | 神经网络原理那 9 篇有强依赖，间隔太久要重新捡 |

**关于「学多久能有用」**：阶段 1 结束（约 3~4 周）你就能看懂大部分模型行为的讨论；阶段 3 结束能独立判断微调和推理优化方案。这个预期比「学完全部」现实得多。
