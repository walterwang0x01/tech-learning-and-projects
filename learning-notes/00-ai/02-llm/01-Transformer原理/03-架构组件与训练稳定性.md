## 1. FFN 层：逐位置的非线性变换

多头注意力算完之后，Transformer 每一层还有一个前馈网络（Feed-Forward Network, FFN），对序列中每个位置的向量独立地做同样的两层全连接变换：

```
FFN(x) = W_2 · activation(W_1 · x + b_1) + b_2

x 形状: [d_model]
W_1 形状: [d_model, d_ff]     ← 升维
W_2 形状: [d_ff, d_model]     ← 降回原维度
```

[注意力层](01-注意力机制推导.md)做的事情是"在不同位置之间交换、聚合信息"；FFN 做的事情是"对聚合完的信息做非线性加工"——把注意力汇聚来的信息，在一个更高维的空间里做非线性变换，再压缩回原维度。两者是互补的：注意力负责位置间的信息流动，FFN 负责单个位置上的特征加工与非线性表达能力补充（自注意力本身是加权求和，是线性操作，整个模型的非线性能力主要来自 FFN 里的激活函数）。

`d_ff`（FFN 中间层维度）通常显著大于 `d_model`，一个常见的经验设计是升维到 4 倍左右（即 `d_ff ≈ 4 × d_model`），这个倍数并非理论上唯一正确的选择，不同模型架构会有出入。

> ⚠️ 待确认：不同具体模型采用的确切升维比例、以及现代模型（如采用 SwiGLU 等变体激活函数的模型）中 FFN 内部结构的具体调整，因模型而异，这里不做具体数值断言。

## 2. 残差连接与 LayerNorm：Pre-LN vs Post-LN

### 2.1 残差连接：为什么必须有

Transformer 每一个子层（注意力子层、FFN 子层）的输出都不是直接替换输入，而是"输入 + 子层的变换量"：`y = x + SubLayer(x)`。这个设计的价值在[反向传播推导](../../01-machine-learning/04-神经网络原理/02-反向传播推导.md)中已经讲过核心机制：`∂y/∂x = 1 + ∂SubLayer/∂x`，那个常数 `1` 保证了梯度无论如何都能原样传下去一部分，不会因为某个子层的梯度很小就导致整条链路梯度消失。Transformer 通常堆叠几十层，没有残差连接，这么深的堆叠在实践中几乎无法稳定训练。

### 2.2 Post-LN 与 Pre-LN

原始 Transformer 论文采用的顺序是：先做子层变换和残差相加，再做 LayerNorm：

```
Post-LN:
  y = LayerNorm(x + SubLayer(x))
```

后续大量工作发现，把 LayerNorm 挪到子层变换之前、残差相加发生在 LayerNorm 之后，训练稳定性明显更好：

```
Pre-LN:
  y = x + SubLayer(LayerNorm(x))
```

### 2.3 为什么顺序会影响训练稳定性

关键在于**残差路径上是否存在归一化操作**。Post-LN 下，残差相加之后还要过一次 LayerNorm（`x → [+SubLayer(x)] → LayerNorm(...)`），这意味着"恒等映射"这条路径（跳过 SubLayer 的部分）在每一层都被 LayerNorm 重新缩放了一次。Pre-LN 下，`x` 本身直接、原封不动地加到输出上（`x → [+SubLayer(LayerNorm(x))]`），LayerNorm 只作用在进入 SubLayer 之前的分支，不影响残差主干这条"直通路径"。

用反向传播的视角看：Pre-LN 下，从输出到输入 `x` 的梯度路径中，主干上的梯度就是纯粹的恒等 `1` 项（不经过 LayerNorm 的梯度变换），梯度可以几乎不受衰减地直接传回浅层。Post-LN 下，因为残差相加之后还要过 LayerNorm，主干上的梯度也会被 LayerNorm 的梯度项影响，多层堆叠后这种影响会累积。

实践中的表现：**层数较浅时 Post-LN 和 Pre-LN 差异不大，甚至 Post-LN 在收敛后的最终效果上可能略有优势；但堆叠层数很深时（几十层以上），Post-LN 明显更容易出现训练不稳定（如损失震荡、爆炸），需要更精细的学习率热身（warmup）策略配合，而 Pre-LN 天然对深层堆叠更友好，训练更稳定**。这是现代大规模语言模型普遍采用 Pre-LN 架构的直接原因。

> ⚠️ 待确认：具体某个模型使用的是 Pre-LN、Post-LN 还是其他变体（如 Sandwich-LN），因模型而异，这里只讨论两种设计的一般性权衡，不对具体模型架构做断言。

## 3. 掩码机制：padding mask 与 causal mask

注意力计算默认是"每个位置可以看到序列中所有位置"，但两种场景需要显式地屏蔽掉某些位置，不让它们参与注意力计算。

### 3.1 Padding mask：屏蔽填充位置

训练时为了把不同长度的句子拼成一个批次（batch），通常会把较短的句子用填充符（padding token）补齐到统一长度。这些填充位置本身不携带真实语义，不应该被其他真实 token 关注。做法是在计算 softmax 之前，把填充位置对应的注意力分数设为 `-∞`（或一个绝对值很大的负数），`softmax(-∞) → 0`，这个位置的注意力权重就变成 0，等效于完全屏蔽。

### 3.2 Causal mask（因果掩码）：防止看到未来

在自回归生成任务中（如语言模型逐词生成下一个词），模型在预测第 `t` 个位置的输出时，只能利用第 `1` 到第 `t` 个位置的信息，不能"偷看"第 `t+1` 及之后的信息（否则训练时相当于用答案本身预测答案）。做法是构造一个下三角矩阵形式的掩码，位置 `(i, j)` 当 `j > i` 时（j 在 i 之后）设为 `-∞`：

```
序列长度 4 的 causal mask（1 表示可见，0 表示屏蔽，经过 softmax 前设为 -∞）：

  位置\被关注位置   1   2   3   4
       1           1   0   0   0     ← 位置1只能看到自己
       2           1   1   0   0     ← 位置2能看到1、2
       3           1   1   1   0     ← 位置3能看到1、2、3
       4           1   1   1   1     ← 位置4能看到1、2、3、4
```

Padding mask 和 causal mask 可以同时使用（生成任务里，一个位置同时需要屏蔽"未来位置"和"填充位置"），两者共同作用的方式是把各自的 `-∞` 掩码在加到分数上时叠加（或取逻辑与）。

## 4. 三种架构：Encoder-only / Decoder-only / Encoder-Decoder

Transformer 原始论文提出的是 Encoder-Decoder 完整架构，后续研究发现可以只用其中一部分，衍生出三条不同的路线，适用场景也不同。

**Encoder-only（如 BERT 一类模型）**：结构上只有 Encoder 堆叠，每层是"双向自注意力（无 causal mask）+ FFN"，每个位置可以同时看到它左边和右边的所有位置（双向）。适用于需要对整段输入做深度理解的任务——文本分类、命名实体识别、句子相似度判断等"理解型"任务，不需要自回归生成新文本。

**Decoder-only（如 GPT 系列一类模型）**：结构上只有 Decoder 堆叠，每层是"带 causal mask 的自注意力 + FFN"，每个位置只能看到它自己和它左边的位置（单向、因果）。适用于自回归文本生成——给定前文，逐词预测下一个词，这是目前绝大多数通用大语言模型采用的架构。

**Encoder-Decoder（如早期机器翻译一类模型）**：Encoder 先对完整输入序列做双向编码，Decoder 在生成输出时，除了自身的 causal 自注意力，还有一个额外的"交叉注意力（cross-attention）"层，Query 来自 Decoder 当前状态，Key/Value 来自 Encoder 的输出。输入和输出是两个不同的序列（如源语言句子 → 目标语言句子），Decoder 生成每个词时都能直接查询整个源序列的编码结果，适用于输入输出结构不同的序列到序列任务——机器翻译、摘要生成。

**为什么现代 LLM 几乎全部走 Decoder-only 路线**：一个直接的原因是，Decoder-only 架构训练时的任务形式最统一、最简单——"预测下一个词"这一个目标就能同时兼顾理解和生成（因为要预测好下一个词，模型必须先充分理解前文），不需要像 Encoder-Decoder 那样为不同任务设计不同的输入输出结构。这种"单一目标、大规模数据、大规模参数"的组合，被证明在扩展性（scaling）上效果显著，是现阶段通用大语言模型的主流选择。

> ⚠️ 待确认：三种架构在具体任务上的性能对比、以及"为什么 Decoder-only 能扩展得更好"背后更深层的理论解释，学术界仍有不同角度的讨论，这里只给出结构性差异，不做效果优劣的定量断言。

## 5. 最小可运行实现：验证 causal mask 的屏蔽效果

```python
"""
用 numpy 验证 causal mask 对注意力权重的实际屏蔽效果：
构造下三角掩码，确认每个位置的注意力权重严格不分配给"未来"位置。
仅依赖 numpy，注释用中文。
"""
import numpy as np


def softmax(x, axis=-1):
    """数值稳定的 softmax"""
    x_shifted = x - np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(x_shifted)
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)


def scaled_dot_product_attention(Q, K, V, mask=None):
    """缩放点积注意力，mask 为 True 的位置会被屏蔽（softmax 后权重趋近 0）"""
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    if mask is not None:
        scores = np.where(mask, -1e9, scores)
    weights = softmax(scores, axis=-1)
    return weights @ V, weights


if __name__ == "__main__":
    rng = np.random.default_rng(42)
    seq_len, d_k = 5, 8

    Q = rng.normal(0, 1, (seq_len, d_k))
    K = rng.normal(0, 1, (seq_len, d_k))
    V = rng.normal(0, 1, (seq_len, d_k))

    print("=== Causal mask 效果验证 ===")
    # np.triu(k=1): 主对角线以上（不含对角线）为 True，即"未来"位置
    causal_mask = np.triu(np.ones((seq_len, seq_len), dtype=bool), k=1)
    print("causal mask（True=屏蔽）:")
    print(causal_mask)

    _, weights = scaled_dot_product_attention(Q, K, V, mask=causal_mask)
    print("\n第 1 行注意力权重（只能关注位置0）:", weights[0].round(3))
    print("第 3 行注意力权重（能关注位置0,1,2）:", weights[2].round(3))
    print("第 5 行注意力权重（能关注全部位置）:", weights[4].round(3))

    # 验证：每一行"未来"位置（j > i）的权重严格为 0
    all_future_zero = True
    for i in range(seq_len):
        future_weights = weights[i, i + 1:]
        if len(future_weights) > 0 and not np.allclose(future_weights, 0):
            all_future_zero = False
    print("\n所有位置的未来权重是否严格为0:", all_future_zero)
```

实测输出（numpy 2.4.4）：

```
=== Causal mask 效果验证 ===
causal mask（True=屏蔽）:
[[False  True  True  True  True]
 [False False  True  True  True]
 [False False False  True  True]
 [False False False False  True]
 [False False False False False]]

第 1 行注意力权重（只能关注位置0）: [1. 0. 0. 0. 0.]
第 3 行注意力权重（能关注位置0,1,2）: [0.371 0.427 0.202 0.    0.   ]
第 5 行注意力权重（能关注全部位置）: [0.116 0.295 0.231 0.132 0.225]

所有位置的未来权重是否严格为0: True
```

结果验证了两点：第 1 行（位置 0）注意力权重是 `[1, 0, 0, 0, 0]`——只能关注自己；第 3 行（位置 2）权重只分布在前 3 个位置上，第 4、5 个位置权重严格为 0；最后一条校验确认所有位置的"未来"权重严格为 0，正确实现了因果掩码。

## 6. 小结

| 组件 | 核心作用 | 关键设计要点 |
| --- | --- | --- |
| FFN | 对聚合后的信息做非线性加工，补充非线性表达能力 | 通常先升维再降回，具体倍数因模型而异 |
| 残差连接 | 保证深层堆叠时梯度能原样传回浅层 | `∂y/∂x` 中恒定的 `1` 项，防止梯度消失 |
| LayerNorm 位置 | 影响残差主干上是否存在归一化，进而影响深层训练稳定性 | Pre-LN 的残差主干不经过归一化，深层堆叠更稳定；Post-LN 深层时更容易训练不稳定 |
| 掩码机制 | 屏蔽不该被关注的位置 | padding mask 屏蔽填充符；causal mask 屏蔽未来位置，防止生成任务中的信息泄露 |
| 架构选择 | 适配不同任务的输入输出结构 | Encoder-only 双向理解；Decoder-only 自回归生成（现代 LLM 主流）；Encoder-Decoder 处理输入输出不同序列的任务 |
