## 2. 核心三大概念

```
Rust 靠三个概念实现"零成本内存安全"：
├─ Ownership（所有权）
├─ Borrowing（借用）
└─ Lifetimes（生命周期）

编译器强制检查，运行时零开销
```

## 3. 变量与可变性

```rust
fn main() {
    let x = 5;              // 不可变
    // x = 6;               // ❌ 编译错

    let mut y = 5;          // 可变
    y = 6;                  // ✅

    const MAX: u32 = 100_000;  // 常量
    let z: i64 = 42;           // 显式类型

    let s = String::from("hello");
    let s = format!("{}!", s);   // 同名变量 shadowing（新变量）
}
```

## 4. Ownership：Rust 的核心

每个值有一个"所有者"，所有者离开作用域时值被丢弃。

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;            // s1 的所有权移到 s2
    // println!("{}", s1);  // ❌ s1 已失效

    let s3 = s2.clone();    // 显式深拷贝
    println!("{} {}", s2, s3);  // ✅

    // 栈上类型（如 i32）实现了 Copy trait，赋值自动复制
    let x = 5;
    let y = x;
    println!("{} {}", x, y);    // ✅
}
```

### 函数调用

```rust
fn takes_ownership(s: String) {
    println!("{}", s);
}   // s 在这里被释放

fn main() {
    let s = String::from("hello");
    takes_ownership(s);
    // println!("{}", s);   // ❌ s 已被移走
}
```

## 5. Borrowing：借用

```rust
// 不可变借用（可以多个）
fn read(s: &String) {
    println!("{}", s);
}

// 可变借用（同一时刻只能一个）
fn append(s: &mut String) {
    s.push_str("!");
}

fn main() {
    let s = String::from("hello");
    read(&s);         // 借用
    read(&s);         // 再借用
    println!("{}", s); // s 还活着

    let mut t = String::from("world");
    append(&mut t);
    println!("{}", t); // world!
}
```

**借用规则**（编译期强制）：
- 要么多个不可变借用，要么一个可变借用（不能混）
- 借用不能比所有者活得长

这两条规则就能**在编译期消除 90% 的并发 bug**。

## 6. 生命周期

```rust
// 返回值的生命周期必须和输入关联
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

fn main() {
    let s1 = String::from("longstring");
    let result;
    {
        let s2 = String::from("short");
        result = longest(&s1, &s2);
        // result 的生命周期 = s1 和 s2 的较小者
        println!("{}", result);
    }   // s2 在此释放
    // println!("{}", result);  // ❌ 如果 result 是 s2 的引用
}
```

**实际编程中**，大多数生命周期可以省略（编译器推断）。只有编译器拿不准时才要显式标注。

## 7. Struct 与 enum

```rust
struct User {
    username: String,
    email: String,
    active: bool,
}

impl User {
    fn new(username: String, email: String) -> Self {
        Self { username, email, active: true }
    }

    fn is_active(&self) -> bool {
        self.active
    }

    fn deactivate(&mut self) {
        self.active = false;
    }
}

// enum 是 Rust 特别强大的概念
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}

// 模式匹配（穷尽性检查）
fn process(msg: Message) {
    match msg {
        Message::Quit => println!("quit"),
        Message::Move { x, y } => println!("move to {}, {}", x, y),
        Message::Write(text) => println!("write: {}", text),
        Message::ChangeColor(r, g, b) => println!("color ({}, {}, {})", r, g, b),
    }
}
```

## 8. Option 和 Result：没有 null 和 exception

```rust
// 可能没有值 → Option
fn find_user(id: u64) -> Option<User> {
    if id == 1 {
        Some(User::new("alice".into(), "a@example.com".into()))
    } else {
        None
    }
}

// 可能失败 → Result
fn read_file(path: &str) -> Result<String, std::io::Error> {
    std::fs::read_to_string(path)
}

fn main() {
    match find_user(1) {
        Some(user) => println!("{}", user.username),
        None => println!("not found"),
    }

    // ? 操作符：自动传播错误
    fn load() -> Result<String, std::io::Error> {
        let content = std::fs::read_to_string("file.txt")?;
        Ok(content.to_uppercase())
    }
}
```

**没有 null 和异常**就意味着所有"可能失败"的情况必须显式处理。这是 Rust 代码质量高的核心原因之一。

## 9. Trait（类似接口）

```rust
trait Summary {
    fn summarize(&self) -> String;

    // 默认实现
    fn headline(&self) -> String {
        format!("(Read more: {})", self.summarize())
    }
}

struct Article {
    title: String,
    content: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("{}, by...", self.title)
    }
}

// 泛型 + trait bound
fn notify<T: Summary>(item: &T) {
    println!("Breaking news: {}", item.summarize());
}

// impl trait 语法糖
fn make_summary() -> impl Summary {
    Article { title: "...".into(), content: "...".into() }
}
```

## 10. 所有权应用示例

```rust
// 错误的 C 风格思维
fn wrong() {
    let s = String::from("hello");
    let len = s.len();
    let first_word = &s[..5];    // 借用 s 一部分

    let mut s2 = s;              // ❌ 错误：s 被 first_word 借用，不能移动
    s2.clear();
}

// 正确的 Rust 思维
fn right() {
    let mut s = String::from("hello world");
    let len: usize;
    {
        let first_word = &s[..5];  // 借用
        len = first_word.len();
    }                              // 借用在此结束
    s.clear();                      // 现在可以改 s
    println!("first word len: {}", len);
}
```

## 11. Edition 2024

```
├─ 新的 match 人体工程学
├─ let chains（if let && x = y 组合）
├─ impl Trait 生命周期规则改进

└─ 部分 API 稳定性调整
```

## 12. 常见错误和修复

```
错误："cannot borrow `x` as mutable more than once"
修复：缩小借用作用域，或改用 Cell / RefCell（运行时检查）

错误："value moved here"
修复：用 clone()，或改成引用 &

错误："missing lifetime specifier"
修复：加 'a 或 '_ 标注

错误："cannot return reference to local variable"
修复：返回所有权（String 而非 &str），或接入参数的生命周期

错误："dropped while still borrowed"
修复：调整变量顺序，或用 Arc / Rc 共享所有权
```
