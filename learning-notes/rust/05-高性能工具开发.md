## 1. 为什么很多工具用 Rust 重写

```
2023-2026 的"大重写"：
├─ Python 包管理：pip → uv（10-100x）
├─ Python Lint：flake8 + isort + black → ruff（100x）
├─ JS 打包：Webpack → Rspack / Turbopack（10-50x）
├─ JS 编译：Babel → SWC（50-100x）
├─ CSS：PostCSS → Lightning CSS（100x）
├─ JS Lint：ESLint → Biome / oxlint（50-100x）
├─ Node 工具：ts-node → tsx（Rust 部分，10x）
└─ JS Runtime：Bun（Zig → Rust，2026-05-14 合并，96 万行 AI 辅助迁移）
```

核心原因：Rust 启动快、无 GC、可多核并行，特别适合 CLI 工具链场景。

## 2. 写 CLI 工具

```bash
cargo new --bin mytool
cd mytool
```

```toml
# Cargo.toml
[package]
name = "mytool"
version = "0.1.0"
edition = "2024"

[dependencies]
clap = { version = "4.5", features = ["derive"] }
tokio = { version = "1.49", features = ["full"] }
anyhow = "1.0"
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"
tracing = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter"] }
```

```rust
// src/main.rs
use anyhow::Result;
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "mytool", version, about = "My CLI tool")]
struct Cli {
    #[command(subcommand)]
    command: Commands,

    #[arg(short, long, global = true)]
    verbose: bool,
}

#[derive(Subcommand)]
enum Commands {
    /// Convert input to uppercase
    Upper { text: String },

    /// Fetch a URL
    Fetch {
        url: String,
        #[arg(short, long, default_value = "5")]
        timeout: u64,
    },
}

#[tokio::main]
async fn main() -> Result<()> {
    let cli = Cli::parse();

    tracing_subscriber::fmt()
        .with_env_filter(if cli.verbose { "debug" } else { "info" })
        .init();

    match cli.command {
        Commands::Upper { text } => println!("{}", text.to_uppercase()),
        Commands::Fetch { url, timeout } => {
            let resp = reqwest::Client::new()
                .get(&url)
                .timeout(std::time::Duration::from_secs(timeout))
                .send()
                .await?;
            println!("status: {}", resp.status());
            println!("{}", resp.text().await?);
        }
    }

    Ok(())
}
```

```bash
# 本地运行
cargo run -- upper hello

# 发布构建（优化）
cargo build --release

# 交叉编译到 Linux
cargo install cross
cross build --target x86_64-unknown-linux-musl --release
```

## 3. PyO3：Python 扩展

让 Python 直接调用 Rust 函数。生产实例：Polars、Pydantic v2、tiktoken 核心。

```toml
# Cargo.toml
[lib]
name = "myrust"
crate-type = ["cdylib"]

[dependencies]
pyo3 = { version = "0.24", features = ["extension-module"] }
```

```rust
// src/lib.rs
use pyo3::prelude::*;

#[pyfunction]
fn fib(n: u32) -> u64 {
    match n {
        0 => 0,
        1 => 1,
        _ => {
            let (mut a, mut b) = (0u64, 1u64);
            for _ in 2..=n {
                let c = a + b;
                a = b;
                b = c;
            }
            b
        }
    }
}

#[pyfunction]
fn sum_numbers(nums: Vec<f64>) -> f64 {
    nums.iter().sum()
}

#[pymodule]
fn myrust(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(fib, m)?)?;
    m.add_function(wrap_pyfunction!(sum_numbers, m)?)?;
    Ok(())
}
```

构建和使用：

```bash
pip install maturin

# 本地开发（构建并安装到当前 venv）
maturin develop

# 打包 wheel
maturin build --release
```

```python
import myrust

print(myrust.fib(30))
print(myrust.sum_numbers([1.0, 2.0, 3.0]))
```

```rust
use napi_derive::napi;

#[napi]
pub fn fib(n: u32) -> u64 {
    // 同 PyO3 示例
    if n < 2 { return n as u64; }
    let (mut a, mut b) = (0u64, 1u64);
    for _ in 2..=n {
        let c = a + b;
        a = b;
        b = c;
    }
    b
}

#[napi]
pub async fn fetch_url(url: String) -> napi::Result<String> {
    let text = reqwest::get(&url)
        .await
        .map_err(|e| napi::Error::from_reason(e.to_string()))?
        .text()
        .await
        .map_err(|e| napi::Error::from_reason(e.to_string()))?;
    Ok(text)
}
```

## 6. 性能优化要点

### 6.1 编译优化

```toml
# Cargo.toml
[profile.release]
opt-level = 3             # 最大优化
lto = "fat"               # Link Time Optimization
codegen-units = 1         # 牺牲编译时间换运行时性能
strip = true              # 去符号表
panic = "abort"           # panic 时直接 abort（更小二进制）
```

### 6.2 数据并行：rayon

```rust
use rayon::prelude::*;

fn main() {
    let numbers: Vec<u64> = (0..1_000_000).collect();

    // 单线程
    let sum: u64 = numbers.iter().sum();

    // 多核并行（一行改动）
    let sum: u64 = numbers.par_iter().sum();
}
```

### 6.3 零拷贝字符串

```rust
// ❌ String 是堆分配
fn bad(s: &str) -> String {
    s.to_string()
}

// ✅ 借用，零拷贝
fn good(s: &str) -> &str {
    s.trim()
}

// ✅ Cow 在需要修改时才拷贝
use std::borrow::Cow;

fn process(s: &str) -> Cow<str> {
    if s.contains("_") {
        Cow::Owned(s.replace("_", "-"))
    } else {
        Cow::Borrowed(s)
    }
}
```

## 8. 实战案例：重写一个 Python 工具

假设你有个 Python CLI 慢：

```python
# Python 版：100 MB CSV 要跑 10 秒
import csv
import sys

total = 0
with open(sys.argv[1]) as f:
    reader = csv.reader(f)
    next(reader)
    for row in reader:
        total += float(row[3])

print(total)
```

Rust 重写（0.5 秒）：

```rust
use anyhow::Result;
use std::env;
use std::fs::File;
use std::io::BufReader;

fn main() -> Result<()> {
    let path = env::args().nth(1).expect("usage: sum <csv>");
    let file = File::open(path)?;
    let mut reader = csv::Reader::from_reader(BufReader::new(file));

    let mut total: f64 = 0.0;
    for result in reader.records() {
        let record = result?;
        total += record.get(3).unwrap().parse::<f64>().unwrap();
    }

    println!("{}", total);
    Ok(())
}
```

加并行（0.1 秒）：

```rust
// 用 polars 或手写 chunk
use polars::prelude::*;

fn main() -> PolarsResult<()> {
    let df = CsvReadOptions::default()
        .with_has_header(true)
        .try_into_reader_with_file_path(Some("data.csv".into()))?
        .finish()?;

    let sum = df["amount"].sum::<f64>().unwrap();
    println!("{}", sum);
    Ok(())
}
```

## 10. 反模式

```
❌ 所有字段都用 String
   → 到处堆分配，用 &str 或 Cow<str>

❌ async 覆盖一切
   → CPU 密集就用 rayon

❌ 过度抽象（泛型套泛型套泛型）
   → 编译慢，读起来痛苦

❌ 忽视 clippy 警告
   → 免费的 code review，必开

❌ 手写 unsafe 不写测试
   → unsafe 是自己承担责任

❌ 把 Rust 当 C++
   → Rust 的优势在高层抽象 + 安全，不是裸指针
```
