## 1. Rust 的错误哲学

```
Rust 没有 exception，只有：
├─ Result<T, E>  可恢复错误
├─ Option<T>     可能没值
└─ panic!        不可恢复（程序终止）

编译器强制处理：Result 不用会警告
```

## 2. Result 基础

```rust
use std::fs;
use std::io;

fn read_file(path: &str) -> Result<String, io::Error> {
    fs::read_to_string(path)
}

// match
match read_file("config.toml") {
    Ok(content) => println!("{}", content),
    Err(e) => eprintln!("error: {}", e),
}

// if let
if let Ok(content) = read_file("config.toml") {
    println!("{}", content);
}

// unwrap（调试/示例用）
let content = read_file("config.toml").unwrap();

// expect（带消息的 unwrap）
let content = read_file("config.toml").expect("config.toml required");

// unwrap_or
let content = read_file("config.toml").unwrap_or_default();
```

## 3. ? 操作符（必学）

```rust
fn load_config() -> Result<Config, io::Error> {
    let content = fs::read_to_string("config.toml")?;  // 出错直接 return
    let config: Config = toml::from_str(&content)?;
    Ok(config)
}

// 等价于
fn load_config_verbose() -> Result<Config, io::Error> {
    let content = match fs::read_to_string("config.toml") {
        Ok(c) => c,
        Err(e) => return Err(e),
    };
    // ...
}
```

`?` 会自动把 error 转换（通过 `From` trait）。

## 4. 自定义错误：thiserror

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum UserError {
    #[error("user {0} not found")]
    NotFound(u64),

    #[error("invalid email: {email}")]
    InvalidEmail { email: String },

    #[error("database error")]
    Database(#[from] sqlx::Error),     // 自动 From 实现

    #[error("io error")]
    Io(#[from] std::io::Error),
}

// 使用
fn find(id: u64) -> Result<User, UserError> {
    let user = sqlx::query_as!(User, "SELECT ...")
        .fetch_optional(&pool)
        .await?;          // sqlx::Error 自动转 UserError::Database
    user.ok_or(UserError::NotFound(id))
}
```

## 5. 应用层错误：anyhow

库内部用 thiserror（精确错误类型），应用层用 anyhow（省事）：

```rust
use anyhow::{Context, Result, anyhow};

fn process() -> Result<()> {
    let config = load_config()
        .context("loading config")?;

    let db = connect(&config.db_url)
        .context("connecting to db")?;

    let users = fetch_users(&db).await
        .context("fetching users")?;

    if users.is_empty() {
        return Err(anyhow!("no users found"));
    }

    Ok(())
}

fn main() -> Result<()> {
    process()?;
    Ok(())
}

// 错误输出：
// Error: fetching users
//
// Caused by:
//     0: connecting to db
//     1: connection refused
```

## 6. Option 处理

```rust
let x: Option<i32> = Some(5);

// unwrap_or
let v = x.unwrap_or(0);

// map
let y: Option<i32> = x.map(|n| n * 2);

// and_then（扁平化）
let z: Option<i32> = x.and_then(|n| if n > 0 { Some(n * 10) } else { None });

// 组合 Option 和 Result
let result: Result<i32, String> = x.ok_or("no value".to_string());

// ? 也能用于 Option
fn first_char(s: &str) -> Option<char> {
    let first = s.chars().next()?;  // None 则直接 return None
    Some(first.to_ascii_uppercase())
}
```

## 7. 单元测试

```rust
// src/math.rs
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
    }

    #[test]
    #[should_panic(expected = "divide by zero")]
    fn test_divide_by_zero() {
        divide(10, 0);
    }

    #[test]
    fn test_result() -> Result<(), String> {
        let r = parse("42")?;
        assert_eq!(r, 42);
        Ok(())
    }
}
```

```bash
cargo test                      # 所有测试
cargo test tests::test_add      # 特定测试
cargo test -- --nocapture        # 显示 println
cargo test -- --test-threads=1   # 串行跑
```

## 10. Mock 测试：mockall

```rust
use mockall::automock;

#[automock]
trait Database {
    fn find_user(&self, id: u64) -> Option<User>;
}

struct UserService<D: Database> {
    db: D,
}

impl<D: Database> UserService<D> {
    fn get(&self, id: u64) -> Option<User> {
        self.db.find_user(id)
    }
}

#[test]
fn test_user_service() {
    let mut mock = MockDatabase::new();
    mock.expect_find_user()
        .with(mockall::predicate::eq(1))
        .times(1)
        .return_const(Some(User { id: 1, name: "Alice".into() }));

    let svc = UserService { db: mock };
    let u = svc.get(1).unwrap();
    assert_eq!(u.name, "Alice");
}
```

## 11. Property-based Testing：proptest

```rust
use proptest::prelude::*;

fn reverse<T: Clone>(xs: Vec<T>) -> Vec<T> {
    xs.into_iter().rev().collect()
}

proptest! {
    #[test]
    fn reverse_twice_is_identity(xs in prop::collection::vec(any::<i32>(), 0..100)) {
        let reversed = reverse(reverse(xs.clone()));
        prop_assert_eq!(reversed, xs);
    }

    #[test]
    fn sort_is_idempotent(mut xs in prop::collection::vec(any::<i32>(), 0..100)) {
        xs.sort();
        let sorted_once = xs.clone();
        xs.sort();
        prop_assert_eq!(xs, sorted_once);
    }
}
```

Proptest 会自动生成 100 个输入尝试破解你的函数，找出边界 case。

## 14. 基准测试：Criterion

```toml
# Cargo.toml
[dev-dependencies]
criterion = "0.5"

[[bench]]
name = "my_bench"
harness = false
```

```rust
// benches/my_bench.rs
use criterion::{black_box, criterion_group, criterion_main, Criterion};

fn fibonacci(n: u64) -> u64 {
    match n { 0 => 0, 1 => 1, _ => fibonacci(n-1) + fibonacci(n-2) }
}

fn benchmark(c: &mut Criterion) {
    c.bench_function("fib 20", |b| b.iter(|| fibonacci(black_box(20))));
}

criterion_group!(benches, benchmark);
criterion_main!(benches);
```

```bash
cargo bench
# 自动生成 HTML 报告：target/criterion/report/index.html
```

## 15. 反模式

```
❌ 到处 unwrap
   → panic 信息不友好，测试和示例可以用，生产别

❌ 吞掉错误
   match result { Ok(_) => {}, Err(_) => {} }

❌ 用 unwrap 代替合理的 Result 传播
   不如用 ?

❌ 自定义错误不实现 From
   → 每次都手动 map_err，啰嗦

❌ 测试依赖外部资源（真实数据库、网络）
   → 慢、flaky
   ✅ 用 mock 或 testcontainers

❌ 不写 doctest
   /// # Examples
   /// ```
   /// assert_eq!(add(2, 3), 5);
   /// ```
   → 文档即测试，rustdoc 自动跑
```
