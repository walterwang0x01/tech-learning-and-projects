## 1. 密码学核心原语

```
对称加密（Symmetric）
  └─ 加密和解密用同一个密钥
     ├─ AES-256-GCM（推荐）
     └─ ChaCha20-Poly1305

非对称加密（Asymmetric）
  └─ 公钥加密，私钥解密
     ├─ RSA（逐步淘汰大尺寸）
     ├─ ECC（Ed25519 / X25519 推荐）
     └─ Post-Quantum（Kyber, Dilithium, 2026 NIST 标准化）

哈希（Hash）
  └─ 单向，任意长度 → 固定长度
     ├─ SHA-256 / SHA-3（通用）
     ├─ BLAKE3（快、新）
     └─ Argon2id / bcrypt（密码专用）

MAC / 签名
  └─ 数据完整性 + 认证
     ├─ HMAC-SHA256
     ├─ Ed25519（签名）
     └─ ECDSA
```

## 2. 绝对不要自己实现

**"Don't roll your own crypto"** 是铁律。

```
用标准库：
├─ Python：cryptography、pynacl
├─ Go：crypto/...、golang.org/x/crypto
├─ Rust：ring、RustCrypto 系列
├─ Java：JCE / Bouncy Castle
└─ Node.js：crypto（内置）
```

## 3. 密码哈希

**密码永远不能明文存储**，也不能用 MD5/SHA 直接 hash（太快）。

### Argon2id（推荐）

2015 年密码哈希竞赛胜出者，**新项目的默认选择**。

```python
# pip install argon2-cffi
from argon2 import PasswordHasher

ph = PasswordHasher(
    time_cost=3,
    memory_cost=65536,  # 64 MiB
    parallelism=4,
)

# 哈希
hashed = ph.hash("mypassword")
# $argon2id$v=19$m=65536,t=3,p=4$xxx$yyy

# 验证
try:
    ph.verify(hashed, "mypassword")
except VerifyMismatchError:
    print("wrong password")

# 自动 rehash（如果参数调整了）
if ph.check_needs_rehash(hashed):
    hashed = ph.hash("mypassword")
```

### bcrypt（兼容老系统）

```python
import bcrypt

hashed = bcrypt.hashpw("mypassword".encode(), bcrypt.gensalt(rounds=12))
bcrypt.checkpw("mypassword".encode(), hashed)
```

## 4. 对称加密

**推荐：AES-256-GCM 或 ChaCha20-Poly1305**。两者都是 AEAD（Authenticated Encryption with Associated Data）。

```python
# cryptography 库
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os

key = AESGCM.generate_key(bit_length=256)
aesgcm = AESGCM(key)

# 加密
nonce = os.urandom(12)           # 12 字节，每次必须唯一
plaintext = b"sensitive data"
aad = b"additional_metadata"     # 关联数据，不加密但要验证

ciphertext = aesgcm.encrypt(nonce, plaintext, aad)
# 传输：nonce || ciphertext

# 解密
decrypted = aesgcm.decrypt(nonce, ciphertext, aad)
```

**关键**：
- Nonce 每次必须唯一，**绝不能复用**
- 不用 ECB 模式（会泄露重复模式）
- CBC 模式需要显式 MAC，易出错，优先 GCM

## 5. 非对称加密

### Ed25519（推荐签名）

```python
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey

# 生成
private_key = Ed25519PrivateKey.generate()
public_key = private_key.public_key()

# 签名
signature = private_key.sign(b"message")

# 验证
try:
    public_key.verify(signature, b"message")
except InvalidSignature:
    print("invalid signature")
```

### X25519（密钥协商）

```python
from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PrivateKey

alice_private = X25519PrivateKey.generate()
bob_private = X25519PrivateKey.generate()

alice_public = alice_private.public_key()
bob_public = bob_private.public_key()

# 双方计算相同的 shared secret
alice_shared = alice_private.exchange(bob_public)
bob_shared = bob_private.exchange(alice_public)
assert alice_shared == bob_shared
```

### RSA（仍在用，但推荐 ECC）

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

private_key = rsa.generate_private_key(public_exponent=65537, key_size=4096)
public_key = private_key.public_key()

# 签名（PSS padding）
signature = private_key.sign(
    b"message",
    padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
    hashes.SHA256(),
)
```

## 6. 哈希

```python
from cryptography.hazmat.primitives import hashes

digest = hashes.Hash(hashes.SHA256())
digest.update(b"hello")
digest.update(b" world")
h = digest.finalize()
# 32 字节

# BLAKE3（更快）
# pip install blake3
import blake3
h = blake3.blake3(b"hello world").digest()
```

## 7. HMAC

```python
import hmac
import hashlib

key = b"secret"
message = b"payload"

mac = hmac.new(key, message, hashlib.sha256).digest()

# 验证（恒时比较防时序攻击）
received_mac = b"..."
if hmac.compare_digest(mac, received_mac):
    print("valid")
```

**关键**：比较 MAC / Token 必须用**恒定时间比较**（`hmac.compare_digest`、`subtle.ConstantTimeCompare` 等）。

## 8. Key Derivation（密钥派生）

从密码或共享密钥派生出加密密钥：

```python
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
from cryptography.hazmat.primitives import hashes

# HKDF：从一个共享秘密派生加密密钥
hkdf = HKDF(
    algorithm=hashes.SHA256(),
    length=32,
    salt=b"unique_salt",
    info=b"myapp v1",
)
derived = hkdf.derive(shared_secret)

# PBKDF2 / Argon2：从密码派生（慢，抗暴力）
# 对密码用 Argon2id 比 PBKDF2 强
```

## 9. 随机数

```python
# ❌ 不要用
import random
random.random()   # 可预测的

# ✅ 密码学安全随机数
import secrets
secrets.token_bytes(32)
secrets.token_hex(32)
secrets.token_urlsafe(32)   # 适合 URL / Token
secrets.randbelow(1000)
```

Go / Rust / Java / Node 都有对应的 CSPRNG API（`crypto/rand` / `rand::thread_rng` / `SecureRandom` / `crypto.randomBytes`）。

## 11. 后量子密码学（PQC）

2024-2026 年 NIST 正式发布 PQC 标准：

```
├─ FIPS 203 (ML-KEM / Kyber)：密钥封装（2024-08 已正式发布）
├─ FIPS 204 (ML-DSA / Dilithium)：签名（2024-08 已正式发布）
├─ FIPS 205 (SLH-DSA / SPHINCS+)：无状态签名（2024-08 已正式发布）
└─ FIPS 206 (FN-DSA / Falcon)：紧凑签名，仍在草案终审阶段，预计 2026 年底~2027 年初正式发布，生产环境暂不应依赖（截至 2026-07 未定稿）

为什么重要：
├─ 未来量子计算机能破 RSA、ECC
├─ "Harvest now, decrypt later" 威胁（今天抓，未来解）
└─ 敏感数据（10+ 年保密）应该考虑过渡

实践：
├─ OpenSSL 3.5+ 支持
├─ Chromium 实验 Hybrid Key Exchange
├─ Cloudflare 已部分部署
└─ 企业：追踪 NIST 建议，分阶段过渡
```

## 12. 常见误用

```
❌ MD5/SHA1 做密码哈希 → Argon2id / bcrypt
❌ 用 time() 做随机 → secrets 模块
❌ AES-ECB 加密 → AES-GCM
❌ 固定 IV/Nonce → 每次随机
❌ DES / 3DES → AES
❌ RSA 直接加密大数据 → 用 RSA 加密密钥，对称加密数据
❌ 对比 token 用 == → 用恒时比较
❌ 自己写 crypto 代码 → 用标准库
❌ 在客户端做密码验证 → 用 Passkey 或服务端验证
❌ 把密钥写在代码里 → Secrets Manager
```
