## 怎么用

**状态列**，改这一个字符即可：

| 符号 | 含义 |
| :-: | --- |
| ☐ | 未开始 |
| ◐ | 在读 |
| ☑ | 读完 |
| ★ | 自测通过（三个问题都能不看笔记答出来） |

**自测列**的三个方格对应每篇开头「读完你能回答的 3 个问题」，答出一个划掉一个：`☑☐☐`。

判定标准：**合上笔记，用自己的话讲一遍**。能讲通才算过，「看着眼熟」不算。

**卡点列**写下读不懂的具体位置，例如「§3 递推式那步不理解为什么能交换求和顺序」。
这一列是这份文件真正的价值所在——它把「我好像没学会」这种模糊焦虑，变成一条条可以单独攻破的具体问题。

## 建议节奏

- 一次只推进一篇，读完立刻做自测，不要连续读三篇再回头测
- 单篇预算 20~30 分钟。超时说明前置知识缺了，去「延伸阅读」里补前置篇
- 卡住不要硬啃：先在卡点列记下来，跳到下一篇，攒够 2~3 个卡点再集中处理
- 每周回看一次本文件，看有没有卡点一直没解决——那通常指向一个真实的知识断层
