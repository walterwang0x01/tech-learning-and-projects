# 📰 信息简报 Hook 模板

> 零代码，任何人都能用。在 Kiro 里创建一个 hook 文件，点按钮就能生成你的个人简报。

## 使用方法

1. 在你的项目根目录创建 `.kiro/hooks/` 文件夹（如果没有的话）
2. 把下面的模板文件复制进去
3. 修改 prompt 里的"关注方向"（改成你自己关心的内容）
4. 在 Kiro 的 Agent Hooks 面板里找到对应按钮，点一下
5. 等 30-60 秒，简报就出来了

## 可用模板

| 文件 | 适合谁 | 关注什么 |
|------|--------|---------|
| `my-daily-briefing.kiro.hook` | 通用版 | 自定义任何方向 |
| `competitor-briefing.kiro.hook` | 市场部 | 竞品动态 |
| `industry-briefing.kiro.hook` | 管理层 | 行业趋势 |

## 自定义指南

你只需要改 hook 文件里 `prompt` 字段中的中文部分：

- **关注方向**：换成你的行业/领域
- **关注对象**：换成你关心的公司/人/产品
- **关注维度**：换成你想追踪的信息类型
- **输出格式**：可以不改，默认格式已经很好用

## 注意事项

- 每次点按钮会用 Kiro 的 web search 能力实时搜索，所以需要联网
- 生成的内容质量取决于你的"关注方向"写得是否具体——越具体越好
- 如果觉得内容太泛，可以在"关注维度"里加更多限定词
