# 分享演示话术脚本

> Author: Walter Wang
> 总时长：10 分钟
> 准备：提前打开两个窗口——① 今天的简报文件 ② agenzo 项目的 Kiro（有竞品日报 hook）

---

## 第 1 页：封面（15 秒）

**说：**

> "大家好，今天分享一个我在实际工作中用 AI 解决的问题——信息过载。"

直接翻页，不废话。

---

## 第 2 页：痛点（1 分钟）

**说：**

> "先问大家一个问题：你每天早上花多少时间刷资讯？"

停顿 3 秒，让大家想一下。

> "我之前的状态是这样的：公众号 50 条未读、行业群 200 条消息、邮箱 3 封 newsletter。花 40 分钟刷完，真正有用的可能就 3 条。"
>
> "问题不是信息太少，是噪音太多。我需要的不是更多信息源，而是一个帮我筛选的东西。"

---

## 第 3 页：我的方案（1 分钟）

**说：**

> "所以我用 AI 搭了一套系统。它每天自动从 27 个信息源里抓取内容，分类、打分、去重，最后生成一份 5 分钟能读完的精选简报。"
>
> "已经连续跑了 28 天，没断过。不是 demo，是我每天真在用的东西。"

指着数字：

> "27 个信息源、每天只需要读 5 分钟、连续运行 28 天。"

---

## 第 4 页：现场演示——我的简报（2.5 分钟）

**说：**

> "光说没用，直接看今天的简报。"

**【切换到浏览器，打开 2026-05-15.md】**

滚动到头条部分：

> "这是今天的头条。系统从几百条信息里筛出了这两条。你看它不是复制粘贴标题，每条都有分析——发生了什么、为什么重要、对你意味着什么。"

滚动到快讯部分：

> "这是快讯，8 条一句话。30 秒扫完就知道今天行业里还发生了什么。每条带链接，想深入就点进去。"

滚动到趋势部分：

> "这个是趋势追踪。比如这条'coding agent 异步化'，已经连续出现好几天了。这说明它不是一次性新闻，是方向。单看一天你发现不了这个，连续追踪才能看到。"

**总结一句：**

> "这就是我每天早上花 5 分钟看的东西。以前要刷 40 分钟才能获得的信息密度。"

---

## 第 5 页：原理（1 分钟）

**说：**

> "原理很简单，五步。"

指着流程图从上到下：

> "第一步，抓取——27 个信息源一次全拉，RSS、新闻、社交媒体、播客都有。"
>
> "第二步，分类——自动打标签，这条是 AI 领域的、那条是国内科技的。"
>
> "第三步，打分——四个维度：新不新、一手不一手、跟我相关吗、有没有实际动作。低分的直接过滤掉。"
>
> "第四步，去重——昨天写过的不再推。"
>
> "第五步，AI 精选——大模型读完候选文章，写出带判断的摘要。不是搬运，是分析。"

**总结：**

> "一句话：AI 不替代你的判断力，而是把大海捞针变成从 10 条里选 5 条。"

快速翻页，不要在这页停太久。

---

## 第 6 页：你也能用（2.5 分钟）

**说：**

> "你可能在想：这个很酷，但我不会写代码。"
>
> "好消息是——你不需要会写代码。你电脑上的 Kiro 就能做到。"

**【切换到 agenzo 项目的 Kiro 窗口】**

> "看，我这里有个按钮叫'每日竞品简报'。"

**【指着 Agent Hooks 面板里的按钮】**

> "我点一下。"

**【点击按钮，等待生成】**

等待的时候说：

> "它现在在做什么呢？用 AI 搜索我设定的几个竞品——特斯拉、比亚迪、蔚来、小鹏——最近的动态，筛选出重要的，生成一份简报。"

**【简报生成出来后】**

> "出来了。重点动态 2-3 条，有详细分析；快讯 5 条一句话扫完。每条带原文链接。"

**【揭秘】**

> "这个按钮背后是什么？不是代码，是一段中文指令。"

**【打开 hook 文件，或者指着 PPT 上的示例】**

> "就是告诉 AI：我关注哪些竞品、关注什么维度、想要什么格式。全是中文，没有一行代码。"

**【展示不同部门的例子】**

> "市场部可以追竞品，产品部可以追用户反馈，管理层可以追行业政策，HR 可以追雇主品牌。你只需要把'竞品名字'换成你关心的东西，这个按钮就是你的了。"

---

**行动号召：**

## 附录 A：给同事的话术模板（直接粘贴到 Kiro 聊天框就能跑）

以下话术经过测试，直接复制粘贴到 Kiro 聊天框发送即可，不需要建任何文件。

### 模板 1：通用版（任何人都能用）

```
帮我搜索今天关于 AI Agent 和大模型领域的最新动态，筛选出最重要的 5 条。

要求：
1. 用 web search 搜索最近 2 天的内容
2. 每条包含：一句话标题 + 为什么重要（1-2 句）+ 原文链接
3. 用中文输出
4. 没有高质量内容就说"今天没有特别重要的动态"，不要凑数
```

### 模板 2：竞品追踪版（市场部）

```
帮我搜索比亚迪、特斯拉、蔚来这三家公司最近 2 天的最新动态。

要求：
1. 用 web search 分别搜索每家公司
2. 只保留有实际动作的新闻（发布新产品、调价、合作、财报等），过滤掉分析文章和传闻
3. 每条格式：公司名 + 做了什么 + 原文链接
4. 如果某家公司没有重要动态就跳过，不要写"暂无"
5. 用中文输出
```

### 模板 3：行业政策版（管理层）

```
帮我搜索最近 2 天中国 SaaS 和企业服务行业的重要动态。

重点关注：
- 政策法规变化
- 大额投融资事件（1 亿以上）
- 头部公司战略调整
- 行业报告发布

要求：
1. 用 web search 搜索
2. 筛选出最重要的 3-5 条
3. 每条格式：一句话说清楚 + 为什么值得关注 + 原文链接
4. 区分事实和传闻
5. 用中文输出
```

### 模板 4：技术趋势版（技术团队）

```
帮我搜索最近 2 天 Rust、Kubernetes、云原生领域的重要动态。

重点关注：
- 新版本发布
- 安全漏洞（CVE）
- 重要开源项目更新
- 技术博客和最佳实践

要求：
1. 用 web search 搜索
2. 筛选出最重要的 5 条
3. 每条格式：项目/技术名 + 发生了什么 + 对开发者意味着什么 + 链接
4. 技术术语用英文，说明用中文
5. 没有重要更新就诚实说明
```

## 附录 B：创建 Hook 的方法（让按钮永久存在）

上面的话术每次都要粘贴一遍。如果想做成一个**按钮**，每天点一下就跑，有两种方式：

### 方式 1：让 Kiro 帮你创建（推荐，最简单）

在 Kiro 聊天框里说：

```
帮我创建一个 hook 文件，保存到 .kiro/hooks/my-briefing.kiro.hook

内容如下：
{
  "name": "📰 我的每日简报",
  "version": "1.0.0",
  "description": "每天点一下，AI 帮我生成行业简报",
  "when": {
    "type": "userTriggered"
  },
  "then": {
    "type": "askAgent",
    "prompt": "请帮我搜索今天关于 AI Agent 和大模型领域的最新动态，筛选出最重要的 5 条。\n\n要求：\n1. 用 web search 搜索最近 2 天的内容\n2. 每条包含：一句话标题 + 为什么重要（1-2 句）+ 原文链接\n3. 用中文输出\n4. 没有高质量内容就说"今天没有特别重要的动态"，不要凑数"
  }
}
```

Kiro 会帮你创建文件。之后在 Agent Hooks 面板里就能看到按钮了。

### 方式 2：自己创建文件（更可控）

1. 在项目根目录下找到（或创建）`.kiro/hooks/` 文件夹
2. 新建一个文件，名字随意，后缀必须是 `.kiro.hook`，比如 `my-briefing.kiro.hook`
3. 把下面的内容粘贴进去：

```json
{
  "name": "📰 我的每日简报",
  "version": "1.0.0",
  "description": "每天点一下，AI 帮我生成行业简报",
  "when": {
    "type": "userTriggered"
  },
  "then": {
    "type": "askAgent",
    "prompt": "请帮我搜索今天关于 AI Agent 和大模型领域的最新动态，筛选出最重要的 5 条。\n\n要求：\n1. 用 web search 搜索最近 2 天的内容\n2. 每条包含：一句话标题 + 为什么重要（1-2 句）+ 原文链接\n3. 用中文输出\n4. 没有高质量内容就说"今天没有特别重要的动态"，不要凑数"
  }
}
```

4. 保存后刷新 Kiro，Agent Hooks 面板里就会出现"📰 我的每日简报"按钮

### 如何定制

只需要改 `prompt` 字段里的中文部分：

- 把"AI Agent 和大模型领域"换成你关心的方向
- 把"5 条"换成你想要的数量
- 加上你关注的具体公司或话题

其他字段不用动。

## 附录 C：竞品日报 Hook 完整文件（演示用）

这是分享时现场演示的那个 hook，已经在 agenzo 项目里创建好了：

文件路径：`.kiro/hooks/daily-competitor-brief.kiro.hook`

```json
{
  "name": "📰 每日竞品简报",
  "version": "1.0.0",
  "description": "点击按钮，AI 自动搜索竞品最新动态并生成简报",
  "when": {
    "type": "userTriggered"
  },
  "then": {
    "type": "askAgent",
    "prompt": "请帮我生成今天的竞品动态简报。\n\n## 关注竞品\n特斯拉、比亚迪、蔚来、小鹏、理想\n\n## 关注维度\n新车发布、价格调整、技术突破、高管动态、营销活动\n\n## 执行步骤\n1. 用 web search 逐个搜索以上竞品最近 2 天的最新动态\n2. 筛选出真正重要的信息（有实际动作的优先，过滤软文和传闻）\n3. 按以下格式输出\n\n## 输出格式\n\n# 竞品日报 — [今天日期]\n\n## 📌 重点动态（2-3 条）\n每条包含：\n- 哪个竞品 + 做了什么\n- 对我们意味着什么（一句话分析）\n- 原文链接\n\n## ⚡ 快讯\n其余动态，每条一句话 + 链接。按竞品分组。\n\n## 规则\n- 用中文输出\n- 每条必须有来源链接\n- 如果某个竞品今天没有重要动态，直接跳过\n- 区分事实和传闻，传闻标注"据报道"\n- 不要凑数，宁少勿滥"
  }
}
```

## 预判 Q&A

**"AI 搜的准吗？"**
> 每条都带原文链接，你可以验证。而且它是帮你筛选，不是替你做决策。

**"会不会漏掉重要信息？"**
> 我的版本 27 个源全覆盖，基本不会漏。简化版用 web search，覆盖面也很广，但确实可能漏一些小众来源。

**"每天要花多少时间？"**
> 点一下按钮，等 30 秒。读简报 5 分钟。总共不到 6 分钟。

**"跟直接问 ChatGPT 有什么区别？"**
> hook 是固定流程——你不用每次重复说一遍你关心什么。点一下就跑，格式固定，方便对比昨天和今天的变化。

**"我想追踪 XX，能做吗？"**
> 能。只要你能用中文描述清楚你关心什么，AI 就能帮你搜和筛。找我聊 5 分钟就能配好。

**"这个会不会消耗很多 AI 额度？"**
> 每次触发大概相当于一次正常的 AI 对话。每天用一次的话，完全在正常使用范围内。
