## 收录规则

1. 收录前必须确认原作者的授权允许非商业分享
2. 每个子目录必须有 `COPYRIGHT.md` 声明版权与授权条款
3. 只收 Markdown/文本，不收二进制（PDF/EPUB 体积大且不适合 git）
4. 自己的提炼写在 `我的读书笔记.md`，与原文分开——那部分是原创，适用 MIT
