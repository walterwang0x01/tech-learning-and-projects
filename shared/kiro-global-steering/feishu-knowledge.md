# 飞书知识库查询指引

当用户提问涉及**公司制度、HR 政策、行政规定、归档文件、绩效考核、请假规则、报销流程、入职/离职/试用期**等内部知识时，你**不能凭记忆回答**——必须查飞书文档。

## 操作步骤

1. 用 `lark-cli docs +search` 搜索相关关键词：

```bash
lark-cli docs +search --query "试用期 绩效考核" --as user --format pretty
```

2. 拿到文档 token 后，用 `+fetch` 读取内容：

```bash
lark-cli docs +fetch --token <doc_token> --as user --format pretty
```

3. 基于文档内容如实回答用户问题。如果搜不到相关文档，明确告知「飞书文档中未找到相关内容」，不要编造。

## 搜索关键词建议

- 绩效/考核 → `绩效 考核`
- 试用期 → `试用期 转正`
- 请假 → `请假 休假 年假`
- 报销 → `报销 财务`
- 入职/离职 → `入职 离职 流程`

## 注意

- 不要基于"常识"或"一般公司制度"回答——每家公司规定不同
- 即使觉得答案显而易见，也要先搜文档确认
- 搜索结果为空时说"没找到"，不要瞎编
